# Active Recall

**Active recall** is the mechanism by which the effortful retrieval of information from memory — rather than its passive re-exposure — strengthens later retention. It is the causal channel underlying the *testing effect*: being tested on material produces more durable learning than restudying it for an equivalent period.

## Retrieval as a learning event

The central claim is that retrieval is not merely a measurement of memory but an intervention on it. Each successful retrieval reconsolidates and strengthens the memory trace, and the difficulty of the retrieval predicts the size of the gain.

$$\text{retention} \propto \text{effort}$$

> [!tip]
> Make notes *answerable*: phrase a note so that you can hide the answer and attempt to reconstruct it. A note you can only re-read trains recognition, not recall.

## Interaction with scheduling

Active recall supplies the per-review benefit that [[spaced-repetition]] schedules over time: the spacing decides *when* to retrieve, while active recall determines *what* the retrieval does to memory. Note systems such as the [[zettelkasten]] provide the raw material, since well-formed atomic notes are easy to convert into retrieval prompts.
