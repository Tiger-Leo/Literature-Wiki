# 专利质量对企业出口竞争力的影响机制:基于知识宽度视角的探究

李 宏<sup>1</sup> 王云廷<sup>2</sup> 吴东松<sup>3</sup>

内容提要 如何通过创新驱动发展战略提升制造业企业出口竞争力是中国对外贸易转型升级面临的重要问题 专利作为创新研发的直接产物，常被用于衡量企业创新能力 文章从企业专利质量异质性出发，基于知识宽度这一视角，利用上市公司专利数据 海关进出口数据和企业财务数据估计了企业专利质量及出口竞争力，考察了企业专利质量对企业出口竞争力的影响及作用机制 实证检验发现，企业专利质量通过横向扩展出口产品种类与纵向提升出口产品质量增强了企业出口竞争力，在变换核心变量估计方法后上述结论仍稳健成立 进一步检验发现，企业专利质量对不同专利密集型企业的影响路径存在差异，在按所有制分类的子样本中，专利质量未对国有企业出口竞争力造成显著影响

关 键 词 专利质量 知识宽度 出口竞争力 上市公司 多元中介模型

作者单位 1 天津财经大学现代经济管理研究院;2 3 天津财经大学经济学院

## 一<sub>、</sub>文献综述与问题的提出

传统的经济增长理论认为，创新与技术进步是经济增长的唯一源泉 熊彼特在 《经济发展理论》一书中指出，创新是一种内在因素，所谓创新，指的是把将生产要素与生产条件的 <sup>“</sup>新组合<sup>”</sup>引入现有生产环节中 这种要素与条件的 <sup>“</sup>新组合<sup>”</sup>对生产的影响是通过改变产品结构和突破经济发展瓶颈来实现的 索洛的新古典增长理论也表明，经济的长期增长只能通过技术进步实现 改革开放以来，特别是加入世贸组织以来，出口贸易的扩张始终是中国经济高速增长的主要推动力 2019 年，中国全年出口额达到 亿美元①，自 年起已经连续 年蝉联世界货物贸易出口第一大国 但长期以来中国出口产品水平偏低( 李坤望等，2014) ，<sup>“</sup>大而不强<sup>”</sup>始终是困扰中国贸易继续发展的难题 党的十九大报告明确提出，要继续积极发展对外贸易，寻找新的贸易增长点，将中国从贸易大国转变为贸易强国这一重要论点的提出更加证明了对外贸易在中国经济体制中具有重要地位 随着人口红利逐渐消失与生产成本不断上升，如何通过自主创新进一步提升中国企业出口竞争力，成为了当前亟待解决的问题<sub>。</sub>

对于中国出口竞争力水平及影响因素，已有众多学者进行了探究<sub>。</sub> 宏观上，R<sub>o</sub>d<sub>r</sub>ik(2006) 通过对中国1999 2001 三年的出口技术复杂度进行测算，发现中国的出口竞争力水平远较其经济发展水平为高 X (2007) 研究发现，中国出口商品的组成从低端逐渐进入高端领域，并且相对价格呈明显的下降趋势 同时，对外开放水平( 李昕等，2018) FDI 与 OFDI 投入( X<sub>u</sub> 和 L<sub>u</sub>，2009; 余姗和樊秀峰，2016; 李骥宇和李宏兵，2018) 以及国内经济复杂度的提升( 李颖和佘群芝，2017) 都影响了中国出口竞争力 微观上，通过对企业的研究发现，贸易自由化程度( 杨晶晶等，2013;周茂等，2016;盛斌和毛其淋，2017) 全球价值链嵌入程度( 刘维林等，2014; 刘琳，2015) 市场规模 市场分割( 陈媛媛，2013; 赵奇伟等，2016)和融资约束( 黎日荣，2016) 等因素均对企业出口竞争力有显著影响

与本文有关的另一类文献是关于企业创新行为的研究 企业是实现创新的微观主体 王红领等(2006) 验证了<sup>“</sup>企业只要在研发创新中稍稍领先，就存在占据绝大部分市场份额的可能<sup>”</sup> B<sub>ec</sub>k<sub>er</sub> 和E (2007) 的研究发现，在创造性破坏和熊彼特增长模式中，企业能否开拓新的海外市场，产品创新占据了主导因素<sub>。</sub> 基于技术复杂度角度的研究认为，企业在创新研发领域投入越大，企业出口竞争力会随之增强( 毛其淋和方森辉，2018) 由此可见，创新是企业不断发展并提高出口竞争力的不竭动力 专利作为生产要素与研发活动的直接成果，已被众多文献作为衡量创新研发能力的指标，代表了企业在产品方面的创新能力( Ki<sub>m</sub> 等，2009;J<sub>a</sub>ll<sub>e</sub>，2010) ;同时，专利作为知识的重要载体，是一个企业的产品取得市场普遍认同和保持长期竞争优势的重要利器，其背后体现的是市场竞争主体的创新能力( Z<sub>o</sub>l<sub>tan</sub> 等，2002) <sub>。</sub>

然而，中国企业专利申请数量虽然迅速增长，但数量的上升是否能够充分反映企业专利质量和研发创新能力的提升? 年国家知识产权局发布的报告指出，中国企业虽然专利申请数量大，但高质量专利占比少，专利还不足以支撑中国经济向高端领域转型发展 张杰和郑文平(2018) 的研究也发现，中国企业长期以来存在着 <sup>“</sup>专利泡沫<sup>”</sup>问题，即在政府的创新政策激励下，企业 R＆D 效率低下，专利申请动机出现扭曲，导致大量的低质量专利产生 在这种情况下，通过研发投入或企业专利数量来衡量企业的创新研发能力难免出现偏差 企业创新能力的衡量理应从 <sup>“</sup>量<sup>”</sup>转向 <sup>“</sup>质<sup>”</sup> 通过对文献的梳理，我们发现，以往对企业出口竞争力的研究大多停留在企业的外部因素上，少有研究涉及企业自身特征对企业出口竞争力的影响 偶有涉及创新研发与企业出口行为的文献不仅缺少对其内在影响机制的挖掘，而且未深入探究企业创新成果质量高低

与既有文献相比，本文可能的贡献归结如下: 第一，本文基于上市公司专利数据，从知识宽度的角度出发，对上市公司专利质量做了更准确细致的衡量;第二，本文建立多元中介模型，不仅发现了专利质量对企业出口竞争力存在促进作用，而且检验了专利质量影响企业出口竞争力的两条路径，即横向增加出口产品种类和提供差异化产品以及纵向提升产品质量; 第三，考察了专利质量对专利密集型企业 非专利密集型企业和不同所有制企业出口竞争力影响及作用机制的差异

## 二 理论基础:专利质量如何影响企业出口竞争力

在内生技术进步模型中，企业收益递增是由知识积累引起的 有研究表明，企业由于知识积累所获得的收益增长通过垂直与水平两种具有 <sup>“</sup>创造性破坏<sup>”</sup>特征的途径实现，即制造出更高质量的产品( G<sub>rossman</sub> 和 H<sub>e</sub>l<sub>pman</sub>，1991) 和扩大产品种类( R<sub>omer</sub>，1990) 在消费者具有非厌足性及多样性偏好的假定下，一方面，消费者对于一种既有产品的消费比例取决于该产品的质量等级及质量提升幅度，随着产品质量等级的提高，消费者对这种产品的消费量也随之上升; 另一方面，某种新产品出现会挤占已有产品的市场，挤占程度取决于这种新产品的创新程度，而消费者通过对新产品的消费获得了更高的效用，企业则获得了更大的收益( 钟春平和徐长生，2011) 在出口行为中，知识积累所驱动的企业效益提升不仅来源于消费者消费量的增加，同时来源于企业的成本优势 一方面，<sup>“</sup>优等品远销<sup>”</sup>现象表明，高质量的产品在负担出口成本后相对价格降低，更容易销售到海外市场; 另一方面，出口行为存在一个固定的进入成本，企业出口产品的多样化能够在一定程度上降低出口不确定性( Gh<sub>os</sub>h 和 O<sub>stry</sub>，1994) ，由于无论是多产品出口企业还是单一产品出口企业均具有相同的进入成本，因而多产品出口企业每一种产品的平均进入成本更低，成本优势更加明显( A<sub>n</sub>d<sub>ersson</sub>，2012) 两种效应的同时存在使得企业相对于自身规模出口了更多的产品，提高了出口竞争力 总的来说，R＆D 行为驱动的垂直与水平创新提高了企业的出口竞争力

但不得不注意的是，知识发现的意义在于独特性与创新性，重复发现知识是无意义的 企业在生产中总是投入相同或相似的知识，是不能带来持续的质量提升与种类扩张的 换句话说，企业要获得知识的驱动效应，总要不断地投入各种新知识，丰富自身的知识组成，并对其进行组合运用，而不是原地踏步 理论上讲，若企业知识积累中所包含的知识构成越复杂，那么企业能够组合运用的知识就越多，每次创造行为所带来的质量提升幅度会越大，提供的新种类产品与原有产品相比创新程度也越高，这意味着企业可以获得更大的收益增长与市场份额( 钟春平和徐长生，2011) ，企业保持有效知识垄断的时间更长 此外，复杂的知识结构使得相关改进与创新更难以实现，替代产品越少，企业绩效水平就越高( 张杰和郑文平，2018)

显然，企业进行创新活动的驱动因素是存在取得私有收益和扩大市场份额的期望 如果企业能够通过知识获取收益，那么知识在生产上必须具有排他性，这种排他性通过知识产权法律的途径实现，即知识被企业获取后，通过专利注册的形式在一段时间内进行垄断，从而获取知识所带来的垄断收益

由上述讨论我们可以得到结论: 知识通过垂直提升产品质量与水平扩展产品种类两种途径促进了企业竞争力的增长，累积投入知识的复杂度越高，企业竞争力的增长就越明显;同时，企业通过专利的形式使知识获得排他性<sub>。</sub> 若通过企业累积专利所包含的知识复杂度去衡量企业的专利质量，那么更高的专利质量就意味着产品质量的提升与新产品种类的扩张，从而使企业相对于自身规模出口了更多的产品，具有更强的出口竞争力 由此，我们提出了本文的研究假设

研究假设1: 企业专利质量的提高通过提升出口产品质量，进而提高了企业出口竞争力<sub>。</sub>

研究假设2: 企业专利质量的提高通过扩展新产品种类，进而提高了企业出口竞争力

## 三<sub>、</sub>变量<sub>、</sub>模型设定及数据来源

## 1． 计量模型设定

本文建立了检验专利质量对上市公司出口竞争力影响的基本模型1，模型1 如式(1) 所示:

$$
\ln E c i _ {i t} = \alpha_ {0} + \alpha_ {1} \ln P a t e n t q u a l i t y _ {i t} + \theta X _ {i t} + \mu_ {i t}\tag{1}
$$

式( 1) 中 $, \mathrm { l n } E c i _ { i }$ 代表了企业 i 在 t 年的出口竞争力指标; $P a t e n t q u a l i t y _ { i t }$ 表示企业 i 在 t 年的专利质量，具体测定方法见后文

同时，为检验专利质量对出口竞争力的影响渠道，本文建立模型 2 模型 3 和模型 4，与模型 1 组成多元中介效应检验模型 <sub>。</sub> 其中，l<sub>np</sub>roduct<sub>q</sub>ualit<sub>y</sub> 与 $\ln n u m b e r _ { i t }$ 分别表示 i 企业第 t 年的出口产品质量与出口产品种类，模型2<sub>、</sub>模型3 和模型4 如式(2) 式(3) 及式(4) 所示:

$$
\ln \text { productquality } _ {i t} = \gamma_ {0} + \gamma_ {1} \ln \text { Patentquality } _ {i t} + \epsilon X _ {i t} + \mu_ {i t}\tag{2}
$$

$$
\ln \text { number } _ {i t} = \rho_ {0} + \rho_ {1} \ln \text { Patentquality } _ {i t} + \varphi X _ {i t} + \mu_ {i t}\tag{3}
$$

$$
\ln E c i _ {i t} = \beta_ {0} + \beta_ {1} \ln P a t e n t q u a l i t y _ {i t} + \beta_ {2} \ln p r o d u c t q u a l i t y _ {i t} + \beta_ {3} \ln n u m b e r _ {i t} + \tau X _ {i t} + \mu_ {i t}\tag{4}
$$

控制变量 $X _ { i t }$ 具体包括以下内容: 研发强度 $\left[ { \mathrm { l n } r e s e r c h } _ { i t } \right]$ ，通过企业 i 在第 t 年研发投入的自然对数衡量 参考毛其淋和方森辉(2018) 对类似问题的讨论，企业的研发强度会影响其出口竞争力，研发强度的提高往往带来了更强的出口竞争力 全要素生产率( $T F P _ { i t } )$ ，测算方法参考 Gi<sub>annett</sub>i 等( 2015) 的方法<sub>。</sub> 有研究表明，企业全要素生产率是影响其出口竞争力的重要因素( 盛斌和毛其淋，2017; 赵奇伟等，2016) 资本密度( $k l r a t i o _ { i t } )$ ，用固定资产净额与员工数目比值的自然对数衡量 融资约束 $b c r e d i t _ { i t } )$ ，采用短期借款与总资产之比进行衡量，该值越低，银行融资约束就越明显 企业规模( $s i z e _ { i t } )$ ，通过总资产的自然对数值进行衡量，有理论认为，中国企业的规模与企业出口竞争力具有高度相关性( 张杰等，2010) 行业集中度( $H H I _ { i t } )$ ，采用赫芬达尔指数衡量，表示了 i 企业第 t 年所在行业的集中程度，该指数越大说明这一行业垄断程度越高 竞争是影响企业 R＆D 投入的重要因素，因此，行业集中度可能会影响企业的专利研发 申请及授权 同时，模型还引入了时间和行业的虚拟变量

## 2． 重要变量设定说明

## (1) 企业出口竞争力的测定

本文所定义的企业出口竞争力指数参考赵奇伟等(2016) 的做法，即 $E C I _ { i t } = \#$ 企业出口所占行业出口比重/该企业生产总值占行业生产总值比重，用公式表述如下:

$$
E C I _ {i t} = \frac {E X _ {i t} / E X _ {t}}{X _ {i t} / X _ {t}}
$$

其中， $E X _ { i t }$ 和 $X _ { i t }$ 分别表示 i 企业 t 年的出口交货值与企业生产总值， $E X _ { t }$ 和 $X _ { t }$ 分别表示 i 企业所在行业 t 年的出口交货值与生产总值<sub>。</sub>

## (2) 企业专利质量的测算

为了测度企业专利质量，本文获取了上市公司所申请专利的主分类号 中国所应用的 IPC 专利分类号格式为<sup>“</sup>部 <sub>－</sub>大类 <sub>－</sub>小类 <sub>－</sub> 大组 <sub>－</sub> 小组<sup>”</sup>，如 $^ { 6 6 } { \mathrm { A 0 1 } } { \mathrm { B 0 1 } } / { 0 0 } ^ { 3 9 }$ 具体而言，分类号的第一个字母代表了 个大部( 部: 生活必需( 农 轻 医) ; 部: 作业 运输; 部: 化学 冶金; 部: 纺织 造纸; 部: 固定建筑物;F 部: 机械工程 照明 采暖 武器 爆破;G 部: 物理;H 部: 电技术) ，第2 <sub>～</sub>3 个数字表示大类，第4 个字母表示小类 本文采用知识宽度反映企业专利质量 首先，若仅采用企业专利所包含的主分类号数量测度企业专利质量并不能准确区分出企业专利的内部差异，进而可能对专利质量产业过高估计<sub>。</sub> 例如，一家企业拥有三个专利，其主分类号分别为 A01B01/01 A01B01/02 A01B01/03，而另一家企业三个专利的主分类号分别为 A01B02/00<sub>、</sub>B02C03/00<sub>、</sub>C03D04/00，这两项专利虽然专利分类号数量相同，但由于第一家企业的专利只利用了 A01B01 的一个大组信息，而第二家企业则利用了 A01B02这三个大组信息，显然第二家企业专利所运用的知识宽度要大于第一家，因此其专利质量相应也更高 本文参考赫芬达尔指数的计算思路，在大组层面上定义企业专利知识宽度为:

$$
\text { Patentknowledge } _ {i t} = 1 - \sum \left(\frac {Z _ {i m t}}{Z _ {i t}}\right) ^ {2}
$$

其中， $\mathbf { \Omega } _ { \mathbf { \lambda } } , Z _ { \mathrm { { \it i m t } } }$ 为企业 i 截至 t 年在 m 大组下发明与实用新型申请专利的累计数目， $\mathbf { \nabla } _ { \mathbf { \mathfrak { s } } } Z _ { \mathfrak { i } \mathfrak { t } }$ 为企业 i 截至 t 年在全部大组下申请专利的累计数目 $P a t e n t k n o w l e d g e _ { i t }$ 的值越大，说明企业专利的知识宽度越大，专利质量越高<sub>。</sub>

值得一提的是，在计算该指标的过程中，我们对数据进行了以下处理:1) 只选取了发明专利与实用新型专利，这样做一是因为外观设计专利的编号方式与发明专利和实用新型专利完全不同，不能依照相同的方法进行计算;二是因为相比于发明专利和实用新型专利，外观设计专利所体现的自主创新能力相对较低，不能较好体现企业创造专利过程中所应用知识的复杂程度 2) 剔除了由于 <sup>“</sup>避重弃权<sup>”</sup>而标明无效的实用新型专利<sup>①</sup>

## (3) 中介变量的测算

## 1) 出口产品种类

## 2) 出口产品质量的测算

本文参考 H<sub>a</sub>ll<sub>a</sub>k 和 Si<sub>va</sub>d<sub>asan</sub>(2009) 的做法，利用反事实推理法测度企业 i 在 t 年的出口产品质量若市场中消费者的需求为不变替代弹性，那么其效用函数应如下式:

$$
U = \sum \left[ \lambda_ {j} q _ {j}\right) ^ {(\sigma - 1) / \sigma} ] ^ {\sigma / (\sigma - 1)}
$$

其中，U代表 n 国消费者消费产品j 获得的效用， $\mathbf { \sigma } _ { \bullet \lambda _ { j } }$ 表示产品j 的质量水平 ${ \bullet } q _ { j }$ 表示 n 国消费者消费产品j 的数量 ${ \mathfrak { s o } }$ 表示替代弹性<sub>。</sub>

$$
P _ {j n t} = \sum p _ {i j n t} ^ {- \sigma} \lambda_ {i j n t} ^ {\sigma - 1}
$$

上式为对应的价格指数 $\pmb { \mathscr { s p } } _ { i j n t }$ 与 $\lambda _ { i j n t }$ 分别代表 i 企业在 t 年出口到 n 国产品j 的价格与质量<sub>。</sub> 由此可见，消费者对产品j 的需求同时取决于产品的价格和质量 那么 $\bullet n$ 国消费者 t 年对企业 i 产品j 的需求数量可以被表示为:

$$
q _ {i j n t} = p _ {i j n t} ^ {- \sigma} \lambda_ {i j n t} ^ {\sigma - 1} \frac {E _ {j n t}}{P _ {j n t}}
$$

其中， $\mathbf { \Delta } _ { \mathbf { \lambda } } \mathbf { , } E _ { j n t }$ 为t 年n 国消费者在商品j 上的支出， $\mathbf { \Omega } _ { \mathfrak { s } } P _ { j n t }$ 为对应的价格指数<sub>。</sub> 对上式两侧取自然对数，可得:

$$
\ln q _ {i j n t} = (\sigma - 1) \ln \lambda_ {i j n t} - \sigma \ln p _ {i j n t} + \mu_ {i j n t}
$$

其中 $\mathsf { \pmb { \mathscr { s } } } \mu _ { i j n t } = \mathrm { l n } E _ { j n t } - \mathrm { l n } P _ { j n }$ 控制了进口国 <sub>－</sub>年份虚拟变量 令残差项 $\varepsilon _ { i j n t } = \big ( \sigma - 1 \big ) \ln \lambda _ { i j n t }$ ，对上式进行回归，提取残差项，则可测得企业 i 在 t 年对 n 国出口产品j 的质量:

$$
\text { quality } _ {i j n t} = \ln \lambda_ {i j n t} = \frac {\varepsilon_ {i j n t}}{\sigma - 1}
$$

由于本文是在企业层面上进行研究的，不同种类产品的出口质量进行简单加总不具有特殊的经济学意义，因此我们参考施炳展(2014) 的方法，对 $q u a l i t y _ { i j n t }$ 进行无量纲处理:

$$
\text { Standardquality } _ {i j n t} = \frac {\text { quality } _ {i j n t} - \text { minquality } _ {i j n t}}{\text { maxquality } _ {i j n t} - \text { minquality } _ {i j n t}}
$$

其中，<sub>maxq</sub>ualit<sub>yi t</sub>与 $\operatorname* { m i n } { q u a l i t y _ { i j n t } }$ 分别为产品 i 在所有年度所有企业所有进口国的层面上求得的最大值与最小值<sub>。</sub> 上式定义的标准化产品质量没有单位且归于［0，1］之间，我们将标准化产品质量以产品出口额占企业出口总额的比例作为权重，将产品 企业 年度 国家层面上的产品质量加总到企业 <sub>－</sub>年度层面上:

$$
\text { Standardquality } _ {i t} = \sum_ {n} \left(\frac {x _ {i n t}}{x _ {i t}} \sum_ {j} \frac {x _ {i j n t}}{x _ {i n t}} \times \text { Standardquality } _ {i j n t}\right)
$$

## 五<sub>、</sub>结论与启示

本文利用制造业上市公司贸易数据，从企业层面考察了企业专利质量与企业出口竞争力之间的关《世界经济研究》 年第 期

系，主要得到了以下四点结论: (1) 企业专利质量的提升提高了企业出口竞争力，且获得授权的专利质量对企业出口竞争力的提升作用大于申请专利;(2) 多元中介效应模型实证结果表明，无论是企业申请专利还是获得授权的专利，专利质量都会通过提高企业出口产品质量与扩展企业出口产品种类两条路径实现对出口竞争力的提升，且这两条影响路径在变更企业专利识别范围 重新测算企业出口竞争力及重新估计企业出口产品质量后仍可通过显著性检验; (3) 专利质量对不同专利密集型企业出口竞争力的影响没有显著差别，但影响路径存在差异，具体而言，专利密集型企业专利质量仅通过扩展产品种类影响其出口竞争力，而非专利密集型企业则同时存在上述两条影响路径; ( 4) 对于国有企业而言，无论是申请专利还是获得授权的专利，专利质量并未对企业出口竞争力造成显著影响，而在非国有企业样本中上述提升作用及影响路径均存在

本文在一定程度上填补了从企业专利质量角度研究企业出口竞争力的空白，为探究企业出口竞争力的影响因素提供了新的视角与经验证据 此外，上述结论也具有一定的启示意义 经过四十多年的对外开放，中国已经成为世界第一大贸易国 当前，在建设创新大国和创新强国的大背景下，通过实施创新驱动发展战略推动中国对外贸易高质量发展是中国经济发展新时期要走的必然途径 首先，中国正处于创新追赶阶段，必须加强知识产权保护力度，并制定合理的创新激励机制与专利审核制度 一方面，需要降低企业遭受知识产权侵犯的风险，积极引导鼓励企业进行专利开发;另一方面，需要严格专利审核制度，推动专利数量与专利质量的平衡发展，避免低质无效专利的产生，使专利成果能够切实指导企业进行技术升级，提高产品竞争力 其次，企业要结合自身生产经营状况，积极进行研发创新，并合理应用已有的专利成果提升产品质量和开发新种类产品以迎合市场需求，追求专利成果的最大化利用并以此提高自身出口竞争力 尤其是专利密集型企业，在积极拓展产品种类的同时，也要在各项产品的内在品质上持续努力，应用自身的密集研发优势提高产品的质量水平，多向发力，全面提高出口竞争力最后，国有企业要建立以市场为导向，以利润最大化为目标，以技术激励与技术创新为驱动力的长效发展机制，积极通过技术研发提升产品质量，拓展产品种类，并由此达到提高企业出口竞争力的目的
