［摘 要］基于随机前沿模型关于要素配置效率项的分解，采用各省域服务业投入产出面板数据，测算并分析2008 2017年全国及分区域包含资本 劳动力及能源投入的服务业要素配置效率 结果表明 全国服务业要素配置效率大体呈波动式下降趋势，其中，资本要素配置效率对其促进作用最显著，能源要素配置效率次之，而数值为负的劳动力要素配置效率是拖累其提升的主要因素 各地区服务业要素配置效率差异与地区内服务业省际平均产值规模相似，呈现<sup>“</sup>东部－中部－东北－西部<sup>”</sup>递减态势，其三种要素的配置效率也因区域服务业经济运行特征相异而表现出异质性

## 一<sub>、</sub>引言

资本 劳动力与能源要素作为维持生产活动不可或缺的物质基础，为产业乃至中国经济发展提供了有力支撑 改革开放以来，中国经济的高速增长依赖于生产要素无序的高投入 高消耗，这种粗放型发展方式已被反复证实存在难以忽视的要素配置扭曲（钱雪亚和缪仁余，2014）[<sup>1</sup>]，引起了各类要素过度消耗以及效率低下等严重制约经济可持续高质量发展的问题 因此，不能忽视要素重置对实现以效率改善为变革动力之一的高质量发展的促进作用，尤其是面对中国要素资源趋于紧缺的挑战，释放要素重置产生的配置效率改进效应，成为新时代加快我国经济高质量发展战略的必然要求之一

近年来，服务业呈现平稳较快的发展态势，其在国内生产总值中的比重于 2019 年达到 539%，比上一年提高了 06% 服务业已成为经济新常态下带动中国经济可持续高质量发展的重要引擎，必然需要更多要素投入，要素资源约束将会更多地体现于服务业，以服务业提质增效为重点的发展方式转变要求也尤为迫切 因此，从要素配置效率视角出发，审视服务业发展质量，既是加快服务业提质增效步伐的关键所在，更是提升中国经济可持续高质量发展能力的战略要求 同时，传统高耗能服务业的快速发展及其向<sup>“</sup>夜经济<sup>”</sup>的延伸，使得合理配置能源投入也成为促进服务业可持续高质量发展的重要因素，忽视能源要素投入的配置效率测算与分析已难以完整反映服务业运行的实际情况 因此，将能源视为同资本 劳动力相异质的生产要素纳入配置效率的测算框架，并厘清其全国及区域分布特征，在此基础上，提出改进要素配置效率进而通过效率变革促进中国服务业高质量发展的相关政策建议，具有重要的理论支撑与决策参考价值

## 二<sub>、</sub>文献综述

服务业作为工业化后期经济发展方式转变的重要经济领域，国内外学者围绕其高质量发展的重要因素——服务业全要素生产率进行了许多有益研究 多数学者认为，服务业经济增长主要依靠具有明显粗放特征的要素高投入，而全要素生产率增长率的贡献程度偏低 （R<sub>enu</sub>k<sub>a an</sub>d K<sub>a</sub>li<sub>rajan</sub>，1999）[<sup>2</sup>]，且存在显著的行业及区域异质性（W lfl，2005）[<sup>3</sup>] 其中，技术进步的促进作用明显，技术效率的作用则有待提高（刘兴凯和张诚，2010；王恕立和滕泽伟，2015）[<sup>4，5</sup>] 作为全要素生产率增长率的一项重要构成，要素配置效率提高能够改善全要素生产率增长率对服务业经济增长的贡献程度，从而有助于服务业经济高质量发展 因此，有研究对工业与服务业要素配置状态进行比较分析，结果均表明服务业经济运行中存在明显高于工业的要素配置扭曲（B ，M d i l d P S ，2012）[<sup>6</sup>]，进而运用反事实估计方法测算发现，消除要素配置扭曲能够显著促进服务业高质量发展（Di<sub>as</sub>，Ri<sub>c</sub>h<sub>mon</sub>d <sub>an</sub>d M<sub>arques</sub>，2018；陆江源和张平，2018）[<sup>7，8</sup>]

要素配置效率的测算一直是国内外学者在经济效率方面的研究热点，通常是通过估计全要素生产率增长率进而分解得到，而且，大多要素配置效率相关研究仅关注到资本要素与劳动力要素的互补关系 李言和高波（2018）[<sup>9</sup>]等运用传统增长核算法探究要素配置效率的空间分布特征，发现我国西部地区较稀缺的资本与劳动力要素禀赋特征使其对要素配置扭曲更为敏感，故要素配置效率要高于东部与中部地区 陈永伟和胡伟民（2 ）[<sup>10</sup>]同样运用传统增长核算法测度工业行业要素配置效率，结果表明行业间要素重置引致的配置效率对经济增长的作用并不明显 龚关和胡关亮等（2013）[<sup>11</sup>] 杨汝岱（2015）[<sup>12</sup>]均运用LP 半参数方法研究工业企业要素配置效率，发现企业间尤其是国有与非国有企业间资本与劳动力要素重置引致的配置效率改善有利于工业发展质量提高 经济发展过程中能源要素投入激增使其对产出的促进作用已无法忽视，有学者将要素配置效率研究视角转移到能源要素上 魏楚和沈满洪（2009）[<sup>13</sup>]采用数据包络模型（DEA）对35 个国家能源效率进行测算，发现其配置效率偏低是造成我国能源利用低效的主要原因 孙传旺和林伯强（2014）[<sup>14</sup>]运用随机前沿模型（SFA）研究发现，我国工业能源要素配置效率于 2000－2009 年间呈现先恶化后改善的波动趋势 陈诗一和陈登科（2 1 ）[<sup>15</sup>]首次将能源要素引入仅包括资本与劳动力投入的传统要素配置效率测算框架，与已有文献传统要素配置效率有所改善的结果不同，考虑能源投入后的要素配置效率并未出现明显改善

虽然已有的针对经济体 行业及企业等视角的要素配置效率研究，对测算分析乃至提高我国服务业要素配置效率具有重要参考价值，但考虑我国服务业高质量发展的战略要求，发现既有的相关研究仍有待深入之处 （1）多数关于服务业经济发展质量的研究侧重于全要素生产率增长率或其分解项中的技术效率与技术进步，对要素配置效率的研究虽偶有涉及，但通过反事实估计仅能体现完全消除要素配置扭曲对服务业产出增加的最大潜力，而服务业经济运行中实际发生的要素投入结构变动引致的配置效率会呈现怎样的全国性和空间分布特征，如何探其根源以提高要素配置效率，值得深入研究（2）现有的要素配置效率相关研究大都聚焦于资本与劳动力要素的互补关系或单一能源要素，忽视了三种要素间的耦合作用，而仅有的将能源要素纳入传统要素配置效率测算框架的研究针对工业领域，随着服务业对能源要素需求的增加，将这一研究扩展到服务业能够全面准确反映其经济运行实际情况，以确保测算结果的精确性 （3）众多研究常用的要素配置效率测算方法中，基于 C-D 生产函数的传统增长核算法容易造成模型误设问题，会影响测算结果的准确性和科学性 $\mathrm { L P }$ 半参数法以微观企业数据为基础，不适用于省际宏观数据的测算 数据包络模型（DEA）存在投入数据不同，测算结果波动也较大的缺陷 相对而言，随机前沿模型（ FA）在确定效率前沿时可以对多种函数形式进行检验，降低因函数形式非合理厘定而产生偏误的风险，且能够分离出不可控因素的影响，确保其结果不会受测量误差或其他随机性误差冲击

鉴于此，本文基于随机前沿模型（SFA）关于要素配置效率项的分解，采用各省域服务业投入产出面板数据，从包含资本 劳动力和能源投入的三要素超越对数型柯布-道格拉斯生产函数及各要素价格信息中，反映出要素实际投入与最优投入间的扭曲程度，进而测算得到 2008 2017 年不同空间尺度样本的服务业要素配置效率，并从三要素耦合视角探究其在全国乃至区域服务业中的变动及相对大小特征，以期获得提升要素配置效率从而实现服务业可持续高质量发展的整体性与区域针对性政策建议

## 三 要素配置效率测算理论模型

## （一）随机前沿模型（SFA）

根据 Kumbhakar（2002）[<sup>16</sup>]基于随机前沿模型对全要素生产率增长率的分解法，可以得到要素配置效率的理论构成 假设随机前沿生产函数为：

$$
y _ {i t} = f (x, t) e ^ {- u _ {i t}}\tag{1}
$$

式（1）中， $, y _ { i t }$ 为 $i ( i { = } 1 , 2 { \cdots } N ,$ ，）地区 $t ( t = 1 , 2 ^ { \cdots } T )$ 年的产出规模， $\mathrm { , } f ( \cdot )$ 表示生 $\vec { y } ^ { \mathrm { s } }$ 函数前沿面，是要素投入向量， $u _ { i t } { > } 0$ 为产出导向型生产非效率项

已取对数的式（1）对时间 求导得（为简化，省略 i，<sub>t</sub>）：

$$
\frac {\partial \ln y}{\partial t} = \frac {\partial \ln f (x , t)}{\partial t} + \sum_ {j} \frac {\partial \ln f (x , t)}{\partial i n x _ {j}} \cdot \frac {\partial \ln x _ {j}}{\partial t} - \frac {\partial u}{\partial t}\tag{2}
$$

式（2）中， $\frac { \partial \ln { \gamma } } { \partial t }$ 为产出增长率 $( \dot { y } )$ ，右边第一项衡量了前沿技术进步率（FTP）；第二项表示要素投入变化引起的前沿产出变化， $x _ { j }$ 为<sub>j</sub> 要素投入量，$\frac { \partial \ln f ( x , t ) } { \partial i n x _ { i } }$ 为<sub>j</sub> 要素产出弹性 $( \varepsilon _ { j } ) , \frac { \partial \mathrm { l n } x _ { j } } { \partial t }$ 是<sub>j</sub> 要素投入增长率 $( { \dot { x } } _ { j } )$ ；第三项表示生产效率变化率（TEC）

因此，式（2）可以被写为：

$$
\dot {y} = F T P + \sum_ {j} \varepsilon_ {j} \dot {x} _ {j} + T E C\tag{3}
$$

全要素生产率增长率（TF觶 P）是产出增加不能被要素投入增加所解释的部分，用 $s _ { j }$ 表示<sub>j</sub> 要素投入成本在投入总成本中的占比，即<sub>j</sub> 要素投入成本份额，可得全要素生产率增长率（TF P）为：

$$
T \dot {F} P = \dot {y} - \sum_ {j} \varepsilon_ {j} \dot {x} _ {j}\tag{4}
$$

将式（3）代入式（4），式（4）可以被写为：

$$
\begin{array}{r l} T \dot {F} P & = F T P + \sum_ {j} \varepsilon_ {j} \dot {x} _ {j} + T E C - \sum_ {j} s _ {j} \dot {x} _ {j} \\ & = F T P + T E C + \sum_ {j} (\varepsilon_ {j} - s _ {j}) \dot {x} _ {j} \\ & = F T P + T E C + (R T S - 1) \sum_ {j} \lambda_ {j} \dot {x} _ {j} + \sum_ {j} (\lambda_ {j} - s _ {j}) \dot {x} _ {j} \end{array}\tag{5}
$$

式（5）中， $\begin{array} { r } { R T S = \sum _ { j } \varepsilon _ { j } } \end{array}$ 是各要素产出弹性之和，表示对要素规模报酬的衡量 $; \lambda _ { j } { = } \frac { \pmb { \varepsilon } _ { j } } { \sum _ { j } \pmb { \varepsilon } _ { j } } { = } \frac { \pmb { \varepsilon } _ { j } } { R T S }$ 为 <sub>j</sub> 要素产出弹性份额；第四项即为要素配置效率（AE），数值上等于各要素的配置效率之和，其中， $( \lambda _ { j } - s _ { j } )$ 表示<sub>j</sub> 要素配置扭曲程度，当扭曲程度为零 $( \lambda _ { j } { = } s _ { j } )$ 时 $, j$ 要素达到最优配置状态

## （二）要素最优配置状态与要素配置效率变动的结构性根源

完全竞争要素市场下生产要素的自由流动使其能够追求更高效率，且供求双方均拥有完全信息以保证交换与竞争不会受到任何阻碍与干扰，可以认为此时的要素配置处于最优状态

参照 Kim（1992）[<sup>17</sup>]与孙传旺（2014）[<sup>14</sup>]关于要素最优配置状态的推导，假设在完全竞争要素市场条件下：

$$
\text { 生产函数为: } Y = f (x _ {1}, x _ {2} \dots x j)\tag{6}
$$

$$
\text { 利润函数为: } \pi = T R - c = p \cdot f (x _ {1}, x _ {2} \dots x j) - \sum_ {j} w _ {j} x _ {j}\tag{7}
$$

式（6）（7）中，TR 为总收益，C 表示要素投入总成本，Y 是产出规模， $P$ 为产出价格水平，<sub>x</sub> 表示 $, x _ { j }$ $j$ 要素投入量， $w _ { j }$ 是 $; j$ 要素价格水平

根据要素市场利润最大化条件 $\frac { \partial \pi } { \partial x _ { j } } = 0$ 可以推导得到： $\frac { \partial Y } { \partial x _ { j } } { = } \frac { w _ { j } } { p }$ （8）

即要素边际收益等于要素市场价格

式（8）两边同时乘 $x _ { j }$ 再对要素 $j$ 求和得：

$$
\sum_ {j} \frac {\partial Y}{\partial x _ {j}} \cdot x _ {j} = \sum_ {j} \frac {w _ {j} x _ {j}}{p}\tag{9}
$$

将 $\textstyle C = \sum _ { j } w _ { j } x _ { j }$ 代入式（9）整理得到：

$$
\mathrm{p} = \frac {C}{\sum_ {j} \left(\frac {\partial Y}{\partial x _ {j}} x _ {j}\right)}\tag{10}
$$

<sub>j</sub> 要素产出弹性 $\varepsilon _ { j }$ 为：

$$
\varepsilon_ {j} = \frac {\Delta Y}{\Delta x} \cdot \frac {x _ {j}}{Y} = \frac {\partial Y}{\partial x} \cdot \frac {x _ {j}}{Y} = \frac {w _ {j}}{p} \cdot \frac {x _ {j}}{Y}\tag{11}
$$

<sub>j</sub> 要素投入成本份额 $S _ { j }$ 为：

$$
S _ {j} = \frac {w _ {j} x _ {j}}{C}\tag{12}
$$

将式（10）（11）代入式（12）整理得到：

$$
S _ {j} = \frac {\varepsilon_ {j}}{\sum_ {j} \frac {\partial Y}{\partial x _ {j}} \cdot \frac {x _ {j}}{Y}} = \frac {\varepsilon_ {j}}{\sum_ {j} \varepsilon_ {j}} = \lambda_ {j}\tag{13}
$$

式（13）中， $\lambda _ { j } { = } \frac { \pmb { \mathscr { E } } _ { j } } { \sum _ { j } \pmb { \mathscr { E } } _ { j } }$ 为<sub>j</sub> 要素产出弹性份额，表示最优要素投入水平 $; s _ { j }$ 为 $j$ 要素投入成本份额，表示实际要素投入水平

在完全竞争要素市场及利润最大化条件下，要素的边际收益等于市场价格，从而要素的产出弹性份额（最优投入）等于成本份额（实际投入），即 $\lambda _ { j } { = } s _ { j }$ 这时，要素配置处于最优状态 然而，在中国特色市场经济体制不完善背景下，要素的产出弹性份额与投入成本份额可能产生偏离，要素配置无法达到最优状态，要素配置扭曲程度 $( \lambda _ { i } – s _ { i } )$ 则不会为零

要素配置效率 $\begin{array} { r } { ( A E \mathrm { = } \sum _ { j } ( \lambda _ { j } \mathrm { - } s _ { j } ) \dot { x } _ { j } ) } \end{array}$ 大小取决于要素配置扭曲程度 $( \lambda _ { j } - s _ { j } )$ 与要素投入增长率 $( { \dot { x } } _ { j } )$ 的数值表现：当要素配置扭曲程度一定且为正值时，要素投入增长率越大，要素配置效率也越高；当要素投入增长率一定且为正值时，要素配置扭曲程度越大，要素配置效率就越高，而随着要素配置扭曲程度的降低，相同的要素投入量变化产生的配置效率会逐渐减小 因此，这种扭曲存在有利的一面，它使欠发达经济体或产业部门通过要素重置促进经济高质量发展的潜力相比成熟经济体要大（张军和陈诗一，2009）[<sup>18</sup>] 由此可见，测算要素配置效率需要先采用适宜样本数据的前沿生产函数估算出要素配置扭曲程度，进而结合要素投入增长率计算得到

\left(\ln L _ {i t}\right) ^ {2} + \beta_ {7} \left(\ln E _ {i t}\right) ^ {2} + \beta_ {9} \ln K _ {i t} \ln L _ {i t} + \beta_ {1 0} \ln K _ {i t} \ln E _ {i t} + \beta_ {1 1} \ln L _ {i t} \ln E _ {i t} +
$$

$$
\beta_ {1 2} t \ln K _ {i t} + \beta_ {1 3} t \ln L _ {i t} + \beta_ {1 4} t \ln E _ {i t} + v _ {i t} - u _ {i t}\tag{14}
$$

式（14）中， $\mathrm { l n } Y _ { i t } . \mathrm { l n } K _ { i t } . \mathrm { l n } L _ { i t }$ 和 $\ln E _ { i t }$ 分别表示 i 地区 <sub>t</sub> 年的实际产出规模 资本要素投入 劳动力要素投入和能源要素投入的对数形式， $\mathbf { \nabla } _ { u }$ 是 i 地区 <sub>t</sub> 年的产出导向型生产非效率项， 是 i 地区 年生产过程 $. v _ { i t }$ 中的随机误差项

（1）要素配置扭曲程度 $( \lambda _ { i j t }  – S _ { i j t } )$ 根据上述关于要素最优配置状态的推导可知，要素产出弹性份额与其成本份额的偏离程度 $( \lambda _ { i j t }  – S _ { i j t } )$ 反映了要素配置扭曲程度 当 $\lambda _ { i j t } - S _ { i j t } { > } 0$ ，要素配置存在正扭曲，表明要素成本份额即实际投入过低，增加要素投入量会使其成本份额逐步接近产出弹性份额（最优投入），进而 $( \lambda _ { i j t } - S _ { i j t } )$ 趋于 0，要素配置接近最优状态，故称$\lambda _ { i j t } { - } S _ { i j t } { > } 0$ 为要素投入不足；反之，当 $\lambda _ { i j t } { - } S _ { i j t } { < } 0$ ，要素配置存在负扭曲，称之为要素投入过剩 <sup>①</sup>

<sub>j</sub> 要素产出弹性份额 $( \lambda _ { i i } )$ 的测算公式为：

$$
\lambda_ {i t j} = \frac {\varepsilon_ {i t j}}{\sum_ {j} \varepsilon_ {i t j}} = \frac {\varepsilon_ {i t j}}{R T S}\tag{15}
$$

<sub>j</sub> 要素投入成本份额 $( S _ { i t j } )$ ）的测算公式为：

$$
S _ {i t j} = \frac {C}{\sum_ {j} C _ {i t j}}\tag{16}
$$

式（16）中， $C _ { i t j }$ 表示 $j$ 要素投入成本， $\textstyle \sum _ { j } C _ { i j j }$ 表示资本 劳动力与能源要素投入成本之和，即要素投入总成本 根据（15）式，计算要素产出弹性份额 $( \lambda _ { i j } )$ 需要分别对资本 劳动力与能源的要素产出弹性（ $( \varepsilon _ { i i j } )$ 进行测算

（2）要素产出弹性 $( \varepsilon _ { i j } )$ 要素产出弹性指当其他要素投入保持不变时，某一种要素投入量变动百分之一引起的产出规模变动的百分比，其值等于要素边际产出乘要素投入量与产出之比，即 $\frac { \partial Y } { \partial X } \cdot \frac { X } { \partial Y }$ 。因此，要素的边际产出与投入规模越大，其产出弹性就越高

根据式（14）的参数估计结果，资本要素产出弹性 $( \varepsilon _ { i t K } )$ 劳动力要素产出弹性 $( \varepsilon _ { i t L } )$ 能源要素产出弹性 $( \varepsilon _ { i t E } )$ 的测算公式分别为：<sup>②</sup>

$$
\varepsilon_ {i t K} = \frac {\partial \ln f (x , t)}{\partial \ln K} = \beta_ {1} + 2 \beta_ {5} \ln K _ {i t} + \beta_ {9} \ln L _ {i t} + \beta_ {1 0} \ln E _ {i t} + \beta_ {1 2} t\tag{17}
$$

$$
\varepsilon_ {i t L} = \frac {\partial \ln f (x , t)}{\partial \ln L} = \beta_ {2} + 2 \beta_ {6} \ln L _ {i t} + \beta_ {9} \ln K _ {i t} + \beta_ {1 1} \ln E _ {i t} + \beta_ {1 3} t\tag{18}
$$

$$
\varepsilon_ {i t E} = \frac {\partial \ln f (x , t)}{\partial \ln E} = \beta_ {3} + 2 \beta_ {7} \ln E + \beta_ {1 0} \ln K _ {i t} + \beta_ {1 1} \ln L _ {i t} + \beta_ {1 4} t\tag{19}
$$

（3）要素投入增长率 $( \dot { x } _ { i j } ) _ { \mathrm { ~ o ~ } } \dot { x } _ { i j }$ 为<sub>j</sub> 要素投入增长率，指一定时期内 $j$ 要素投入增长量与上一年<sub>j</sub> 要素投入量的比值，测算公式为：

$$
\dot {x} _ {i t j} = \frac {x _ {i j , t} - x _ {i j , t - 1}}{x _ {i j , t - 1}}\tag{20}
$$

（4）要素配置效率 $( A E _ { i t j } )$ 要素配置效率是当要素产出弹性份额与成本份额存在偏差时要素投入结构变化产生的效率，在数值上表现为要素投入量变化 $( \dot { x } _ { i i j } )$ 对要素配置扭曲程度 $( \lambda _ { i j t } - S _ { i j t } )$ 的消长过程（孙传旺和林伯强，2014）[<sup>14</sup>] 具体为：当要素配置存在正扭曲即投入不足时 $\langle \lambda _ { i j t } - S _ { i j t } > 0 )$ ，增加要素投入量 $( \dot { x } _ { i j } >$ 0）能够通过提高成本份额使（ $\lambda _ { i j t } \mathrm { - } S _ { i j t } )$ 接近于 0，要素配置状态得以改善，进而产生数值为正的要素配置效率（ $\left( \lambda _ { i j } - S _ { i i j } \right) \dot { x } _ { i i j } { > } 0 )$ ），反之则产生数值为负的要素配置效率；当要素配置存在负扭曲即投入过剩时 $( \lambda _ { i j t } -$ $S _ { i j t } { < } 0 )$ ），增加要素投入量 $( { \dot { x } } _ { i i j } { > } 0 )$ 会进一步增加成本份额，不利于要素配置状态改善，进而产生数值为负的要素配置效率（ $\left( \lambda _ { i j } { - } S _ { i j } \right) \dot { x } _ { i j } { < } 0 )$ ，反之则产生数值为正的要素配置效率

根据上述随机前沿模型关于要素配置效率理论构成的推导可知，资本要素配置效率（A $E _ { i t K } )$ 劳动力要素配置效率 $( A E _ { i t L } )$ 及能源要素配置效率 $( A E _ { i t E } )$ 的测算公式依次分别为：

$$
A E _ {i t K} = \left(\lambda_ {i t K} - S _ {i t K}\right) \dot {x} _ {i t K}\tag{21}
$$

$$
A E _ {i t L} = (\lambda_ {i t L} - S _ {i t L}) \dot {x} _ {i t L}\tag{22}
$$

$$
A E _ {i t E} = (\lambda_ {i t E} - S _ {i t E}) \dot {x} _ {i t E}\tag{23}
$$

依据对要素配置效率测度公式，按式（24）分解三种要素的配置效率对服务业要素配置效率的贡献程度，可知服务业要素配置效率 $( A E _ { i t } )$ 为资本 劳动力及能源投入的单要素配置效率之和：

$$
\begin{array}{r l} A E _ {i t} & = \sum_ {j} (\lambda_ {i t j} - S _ {i t j}) \dot {x} _ {i t j} \\ & = (\lambda_ {i t K} - S _ {i t K}) \dot {x} _ {i t K} + (\lambda_ {i t L} - S _ {i t L}) \dot {x} _ {i t L} + (\lambda_ {i t E} - S _ {i t E}) \dot {x} _ {i t E} \\ & = A E _ {i t K} + A E _ {i t L} + A E _ {i t E} \end{array}\tag{24}
$$

## （二）测算数据选取与处理

本文选取我国 30 个省（市 自治区）2007－2017年服务业投入产出数据作为样本（西藏地区除外），其中，产出是指服务业产出规模，投入包括服务业资本 劳动力与能源要素投入 因2019 年《中国能源统计年鉴》尚未公布，缺少 2018 年能源要素投入相关数据，故本文测算数据只能截止到 2017 年

1 产出规模 选取第三产业增加值作为产出规模指标，并采用分省市第三产业 GDP 指数将其折算到2007 年为基期的不变价格

2 资本要素投入 资本要素投入是指服务业资本存量，通常采用永续盘存法对其估算（张军和吴桂英，2004）[<sup>20</sup>] 估算公式为：

$$
K _ {i, t} = I _ {i, t} + (1 - \sigma) K _ {i, t - 1}
$$

其中， $K _ { i , t } { \setminus } K _ { i , t - 1 }$ 分别指 i 地区 <sub>t</sub> 年和 <sub>t</sub> 1 年服务业资本存量； $; I _ { i , t }$ 表示 i 地区 年服务业固定资产投资额，选取第三产业全社会固定资产投资额衡量（王恕立和胡宗彪，2012）[<sup>19</sup>]，并采用分省市固定资产投资价格指数消除价格因素 $; \sigma$ 表示服务业资本折旧率，将其设为 4%（王恕立和胡宗彪，2012；L <sub>n</sub>dH<sub>on</sub> ，2012）[<sup>21，22</sup>] 基期年资本存量计算公式为：

$$
K _ {i, 2 0 0 7} = I _ {i, 2 0 0 7} / (\sigma + g)
$$

式中， $\sigma$ 的含义及衡量同上 $\div g$ 为产出平均增长率，此处取 2007 2017 年各省市服务业实际增加值的年均增长率 资本要素投入成本为固定资产折旧与利息支出之和，分别采用<sup>“</sup>资本存量 资本折旧率<sup>”</sup><sup>“</sup>资本存量 当年的五年期贷款利率<sup>”</sup>予以计算（孙传旺和林伯强，2014）[<sup>14</sup>] 资本折旧率与上述取值一致，五年期贷款利率来源于 i d 数据库并取其年算术平均值

3 劳动力要素投入 劳动力要素投入在理论上应是劳动力的数量 质量及工作时间综合考量的结果，但因缺乏劳动力质量与工作时间数据，选取第三产业年末从业人员数作为劳动力要素投入指标 劳动力要素投入成本主要指劳动报酬，即第三产业年末从业人员数与人均工资水平的乘积 为解决服务业人均工资水平数据缺乏的问题，采用服务业城镇单位就业人员人均工资作为替代指标，并使用居民消费物价指数将其折算到 2007 年为基期的不变价格 由于仅可获取服务业分行业数据，故分别用 $L _ { a c } \backprime$ $w _ { a c }$ 表示 行业城镇单位就业人员数及人均工资，可得服务业城镇单位就业人员人均工资 $w _ { c }$ 为：

由此可见，过低的劳动力要素产出弹性及其投入量持续增加，是劳动力要素配置效率呈现负值的根本原因，而服务业最大就业<sup>“</sup>容纳器<sup>”</sup>的作用决定其劳动力要素投入短期内必然不会减少，故提升过低的劳动力要素产出弹性将成为改善其配置效率的核心途径 从我国劳动力转移特征及其分工现状来看，服务业劳动力要素产出弹性低下可能存在的原因在于：一方面，我国城市化进程的推进促使农村剩余劳动力向城市快速转移，多数技能水平较低的农村劳动力向制造业转移存在一定技术壁垒，进而选择流入餐饮娱乐业等低资本 低技术类生活性服务业，导致服务业劳动力要素产出弹性较低；另一方面，足量的资本投入能够开创更多生产领域从而扩大市场规模，为劳动力分工创造良好的市场条件，促进劳动力要素产出弹性提升，但现阶段我国服务业经济运行中存在资本要素投入不足的正扭曲现象，不利于劳动力形成更精细的分工，其产出弹性也难以增长 因此，促使服务业低技能劳动力职业化并扩大资本投入规模，应是提高劳动力要素产出弹性进而改进劳动力要素对要素配置效率负向作用的有效举措

我国能源要素价格阶段性下跌使其成本份额逐年下降，与有所上升的产出弹性份额相背离，形成缓慢增加的能源要素配置正扭曲，但节能降耗政策的实施对能源要素投入增长率提高的约束致使其配置效率呈现出稳中有降的趋势 各能源价格于 2008－2011 年间处于较平稳波动状态，但煤炭价格由于受产能过剩与国外进口低价煤等多方面冲击，于 2012年开始缓慢下降，石油价格又因 2015 年的国际市场供过于求而暴跌将近一半，且均于 2017 年才略微回升，电力和天然气价格在此期间则相对平稳 煤炭石油价格的阶段性下跌，在服务业能源要素投入量逐年增加的情况下，其成本甚至于 2015 年有所下降，导致 2008 2017 年间能源要素投入成本仅增加了 0 65 倍，而资本和劳动力要素投入成本分别增加了 3 65 3 08 倍，从而能源要素成本份额（实际投入）

逐年减少，背离其产出弹性份额（最优投入）稳步上升的趋势，能源要素配置正扭曲程度随之增加 尽管能源价格有所下降，但我国节能降耗硬约束迫使服务业能源要素投入增长率从 2008 年的 15%降至2017 年的 3 71%，未能发挥出正扭曲程度增加引致的能源要素配置效率提升的潜力，使其呈现稳中有降的趋势 由此可见，我国煤炭 石油价格阶段性下跌，加之节能降耗政策约束，造成了服务业能源要素配置效率的损失 适时适度提高能源价格以增加其成本份额从而改善能源要素配置状态，优化服务业能源消费结构以减轻节能降耗政策对能源要素投入的约束，是促进服务业能源要素配置效率提升的有效举措

总之，我国服务业的资本与能源要素的配置存在正扭曲（投入不足），而劳动力要素配置存在负扭曲（投入过剩），这与我国资本和能源相对稀缺而劳动力较为充裕的要素禀赋特征相符 另外，这也表明，服务业生产过程中各要素配置均未达到最优状态，仍存在通过要素重置改进要素配置效率进而促进服务业高质量发展的巨大潜力 三种要素投入量变动使其对服务业要素配置效率产生不同贡献程度，从大到小依次为资本 能源 劳动力 （）服务业资本与能源要素投入量的增加，使其均存在正扭曲的配置状态得以改善，产生数值为正的配置效率，而由于资本要素配置的正扭曲程度高于能源要素，故资本要素投入量增加引致的配置效率乃至其对服务业要素配置效率的贡献程度高于能源要素 （2）煤炭 石油价格阶段性下跌使服务业能源要素的配置正扭曲程度于 2008 2017 年间缓慢上升，若其投入增长率能够增加，能源要素配置效率及其对要素配置效率的贡献程度均将得以提升，但节能降耗硬约束却迫使其投入增长率逐年下降，能源要素配置效率随之呈现稳中有降的趋势 （3）服务业的劳动力要素产出弹性及其份额因受劳动力技能水平低下及资本投入不足的限制而处于偏低水平，加之过高的劳动力要素成本份额致使劳动力要素配置存在负扭曲，其投入量增加又造成配置状态进一步恶化，进而对要素配置效率产生负向影响 这说明，劳动力要素对服务业要素配置效率的作用仍有较大改进空间

服务业能源要素投入增长率在地区间相异的下降幅度，致使存在不同程度能源要素配置正扭曲的各地区产生的配置效率表现出一定趋同特征 为实现节能降耗目标，各级政府对减少能源消耗给予高度重视，各地区服务业能源要素投入增长率均有所下降 而且，高耗能行业密集分布的中西部地区，由于相对落后的能源利用技术更易显著提高及服务业规模增长动力相对不足问题，致使原本较高的能源要素投入增长率下降幅度可能也更大，其次是东北东部 因此，在大幅下降的能源要素投入增长率作用下，中西部地区无法发挥出较高能源要素配置正扭曲得以持续矫正所能产生的配置效率的潜力，使其相对高的配置效率也更大幅波动式下降，逐步趋近于能源要素配置效率相对小但稳中有降的东部与东北地区 由此可见，我国节能降耗政策虽使各地区能源要素配置效率都有所下降，但对能源利用技术更易取得显著进步 服务业规模增长乏力的中西部地区产生了较其他地区可能相对更显著的影响

## 六 研究结论与政策建议

## （一）研究结论

在随机前沿模型关于要素配置效率理论构成推导的基础上，通过构建包括资本 劳动力和能源投入的三要素超越对数型柯布 道格拉斯生产函数，厘定了要素配置效率的具体测算公式，采用 2007—2017年服务业省际投入产出面板数据，对 2008 2017 年服务业资本 劳动力及能源要素的配置效率加权平均值予以测算，加总得到服务业要素配置效率，进一步对测算结果的全国及区域异质性进行分析

## 本文的主要研究结论，可以概括为四个方面

第一，全国服务业要素配置效率大体上呈现波动式下降趋势，2009 年显著提高至 0 113 5，2010 年仍维持在 0 1 12 1 的较高水平，201 1－2017 年间处于小幅波动下降过程 其中，资本要素的配置效率对要素配置效率的贡献最大，能源要素次之，劳动力要素配置效率低下则是拖累要素配置效率提高的主要成因 从分区域视角来看，服务业要素配置效率总体呈现<sup>“</sup>东部 中部 东北 西部<sup>”</sup>递减态势，符合我国服务业经济发展基本情况，即服务业省际平均产值规模较高的地区，其要素配置效率相应更高

第二，全国服务业的资本要素配置效率最高，于2009 年大幅上升到近年来最高值并维持至 2010年，2011－2017 年间则稳定在 0 09 左右，表现为资本要素的产出弹性份额明显高于成本份额，资本要素配置存在较高正扭曲（投入不足），伴随投入量增加产生数值为正且对要素配置效率具有显著正向贡献的资本要素配置效率 从分区域视角来看，各地区服务业的资本要素配置效率与本区域服务业省际平均产值规模表现出较强正向联系，于 2008－2014 呈现<sup>“</sup>东部－中部－东北－西部<sup>”</sup> 递减态势，于 2015－2017年又呈现<sup>“</sup>东部 中部 西部 东北<sup>”</sup>递减态势 东部地区相对更有效的投资使资本要素的产出弹性份额要远高于成本份额，产生的资本要素配置正扭曲程度及其引致的配置效率也最高 东北与中部地区资本要素配置效率位于中间水平，但东北地区的资本要素配置效率因 2013 年后资本要素投入增长率的下降而骤减 西部地区部分欠发达省市相对较小的服务业投资规模，加之以国有企业为主的投资模式，致使其资本要素配置效率一直处于相对偏低水平

第三，全国服务业的劳动力要素配置效率最低，且仅有小幅波动，其值为负介于－0 042 8<sub>\~</sub>－0 020 5之间，表现为劳动力要素的产出弹性份额低下而成本份额偏高，造成其配置存在负扭曲（投入过剩），伴随劳动力要素投入量增加产生数值为负的劳动力要素配置效率，表明其对要素配置效率的影响有较大的改进空间 从分区域视角来看，服务业劳动力要素的配置效率于 2008 2014 年呈现 <sup>“</sup>西部 中部 东北 东部<sup>”</sup>递减态势，于 2015 2017 年又呈现<sup>“</sup>东部中部 西部 东北<sup>”</sup>递减态势，表现出与资本要素相反的特征 服务业省际平均产值规模最高的东部地区，劳动力要素产出弹性份额反而最低且为负值，加之过高的成本份额，伴随劳动力要素投入增加导致劳动力要素配置效率低下 东北与中部地区劳动力要素配置效率于 2008 2014 间数值相近且处于中间水平，但东北地区的劳动力要素配置效率于 2015－2017 年间因劳动力要素投入增长率的减少而波动式上升 西部地区劳动力要素配置效率 2008－2014年间一直位于最高水平，2015 2017 年间伴随劳动力要素投入增长率的上升而略微下降

第四，我国服务业能源要素的配置效率为正，低于资本要素而高于劳动力要素，呈现稳中有降特征，数值介于 0 005 0 0 016 0 之间，表现为能源要素的产出弹性份额略高于成本份额，而煤炭 石油价格阶段性下跌又使其逐年下降的成本份额与有所上升的产出弹性份额相背离，形成不断增加的能源要素配置正扭曲（投入不足） 在节能降耗政策的硬约束下，能源要素投入增长率的下降致使数值为正的能源要素配置效率呈现稳中有降趋势 从分区域视角来看，能源要素配置效率呈现<sup>“</sup>中部 西部 东北 东部<sup>”</sup>递减态势，并未与区域服务业省际平均产值规模显示出关联性，尽管存在不同波动趋势，却表现出明显的逐渐趋同特征 中西部地区基于能源要素的偏高的产出弹性份额及较低的成本份额，形成高于东部及东北地区的能源要素配置正扭曲，伴随投入量增加而产生相对较高的能源要素配置效率 然而，节能降耗政策的实施，可能迫使能源利用技术更易显著进步且存在服务业规模扩大动力相对不足问题的中西部地区的能源要素投入增长率更显著减少，相对高的能源要素配置效率随之大幅下降至趋近于东部与东北地区

## （二）政策建议

在中国特色市场经济体制不完善及资源等要素趋紧的背景下，释放要素重置引致的配置效率改进的潜力，能够促进服务业高质量发展

第一，各级各地政府应尽可能通过贴息 补助等优惠政策，引导社会资本投入服务业各行业，以此扩大服务业资本投入规模，促进资本要素配置效率提升 同时，加强职业教育培训，使服务业劳动力技能素质与岗位需求相匹配以增加劳动力要素产出弹性，进而改善劳动力要素配置效率偏低对服务业要素配置效率提升的拖累作用

第二，采用清洁能源补贴等政策降低其使用价格，并视国内经济发展方式转变进程与市场承受能力，适时适度提高传统能源价格 通过不同能源间的价格差战略，增加能源要素成本份额以提高其配置效率，同时有助于清洁能源在服务业生产过程中逐步替代传统能源，减轻节能降耗政策实施对服务业能源要素配置效率提高的抑制作用

第三，因地制宜，注重解决各地区突出问题 东部地区应率先通过对服务业低技能劳动力进行职业培训增加其产出弹性，改善长期处于落后水平的劳动力要素配置效率 中部地区需要在服务业生产过程中优先使用清洁能源并注重传统能源的清洁化利用，减少节能降耗政策实施造成的能源要素配置效率损失 东北地区政府部门应着力改善营商环境，以建立具有活力且有序竞争的服务业市场，避免服务业资本投入大量流失从而缓解资本要素配置效率的大幅下降 西部地区政府部门需要积极支持并扩大民间投资，转化以国有企业为主的服务业投资模式，优化投资结构，促进偏低的资本要素产出弹性及配置效率提升

## （三）研究不足与展望

首先，在测算分析服务业要素配置效率时，本文将服务业作为一个整体，未能从更细分的行业维度对服务业要素配置效率予以深入分析 然而，服务业由众多性质相异的行业构成，资本 劳动力及能源的投入量及价格存在一定差异，这使得服务业要素配置效率可能表现出细分行业异质性，后续研究可在此方面进行更详细的分析 其次，我国节能降耗措施关键在于减少煤炭 石油等传统化石能源投入，鼓励使用电力 天然气等清洁能源，后续研究可在生产函数中对能源投入种类加以区分，深入探讨服务业中不同能源的配置效率，并遵循国家政策倾向提出可行的高质量发展建议
