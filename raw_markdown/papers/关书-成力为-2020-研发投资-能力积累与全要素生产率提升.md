# 研发投资<sub>、</sub>能力积累与全要素生产率提升

关 书，成力为( 大连理工大学经济管理学院，辽宁大连 116024)

摘 要:本文基于反射法测算了中国制造业出口企业能力积累指标，依据测算结果展示了中国微观企业能力积累的差异与分布情况，并以2000 2006 年工业企业数据库与海关数据库的微观数据为样本，构建实证模型考察了企业研发投资<sub>、</sub>能力积累与全要素生产率提升之间的关系<sub>。</sub> 结果发现: 企业研发与能力积累都有助于全要素生产率提高，中国企业在总体上表现出了产品创新生产模式的特点; 对于异质性企业样本估计结果，非国有企业与税收优惠企业表现出产品创新生产模式的特点，国有企业与补贴企业表现出过程创新生产模式的特点;中国在高技术行业与中高技术行业尚未表现出产品创新模式的特征 中国应减少选择性产业政策，采用更具普惠性的税收优惠政策，更好地发挥市场竞争作用，激励企业的产品创新模式与生产率水平提高<sub>。</sub>

关键词:研发投资;能力积累;全要素生产率;产品创新;过程创新

如何通过科技创新提高全要素生产率，是当前迫切需要研究的理论问题，也是实施创新驱动发展战略必须解决的现实问题 全国科技经费投入统计公报数据显示，2017 年我国企业<sub>、</sub>政府属研究机构<sub>、</sub>高等学校研发经费支出所占比重分别为 77 6%13 8%和7 2%，企业无疑是我国研发投资最重要的主体 但庞大的企业研发投资并没有带来全要素生产率的显著提高，进入工业化中后期之后，中国全要素生产率的增速及其对经济增长的贡献都在不断下降<sup>［1］</sup> 在宏观层面，因为政府科学研究投入过少，技术开发投入过多，所以科学研究在短期内对提高全要素生产率没有直接影响，技术开发对提高全要素生产率存在显著抑制作用<sup>［2］</sup>; 在微观层面，具有偏向性的政府支持可能激励企业策略性创新行为，降低企业技术开发活动的质量<sup>［3］</sup>

发展经济学认为经济发展的核心问题是结构转型及转型所需要的能力积累过程 结构转型所需能力如何积累，已有经济增长理论认为一国应专业化生产具有比较优势的产品，通过<sup>“</sup>看中学<sup>” “</sup>干中学<sup>”</sup>等模仿途径或规模经济<sub>、</sub>交易成本节约等效应实现能力积累和比较优势的内生转换<sup>［4］</sup> 但 <sup>“</sup>中兴事件<sup>”</sup>高端芯片 <sup>“</sup>卡住咽喉<sup>”</sup>之痛，迫使我们将研究的重心转向企业的能力积累<sub>。</sub> 大多数文献认为研发投资是影响企业全要素生产率的主要因素，然而，企业研发到底是通过怎样的方式促进生产率提高的呢?是改变产品结构，加速企业能力积累，突破经济发展的瓶颈式的产品创新( d <sub>t</sub> i <sub>t</sub>i ) ? 还是抵消生产过程中的生产要素报酬递减式的过程创新( i i ) ? 熊彼特认为这两种创新模式对企业成长以及经济增长质量方面起到不同的作用<sup>［5］</sup> 这引发了我们对下列问题的思考: 第一，中国企业的创新模式属于产品创新模式还是过程创新模式? 第二，处于经济转型的关键时期，政府应该制定怎样的产业政策增加企业的产品创新，提高企业生产率? 解答这些问题，对中国经济 <sup>“</sup>新常态<sup>”</sup>背景下的科技体制改革 高技术产品出口技术复杂度的提升<sub>、</sub>企业全要素生产率提升与国家竞争优势的增强等都具有指导意义<sub>。</sub>

## 1 文献综述

## 1．1 全要素生产率

探求全要素生产率提高的途径一般在两个层面进行: (1) 国家( 宏观) 和产业( 中观) 层面减少资源在不同企业间的错配，提高资源配置效率 这些研究多从产业间 产业内企业间全要素生产率的差异入手，着重分析制度缺陷<sub>、</sub>政策因素<sub>、</sub>经济非自由化程度和不完全信息对淘汰低生产率企业<sub>、</sub>激励高效率企业进入的影响机制，通过企业进出的动态变化发挥资源重新配置或重新组合的作用<sup>［6］</sup>; 测度要素价格扭曲<sub>、</sub>优胜劣汰市场选择机制缺失<sub>、</sub>企业进入与退出成本对市场均衡时生产率分布临界值的影响，强调资源在不同生产率企业间的流动的重要性，致力于减少产业间或产业内企业间的资源错配，缩小企业间全要素生产率的差距，促进全要素生产率的提高<sup>［7］</sup>;(2) 企业层面加大研发投资活动，提高个体的生产率水平<sub>。</sub> 例如，强化人力资本及 R＆D 前后溢出之间的交互作用对全要素生产率 技术效率和技术进步的影响<sup>［8］</sup>; 寻求有效的创新模式，在中国经济转型期，合作创新是优于模仿和独立创新的产品开发模式<sup>［9］</sup>; 强调受技术差距 消化吸收能力等因素的影响，技术引进对经济增长方式转变的作用较为复杂<sup>［10］</sup> 随着大中型工业企业知识资本投入结构的变化，技术开发和技术改造投入与企业全要素生产率具有显著正相关性，国内外技术引进和消化吸收对企业创新的作用减弱<sup>［11］</sup> 全球化条件下随着一国经济发展，国内外产业技术差距逐渐缩小，无论短期政策调整 要素重置，还是长期加大研发投资，最终都要落在企业的能力积累上，通过能力积累提高全要素生产率的产品创新模式是以创新推动需求，提升产品质量的创新方式，不仅能够切实提高企业产品在国际市场上的竞争力，而且对于经济增长突破瓶颈，实现高质量发展至关重要<sup>［5］</sup> 而目前对研发投资带来的企业能力积累缺乏研究: 第一，企业能力难以度量;第二，研究创新对中国企业全要素生产率的影响，大多采用各地区大中型工业企业行业层面的数据，缺乏大样本的企业数据

## 1．2 企业能力

Ab i<sub>t</sub> 在其经典文章认为 <sup>“</sup>落后国家可以利用先进国家的技术而获得更高增长率<sup>”</sup>的传统说法需要限制条件，为此他引入了 <sup>“</sup>社会能力<sup>”</sup>变量，这一变量不仅包含了经济体的教育水平和公司组织方式，也包含经济体系的其他方面如市场开放程度新公司的建立和运营 新产品和服务的销售和购买的制度保障 为企业动员资本的金融制度和市场后来他又添加了具有竞争意识，如诚实和信任他人诚实的个人特性 以及稳定有效的政府等因素<sup>［12］［13］</sup> 其核心思想是社会能力及背后的决定因素导致了不同国家和地区经济发展绩效的差异<sub>。</sub>P<sub>ra</sub>h<sub>a</sub>l<sub>a</sub>d 和 H<sub>ame</sub>l 从企业层面提出了企业能力的概念，他们比较了美国 GTE 公司和日本 NEC 公司核心能力的差异，认为正是这种核心能力的差异造成了两个企业完全不同的经济绩效，因此，企业应该是各种能力的有机结合体<sup>［14］</sup><sub>。</sub> 企业战略管理学者认为企业必须大力培育自己的动态能力，对现有的资源<sub>、</sub>技能和能力进行构建<sub>、</sub>调整<sub>、</sub>整合和重构以应对全球化 技术进步和创新速度加快对企业发展所带来的挑战<sup>［15］</sup><sub>。</sub> 现有的研究定义企业能力大致基于两方面: 第一，沿用最初的动态能力概念的基础上把动态能力定义为比较抽象的企业构建 调整 整合重构内外部资源或能力的能力，企业感知和识别机会和威胁的能力，企业剥离和释放资源的能力或者进行学习的能力;第二，组织和实证的角度把动态能力视为一系列实施具体战略和组织过程或活动的能力，如产品开发 结盟 战略决策能力，营销和研发能力，创意 破坏市场 开发新产品和新流程的能力，或者开发新产品或服务 实施新的业务流程 创建新的顾客关系 改变经商方式的能力 在企业战略管理中，动态能力试图探求的是隐藏或不可见的 复杂并缄默的难以实现和模糊因果关系，实证研究多是基于单个组织的个案的解剖，以寻求个体组织的异质性 还没有涉及可以反映企业间共性并可识别和测量的具体方法 例如，罗仲伟等基于动态能力 技术范式和创新战略行为之间半交互影响的理论框架，尝试通过腾讯微信的 <sup>“</sup>整合<sup>”</sup>与 <sup>“</sup>迭代<sup>”</sup>打开 <sup>“</sup>微创新<sup>”</sup>战略的黑箱<sup>［16］</sup> 应瑛等基于后发企业从开放式创新网络中价值独占的理论框架，试图通过海康威视打开如何在开放式创新网络中实现价值独占的<sup>“</sup>黑箱<sup>”［17］</sup> 这些融入中国情景个案，在个体组织的异质性上深入 生动 细致，不仅丰富了该领域的基本理论，也对中国其他企业有较大启示意义

但企业能力的形成与积累，不仅包括个体企业的异质性过程，还包括企业间共性特征及所处的制度环境<sub>。</sub> 在全世界出口产品空间中，一国能够出口什么样的产品 在出口产品空间处于什么位置，承载着一国( 地区) 研发设计 营销管理 工艺创新 生产技术 人力资本及人力资源管理 财务金融 资本运作等众多生产性知识与能力<sup>［18］</sup><sub>。</sub> Hid<sub>a</sub>l<sub>go</sub> 等根据国际贸易产品空间高度异质性及产品集的不连续性等特征，提出的利用复杂网络的方法测度产品与国家( 地区) 复杂度的反射方法为本文在企业层面研究能力积累与全要素生产率提升提供了方法遵循<sup>［19］</sup><sub>。</sub>

因此，本文的可能的创新: 第一，利用国际贸易数据，借助于 Hid l 等提出了反射法<sup>［19］</sup>，经过多次迭代得到国家与产品的能力值，即复杂度值，另外与海关企业数据库中的中国企业出口数据匹配，测度了企业出口技术复杂度指标，丰富和深化了出口技术复杂度的研究内容，而且为地方政府依据自身的实际情况适当改变技术密集度等企业特征提供了针对性的政策建议;第二，把企业的研发投资活动与能力积累联系，构建了 <sup>“</sup>研发投资———能力积累——全要素生产率提高<sup>”</sup>的逻辑链条，深入到企业产品创新层面对研发投资促进全要素生产率提升的机制进行分析，区分了企业过程创新与产品创新的生产模式，并得出了富有启示意义的研究结论 这既丰富了出口技术复杂度的研究视角，又拓展了全要素生产率的研究领域，是对全要素生产率和出口技术复杂度理论的有益补充

## 2 研究设计

## 2．1 数据来源

本文数据主要来源于中国工业企业数据库与中国海关数据库 企业数据库提供了企业相关的一些指标，海关数据库提供了海关记录的每一笔详细的交易信息，包括进出口产品代码 金额 数量等等由于两个数据库中企业的编码方式不同，工业企业数据库中企业代码为10 位，海关数据库中企业代码为9 位，所以为了保证匹配的精准性，采取了企业名称加年份进行匹配 在匹配之前，剔除工业数据库中的不合理样本: 剔除主营业务收入小于 500 万的样本，剔除利润总额大于主营业务收入的样本，剔除补贴小于0 的样本，剔除长期投资小于0 的样本，剔除从业人数小于 8 的样本 最终获得 2000 2006年，165987 组匹配样本

K _ {c, n} = \frac {1}{K _ {c , 0}} \sum M _ {c p} K _ {p, n - 1}, K _ {p, n} = \frac {1}{K _ {p , 0}} \sum M _ {c p} K _ {c, n - 1}\tag{3}
$$

其中，<sub>c</sub> 代表国家，<sub>p</sub> 代表产品， $\mathrm { M _ { c p } }$ 连接了国家与产品的贸易信息，RCA 是显示性比较优势指数，$R C A _ { c p } ~ = ~ { \frac { X _ { c p } / \sum X _ { c p } } { \sum X _ { c p } / \sum ~ \sum X _ { c p } } }$ ，<sub>c</sub> 代表国家，<sub>p</sub> 代表产品，X 代表出口额<sub>。</sub> 如果 $\mathrm { R C A } > 1$ ，表示 <sub>c</sub> 国具有生产 $\mathrm { ~ p ~ } \overrightarrow { r }$ 品的能力， $\mathrm { M } _ { \mathrm { c p } } = 1$ ，否则 $\mathrm { M } _ { \mathrm { c p } } = 0$ <sub>。</sub> 迭代公式( 3) 直到 $K _ { c , n + 2 } \ = K _ { c , n } \ , K _ { p , n + 2 } \ = K _ { p , n }$ 停止<sub>。</sub> 对于国家来说，偶数次项代表了国家复杂度信息，奇数次项代表了产品复杂度信息;对于产品来说， $K _ { p , n }$ 偶数次项代表了产品复杂度信息，奇数次项代表了国家复杂度信息<sub>。</sub> 本文在产品复杂度指标中综合考虑了产品在世界范围内出口的普遍性特征和国家出口产品的分散化特征两方面信息，更好地体现了网状经济结构视角下的产品复杂度特征<sub>。</sub> 为了方便后文计算企业层面的复杂度特征，对产品复杂度进行了标准化处 理 为 了 使 指 标 具 有 可 比 性， $\begin{array} { r l } { p c i ^ { r } } & { { } = } \end{array}$ $\frac { K _ { p , n } \ - \ m e a n ( \ K _ { p , n } ) } { s t d ( \ K _ { p , n } ) }$ ，其中 $m e a n ( K _ { p , n } )$ 代表了所有产品的复杂度均值， $s t d ( K _ { p , n } )$ 代表了所有产品的复杂度标准差， $p c i ^ { \prime }$ 代表了标准化的产品复杂度指数，该指标越大，说明该产品对技术生产水平的要求越高

借鉴张龑和孙浦阳的方法<sup>［21］</sup>，基于不同企业对于不同产品的出口额进行加权平均得到企业出口技术复杂度的指标，即 $f p c i = \frac { v a l u e _ { i } } { \sum v a l u e _ { i } } \times p c i ^ { r }$ ，企业出口技术复杂度在一定程度反映了企业生产能力的积累<sub>。</sub> 产品复杂度与企业出口技术复杂度的计算需要的全球贸易数据来自 UNCOMTRADE 数据库，产品编码为HS6 位代码，使用反射法计算得到 2000 2006年5109 种HS 编码产品的复杂度指标，企业出口技术复杂度中的出口额权重指标来自中国海关数据库

其他变量 企业规模( scale) : 企业员工人数的自然对数 政府补贴( subsid ) : 补贴收入的自然对数<sub>。</sub> 资本密集度( kl) : 固定资产年末净值与员工人数比值的自然对数<sub>。</sub> 融资约束(finance) : 应收账款与营业收入的比值 利润率( ro) : 利润收入与营业收入的比值 资产负债率( debt) : 负债总计与资产总计的比值<sub>。</sub> 另外，引入地区虚拟变变量，行业虚拟变量与时间虚拟变量，地区虚拟变量控制了省份之间基础设施 地理位置等影响，行业虚拟变量控制了行业竞争差异等影响，时间虚拟变量控制了汇率变动等影响<sub>。</sub>

专业化分工理论认为由于国家具有的能力不同，会选择体现自己能力优势的产品进行专业化生产<sup>［23］</sup> 在微观层面，同一国家内的不同企业进行产品差异化生产的根本原因在于拥有的能力不同，企业生产能力和产出产品之间形成的网状供给关系，能够较好地体现企业生产选择和产品特征之间的互动关系 借鉴 Hid l 等国家 能力 产品的网状关系描述，本文绘制图 2 所示的企业 <sub>－</sub> 能力 <sub>－</sub> 产品的关系<sup>［19］</sup> 图2( ) 中生产关系中存在3 个企业与3 种能力，企业根据自身能力的不同生产不同的产品<sub>。</sub> 企业1 具有3 种能力，生产能力最强，企业2 具有能力2 与能力3，生产能力次之，企业3 只具有能力3，生产能力最弱<sub>。</sub> 而在实际研究中，我们很难准确地将能力分成不同的单元，我们往往更关注企业生产能力的差异，哪类企业生产能力较强，哪类企业生产能力较弱 图 2( b) 是直接将企业与产品通过能力网络的关系图，根据结果导向，企业1 能够生产3 种产品，我们认为企业 1 同时具备生产 3 种产品所必需的所有能力，生产能力最强，同理企业2 具备生产产品2 与产品3 所需的能力，生产能力次之，而企业3 只能够生产产品 3，只具备产品 3 所需的能力，生产能力最弱<sub>。</sub>

从产品层面来看，产品 3 在 3 个企业中都能被生产，而产品1 只有企业1 可以生产，我们可以认为产品1 具有较高的异质性( 对生产能力要求较高) ，而产品3 具有较高的普遍性( 对生产能力要求较弱) 在产品空间中，低普遍性并不一定意味着高复杂度，有可能因为出口国的天然比较优势或者是特定的消费偏好，例如原材料出口 反射法通过反复的迭代计算，将国家的多样性与产品的普遍性信息互相渗透，使得产品复杂度指标中同时包含了多样性与普遍性的信息 作为生产行为的主体，生产过程的实质是企业将自身具有的资源与能力进行组合的过程，企业的能力积累决定了各自专业化生产体现各自能力优势的产品组合 因此，我们认为可以通过产品中代表的能力推断生产这些产品的企业的能力 使用具有生产与销售的全球化特征的产品复杂度指标，可以进而构建企业出口技术复杂度指标来代表企业能力积累

## 4 结论与启示

本文使用宏观国际贸易数据完成了对微观产品复杂度与企业能力的测算，讨论了企业研发 能力积累对于全要素生产率提高的影响 主要结论是: 企业研发与能力积累都有助于全要素生产率提高，中国企业在总体上表现出了产品创新生产模式的特点;对于异质性企业样本估计结果，非国有企业与税收优惠企业表现出产品创新生产模式的特点，国有企业与补贴企业表现出过程创新生产模式的特点<sub>。</sub>从行业技术水平角度，中国在高技术行业与中高技术行业尚未表现出产品创新模式的特征

由于生产能力积累的不足，中国企业长期以来往往跟随着国外的技术路线，进行模仿性与同化性生产，然而，每当国外推出效率更高的替代技术或替代产品时，中国企业又陷入了落后追赶的局面 模仿只是实现追赶的一种低效率的生产模式，要实现<sup>“</sup>弯道超车<sup>”</sup>，需要长时间的能力积累来实现向规模报酬递增的结构性转变 在此过程中要求中国企业由过程创新的生产模式转变为产品创新的生产模式<sub>。</sub> 由于能力的积累存在路径依赖的特征，高新产业的发展需要以传统产业的能力为基础 这要求政府在制定一产业扶持政策来促进高新产业发展时，减小直接补贴等选择性政策，更多采用具有普惠性的支持政策 在微观企业层面，要深化现代企业制度和管理体制改革，提高公司治理水平，刺激企业进行研发活动的动力，切实提升企业出口产品的技术含量，实现企业能力积累的突破，切实提高企业生产率水平，促进中国经济的高质量发展
