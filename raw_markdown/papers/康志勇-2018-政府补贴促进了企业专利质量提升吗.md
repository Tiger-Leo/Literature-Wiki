# 政府补贴促进了企业专利质量提升吗?

康志勇( 扬州大学商学院，江苏扬州 225009)

摘 要:中国经济正处于由要素推动型模式向创新驱动模式转变的历史时期，政府补贴已成为激励企业创新研发 加快经济发展方式转型的主要推手 本文以此为背景，借助匹配模型和企业专利数据就中国政府补贴对企业专利质量的总体影响效果 影响的滞后性 持续性等问题进行了实证研究 检验发现，政府补贴对企业专利质量的提升具有促进作用，同时这种促进作用具有一定的滞后性和持续性 在分样本检验中发现，政府补贴的促进作用与被资助企业的所有制属性 企业规模以及知识产权保护的力度密切相关 这些实证结果为中国未来创新资助政策的调整提供了有意义的参考

关键词:政府补贴;专利质量;匹配模型

为了有效提升中国创新能力，中国于2006 年提出建设<sup>“</sup>创新型国家<sup>”</sup>的发展目标 年将 <sup>“</sup>创新驱动发展战略<sup>”</sup>写入了党的十八大报告 2013 年颁布了 《关于强化企业技术创新主体地位全面提升企业创新能力的意见》，明确将提升企业为主的技术创新能力，作为实施创新驱动发展战略以及建设创新型国家的核心目标 中国各级政府更是不遗余力地加大对企业的补贴支持力度以促进企业创新水平和能力的提升<sub>。</sub> 依据统计，2001 至 2010 年间中国沪深两市50%以上企业得到政府补贴，补贴总额从2001 年的37 亿快速增长到 2010 年的 330 亿元，年均增长率达 24． 32%<sup>［1］</sup> 在中国政府大力推进下，中国创新能力得到了显著提升 以中国专利申请量和授权量为例<sub>。</sub> 三种专利的申请受理量由 1995 年的 83045 件增加到 2013 年的 2377061 件，增长了28．63 倍，年平均增长率均高达 20． 69%，2012 年成为全球发明专利申请数量第一大国 根据世界知识产权组织发布的最新报告，2014 年中国企业在 《专利合作条约》 PCT 框架下共提交国际专利申请25539 件，年增长率高达18．7%，增长速度位列全球第一 虽然近年中国在创新研发方面取得长足进步，但与主要发达国家相比仍然存在较大差距，中国创新指数在全球排名仅为第29 位;从反映各国专利数量的<sup>“</sup>专利族<sup>”</sup>规模看，中国仅 891 件，占世界总量的 1． 36% 。

补贴对于企业创新行为的研究由来已久 由于企业的创新研发活动具有明显的正外部性，企业创新研发活动的私人收益可能会小于社会收益，市场失灵导致企业私人创新研发投入小于社会最优水平，阻碍一国经济增长 为了纠正这一缺陷，各国政府都在不遗余力的采用政策手段鼓励企业增加创新研发投入，促进企业创新研发能力提升<sub>。</sub> 20 世纪90年代以来，美国企业创新研发投入的 30%来源于政府资助，同期欧盟和日本分别为 35%和 18． 5%<sup>［2］</sup>尽管创新补贴是一项被广泛实施的经济政策，但学术界对其作用的效果尚未形成一致的看法<sup>［3］</sup> 国内学者就政府补贴对企业创新研发的影响也进行了实证研究，大多数结果认为政府补贴对企业研发投入的具有显著的促进作用 纵观现有文献不难发现，国内外的主流文献基本都以企业研发投入为研究对象，重视企业研发投入数量而忽视了对研发产出质量( 专利质量) 的研究 企业研发投入的数量和研发产出的质量是全面衡量企业创新研发行为不可或缺的两个维度，因此政府补贴与企业专利质量之间的关系应该得到足够的重视

## 1 文献综述与研究假设

中国专利数量迅速增长及其背后的原因引发了国外机构 学者们的关注和质疑，他们认为中国企业申请专利数量的快速增长主要源于中国政府的政策干预而非企业创新研发能力的提升<sup>［4］</sup> 汤森路透集团发布的 《中国的创新份额》(2014) 报告指出，中国专利申请数量的飞速增长是政府专利发展战略和资助政策推动的产物 英国 《经济学家》( 2014) 更将中国专利增长定义为一种由政府主导的 <sup>“</sup>专利泡沫<sup>”</sup> <sub>。</sub> 中国欧盟商会 2014 年发布的 《创新迷途: 中国的专利政策与实践如何阻碍了创新的脚步》报告预计，2015 年中国高质量专利申请量将大幅度减少，低质量专利申请量可能将超过260 万件，两者间的差距将进一步扩大 中国政府的专利激励政策显著促进了专利申请数量和授权数的提高，但是却显著降低了企业专利的平均质量<sup>［5</sup> <sup>－</sup> <sup>7］</sup><sub>。</sub> 但也有学者持相反的看法<sup>［8］</sup>，指出近年来中国专利授权率并未明显下降间接论证了政府补贴政策并未引发企业创新研发质量的下降<sub>。</sub> 作为一个转型经济体，中国政府在推动经济发展以及企业创新能力提升过程中扮演着极其重要的角色，中国的专利质量也必然受到了政府行为的影响 那么，广泛实施的政府补贴是引发中国企业专利质量下降的<sup>“</sup>罪魁祸首<sup>”</sup>吗?

政府补贴对企业专利质量的影响存在两种截然相反的作用机制 一方面，政府补贴对企业专利质量的提升具体积极的促进作用 企业创新研发需要大量资金的长期投入，资金不足则会导致研发终止或失败，因此企业研发需要融资体系的有效支撑现实中无论发达国家还是发展中国家融资约束都是困扰各国企业的一个普遍性难题<sup>［9］</sup> 中国普遍存在金融发展滞后和金融抑制的现象<sup>［10］</sup>，更加剧中国企业特别是中小微企业以及高科技企业的融资约束问题，对企业创新研发活动产生抑制 政府补贴可以在一定程度上缓解企业面临的融资约束，而且作为企业总利润的一部分，可以直接增加企业收益，对企业研发活动产生积极的促进作用 特别是，针对企业新产品研发以及专利申请方面的专项补贴还可以有效降低企业创新过程中的成本和风险，激发企业加大创新研发投入，促进企业专利质量的提升另外，当外部市场环境存在一些制度缺失或扭曲不利于企业创新时，政府补贴往往可以起到对缺失或扭曲制度的弥补<sub>。</sub> 比如，由于经济转型中国存在或多或少的要素市场扭曲和国内市场的分割，这些都对企业创新投入乃至专利质量具有负面效应，政府补贴可以作为缺失制度的一种弥补，激励企业的创新研发投入，促进企业专利质量的提升<sub>。</sub>

另一方面，政府补贴对企业专利质量的提升也具有抑制作用<sub>。</sub> 首选，政府补贴可能存在挤出效应，抑制企业专利的质量 当政府实施补贴计划时，部分企业更加倾向于申请政府补贴计划内的研发项目，因为政府补贴对于这些企业来说边际成本机会为零<sub>。</sub> 由于对专利真实质量存在信息不对称，政府无法对企业专利质量进行有效研判，更加倾向于关注企业专利的数量变化<sub>。</sub> 因此，政府补贴会诱使微观主体的专利申请活动出现逆向选择和道德风险，可能会导致大量低质量以及不具有产业运用价值的专利的产生 因此，政府补贴实际上不仅会挤出了企业研发支出还会抑制专利的质量 其次，政府补贴还会扭曲资源配置 政府补贴的 <sup>“</sup>援助之手<sup>”</sup>还会被利益集团或政客所扭曲<sup>［11］</sup>，各级政府倾向于支持与其政治关联更密切的企业，企业也会千方百计套取政府补贴来直接增加企业利润，而并不愿意去进行风险更高的创新研发活动，这也会导致企业专利质量的下降 最后，企业专利数量是一种有效的信号显示器，中国不少企业进行专利申请以及获得专利授权只是将其作为向客户或市场传递企业具有市场竞争优势的一种信号机制<sup>［12］</sup>，目的只是更有利于争取政府的各项优惠政策和补贴，例如: 高新技术企业发展扶持政策及税收优惠等 企业在宣传自身竞争优势时将有多少专利申请以及获得多少授权专利作为证明企业竞争实力的信号，而有意无意地忽视了相关专利质量以及专利的产业化运用等信息，这种重数量 轻质量的机制也诱使企业偏向于低质量专利的制造与申请，而不会激励企业创造高质量的专利以及强化专利的产业运用 中国企业授权专利中高达27．6%的发明专利以及 30．9%的实用新型专利的非正常放弃，在很大程度上可能就说明了这些现象的负面效应 基于以上分析，本文提出如下研究假设:

大部分文献就补贴对企业创新行为当期或短期效果进行研究，但是政府补贴的效果可能在更长时间内才能完全体现 有研究指出补贴可以为企业带来一定的知识溢出效应和增加研发人员数量，这些因素会在今后逐步持续发挥作用<sup>［13］［14］</sup><sub>。</sub> 还有学者认为，企业创新研发活动会面临一定的协调成本也是造成补贴作用在数年后体现的原因之一<sup>［15］</sup> 因此对补贴效果长期性的研究必不可少<sub>。</sub>

假说3 政府补贴对企业专利质量的影响可能具有一定的滞后性和持续性<sub>。</sub>

所有制类别<sub>、</sub>企业规模以及知识产权保护可能会影响政府补贴的作用效果<sub>。</sub> 考虑到现阶段中国经济所处转型背景下，不同所有制类型以及不同规模的企业在获得金融资源及政府政策<sub>、</sub>商业机会<sub>、</sub>自身研发水平以及企业内部效率方面存在明显差异，这些差异都会对政府补贴的作用效果产生影响 如果知识产权保护制度的相对不完善或者是执行机制的缺位，会导致企业的创新活动得不到有效保护，企业也倾向于选择低质量专利

## 2 模型设定与数据来源

## 2．1 样本数据处理与说明

本文使用的研究样本数据主要来源于中国国家专利局发布1985 年至2013 年的所有工业企业的专利数据库和国家统计局发布的1999 年至2007 年间规模以上工业企业数据库中的本土企业样本数据考虑到工业企业数据库中6 －12 的二分位制造业行业均是依赖自然资源禀赋的采矿相关行业，很多省份地区由于自然资源的缺乏并不存在采矿业相关行业 本文利用规模以上工业企业数据库所有企业的中文名称作为匹配工具，来对国家专利局数据库中的所有样本数据进行匹配

## 2． 2 PSM － DID 模型

从研究方法角度来看，能否有效地解决样本选择偏差以及获取政府补贴和企业专利质量之间由于逆向因果关系导致的内生性问题是正确判断政府补贴是否可以促进企业专利质量提升的关键所在 以往文献一般多利用工具变量法来解决上述问题，但是由于选择合理工具变量的难度非常大，因此，越来越多的研究开始采用倾向得分匹配法( PSM，Propen-sity Score Matching) 来有效解决内生性及样本选择偏差等问题 为了进一步减少非参数估计的偏差并消除不随时间变动的企业个体效应对配对估计的影响<sup>［16］</sup>，本文还将在倾向匹配法的基础上融入倍差法( DID，Difference In Difference) ，即采用 PSM － DID作为本文的计量框架

从样本企业中选择两种类型企业作为分析对象: 一类是为样本期间内没有获得补贴资助的企业;另一类是样本期间内于某一年获得补贴资助的企业，将前者称为对照组企业，后者称为处理组企业定义一个二元虚拟变量 $S u b s i d y _ { k t } ~ = ~ \{ 0 , 1 \}$ ，其中取值1 表示企业 k 在时期 t 为处理组企业，取值 0 表示其为对照组企业<sub>。</sub> 定义企业专利质量为 $P Q ( \mathrm { P a } - $ tent Quality，PQ) ，变量 $Q P _ { k t + } ^ { 1 }$ 为获得补贴企业 k 于时期 t 获得补贴资助后在第 $\mathrm { ~ t ~ } + \mathrm { ~ s ~ }$ 年时专利的质量<sub>。</sub>定义变量 $Q P _ { k t } ^ { 0 }$ +s 为获得资助企业 k 于时期 t 未获得补贴资助时在第 $\mathrm { \bf ~ t } + \mathrm { \bf ~ s }$ 年时专利的质量 令下标 $\mathbf { k } =$ $\{ \mathrm { i } , \mathrm { j } \}$ ，其中 k =i 代表处理组企业， $\mathbf { k } = \mathbf { j }$ 代表对照组企业 根据 Smith 和 Todd 的处理方法，处理组企业于第 t 年获得补贴资助后在第 $\mathrm { \bf ~ t } + \mathrm { \bf ~ s }$ 年补贴资助对其专利质量的因果影响为:

$$
\begin{array}{r l} A T T & = E \left(P Q _ {i t + s} ^ {1} - P Q _ {i t + s} ^ {0} \mid S u b s i d y _ {i t} = 1\right) \\ & = E \left(P Q _ {i t + s} ^ {1} \mid S u b s i d y _ {i t} = 1\right) - E \left(P Q _ {i t + s} ^ {0} \mid S u b s i d y _ {i t} = 1\right) \end{array} \tag {1}
$$

实际中 E( $P Q _ { i t + s } ^ { 0 } \mid S u b s i d y _ { i t } \ = \ 1 \big )$ 是不可观测的，可以通过 <sup>“</sup>反事实 $\mathrm { " } \left( \mathrm { \ c o u n t e r - f a c t u a l { l } } \right)$ 方法进行估算，其基本逻辑是: 从未获得补贴资助的样本企业中寻找与获得补贴资助企业的基本特征相匹配的样本( 控制组) ，以替代那些实际上获得补贴资助但假定其未获得补贴资助时专利质量的对比组企业，即寻找对照组企业在第 $\mathrm { ~ t ~ } + \mathrm { ~ s ~ }$ 年专利质量 $E \big ( \mathbf { \nabla } P Q _ { i t + } ^ { 0 }$ <sub>s</sub> |$S u b s i d y _ { i t } ~ = ~ 0 )$ 作为 $E \{ ~ P Q _ { i t + s } ^ { 0 } ~ | ~ S u b s i d y _ { i t } ~ = ~ 1 \}$ 的替代 假定处理组和控制组企业的差异，可以由包含企业在获得补贴资助前的一系列相关特征变量所准确反映<sup>［17］</sup> 令 $p \ = \ p { \big ( } \ S u b s i d y _ { k t } \ = \ 1 { \big ) } \ = \mu { \big ( } \ X _ { k t - 1 } { \big ) }$ 为企业获得补贴资助的概率， $X _ { k t - 1 }$ 为匹配变量即共同影响因素 采用 Probit 或者 $\mathrm { L o g i t }$ 方法可以对上式进行估算，得到处理组企业 i 获得补贴资助概率的预测值记为p ，对照组企业 j 获得补贴资助概率的 $p _ { i }$ 预测值记为 $p _ { j }$ ，则政府补贴对企业专利质量的因果效应为:

$$
A T T = \frac {1}{n _ {i}} \sum_ {i \in (T = 1)} \left[ P Q _ {i t + s} - \sum_ {j \in (T = 1)} g \left(p _ {i}, p _ {j}\right) P Q _ {j t + s} \right]\tag{2}
$$

将倍差法( DID) 引入匹配估计可以显著减少原来 PSM 非参数估计的偏差，消除不随时间变动的企业个体效应对配对估计的影响<sup>［16］</sup><sub>。</sub> 令 $\Delta P Q _ { k t + s } ~ =$ $P Q _ { k t + s } \ - \ P Q _ { k t - }$ 表示企业 k 获得补贴资助前后其专利质量的变动情况，则基于倍差法的倾向评分匹配估计方程为:

$$
\begin{array}{r l} A T T & = \frac {1}{n _ {i}} \sum_ {i \in (T = 1)} [ \Delta P Q _ {i t + s} - \sum_ {j \in (T = 1)} g (p _ {i}, \\ p _ {j}) \Delta P Q _ {j t + s} ] \end{array} \tag {3}
$$

(3) 式表明本文采用了 PSM － DID 计量框架后，可以估算企业在不同时期内获得补贴资助对企业专利质量的长期影响<sub>。</sub> 在实际匹配时还必须考虑数据本身可能引发的估算偏差 传统 PSM 模型一般基于截面数据进行分析，但本文数据为面板数据，同一个变量存在多期观察值<sub>。</sub> 在设定企业是否获得补贴资助的二元虚拟变量 $S u b s i d y t _ { k t }$ 进行匹配时，PSM 命令会将整个数据 <sup>“</sup>错误<sup>”</sup>的设定成截面数据，导致不同时期的同一企业被视为不同的企业出现相互匹配的情况 为了避免这一情况的出现，本文将对于处理变量 $S u b s i d y _ { k i }$ 作了进一步定义，即将该企业在其他年份的处理变量值变为缺失值 这样，获得补贴资助的企业仅在获取政府补贴资助的年份具有处理变量值，在匹配中只会与从未获得补贴资助的企业进行匹配<sub>。</sub>

$$

## 3．4 企业规模视角的检验与分析

企业自身规模的差异可能也会导致政府补贴对企业专利质量的作用效应造成差异性影响<sub>。</sub> 一般认为，小企业拥有更高的研发意愿; 相反，规模较大的企业可能会拥有较为完备的创新研发体系，生产效率和自身技术水平也会更高( 以 TFP 衡量) <sup>⑤</sup> 规模较小的企业受制于自身技术能力，寻租动机可能更加强烈<sub>。</sub> 根据笔者对长三角地区中小企业的走访调研发现，很多小企业研发的根本目的只是为了获得政府相应的补贴，形成给钱就研发的局面<sub>。</sub> 另外，政府补贴规模一旦超出企业运用所拥有资源进行生产 研发等经营活动的能力( 以企业规模来衡量) ，也会生产对专利质量的负面影响<sub>。</sub> 基于以上考虑，本文将企业规模大于样本均值的企业定义为规模较大的企业样本组，而将企业规模小于样本均值的企业定义为规模较小的企业样本组 表7 和表8 分别列示了规模较大企业样本和规模较小企业样本的估计结果 对于规模较大企业样本( 表 7) ，无论处理变量是发明专利还是实用新型专利，政府补贴对文本解读发计算的发明专利质量的滞后1 2 期和实用新型专利的滞后第 3 期系数显著的促进作用，即政府补贴对企业专利质量产生了较为显著的 持续性的促进效应 而对于规模较小企业样本( 表 8) ，政府补贴仅对企业发明专利质量提升产生微弱的促进效应( 滞后3 期的系数在10%水平上显著性为正) ，而且在对实用新型专利质量产生了抑制作用( 滞后6 期的系数在10%水平上显著性为负) 本文的结论验证了熊彼特假说，创新的企业拥有一定的市场支配力量是确保创新激励不可或缺的手段，企业规模越大，技术创新就越有效率，专利质量也就越高<sub>。</sub>这些经验结果深刻说明，中国背景下政府补贴政策提升专利质量的有效性实际上是与企业自身条件紧密相关的，只对那些自身规模较大 竞争能力强的企业的专利质量的提升产生可持续性的促进效应<sub>。</sub>

## 3．5 知识产权保护视角的检验与分析

既有研究发现中国的知识产权保护制度是影响企业创新研发的重要因素，知识产权保护越不完善的地区，企业研发成果被抄袭的几率越高，企业进行高质量研发的动机会被极大的削弱，政府补贴对专利质量的提升作用也会被遏制 为了检验政府补贴对专利质量的作用是否会因知识产权保护程度的不同而表现出一定的差异，本文引入知识产权保护变量 <sub>。</sub> 本文度量知识产权保护变量( Intellectual Prop-erty Protection，IPP) 采用 《中国市场化指数 》 中对中国各省份地区知识产权保护程度的测度指标，该变量越大，则说明地区的知识产权保护制度越好<sub>。</sub> 根据 IPP 值的大小，将所有样本分为保护较强的样本( 大于每年知识知识产权保护水平的均值) 和保护较弱的样本( 小于每年知识知识产权保护水平的均值) 进行重新检验，结果见表9 10 结果证实，知识产权保护越完善的地区，政府补贴对企业专利质量提升的作用更加显著;相反，在知识产权保护越不完善的地区，政府补贴对企业专利质量具有抑制作用<sub>。</sub>整体上看，由于中国企业大多数还处于模仿阶段，模仿创新的成果未必会以专利的形式呈现，知识产权保护制度的相对不完善或者是执行机制的缺位，导致企业的创新活动得不到有效保护<sub>。</sub> 这种情形下，很多企业就失去了通过专利申请来保护自身高质量创新成果的激励<sub>。</sub>

## 4 结论和政策含义

本文采用国家统计局规模以上工业企业库和中国所有工业企业的专利数据库的合并数据，依靠改进的 PSM － DID 计量框架，实证检验中国背景下政府补贴对企业专利质量的综合影响效应<sub>。</sub> 本文为中国制造业企业创新活动的动态演变提供了质量视角的新解释，也为衡量中国政府补贴政策的效果和完善补贴政策提供了新的证据 本文有意义的发现归结如下: 第一，本文基于文本解读法和知识宽度法估算了中国企业获得授权的发明专利和实用新型专利的质量水平，样本期内均未发现中国企业发明专利与实用新型专利的质量有明显的下降趋势，这一判断与国外一些研究的结论不一致<sub>。</sub> 第二，总体看当前中国政府的政府补贴对促进企业专利质量没用出现负面的影响，相反具有一定的促进作用，虽然这种促进作用的效果相对有限，持续的时间也较为短暂第三，从更为细致的角度来看，在民营企业 规模较大企业以及知识产权保护较为完善地区的样本企业组中，发现了政府补贴对企业专利质量造成了显著的持续性的促进作用;在国有集体企业 规模较小企业以及识产权保护较不完善的样本企业组中，并未发现显著且持久的促进作用，相反，还不同程度出现了抑制作用 此表明，中国背景下政府实施的补贴对企业专利质量的影响效果与企业自身因素及外部市场环境密切相关<sub>。</sub>

中国经济已经走到了依靠企业研发创新能力提高以促进经济结构调整和经济发展质量水平提升的重要关口，虽然从总体上看，中国政府补贴对企业专利质量的提升起到了一定的作用，但不可否认政府补贴在一些样本中也体现出了明显的抑制作用<sub>。</sub> 因此，在短期内无法放弃政府补贴这一政策手段的前提下，强调政府补贴政策与知识产权保护制度的完善化 金融市场的市场化改革以及公平竞争的市场环境建设等政策的配合就显得尤为重要，不仅要实现中国企业专利在数量上的追赶，更要实现专利质量上的提升 从长远看，政府更应该逐步放弃差异性财税政策，撇清与企业的关系，让企业真正成为创新研发的主体，通过着力构建公平的市场环境和完善的创新驱动发展战略的顶层设计来推进企业创新研发<sub>。</sub>
