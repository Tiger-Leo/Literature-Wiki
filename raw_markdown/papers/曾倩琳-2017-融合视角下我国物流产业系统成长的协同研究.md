# 融合视角下我国物流产业系统成长的协同研究

曾倩琳<sup>1，2</sup>

（1.福州大学 经济与管理学院；2.福建江夏学院 工商管理学院，福州350108）

摘 要：基于物流产业系统的成长模型，文章分析了复合系统内各子系统的相互作用和相互影响，并共同推动了物流产业系统的成长。同时以我国物流上市公司为样本，基于物流产业系统的协同发展模型，测算了我国物流产业各子系统的有序度和复合系统的协同度，结果表明三个子系统有序度处于波动状态，且某些子系统有序度的短板效应，导致了我国物流产业未能协调发展。

## 0 引言

信息化时代，融合现象的出现是产业系统面临的最主要的外界环境，同时由于融合的关键和驱动力是以信息技术为代表的信息化，两者互相作用，产业融合产生了复合经济效应，进而推动了产业系统在结构和组织上的演化，产业由此获得巨大的发展潜力，加速成长。

在融合背景下，物流产业系统的成长是一个复合系统，其要素之间是相互影响的，产业结构和组织形式也会反作用于产业融合，共同推动物流产业系统的成长。故，第一，本文试图回答，在以信息技术为代表的信息化时代，基于产业融合视角，物流产业系统成长的演变是如何进行的？有哪些要素构成？它们之间的联系和作用是怎么样的？第二，现有文献大多采用的是定性或是宏观角度分析物流产业系统的成长演化，缺乏事实的支撑，而物流产业演化过程最终都是通过企业这个载体得以实现，基于此，本文从企业的微观角度出发，以我国物流上市公司为对象，评价物流产业系统演化的有序度和协同度。

## 1 物流产业系统成长的协同模型构建

## 1.1 物流产业系统成长的协同模型

物流产业的形成和发展是一个历史过程其在成长中的产业融合现象并非偶然的经济现象，它是生产力发展、社会分工深化，科技进步和物流产业结构高效化的必然趋势。物流产业融合的发展对物流产业的组织、结构、技术、管理以及资源配置都产生了很大的影响，促进了有效竞争，重塑了市场结构和产业组织，由于物流产业具有高复合性、服务性和关联性，物流产业融合通过物流服务的运作，微观上改变了产业的市场结构和绩效，宏观上改变了国家的产业结构和经济增长方式。基于融合对物流产业系统的效应分析，其成长涉及产业融合、产业结构和产业组织三个要素，是这三个子系统互相作用、互相协同的结果。

物流产业融合形式上表现为产业交叉、产业渗透与业态创新，实质上则内化于物流企业在资源整合基础上的模式、组织及服务。故根据以上分析，对于企业而言，产业融合表现为企业的市场结构和市场行为，产业结构表现为企业在资产、劳动力、技术等资源配置上的调整，产业组织则通过策略调整表现于企业的市场绩效。物流产业系统成长的三个子系统互相作用，信息化是融合的催化剂，支持、保障产业结构的调整和产业组织的改善，融合促进了产业结构的升级和产业组织的优化，而后两者又反作用于产业融合，为物流产业融合的推进创造了条件。三个子系统通过彼此之间的协同竞争，相互影响，构成了物流产业系统的成长模型，如图1。在开放的物流产业系统中，各子系统的协同度大小是物流产业系统可持续发展的关键，不同子系统之间非线性协作与竞争使物流产业系统向融合化。有序化和专业化的方向发展。

如前所述，物流产业系统成长是由3个子系统构成的复杂系统 $S { = } \left( S _ { 1 } , S _ { 2 } , S _ { 3 } \right)$ ，其中 $S _ { j }$ 为第j个子系统，每个子系统用序参量 $S _ { j } = \left( S _ { j 1 } , S _ { j 2 } , \cdots , S _ { j m } \right)$ 描述。 $S _ { j m }$ 的值越大，该子系统的有序程度越高，贡献也就越大。物流产业系统成长的复合因子 $S { = } f \big ( S _ { 1 } , S _ { 2 } , S _ { 3 } \big )$ ，即协同度由各子系统的和谐程度决定。

## （1）各子系统的有序度

子系统在发展过程中的序参量为 $e _ { j } = { \big ( } e _ { j 1 } , e _ { j 2 } , \cdots , e _ { j m } { \big ) } .$ $m \geq 1 , \beta _ { j i } \leq e _ { j i } \leq \alpha _ { j i } , i \in [ 1 , m ]$ ，分为慢驰豫变量和快驰豫变量，如果 $e _ { j 1 } , e _ { j 2 } , \cdots e _ { j l }$ 为慢驰豫变量，取值越大，系统的有序程度越高，反之则系统有序程度越低，而快驰豫变量的意义相反。据此序参量有序度的计算公式为：

$$
U _ {j} \left(e _ {j i}\right) \left\{ \begin{array}{l} \frac {\left(e _ {j i} - \beta_ {j i}\right)}{\left(\alpha_ {j i} - \beta_ {j i}\right)}, i \in [ 1, l ] \\ \frac {\left(\alpha_ {j i} - e _ {j i}\right)}{\left(\alpha_ {j i} - \beta_ {j i}\right)}, i \in [ l + 1, m ] \end{array} \right.\tag{1}
$$

其中，α 和 $a _ { j i }$ $\beta _ { j i }$ 分别是第j个子系统在第i个指标的上限值和下限值。由公式（1）可知， $u _ { j } \big ( e _ { j i } \big ) \in [ 0 , 1 ]$ ，值越大，序参量 $e _ { j i }$ 对相应子系统有序的贡献越大。

序参量变量 $e _ { j i }$ 对子系统 $S _ { j }$ 有序程度的总贡献可通过$u _ { j } \big ( e _ { j i } \big )$ 的集成来实现。集成形式在应用中主要有几何平均法和线性加权求和法，本文采用后者处理数据，即 $S _ { j }$ 子系统的有序度计算公式为：

$$
u _ {j} \left(e _ {j}\right) = \sum_ {i = 1} ^ {m} \omega_ {i} u _ {j} \left(e _ {j i}\right), \omega_ {i} \geq 0, \sum_ {i = 1} ^ {m} \omega_ {i} = 1\tag{2}
$$

由公式（2）可知， $u _ { j } \big ( e _ { j } \big ) \in [ 0 \AA$ 1]，其取值越高，子系统的有序度越高，反之子系统的有序度越低。

## （2）物流 $\vec { r } ^ { x }$ 业系统的协同度

设 在 $t _ { 0 }$ 初 始 时 刻 ，各 子 系 统 的 有 序 度 为${ u _ { j } ^ { \ : 0 } \big ( e _ { j } \big ) } , j = 1 , 2 , \cdots n$ ，而当整个复合系统发展演化到时刻$t _ { 1 }$ ，各子系统的有序度为 $u _ { j } ^ { { \scriptscriptstyle 1 } } \big ( e _ { j } \big ) , j = 1 , 2 \cdots n$ 。则复合系统的协调度为：

$$
C = \theta \sum_ {j = 1} ^ {n} \delta_ {j} \left| u _ {j} ^ {1} \left(e _ {j}\right) - u _ {j} ^ {0} \left(e _ {j}\right) \right|, \delta_ {j} \geq 0, \sum_ {j = 1} ^ {n} \delta_ {j} = 1\tag{3}
$$

其中

$$
\theta = \frac {\min \left[ u _ {j} ^ {1} \left(e _ {j}\right) - u _ {j} ^ {0} \left(e _ {j}\right) \neq 0 \right]}{\left| \min \left[ u _ {j} ^ {1} \left(e _ {j}\right) - u _ {j} ^ {0} \left(e _ {j}\right) \neq 0 \right] \right|}, j = 1, 2, \dots n, \delta_ {j} \geq 0, \sum_ {j = 1} ^ {n} \delta_ {j} = 1
$$

由式（3）可知复合系统协调度 $C \in [ - 1 , 1 ]$ ，值越大，协调发展的程度越高，反之则越低。另外，公式（3）考虑了所有子系统情况，当且仅当所有的 $u _ { j } ^ { 1 } \big ( e _ { j } ^ { } \big ) - u _ { j } ^ { 0 } \big ( e _ { j } ^ { } \big ) > 0$ 成立时，复合系统才有正的协同度，如果整个系统不能处于较好的协调状态或根本不协调，体现为 $C \in [ - 1 , 0 ]$ 。以上公式也反映了这是一种动态分析的过程，可以检验物流成长系统协同程度的特征与变化趋势。

## 2.2 数据来源

根据中国GICS行业分类法，剔除物流业务收入占公司总收入50%以下、近3年被ST和STT的上市公司，最终选取78家物流业上市公司作为研究样本，以其2007—2014年的数据为基础进行实证分析，原始数据来源于巨潮资讯网和相应上市公司的的年度报告。对原始数据进行整理，剔除残损数值，计算出2007—2014年各个指标的累计值，并对各项指标的累计值求得均值，得到物流产业成长系统评价体系。

## 2.4 结果分析

如表11中的协同度数值所示，除了2009年和2014年的协同度为正，其余年度显示为负值，总体来说，目前我国物流业不能协调发展，但这种不协调逐步在缩小。根据表11数据，绘制出各子系统有序度的变化趋势图，从图2中可看出我国物流业系统成长系统协调发展存在“木桶效应”，即某些子系统有序度的短板在一定程度上影响了整体的协同发展，如2007—2008年，组织子系统的有序度较高，但结构子系统和融合子系统有序度处于较低水平，导致整个复合系统协同度较低·在2009一2010年虽然融合子系统和组织子系统的有序度上升，达到了较高水平，但结构子系统的有序度较低，导致整个复合系统协同度仍然不高。

从我国物流业成长系统演变的协同度动态发展过程来看，在2007—2014年间，整个成长系统的协同度呈现波动演变状态·在2007—2010年，各子系统的有序度一致呈现先下降后上升的趋势，整个复合系统的协同度表现为上升，在2010—2012年，融合子系统和组织子系统呈现下降趋势，而结构子系统呈现先上升后下降趋势，导致整个复合系统协同度呈现下降态势，2013—2014年，融合、结构和组织三个子系统呈现上升的趋势，复合系统的协同度表现为上升。

从各子系统有序度的发展情况来看，融合子系统、结构子系统和组织子系统的有序度呈现无序波动态势，皆不能处于有序发展状态。通过序变量有序度变化情况可知，其中融合子系统未实现有序发展主要是由于“市场融合(eu)”、“市场拓展水平(e₂)”和“技术人员比率(ew)”三个序变量有序度的波动导致。市场融合是融合下企业得以生存的基础，通过市场规模和市场状况来考察融合的真实情况，市场拓展水平反映了融合下企业提供的一体化物流服务的市场范围和市场扩散程度，而技术人员比率说明了含技术知识和管理知识的技术人力资本是技术创新和融合的决定性因素。三个序变量的波动与我国物流业的现状和特点相符·融合型物流企业通过提供现代化，一体化物流服务，可以提高物流服务产品的差异化，满足客户不同的物流偏好，从而能够迅速扩大其市场份额，但我国物流企业的融合并不凸显，如第四物流企业，即物流提供商与供应链服务设计提供商的联盟匮乏缺，且大部分物流企业规模小、业务范围窄，功能不完善，服务水平和能力不足，无法满足日益提升的个性化的物流需求，中国物流企业50强企业，拥有超过3％市场份额的企业却无一家，此外，我国物流企业的研发实力弱，主要依赖信息技术与物流的融合来提高物流技术的通用性存在滞后效应，另外，结构子系统和组织子系统不能有序发展源于各自的序参量一直处于波动状态，作为物流产业系统成长最主要表现的组织子系统，变动幅度最大，其通过物流企业绩效水平不佳、处于不稳定状态的表现，反映了物流企业的组织形式、资源配置途径未能向正常化、有序化的方向发展。我国物流业的融合状态在进入信息化时代才开始显现，是融合环境、企业组织调整和管理改善及其由此形成的资源整合能力等因素的共同作用结果，而技术，人才和绩效等因素都制约着产业融合效应的出现，在融合背景下，由于各子系统的有序度波动，同时在一定时期内复合系统受某些子系统有序度短板的影响，导致整个物流业不能协调发展。

## 3 结论与建议

本文首先在物流产业系统的成长模型基础上，分析了复合系统内各子系统的相互作用和相互影响物流产业融合能促进产业结构升级，产业组织优化，而后两者又反作用于产业融合，为物流产业融合的发展创造了条件，三者共同推动物流产业系统的成长。随后，以中国物流上市公司为对象，基于物流产业系统的协同发展模型，测算了中国物流产业各子系统的有序度和复合系统的协同度，结果表明，市场融合、市场拓展水平和技术人员的比率三个序参量的波动导致了融合子系统不能有序发展，影响了物流产业结构升级和组织优化，同时结构和组织

在融合背景下，要促使物流产业系统的协同成长，要为物流产业创造成熟的融合环境和条件，如规制放松为物流产业融合提供了支持，但为了优化市场结构，提高市场集中度，在放松规制同时也要规范市场运行机制，对于规模小、服务水平低、设备落后的物流企业要提高门槛。于物流企业而言，作为物流产业融合的载体和执行者，一方面，通过兼并、重组、联盟和虚拟物流企业等多种形式，整合横向和纵向资源，改变物流企业各自为政现象，提高物流企业的竞争力和市场运行效率。如物流企业与工商企业之间的物流联盟，可以通过市场内部化实现规模经济、范围经济和速度经济的多重效应<sup>[9]</sup>，而物流虚拟企业作为产业内部融合的表现形式，有利于物流企业集中精力发展自己的专业职能和建设优质的客户服务体系，可充分发挥行业协会和政府的作用，推动物流虚拟企业的运作。另一方面，技术作为物流产业融合的催化剂和保障，能改变物流企业的运作模式、推动服务系统的发展和市场竞争格局的转变，物流企业在融合的进程中要充分借助技术的创新促进资源配置的优化和战略的调整，以提高绩效并保持长期竞争优势。
