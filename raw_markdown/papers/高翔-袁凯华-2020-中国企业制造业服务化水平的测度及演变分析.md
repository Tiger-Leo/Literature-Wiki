# 中国企业制造业服务化水平的测度及演变分析

高 翔<sup>1</sup> 袁凯华<sup>2</sup>

(1. 上海对外经贸大学国际经贸学院; 2. 中南财经政法大学经济学院)

研究目标: 解构2000 ～2011 年中国企业制造业服务化水平及动态演变特征研究方法: 通过综合区分中国贸易方式的国家区域间投入产出表 中国工业企业数据库和海关贸易数据库，基于投入产出分析方法和企业贸易增加值核算方法进行测度和分析 研究发现: 加工贸易企业和一般贸易企业的制造业服务化水平分别由2000 年的 0<sub>.</sub> 2932 和 0<sub>.</sub> 2121 上升到 2011 年的 0<sub>.</sub> 3063 和 0<sub>.</sub> 2277，上升幅度不大，但是国内服务要素对于中国企业制造业服务化转型的贡献程度在不断提高 比较来看，加工贸易企业的国内服务化程度低于一般贸易企业，但其国内服务化进程要快于一般贸易企业，呈现明显的 <sup>“</sup>国内服务替代国外服务<sup>”</sup> 的趋势特征 进一步考察不同行业类型 所有制属性和空间区域的异质性因素后发现，劳动密集型企业外资企业和东部地区企业的制造业服务化水平相对较高<sub>。</sub> 研究创新: 首次在考虑贸易方式二元性和企业异质性后从服务要素投入视角对中国企业制造业服务化水平进行准确测度和动态分析 研究价值: 为后续对中国企业制造业服务化水平的影响因素和效应评估研究提供范式借鉴，同时为促进中国制造业转型升级及全球价值链地位攀升提供决策参考

关键词 贸易增加值 制造业服务化 贸易方式二元性 企业异质性 全球价值链

## 引 言

目前，制造业服务化已经成为全球产业发展的重要趋势，通过将生产制造环节向产业价值链 <sup>“</sup>微笑曲线<sup>”</sup> 两端攀升，即向研发 设计 品牌 渠道 服务等方向的跃升，使得服务要素在制造业企业生产投入要素中的占比不断提高，进而大大提升制造业的 <sup>“</sup>含金量<sup>”</sup>从世界各国来看，无论是 <sup>“</sup>美国工业互联网<sup>” “</sup>德国工业4<sub>.</sub>0<sup>”</sup>，还是 <sup>“</sup>中国制造2025<sup>”</sup> 都把制造业服务化视作产业转型升级的关键环节<sub>。</sub> 党的十九大报告更是明确提出构建现代化经济体系，推动先进制造业和现代服务业深度融合的战略目标 然而，同发达国家服务产业结构普遍存在的 <sup>“</sup>两个70% <sup>”</sup> ( 即服务业占 GDP 的70% 生产性服务业占服务业的70%) 现象相比，我国服务业占 GDP 比重尚不足50%，加之服务要素投入缺乏竞争力 生产性服务业发展相对滞后 服务业产业结构不合理等问题，使得总体上我国制造业服务化水平依然较低，进而成为导致中国制造业全球价值链 <sup>“</sup>低端锁定<sup>”</sup> 的重要肇因 因此，如何持续有效提升中国企业的制造业服务化水平，实现中国制造业产业链水平和国际分工地位的提升，成为摆在学术界 政府和产业界面前的重大现实问题和研究热点<sub>。</sub> 这一方面需要对中国企业制造业服务化水平进行准确测度; 另一方面还需要对中国企业制造业服务化水平的变化特征进行动态把握，为探寻促进中国制造业转型升级及全球价值链地位攀升提供决策参考

有鉴于此，本文利用经济合作与发展组织 ( OECD) 公布的 2016 版区分中国贸易方式的国家区域间投入产出表 ( ICIOT，Inter-Countr In ut-Out ut Tables) ，结合中国工业企业数据库和海关贸易数据库，首次在考虑贸易方式二元性和企业异质性后从服务要素投入视角对中国企业的制造业服务化水平进行准确测度和动态分析 相对于已有研究，本文贡献主要体现在两个方面: 第一，本文在构建企业制造业服务化指数的测算框架基础上，首先利用OECD<sub>-</sub>ICIOT 数据测算了2000 <sub>～</sub>2011 年间中国制造业出口中蕴含的增加值和服务增加值，进而利用同时期中国出口企业的增加值率指标作为权重因子进行加权处理，测算了高度细化的企业制造业服务化指数 第二，本文在借助 OECD<sub>-</sub>ICIOT 数据和中国制造业企业数据测算企业制造业服务化指数时，不仅采用贸易增加值核算方法有效规避了传统贸易统计中存在的<sup>“</sup>虚假统计<sup>” “</sup>重复统计<sup>”</sup> 等问题，还综合考虑了服务要素投入的国别来源<sub>、</sub> 贸易方式的二元特征<sub>、</sub> 行业特点<sub>、</sub> 所有制属性<sub>、</sub> 空间区域异质性等重要影响因素，对近年来中国企业的制造业服务化水平及其变化趋势进行了准确的识别和详细的讨论

## 一<sub>、</sub> 文献综述

目前，学界对于如何测度制造业服务化水平进行了大量富有成效的研究，与本文密切相关的研究文献根据使用数据和方法的不同可以被划分为如下三大类<sub>。</sub>

第一类文献主要是基于投入产出分析法中的直接消耗或者完全消耗系数法，通过测算某行业生产单位总产出直接消耗或者完全消耗的各行业服务的数量，利用该行业中服务要素投入占总投入的比例来测度制造业服务化水平 L<sub>a</sub> 等 (2010) 利用投入产出数据测算欧洲制造业行业消耗其他服务行业的系数发现，制造业从以生产制造为主导向以增值服务为主导的制造业服务化进程有助于制造业重构竞争优势 顾乃华和夏杰长 (2010) 基于2007 年中国投入产出数据研究发现，提高制造业服务化水平可以显著提升制造业的增加值率 彭水军和李虹静 (2014) 利用中国1987 ～2007 年间投入产出数据，测算发现中国制造业对生产者服务的直接消耗系数和完全消耗系数均有较大幅度的提高，同时劳动 资本密集型生产性服务正逐渐被人力资本 知识资本密集型生产性服务所替代 刘斌等 (2016) 分析了制造业服务化对于中国企业参与全球价值链的影响，研究结果表明制造业服务化加深了中国企业参与全球价值链的程度，并提升了中国的国际分工地位 许和连等 (2017) 实证分析了全球价值链中制造业服务化对中国企业出口国内增加值率的影响，研究发现制造业服务化与中国企业出口国内增加值率之间呈现显著的 <sup>“</sup>U<sup>”</sup> 形关系 刘维刚和倪红福 ( 2018) 研究发现，制造业服务化虽然在总体上没有提升中国制造业企业技术进步，但是间接和国外服务化却通过创新效应和分工效应显著促进了企业技术进步

第二类文献主要是基于贸易增加值核算方法 ( J<sub>o</sub>hn<sub>so</sub>n 和 N<sub>ogue</sub>r<sub>a</sub>，2012; K<sub>oop</sub>m<sub>a</sub>n 等，2014; 王直等，2015) ，通过区分服务要素投入的国别来源，利用制造业出口中包含的服务要素含量的比例测度一国 ( 地区) 的制造业服务化水平 程大中和陈卓 (2015) 研究发现，中国增加值贸易出口中的服务要素含量趋于上升，但是这主要是由于来自国外的服务要素含量占比的提升，而来自国内的服务要素含量占比不升反降 戴翔 (2016) 利用 WIOD 数据测算发现，服务增加值在中国制造业出口中的占比有逐步提升之势，然而从动态角度看，国内服务增加值的地位有 <sup>“</sup>弱化<sup>”</sup> 迹象，国外服务增加值的地位则有上升趋势<sub>。</sub> 上述研究表明中国制造业服务化过程中存在 <sup>“</sup>国外服务代替国内服务<sup>”</sup> 的变动趋势，这与国内服务业近年来较快的发展势头以及发达国家制造业服务化的经验特征相悖，中国制造业可能存在<sup>“</sup>服务化悖论<sup>”</sup> <sub>。</sub> 国内学者如张月友 (2014) 刘维林 (2015) 从贸易方式二元性视角给出了自己的解释，他们认为，受制于 <sup>“</sup>大进大出 两头在外<sup>”</sup> 的加工贸易模式，中国制造业所需的服务要素投入大量来自国外，导致国内产业关联和循环体系出现 <sup>“</sup>断点<sup>”</sup>，进而阻碍了国内服务业的发展 彭水军等 (2017) 基于MRIO 模型的贸易增加值核算方法发现，考虑中国贸易的二元结构后，尽管中国制造业出口中服务增加值在 1995 <sub>～</sub>2011 年期间的上升幅度很小，但国内服务增加值对于制造业出口增加值创造的重要性正在快速提高<sub>。</sub>

第三类文献主要是基于微观层面的企业制造业服务化水平核算方法，通过计算单个企业的经营性服务收入占企业总收入的比重，利用企业提供服务业务获得的产出在总产出的占比测度微观企业的制造业服务化水平<sub>。</sub> N<sub>ee</sub>l (2008) 基于全球上市公司数据库的研究结果显示，规模越大的企业越倾向于提升自身的制造业服务化水平<sub>。</sub> Fan<sub>g</sub> 等 (2008) 利用美国上市公司数据，研究发现美国上市企业的制造业服务化程度与企业销售总额以及市场价值之间呈现显著的 <sup>“</sup>U<sup>”</sup> 形关系 陈漫和张新国 (2016) 基于中国上市企业数据，检验了两种制造业服务化转型模式对于企业托宾 Q 值的影响，研究发现嵌入式制造业服务化转型能够提升企业绩效，而混入式制造业服务化转型对企业绩效并无明显作用，同时经济周期性对于大 小企业的制造业服务化模式选择具有重要影响 陈丽娴 (2017) 以沪深上市的制造业企业为研究对象，动态考察了不同生命周期阶段下制造业服务化对于企业绩效的差别化影响，研究发现成熟期下制造业服务化和企业绩效呈 <sup>“</sup>U<sup>”</sup> 形关系，成长期下制造业服务化和企业绩效呈反 <sup>“</sup>L<sup>”</sup> 形关系，衰退期下制造业服务化和企业绩效的关系不明显 肖挺(2018) 利用 CSMAR 数据库，研究了制造业服务化与企业绩效的关联性，研究发现制造业服务化企业在企业绩效上并没有比非制造业服务化企业表现出明显优势，反而在短期内更容易陷入 <sup>“</sup>制造业服务化—利润陷阱<sup>”</sup>

梳理文献发现，目前国内外学者对于制造业服务化水平测度的研究正日趋成熟，但是仍然存在以下不足: 第一，对于第一类和第二类文献而言，其主要是基于投入产出模型对于制造业服务化水平进行测度，上述文献往往假设加工贸易和一般贸易拥有相同的生产技术特征，这明显有悖于中国贸易模式的二元性结构 此外，基于投入产出模型的制造业服务化水平测度方法只能从服务投入视角具体到国家—产业层面，未能深入微观企业层面 第二，对于第三类文献而言，尽管基于微观层面的企业制造业服务化水平核算方法可以测算企业制造业服务化水平，但其往往是基于服务产出视角，不能对于服务要素的投入来源进行具体区分 此外，相对于提供制造业企业服务收入指标的国外优质企业数据库 ( 例如全球 OSI-RIS数据库 世界 ORBIS 数据库 法国 BRN 数据库) 而言，目前国内对于企业制造业服务化的研究往往受到指标选择 企业特性 样本容量等因素的限制，亟须在相关领域进行拓展 据此，本文在考虑贸易方式二元性和企业异质性后，从服务要素投入视角对中国企业制造业服务化水平进行了准确测度和动态分析，这大大拓展了研究样本的数量，为后续对于中国企业制造业服务化水平的影响因素和效应评估提供范式借鉴，同时为促进中国制造业转型升级及全球价值链地位攀升提供决策参考<sub>。</sub>

## 二<sub>、</sub> 模型构建<sub>、</sub> 测度框架与数据说明

## 1. 区分贸易方式的投入产出模型

以跨国协作为代表的全球价值链模式已经成为经济全球化与国际分工的新常态 ( B<sub>a</sub>ldw-i<sub>n</sub> 和 L<sub>o ez-</sub>G<sub>onza</sub>l<sub>ez</sub>，2015) 为了客观测度一国制造业出口中蕴含的服务投入，越来越多的研究 ( 程大中与程卓，2015; 戴翔，2016; 彭水军等，2017) 开始借助贸易增加值核算进行制造业服务化转型的研究<sub>。</sub> 不过，受数据所限，已有研究普遍内含 <sup>“</sup>生产同质性<sup>”</sup> 假设( 即 <sup>“</sup>假定进口的中间投入会均等程度地用于生产内销的最终产品和用于出口的最终产品<sup>”</sup>) 虽然这一假定适用于多数国家，却并不适用于加工贸易盛行的中国制造<sub>。</sub> 这是因为，不同于一般贸易，加工贸易生产链条的上游投入与下游市场高度依赖国外<sub>。</sub> 大量研究表明一般贸易和加工贸易在制造业服务化水平 出口国内增加值率 生产链位置上存在较大差别( 彭水军等，2017; 高翔等，2018; 王振国等，2019) 显然，如果单纯地将两种贸易方式等同对待，测算结果将会极大程度地扭曲真实的要素投入来源，致使制造业服务化水平受到一定程度的误判<sub>。</sub> 据此，本文采用区分贸易方式的 2016 版 OECD-ICIOT 数据，利用贸易增加值核算技术方法，建立能够客观测度不同贸易方式部门下制造业服务化转型的框架，以进一步厘清中国制造业服务化转型的特点与不足<sub>。</sub>

与世界投入产出表 ( WIOT) 不同，OECD-ICIOT 首次基于全球生产网络，建立了区分贸易方式的投入产出架构，使得区分贸易方式的价值链研究成为可能 为了便于对比，假定全球仅存在 r 与 c 两个国家<sub>、</sub> 两个生产部门<sub>。</sub> 其中，r 与 c 分别代表外国与中国，部门 1<sub>、</sub> 2分别代表生产部门与服务部门 如果不区分贸易方式，此时的投入产出表将会如同表 1 所示，存在对称的投入产出结构<sub>。</sub> 然而，一旦考虑到中国特殊的二元出口架构，投入产出结构将会变得更为繁杂 ( 如表2 所示) ①<sub>。</sub> 因此，相比表1，表2 不仅更加精确地刻画了不同贸易方式的生产技术特征差异，亦为更加客观的中国制造业服务化测度结果提供了坚实保障

## 2. 国内 ( 外) 增加值率与国内 ( 外) 服务增加值率的测算

## 3. 企业国内 ( 外) 增加值率的测算

目前企业贸易增加值的测算方法已日趋成熟 ( U ward 等，2013; 张杰等，2013; Kee和 Tan<sub>g</sub>，2016) ，考虑到本文研究样本期间为 2000 ～ 2011 年，但 2008 年以后中国工业企业数据库缺少中间要素投入这一关键变量，因而本文主要参照 U<sub>pwa</sub>rd 等 (2013) 的方法测算企业国内增加值率 ( DVAR<sub>\_</sub> FIRM) ，该方法假定企业从事加工贸易活动全部进口中间品，并且进口中间品全部被用于出口，而企业从事一般贸易活动可以进口中间品 资本品和消费品，并且进口中间品既可被用于出口也可被用于内销，用公式表述为:

$$
D V A R _ {-} F I R M = 1 - \left(M _ {P} + \frac {M _ {o}}{X - E _ {P}} \times E _ {o}\right) / E\tag{16}
$$

其中， $M _ { o }$ 和 $M _ { P }$ 表示企业从事一般贸易活动和加工贸易活动对应的进口中间品额， $E _ { o }$ $E _ { P }$ 和 E 表示企业的一般贸易出口额<sub>、</sub> 加工贸易出口额和总出口额，X 表示企业总产出<sub>。</sub> U<sub>p-</sub>ward 等 (2013) 进一步假定企业一般出口和内销拥有相同的进口中间品投入结构，根据<sup>“</sup>同比例假设<sup>”</sup>，式 (16) 可以被改写为:

$$
D V A R _ {-} F I R M = \frac {E _ {P}}{E} \left(1 - \frac {M _ {P}}{E _ {P}}\right) + \frac {E _ {O}}{E} \left(1 - \frac {M _ {O}}{X - E _ {P}}\right)
$$

( 17)

然而上述方法可能会高估企业国内增加值率，为得到更为准确的测算结果，本文从以下几点问题着手进行改进: 第一，标记企业进口产品类型问题<sub>。</sub> 对接联合国广义经济分类标准 ( Broad Economic Catalo<sub>g</sub>ue，BEC) 和海关产品代码 ( HS6 位码) ，识别企业从事一般贸易活动进口的中间品类型，将 $M _ { o }$ 改为 $M _ { o \_ B E C }$ 第二，识别贸易中间商问题 借鉴 Ahn 等 (2011) 的做法，剔除那些企业名称中包含 <sup>“</sup>进出口<sup>” “</sup>贸易<sup>” “</sup>经贸<sup>” “</sup>外经<sup>” “</sup>科贸<sup>”</sup> 字样的贸易中间商企业 第三，处理资本品折旧问题 利用 BEC 产品分类标准，将企业从事一般贸易活动中进口资本品定义为 $K _ { o \_ B E C }$ ，参照单豪杰 (2008) 的研究，将资本折旧率 $\varphi$ 设定为10<sub>.</sub>96% <sub>。</sub> 第四，解决 <sup>“</sup>过度进口<sup>”</sup> 和 <sup>“</sup>过度出口<sup>”</sup> 企业问题<sub>。</sub> 借鉴 Kee 和 Tan ( 2016) 吕越等 ( 2017) 的做法，对 <sup>“</sup>过度进口<sup>”</sup> 和 <sup>“</sup>过度出口<sup>”</sup> 企业样本进行删除处理<sub>。</sub> 第五，考虑 <sup>“</sup>附加值回流<sup>”</sup> 和 <sup>“</sup>重复计算<sup>”</sup> 问题<sub>。</sub> 参照高翔等 ( 2019)公布的回流系数 $( \theta _ { R D V } )$ 和重复计算系数 $( \ : \theta _ { P D C } )$ ，通过关联 WIOD 行业分类和 CIC 行业分类，对测算结果进行调整 在进行上述步骤处理后，企业国内增加值率的测算公式被确定为:

$$
D V A R _ {-} F I R M = \frac {E _ {P}}{E} \left(1 - \frac {M _ {P}}{E _ {P}}\right) + \frac {E _ {O}}{E} \left(1 - \frac {M _ {O - B E C} + \varphi K _ {O - B E C}}{X - E _ {P}}\right) + \theta_ {R D V} - \theta_ {P D C}\tag{18}
$$

最后，考虑到企业国内增加值率和企业国外增加值率是 <sup>“</sup>一枚硬币的两面<sup>”</sup>，本文将企业国外增加值率 ( FVAR<sub>\_</sub> FIRM) 的测算公式定义为:

$$
\begin{array}{r l} F V A R _ {-} F I R M & = 1 - D V A R _ {-} F I R M = 1 - \frac {E _ {P}}{E} \left(1 - \frac {M _ {P}}{E _ {P}}\right) \\ & - \frac {E _ {O}}{E} \left(1 - \frac {M _ {O _ {-} B E C} + \varphi K _ {O _ {-} B E C}}{X - E _ {P}}\right) - \theta_ {R D V} + \theta_ {P D C} \end{array}\tag{19}
$$

## 4. 企业制造业服务化指数的构建与测度

在完成上述指标的准备基础上，本文将企业制造业服务化指数 ( SERVITIZATION) 的测算公式定义为<sup>①</sup>:

$$
\begin{array}{r l} & \underbrace {S E R V I T I Z A T I O N} _ {\text {企业制造业服务化指数}} \\ & = \left( \begin{array}{l} \underbrace {D V A R _ {-} F I R M \times \frac {S D V A R _ {1} ^ {c 2}}{D V A R _ {1} ^ {c 2}}} _ {\text {加工贸易企业制造业国内服务化指数}} + \underbrace {F V A R _ {-} F I R M \times \frac {S F V A R _ {1} ^ {c 2}}{F V A R _ {1} ^ {c 2}}} _ {\text {加工贸易企业制造业国外服务化指数}} (\text {加工贸易企业}) \\ \underbrace {D V A R _ {-} F I R M \times \frac {S D V A R _ {1} ^ {c 3}}{D V A R _ {1} ^ {c 3}}} _ {\text {一般贸易企业制造业国内服务化指数}} + \underbrace {F V A R _ {-} F I R M \times \frac {S F V A R _ {1} ^ {c 3}}{F V A R _ {1} ^ {c 3}}} _ {\text {一般贸易企业制造业国外服务化指数}} (\text {一般贸易企业}) \end{array} \right) \end{array}\tag{20}
$$

对于式 (20) ，有以下几点问题需要说明: 第一，考虑到制造业企业出口中蕴含的服务增加值包含国内和国外两部分，本文按照服务要素投入的国别来源，将企业制造业服务化指数分解为企业制造业国内 ( 外) 服务化指数两部分 第二，构造企业制造业服务化指数时，本文假设同一行业拥有固定的国内 ( 外) 服务要素投入投入结构，但是每个企业具有不同的国内 ( 外) 增值收益能力，进而利用企业国内 ( 外) 增加值率指标作为权重因子，将企业制造业国内 ( 外) 服务化指数加权到企业总体层面的制造业服务化指数<sup>②</sup><sub>。</sub> 第三，鉴于中国制造业出口具有典型的二元结构特征 ( 加工贸易和一般贸易) ，除了考虑不同贸易方式下企业国内 ( 外) 增加值率存在明显差别外<sup>①</sup>，本文还利用 OECD-ICIOT 数据，从行业层面区分了不同贸易方式下制造业服务化转型的贸易结构特征<sub>。</sub>

## 5. 数据说明

为测算中国制造业加工贸易部门和一般贸易部门的国内 ( 外) 增加值率与国内 ( 外)服务增加值率，本文主要使用了经济合作与发展组织 ( OECD) 公布的 2016 版本区分中国贸易方式的国家区域间投入产出表 ( ICIOT) ，2016 版本 OECD-ICIOT 数据提供了 1995 ～2011 年 66 个国家 ( 地区) ( 35 个 OECD 国家<sub>、</sub> 28 个非 OECD 经济体<sub>、</sub> 墨西哥<sub>、</sub> 中国与世界其他地区 ( Rest Of World，ROW) ) 34 个国际标准产业部门 ( ISIC REV. 3) ( 1 个农林牧渔行业 1 个采矿行业 16 个制造行业和16 个服务行业) 的投入产出数据 本文选取 OECD-ICIOT 数据的主要理由在于: 第一，OECD<sub>-</sub>ICIOT 数据的最大优势在于提供了中国制造业( 包括国内销售部门 ( c1) 加工出口部门 ( c2) 一般出口部门 ( c3) 和服务行业 ( c4) 的经济活动信息，这使得本文在测算行业层面的国内 ( 外) 增加值率与国内 ( 外) 服务增加值率时，可以充分考虑到中国贸易方式的二元性特征和服务要素的国别投入来源 第二，最新的 2016 版本 OECD<sub>-</sub>ICIOT 数据拓展了样本期效，从原来的 1995 年 2000 年 2005 年2008 <sub>～</sub>2011 年拓展到1995 <sub>～</sub>2011 年，这为本文从一个长期 动态的视角考察中国制造业的服务化进程提供了研究基础，同时 2016 版本 OECD<sub>-</sub>ICIOT 数据也与同时期的中国微观企业数据有了更好的匹配度 第三，本文也注意到，OECD 已经基于SNA08 ISIC REV<sub>.</sub>4 公布了2005 <sub>～</sub>2015 年的 ICIOT 数据，然而其并未对中国制造业的非加工出口活动进行区分，因而本文无法区分国内销售部门和一般出口部门的制造业服务化进程，同时考虑到其与 2000 <sub>～</sub>2011 年中国工业企业海关贸易合并数据的时间同步性较差，因而本文在研究和测算过程中没有选择 2005 <sub>～</sub> 2015 年的 OECD<sub>-</sub>ICIOT 数据 <sub>。</sub>

为测算企业国内 ( 外) 增加值率，本文主要使用了两套数据: 第一套数据来自国家统计局公布的2000 <sub>～</sub>2011 年中国工业企业数据库 对于工业库的处理，本文首先参照 B<sub>ra</sub>ndt等 (2012) 的 <sup>“</sup>序贯匹配<sup>”</sup> 方法对数据进行清洗，同时借鉴 Feenstra 等 ( 2014) 的做法，对整理的工业企业数据进行了一系列处理，不再赘述 第二套数据来自中国海关总署公布的2000 ～2011 年海关贸易数据库 本文首先将月度数据加总为年度数据，然后将 HS8 位码产品加总到 HS6 位码 为减少企业国内 ( 外) 增加值率测算的误差，本文还需剔除同年海关企业名称重复的企业和贸易中间商企业，根据 U ward 等 (2013) 的方法通过企业名称以及企业所在地邮编和电话等信息对工业企业数据库和海关贸易数据库进行匹配合并<sub>。</sub> 完成初始样本构建后，为减少异常值的影响，本文还采用双边缩尾方法按照 1%的标准对数据进行处理，同时根据研究主题只保留了2000 <sub>～</sub>2011 年一共216796 个制造业企业样本 最后，本文根据表3 所示的经济合作与发展组织 ( OECD) 行业分类与国民经济 ( CIC) 行业分类对照表<sup>②</sup>，将利用国家区域间投入产出表测算得到的行业层面数据与中国工业企业—海关贸易数据进行对接，测度出中国企业的制造业服务化指数，并按照服务要素的投入来源分解为制造业国内服务化指数和制造业国外服务化指数两部分

## 四<sub>、</sub> 主要结论与政策启示

本文利用区分中国贸易方式的国家区域间投入产出表，结合中国工业企业数据库和中国海关贸易数据库，首次在考虑贸易方式二元性和企业异质性后，从服务要素投入视角构造出中国企业制造业服务化指数，对2000 <sub>～</sub>2011 年不同贸易方式下中国企业的制造业服务化水平进行了准确测度和动态分析<sub>。</sub> 本文得到的主要结论有:

第一，测度分析结果表明，加工贸易企业和一般贸易企业的制造业服务化指数分别由2000 年的 0<sub>.</sub> 2932 和 0<sub>.</sub> 2121 上升到 2011 年的 0<sub>.</sub> 3063 和 0<sub>.</sub> 2277，上升幅度不大 这意味着整体上中国制造业服务化水平较为低下和制造业服务化转型进程较为迟滞<sub>。</sub> 从服务要素投入来源看，加工贸易企业的服务增加值主要源自国外服务要素投入，而国内服务要素投入在一般贸易企业服务增加值创造中占据主导地位 从国内外服务要素的相对变动趋势看，加工贸易企业和一般贸易企业中都存在不同程度的 <sup>“</sup>国内服务替代国外服务<sup>”</sup> 的趋势，然而这种趋势在加工贸易企业中表现得较为明显，其国内服务化进程要快于一般贸易企业 上述现象表明国内服务要素对于中国企业制造业服务化转型的贡献程度在不断提高，而加工贸易企业是推动制造业国内服务化进程的主要动力来源

第二，异质性分析结果表明，首先，劳动密集型行业实现了较为快速的国内服务化转型进程 资本密集型行业由于受到 <sup>“</sup>资源诅咒效应<sup>”</sup> 的影响，其国内服务化转型相对落后，呈现 <sup>“</sup>资本密集结构塌陷<sup>”</sup> 的特征 知识密集型行业的国内服务化转型程度最高，然而知识密集型一般贸易企业对于国外服务的依赖程度相对较高，表明国内服务已无法满足其制造业服务化转型要求，对于高端服务的需求只能更多依赖国外进口 其次，本土企业更加偏好使用国内服务，然而外资企业利用国内服务和国外服务的能力相对更强，因而相同贸易方式下外资企业的制造业服务化水平要大于本土企业的制造业服务化水平 最后，东部企业借助地理区位条件和市场竞争优势，统筹使用国内服务和国外服务的能力要强于中西部企业，因而相同贸易方式下东部企业的制造业服务化水平要高于中西部企业的制造业服务化水平

## 根据本文研究结论，可以得到如下政策启示:

第一，推动中国制造业服务化转型，强化制造业与服务业之间的互动融合 本文研究结论表明虽然样本观察期内中国企业的制造业服务化指数有所提升，但制造业服务化转型进程仍然较为迟滞，同时服务增加值在制造业出口增加值创造中的贡献率仍然较低 因此，中国制造业要加快服务化进程，通过产业集聚发展 重点行业引领 大企业带头示范等形式，加快创新设计<sub>、</sub> 管理模式<sub>、</sub> 业务流程<sub>、</sub> 品牌营销等重点环节的转型步伐，推动制造业和服务业的深度融合，提高产业互联程度，不断向产业价值链 <sup>“</sup>微笑曲线<sup>”</sup> 的两端攀移

第二，促进服务业供给侧改革，提升国内服务要素供给质量 本文研究发现，尽管中国制造业存在 <sup>“</sup>国内服务替代国外服务<sup>”</sup> 的趋势，但是仍然存在国内服务对于加工贸易企业服务增加值的贡献率相对较低，知识密集型一般贸易企业对于国外服务的依赖程度相对较高等问题 因此，应该进一步深化国内服务领域的改革开放，大力推动国内服务业发展 同时要强化以人工智能 互联网 大数据 区块链等为代表的新一代信息技术的应用，提升国内服务竞争力，充分发挥国内服务业特别是现代服务业对于制造业的支撑和渗透作用<sub>。</sub>

第三，加快国内市场一体化进程，建设开放统一 竞争有序的市场体系 本文研究结果显示，中国制造业国内服务化进程主要依靠劳动密集型行业带动，而资本密集型和知识密集型行业的服务增加值提升相对依赖国外服务进口，同时本土企业和中西部企业统筹利用国内服务和国外服务的能力相对较弱 因此，要推动国内市场整合，弱化地方政府干预市场的经济激励，消除区域间的要素流动壁垒，减少地方保护主义和行业垄断的消极影响，同时继续扩大开放，逐渐形成贯通国内外的价值链和大市场，助力中国制造业国内服务化转型

第四，重视加工贸易在中国制造业服务化转型中的重要作用 本文研究还发现，加工贸易企业的国内服务化程度低于一般贸易企业，但其国内服务化进程要快于一般贸易企业，呈现明显的 <sup>“</sup>国内服务替代国外服务<sup>”</sup> 的趋势特征<sub>。</sub> 因此，一方面要做好 <sup>“</sup>六稳<sup>” “</sup>六保<sup>”</sup>工作，切实维护好加工贸易既有的外部需求和市场份额，切忌 <sup>“</sup>腾笼换鸟<sup>”</sup> 式的转型升级方式<sub>。</sub> 另一方面，要通过产能改造 技术改良降低产品和服务成本，提高资源配置效率，提升加工贸易企业的制造业服务化水平特别是国内服务化水平

第五，构建国内 国际 <sup>“</sup>双循环<sup>”</sup> 导向的产业政策，充分利用 <sup>“</sup>两个市场<sup>” “</sup>两种资源<sup>”</sup> 目前，中国制造业已经成为发达国家产业链和发展中国家产业链 全球价值链和国内价值链的突出链接环节 <sup>“</sup>双循环<sup>”</sup> 导向的产业政策一方面要坚持 <sup>“</sup>引进来<sup>”</sup> 和 <sup>“</sup>走出去<sup>”</sup> 相结合，充分发挥外商投资和对外投资的技术溢出效应，实现外部高级要素的不断流入和本国产业资本的有序流出; 另一方面要培育国内市场，促进国内消费结构升级，加快全球价值链和国内价值链的衔接和互动，促进中国企业制造业服务化水平的提高和全球价值链地位的攀升
