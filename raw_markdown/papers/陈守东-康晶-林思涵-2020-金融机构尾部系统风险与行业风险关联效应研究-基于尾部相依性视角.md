# 金融机构尾部系统风险与行业风险关联效应研究

——基于尾部相依性视角

陈守东 康 晶 林思涵

［摘 要］本文采用基于极值理论的尾部系统风险测度指标（Tail-<sub>β</sub>），从静态、动态两个角度研究不同类型金融机构尾部系统风险异质性，并分析行业间尾部风险关联效应。研究表明：（1）银行体系中，城商行对于不利冲击反应较为敏感，应对风险能力明显不足。（2）证券部门在极端情形下表现出更强的脆弱性，存在明显的金融风险隐患。（3）部门间尾部风险关联程度随极端金融事件的发生显著上升；其中，银行和保险部门风险关联最强，证券部门与其他部门具有普遍的风险关联效应。（4）房地产部门在股市动荡时期也是金融风险的主要输出者。

# A Research on Correlation of Tail Systematic Risk and Cross-Section Risk in Financial Institutions Based on Tail Dependence Perspective

CHEN Shou-dong KANG Jing LIN Si-han

［Abstract］This paper uses the tail systemic risk measurement index (Tail-<sub>β</sub>) based on extreme value theory to explore the tail systemic risk heterogeneity of different types of financial institutions, from both static and dynamic perspective, and al－ so analyzes the correlation of cross-section tail risks. The results shows that: (1) urban commercial banks are more sensitive to adverse shocks and have insufficient ability to deal with risks; (2) under extreme circumstances, the securities sector is more vulnerable and has obvious financial risks; (3) the correlation degree of tail risk between sectors increases significantly with the occurrence of extreme financial eventsspecificaaly, the banking and insurance sectors have the strongest risk correla－ tion, and there is a general risk correlation effect between the securities sector and other sectors; (4) the real estate sector is also the main exporter of financial risk in the period of stock market turbulence

［Key words］financial institution; systemic risk measurement; extreme value theory; tail systematic risk; correlation effect of risk

## 一、引 言

伴随着中国经济的迅猛发展，金融业规模迅速攀升，不同金融机构提供的金融服务产品趋于同质化，行业间不断增强的关联性为风险的爆发带来更大的隐患。在宏观不利冲击中，个体机构违约会通过“多米诺骨牌”效应使整个金融系统陷入极端风险中，如 2015 年股市异常波动时期，上证指数从峰值的 6 124.04 点大幅度下滑，对实体经济造成的影响至今仍未消散。极端金融事件虽然发生概率较小，但具有传播速度快、幅度大和范围广等特点，往往牵一发而动全身，其引发的金融风险不仅会对实体经济造成巨大的负外部性，还会通过行业间密切的业务往来传播至整个金融体系，进而引发系统性风险。探究极端事件发生时期微观个体金融机构的尾部系统风险，有助于监管机构更加有效地监控和防范风险爆发与传染。

当金融市场处于极端情形时，单个资产与市场往往出现大幅的同涨同跌现象，由此产生了尾部系统风险（systematic tail risk）概念，它表示资产价格随市场暴涨暴跌的概率，或单个资产和市场收益之间的相关性（李志生等，2019）。近年来，关于极端情形下的尾部系统风险测度与实证研究也取得了积极进展。Kelly 和Jiang（2014）利用动态幂率构建了一种时变尾部风险度量方法，以研究极端事件对资本市场的影响，发现尾部风险对市场收益具有较强的预测能力。Balla 等（2014）研究了美国大型存款机构资产收益损失间的极值相关性，发现基于尾部依赖的系统风险指标能够很好地跟踪金融稳定和动荡期。Van 和 Zhou（2016）基于极值理论度量了资产价格对于极端市场风险的敏感程度，发现尾部系统风险高的资产遭受损失更大。Chabi-Yo等（2016）通过以 Copula 为基础的尾部依赖指数，捕捉市场处于低迷条件下，股票对市场波动的依赖度。Straetmans 和 Chaudhry（2015）基于极值理论构建尾部系统风险测度指标，对美国和欧元区银行的尾部依赖性进行比较发现，无论如何设定样本期，美国的尾部系统风险均高于欧元区。

近年来，国内学者也借鉴国际流行的风险度量方法，从不同角度对极端情形中的风险度量进行了研究。大体分为三类：其一，基于基础尾部度量指标（VaR、ES）的改进，谢尚宇等（2014）利用 ARCH- Expectile 方法测度民生银行股票损益的VaR 和 ES 尾部风险。陈声利等（2018）结合极值理论和高频波动率，构建RV-EVT尾部风险测量方法，得出 ES 比 VaR 具有更优的尾部风险测度水平。李政等（2019）利用 CoES 指标，同时对中国金融部门左、右尾的系统风险溢出进行测度，发现金融部门具有显著的系统风险溢出效应。其二，基于极值理论或 Copula 函数度量尾部相依性。赵宁等（2019）通过美国和中国的金融指数，研究了中美两国金融机构系统风险的右尾极值扩散过程。陈守东等（2016）利用二元 POT 极值模型考察了货币市场与资本市场的尾部相依性。李志生等（2019）基于 SJC Copula 函数度量股票价格的尾部系统风险，并研究了“国家队”持股对风险的影响。其三，捕捉金融风险的网络效应和跨行业传染特征，构建金融机构尾部风险网络。蒋海和张锦意（2018）利用 LASSO 算法和分位数回归研究了上市银行尾部风险网络的关联特征。杨文华等（2019）使用改进的 Lasso-Expectile 模型构建金融机构的尾部关联网络，测度了行业系统风险。

纵观国内现有尾部系统风险测度文献，大都关注银行系统内风险（刘志洋，2018），或基于行业指数、股票收益率分析不同金融市场的尾部相依性、尾部风险网络，对于尾部风险的研究很少考虑金融机构的系统性，更少有文献基于极值理论从尾部风险角度度量个体金融机构的系统性风险。而在微观机构系统性风险边际贡献方面，边际预期损失 MES、长期边际预期损失 LRMES、增量条件在险价值 ΔCoVaR 被国内外学者广泛运用（Brownlessand Engle，2010；Adrian and Brunnermeier，2016；Acharya，et al.，2017；Benoit，et al.，2017；陈湘鹏，2019）。其中，MES为市场大幅下跌时，个体机构收益率的期望损失，考察单个机构对系统金融风险的贡献程度；LRMES 指长期内整个系统收益率下跌幅度超过 40%时，单个机构股权价值的预期损失；ΔCoVaR关注个体机构在危机时期对系统风险的边际贡献。但较高的 MES、LRMES 并不意味着极端事件的发生，未关注各个微观金融机构个体的尾部事件。基于分位数回归的 ΔCoVaR 一般刻画的是线性结构，对于非线性结构的刻画存在一定缺陷。极端事件或尾部风险对于监管机构制定宏观审慎政策具有不可忽视的重要作用，而基于极端事件有效测度和监控金融机构尾部系统风险有助于防控金融风险的爆发与传染。鉴于此，本文借鉴 Straetmans 等（2015）提出的 Tail- 模型，从个股与市场尾部风险关联的视角出发，度量金融机构的尾部系统风险，即单个资产随市场暴跌的条件概率，并在此基础上探究极端金融事件发生时期金融行业间的尾部风险关联效应。

基于极值理论的尾部条件相依性能够很好地刻画金融资产间的非线性相依结构，不仅可以反映资产与市场之间的尾部相依结构，还可以测度不同行业间的尾部风险有向关联，探究出易受其他行业极端异常波动冲击陷入困境的机构。因此，本文通过将单变量和多变量极值理论（Extreme Value Theory，ETV）应用于金融机构资产收益的尾部，首先测算预期损失 ES 指标来度量尾部风险，进而采用 Tail- 指标识别不同类型金融机构的尾部系统风险，以估计个体金融机构在极端情形下随市场异常波动的概率；其次，从静、动两个角度探究银行、证券、保险、房地产部门的不同尾部系统风险程度与时间异质性；第三，基于 $\mathrm { T a i l - \beta }$ 指标分析部门间的有向风险关联效应，探索极易受其他行业极端异常波动影响的机构，并利用滚动估计探究部门间风险关联动态；最后与当前在科研以及实务中广泛使用的系统风险指标 ES、MES、ΔCoVaR 进行对比分析，以验证其有效性与预警作用。该方法既能从整体上测度各金融机构的尾部系统性风险，又考察了两两金融行业间的有向风险关联效应，丰富了系统风险分析工具箱及微观层面金融机构系统风险研究，且为维护极端事件发生时的风险治理提供了相应的政策建议。

本文余下部分安排如下：第二部分介绍尾部系统风险指标的构建与估计；第三部分为中国金融机构尾部系统风险异质性实证分析；第四部分为基于 $\mathrm { T a i l } { - \beta }$ 指标的行业间尾部风险关联效应研究；第五部分为稳健性检验；第六部分为结论与政策建议。

## 二、尾部系统风险指标构建与估计

传统研究中金融资产收益服从正态分布，而近年来的大量实证研究表明，资产收益呈现厚尾特征，非正态分布的尾部风险可以更准确地刻画极端金融事件发生的概率。因此，我们首先介绍极值理论在金融机构资产数据上的相近刻画，进而引入单变量尾部指标 ES 以确定金融机构收益损失尾部风险，随后构建反映个体金融机构资产收益和市场收益极值相关性的尾部系统风险指标 $\mathrm { T a i l - \beta }$

## （一）极值理论与厚尾分布

极值理论是研究分布尾部行为的重要工具，近年来，研究学者将极值理论应用到金融学中，能够处理数据厚尾现象，预测市场的极端波动，是测量在极端市场条件下风险损失的一种统计方法。从统计学上看，极值是指某一时期随机过程中的最大或最小值，通常分布在金融数据的尾部，主要研究极值的分布及其特征。

定义同分布的随机变量序列： $X _ { 1 } , X _ { 2 } , \cdots X _ { n }$ ，而 $X _ { n , 1 } ^ { ( i ) } \leqslant \cdots \leqslant X _ { n , n - m } ^ { ( i ) } \leqslant \cdots \leqslant X _ { n , n } ^ { ( i ) }$ 为随机变量的升序统计量， $X _ { t }$ 服从分布函数 $F ( x )$ ，令 $M _ { n } { \mathrm { = } } \operatorname* { m a x } \{ X _ { 1 } , X _ { 2 } , \cdots X _ { n } \} \ , m _ { n } { \mathrm { = } } \operatorname* { m a x } \{ X _ { 1 } , X _ { 2 } , \cdots X _ { n } \}$ 分别为 个随机变量的最大、最小值，那么：

$$
P \left(M _ {n} \leqslant x\right) = P \left(X _ {1} \leqslant x, \dots X _ {n} \leqslant x\right) = F ^ {n} (x), x \in R\tag{1}
$$

$$
P (m _ {n} \leqslant x) = 1 - P (x \leqslant m _ {n}) = 1 - [ 1 - F ^ {n} (x) ] ^ {n}, x \in R\tag{2}
$$

如果存在数列 $a _ { n } { > } 0$ 和 $b _ { n }$ ，使得：

$$
\lim _ {n \rightarrow \infty} p \left(\frac {X _ {n , n} ^ {(i)} - b _ {n}}{a _ {n}} \leqslant x\right) = G (x, \xi)\tag{3}
$$

$G ( x , \xi )$ 为一个非退化的分布函数，参数 $\xi$ 为极值指数，表示极端事件发生的概率，刻画X 尾部的形状，记 ${ \xi } \mathrm { = } 1 / \alpha _ { \circ }$ 。则标准化的极限分布有三种形式，本文采用极值分布中的 Frechet 分布，对于金融资产收益率尖峰厚尾特性，具有最相近的刻画，其 CDF 为：

$$
G (x; \xi) = \left\{ \begin{array}{l l} 1 - \exp \big [ - (1 + \xi x) ^ {1 / \xi} \big ] & x <   - 1 / \xi \\ 0 & x \geqslant - 1 / \xi \end{array} \right.\tag{4}
$$

当 $\xi > 0$ 时， $F ( x )$ 属于极值分布中的Frechet分布，记作 $F ( x ) \in M D A \left( \Phi _ { \alpha } \right) , \Phi _ { \alpha } { = } \exp ( - x ^ { - \alpha } ) , x { > } 0 , \alpha { > } 0 _ { \circ }$ 。当 $x ^ { \longrightarrow \infty }$ 时：

$$
\bar {F} (x) = 1 - F (x) = x ^ {- \alpha} L (x)\tag{5}
$$

$L ( x )$ 是慢变化函数，满足 $\operatorname* { l i m } _ { t  \infty } L ^ { ( } t x ) / L ^ { ( } t ) = 1 , x { > } 0 , c$ 为其尾部指数。而近几年来实证文献表明金融数据呈现尖峰厚尾特征，厚尾发生极端事件的概率要比正态分布更高，具有更精准有效的估计能力。

## （二）单变量尾部风险度量与估计

基于极值理论对于金融资产尾部的刻画，为金融机构定义极端下行风险测度。令 $S _ { t }$ 代表金融机构股价，$\mathrm { X } { = } { - } \mathrm { l n } \big ( S _ { t } / S _ { t - 1 } \big )$ 即为负对数收益损失，由 Mandelbrot（1963）对厚尾分布的研究表明，如果想要对金融危机，机构倒闭等极端事件进行概率估计，X 的边际尾部概率可以近似地由下式描述：

$$
P \{X > x \} = 1 - F (x) \sim a x ^ {- \alpha}, x \longrightarrow \infty\tag{6}
$$

其中 $\alpha { > } 0$ ，且 $0 < \alpha < \infty \mathrm { ~ , ~ } \alpha$ 为尾部衰减发生的速率，也称为尾部指数，较高的 $\alpha$ 意味着尾部较快的衰减为零。显然，（6）式中的尾部概率 $p$ 是针对损失序列给定分位数<sub>x</sub> 得到的，求解尾部分位数 $x _ { p }$ $x _ { p }$ 作为 $p$ 的函数：

$$
x _ {p} \sim (\frac {p}{a}) ^ {- 1 / \alpha}\tag{7}
$$

则在 EVT 框架内，期望损失 ES 与 VaR 呈线性关系，表示为：

$$
E \left(X - x _ {p} \mid X > x _ {p}\right) = \frac {x _ {p}}{\alpha - 1}\tag{8}
$$

条件期望损失表示在极端情形下，收益超出阈值的严重程度。在机构股本方面，它反映了损失一旦超过一个临界门槛，股票资本预计出现的下降。极值理论框架下的期望损失较传统期望损失更多关注尾部风险，可以测算出个体机构的极端状况。

为避免对金融资产收益进行过于严格的分布假设，我们引入极端下行风险的半参数估计。定义收益损失如下： $\cdot X _ { t } , t { = } 1 , \cdots , n$ ，其中 $X _ { n , 1 } ^ { ( i ) } \leqslant \cdots \leqslant X _ { n , n - m } ^ { ( i ) } \leqslant \cdots \leqslant X _ { n , n } ^ { ( i ) }$ 表示在收益损失样本上定义的升序统计量， $X _ { n - m , n } ^ { ( \textit { i } ) }$ 是股票 i 的负对数收益的第 $m { + } 1$ 个次序统计量， $m$ 为估计中使用的极端值数，因此可以将尾部概率（6）式估计为：

$$
P (X > x) = \frac {m}{n} \left(X _ {n - m, n}\right) ^ {\alpha} x ^ {- \alpha}\tag{9}
$$

为此，我们实现了 Haan 等（1994）的半参数分位数估计：

$$
x p \simeq X _ {n - m, n} \left(\frac {m}{n p}\right) ^ {1 / \alpha}\tag{10}
$$

分位数估计（10）式仍然需要估计尾部指数 $\alpha _ { \mathrm { o } }$ 。根据大量关于非正态、极端事件的实证研究，我们用流行的 Hill（Hill and Bruce，1975）统计量估计尾部指数：

$$
\hat {\alpha} _ {i} = \left[ \frac {1}{m} \sum_ {j = 0} ^ {m - 1} \ln \left(\frac {X _ {n , n - j + 1} ^ {(i)}}{X _ {n , n - m} ^ {(i)}}\right) \right] ^ {- 1}\tag{11}
$$

其中 $n$ 为观察到的收益个数，通过在预期损失的定义中嵌入 Hill 统计量和分位数估计量，可以很容易地得到预期损失 ES 的估计量：

$$
\hat {E} (X - \hat {x} _ {p} | X > \hat {x} _ {p}) = \frac {\hat {x} _ {p}}{\hat {\alpha} - 1}\tag{12}
$$

Hill 统计量及其伴随的分位数和预期损失估计值仍然取决于选择参数的值，通过最小化 Hill 统计量的渐近均方误差（AMSE）（Danielsson，et al.，2001）选择该阈值。至此，我们得到单变量尾部风险测度 ES。

## （三）尾部系统风险指标 T<sub>a</sub>il-<sub>β</sub> 估计

为衡量极端情况下各金融机构资产收益与市场收益之间的联动性，我们定义 Tail- 指标，度量单个资产随市场暴跌的条件概率，即统计意义上市场收益损失超出阈值条件下的单个资产收益损失处于极端值的概率，以反映在市场总体压力时期，单个资产损失与市场损失的相依性。

假设 $X _ { 1 \setminus X _ { M } }$ 分别为单个资产价格、市场投资组合的对数收益损失。为研究联合损失，我们选择尾部分位数 $Q _ { 1 }$ 和 $Q _ { M } ,$ ，使两个随机变量具有相同的尾部概率即 $P \{ X _ { 1 } > Q _ { 1 } ( p ) \} = P \{ X _ { M } > Q _ { M } ( p ) \} = p$ 。在一个共同的显著性水平 $p$ 值下，将尾部系统风险指标 Tail-<sub>β</sub> 表示为：

$$
\tau_ {\beta} \equiv P \left\{X _ {1} > Q _ {1} (p) \mid X _ {M} > Q _ {M} (p) \right\} = \frac {P \left\{X _ {1} > Q _ {1} (p) , X _ {M} > Q _ {M} (p) \right\}}{P \left\{X _ {M} > Q _ {M} (p) \right\}} = \frac {P \left\{X _ {1} > Q _ {1} (p) , X _ {M} > Q _ {M} (p) \right\}}{p}\tag{13}
$$

该指标反映了存在极端负面市场冲击时，个别资产大幅下跌的可能性。概率测度 $\tau _ { \beta }$ 即 Tail-<sub>β</sub> 反映了当两个变量共同超过危机阈值 $Q _ { 1 }$ 和 $Q _ { M }$ 时，损失 $X _ { 1 }$ 和 $X _ { M }$ 的相互依赖程度。在完全统计独立性下， $\tau _ { \beta }$ 降为 $p$ ，作为极端系统风险的下界。Tail-<sub>β</sub> 将个别股票收益变动与市场投资组合变动联系起来，估计了联合分布的尾部概率。

估计（13）式中的Tail-<sub>β</sub>，主要计算分子中的联合概率，为避免对边际收益分布及其（尾部）依赖结构做出非常具体的分布假设，我们选择半参数方法 （Poon，et al.，2004；Hartmann，et al.，2006；Straetmans，et al.，2008），对原始收益率序列进行转换，使其呈现相同的边际分布，消除边际方面对联合尾部概率的可能影响，联合尾部概率的差异仅仅归因于尾部依赖结构的差异，因此，将单个资产损失变量转换为单位帕累托边际（Draisma，et al.，2004）：

$$
\widetilde {X} _ {i} = \frac {1}{1 - F _ {i} (X _ {i})}, i = 1, 2\tag{14}
$$

$F _ { i } ( \cdot )$ 表示 $X _ { i }$ 的边际累积分布函数，我们用它们的经验分布代替，即对于每一个 $X _ { i }$ ：

$$
\widetilde {X} _ {i} = \frac {1}{1 - R _ {X _ {i}} / (n + 1)}, i = 1, 2\tag{15}
$$

其中 $R _ { X _ { i } } { = } r a n k ( X _ { i l } , l { = } 1 , \cdots , n )$ 为时间序列中观察到的股票收益 i 的等级。应用此单位帕累托边际变换，可以将（13）式中分子的二元分布归结为：

$$
P \left\{X _ {1} > Q _ {1} (p), X _ {M} > Q _ {M} (p) \right\} = P \left\{\widetilde {X} _ {1} > s, \widetilde {X} _ {M} > s \right\}\tag{16}
$$

其中对于大样本， $s { = } 1 / p$ ，（Hartmann，et al.，2006），因此，通过考虑变换后两个收益序列横截面的最小值，公共分位数能将双变量概率的估计化简到单变量的概率估计。

$$
P \{\widetilde {X} _ {1} > s, \widetilde {X} _ {M} > s \} = P \{\min (\widetilde {X} _ {1}, \widetilde {X} _ {2}) > s \} = P \{Z _ {\min} > s \}\tag{17}
$$

其中辅助变量 $Z _ { \mathrm { m i n } } \equiv _ { \mathrm { m i n } } ( \widetilde { X } _ { 1 } , \widetilde { X } _ { 2 } )$ ，辅助变量的尾部具有原始金融机构收益的厚尾属性：

$$
P \{Z _ {\min} > s \} \approx a s ^ {- \alpha}, \alpha \geqslant 1\tag{18}
$$

因此联合概率的估计可以映射到单变量估计问题：

$$
\hat {p} = \frac {m}{n} \left(Z _ {n - m, n}\right) ^ {\alpha} s ^ {- \alpha}\tag{19}
$$

通过将（19）式除以 ，容易得出（13）式中的共同超越概率 $p$ $\tau _ { \beta }$ 的估计量：

$$
\tau_ {\beta} = \frac {p _ {s}}{p} = \frac {m}{n} \left(Z _ {n - m, n}\right) ^ {\alpha} s ^ {1 - \alpha}\tag{20}
$$

很明显，尾部指数 $\alpha$ 在尾部 $\beta$ 的估计中起双重作用：它驱动辅助变量 Z的尾部厚度和原始收益对 $( X _ { 1 }$ $X _ { 2 } )$ 的尾部依赖程度，由以上程序最终得到 $\mathrm { T a i l - \beta }$ 的估计结果。

## 三、金融机构尾部系统风险异质性实证分析

## （一）数据

由于各金融机构上市时间具有差异性，仅少数几家大型金融机构 2010 年后上市，因此从数据长度的角度考虑，本文选取了截至 2010 年 10 月已上市的 35 家金融机构，其中银行机构 16 家，证券机构 16 家，保险机构 3 家<sup>①</sup>。房地产部门作为典型的资金密集型行业，其产品具有抵押品和投资品的双重属性，与金融行业密切相关，其价格波动的潜在风险会对金融体系稳定造成巨大冲击（陈湘鹏等，2019；杨子晖等，2018）。考虑到房地产行业的类金融属性，本文选取 15 家房地产机构<sup>②</sup>纳入我们的研究样本。样本区间为 2010 年 10 月至 2019 年 7 月，涵盖 2015 年中国股市异常波动，此次波动与之前的多次大跌不同，其传播速度快，范围广，影响程度深，表现出极强的尾部系统风险。因此，为明晰此次异常波动前后金融风险的动态演化，我们将样本区间划分为三个子样本：2010 年 10 月至 2015 年 6 月 11 日为危机前样本、2015 年 6 月 12 日至 2017 年5 月 12 日为危机时样本、2017 年 5 月 13 日至 2019 年 7 月为危机后样本。最后选取沪深 300 指数收益率代表市场收益率，数据来源于 Wind 数据库。

表1 给出了各行业风险指标在各样本区间内的均值、中位数和标准差。由表 1 可知，危机前尾部指数均值多处于 2\~3 之间，而在危机时刻基本下降到 2 以下，厚尾特征越发显著，尾部风险增加；尾部分位数在股市动荡时期均上涨至危机前的2 倍左右，危机阈值显著增加，个体金融机构遭受更大损失。观察一致风险度量指标 ES 的估计结果可以发现，动荡前证券部门 ES 值为 15.01，略高于其他三个行业，尾部风险较高，而在危机时期所有行业尾部风险大幅度增加，保险和证券部门均表现出更强的尾部风险，ES 值分别大幅攀升至 76.94、74.83，表明在危机期间金融机构收益损失处于尾部的概率大幅增加，预计的资本下跌概率显著上升，凸显出极端事件给机构带来的巨大尾部风险。而观察危机后样本，相较于危机时期样本，尾部指数 上升，尾部分位数 $q$ 、期望损失 ES 均大幅下降，证券部门尾部风险（ES）依然最高。

不同类型金融机构危机期间 Tail- 值也存在明显的异质性，危机前银行、证券和保险机构行业均值相差不大，危机时期均大幅攀升，表明在股市异常波动时期，个体金融机构和市场收益率的尾部依赖性显著增强。而证券部门 Tail- 值由 27.05 上涨为 71.77，说明相比银行和保险部门，证券行业更容易受到市场股市异常波动等宏观不利冲击的影响，抗风险能力较弱。证券行业是资本市场的主体结构，且随着行业的发展，金融衍生产品增多，行业内部易发生较强的传导效应，极易受到市场行情与监管政策的影响。而房地产机构危机前Tail- 均值仅为9.36，远低于三个金融行业，危机时期却上涨到 40.54，在股市异常波动时期，房地产机构与市场收益的尾部联动性逐渐显现出来，亦表现出一定的脆弱性。而对于危机后样本，相较于危机时期，四类机构 Tail-<sub>β</sub> 值均大幅下降，其中，证券、保险部门表现出相对较高的尾部系统风险水平。

次危机中占据风险的主导地位，究其本源，金融体系形成的由资产负债表相互关联的网络，使得整个银行业呈现出休戚相关的密切关联特征，钱荒事件的冲击令银行外部性成本无法彻底的内部化，各类银行被迫承担风险，形成了风险传播的网络效应。而在 2015 年 6 月股市异常波动时期，各行业的 Tail-<sub>β</sub> 指标更急剧攀升，达到历史峰值，银行、证券、保险行业均在此次危机中表现出更高的尾部系统风险，此次股灾与之前的多次局部金融市场大跌不同，整个金融系统表现出巨大的系统风险。其中，证券行业尾部系统风险攀升幅度最大，并持续成为四个行业中风险较高的部门。危机时期，证券行业存在明显的金融风险隐患，股灾的极端金融事件对证券部门的冲击更易使其与市场共同暴跌。其次，保险行业在股市大幅动荡时期亦表现出明显的尾部风险，仅次于证券部门。中国保险行业虽然发展历史较短，但产品创新及其与资本市场的融合度不断攀升，其投资业绩易受整个资本市场环境的冲击，近年来的风险隐患日益凸显。房地产行业尾部系统风险相对其他三部门较低，但由于与其他金融机构的深度融合，亦使其对极端金融冲击表现出较高的敏感性。此后，各行业尾部系统风险开始逐渐走低，并呈现平缓收敛的态势，于 2019 年有小幅度回升。

## 四、行业间尾部风险关联效应研究

## （一）静态行业尾部风险关联水平

随着中国金融开放水平不断提高及金融科技快速发展，银行、证券、保险等金融机构加速融合渗透，交叉性金融业务和产品不断推出，也加剧了风险的跨部门、跨市场传染，探究不同行业间的风险关联程度具有一定现实意义。而随着金融机构与其他行业的混营发展，房地产部门与金融部门之间的风险传导效应也在不断增强，对其尾部风险关联效应展开深入研究也十分必要（杨子晖，2018）。因此，本文选取申银万国二级行业指数的银行、证券、保险、房地产行业指数作为分部门的代理变量，定义此时的 Tail- 值为各行业机构资产随其他行业指数暴跌的条件概率<sup>①</sup>，以反映两两部门间的尾部风险关联水平，样本区间划分与指标估计方法同上文。表 3 给出了不同样本区间内各行业指数条件下的部门 Tail-<sub>β</sub> 均值。

房地产行业中金融街、保利集团、雅戈尔地产均进入四个部门尾部风险关联水平的前列，与金融机构的深入融合最高。房地产是企业部门中影响力最大、与其他行业关联度最高的行业，在金融稳定中扮演重要角色，一旦房地产市场泡沫破裂，借贷的巨额资金无法偿还，关联企业的经营效益和偿债能力也受到严重冲击，风险间接向金融部门传导，反过来又形成了向房地产行业传导的恶性循环态势。因此，对于房地产行业

重点机构的风险监控，有助于及时切断风险传播来源。

具体比较行业间影响可知，证券部门对保险和银行部门的 Tail- 值均较高，在危机时期对于房地产的冲击也略高于其他两部门对房地产的影响，是风险传染的主要来源。银行和保险部门在股灾时期行业关联度最深，近些年两部门业务来往密切，交叉业务监管不足，职责模糊，而保险公司销售产品的重要渠道便是通过银行代销，两部门业务合作密切，一旦发生违规违约行为，出现重大问题或破产时，客户不仅会对保险公司进行索赔，同时会对代理银行有挤兑行为，导致风险在两部门间传播。房地产部门在危机前对三个金融部门的尾部风险影响基本没有差别，而动荡时期对证券行业的影响开始凸显。自中国住房管理体制市场化改革以来，面对严格的房地产调控政策，现行房地产行业经营模式、融资方式都发生较大变化，银行信贷等融资方式严重受限。而随着房地产资产证券化，其与证券市场的联动性提升，银行在信贷业务方面承担的风险被分散，房地产资产证券化成为一种新的融资渠道。且房地产行业总市值较大，价格波动一定程度上牵动股市的变化趋势，股票市场的整体趋势又必然会影响到证券行业股票价格，进而凸显出对证券行业的风险传递。除此之外，危机时期房地产部门对于银行、保险部门的 Tail- 值相对低于金融部门两两间的影响力，但危机时期其对金融行业的风险传导也不可忽视。综上分析，风险一般在经济繁荣时期积累扩大，而当经济下行时期，某些机构的损失通过资产负债表传导至其他金融机构，羊群效应放大了系统中个体的关联性，风险便通过资产负债表、投资者恐慌情绪传染扩散开来。日益增强的金融机构关联性为风险的扩散提供了“温床”，使得危机累积阶段看似稳健的金融机构在危机时期风险状况突升。

## 五、稳健性检验

当前在度量微观机构系统性风险边际贡献方面，边际损失预期 MES、长期边际预期损失 LRMES、增量条件在险价值 ΔCoVaR 被国内外学者广泛运用（Brownless and Engle，2010；Brunnermeier，2016；Acharya，et al.，2017；Benoit，et al.，2017；陈湘鹏，2019）。为进一步验证 Tail- 指标的稳健性，本文将其与上述三种系统风险度量指标进行比较分析。首先在原有数据基础上增加各机构的市值以及季度资产负债表数据得到 MES、LRMES 和 ΔCoVaR 估计结果，然后通过各样本期间 Tail- 的风险排序与上述指标排序的斯皮尔曼等级相关性，来检验指标构建对于中国金融机构风险度量的适用性，具体系数结果如表 5 所示。由表可知，基于Tail- 指标的风险排序与 MES、LRMES、ΔCoVaR 风险排序在各样本期均具有显著的相关性，该结果表明Tail- 指标在测度系统风险方面与其他风险指标较为一致，是可信赖的系统风险度量指标。

## 六、结 论

本文基于极值理论，通过半参数估计得到预期损失（ES）和尾部系统风险（Tail- ）指标，测度银行、证券、保险、房地产部门不同样本区间内的风险异质性，并与国际认可程度较高的几类风险指标对比，得到如下结论：（1）在极端事件冲击下，金融机构会产生巨大的尾部风险，危机期间，所有行业尾部风险（ES）均大幅度增加、厚尾特征显著，其中，保险和证券部门表现出更强的尾部风险。（2）银行总体在应对极端事件冲击时具有一定的稳定性，抵御风险能力较强。但因银行体系组织架构庞大，类型众多，部分银行仍对冲击表现出较高的敏感性，其中，城市商业银行危机前、危机时系统风险指标增幅较高，应对风险能力最弱。（3）证券部门在极端情形下，更易受到股市异常波动等宏观不利冲击的影响，较其他行业表现出更强的脆弱性，存在着较明显的金融风险隐患，是系统金融风险的最重要来源。（4）部门间风险关联均随极端金融事件的发生明显上升，且存在不对称性；证券部门对于其他行业尾部风险影响均较高，是风险传染的主要来源；银行和保险部门行业关联度最深；房地产部门危机期间也成为金融系统风险的主要输出者。（5）各部门中南京银行、宁波银行、招商证券、光大证券、广发证券、中国平安、金融街、保利集团、雅戈尔等机构与其他行业关联度高，极易受其他行业极端异常波动的冲击而陷入困境，值得重点关注。（6）通过与国际较认可的MES、LRMES、ΔCoVaR 系统风险度量指标对比分析，证实了 Tail-<sub>β</sub> 指标的有效性，并且相比以上指标对于证券、保险和房地产部门具有更好的预警作用。

鉴于以上结论，本文提出以下几点建议：（1）从风险抵抗的脆弱性角度来看，在银行业方面，中国系统金融风险主要源于城市商业银行，这类银行经营机制较灵活、鼓励金融创新，但它们应对金融风险的能力不足，极易受到极端事件冲击，引发系统金融风险，因此在督促其加强内部控制，规范业务经营的同时，应加强对城市商业银行的监管，以防范风险于未然。（2）对于证券部门，防范重点应当在于提高其经营的稳定性，有效降低部门脆弱性，尤其关注重点机构的抗风险冲击能力。在风险爆发阶段，严格监控信息披露来降低信息不对称，稳定投资者情绪，避免羊群效应等大范围风险传染。健全风险监测预警和早期干预机制，尽量避免大规模的风险外溢，及时阻断风险跨机构、跨行业传导。（3）由于银行与保险业在资产结构、投资组合、交叉业务等多方面具有相似性，近年来越发加强的行业关联性导致二者共同暴露程度加深。因此有针对性地加强对银行、保险个体机构的监控，可以有效地控制银行与保险个体的风险程度，及时切断系统风险的来源。（4）行业间关联水平呈现周期性变化，在危机时期通过直接、间接等渠道由单一部门传染至各个部门，进而引发整个金融系统风险水平的大幅上升，因此。监管机构应有效降低跨机构、跨行业的风险累积程度，把握好防范化解风险的时机，完善周期性监管机制。
