# 数据要素参与价值创造的途径——基于广义价值论的一般均衡分析

蔡继明 刘 媛 高 宏 陈 臣

摘要：数据要素具有虚拟性、非竞争性、非排他性（或部分排他性）、规模报酬递增、正外部性等特征，是经济增长和价值创造的重要源泉。本文基于广义价值论，建立了纳入数据要素的一般均衡分析框架。本文认为，数据要素可以通过数据的初始存量、前期收集处理数据所投入的劳动以及当期在收集处理数据所投入的劳动等 种途径提高绝对生产力，进而通过综合生产力和比较生产力的提升引起价值量的增加。由此表明数据自身、前期物化在数据收集处理中的劳动以及当期用于数据收集处理的活劳动均参与价值创造。同时，数据要素的正外部性特征还能够推动综合生产力提升，并进一步增强消费—生产者的比较优势。

数据要素是数字经济的微观基础和创新引擎，但关于数据要素价值基础的研究在国内外均是一个全新课题。一方面，关于数据能否创造价值，在理论上仍有不少人持怀疑甚至否定态度。澄清这一问题，关键在于揭示非劳动要素或劳动生产力的提高在价值总量形成过程中的作用，从而把握现实中经济增长背后的驱动因素。另一方面，囿于理论层面的研究缺乏，数据要素在实践层面的界权、核算均面临较大挑战。从微观角度看，数据权属界定不清已成为数据要素市场化配置的最大制度障碍之一。由于数据的全生命周期包含多个参与者各生产环节的边界难以清晰界定 且权利内容往往随着应用场景的变化而变化造成数据权属模糊(用杰棠、刘露瑶， ；熊巧琴、汤珂， ），并进一步导致数据要素定价困难，以及数据要素市场发展受阻、交易机制不完善和资源难以高效配置（曾铮、王磊， ；王明姬， ）。从宏观角度看，数据要素的价值理论研究不足也给国民经济核算带来了挑战。现行的国民账户体系（ ）没有专门研究数据要素或数据资产的核算问题。数字技术的替代性、渗透性、协同性特征也使得常规方法难以核算数据要素及数字经济规模（蔡跃洲2018）哪些类型数据能纳入核算范围如何测度资产价值如何处理折旧及价格指数等成为实践中亟待解决的难题（续继、唐琦， ；许宪春等， ）。因此，基于数据要素区别于传统生产要素的新特点，从理论层面构建数据要素参与价值创造的微观基础是解决实践层面困难的必要途径。

数据要素具有虚拟性、非竞争性、非排他性（或部分排他性）、规模报酬递增、正外部性等特征，数据要素在与其他生产要素的结合过程中驱动创新和技术进步，提高资源配置效率，进而推动经济增长，基于数据要素的经济特征，本文把数据要素纳入广义价值论的经典分析框架中，研究其在价值创造中的重要地位。本文的主要贡献在于论证了数据要素本身以及物化在数据开发上的前期劳动与本期用于数据收集处理的活劳动同样创造价值，揭示了数据要素创造价值的微观机制，从而为数据要素按贡献参与分配奠定了价值基础。

## 二、文献综述

## （一）数据、数据产品与数据要素

要说明数据要素是否以及如何创造价值，首先需要对数据、数据产品与数据要素的概念进行清晰的界定。生产要素是人们进行生产经营活动所需要的经济资源，是财富创造的基础和经济增长的源泉（李政、周希禛， ）。原始数据由于其碎片化、非结构性的特征，不能直接为最终产品生产提供有价值的信息，其本身并不具有生产要素的属性。原始数据需要经过收集、存储、清理、分析等环节，首先转化为具有使用价值的数据产品，才能作为数据要素投入最终产品的生产（王颂吉等， ）。也就是说，数据要素是经劳动加工过的数据产品（何玉长、王伟， ）。

原始数据要能够被直接利用，需要通过数据的生产即数据的收集处理得到数据所承载的“信息”或其他产品和服务的加入。被生产出来的数据产品中，一部分可以作为最终产品直接进入消费过程，一部分作为生产要素再投入生产过程，同一数据产品（服务）也可能既可以作为消费品，也可以作为中间投入品。比如众多病人的病例以及医生针对病症开出的药方和康复建议，对每一个对应的病人来说就是最终产品，但对其他医生来说，作为临床就诊时的参考，就是投入品（要素）。如在 和 （ ）研究中提到的自动驾驶汽车的生产的例子，更多的数据可以用来对算法进行更好的训练，从而使自动驾驶汽车更加安全。在这里，由大量数据训练的算法（数据产品）作为自动驾驶汽车的投入要素，进入自动驾驶汽车的生产函数。

## （二）数据要素的经济特征

工业革命以来的历次技术革命显示，新的关键生产要素往往成本较低，并且能够大规模获取，进而推动经济社会组织模式的重构和技术—经济范式的转换（ ， ）。研究数据要素的经济特征，有助于认识数据在价值创造中的重要作用。

首先数据要素是虚拟的不能独立创造价值，与劳动，资本，土地等传统生产要素不同数据要素需要依附现代信息网络等载体，无法以独立的要素形态存在（ ， ； ， ）。因此，数据要素必须与其他生产要素结合才能提高微观运行效率，推动企业在产品、技术等环节上进行创新（谢康等， ；林志杰、孟政炫， ）。

其次，数据具有非竞争性、非排他性（或部分排他性）。额外增加数据的使用者并不会减少现有使用者的效用，同一组数据可以被多个经济主体使用，因而数据是非竞争性的（唐要家、唐春晖， ；熊巧琴、汤珂，）。同时，数据生成过程中往往涉及多个主体，加之数据信息易于扩散的特点，数据要素通常是非排他的（ ， ；戴双兴， ）。不过，受益于加密技术的应用，部分用户也可能被排除在数据要素的使用范围之外，因而数据要素也可以是部分排他的（蔡跃洲、马文君， ）。

再次，数据要素具有规模报酬递增特征。 （ ）认为，非竞争生产要素的生产和积累能够推动经济增长 也能够与劳动力结合产生规模报酬递增效应，由于数据要素是非竞争的数据规模越大，种类越丰富，使用者越多，越能够推动生产效率的提升，推动总产出的增长幅度超过要素投入的增长幅度（裴长洪等， ；徐翔等， ）。不过，随着数据积累规模的增大，效率提升的速度也将不断下降，从长期看，数据要素的回报率可能呈递减趋势（蔡跃洲、马文君， ）。

最后数据要素具有正外部性，数据的收售和使用能够进一步推动数据积累形成正反馈效应和滚雪球式的自我强化。同时，数据要素的溢出效应明显，数据分析处理技术通常表现出“通用目的技术”特征，间接推动其他生产部门的效率提升（徐翔等2021·张宇，蒋殿春2021）。

## （四）数据要素与价值创造

对于数据要素按贡献参与分配学者一般并没有异议但对于数据要素贡献的属性是使用价值还是价值或者更直接地说，数据要素本身是否创造价值，学术界仍然存在分歧。一种观点认为，数据要素的贡献就是数据要素本身所创造的价值，数据要素也是剩余价值的重要源泉（庄子银， ）。另一种观点认为，数据要素的贡献是使用价值（王颂吉， ），数据要素可以提高劳动生产率，但并不直接创造价值 ，“直接创造价值”的观点是“三位一体”公式和“边际生产力”理论的翻版（王胜利、樊悦， ）。看来，消除这种分歧的根本途径在于 建立一个逻辑一致的一般均衡框架将数据要素与其他生产要素(如劳动)置于统一的模型中探讨其对价值创造的贡献<sup>①</sup>。有鉴于此，本文把数据要素纳入广义价值论的经典分析框架中，以期为数据要素是否创造价值、如何创造价值提供严谨的逻辑实证。

## 三、纳入数据要素的一般均衡框架

## （一）广义价值论简介

作为本研究的理论基础，广义价值论从初创（蔡继明， ）到基本模型建立（蔡继明， ， ），再到此后一系列的拓展和完善（蔡继明， ， ；蔡继明、江永基， ；蔡继明等， ），经 多年系统研究，已成为一个相对成熟的价值理论。

广义价值论吸收了劳动价值论、新古典价值论和斯拉法价值论的科学成分，根据比较利益率均等原则构建了均衡价格比例和价值决定模型。广义价值论认为，相对生产力差别是比较优势以及相应的比较利益<sup>②</sup>产生的原因和分工交换的基础，均衡交换比率是根据比较利益率相等原则决定的。部门综合生产力（同一生产者在两种产品上的生产力的几何平均)的上升能够推动单位平均劳动创造的价值量增加也能带来部门总劳动创造的价值总量上升由于数据只是在党的士九届四中全会(2019)之后才纳入按贡献参与分配的生产要素范畴，广义价值论的现有文献并未专门讨论其在价值创造和价值分配中的作用。不过，蔡继明和江永基（ ）已经对非劳动要素在价值创造和价值分配中的作用做了深入研究，蔡继明等（ ）也以技术进步为例，讨论了经济增长和价值总量扩大的问题。这些研究均为数据要素参与价值创造和分配提供了参考。

\frac {M _ {2 _ {i}}}{M _ {1 _ {i}}} = \left[ \frac {\left(1 - \beta_ {1}\right) F _ {1 x} \left(\vartheta_ {1 x _ {i}}\right) F _ {1 y} \left(F _ {1 x} ^ {- 1} \left((1 - \beta_ {1}) F _ {1 x} \left(\vartheta_ {1 x _ {i}}\right)\right)\right)}{\beta_ {2} F _ {2 y} (1) F _ {2 x} \left(F _ {2 y} ^ {- 1} \left(\beta_ {2} F _ {2 y} (1)\right)\right)} \right] ^ {\frac {1}{2}}\tag{26}

根据广义价值论对多种形态劳动生产力的定义（蔡继明， ），可以看出 $F _ { 1 x } ( \vartheta _ { 1 x _ { t } } )$ 和 $F _ { 1 y } ( { F ^ { - } } _ { 1 x } ( { \mathrm { ~ ( ~ } } 1 \mathrm { { - } } \beta _ { 1 } { \mathrm { ) } } F _ { 1 x } ( { \vartheta } _ { 1 x } ) { \mathrm { ) } } )$ 分别为消费—生产者 在产品 $x$ 和 $y$ 上的绝对生产力，F（ ）和 $F _ { 2 x } ( F _ { 2 y } ^ { - 1 } ( \beta _ { 2 } F _ { 2 y } ( 1 ) ) )$ ）分别为消费—生产者 在产品 $y$ 和 $x$ 上的绝对生产力。因此消费—生产者的综合生产力及比较生产力分别为：

$$
C P _ {1 _ {t}} = \left[ F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right) F _ {1 y} \left(F _ {1 x} ^ {- 1} \left(\left(1 - \beta_ {1}\right) F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)\right)\right) \right] ^ {\frac {1}{2}}\tag{27}
$$

$$
C P _ {2 _ {t}} = \left[ F _ {2 y} (1) F _ {2 x} \left(F _ {2 y} ^ {- 1} \left(\beta_ {2} F _ {2 y} (1)\right)\right) \right] ^ {\frac {1}{2}}\tag{28}
$$

$$
C P _ {1 _ {t} / 2 _ {t}} = \left[ \frac {F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right) F _ {1 y} \left(F _ {1 x} ^ {- 1} \left((1 - \beta_ {1}) F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)\right)\right)}{F _ {2 y} (1) F _ {2 x} \left(F _ {2 y} ^ {- 1} \left(\beta_ {2} F _ {2 y} (1)\right)\right)} \right] ^ {\frac {1}{2}}\tag{29}
$$

## 经济学

由公式（ ）和（ ）可得，均衡条件下消费—生产者 和 的劳动投入比例为：

$$
\frac {M _ {2 _ {t}}}{M _ {1 _ {t}}} = \left[ \frac {(1 - \beta_ {1})}{\beta_ {2}} \right] ^ {\frac {1}{2}} C P _ {1 _ {t} / 2 _ {t}} \equiv \tilde {C P} _ {1 _ {t} / 2 _ {t}}\tag{30}
$$

特别地，广义价值论基础模型重点关注来自生 $\vec { \cal J } ^ { \pm }$ 层面的比较优势，即假定 $\beta _ { 1 } { = } \beta _ { 2 } { = } 1 / 2$ 。此时有 $M _ { 2 } / M _ { 1 } =$ $C P _ { 1 , / 2 , }$ 。由消费—生产者的总人数 $\overline { { M } } = M _ { 1 } + M _ { 2 }$ ，可得：

$$
\left\{ \begin{array}{l} M _ {1} = \frac {1}{1 + \tilde {C P} _ {^ {1 _ {t} / 2 _ {t}}}} \bar {M} \\ M _ {2} = \frac {\tilde {C P} _ {^ {1 _ {t} / 2 _ {t}}}}{1 + \tilde {C P} _ {^ {1 _ {t} / 2 _ {t}}}} \bar {M} \end{array} \right.\tag{31}
$$

由总价值量等于生产 $x$ 和 $y$ 两种产品的社会总劳动时间，可得：

$$
M _ {1 _ {t}} v _ {x _ {t}} x _ {1 _ {t}} ^ {p} + M _ {2 _ {t}} v _ {y _ {t}} y _ {2 _ {t}} ^ {p} = M _ {1 _ {t}} + M _ {2 _ {t}}\tag{32}
$$

则由公式（ ）和（ ）可得：

\left\{ \begin{array}{l} v _ {x _ {t}} = \frac {\beta_ {2}}{1 - \beta_ {1} + \beta_ {2}} \frac {1}{F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)} \left(1 + \tilde {C P} _ {1, f ^ {2 _ {t}}}\right) \\ v _ {y _ {t}} = \frac {1 - \beta_ {1}}{1 - \beta_ {1} + \beta_ {2}} \frac {1}{F _ {2 y} (1)} \left(1 + \frac {1}{\tilde {C P} _ {1 , f ^ {2 _ {t}}}}\right) \end{array} \right.\tag{33}

## 四、数据要素是价值创造的重要源泉

从广义价值论基本模型已经可以得出，单位商品价值与绝对生产力负相关但不成反比、单位平均劳动创造的价值量与部门比较生产力正相关、部门总劳动创造的价值总量与部门比较生产力正相关、全社会价值总量与社会总和生产力正相关等重要结论，详见蔡继明（ ）。这些结论在本文的模型中仍可以推导出来，此处不做进一步展开。仅以公式（ ）为例，可以得到：

$$
\frac {\partial v _ {x _ {t}}}{\partial F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)} = \frac {\beta_ {2}}{1 - \beta_ {1} + \beta_ {2}} \left[ - \frac {1 + \tilde {C P} _ {1 / z _ {t}}}{\left(F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)\right) ^ {2}} + \frac {\partial \tilde {C P} _ {1 / z _ {t}} / \partial F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)}{F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right)} \right] <   0\tag{34}
$$

从公式（ ）可以看出，生产力的提高对单位商品价值量的影响分解为两部分，一部分导致单位商品价值量下降，即中括号的前半部分，是小于 的负效应；另一部分导致单位商品价值量上升，即中括号的后半部分，是大于 的正效应。正是由于后半部分的存在，抵消了单位商品价值量的降低幅度，使得单位商品价值量的降低幅度小于部门综合生产力的提高幅度。由此，我们可以知道，消费—生产者 在产品 上的生产力提高，一方面有直接导致产品 单位价值量下降的负效应，另一方面有间接导致单位价值量上升的正效应。消费—生产者 在产品x上的绝对生产力与其综合生产力的关联效应，抵消了单位价值量的降低幅度，使得单位价值量的降低幅度小于综合生产力的提高幅度，便可以得出单位商品价值与绝对生产力负相关但不成反比的结论。这不仅校正了马克思部门劳动生产力与单位商品价值量成反比的命题，而且从逻辑上否定了马克思部门劳动生产力与部门价值总量不相关的命题，因为既然部门劳动生产力提高时，单位商品价值不会成比例下降，而总产量的增加足以抵消单位产品价值下降而有余，部门总价值自然会增加而不是保持不变<sup>④</sup>。

需要强调的是广义价值论基本模型假定绝对生产力的提高由外生决定 并未深入讨论生产力提高的源泉。蔡继明等（ ）虽然在解释“价值总量之谜”的同时，阐述了技术进步对劳动生产率提高和经济增长的重要作用但并未将技术进步与绝对生产力密切联系也未过论技术进步与综合生产力和比较生产力之间的关系。本文在这些研究的基础上，以数据要素为例，进一步探讨推动生产力提高的因素，也就是要进一步揭示价值创造的源泉。

由公式（<sub>8</sub>）可得：

$$
D _ {1 _ {t}} = g _ {1 D} \left(D _ {1 _ {t - 1}}\right) f _ {1 D} \left(l _ {1 D _ {t}}\right) = \left(D _ {1 _ {t - 1}}\right) ^ {a} \left(\frac {l _ {1 D _ {t}}}{\bar {l}}\right) ^ {b} = \left(D _ {0}\right) ^ {a ^ {t}} \prod_ {\tau = 0} ^ {t - 1} \left(\frac {l _ {1 D _ {t - \tau}}}{\bar {l}}\right) ^ {a ^ {\tau} b}\tag{35}
$$

因此消费—生产者 在产品 $x$ 上的绝对生产力为：

$$
F _ {1 x} \left(\vartheta_ {1 x _ {t}}\right) = \left(D _ {0}\right) ^ {a ^ {\prime} \alpha_ {x}} \prod_ {\tau = 1} ^ {t - 1} \left(\frac {l _ {1 D _ {t - \tau}}}{\bar {l}}\right) ^ {a ^ {\tau} b \alpha_ {x}} \left(\frac {b \alpha_ {x}}{\left(b \alpha_ {x} + \gamma_ {x}\right) \bar {l}}\right) ^ {b \alpha_ {x}} \left(\frac {\gamma_ {x}}{b \alpha_ {x} + \gamma_ {x}}\right) ^ {\gamma_ {x}}\tag{36}
$$

可见，消费—生产者 在 $\vec { \cal J } ^ { \pm }$ 品x上的绝对生 $\vec { \boldsymbol { J } ^ { \pm } }$ 力取决于 种因素：一是数据要素的初始存量 $D _ { 0 }$ ，二是前期收集处理数据所投入的劳动 $l _ { 1 D _ { t - \tau } } , \tau { = } \{ 1 , 2 , \cdots , t { - } 1 \}$ ，三是当期在收集处理数据所投入的劳动 $l _ { 1 D _ { i } }$ 和生 $\vec { \cal J } ^ { \pm }$ 产品所投入的劳动 $l _ { 1 x _ { t } \circ }$ 。其中， $l _ { 1 D _ { i } }$ 和 $l _ { 1 x _ { t } }$ 是活劳动，它们对价值创造的贡献无可争议。本文关注的重点在于前两个因素。

首先，数据要素自身能否创造价值？答案是肯定的。数据要素是能够进入生产过程中的信息，脱离数据要素本身而谈收集处理数据的劳动，是无根之木，无源之水。同时，数据要素的初始存量规模越大，越有助于形成较高的绝对生产力。从现实情况看，我国长期以来拥有人口资源禀赋的巨大优势，由此产生的巨大规模数据初始存量，及其通过乘数效应的进一步集聚、累积，意味着我国在互联网经济时代拥有先天的比较优势或潜力。不过，初始禀赋的“先人一步”不代表比较优势的“一成不变”。公式（ ）也表明，由于 $0 < a < 1$ ，随着时间推移，数据初始存量对绝对生产力的贡献将越来越小。

其次，物化在数据收集处理中的劳动是否创造价值？答案也是肯定的。部分研究认为，价值的惟一源泉是活劳动，价值分配是按生产要素所有权进行的，价值创造和价值分配是两回事。本文的研究表明，绝对生产力不仅取决于活劳动，也取决于物化劳动。物化劳动创造价值的一个重要途径就是收集处理数据，由于前期的数据能够为企业当期乃至未来生产决策提供重要信息，前期为收集处理数据投入的劳动越多，越有助于提升企业当期及未来的创新能力和资源配置效率，降低成本和不确定性。当然，从现实角度看，经济活动面临的外部环境复杂多变，过时的数据信息可能无法为当前决策提供可靠参考，这就要求生产者不断投入新的劳动用于数据收集处理。这反映在理论模型中，就是由于 $0 < a < 1$ ，前期的物化劳动将不断折旧，对绝对生产力的贡献也呈递减趋势。

接下来，本文进一步关注数据要素的正外部性特征及其对综合生产力的贡献。前文指出，数据要素通常具有正外部性的特点，能够带动其他产品生产效率的提升。假定专业化生产 $x$ 的消费—生产者 投入 $l _ { 1 D _ { i } }$ 单位的劳动用于收集处理数据，产生的正外部性可折算为 $\eta l _ { 1 D _ { t } }$ 单位的劳动进入到产品 $y$ 的生产中<sup>⑤</sup>。其中， $\eta \in ( 0 , 1 )$ 反映正外部性的程度。因此消费—生产者 生产产品 $y$ 的隐含数据要素存量 $\widetilde { D } _ { i }$ 为：

$$
\tilde {D} _ {1 _ {t}} = g _ {1 D} \left(\tilde {D} _ {1 _ {t - 1}}\right) f _ {1 D} \left(l _ {1 D _ {t}}\right) = \left(\tilde {D} _ {1 _ {t - 1}}\right) ^ {a} \left(\frac {l _ {1 D _ {t}}}{\bar {l}}\right) ^ {b} = \left(D _ {0}\right) ^ {a ^ {\prime}} \left[ \prod_ {\tau = 1} ^ {t - 1} \left(\eta \frac {l _ {1 D _ {t - \tau}}}{\bar {l}}\right) ^ {a ^ {\tau b}} \right] \left(\frac {l _ {1 D _ {t}}}{\bar {l}}\right) ^ {b}\tag{37}
$$

由公式（ ）和（ ）可以得到：

$$
\tilde {D} _ {1 _ {t}} = \eta^ {\sum_ {\tau = 1} ^ {t - 1} a ^ {\tau} b} \left(D _ {0}\right) ^ {a ^ {t}} \left[ \prod_ {\tau = 1} ^ {t - 1} \left(\frac {l _ {1 D _ {t - \tau}}}{\bar {l}}\right) ^ {a ^ {\tau} b} \right] \left(\frac {l _ {1 D _ {t}}}{\bar {l}}\right) ^ {b} = \eta^ {\frac {a b}{1 - a} (1 - a ^ {t - 1})} D _ {1 _ {t}}\tag{38}
$$

则消费—生产者 在产品 $y$ 上的绝对生产力为：

$$
F _ {1 y} \left(\vartheta_ {1 y _ {i}}\right) = \eta^ {\frac {a b \alpha_ {y}}{1 - a} \left(1 - a ^ {t - 1}\right)} \left(D _ {0}\right) ^ {a ^ {t} \alpha_ {y}} \prod_ {\tau = 1} ^ {t - 1} \left(\frac {l _ {1 D _ {t - r}}}{\bar {l}}\right) ^ {a ^ {\tau} b \alpha_ {y}} \left(\frac {b \alpha_ {y}}{\left(b \alpha_ {y} + \gamma_ {y}\right) \bar {l}}\right) ^ {b \alpha_ {y}} \left(\frac {\gamma_ {y}}{b \alpha_ {y} + \gamma_ {y}}\right) ^ {\gamma_ {y}}\tag{39}
$$

与 $F _ { 1 x } ( \vartheta _ { 1 x _ { t } } )$ 类似，消费—生产者 在产品 $y$ 上的绝对生产力 $F _ { 1 y } ( \vartheta _ { 1 y _ { t } } )$ 也取决于 种因素：一是数据的初始存量 $D _ { 0 }$ ，二是前期收集处理数据所投入的劳动 $\eta l _ { 1 D _ { t - \tau } }$ ，三是当期在收集处理数据所投入的劳动 $l _ { 1 D _ { i } }$ 和生产产品所投入的劳动 $l _ { 1 y _ { i } \subset }$ 。同样地，数据的初始存量，以及物化的劳动耗费也能够推动消费—生产者 在产品 $y$ 上的绝对生产力提高，进而推动综合生产力 $C P _ { 1 }$ 提高，是价值创造的另一种途径。

此外，在t 期，消费—生产者 的（产品x对产品 $y )$ 相对生产力

$$
R P _ {1 _ {0}} = \frac {F _ {1 x} \left(\vartheta_ {1 x _ {0}}\right)}{F _ {1 y} \left(\vartheta_ {1 y _ {0}}\right)} = \left(D _ {0}\right) ^ {\left(\alpha_ {x} - \alpha_ {y}\right)} \frac {\left(\frac {b \alpha_ {x}}{\left(b \alpha_ {x} + \gamma_ {x}\right) \bar {l}}\right) ^ {b \alpha_ {x}} \left(\frac {\gamma_ {x}}{b \alpha_ {x} + \gamma_ {x}}\right) ^ {\gamma_ {x}}}{\left(\frac {b \alpha_ {y}}{\left(b \alpha_ {y} + \gamma_ {y}\right) \bar {l}}\right) ^ {b \alpha_ {y}} \left(\frac {\gamma_ {y}}{b \alpha_ {y} + \gamma_ {y}}\right) ^ {\gamma_ {y}}}\tag{40}
$$

在 $t > 0$ 期，消费—生产者 的（产品x对产品 $_ y )$ ）相对生产力为：

$$
R P _ {1 _ {t}} = \eta^ {- \frac {a b \alpha_ {y}}{1 - a} (1 - a ^ {t - 1})} \prod_ {\tau = 1} ^ {t - 1} \left(\frac {l _ {1 D _ {t - \tau}}}{\bar {l}}\right) ^ {a ^ {\tau} b (\alpha_ {x} - \alpha_ {y})} R P _ {1 _ {0}}\tag{41}
$$

## 经济学

随着时间推移， $\eta ^ { - \frac { a b \alpha _ { y } } { 1 - a } \left( 1 - a ^ { t - 1 } \right) }$ 呈递增趋势。如果 $\alpha _ { x } \geqslant \alpha _ { y }$ ，那么相对生产力 $R P _ { 1 }$ 也将递增，这意味着数据要素的累积不会改变分工方向，而是不断扩大消费—生产者 在产品x上的比较优势。如果 $\alpha _ { x } < \alpha _ { y }$ ，则在短期内分工方向改变，消费—生产者 专业化生产y，投入 $l _ { 1 D _ { \mathrm { f } } } .$ 单位的劳动用于收集处理数据，产生的正外部性可折算为 $\eta l _ { 1 D _ { i } }$ 单位的劳动进入到产品x的生产中。这样，从长期看，数据要素的累积将导致消费—生产者 在产品 $y$ 上的比较优势不断扩大。

从生产过程看，数据要素的价值来自于两部分：归属于公众的共有数据和归属于特定消费—生产者的用于生产数据要素的劳动投入。由公式（ ）、（ ）可以看出，数据的初始存量是不依赖于消费—生产者的劳动投入而产生的，这部分数据就是共有数据。由前期劳动形成的数据要素是属于消费—生产者的私人部分，既影响他在产品x上的绝对生产力，也影响他在产品y上的绝对生产力。同理，由当期劳动形成的这部分数据要素也属于消费—生产者的私人部分。由上文可知，纵观整个生产和交换过程，价值创造由三部分组成：数据的初始存量，前期投入的劳动，当期收集处理数据的劳动和生产产品投入的劳动，价值也应当按照这三部分的贡献进行分配。本文进一步用模拟图刻画数据的初始存量规模以及前期收集处理数据的劳动耗费对绝对生产力的贡献。

## 五、结论

我国经济已由高速增长阶段转向高质量发展阶段，数据要素对于推动我国高质量发展并在国际高新技术领域实现弯道超车的重要性日益凸显。虽然党的十九届四中全会已经把数据列入按贡献参与分配的生产要素范畴，不过囿于理论层面的研究缺乏，数据要素在实践层面的界权、核算均面临较大挑战。本文把数据要素纳入广义价值论的经典分析框架中，以求为数据要素参与价值创造和价值分配提供坚实的理论基础。

## 经济学

数据要素通常具有正外部性的特点，能够带动其他产品生产效率的提升，本文也刻画了这种性质及对生产力的影响。

其次，本文分析了数据要素对绝对生产力的影响。绝对生产力不仅取决于当期在收集处理数据所投入的劳动和生产产品所投入的劳动，也取决于数据的初始存量和前期收集处理数据所投入的劳动。这意味着数据的初始存量规模越大，越有助于形成较高的绝对生产力；前期为收集处理数据投入的劳动耗费越多，越有助于提升绝对生产力。数据自身以及物化的劳动耗费均能够创造价值。

再次，本文分析了数据要素对综合生产力的影响。数据要素的正外部性特征使得数据的收集处理能够带动其他产品生产效率的提升，即提升消费—生产者在不具备比较优势的产品上的绝对生产力，进而提升其在两种产品上的综合生产力。

本文的理论模型揭示了数据要素对于价值创造的重要贡献。从实践层面看，我国人口众多、经济体量庞大拥有构建超大规模数据市场的条件也具备在数字经济时代获得战略先机的基础，未来更需要清晰界定数据资源的产权属性，构建和完善数据要素市场，充分发掘和实现数据要素所蕴含的的巨大生产力和社会价值。

# The Approach of Data Factor Participating in Value Creation: A General Equilibrium Analysis Based on the General Theory of Value

Cai Jiming<sup>a</sup>, Liu Yuan<sup>b</sup>, Gao Hong<sup>a</sup> and Chen Chen<sup>a</sup>

(a. Center for Political Economy, Tsinghua University; b. School of Economics. Capital University of Economics and Business)

Summary: The academic community has two different views on what is the value basis for data factor to participate in the distribution according to their contributions: one is that the contribution of data factor is the value created by the data factor itself; the other is that data factor can improve labor productivity and create use value, but does not directly create value. Based on the characteristics of virtuality, non-competitiveness, non-exclusivity (or partial exclusivity), increasing returns to scale, and positive externalities of data factor, this paper incorporates data factor into the general equilibrium analysis framework of the general theory of value, and uses the consumer-producer two-stage decision-making model to reveal the ways in which data factor participate in value creation by increasing the absolute and comprehensive productivity of labor.

The main contribution of this paper is to demonstrate that data factor can sequentially improve the absolute productivity, comprehensive productivity and comparative productivity of labor through initial stock of data, the labor invested in collecting and processing data in the previous period, and in the current period. Furthermore, with the help of the equilibrium exchange ratio formed based on the principle of equality of comparative interest rates and the principle of positive correlation between comparative productivity and value, the micro-mechanism of data factor creating value is revealed, thereby laying a value foundation for data factor to participate in the distribution according to their contributions.

This paper firstly sets the production function including data factor, and then analyzes the effects of the initial stock of data, the previous and current labor invested in data collection and processing on the production efficiency of final products. According to the principles of production value maximization and utility maximization, it analyzes the division of labor between the two types of consumption-producers in the production of two products according to their respective comparative advantages, and the allocation of their labor in collecting and processing data and using data factor to directly produce products. Then a general equilibrium system is constructed according to the principle of equality of comparative interest rates and market clearing conditions.

Based on the basic principles of the general value theory that the unit commodity value is negatively correlated with absolute productivity but not inversely proportional, the value created by unit average labor is positively correlated with sectoral comparative productivity, the total value created by sectoral total labor is positively correlated with sectoral comparative productivity, and the total social value is positively correlated with the total social productivity. this paper analyzes the influence of data factor and the previous and current labor invested in data collection and processing on absolute productivity, comprehensive productivity and comparative productivity, thus demonstrating the im: portance of data factor in value creation. The comparative advantage formed by the initial endowment will decrease over time. Among them, the more labor spent in the early stage for data collection and processing, the more helpful it is to improve the current and future innovation capabilities of enterprises, The positive externality of the data factor makes the above effects not only strengthen the comparative advantage of the department, but also weaken the comparative disadvantage, thereby further improving the comprehensive productivity level of the sector and enabling the unit labor to create more value.
