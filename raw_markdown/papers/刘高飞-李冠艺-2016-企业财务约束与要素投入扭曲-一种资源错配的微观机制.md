# 企业财务约束与要素投入扭曲

# ——一种资源错配的微观机制

刘高飞 李冠艺

摘要：本文考察了企业财务结构差异在资源错配形成过程中的重要作用，尝试在要素市场价格扭曲与企业最优化决策之间架设起一座桥梁，为探索资源错配形成的微观机制提供一个崭新的思路。为此，本文以Heish与Klenow（2009）提出的资源错配模型为基础，设计了一个由异质性企业组成的垄断竞争模型，推断出企业要素投入扭曲是要素市场价格扭曲和个体财务结构差异的共同结果，进而利用1999年～2013年制造业企业数据证实了理论假设。研究发现：在资本价格扭曲的环境下，财务状况恶劣的企业要素投入扭曲程度更严重，其生产更倾向于劳动密集型。

关键词：财务约束；要素投入扭曲；资源错配；异质性企业垄断竞争模型

JEL分类号：E44,G31,G32

## 一、引言

在总体经济中，乃至一个行业内部，企业之间的财务结构存在着明显的差异。这种财务结构异质性是否影响企业的市场绩效？如果答案是肯定的，财务结构异质性会通过何种效应来影响企业绩效？这类问题一直是公司金融领域研究的热点。Modigliani和Miller（1958）提出，在满足资本市场完美等一系列严格假定的条件下，企业的财务结构不会对市场绩效产生影响，因此，资本结构差异与企业之间的盈利水平差异无关——这个结论以MM定理的形式为其后的资本结构研究提供了一个标杆。此后，大量研究开始尝试放松MM定理的严格假定，以得出更接近经济现实的结论。许多研究指出，在信用市场不完美的条件下，恶劣的财务状况会阻碍企业对外部资本的获取，从而削弱他们的盈利水平。

另一方面，经济学家长期以来一直在关注广泛并持续存在着的企业生产率差异。以往通常认为，造成这些差异的原因最可能来自生产性资源的匮乏，比如资本要素、各类素质的劳动力等，或者是企业家精神的差异以及新技术、新方法的采纳速度不同。然而，自Hsieh和Klenow（2009）提出一个描述资源错配与生产率损失的结构化模型以来，这一课题的研究被引入了一个全新的领域。Hsieh和Klenow认为，总体生产率不仅取决于个体企业的生产率，也取决于要素在异质性企业间的配置效率，换言之，生产性资源在企业间的配置不当（misallocation，以下译为“资源错配”），也会造成总体生产率的巨大损失。

资源错配问题本是一个发展经济学课题，但随着Hsieh和Klenow（2009）开创性的实证研究所指示的研究方向，一批学者开始从企业最优化决策的角度出发，研究特定诱因下资源错配形成的微观机制。另一种研究资源错配的重要思路由Restuccia和Rogerson（2008）提出，他们将政策扭曲视为一种征收于企业产出之上的比例税，政策扭曲的程度越高，资本积累和劳动供给越低，最终导致较低的产出。还有不少文献关注资本要素的配置，Modrigan和Xu（2012）利用一个动态模型研究了金融市场摩擦能够在多大程度上解释资源错配的形成，他们发现，金融市场摩擦降低TFP的途径有两种：干扰企业的进入决策和技术采纳速度，以及造成企业间资本回报水平的差异。此外，Banerjee和Moll（2010）、余婧、罗杰（2012）以及张佩、马弘（2012）还从企业融资约束的角度提出了非常有益的见解。

造成资源错配的原因多种多样，如市场摩擦、政策扭曲、加成率等原因都已得到了研究者的较多关注；资本错配的测度方法也已日臻成熟，钱学锋、蔡庸强（2014）指出，要素投入扭曲、TFP扭曲和加成率异质性是三种最重要的测算方法。但是，针对企业财务约束与要素投入扭曲关系的研究仍然十分稀少，对这一问题的实证研究也较为零散。本文沿着资源错配问题的研究脉络，从财务结构影响企业最优决策的角度出发，试图在要素市场扭曲与企业生产决策之间架设起一座桥梁，为探索资源错配形成的微观机制提供一个崭新的思路。

为此，本文以Hsieh和Klenow（2009）的资源错配模型（以下简称H&K模型）为基础，借鉴Uras（2013）对该模型的改进，设计了一个包含异质性企业的垄断竞争模型——与H&K模型不同，本文理论模型中企业异质性的内涵更广，不仅包括了企业间生产率水平差异与资本成本差异，也允许在财务结构方面存在差异，使之更加贴近企业决策的现实环境。

本文重点区别了一组概念：“要素市场扭曲”是企业面临的外部压力，“财务异质性”是企业自身在财务结构方面的特征；而“要素投入扭曲”是企业生产决策的结果，也是对资源错配实际程度的一种测度。企业在确定投入量和要素投入比率时，不仅要考虑资本市场价格，还必须依据自身受到的财务约束。本文将会证明：企业财务异质性在资源错配形成过程中起到了无法忽视的作用。具体而言，企业财务结构的异质性表现为资产流动性和外源融资能力两个方面，前者反映企业从内部获取资本的能力，后者则反映了企业获取外部资本的能力——在资本价格扭曲的背景下，二者共同构成了资本错配形成过程的完整拼图：保持其他条件不变，企业资产流动性水平越低、外源融资能力越差，其要素投入的扭曲程度就越高，与行业水平相比，该企业在生产中更倾向于减少资本投入，转而密集使用劳动要素。

实证方面，本文利用1999年～2013年中国制造业上市企业数据，对流动性指标、外源融资能力指标与要素投入扭曲度的关系进行了回归分析，计量分析的结果证实了模型所提出的理论假设。本文接下来的篇幅安排如下：第二部分为一个异质性企业垄断竞争模型，该模型的核心是流动性与外源融资能力在企业生产决策中的作用，模型的最后部分将自然引出两项理论假设；第三部分为实证检验，具体环节包括数据描述、模型和指标设定、计量结果分析等；最后一部分是结论与研究展望。

## 二、理论模型

本文认为，财务约束条件下的企业最优化决策是资本错配的直接原因。以下，我们将构建一个由异质性企业组成的垄断竞争模型，以求证明：要素市场价格扭曲必须通过个体的财务约束才能对企业决策产生影响——由于财务约束主要表现为流动性和外源融资能力，因此，企业最终的资本投入量以及“资本—劳动”投入比例是流动性、外源融资能力与要素市场价格共同决定的结果。

## （一）一个三层结构的投入—产出模型

首先，本文假设生产要素分为劳动和资本两种，假设劳动要素的供给是无弹性的，劳动报酬完全由市场决定，不存在扭曲，资本是要素扭曲的唯一来源。资本供给由外生决定且总规模固定，但是，资本要素能够以一定的价格在生产企业之间进行交易。其次，假设市场中存在一系列具有异质性的中间产品生产企业，它们的生产率存在差异，财务结构也各不相同。这些企业根据资本市场价格和自身财务约束，遵循利润最大化原则，确定其所利用的生产要素的规模、不同要素的相对比例、以及价格和产量规模。最后，假设一系列中间产品将被用于生产最终产品，同时，最终产品也作为计价单位被支付给各中间产品生产企业。

1.标记s行业的最终产品为 $\Upsilon _ { s }$ ，其投入品是各类中间产品 $\mathrm { Y _ { s i } }$ 。设最终产品的生产函数为一个CES函数：

$$
Y _ {s} = (\sum_ {i = 1} ^ {M _ {s}} Y _ {s i} ^ {\frac {\sigma - 1}{\sigma}}) ^ {\frac {\sigma}{\sigma - 1}}\tag{1}
$$

其中， $\sigma$ 为不变替代弹性；假设每个中间产品企业只生产一种差异化产品，则 $\mathbf { M } _ { s }$ 是中间产品的种类数及中间产品生产企业的总数。标记中间产品的价格为 $\mathrm { P _ { s i } }$ ，中间产品的实际需求为 $\mathrm { Y _ { s i } ^ { \ d } }$ ，则最终产品成本最小化的条件可以表达为下式：

$$
\min \sum P _ {s i} Y _ {s i} ^ {d}, \quad \text { s   .   t   . } \quad Y _ {s} = \left(\sum_ {i = 1} ^ {M _ {s}} Y _ {s i} ^ {\frac {\sigma - 1}{\sigma}}\right) ^ {\frac {\sigma}{\sigma - 1}}
$$

进一步地，通过成本最小化的一阶条件得到各类中间产品 $\mathrm { Y _ { s i } }$ 的需求函数：

$$
\mathrm{Y} _ {\mathrm{si}} ^ {\mathrm{d}} = \left(\frac {\mathrm{P} _ {\mathrm{si}}}{\mathrm{P} _ {\mathrm{s}}}\right) ^ {- \sigma} \mathrm{Y} _ {\mathrm{s}}
$$

其中， $\mathrm { P _ { s } } = \bigl ( \sum \mathrm { P _ { s i } } ^ { 1 \cdot \sigma } \bigr ) ^ { \frac { 1 } { 1 - \sigma } }$ 为最终产品s的行业价格。此即为行业级的决策过程（最终产品生产决策确定了中间产品的需求量）。

2.设中间产品 $\mathrm { Y _ { s i } }$ 的生产函数为一个C-D函数：

$$
\mathrm{Y} _ {\mathrm{si}} = \mathrm{A} _ {\mathrm{si}} \mathrm{K} _ {\mathrm{si}} ^ {\alpha} \mathrm{L} _ {\mathrm{si}} ^ {1 - \alpha}, \mathrm{A} _ {\mathrm{si}} \sim \mathrm{iid}\tag{2}
$$

(2)式中，中间产品企业的异质性表现为全要素生产率在企业间存在差异，以全要素生产率独立同分布来表示。

3.在要素供给方面，假设生产要素包括劳动和资本两种。本文假设劳动要素的供给是外生决定的，劳动市场完美无摩擦，劳动报酬不存在扭曲。另一方面，由于企业对资本要素的使用不及劳动要素灵活，无法以较低的代价迅速调整资本投入规模（De Loecker and Warzynski, 2012），本文于是把“要素扭曲”这一概念限定为资本价格的扭曲，亦即，不同企业面对的资本成本是不同的。

资本要素的总供给也是外生决定的，其固定规模为 $\mathrm { K } _ { s }$ ，然而，中间产品生产企业能够以一定的代价对资本要素进行交易，交易以最终产品 $\mathrm { Y } _ { s }$ 作为度量单位。在初始阶段，中间产品生产企业各自拥有一定的禀赋 $\xi _ { \mathrm { s i } } \mathrm { K } _ { s }$ ，在获得资本禀赋的同时，也获得了 $\omega _ { \mathrm { i } }$ 单位的行业最终产品禀赋。

## （二）要素价格扭曲与个体财务约束的共同作用机制

受到资本市场不完善、信用环境恶劣等多重因素的影响，资本价格呈现出扭曲的特征。举例而言，对地方财政贡献巨大的国有企业往往能以较低成本获得大量资本要素，而融资渠道匮乏的小型民营企业，其资本成本很可能是极高的。企业面对的资本成本表现为市场平均利率 ${ \mathrm { ~ \bf ~ r ~ } } ^ { \mathrm { c } }$ 乘以扭曲系数 $\tau _ { \mathrm { s i } }$ ：

$$
\mathrm{r} _ {\mathrm{si}} = \mathrm{r} ^ {\mathrm{c}} \cdot (1 + \tau_ {\mathrm{si}})
$$

其中， $\tau { \sim } \mathsf { G } \left( \tau \right)$ 。这也即是H&K模型中资本要素价格扭曲的标准表达形式。然而，由于企业拥有多种获得资本要素的渠道，要素市场的扭曲未必能够对企业生产决策产生直接的影响。为了更准确的刻画要素市场扭曲到个体决策扭曲的传递过程，Uras（2013）对H&K模型进行了合理的改进，本文遵循Ura（2013）的思路，允许企业通过租赁和购买两种交易方式获得额外的资本品。

如果选择购买资本品，那么企业的支付方式便是其所控制的最终产品，实际上，企业不仅能够利用自有资金 $\omega _ { \mathrm { i } }$ 去购买资本要素，还可以通过外部融资获取额外的最终产品，再以之购买资本品。假设购买价格为 $\mathtt { R } ^ { \mathtt { c } }$ ，企业购买资本的交换率就是 $\frac { \omega _ { \mathrm { i } } } { \mathrm { R } ^ { \mathrm { c } } } { = } \frac { \mathrm { K } } { 1 }$

当然，企业不能无限制的进行外部融资，这条“借入Y —购买K”的方式能在多大程度上产生效果，受到每个企业外部融资能力的制约。这种制约的严格程度便取决于企业各自的财务结构状况，下式描述了企业最大融资规模受到融资能力的限制：

$$
\mathrm{B} _ {\mathrm{si}} \equiv \mathrm{r} ^ {c} \mathrm{K} _ {\mathrm{si}} - \left(\mathrm{r} ^ {c} \xi_ {\mathrm{si}} \mathrm{K} _ {\mathrm{s}} + \omega_ {\mathrm{i}}\right) \leq \theta_ {\mathrm{si}} \mathrm{R} ^ {c} \mathrm{K} _ {\mathrm{si}}\tag{3}
$$

其中， $\mathtt { R } ^ { \mathtt { c } }$ 为市场平均购买价格， $\omega _ { \mathrm { s i } } , \xi _ { \mathrm { s i } } , \theta _ { \mathrm { s i } }$ 服从联合分布函数 $\big \mathrm { J } \left( \omega , \xi , \theta \right)$

(3)式左端的 $\mathrm { B _ { s i } }$ 代表企业为满足生产所需要的融资规模，该规模由其生产所需要的资本 $\mathrm { K _ { s i } }$ ，与本企业实际拥有的资本（包括禀赋资本和禀赋最终产品所折算的资本）的差额计算而得；(3)式右端的 $\Theta _ { \mathrm { s i } } \mathrm { R } ^ { \mathrm { c } } \mathrm { K } _ { \mathrm { s i } }$ 的含义在于，受到自身融资能力的严格限制，企业无法100%的满足融资需求，外源融资缺口以一个大于0小于1的系数 $\theta _ { \mathrm { s i } }$ 表示。

(3)式表明，企业拥有“租赁”和“购买”两种获取资本要素的方式，这两种方式各有利弊：在资本品租赁市场上，企业必须接受扭曲后资本成本，由于要素市场扭曲系数 $\tau _ { \mathrm { s i } }$ 的存在，租赁对企业而言是不经济的；而作为替代选择，企业也可以借助外源融资来购买资本品，这种方式在一定程度上能够缓解企业面临的高租金，但企业融资能力往往不能满足全部的资本需求——因此，资本价格并不是决定资本投入规模的唯一因素，企业的生产决策必须同时考虑要素市场价格以及自身的财务能力。

## （三）中间产品企业的最优化决策

如同现实环境一样，模型中的企业也分为资本买方和资本卖方，这是由企业资本禀赋与生产所需资本规模的相对大小决定的。如果资本禀赋大于所需资本规模，就定义这类企业为资本卖方，他们将在市场上会出售资本要素；如果持有的资本禀赋小于所需资本规模，则定义这种企业为资本买方，他们必须在市场上购买或租赁资本。

通过以上的模型设定可以得知，为获得满足生产所需的资本要素，作为资本买方的某企业必须作出一个权衡选择：或者选择租赁资本品——但是必须承受租赁市场的错误定价；或者通过融资采购资本——但由于融资规模受限，采购到的资本往往杯水车薪。

根据无套利定价思想，使得企业在租赁市场和购买市场之间无差别的均衡定价为：

$$
\mathrm{r} ^ {\mathrm{c}} = \mathrm{R} ^ {\mathrm{c}} = \mathrm{R}
$$

考察一个资本买方，其资本投入一部分来自企业内部的资本禀赋，标记为 $\mathrm { K } _ { \mathrm { s i } } ^ { \mathrm { ~ I ~ } }$ ，另一部分来自于外部，句括或租或买而得到的资本标记为 $\mathrm { K } _ { \mathrm { s i } } ^ { \mathrm { ~ E ~ } }$ $\mathrm { K } _ { \mathrm { s i } } ^ { \mathrm { ~ E ~ } }$ 的成本构成较为复杂，这是因为在资本价格扭曲的条件下，资本租赁的成本高昂，企业会优先选择“先融资—后购买”这种途径，优先借款至其上限，因此，两种外部渠道获得的资本规模分别为 $\mathrm { R K } _ { \mathrm { s i } } ^ { \mathrm { ~ E ~ } }$ 和 $( 1 + \tau _ { \mathrm { s i } } ) \mathrm { R K _ { s i } ^ { \mathrm { ~ E ~ } } }$ ，其权重分别为 $\theta _ { \mathrm { s i } }$ 和 $1 - \theta _ { \mathrm { s i } }$ 。于是，本模型的问题转化为中间产品企业的利润最大化问题：

$$
\max _ {\mathrm{P}, \mathrm{K} ^ {\mathrm{E}}, \mathrm{K} ^ {\mathrm{I}}, \mathrm{L}} \pi_ {\mathrm{si}} \equiv \left\{\mathrm{P} _ {\mathrm{si}} \mathrm{A} _ {\mathrm{si}} \left(\mathrm{K} _ {\mathrm{si}} ^ {\mathrm{E}} + \mathrm{K} _ {\mathrm{si}} ^ {\mathrm{I}}\right) ^ {\alpha} \mathrm{L} _ {\mathrm{si}} ^ {1 - \alpha} - w \mathrm{L} _ {\mathrm{si}} - R \left[ (1 + \tau_ {\mathrm{si}}) (1 - \theta_ {\mathrm{si}}) + \theta_ {\mathrm{si}} \right] \cdot \mathrm{K} _ {\mathrm{si}} ^ {\mathrm{E}} - R \mathrm{K} _ {\mathrm{si}} ^ {\mathrm{I}} \right\}
$$

$$
\text {s.t.} \quad \left\{ \begin{array}{l} \text {资本结构恒等式} K _ {\mathrm{si}} ^ {\mathrm{I}} + K _ {\mathrm{si}} ^ {\mathrm{E}} = K _ {\mathrm{si}} \\ \text {外部融资约束} r ^ {\mathrm{c}} K _ {\mathrm{si}} - \left(r ^ {\mathrm{c}} \xi_ {\mathrm{si}} K _ {\mathrm{s}} + \omega_ {\mathrm{i}}\right) \leq \theta_ {\mathrm{si}} R ^ {\mathrm{c}} K _ {\mathrm{si}} \end{array} \right.
$$

为将 $\mathrm { K } _ { \mathrm { s i } } ^ { \mathrm { ~ I ~ } }$ 与 $\mathrm { K } _ { \mathrm { s i } } ^ { \mathrm { ~ E ~ } }$ 统一在企业的资本要素使用量中，本文引入内部资本比例 $\lambda _ { \mathrm { s i } }$ 的概念，定义：

$$
\lambda_ {\mathrm{si}} = \min \left\{\frac {\omega_ {\mathrm{si}} + \mathrm{R} \xi_ {\mathrm{si}} \mathrm{K} _ {\mathrm{s}}}{\mathrm{RK} _ {\mathrm{si}}}, 1 \right\}
$$

分子部分为企业获得内部资本的能力，分母部分为为满足生产实际需要的资本规模。整理上式得到：

$$
\max _ {P _ {\text {si}}, K _ {\text {si}}, L _ {\text {si}}} \pi_ {\text {si}} \equiv \{P _ {\text {si}} A _ {\text {si}} K _ {\text {si}} ^ {\alpha} L _ {\text {si}} ^ {1 - \alpha} - w L _ {\text {si}} - R [ \lambda_ {\text {si}} + (1 - \lambda_ {\text {si}}) [ (1 + \tau_ {\text {si}}) (1 - \theta_ {\text {si}}) + \theta_ {\text {si}} ] ] K _ {\text {si}} \}\tag{4}
$$

由此可见，企业的资本成本为市场平均价格R乘以系数 $\lambda _ { \mathrm { s i } } + ( 1 - \lambda _ { \mathrm { s i } } ) [ ( 1 + \tau _ { \mathrm { s i } } ) ( 1 - \theta _ { \mathrm { s i } } ) + \theta _ { \mathrm { s i } }$ ，定义资本价格扭曲系数 $\gamma _ { \mathrm { s i } }$ ，将其整理为：

$$
1 + \gamma_ {\mathrm{si}} = 1 + \tau_ {\mathrm{si}} (1 - \lambda_ {\mathrm{si}}) (1 - \theta_ {\mathrm{si}})
$$

从而得出：

$$
\gamma_ {\mathrm{si}} = \tau_ {\mathrm{si}} (1 - \lambda_ {\mathrm{si}}) (1 - \theta_ {\mathrm{si}})
$$

由此可知，企业实际利用资本的成本受到两方面因素的影响：

1.由市场摩擦等原因导致的资本价格扭曲，反映为H&K定义的资本价格扭曲系数 $\tau _ { \mathrm { s i } }$ ；

2.企业个体的财务特质，亦即企业的流动性水平 $( 1 - \lambda _ { \mathrm { s i } } )$ 和外部融资能力 $( 1 - \theta _ { \mathrm { s i } } )$

由现实条件可知， $\lambda _ { \mathrm { s i } }$ 与 $\theta _ { \mathrm { s i } }$ 均在 $^ { ( 0 , 1 ) }$ 范围内取值，通过计算偏导可知， $\tau _ { \mathrm { s i } }$ 与 $\gamma _ { \mathrm { s i } }$ 呈正方向变化， $\theta _ { \mathrm { s i } }$ ， $\lambda _ { \mathrm { s i } }$ 与 $\gamma _ { \mathrm { s i } }$ 呈反方向变化。

$$
\left\{ \begin{array}{l} \frac {\partial \gamma^ {2}}{\partial \tau \partial \theta} <   0 \\ \frac {\partial \gamma^ {2}}{\partial \tau \partial \lambda} <   0 \\ \frac {\partial \gamma^ {2}}{\partial \theta \partial \lambda} > 0 \end{array} \right.
$$

如果某地区融资渠道较为匮乏，当地企业面临的资本成本往往偏高，这意味着 $\tau _ { \mathrm { s i } } > 0$ 。然而，如果 $\lambda _ { \mathrm { s i } }$ 与 $\theta _ { \mathrm { s i } }$ 越高，说明企业外部融资的需求较小，且外部融资的能力较强，则企业就能够减少资本价格扭曲的影响，企业面对的扭曲系数 $\gamma _ { \mathrm { s i } }$ 较小。特别地，当极端情况 $\theta _ { \mathrm { s i } } = 1$ 或者 $\lambda _ { \mathrm { s i } } = 1$ 时，企业能够充分利用信用市场规避资本错配的影响，此时 $\gamma _ { \mathrm { { s i } } } = 0$ ，企业投入资本的成本等于市场平均成本。

另一方面，如果企业从内源融资的能力较弱、对外源融资的依赖程度较高（ $\lambda _ { \mathrm { s i } }$ 较低），或者外源融资的能力较弱（ $\lvert \theta _ { \mathrm { s i } }$ 较低），则资本市场扭曲系数 $\tau _ { \mathrm { s i } }$ 就会被放大，导致 $\gamma _ { \mathrm { s i } } > \tau _ { \mathrm { s i } }$ o

在现实经济中， $\theta _ { \mathrm { s i } } < 1$ 和 $\lambda _ { \mathrm { s i } } < 1$ 对企业而言是极为常见的。由此可见，企业要素投入量受到要素市场错配和个体财务特征的综合影响——这个结论的重大意义在于，财务结构异质性不再仅限于影响企业的投融资决策，更会通过资源错配效应影响到企业的生产决策。

## （四）企业财务约束对生产决策的影响

为实施比较静态分析，假设存在一个不面临资源错配 $( \tau _ { \mathrm { i t } } = 0 \ )$ 且不存在财务约束（ $\theta _ { \mathrm { s i } } = 1$ 或 $\lambda _ { \mathrm { s i } } = 1 \ )$ 的企业，以这个理想中的企业作为参照组，其资本成本为市场平均成本 $\mathrm { R } ;$ ；以同时面临资源错配（ $\tau _ { \mathrm { i t } } \neq 0$ ）和财务约束（ $( \theta _ { \mathrm { s i } } < 1$ 且 $\lambda _ { \mathrm { s i } } < 1$ ）的企业作为研究组，其资本成本为 $\big [ 1 + \tau _ { \mathrm { s i } } \big ( 1 - \lambda _ { \mathrm { s i } } \big ) \big ( 1 - \theta _ { \mathrm { s i } } \big ) \big ] \cdot \mathrm { R }$

定义要素使用扭曲度 $\mathrm { D _ { s i } = { \frac { K _ { s i } } { L _ { s i } } } }$ ，继续考察两组企业最优决策下的“资本—劳动”投入比例。无约束企业的要素使用比例为：

$$
D _ {s i} ^ {u} = \frac {K _ {s i} ^ {u}}{L _ {s i} ^ {u}} = \frac {\alpha}{1 - \alpha} \frac {w}{R}\tag{5}
$$

存在财务约束企业的要素使用比例：

$$
D _ {s i} ^ {c} = \frac {K _ {s i} ^ {c}}{L _ {s i} ^ {c}} = \frac {\alpha}{1 - \alpha} \frac {w}{R} \frac {1}{\left[ 1 + \tau_ {s i} (1 - \lambda_ {s i}) (1 - \theta_ {s i}) \right]}\tag{6}
$$

由于 $1 + \tau _ { \mathrm { s i } } \big ( 1 - \lambda _ { \mathrm { s i } } \big ) \big ( 1 - \theta _ { \mathrm { s i } } \big ) > 1$ ，可知， $\mathrm { D _ { s i } ^ { c } } / \mathrm { D _ { s i } ^ { u } } < 1$ ，说明存在财务约束的企业，与其同类企业相比，其生产更加偏向于密集使用劳动力。

$$
\frac {D _ {\mathrm{si}} ^ {\mathrm{c}}}{D _ {\mathrm{si}} ^ {\mathrm{u}}} = 1 + \tau_ {\mathrm{si}} (1 - \lambda_ {\mathrm{si}}) (1 - \theta_ {\mathrm{si}}) <   1
$$

由(6)式可知，

$$
\frac {K _ {\mathrm{si}} ^ {c}}{L _ {\mathrm{si}} ^ {c}} = \frac {\alpha}{1 - \alpha} \frac {w}{R} \frac {1}{(1 + \gamma_ {\mathrm{si}})}
$$

进一步地分解要素使用比例：

$$
1 + \gamma_ {\mathrm{si}} = 1 + \tau_ {\mathrm{si}} (1 - \lambda_ {\mathrm{si}}) (1 - \theta_ {\mathrm{si}}) = \frac {\alpha}{1 - \alpha} \frac {w}{R} \frac {L _ {\mathrm{si}}}{K _ {\mathrm{si}}}\tag{7}
$$

到此为止，企业层面的“资本—劳动”投入决策已经完毕。正如(7)式所指示的，企业实际要素投入比例受到三个变量的共同影响，分别是：要素市场扭曲系数（ $\tau _ { \mathrm { s i } }$ ）、企业资产流动性 $( \lambda _ { \mathrm { s i } }$ ）和外源融资能力$( \theta _ { \mathrm { { s i } } } )$ ）。以下将对各变量的影响程度做进一步的定量分析。

## 三、实证分析

由以上的理论模型可知，企业在确定其资本投入量以及“资本—劳动”投入比率时，不仅需要考虑资本市场价格 $( \tau _ { \mathrm { s i } }$ ），还必须依据自身受到的财务约束。财务约束主要表现为流动性（ $\lambda _ { \mathrm { s i } }$ ）和外源融资能力$( \xi _ { \mathrm { s i } }$ ）两种指标，前者反映企业对外部资本的需求，后者则反映了企业获取外部资本的的能力——在资本价格扭曲的背景下，二者共同构成了资本错配形成过程的完整拼图。根据(7)式的指示，本文提出以下两条假设：

H1：流动性水平对企业资本投入具有负向影响：流动性越低，生产越偏向劳动密集型。

H2：外部融资能力对企业资本投入具有负向影响，外部融资能力越低，生产越偏向劳动密集型。

## （一）数据来源

本文采用的数据来自中国上市公司数据库，时间跨度为1999年—2013年。选择上市公司数据而非工业企业数据的原因是，上市公司财务报告质量较高，并且市场进入退出程度较低，不仅适合本文所采用的静态分析方法，而且有利于排除所有制、再配置效应等非主要研究对象对实证结果的干扰。

本文采用了覆盖36个子行业的制造业上市公司样本，在样本筛选方面，只保留了主板市场上满足观察期内主营业务保持不变、且至少经营五年以上的企业。筛选完成后，样本个数为415，每个变量大约拥有5800个观测值。

本文使用的数据集由两个数据来源合并而成，其中，公司成立年份、行业分类、所有权比例、职工人数等基础信息来自WIND数据库，资产负债表项目、利润表项目和现金流量表项目等财务数据来自RESSET数据库。为了消除价格水平波动带来的干扰，本文设1999年为基期，利用历年《中国统计年鉴》提供的固定资产投资价格指数对固定资产净值进行平减、利用CPI对应付职工薪酬进行平减，从而得到相当于基期水平的可比价值。

## （二）模型设定与指标选取

为检验两个假设是否成立，本文将定义企业要素扭曲度指标，并分别用代表流动性和外源融资能力的指标对其进行回归，基本方程如下：

$$
\begin{array}{l} \text {KL distortion} _ {\mathrm{it}} = \beta_ {0} + \beta_ {1} X _ {1 \mathrm{it}} + \beta_ {2} Z _ {\mathrm{it}} + \varepsilon_ {\mathrm{it}} \\ \text {KL distortion} _ {\mathrm{it}} = \gamma_ {0} + \gamma_ {1} X _ {2 \mathrm{it}} + \gamma_ {2} Z _ {\mathrm{it}} + \varepsilon_ {\mathrm{it}} \end{array}
$$

其中，被解释变量 KL distorti $) \mathrm { { n } _ { i t } }$ 是由理论模型定义的企业要素投入扭曲度 $( \gamma _ { \mathrm { { i t } } } \ )$ ），它代表i企业于t时点的要素使用比例与校准比例的偏差程度，根据(7)式的定义，企业要素扭曲度可以由下式得到：

$$
\mathrm{KL} \text { distortion } _ {\mathrm{it}} = \gamma_ {\mathrm{it}} = \frac {\alpha_ {\mathrm{s}}}{1 - \alpha_ {\mathrm{s}}} \frac {\mathrm{w}}{\mathrm{R}} \frac {\mathrm{L} _ {\mathrm{it}}}{\mathrm{K} _ {\mathrm{it}}} - 1
$$

要素投入扭曲度的构建需要行业级要素产出弹性、企业级劳动和资本投入量、资本和劳动力价格等信息。一般认为，扭曲程度较低的美国要素市场能够为要素产出弹性提供校准，因此通常将资本弹性α 统一设为1/3（Hsieh and Klenow, 2009），为充分反映要素弹性在行业间的巨大差异，本文利用NBER数据库提供的美国二位码行业信息，对制造业不同子行业的 $\alpha _ { s }$ 进行了分别设定。劳动价格与劳动投入量的乘积${ \mathrm { w L } } _ { \mathrm { i t } }$ 则由资产负债表中的应付职工薪酬项目得到。资本市场价格R取15%，资本投入规模则采用永续盘存法推得的每年度固定资产投资净额，固定资产折旧率设为10%。

从计算公式可以看出，KL $\mathrm { d i s t o r t i o n } _ { \mathrm { i t } }$ 越高，企业受资本市场扭曲的影响就越大，保持其他条件不变，该企业的生产也更加偏向劳动密集型。另一方面，由于模型推断出 $\gamma _ { \mathrm { i t } } = \tau _ { \mathrm { i t } } \big ( 1 - \lambda _ { \mathrm { i t } } \big ) \big ( 1 - \theta _ { \mathrm { i t } } \big )$ ，理论上，企业要素扭曲度应当受到资产流动性水平与外源融资能力的负向影响。以下，将为这两种财务变量寻找合适的指标。

解释变量包括流动性指标和外部融资能力指标。流动性指标（Liquidity）以企业的流动资产与流动负债的差额，除以流动负债规模而得到；外源融资能力指标则比较复杂，靳来群（2015）认为，外源融资包括银行信贷、发行债券或股票以及商业信贷等多种形式，其中，最重要的是以商业银行为主体的借贷市场和企业间商业信贷。根据张佩和马弘（2012）的研究，银行借贷约束的松紧可以由利息支出与总负债的比值来描述，定义这个反映借贷约束的指标为Outf1，Outf1越高，企业面临的借贷约束就越紧，要素投入扭曲程度可能会偏高；此外，余婧、罗杰（2012）认为，工业企业能够通过调整其应收帐款和应付账款来从交易对手方面获得融资，企业间商业信贷虽然是一种非正式的融资渠道，但一直在中国金融资源的配置中发挥着重要的作用，定义反映这种商业信用融资的指标为Outf2，计算公式为（年均应付账款—年均应收帐款）/总资产，Outf2越高，企业通过商业信贷获得外部融资的能力越强，要素投入扭曲度就可能偏低。

为保证计量结果的稳健性，回归模型中还包括了一些重要的控制变量，包括：企业规模（Size），以企业固定资产净值的对数来衡量；企业年龄 $\left( \mathrm { A g e } \right)$ ），以观测年份与企业成立时间的差值来表示；债务结构（LiaStruct），以长期借款与总负债的比值来表示；盈利能力（Profita），以企业每年的营业利润率来表示；细分行业资本依赖度（Kintens），以行业固定资产净值总额与总资产总额的比值来衡量。由于要素投入比例在制造业内部各细分子行业之间存在明显的差别能否控制行业差异便成为了决定本文的实证结果可靠与否的关键，为此，本文采取了两条措施，首先，在选取校准要素投入弹性时，没有采取一刀切的0.33与0.66，而是利用了美国三位码行业的相关数据，与中国制造业分类进行了行业级匹配；其次，计算了资本依赖度来对行业间差异加以控制，以提升主要解释变量回归系数的显著度。

方程（1）考察了企业资产流动性与要素扭曲度的关系，回归系数表明，保持其他条件不变，流动性更差的企业要素投入扭曲更严重，并且回归系数在5%的置信水平上显著；方程（2）反映出企业借贷约束的松紧程度与要素投入扭曲度的关系，企业面对的借贷约束越紧张，进一步进行外源融资的空间就越窄，要素投入扭曲受市场价格扭曲的影响就越大；方程（3）则表明商业信贷也是影响要素投入扭曲度的重要因素，商业信用融资能力越强，企业受到要素市场价格扭曲的影响越小，相对校准要素投入比例的偏离程度就越低。

三个方程中，解释变量回归系数的方向均与设想结果一致，并分别在各自水平上显著。这表明，财务结构是影响要素价格扭曲环境下企业生产决策的重要因素，流动性水平与外源融资能力越弱，企业受要素市场扭曲的影响就越大，其生产更加偏向于劳动密集型。

从控制变量方面看，企业规模、企业年龄、行业级资本依赖程度的回归系数均呈显著。具体而言，企业规模（Size）越大、年龄 $\left( \mathrm { A g e } \right)$ ）越大，要素投入扭曲程度越低，这可能是因为规模越大、营运越久的企业越容易通过各种渠道获得资本，这与通常的印象是吻合的。资本依赖程度（Kintens）则对要素投入扭曲存在正向的影响，严重依赖资本投入的行业及企业的要素扭曲程度往往更高。此外，负债结构指标在（2）、（3）两方程中并不显著，而在方程（1）中显著，这是由于负债结构对流动性回归方程而言是一个极好的信息补充，而外源融资能力回归方程的解释变量已经包含了负债信息，因此减弱了该项系数的显著性。同时，企业盈利能力对要素投入扭曲的影响并不显著，没有发现利润表项目会对本文所研究的资源错配机制构成干扰。

## （四）稳健性检验

针对各变量计算过程以及回归分析中可能存在的问题，本文从两方面进行了稳健性检验。首先，对固定资产折旧率的假设确实会影响要素投入扭曲度的测算结果，根据计算公式，较高的折旧率不仅会提高企业资本投入规模 $\mathrm { K _ { i t } }$ ，也会抬高平均资本价格R。上文在10%折旧率和15%平均资本价格的设定下得出了验证结论，这一结论在5%的折旧率假设下仍然是稳健的；其次，按照WIND数据库提供的所有制类型划分方法，本文选取的415个样本包括145个民营企业（含民营企业、其他企业）和270个国有企业（含地方国企、中央国企），所有制区别是否会对这种资源错配机制产生影响是一个值得思考的问题。但是，本文的数据来自上市企业数据库，根据统计，2012年，在中国的2537家上市公司中，有2387家获得了政府补贴，占比高达94%，累计补助金额约为1070亿元（韩剑、郑秋玲，2014），因此，本文认为民营上市企业和国有企业在财务指标方面的差距并不大。在稳健性检验中，本文将所有制虚拟变量与解释变量的交乘项加入回归，结果发现交乘项系数不显著，说明财务异质性对资源错配的作用机制是普遍适用于各类所有制企业的。

## 四、结论与研究展望

本文研究了企业财务结构差异在资源错配形成过程中的重要作用，证明了在要素市场存在扭曲的环境下，企业生产决策必须兼顾扭曲价格与个体财务约束，最终确定的“资本—劳动”投入比例必然受到个体财务异质性的影响。因此，资本错配是企业财务结构差异与要素价格扭曲共同作用的结果。进一步地，财务异质性又包括资产流动性与外源融资能力，流动性与外源融资能力越高，企业生产决策受到要素市场扭曲的影响越小，要素投入比例也越接近不存在扭曲条件下的最优比例。计量分析的结果证实了理论模型提出的假设

受到建模方法与数据的限制，本文的研究仍然存在一定的局限性，例如，C-D生产函数中忽视了原材料投入和能源投入，有文献认为中国企业的中间产品产出弹性是极高的，无法将企业简单的划分为资本密集型或者劳动密集型。由于上市公司数据没有包括这些信息，本文便无法对要素扭曲度做更精准的测算。另外，除了银行借贷、商业信贷这两种最重要的融资方式，上市公司还可以通过时断时续的股票再融资获得资金，鉴于再融资不仅是一种市场行为，更像是一种制度安排，本文也没有将再融资因素纳入模型。尽管存在一些局限，但本文从财务结构的角度，揭示了一种资源错配的微观机制，最终得出了具有稳健性的结论，为企业异质性与资源配置效率关系的研究，乃至于资本结构与市场绩效的研究都提供了一个新的思路。
