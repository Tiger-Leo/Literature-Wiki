# 对外直接投资的逆向技术溢出效应对中国全要素生产率影响的经验检验

白 洁

内容提要 技术获取型对外直接投资能够产生对投资母国的技术溢出效应 本文依据1985 2006年我国对14个主要国家和地区的对外直接投资数据 运用LP模型测算了通过ODI渠道溢出的外国研发资本存量 并采用国际R＆D溢出回归方法 就逆向技术溢出对全要素生产率的影响作了实证分析 结果显示 对外直接投资产生的逆向技术溢出能够对全要素生产率产生积极影响 但在统计上不显著 其主要原因在于 现有统计数据对投资规模的低估 技术寻求型ODI所占比例较小 海外投资产业集中在技术密集度低的行业

关 键 词 反向溢出效应 对外直接投资 全要素生产率

## 一、问题的提出

我国正从以吸收外资为主转向吸收外资和对外投资并重的阶段 2006年中国对外直接投资流量为2116亿美元 占全球对外直接投资 流出 流量的272 位于全球国家 地区 排名的第13位 随着对外直接投资加速增长 部分优秀企业以获取先进技术为动机 嵌入国外研发密集地区 整合利用当地技术资源大大增强了母公司的技术优势和竞争实力 那么 在宏观层面上 对外直接投资对我国技术进步是否产生积极影响 逆向技术溢出效应是否存在 这些问题的研究对于我国实施 走出去 战略具有重要理论意义

目前国内的研究存在以下不足 1在国际技术溢出框架下 对国际贸易和 FDI为溢出渠道的研究较多但对 QDI为技术溢出渠道的研究甚少，这与我国融入经济一体化的程度不无关系 随着更多企业积极 走出去”参与国际分工，关于这一领域的研究势必会成为热点 2关于 ODI的逆向技术溢出效应研究大多集中在理论综述 机理分析上 实证分析少之又少 统计数据的滞后和缺失是这一领域难以深入研究的重要原因3实证检验往往忽视外国的 R＆D变量 缺乏对 ODI溢出的国外研发资本存量的测算。

本文试图在以下两个方面对现有文献进行扩展(1)采用 LP方法测算了我国 ODI溢出的国外研发资本存量 现有的研究往往利用 ODI流量或存量数据直接对TFP进行回归分析 忽视了国外研发资本这一变量2采用国际 R＆D溢出回归方法 实证检验了逆向技术溢出效应是否存在 在选取数据方面 目前国内为数不多的研究选取的东道国数量较少 且以发达国家为主易造成对逆向技术溢出效应的低估 美国与日本之间存在的双向技术溢出证实了投资在技术差距较小或技术水平相近的国家同样有带来反向溢出效应的可能 因此 根据我国对外直接投资的主要去向并结合各国研发资本存量的多少 本文选取美国 日本 英国 法国 德国 意大利 西班牙 加拿大 澳大利亚 中国香港 韩国 新加坡印度和巴西14个国家和地区为研究对象 以便能够对我国ODI对技术进步的作用进行全面 客观地分析

## 二、理论回顾

传统跨国公司理论认为，公司特定所有权优势是跨国公司进行对外直接投资的必要条件 但最近研究对传统理论的观点提出质疑 即使在不具备特定优势的情况下 企业同样可以进行 ODI这类投资的动机在于获得东道国先进技术 Kogut和 Chang 1991 Teece（1992) Fosfuri与 M otta(1999)等学者从投资动机角度论证了技术寻求型FDI的存在 那么技术寻求型 FDI企业是否能够获取技术溢出效益？逆向溢出效应如何测定 影响因素又有那些 一些学者就这一系列问题从国家、产业和企业层面分别进行了实证检验。

Lichtenberg<sub></sub>F<sub>．</sub>和 B<sub>．</sub>vanPottelsberghedelaPotterieLP2000以1971 1990年间美国 日本和德国等 13个国家为样本 对进口 利用外资与对外投资三种途径所导致的国外R＆D外溢效应进行检验 结果证实了进口和ODI均是国际技术溢出的重要渠道 而FDI却没有对东道国的技术进步产生推动作用 作者认为 通过ODI带来的国际技术溢出效应与东道国的研发密集度有关 美国作为研发密集国家是 R＆D外溢传播者但本身很少能获得逆向技术溢出效应 日本是 R＆D外溢接收者 通过 ODI获得国外研发资本外溢 而投资在日本的国外企业却很少获得这种溢出效应

N igel D riffield 和 James H. Love （2003) 采用 1984\~1992年间英国制造业部门的面板数据 运用GMM法进行计量检验 结果显示 从英国国内行业向国外跨国企业的技术溢出是存在的，但这种逆向溢出效应局限于研发密集度高的行业 另外 逆向技术溢出效应受到产业空间集聚的影响 产业的空间集聚大 这种效应就更为明显

Branstetter2006从企业层面分析了日本与美国公司之间通过资本跨国流动带来的技术溢出效应 通过计量分析证实了双向外溢效应的存在 即日本投资到美国不仅对美国本土企业存在知识外溢，而且美国公司对日本的投资企业同样存在知识外溢现象 进一步Branstetter将分支机构的特征纳入分析框架 发现分支机构的类型影响外溢效应 日本的研发类和产品开发类子公司从美国得到的知识外溢更为明显 而绿地投资这种方式更容易使得日本公司知识外溢到美国本土公司

国内关于逆向技术溢出效应的实证研究甚少，赵伟 古广东和何元庆 2006分析了外向 FDI促进母国技术进步的机理 并进行了初步的经验性检验 证实了FDI流量与要素生产率变化之间存在正相关性的关系邹玉娟 陈漓高 2008利用 VAR模型对我国对外直接投资增长率和全要素生产率增长率的关系做了初步的实证研究 结果发现 二者之间有一定的同步关系 但由于现阶段我国对外直接投资规模较小 力度较弱 对外直接投资增长率对全要素生产率增长率的作用并不是十分明显，王英，刘思峰(2008)实证分析了国内研发资本存量和对外直接投资存量对全要素生产率的贡献度 结果显示 中国对外直接投资存量对全要素生产率增长产生积极影响 但作用要低于国内研发支出 林青，陈湛匀(2008)以主要10个国家对美国的外商直接投资为横截单元 以不同国家 1990 1999年的专利引用频率构成一套面板数据建立FDI反向溢出效应模型研究结果表明 投资国FDI对于获取知识技术的反向流动影响显著为正

综上所述 技术寻求型 ODI能够学习东道国先进的知识技术 带动投资国整个产业的技术水平的提高从而产生反向溢出效应 反向溢出效应的产生受投资国技术水平 投资方式 行业技术密集度及技术差距等因素的影响

## 1．计量模型

我们参照 LP模型构建国际 R＆D溢出回归模型首先假定技术进步是希克斯中性的 一国在 t时间的产出 实物资本 劳动和知识资本分别表示为 $\mathrm { Y } _ { \mathrm { t s } } \mathrm { K } _ { \mathrm { t s } }$ 、L和$\mathrm { S } _ { \mathrm { t o } }$ 根据CD生产函数可得

$$
\mathbf {Y} _ {\mathrm{t}} = \mathbf {A} _ {\mathrm{t}} \mathbf {K} _ {\mathrm{t}} ^ {\alpha} \mathbf {L} _ {\mathrm{t}} ^ {\beta} \mathbf {S} _ {\mathrm{t}} ^ {\gamma}\tag{1}
$$

其中 $\mathrm { A } _ { \mathrm { t } } ^ { \prime }$ 代表一国在t时间的技术水平 $\alpha _ { \setminus }$ 、β、γ是生$\vec { \cal J } ^ { \pm }$ 函数中的参数 将全要素生产率 TFP定义为 $\mathrm { Y } _ { \mathfrak { t } }$ ／K<sup>α</sup>${ \mathrm { L } } _ { \mathrm { t } } ^ { \beta }$ 并以TFP表示一国技术进步水平 通常假设 $\alpha + \beta$ ＝1即规模报酬不变 则有回归方程

$$
\ln \left(\mathrm{Y} _ {\mathrm{t}} / \mathrm{L} _ {\mathrm{t}}\right) = \ln (\mathrm{A}) + \alpha \ln \left(\mathrm{K} _ {\mathrm{t}} / \mathrm{L} _ {\mathrm{t}}\right) + \varepsilon_ {\mathrm{t}}\tag{2}
$$

考虑到时间因素和政策因素的影响 我们引入时间趋势项T和虚拟变量Z回归方程转变为

$$
\begin{array}{r l} \ln (\mathrm{Y} _ {\mathrm{t}} / \mathrm{L} _ {\mathrm{t}}) & = \ln (\mathrm{A}) + \alpha \ln (\mathrm{K} _ {\mathrm{t}} / \mathrm{L} _ {\mathrm{t}}) \\ & + \theta_ {1} \mathrm{T} + \theta_ {2} \mathrm{Z} + \varepsilon_ {\mathrm{t}} \end{array}\tag{3}
$$

这是一个双对数模型 可以用 OLS进行估算 从而得到 $\alpha .$ 和β的数值 依据 $\mathrm { T F P } = \mathrm { Y } _ { \mathrm { t } }$ ／K<sup>α</sup> $\mathrm { L } _ { \mathfrak { t } } ^ { \beta }$ 即可测算出全要素生产率

根据Coe和Helpman1995的贸易溢出模型 在开放经济体中 S取决于本国知识资本和国外的知识溢出 本文假定 $\mathrm { S ^ { = } ( \ r ^ { d } ) } ^ { \ \mathrm { \lambda } \mathrm { ^ { \lambda } } 1 } ( \mathrm { \ s } ^ { \mathrm { f } } ) ^ { \mathrm { \lambda } \mathrm { ^ { \lambda } } 2 } .$ 。将 S和全要素生产率代入 1式中 两边取对数 得到如下回归方程

$$
\log \mathrm{TFP} _ {\mathrm{t}} = \alpha_ {\mathrm{t}} + \lambda_ {1} \log \mathrm{S} _ {\mathrm{t}} ^ {\mathrm{d}} + \lambda_ {2} \log \mathrm{S} _ {\mathrm{t}} ^ {\mathrm{f}} + \lambda_ {3} \mathrm{Z} + \varepsilon_ {\mathrm{t}}\tag{4}
$$

其中 TFP表示我国第 t时期的全要素生产率S<sup>d</sup>表示t时期我国的研发资本存量S<sup>f</sup>表示我国通过对外直接投资技术扩散路径所溢出的国外研发资本存量。$\alpha _ { _ { \uparrow } }$ 为截距项 $\lambda _ { 1 }$ 和 $\lambda _ { 2 }$ 表示与国内研发资本存量和 ODI逆向技术溢出相关的 TFP弹性系数 Z为虚拟变量 $\varepsilon _ { \mathrm { r } }$ 是误差项

我们参考 LP2001对国外知识溢出的测算方法建立逆向技术溢出资本存量的计算公式

$$
\mathrm{S} _ {\mathrm{it}} ^ {\mathrm{f}} = \sum_ {\neq \mathrm{j}} \frac {\mathrm{ODI} _ {\mathrm{jt}}}{\mathrm{Y} _ {\mathrm{jt}}} \mathrm{S} _ {\mathrm{jt}}\tag{5}
$$

## 四 结论及启示

结合我国对外直接投资的现状 我们把具有实际意义的结论归纳如下

1. QDI作为国际技术溢出的途径，对我国全要素生产率的增长有正向作用 从回归结果中可以看出 通过对外直接投资溢出的国外研发存量对全要素生产率的贡献度为0044056 随着我国经济实力的增强 部分优秀企业充分利用科技全球化的契机 通过在国外设立研发机构或并购拥有核心技术的企业来整合全球资源获取国外先进技术 通过逆向技术溢出效应传递到母公司 并通过示范效应 带动国内其他企业改进技术 推动技术升级和产业升级 体现在国家层面则是促进我国技术进步

2我国对外直接投资产生的逆向技术溢出效应在统计上不显著，这一结论符合我国实际情况，其主要原因有以下几点

1现有的统计数据大大低估了我国实际的对外直接投资规模我国商务部的统计是中国企业电报目获得批准的初始的对外直接投资额 而不是其实际对外直接投资额国家外汇管理局的数据，统计口径广泛，更能反映我国实际的对外直接投资规模 但是 这套数据只有总量数据，没有商务部所提供的按地区和产业分类的数据。对外直接投资统计数据的缺失，会导致对逆向技术溢出效应的低估

2以获取先进技术为动机的对外直接投资不断增多 但所占比重较小 根据商务部研究院课题组的一项调查显示 有 254 的受访企业对外直接投资的动机是增加市场销售份额 仅有 103 的受访企业其投资动机是为了获得外国的先进技术 可见 我国对外直接投资类型仍以市场导向型为主 这一类型的 ODI对创新路径产生锁定效应 往往依靠原有的技术优势来寻求更多的市场份额 创新动力不大 对本国的技术进步作用有限

(3)中国对外直接投资的产业结构偏重于技术含量低的劳动密集型产业，对高新技术产业的投资严重偏小 根据 2007年度中国对外直接投资统计公报 显示 2007年我国对外直接投资流向制造业为213亿美元 占总投资额8 信息传输 计算机服务和软件业为

3亿美元 占11 科学研究 技术服务和地质勘查业为3亿美元 占11 我国对外直接投资总体呈现低技术格局 因此对我国技术进步的促进作用并不显著
