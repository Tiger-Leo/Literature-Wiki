## 一、企业国际竞争力的概念

目前国内外还没有一个研究机构或研究者在企业国际竞争力评价体系的研究方面取得让学术界高度认可的成果 国内外现有的研究还没有形成系统的 完善的理论体系 学者们在企业国际竞争力的内涵 评价对象 指标类型研究方法以及理论基础等方面都存在较大的分歧 但有一点是可以肯定的 那就是企业国际竞争力的研究需要进一步向实际应用拓展 本文研究对象是中央企业 中央企业国际竞争力评价具有一定的特殊性 目前主要由国资委对中央企业国际竞争力进行评价 从国资委的需求看 国际竞争力评价的目标是为国资委提供关于中央企业运营的相关信息 这些信息主要用于监督管理企业 考核管理者业绩 规范中央企业行为 指导国资委和中央企业正确进行决策等 而不是单纯评出名次及优劣的程度

因此 本文将借鉴国务院办公厅 关于发展具有国际竞争力的大型企业集团的指导意见 中对中央企业国际竞争力的界定 技术创新能力强 主业突出 拥有知名品牌和自主知识产权 市场开拓能力强 有健全的营销网络 拥有持续的市场占有率 经营管理能力强 有适应国际化经营的优秀管理人才队伍和现代化管理手段 劳动生产率 净资产收益率等主要经济指标达到国际同行业先进水平 规模经济效益好 具有持续的盈利能力和抵御风险能力

## 二、中央企业国际竞争力评价指标体系

从上文论述可见 中央企业国际竞争力是一个有多种相互联系，相互作用的要素构成的有机整体，是一个复杂的系统 因而建立一个科学的 系统化的 严谨的指标体系非常重要 国际竞争力评价是指为了实现中央企业的战略目标 运用特定的指标 采用科学的方法 对中央企业经营环境 过程及其结果进行的综合评价 对国际竞争力进行评价要考虑中央企业内外部各种因素 特别是要考虑我国中央企业所处的国情特点和环境的特殊性

中央企业国际竞争力的构成要素分为外部因素和内部因素 其中外部因素是指来自企业外部的 能够对中央企业国际竞争力产生影响的因素 主要是指间接因素 包括自然资源 政策环境 经济环境 人文环境和产业环境五类因素 内部因素是指来自企业内部的 能够对中央企业国际竞争力的形成产生影响的因素 主要是指直接因素 主要包括 企业资源 基础性因素 企业能力 可持续发展因素 和企业机制等三大部分 资源是指企业所拥有或控制的 可用于向客户提供产品或服务过程中的客观性存量资产的总和 企业需要包括有形资源和无形资源在内的各种资源的投入才能得以运行 资源的战略价值取决于其对国际竞争力形成的贡献程度 能力是由企业积累的 存在于企业组织成员或职能机构中 不易被仿制的 完成某项工作任务的可能性 包括市场开拓能力 技术开发和创新能力是巩固和强化企业资源的动力 可以使企业竞争力不断得到变化和提升 机制是指企业管理机制 促使企业利用其能力整合资源将国际竞争力从可能变成现实

因此 中央企业国际竞争力评价体系分为四个部分（1）竞争环境评价体系；（2）企业资源评价体系；（3）企业能力评价体系 企业机制评价体系

$$
\begin{array}{r l} \mathrm{CECI} & = 0. 2 5 \times \sum_ {\mathrm{j}} ^ {4} \mathrm{X} _ {\mathrm{j}} = 0. 2 5 \times [ \mathrm{X} _ {1} + \mathrm{X} _ {2} + \sum_ {\mathrm{i} = 1} ^ {2} (0. 2 5 \times \mathrm{X} _ {3 \mathrm{i}}) \\ & + \sum_ {\mathrm{i} = 1} ^ {4} (0. 2 5 \times \mathrm{X} _ {4 \mathrm{i}}) ] \end{array}
$$

其中 CECI为中央企业国际竞争力指数 $\mathrm { X } _ { \mathrm { j } } , \ \mathrm { j } ^ { = 1 , \dots , \ 4 }$ 分别表示竞争环境指数 企业机制指数 企业资源指数和企业能力指数 $\mathrm { X } _ { 3 } { \mathrm { , ~ } } \mathrm { i } { = } 1 ,$ 分别表示总资产和人均总资产的指标评价值 $\mathrm { X } _ { 3 } , ~ \mathrm { i } { = } 1 , \cdots$ 分别表示主营业务收入 资产负债率 主营业务收入和总资产利润率的指标评价值 式中和 都是权重 作用是使 CECI企业资源指数和企业能力指数的计算结果都为百分制形式
