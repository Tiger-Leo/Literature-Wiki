# 我国生产服务业与战略性新兴产业融合问题研究\*

贺正楚 吴艳 张蜜 文先明

摘要：通过对全国以及江苏、湖北和陕西的生产服务业与战略性新兴产业融合发展状况的测度分析，发现我国战略性新兴产业在驱动生产服务业发展时，二者存在着融合程度不均衡、融合性不显著问题。战略性新兴产业对生产服务业融合力较强，而生产服务业过于依赖战略性新兴产业的投入和需求。我国生产服务业与战略性新兴产业，均应由制造业驱动方向服务经济驱动方转变。

关键词: 生产服务业

战略性新兴产业 发展模式

## (一)生产服务业与战略性新兴产业融合发展模式

根据“微笑曲线”理论，在一条产业价值链中，其核心产业应该是提供高端技术、高端部件生产、信息、资金服务的生产服务业或新兴制造部门。我国正在加强战略性新兴产业的发展，战略性新兴产业该如何融合生产服务业的发展，以共同实现产业链价值的高端化。为此需要对二者融合发展的机理模式进行推导，其中的推导过程见图1。

推导1:当战略性新兴产业为发展的驱动方时,产业价值链的重心在战略性新兴产业上,与生产服务业融合现象不明显。此时的产业链价值环节为战略性新兴产业主导产品所创造,具体体现为制造而非创造,这将是生产价值链的核心竞争环节。在该核心竞争环节中,企业的主要任务是提高产品竞争力、降低生产成本,故应将远离核心竞争力的生产性服务外包给生产服务业或将内部生产服务业剥离出去,得以集中资源从事生产制造。生产服务业得益于战略性新兴产业的需求驱动,开始专业化的发展,一方面为战略性新兴产业提供资金流、信息流、知识流、物流的专业化服务;另一方面随着与战略性新兴产业共性技术、核心技术的交互协作,其生产性配套服务业也跟着升级。在以战略性新兴产业为发展的驱动力过程中,二者的融合现象并不明显,即发展并不是同步的,生产服务业依赖于战略性新兴产业的发展,更多的是提供物流、金融、信息等基础性服务活动。随着二者互动的加深,产业环境的完善,战略性新兴产业核心技术产业链逐渐成熟,来自于战略性新兴产业内部的核心研发技术可内部化为知识密集度高的生产服务业,参与到市场竞争中,为其他同类新兴制造业、生产服务业提供技术咨询、技术合作，此时产业价值链核心产业居于“微笑曲线”的两端；而生产服务业在接受大量新兴产业合作订单的过程中，自身的产业实力和规模也逐步扩大，为其他新兴制造业服务的大量经验得以积累，创新能力和知识密集度得到提升。

推导2:当生产服务业为产业链的价值环节时,发展重心为生产服务业部门(包括提供专业化生产服务的企业和由战略性新兴产业价值链升级内部化产生出的生产服务业部门),此时生产服务业与战略性新兴产业融合现象密切。生产服务业发展的高速阶段是工业化进程成熟时期,在此时期,战略性新兴产业的技术、市场均已成熟,而围绕其主导产品生产的产业链上,核心增值环节来自于金融业所提供的金融创新服务,科学研究业所提供的技术创新服务,商务、信息、法律行业所提供的及时信息服务,交通运输业所提供的便捷物流服务。与此同时,由于战略性新兴产业内部的技术创新降低,需要开拓新的核心技术产业链,而生产服务业可以凭借为制造业提供长期服务的经验参与到战略性新兴产业的技术开发中,二者在产业链的发展上出现技术、市场、业务边界的模糊,实现真正的融合,核心产业亦处于‘微笑曲线’两端。

## (二)产业融合测度指标

在探索生产服务业与战略性新兴产业的融合关系时，需要对融合程度进行度量，为此，建立融合测度指标。这里从中观视角，基于产业价值链层面的互动，采取基于价值型投入产出表的方法。投入产出表均衡模型为 $\sum_{j=1}^{n}x_{ij}+Y_{i}=X_{i}$ （该式反映各产业部门产品流向）和 $\sum_{i=1}^{n}x_{ij}+D_{j}+N_{j}=X_{j}$ （该式反映每一产业部门的产出与各产业部门为之投入的平衡关系）。其中， $x_{ij}$ 为第j产业部门生产中所消耗第i产业部门产品数量的价值 $(i=1,2,\cdots,n;j=1,2,\cdots,n)$ ； $X_{i}$ 为第i产业部门的年产品价值总量； $Y_{i}$ 为第i产业部门所提供的年最终产品价值； $D_{j}$ 为第j产业部门全年提取的折旧基金； $N_{j}$ 为第j产业部门在一年内的劳动报酬。

1. 中间投入率。j 产业部门中间投入率为该产业部门在一定时期内，生产过程中的中间投入与总投入之比 $f_{i}=\sum_{j=1}^{n}x_{ij}/\left(\sum_{j=1}^{n}x_{ij}+D_{j}+N\right)$ 。其中， $j(j=1,2,\cdots,n)$ 产业部门的中间投入率越高，该产业对其他部门的生产驱动力越强，附加值率则越低，反之则生产驱动力低，附加值率则越高。

2. 特定产业投入率。因为需要探索生产性服务产业各部门与战略性新兴产业各部门之间的影响力关系，可设定特定产业投入率指标进行测量。该指标为 $i$ 产业对 $j$ 产业的中间投入所占 $j$ 产业总中间投入的比率，该指标值越大，则 $j$ 产业对 $i$ 产业的投入依赖程度愈强，也意味着 $i$ 产业对 $j$ 产业的影响力越大 $f_{i-j} = x_{ij} / \left(\sum_{j=1}^{n} x_{ij} + D_j + N_j\right)$ 。

3. 中间需求率。i 产业部门的中间需求率为各产业部门对 i 产业产品的中间需求之和，与整个国民经济对该产业部门产品的总需求之比 $g_{i}=\sum_{j=1}^{n}x_{ij}/\left(\sum_{j=1}^{n}x_{ij}+Y_{i}\right)$ 。其中， $i(i=1,2,\cdots,n)$ 产业部门需求率越高，则该产业部门对其他部

4. 特定产业需求率。该指标可以反映生产服务业各部门与战略性新兴产业各部门之间的影响力关系。i 产业被 j 产业消耗的中间需求率为 $g_{i-j} = x_{ij} / \sum_{j=1}^{n} x_{ij} + Y_i$ 。其中，i 产业的中间需求率越大，则 i 产业的发展越依赖于 j 产业的中间消费。

5. 融合均衡度。该指标用于反映产业部门之间在中间投入或中间需求关系上的融合均衡程度，指标值越接近1，则产业部门之间的融合均衡程度越强。衡量融合均衡度的指标有两个：一是投入融合度 $F_{ij} = f_{i-j} / f_{j-i}$ ，二是需求融合度 $G_{ij} = g_{i-j} / g_{j-i}$ 。它们分别反映 $i$ 产业与 $j$ 产业彼此之间的特定产业投入率比值和特定产业需求率比值。

## (四) 结论

本文采用投入产出分析法，验算全国及3个省的战略性新兴产业与生产服务业二者融合发展现状，发现二者产业融合不甚显著。这表明二者的需求推动力在当地发展的不一致，产业结构有所失衡，生产服务业的发展依赖于战略性新兴产业的推动，且二者之间的融合性较差。这也侧面反应出我国产业结构层次协调发展失衡的现状，我国仍处于‘重工业、轻服务业’的发展思路中。生产服务业融合力度较弱，也意味着提供核心技术服务的产业发展力度不够。我国要想抢占经济与技术双重制高点，必须借助战略性新兴产业这样一个产业平台向高端制造前进，剥离出具备核心技术竞争力的生产服务业部门，这样才能实现‘中国制造’向‘中国创造’的转变。为此，政府应从宏观环境方面给予一定的支持，推进市场机制、体制的灵活创新与转变，为汇集资本、技术、人才和资源创造良好的制度环境，引导战略性新兴产业与生产服务业的良性融合发展。
