# 中国宏观杠杆率对房地产价格泡沫的非对称动态影响研究

林思涵 陈守东 王 妍

〔摘 要〕 本文从理论上分析资产价格泡沫与金融杠杆之间的定价关系，发现在违约概率为正的前提下，金融杠杆的上升会导致正向资产价格泡沫增大 为验证上述理论结果，本文采用 NARDL 模型实证分析了分部门宏观杠杆率对我国房地产价格泡沫的长 短期非对称影响 实证结果表明，首先，实体经济部门以及金融部门杠杆率的负向调整均会长期有效抑制房地产价格泡沫的持续膨胀，但<sup>“</sup>一刀切<sup>”</sup>的逆周期杠杆调整不利于房地产市场的长期稳定运行，因此应实行差异化的杠杆调控政策<sub>。</sub> 其次，在长期可采用非金融企业部门向居民部门的杠杆转移来实现对房地产价格泡沫的温和平抑作用 再次，应有效合理发挥中央政府杠杆的前瞻指引作用 同时，政策当局不应对地方政府施行强效去杠杆政策，应试图<sup>“</sup>熨平<sup>”</sup>地方政府债务波动以免引发局部房地产价格泡沫风险 最后，就金融部门而言，应对金融部门杠杆进行有效调控，谨防金融资产价格泡沫向房地产价格泡沫转移所引发的房地产市场泡沫风险<sub>。</sub>

## 一<sub>、</sub>引 言

2008 年国际金融危机爆发以来，越来越多的证据表明资产价格泡沫<sub>、</sub>信贷繁荣同金融危机之间存在广泛联系 当<sup>“</sup>信贷繁荣<sup>”</sup>不复存在时，持续的信贷收缩将使得资产价格泡沫化难以为继，而泡沫破灭加之信贷收缩则会导致经济运行中的流动性较为紧张，因此会进一步加剧宏观经济风险( Mishkin，2009) 大量事实表明，金融风险的发生时常伴随着资产价格泡沫的膨胀与破灭，并且由高杠杆驱动的资产价格泡沫的破灭往往会大幅提升金融风险的危害( Mian and Sufi，2009) 例如，以融资融券 场外配资为代表的杠杆资金入市导致的我国2015 年股票市场异常波动，以及由信贷扩张驱动的房地产价格泡沫等，都对我国金融市场以及实体经济构成严重威胁 当前，我国经济正处于国内经济结构调整 疫情后恢复与复杂国际环境多重压力之下 如何调控各经济主体的实际杠杆水平，以促进实体经济发展，并避免引发重大金融危机，是当前我国经济运行亟待解决的重大问题 鉴于此，本文围绕资产价格泡沫与金融杠杆展开研究，详细探讨宏观经济各部门的杠杆调整对资产价格泡沫的影响效应

关于信贷引发资产价格泡沫的理论研究多基于理性泡沫框架( Tirole，1985) 展开<sub>。</sub> 比较有代表性的理论研究围绕着风险转移以及金融摩擦展开 其中，风险转移理论强调由信贷引发的资产价格泡沫的风险转移作用 在包含信贷扩张的资产价格泡沫模型，信贷扩张导致的高杠杆下投资者的风险转移行为会催生资产价格泡沫的产生，而资产价格泡沫的破裂则会引致大量的债务违约( Allen and Gall，2000; Barlev ，2014; Ikeda and Phan，2016) 带有金融摩擦的理论扩展通常基于泡沫资产的可抵押性得以展开 就金融杠杆对实体经济以及金融市场上的影响来看，当投资者面临信贷约束时，若泡沫资产为企业提供信贷抵押，那么该泡沫破裂则会导致严重的经济衰退和资产市场崩盘( Miao and Wan<sub>g</sub>，2018) 虽然资产泡沫的存在可以适当地缓解融资约束所带来的流动性短缺，改善由于信贷约束导致的资源错配，但是资产泡沫的膨胀与破灭又会加大整个金融系统风险，甚至对宏观经济造成威胁( 董丰和许志伟，2020) <sub>。</sub> 适度的金融杠杆有利于实体经济以及金融市场的健康发展，但过度 持续的高杠杆会则诱发严重的资产泡沫化 金融风险以及市场危机，并且会通过 <sup>“</sup>挤出效应<sup>”</sup>等方式影响实体经济发展( Martin and Ventura，2012; 王爱俭和杜强，2017) 强制的<sup>“</sup>去杠杆化<sup>”</sup>过程通过外生地加强债务约束，迫使过度负债的主体代表快速进行去杠杆，会同时对资产价格水平及总需求形成负向冲击( E ertsson and Kru man，2012) 因此金融杠杆的变动是资产价格巨幅波动 资源扭曲配置以及金融风险的重要动因<sub>。</sub> 在实证方面，相关结果也验证了金融杠杆与资产价格之间具有较强相关关系，金融杠杆的大幅扩张使得资产价格暴涨暴跌成为必然( Adrian and Shin，2010) 当过高的金融杠杆超出债务的自身承受能力时，绷紧的债务关系则会在某一薄弱环节崩裂，引致各种形式的金融风险的爆发<sub>。</sub> 而在金融危机发生后，若整个金融<sub>、</sub>经济体进入<sup>“</sup>去杠杆化<sup>”</sup>进程，则有可能导致持续的信贷紧缩以及流动性枯竭( Jordà et al．，2015; Anundsenet al．，2016) 除此之外，金融杠杆对资产价格影响也呈现一定程度的非对称性和非线性，不同部门的杠杆调整对资产价格的影响在强度和方向上均存在较强差异( 刘晓星和石广平，2018)

上述研究在一定程度上揭示了金融杠杆变动与资产价格以及实体经济之间的关系，但由于金融杠杆涉及多个微观部门 种类较多，且不同微观主体的杠杆水平通常具有较大差异，不同的 <sup>“</sup>转移杠杆<sup>”</sup>以及<sup>“</sup>去杠杆<sup>”</sup>手段可能会对资产价格产生不同程度甚至不同方向的影响，因此关于资产价格与金融杠杆是否存在显著的相关关系，以及存在何种相关关系( 线性 非线性) 仍处于开放讨论之中，还未达成理论共识，需进一步进行理论与实证方面的分析 此外，现有研究中，关于资产价格泡沫与金融杠杆的研究多集中于理论分析，关于实证分析的讨论较少，且实证分析多围绕资产价格展开，鲜有涉及资产及价格泡沫 鉴于此，本文首先构建理论模型分析金融杠杆对资产价格泡沫的作用机理，进而阐述二者的定价关系 其次，采用广义右尾 ADF( 简称 GSADF) 模型测算了我国房地产市场的代表性房地产价格泡沫，并在此测算基础上采用非线性分布滞后自回归模型( Nonlinear Auto-Re ressive Distributed La ，简称 NARDL) 模型实证检验了中国分部门宏观金融杠杆对房地产价格泡沫的非对称效应 本文的主要贡献在于: 在以往研究的理论框架下拓展金融杠杆与资产价格泡沫的理论模型，建立二者的理论研究框架;对分部门宏观金融杠杆与房地产价格泡沫的影响关系进行全面 细致分析，以厘清各部门杠杆率对房地产价格泡沫在长 短期内的差异性影响;根据理论以及实证分析结果，给出各部门<sup>“</sup>杠杆转移<sup>”</sup>政策以及<sup>“</sup>去杠杆<sup>”</sup>调控政策的相关建议

本文剩余部分的结构安排如下: 第二部分为理论模型，第三部门为房地产价格泡沫测算，第四部分为数据说明以及实证分析，最后为研究结论

## 二<sub>、</sub>金融杠杆不确定性下的资产定价

在理论分析方面，本文扩展了 Allen and Gale(2000) 的风险转移模型，将其模型中的不确定性来源由资产收益以及可借资金扩展为金融杠杆的随机影响，以此来分析金融杠杆变动 资产定价以及债务违约之间的相互作用<sub>。</sub> 模型的基本假设如下<sub>。</sub>

(1) 假设共有两种资产，分别为无风险资产( 国债或现金) 和风险资产( 股票或房地产) ，每个资产的存续期均为三期 $\mathbf { \zeta } _ { \bullet } t = 0 , 1 , 2$ 时期，其中无风险资产价格为 $P _ { s t }$ ，风险资产价格为 $P _ { R t }$

(2) 存在两类代表性资产投资者 其中，Ⅰ 类投资者在 0 期买入两类资产，在 1 期卖出; Ⅱ 类投资者在1 期买入两类资产，在2 期卖出 $t = 0 , 1$ 时期，无风险资产收益率 $r _ { t }$ ，代表性投资者持有$x _ { S t }$ 单位无风险资产与 $x _ { R t }$ 单位风险资产 每期因风险资产交易而产生的交易成本为 $c ( \ v { x } _ { R t } )$ ，成本函数满足了通常的新古典主义性质，即对于所有的 $x > 0$ $c \left( \begin{array} { l } { x } \end{array} \right) \ > 0 , c ^ { \prime \prime } { \left( \begin{array} { l } { x } \end{array} \right) } \ > 0 , c { \left( \begin{array} { l } { 0 } \end{array} \right) } \ = c \cdot { \left( \begin{array} { l } { 0 } \end{array} \right) } \ = 0$ 。

(3) 投资者是风险中性的 $\mathbf { \Omega } _ { \mathfrak { s } { t } } = 0 , 1$ 时期，投资者拥有自有资金 $A _ { t }$ ，也可以通过向金融机构借款$B _ { t }$ 进行两种资产的投资，因此投资者的金融杠杆 $l _ { t } = B _ { t } / A _ { t }$ 在 t1 期引入杠杆不确定性，将 $l _ { 1 }$ 定义为 $\mathbb { b } , l _ { m a x 1 } ]$ 上的随机变量，其密度函数为连续密度函数 $h { \left( \ l _ { 1 } \right) }$ ，设定 t2 风险资产的价格可以表达为$P _ { { \scriptscriptstyle R } 2 } \big ( l _ { 1 } \big )$ 。

由此可得，当 $1 > P r \big ( \textit { l } _ { 1 } < \textit { l } _ { 1 } ^ { * } \big ) > 0$ 时，即存在违约的概率大于 0 情形下，则有 $P _ { B u b b l e 0 } > 0$ 严格成立 此处的投资者违约可以理解为，当1 期积极的信贷扩张无法继续保持，导致1 期风险资产价格的下降，风险资产价格的降低导致投资者无法支付0 期借款，进而导致违约 该违约导致0 期风险资产价格被高估进而产生资产价格泡沫 若后续2 期的信贷扩张继续收缩，无法支持资产价泡沫的存续，则会导致资产价格泡沫的破灭，进而出现金融危机

## 三<sub>、</sub>中国房地产市场资产价格泡沫测度———基于 GSADF 模型

## ( 一) GSADF 模型

本文采取 Philli<sub>p</sub>s et al． (2015) 提出的 GSADF 检验程序对中国房地产市场资产价格泡沫进行测算 该检验的原假设是 <sup>“</sup>中国房地产市场的资产价格序列为单位根序列( 无资产价格泡沫) <sup>”</sup>，备择假设是<sup>“</sup>中国房地产资产价格序列为爆炸序列( 存在资产价格泡沫) <sup>”</sup> ADF 单位根检验的回归方程为

$$
\Delta y _ {t} = \alpha + \beta y _ {t - 1} + \sum_ {i = 1} ^ {K} \gamma_ {i} \Delta y _ {t - i} + \varepsilon_ {t}\tag{12}
$$

其中 $\mathbf { \bullet } _ { \bullet } \mathbf { \^ { \prime } } _ { t }$ 是 t 时刻的资产价格序列，K是滞后阶数( 在应用中设为5) ， $\bullet \varepsilon _ { t }$ 是误差项 原假设为 $\beta = 0$ ，备择假设为 $\beta > 0$ ADF 统计量被定义为 $\beta$ 的最小二乘估计的 t 值

GSADF 检验需要进行子样本回归 其目的是考虑样本期内任何潜在的结构突变或状态转移已知全部样本长度为 $T _ { \mathfrak { s } }$ ，设 <sub>r</sub> 为样本长度分数变量，且有 $t = ~ \left[ T r \right]$ ］，即时点 t 是［T<sub>r</sub>］的整数部分<sub>。</sub> 现假设 $\begin{array} { r l } { \pmb { \mathscr { t } } _ { 1 } = } & { { } \pmb { \mathbb { U } } r _ { 1 } \mathbf { ] } } \end{array}$ ］和 $t _ { 2 } = ~ \mathsf { [ } T _ { 2 } ]$ 是子样本回归的起点和终点，相应的 ADF 统计量表示为 $A D F _ { r _ { 7 } } ^ { r _ { 1 } }$ <sub>。</sub> 首先固定子样本起点 $r _ { 1 }$ ，逐步向前递归改变样本终止点 $r _ { 2 }$ 位置 ${ \bf \Omega } _ { \bullet } r _ { 2 } \in \ \left[ { \bar { \bf \omega } } _ { 0 } , 1 \right]$ ，进而得到向前ADF 统计量序列，对其取上确界得到 SADF 统计量<sub>。</sub> 然后，依次改变样本初始点 $r _ { 1 }$ ，得到向后 SADF 统计量序列，对该 SADF 统计量序列取上确界，得到 GSADF 统计量<sub>。</sub> 其中 $r _ { 0 }$ 是启动回归所需的最小窗口<sub>。</sub>

对于实际应用，参考 Philli<sub>p</sub>s et al． ( 2015) 研究根据 $r _ { 0 } = 0 . 0 1 + 0 . 8 / \sqrt { 7 }$ 的原则来设置 $r _ { 0 }$ ，以降低尺寸失真的概率<sub>。</sub> 在所有可行域上关于 $r _ { 1 }$ 和 $r _ { 2 }$ 广义双侧倒向滚动回归的 $\mathrm { s u p \mathrm { \ - A D F } }$ 统计量记为$G S A D F { ( \ r _ { 0 } ) }$ 如公式(13) 所示，其渐进极限分布如公式(14) 所示<sub>。</sub>

$$
G S A D F \left(r _ {0}\right) = \sup _ {r _ {2} \in [ r _ {0}, 1 ]} ^ {r _ {1} \in [ 0, r _ {2} - r _ {0} ]} \left\{A D F _ {r _ {2}} ^ {r _ {1}} \right\} = \sup _ {r _ {2} \in [ r _ {0}, 1 ]} \left\{B S A D F _ {r _ {2}} \left(r _ {0}\right) \right\}\tag{13}
$$

$$
\sup _ {r _ {2} \in [ r _ {0}, 1 ]} ^ {r _ {1} \in [ 0, r _ {2} - r _ {0} ]} \left\{\frac {\frac {1}{2} r _ {w} \left[ W (r _ {2}) ^ {2} - W (r _ {1}) ^ {2} - r _ {w} \right] - \int_ {r _ {1}} ^ {r _ {2}} W (r) d r \left[ W (r _ {2}) - W (r _ {1}) \right.}{r _ {w} ^ {1 / 2} \left\{r _ {w} \int_ {r _ {1}} ^ {r _ {2}} W (r) ^ {2} d r - \left[ \int_ {r _ {1}} ^ {r _ {2}} W (r) d r \right] ^ {2} \right\} ^ {1 / 2}} \right\}\tag{14}
$$

其中， ${ | \cal { W } | } \cdot  | \cal $ 表示维纳过程， $\bullet ^ { r } { } _ { u }$ 为窗宽<sub>。</sub>

相应地，采用 GSADF 方法进行泡沫周期进行测算的策略为倒向滚动递归策略( 见图 1) ，即首先确定子样本回归终止点 $r _ { 2 }$ ，向后滚动递归样本初始点 $r _ { 1 }$ ，其中 $r _ { 1 } \in \ \mathsf { \Omega } [ 0 , r _ { 2 } - r _ { 0 } ]$ ，得到的 ADF 统计量记作 $B S A D F _ { r _ { 2 } } ( { \bf \Omega } r _ { 0 } )$ ，其与 GSADF 统计量的关系如公式(16) 所示

$$
B S A D F _ {r _ {2}} \left(r _ {0}\right) = \sup _ {r _ {1} \in [ 0, r _ {2} - r _ {0} ]} \left\{A D F _ {r _ {2}} ^ {r _ {1}} \right\}\tag{15}
$$

$$
G B S A D F \left(r _ {0}\right) = \sup _ {r _ {2} \in [ r _ {0}, 1 ]} \left\{B S A D F _ {r _ {2}} \left(r _ {0}\right) \right\}\tag{16}
$$

依次向前递归结束子样本终止点 <sub>r</sub> ，进而到得 $r _ { 2 }$ $B S A D F _ { r _ { 2 } } \left( \mathrm { \Delta } r _ { 0 } \right)$ 统计序列<sub>。</sub> 该方法识别泡沫区间的内在逻辑在于，当 $B S A D F _ { r _ { 2 } } ( { \bf \Omega } r _ { 0 } )$ 首次超出临界值时，将该时点视作一个泡沫区间的初始点，其后超出临界值时点视作该泡沫区间的结束时点，由此得到一个泡沫周期 起止时间分别为公式(17)和( 18) 所示

$$
\hat {r} _ {e} = \inf _ {r _ {2} \in [ r _ {0}, 1 ]} \left\{r _ {2}: B S A D F _ {r _ {2}} > s c v _ {r _ {2}} ^ {\beta_ {T}} \right\}\tag{17}
$$

$$
\hat {r} _ {f} = \inf _ {r _ {2} \in [ r _ {e} + \delta \log (T) / T, 1 ]} \left\{r _ {2}: B S A D F _ {r _ {2}} <   s c v _ {r _ {2}} ^ {\beta_ {T}} \right\}\tag{18}
$$

其中 $s c v _ { r _ { 2 } } ^ { \beta _ { T } }$ 为 BSADF 统计量的 $1 0 0 \bigl ( \mathrm { ~ 1 ~ } { - } \beta _ { T } \bigr )$ %临界值 ${ \mathfrak { s r } } _ { e }$ 为泡沫周期的初始时点 ${ \bullet }  { \boldsymbol { r } } _ { f }$ 为泡沫周期的结束时点 由于房地产价格数据的一个显著特征是条件或无条件异方差 因此本文采用随机自举的方法来获得有限样本临界值 该方法可以复制原始冲击中的异方差模式，因此有望减少尺寸失真的可能性<sub>。</sub> 本文以 GSADF 方法来识别资产价格泡沫区间，并以统计序列 $B S A D F _ { r _ { 2 } } ( { \bf \Omega } r _ { 0 } )$ 来衡量资产价格泡沫规模，该统计序列值的上升，代表泡沫规模的增大

## ( 二) 模型设定

本部分着重考察各部门杠杆率动态调整对资产价格泡沫的非对称影响 基于此，本文采用Shin et al． ( 2014) 提出的 NARDL 模型进行实证分析，相比于 ARDL 模型，NARDL 模型在非线性误差修正模型的基础之上以分布滞后自回归模型形式进行建模，该模型通过对解释变量进行长期和短期正负分解，进而考察解释变量对被解释变量的长 短期非对称影响

模型的具体形式如下

$$
\Delta y _ {t} = \rho y _ {t - 1} + \theta^ {+} x _ {t - 1} ^ {+} + \theta^ {-} x ^ {-} + \sum_ {i = 1} ^ {p - 1} \varphi_ {i} \Delta y _ {t - i} + \sum_ {i = 1} ^ {p - 1} \left(\pi_ {i} ^ {+} \Delta x _ {t - i} ^ {+} + \pi_ {i} ^ {-} \Delta x _ {t - i} ^ {-}\right) + e _ {t}\tag{19}
$$

其中 $\boldsymbol { y } _ { t }$ 为被解释变量 ${ \bf \Pi } _ { \pmb { \sigma } } x _ { t }$ 为解释变量 $\bullet p$ 为滞后阶数， $\bullet { x _ { t } } ^ { + }$ 是 $x _ { t }$ 的长期正向累计增量 $\bullet x _ { t } ^ { - }$ 是 $x _ { t }$ 的长期负向累计增量，

$$
x _ {t} ^ {+} = \sum_ {j = 1} ^ {t} \Delta x _ {j} ^ {+} = \sum_ {j = 1} ^ {t} \max (\Delta x _ {j}, 0), x ^ {-} = \sum_ {j = 1} ^ {t} \Delta x _ {j} ^ {-} = \sum_ {j = 1} ^ {t} \min (\Delta x _ {j}, 0) _ {t}\tag{20}
$$

${ \Delta x _ { j } } ^ { + }$ 为短期正向增量， $\Delta \boldsymbol { x } _ { j } ^ { - }$ 为短期负向增量，且 $x _ { t } \ = \ x _ { t } ^ { \ + } \ + \ x _ { t } ^ { \ - \ + x _ { 0 } }$ <sub>。</sub> 其中， $, \rho , \theta ^ { \scriptscriptstyle + } , \theta ^ { \scriptscriptstyle - } , \varphi _ { i } , \pi _ { i } ^ { \scriptscriptstyle + }$ $\pi _ { i } ^ { - ( i = 1 , 2 , \cdots p - 1 ) }$ 分别为被解释变量滞后一阶系数，解释变量长期正<sub>、</sub>负向累计增量系数，被解释变量 i步一阶差分滞后项系数，解释变量短期正<sub>、</sub>负向短期增量系数<sub>。</sub> $e _ { t }$ 为随机扰动项，服从均值为0，方差为Σ正态分布<sub>。</sub>

当对 ${ x _ { t } } ^ { + }$ 或 $\boldsymbol { x } _ { t } ^ { - }$ 分别施加单位冲击时 $\mathbf { \bullet } _ { \bullet } \mathbf { \mathcal { Y } } _ { t }$ 的累积脉冲响应乘子如式(21) 所示

$$
m _ {h} ^ {+} = \sum_ {j = 0} ^ {h} \frac {\partial y _ {t + j}}{\partial x _ {t} ^ {+}}, m _ {h} ^ {-} = \sum_ {j = 0} ^ {h} \frac {\partial y _ {t + j}}{\partial x _ {t} ^ {-}}, h = 1, 2, \dots\tag{21}
$$

Shin et al． ( 2014) 证明当 $h { \longrightarrow } \infty$ 时 $m _ { h } ^ { \textrm { + } } \longrightarrow - \theta ^ { \textrm { + } } / \rho = \beta ^ { \textrm { + } } , m _ { h } ^ { \textrm { - } } \longrightarrow - \hat { \theta } ^ { \textrm { - } } / \rho = \beta _ { h } ^ { \textrm { - } } , \beta ^ { \textrm { + } }$ <sup>+</sup> 与 $\beta ^ { - }$ 分别表示 $\boldsymbol { y } _ { t }$ 与 $x _ { t }$ 的长期协整关系，

通过对长期累积增量与短期增量施加不同的约束，我们可以进行如下四种模型选择:

(1) 长期和短期非对称形式( AA) ，即不施加约束形式;

(2) 长期对称与短期非对称形式( SA) ，即施加长期约束: $\beta ^ { + } = \beta ^ { - }$ ;

(3) 长期非对称与短期对称形式( AS) ，即施加短期约束: $\pi _ { i } ^ { + } = \pi _ { i } ^ { - } , i = 1 , 2 , \cdots , p - 1 \rangle$ ;

(4)长期和短期对称形式(SS)，即同时施加长期约束 ${ B ^ { \prime } } ^ { * } = \beta ^ { - }$ <sup>－</sup>与短期约束 $\pi _ { i } ^ { + } = \pi _ { i } ^ { - } , i = 1 , 2 , \cdots , p - 1 \rangle$ 。

结合模型估计结果与检验结果，我们对上述四类模型进行比较，进而选取较为符合经济意义同时具有较好统计意义的实证模型

这主要由于，地方政府的财政收入大部分上收中央政府，为缓解地方财政紧张状况，地方政府通过多种方式进行融资以保证财政收支平衡 其中，重要的融资方式即为出让土地，依靠出让土地来缓解债务问题 而土地出让与房地产价格泡沫息息相关，当政府杠杆率处于较高水平时，其出让土地的总量则会显著上升，土地供应的上升会大幅促进房地产行业的繁荣发展，尤其是我们研究样本中的一线城市多处于买方市场，在房地产市场供求不均的前提下，导致地方政府对土地财政的依赖程度与房地产价格泡沫正相关，因此地方政府杠杆的正向增加均会导致房地产价格泡沫的显著上升 而地方政府债务长期减少所引起的房地产价格泡沫小幅上升的内在逻辑体现在，当地方政府债务负担减少时，其土地出让总量降低，在供求平衡的房地产市场中，土地出让的减少会导致房地产供给减少，进而抬升房地产价格，滋生房地产价格泡沫 因此在治理房价泡沫的过程中，地方政府部门杠杆调整的关键在于降低地方政府的杠杆波动，避免大幅度杠杆调整导致的房价泡沫破灭

从上述实体经济部门的杠杆调控效应来看，合理控制实体经济部门整体杠杆率水平以及非金融企业部门杠杆率水平，是控制房地产市场价格泡沫的有效手段 而鉴于房地产价格泡沫对居民杠杆调整的剧烈反应，在进行居民杠杆调整时，应谨防强力去杠杆所引发的资产价格泡沫崩溃 由于房价泡沫对居民部门加杠杆政策敏感性较低，因此可以通过实行宏观经济杠杆向居民部门的转移的方式实现抑制泡沫的效果 此外就政府部门而言，鉴于中央政府对资产价格泡沫的杠杆影响具有的典型对称性特征，因此应发挥中央政府杠杆的信号作用 此外，<sup>“</sup>熨平<sup>”</sup>地方政府债务波动是将房地产泡沫控制在合理运行区间的有效手段

如表4 所示，模型7 和8 中均为金融部门杠杆率对房地产价格泡沫的回归结果 两者核心解释变量的区别在于统计口径的不同，但二者在总量上以及趋势上存在相似性，本部分重点分析模型7 的回归结果<sub>。</sub> 从系数估计结果来看，在模型7 中，金融部门杠杆率的长期正向影响系数为0. 225，长期负向影响系数为0. 425<sub>。</sub> 该结论表明，金融部门杠杆水平对房地产价格泡沫的长期影响的非对称性整体弱于实体经济 首先，金融体系的高杠杆增加其内部流动性，使得以股票为代表性的金融资产价格出现非理性繁荣，这间接导致上市的非金融性公司的价值虚增，进而导致流动性进入房地产部门，最终实现金融资产价格泡沫向房地产价格泡沫转移<sub>。</sub> 其次，当传统的金融资产，如股票<sub>、</sub>债券等无法完全消化金融部门的流动性时，剩余流动性则会流入房地产市场中，此时则体现了房地产市场的金融属性<sub>。</sub> 因此通过上述两种途径可知，金融部门杠杆率的上升导致房地产市场价格泡沫的积聚 此外，相比于房地产价格泡沫的上升机制，其下降机制中的斜率更为陡峭，即当金融部门进入去杠杆周期时，房地产市场价格泡沫会同实体经济一样会经历巨幅下跌<sub>。</sub>

## ( 四) 金融杠杆的动态效应分析

图2 至图4 为依据公式(21) 计算得到的累计脉冲响应图，累计脉冲响应滞后期设为60 期 本部分以脉冲响应乘子曲线的波动性来衡量宏观杠杆冲击的不确定性，以其斜率来衡量资产价格泡沫对宏观杠杆非对称变动的反应速度，以其变化幅度和方向等特征来描述房地产价格泡沫收敛均衡状态的动态路径

实体经济部门杠杆率与其所包含的居民部门 非金融企业部门以及政府部门杠杆率对房地产价格泡沫的累计脉冲响应如图2 所示<sub>。</sub> 首先，实体经济部门杠杆率的正向冲击对房地产价格泡沫具有持续正向影响，且该累计脉冲响应曲线的斜率未随滞后期的变化而发生显著变化，由此可见，面对正向的实体经济部门杠杆冲击，房地产价格泡沫长期保持匀速上涨态势<sub>。</sub> 而当面对负向实体经济部门杠杆冲击，资产价格泡沫的反应速度显著快于正向冲击，该动态乘数随滞后期的增加而较快的下降至最低点( 滞后10 期) ，随后达到均衡，并维持高位运行状态( 见图 A － 实体经济部门) <sub>。</sub>这一结果证实，负向的实体经济部门杠杆冲击会导致房地产价格泡沫的快速收缩甚至致其破灭，因此当经济体中出现大规模的房价泡沫时，企图通过整体降低实体经济部门去杠杆方式得以实现，需谨慎掌握政策强度以防非对称性冲击影响所带来得恶性后果<sub>。</sub>

最后，不同于上述三种部门杠杆率冲击影响，政府部门杠杆率的正向冲击会导致房地产价格泡沫长期维持低位负值运行收敛于 －0.2 附近，即房价泡沫小幅收缩 而其负向冲击则会引起房地产价格泡沫长期上涨，上涨幅度收敛于0.5 附近( 见图 D －政府部门) 该结论表明政府部门的杠杆冲击效应与上述三类杠杆方向相反，但其正负冲击同样呈现较强的非对称性影响<sub>。</sub> 长期来看，若政府部门进入去杠杆阶段，则会导致房价泡沫的大幅度上升

## 五<sub>、</sub>研究结论

本文构建了金融杠杆不确定性下的资产定价的理论模型，通过分析金融杠杆调整对资产价格定价偏差的影响，发现在违约概率大于0 的情况下，金融杠杆的存在会导致资产价格出现正向资产价格泡沫 为验证上述理论结论，本文通过构建 NARDL 模型分析了不同部门的宏观金融杠杆对资产价格泡沫的差异性影响<sub>。</sub>

在构建实证模型之前，本文采用了 GSADF 方法测算了中国房地产市场的代表性房地产价格泡沫，该代表性房地产价格泡沫集中反映了以北京 上海 深圳 天津 广州为代表的五个一线城市的房价泡沫的整体情况<sub>。</sub> 测算结果表明，2009 年11 月至今，我国一线城市房地产市场共发生 4 次房地产泡沫集聚与破灭过程，且从泡沫的持续时长和收缩幅度来看，整体上我国房价泡沫呈现自我累积的正反馈特征
