# 户籍的代际关联<sub>、</sub> <sup>“</sup>农转非<sup>”</sup>与长期人力资本

高跃光 冯 晨 唐 雅

内容提要 实现城乡统筹发展是全面建成小康社会的内在要求，其中的重要途径之一是缩小城乡间人力资本差距 本文基于 <sup>“</sup>农转非<sup>”</sup>落户这一政策背景，考察城乡户籍差异对人力资本积累的影响 研究发现，符合 <sup>“</sup>农转非<sup>”</sup>条件且实现了<sup>“</sup>农转非<sup>”</sup>的个体，其受教育年限有普遍增长<sub>。</sub> 本文的研究反映了城乡户籍制度下教育公共服务存在的问题，对于完善户籍制度改革 推进城乡统筹发展具有一定的指导意义<sub>。</sub>

关 键 词 城乡户籍 <sup>“</sup>农转非<sup>”</sup> 人力资本

## 一 引言

城乡统筹发展是全面建设小康社会的重要任务，党的十九大报告将缩小城乡差距作为基本实现社会主义现代化的重要内容 然而，中国长期存在以城乡二元分割为特征的户籍制度，扩大了农村与城镇地区公共服务的差距，严重影响城乡统筹发展 户籍制度是中国一项特有的制度安排( 蔡昉和都阳，2003; 陆益龙，2003) ，自 1955 年中国建立对农业与非农业人口分别管理的制度以来，学术界与政策界就特别重视其社会与经济效应( 李春玲，2003; 陆益龙，2008; Chen <sub>e</sub>t <sub>a</sub>l. ，2019) 不可否认的是，在实施户籍人口划分的初期，城乡二元分割有效缓解了城市公共服务供给的不足和外来人口的安置压力，在一定程度上有助于社会稳定与国民经济发展 但是，随着经济社会的持续进步，固化的城乡二元分割阻碍了生产要素的自由流动 而且，社会福利制度也与户籍制度紧密相关，特有的福利保障主要由城镇地区的非农业户口受益，如非农业户口受益于粮票制度而享受相对较低的粮食价格，受益于工作分配制度而享受相对优越的工作条件，此外还享受良好的医疗保障 公共教育 住房等等<sub>。</sub> 显然，城乡户籍的受益差异将加剧城乡间发展的不均衡<sub>。</sub>

人力资本的均衡发展是缩小城乡差距的必要条件，人力资本的提高又依赖教育投入( 舒尔茨，1990) ，尤其是政府的教育投入( Fernández and Rogerson，1998) 但城乡二元分割导致教育公共服务的不均衡，大量的优质教育资源在城镇地区集聚，而且还存在偏向于城市的教育经费投入政策( 陈斌开等，2010) 因此，城镇地区的良好教育条件为非农业户口居民的人力资本提升奠定了基础，这也就呼应了相关研究结论，即中国人力资本在不断提升，但城乡人力资本差距依然在扩大( Brown and Park，2002;Connelly and Zheng，2007) ，这显然不利于城乡收入差距的缩小( 郭剑雄，2005; Raval-lion and Chen，2007) 要实现城乡统筹发展，需要在人力资本层面清晰识别农业户口与非农业户口居民的人力资本差距，进而为科学制定政策提供数据支持<sub>。</sub>

现有关于城乡问题的文献侧重研究城乡收入差距( Yang，1999; 蔡昉和杨涛，2000;陆铭和陈钊，2004;沈坤荣和张璟，2007; 陈斌开和林毅夫，2013; 万海远和李实，2013) 和城乡人口流动( 李实，1999; 李强，2003; Whalley and Zhang，2007; 孙文凯等，2011) 等问题 同时，还有学者注重研究劳动力市场中的户籍歧视问题，如姚先国和赖普清( 2004) 余向华和陈雪娟( 2012) 吴晓刚和张卓妮( 2014) 吴贾等( 2015) 均认为城乡户籍的不同劳动者面临不同的工资决定机制，农业户口劳动者工资待遇更低，就业机会更少 陈钊等(2009) 研究发现非农业户口的劳动者更有可能进入高收入行业因此，户籍由农业转换为非农业就显得颇具吸引力，因为户籍转换带来的收益也是可观的，主要表现为社会经济地位的提升，从事管理 技术类职业的机会也会显著增加( 谢桂华，2014) 实践中甚至出现了变相买卖非农业户口的现象(陆益龙，2008)

现有研究较少关注户籍制度导致的长期人力资本差异，李春玲(2003) 认为户籍身份能够使非农业户口居民获得更好的教育机会 但受数据的限制，现有研究并未识别户籍差异导致城乡人力资本差距的因果效应 1998 年国务院批转了公安部 《关于解决当前户口管理工作中几个突出问题意见的通知》，其中规定了落户随父随母自愿的政策，即允许符合条件的个体由农业户口转换为非农业户口，这为识别户籍对人力资本的因果效应提供了条件<sub>。</sub> 我们以2010 年人口普查数据为基础，根据个体的出生年月以及与父母的户籍关联来识别户口性质的转换，进而观察农业与非农业户口居民的长期人力资本差异本文研究发现，实现农业户口转换为非农业户口的个体，其受教育年限平均提升2 年左右

与现有文献相比，本文的贡献主要在于识别策略方面的创新，以往的研究虽然涉及农业与非农业户口居民间的人力资本差距，但并未识别其因果效应 本文利用落户随父随母自愿政策这一外生冲击，使用模糊断点回归法在微观层面识别了农业户口与非农业户口居民的长期人力资本差距，并从多个角度验证了该识别策略的稳健性，这为完善户籍制度改革以及统筹城乡发展提供了基础数据支持

## 二 政策背景

1977 年国务院批转 《公安部关于处理户口迁移的规定》，首次提出 <sup>“</sup>农转非<sup>”</sup>的概念<sub>。</sub> 1980 年以后国家对<sup>“</sup>农转非<sup>”</sup>的限制有所放松，但 <sup>“</sup>农转非<sup>”</sup>仍然被限定在职工家属两地分居 升学或国家工作安排需要等情形<sub>。</sub> 公安部还出台了相关措施以控制 <sup>“</sup>农转非<sup>”</sup>规模，为不同地区在不同时间设定不同的 <sup>“</sup>农转非<sup>”</sup>指标

<sup>“</sup>农转非<sup>”</sup>不仅表现为户口性质在城乡间的转换，还表现为户口性质在代际间的关联 具体来说，1982 年国务院批转了公安部 《关于解决有关农村落户问题的请示的通知》，其中规定了新生婴儿随母落户的原则，即不论新生婴儿出生地在哪里，都应在其母常住户口所在地申报出生登记;还规定凡是没有落户或随母被注销户口的，应由其母原常住户口所在地办理入户手续 因此，母亲的户口性质决定了子代的户口性质 如果母亲是农业户口，则子代也是农业户口;如果母亲是非农业户口，则子代也是非农业户口<sub>。</sub>

不可忽视的是，户籍对城乡通婚会带来显著影响，进而不利于解决家属分居以及子女投靠等需求 为改革户籍制度存在的弊端，1998 年国务院批转了公安部 《关于解决当前户口管理工作中几个突出问题意见的通知》( 国发 〔1998〕 24 号) ，规定了婴儿落户随父随母自愿的政策，从1998 年7 月22 日( 含当天) 起，新生婴儿既可以在父亲也可以在母亲常住户口所在地申报常住户口 其中以下情形可以本着在常住地登记户口的原则解决在城市落户问题: (1) 1998 年7 月22 日以后出生已经随母登记常住户口，现要求迁往父亲常住户口所在地落户的;(2) 对1998 年7 月22 日以前出生尚未落常住户口的;(3) 对1998 年7 月22 日以前出生已经随母在农村落户 尚未成年且要求随父迁往城市落户的 在具体实施过程中，对学龄前儿童优先予以解决，而且还对夫妻分居 父母投靠子女 城乡通婚等户籍迁移提供便利

国发 〔1998〕24 号文件的第(3) 条为符合转换条件的个体实现 <sup>“</sup>农转非<sup>”</sup>提供了机会<sub>。</sub> 具体而言，如果母亲为农业户口而父亲为非农业户口，按照随母落户的原则子代基本都是农业户口 但是，该文件第(3) 条为符合条件的未成年群体转换户籍提供了政策依据，即如果母亲为农业户口而父亲为非农业户口，且子代在 1998 年 7 月 22 日( 含) 尚未成年，那么子代就可以转换为非农业户口

城镇地区的教育资源优于农村地区，在相当长时期内技校 中专等仅面向非农业户口招生，部分大专学校的招生也是以非农业户口居多( 陆益龙，2003) 因此，该文件第(3) 条为符合条件的子代提供了转换户口并在城镇地区接受教育的可能，进而也为其提升人力资本提供了可能<sub>。</sub>

## 三 识别策略<sub>、</sub>数据与变量选取

## ( 一) 识别策略

本文使用的微观数据主要来自2010 年人口普查，该普查是以家庭为单位，包含家庭内部的个人信息 数据的筛选与处理步骤如下: 第一，为分析户籍的代际关联，仅保留户主 配偶与子代三类人员信息;第二，由于户主并非总是男性，因此根据户主和配偶的性别，分别处理后再匹配出子代的父亲与母亲的信息;第三，为了清晰识别户籍制度的作用，并且使得宏微观数据能够匹配，个体所属地区均以户口登记地为准 此外，为了数据的可比性，排除尚在校学习的人口样本

根据本文的研究目的，借鉴 Zhang <sub>e</sub>t <sub>a</sub>l. (2018) 的识别策略，采取模糊断点回归( fuzzy-RD) 框架下的工具变量法来识别 <sup>“</sup>农转非<sup>”</sup>对个体人力资本积累的长期影响个体的户籍性质与其长期人力资本的关系可以用如下第二阶段回归式表示:

$$
Y _ {-} e d u _ {i, c, t} = \alpha + \beta h u k o u _ {i, c, t} + f (d i s \_ m o n t h _ {t} ^ {1 9 8 0 0 8}) + \varphi X _ {i, c, t} + \omega_ {c} + \varepsilon_ {i, c, t}\tag{1}
$$

其中，i 表示( 子代) 个体 $_ { \pmb { \mathscr { S } } } \pmb { \mathscr { C } }$ 表示县( 市 区) $\mathbf { \Omega } _ { \mathbf { \Omega } } \mathbf { \Omega } _ { \mathbf { \Omega } } \mathbf { \Omega } _ { \mathbf { \Omega } } t$ 表示出生年月; $Y _ { - } e d u _ { i , c , t }$ 代表个体的长期人力资本水平; $h u k o u _ { i , c , t }$ 表示个体当前的户口性质，如果是非农业户口则取 1，否则取 $0 ; { \mathcal { f } } { \big ( } d i s \_ m o n t h _ { t } ^ { 1 9 8 0 0 8 } { \big ) }$ 则表示驱动变量的高阶项<sup>①</sup>，di<sub>s</sub>\_<sub>mon</sub>th 表示个体出生年月到1980 年8 月的相隔月份距离; $X _ { i , c , i }$ 表示其他可能影响本文结果的控制变量 ${ \bullet } \omega _ { c }$ 表示地区固定效应( 市级层面) ，<sub>ε</sub> 表示随机扰动项 户口性质的回归系数 $\mathbf { \Omega } _ { \bullet } \varepsilon _ { i , c , t }$ $\beta$ 反映了农业户口与非农业户口个体的长期人力资本差异<sub>。</sub>

要识别农业户口与非农业户口的长期人力资本差异，需要寻求一个相对外生的政策冲击，从而排除其他影响因素的干扰 我们在识别方面引入了工具变量，以尽可能地识别<sup>“</sup>农转非<sup>”</sup>的因果效应，而该工具变量的核心思想在于识别个体是否以及能否实现<sup>“</sup>农转非<sup>”</sup> 根据政策规定我们可以得出两个结论: 一是个体能否实现 <sup>“</sup>农转非<sup>”</sup>依赖于户籍的代际关联，如果父亲是非农业户口，而母亲是农业户口，则子代个体就具有实现<sup>“</sup>农转非<sup>”</sup>的可能性; 二是个体能否实现 <sup>“</sup>农转非<sup>”</sup>还有时间限制，即必须是1980 年7 月22 日以后出生的个体才适用 因此，我们基于上述两个结论构造工具变量，如果出生时间晚于1980 年8 月<sup>①</sup>，且父亲是非农业户口 母亲是农业户口，则视为能够受益于该政策的群体，并对工具变量赋值为1;相反，如果出生时间早于1980 年8月，且父亲与母亲均为农业户口从而不具备户籍转换条件，则工具变量赋值为0

上述处理也可以排除其他原因导致的户籍转换，因为个体当时处于未成年时期，尚不能独自做出<sup>“</sup>农转非<sup>”</sup>的判断或决策，需要依赖父母的干预( 在回归中也控制了父母的因素) ，或者说父母的户籍状况相对于个体而言是外生的 而且，因为政策限定的个体均属于未成年时期，很难因为就业<sub>、</sub>结婚<sub>、</sub>上大学等原因转换户口性质<sub>。</sub> 因此，我们采取 fuzzy-RD 方法，以政策变革为外生冲击，在一阶段回归中识别其对个体现有户籍的影响 采用 fuzzy-RD 方法的原因在于，出生于该时点之后的农村个体只是在一定程度上具有<sup>“</sup>农转非<sup>”</sup>的概率，而并不一定会采取 <sup>“</sup>农转非<sup>”</sup>行动，于是我们引入上文构造的工具变量<sub>。</sub> 一阶段回归方程式如下:

$$
h u k o u _ {i, c, t} = \alpha + \beta \text { eligibility } _ {i, c, t} + f (\text { dis\_month } _ {t} ^ {1 9 8 0 0 8}) + \varphi X _ {i, c, t} + \omega_ {c} + \varepsilon_ {i, c, t}\tag{2}
$$

其中，被解释变量 $h u k o u _ { i , c , t }$ 为个体现在的户籍类型; $e l i g i b i l i t y _ { i , c , i }$ 是核心解释变量，表示子代根据其出生时间与父母户口性质判别得到是否符合 <sup>“</sup>农转非<sup>”</sup>的条件，如上文所述，如果父亲是非农业户口 母亲是农业户口并且在 1980 年 8 月及以后出生，则设为1，如果父母均为农业户口且在1980 年8 月以前出生，则设为0<sub>。</sub>

## 四 经验分析结果

## ( 一) 基准回归检验

## 五 户籍影响人力资本差异的渠道

人力资本依赖于政府对教育的投入( Kotera and Seshadri，2017) ，而地方政府在提供教育公共产品时，面临供给成本与经济产出两方面的权衡 即在农村地区提供教育公共产品的成本相对较高，经济产出能力相对较低;而城镇地区的供给成本相对较低，且还具有集聚效应，进而教育为地方政府带来更多的收益 这不可避免地导致地方政府的教育经费向城市倾斜( 陈斌开等，2010) 城镇与农村地区人力资本差异的主要来源是教育公共服务供给的数量与质量 因此，为分析 <sup>“</sup>农转非<sup>”</sup>如何实现长期人力资本的提升，我们检验<sup>“</sup>农转非<sup>”</sup>的个体能否获得较好的教育公共服务 具体数据主要来源于中国教育追踪调查( China Education Panel Survey，CEPS) ① 本文以 2013－2014 年基线调查数据为主，在个体层面进行反映非农业户口与农业户口个体差异的均值检验，以观察二者接受的教育公共服务的差异<sub>。</sub> 表8 从以下6 个方面展开分析:

第三，教师队伍质量 高质量的教师队伍对于学生的长期人力资本发展具有重要作用，而高质量的教师一般集中于城镇地区，<sup>“</sup>农转非<sup>”</sup>则为个体接受高质量的教育奠定了基础 我们以 CEPS 问卷中各学校高级职称教师占比来表示其教师队伍质量，可以发现两组的差分结果显著为正，说明非农业户口的学生拥有更高质量的教师队伍

第四，教师队伍流失问题 一般而言，高质量的学校会集聚高质量的教师队伍，部分质量较低的学校会面临高质量教师的流失 如果学校存在教师流失问题则教学质量会下降，进而不利于长期人力资本的培养 我们以学校在未来五年是否担心教师流失来进行测度，具体设非常担心为1，有些担心为2，不怎么担心为3，完全不担心为4，数值越大说明学校的高质量教师队伍越有保证<sub>。</sub> 结果显示，两组的差分结果显著为正，说明农业户口的学生所在学校的教师流失问题更严重，教师队伍更不稳定<sub>。</sub>

第五，家长的人力资本 高质量的学校可能还集聚着高人力资本水平的学生家长，因为高人力资本水平的家长会将子代送往高质量的学校，意味着学生还受益于同侪效应的外溢性 人力资本在代际间存在紧密关联( Haveman and Wolfe，1995; Hei-neck and Ri<sub>p</sub>hahn，2009; 杨娟和何婷婷，2015) ，我们此处检验实现 <sup>“</sup>农转非 <sup>”</sup>的个体能否受益于同侪效应的外溢性( 即上一代人力资本水平) 具体衡量指标为该校学生家长的受教育程度在本县( 区) 内属于何种水平，以最低为1，中下为2，中间为3，中上为4，最高为5，该数值越高，则学生上一代的人力资本水平越高，学生同侪效应的外溢性越大 检验结果显示，非农业户口的学生更有可能受益于同侪效应的外溢性

第六，教学质量差异 前文验证了非农业户口个体享受的教育类公共服务具有较大的优势，实际上说明农村与城镇地区的教育类公共服务存在差异 为了观察农村与城镇地区的教学质量差异，我们引入2007 年中国居民收入调查数据，其中的教育模块涉及<sup>“</sup>孩子当前/2007 年的主要生活地点在哪里<sup>” “</sup>其所在学校的教学质量<sup>”</sup>等问题我们将主要生活地点分为农村与非农村地区<sup>①</sup>，进而比较所在学校的教学质量，其中在本市/县中最好设为1，比较好为2，一般为3，比较差为4，其值越小说明其所在学校的教学质量越好 结果显示两组的差分为 －0.412，说明城市地区的学生能够受益于更好的教学质量

## 六 结论与政策建议

实现城乡统筹发展是全面建设小康社会面临的重要课题 户籍制度的存在导致了城乡二元分割，不同户籍的居民面临不同的公共服务，这显然不利于实现城乡统筹发展实现城乡统筹发展需要厘清农业户口与非农业户口人力资本的差异及其作用机制，进而为完善户籍制度改革以及统筹城乡发展提供基础数据 现有关于城乡户籍制度的研究较少关注城乡人力资本的差异，而且很少识别户口性质对城乡人力资本差距的因果效应<sub>。</sub>

1998 年国务院批转了公安部 《关于解决当前户口管理工作中几个突出问题意见的通知》，其中规定符合转换条件的个体落户随父随母自愿，这一外生冲击对于识别不同户口性质的人力资本差距提供了条件 我们基于2010 年人口普查数据构建一个能够识别其因果效应的模糊断点回归模型，即引入是否受益于该政策的不同群体，以观察符合转换条件且实现<sup>“</sup>农转非<sup>”</sup>对个体长期人力资本的影响 根据研究目的与识别策略，本文构造了一个能够识别这种户籍转换的工具变量，该变量吸收了出生年月是否符合转换条件以及父母户籍的代际关联因素 计量分析发现，符合转换条件且实现了 <sup>“</sup>农转非<sup>”</sup>的个体，其长期人力资本水平具有显著的提升，表现为受教育年限提升了约2 年

本文研究结果证实，符合转换条件的个体在实现 <sup>“</sup>农转非<sup>”</sup>后，长期人力资本得到了较大提升，定量反映了农业与非农业户口个体间的人力资本差距 这一结果对于完善户籍制度 实现城乡统筹发展具有重要意义 为了实现城乡统筹发展 缩小城乡间人力资本差距，需要继续完善农村地区的教育类公共服务体系，注重教育类公共服务供给的数量与质量;而且，在承认城乡公共服务存在差距的条件下，需要缩短农村居民与城镇地区公共服务的受益距离，扩大城镇地区公共服务对农村地区的辐射程度 在完善户籍制度改革层面，需要重新思考户籍与公共服务之间的关联，有步骤地打破户籍与公共服务的挂钩机制
