# 公司治理<sub>、</sub> 内部控制与非效率投资:理论分析与经验证据

方红星 金玉娜

( 东北财经大学会计学院/中国内部控制研究中心 116025)

【摘要】 本文以2007—2010 年度 A 股主板非金融类上市公司为研究对象，在按照非效率投资形成的内在机理对其进行分类的基础上，研究公司治理<sub>、</sub> 内部控制对非效率投资的抑制作用<sub>。</sub> 研究发现，公司治理和内部控制能够抑制公司的非效率投资，公司治理能够有效抑制意愿性非效率投资，内部控制能够有效抑制操作性非效率投资<sub>。</sub> 本文理清了公司治理与内部控制在抑制非效率投资方面的作用差异，发现两者在此过程中存在分工效应<sub>。</sub>

【关键词】 公司治理 内部控制 非效率投资 意愿性非效率投资 操作性非效率投资

## 一<sub>、</sub> 引言

投资是拉动经济增长的动力，其效率的高低直接关系公司的成败，高效率的投资将使公司在激烈的竞争中立于不败之地 遗憾的是，现实世界中由于投资意愿偏误和操作失误等因素的影响，非效率投资问题广泛存在 公司资源可能被投资于净现值 ( NPV) 小于 0 的项目，发生过度投资; 也可能在公司拥有闲置资源的情况下，仍然放弃净现值 ( NPV) 大于0 的项目，发生投资不足 非效率投资( 过度投资 投资不足) 使公司偏离企业价值最大化的目标，影响公司的生存与长期发展 如何有效抑制非效率投资是学术界和实务界广泛关注的热点问题

按照非效率投资产生的不同内在机理，非效率投资可以划分为意愿性非效率投资和操作性非效率投资 由于委托代理等问题的存在，管理者可能按照个人利益最大化而非公司价值最大化的目标进行决策，导致投资意愿偏离最优水平，即为意愿性非效率投资; 具体投资项目评估 执行和预算等环节出现问题，造成投资的具体计划和执行过程发生操作失误，即为操作性非效率投资 非效率投资产生的内在机理不同，解决方法可能会存在较大差异，但已有研究都忽略了二者的差异，未能立足于内在机理上的显著差别进行深入分析 本文从非效率投资产生的不同内在机理出发，以便科学探求抑制非效率投资更为有效的机制和途径<sub>。</sub>

公司治理和内部控制作为备受关注的两大机制，能否有效抑制非效率投资，是一个兼具理论价值 实践意义和政策意蕴的重要话题 公司治理可以缓解公司的代理问题，提高高层次 意愿性的决策效率; 内部控制可以增强公司经营效率和效果，提高相对低层次 操作性的实施效率公司治理和内部控制既相互联系，又各有侧重，有必要纳入到同一研究框架中，分析其在抑制非效率投资中的作用机理是否相同 该问题迄今为止尚没有明确的答案 鲜有文献研究内部控制能否提高投资效率，仅见的少量文献也存在较大的分歧 因此，公司治理和内部控制能否有效地抑制非效率投资，对意愿性非效率投资和操作性非效率投资的抑制作用是否存在差异，是当前亟待解决的问题

基于以上考虑，本文的研究旨在丰富有关非效率投资影响因素的认识，验证公司治理和内部控制对不同类型非效率投资的不同作用机理，进而检验公司治理和内部控制在抑制非效率投资中可能存在的分工效应

## 二<sub>、</sub> 文献回顾

## ( 一) 公司治理对非效率投资的影响

近几年，公司治理对非效率投资的影响吸引了大量学者的关注 <sub>。</sub> Aggarwal and Samwick ( 2006) 发现有效的激励契约能够抑制公司的投资不足 Richardson ( 2006) 检验了自由现金流量和投资之间的关系，发现积极行动的股东( activist shareholders) 等一些公司治理因素能够抑制公司的过 度 投 资 <sub>。</sub> Billett et al． ( 2011 ) Giroud and Mueller(2011) 发现公司治理差的公司更可能发生非效率投资<sub>。</sub>Grundy and Li ( 2010) 发现管理者持股加大了公司的投资规模，管理者薪酬与投资的关系不显著

在国内，大量学者对公司治理对非效率投资的影响进行研究，但结论并不一致<sub>。</sub> 张会丽和陆正飞 ( 2012) 俞红海 (2010) 杨兴全等 ( 2010) 研究发现高质量公司治理能够抑制非效率投资 与以上研究结论相反，简建辉等(2011) 发现货币薪酬激励加剧了非效率投资，刘昌国(2006) 发现公司治理对非效率投资的抑制作用较弱<sub>。</sub>

## ( 二) 内部控制对非效率投资的影响

此前关于内部控制经济后果的研究主要集中于会计信息质量 市场反应和资本成本等方面，近期才有少量文献涉猎内部控制对公司投资行为的影响，但研究结论存在明显的分歧 <sub>。</sub> Cheng et al． ( 2013) 李万福等 ( 2011) 李万福等 (2010) 研究发现高质量内部控制能够抑制公司的非效率投资 与其相反，于忠泊和田高良 (2009) 研究表明高质量内部控制不能有效抑制公司的非效率投资

## ( 三) 公司治理与内部控制的关系

公司治理和内部控制有着密不可分的关系，公司治理是内部控制的环境要素之一，内部控制框架与公司治理机制的关系是内部管理监控系统与制度环境的关系 Hoitashet al． ( 2009) Goh ( 2009) 发现高质量的公司治理能够提高内部控制的有效性 林钟高等 ( 2007) 从内部控制五要素角度度量内部控制质量 ( 基本倚重于公司治理的表征变量) ，结果表明内部控制对企业价值有高度显著的正向促进作用 程晓陵和王怀明 ( 2008) 以主营业务资产收益率 财务报告可靠性和遵循法律法规度量公司的内部控制质量，研究发现公司治理对内部控制具有显著影响

综上，有关非效率投资的研究已经取得了丰硕的成果，但已有研究尚未考虑非效率投资产生的不同内在机理，缺乏对不同类型非效率投资影响因素差异的深入分析 投资行为涉及公司自上至下的多个层面，公司治理和内部控制在公司活动中的作用机理不同，对公司不同层面投资行为的影响能力各有侧重，两者对非效率投资是否存在抑制作用，对不同类型非效率投资的抑制作用是否存在差异，还有待进一步检验 部分研究主要依赖公司治理变量度量内部控制质量，混淆了公司治理与内部控制之间的关系，可能导致内部控制度量的偏差 此外，鲜有文献研究内部控制对公司投资的影响，并且没有得出一致的结论，还需要进一步的研究和检验<sub>。</sub> 本文尝试从非效率投资产生的不同内在机理出发，在对非效率投资进行分类的基础上，研究公司治理和内部控制能否有效地抑制公司的非效率投资，其抑制作用对不同类型的投资行为是否存在差异，以期对国内外既有研究做出实质性的改进

## 三<sub>、</sub> 理论分析与研究假设

在所有权和经营权分离的背景下，所有者 ( 委托人)与管理者 ( 代理人) 之间的利益并不完全一致，代理人可能出于个人私利而使公司的投资意愿偏离最优化水平，发生非效率投资<sub>。</sub> 上市公司的投资意愿偏误主要由两类代理问题引起: 第一类代理问题是股东和管理者之间的代理问题 ( Jensen et al． ，1976) 管理者可能出于机会主义动机，按照个人利益最大化的标准进行决策，使公司投资偏离最优水平，发生非效率投资 第二类代理问题是大股东和中小股东的代理问题，大股东有动机通过其控制的管理者进行非效率投资，以侵占中小股东的利益 ( La Porta et al． ，1998) <sub>。</sub>

为了使代理人和委托人的目标更趋于一致，需要设计一系列公司治理机制，对代理人进行监督和激励，以降低代理成本，抑制非效率投资 公司治理是通过一整套包括正式或非正式的 内部或外部的制度或机制来协调公司各利益相关者之间的利益关系，以保证公司决策的科学化，从而最终维护各方的利益 ( 李维安和姜涛，2007) 公司治理水平的高低体现为公司是否具有一整套完善的监督机制和激励机制<sub>。</sub> 有效的监督机制能够制约管理者的机会主义行为，降低管理者偷懒的可能性，抑制非效率投资<sub>。</sub> 有效的激励机制能够促使管理者更为积极地参与公司的投资活动，提高管理者和公司利益的一致性，解决激励不相容和责任不对等问题，促使管理者按照企业价值最大化的原则进行投资决策，抑制非效率投资 由以上分析可知公司治理能够抑制公司的非效率投资，据此提出假设 H1:

假设 H1: 公司治理能够抑制公司的非效率投资

## 假设 H1b: 有效的激励机制能够抑制公司的非效率投资<sub>。</sub>

内部控制旨在合理保证企业实现其经营目标 ( 经营的效率和效果) 报告目标 ( 财务报告信息的可靠性) 和合规目标 ( 遵循适用的法律法规和有关监管要求) 投资效率的高低直接影响经营目标的实现 过度投资将导致公司资源的高投入 低产出; 投资不足将导致公司投资机会的浪费，资源大量闲置，这两种类型的非效率投资都无法实现公司最优的经营效率 公司将资源投资于 NPV 小于零的项目 ( 过度投资) ，使得现金的流入量现值小于现金的流出量现值; 公司放弃 NPV 大于零的项目不予投资 ( 投资不足) ，使得公司的实际经营效果小于期望水平，两种方式的非效率投资都将导致公司无法达到最优的经营效果 有效的内部控制应该能够通过对公司投资决策 实施行为的控制，提高公司投资的效率和效果 另一方面，良好的内部控制能够提高信息和沟通的效率，降低公司内部的信息不对称程度，使信息准确 及时地在组织中相关部门和人员之间传递，组织中的人能够更有效地获取 交流为执行 管理和控制各项事务所需的信息，更全面地了解投资项目的真实情况以及公司的实际经营状况，更合理地选择和执行公司的投资项目 良好的内部控制还可以保证公司内部职能部门之间权力的有效制衡 权责的合理分配 业务流程的有效安排，避免操作性失误的发生 由以上分析可知，有效的内部控制应该能够抑制公司的非效率投资，据此提出假设 H2:

## 假设 H2: 内部控制能够抑制公司的非效率投资

公司治理和内部控制的着眼点不同，对非效率投资的抑制作用可能存在较大差异 公司治理是通过股东 董事会 监事会和高层管理者之间的权利制衡，约束管理者大股东的机会主义行为，提高彼此的信任程度，解决股东和管理者 大股东和小股东之间的代理问题 内部控制是在公司治理解决了股东 董事会 监事会和高级管理者之间的权责划分的基础上，向各级管理人员和员工实施的控制活动，解决不同层级管理者之间以及管理人员和一般员工之间的操作性问题，合理保证既定目标的实现 公司治理主要针对公司战略层面，涉及公司生存发展的重大决策;内部控制主要针对公司运营层面，涉及日常经营活动的决策和实施<sub>。</sub> 公司治理解决公司结构<sub>、</sub> 机制的重大问题; 内部控制解决具体业务的职责分工和业务流程问题 综上，我们可以合理地预期: 公司治理有助于解决高层次 由委托代理等因素导致的意愿性投资决策效率问题; 内部控制有助于解决相对低层次 由于项目评估 预算 决算等操作失误导致的操作性投资决策和实施效率问题，两者存在较为明确的分工<sub>。</sub> 据此，提出假设 H3<sub>、</sub> 假设 H4:

## 四<sub>、</sub> 研究设计

## ( 一) 非效率投资的度量

## 1． 非效率投资水平的度量

本文借鉴 Richardson ( 2006) ，采用模型 ( 1) 对样本数据进行回归分析，计算公司的期望投资水平，用该回归模型估计出的残差来度量非效率投资 ( 正的残差为投资过度，负的残差为投资不足)

$$
\begin{array}{r l} I n v _ {i, t} = & a _ {0} + a _ {1} G r o w t h _ {i, t - 1} + a _ {2} L e v _ {i, t - 1} + a _ {3} C a s h _ {i, t - 1} \\ & + a _ {4} A g e _ {i, t - 1} + a _ {5} S i z e _ {i, t - 1} + a _ {6} R e t _ {i, t - 1} + \\ & a _ {7} I n v _ {i, t - 1} + \sum I n d + \sum Y e a r + \varepsilon_ {i, t} \end{array}\tag{1}
$$

其中，各变量的含义依次为公司的投资总额 ( Inv，固定资产净额 长期股权投资净额和无形资产的年度增加额，除以期初固定资产净额以消除规模影响) 成长机会( Growth，采用 Tobin － Q) 资产负债率 ( Lev) 现金持有量 ( Cash) 上市年数 ( Age，取自然对数) 公司规模( Size，总资产的自然对数) 考虑现金红利再投资的年回报率 ( Ret) 行业 ( Ind) 和年份 ( Year) 控制变量，其中行业按中国证监会2001 颁布的 《上市公司行业分类指引》进行分类，制造业取两位代码分类 ( C2 行业的公司数量较少，归入 C9 行业中) ，其他行业取一位代码分类

使用样本公司数据对模型 (1) 进行回归分析，得到公司 t 年的期望投资水平 $\mathrm { ( \ E x p { \_ } I n v _ { \mathrm { i , t } } ) }$ ，然后用公司的实际投资水平减去期望投资水平，得出 i 公司 t 年的非效率投资$\mathrm { \left( \ I n e _ { - } I n v _ { i , t } \right) }$ 若公司的非效率投资水平大于 0，则表明公司过度投资 $\mathrm { ( 0 v e r _ { - } I n v _ { i , t } ) }$ ; 若公司的非效率投资水平小于0，则表明公司投资不足，并对其取绝对值 $\mathrm { \ ( \ U n d e r _ { - } I n v _ { i , t } ) }$ 具体表示为:

$$
\begin{array}{r l} & {O v e r \_ I n v _ {\mathrm{i,t}} = I n v _ {\mathrm{i,t}} - E x p \_ I n v _ {\mathrm{i,t}}} \\ & {(  \text {当}   I n v _ {\mathrm{i,t}} - E x p \_ I n v _ {\mathrm{i,t}} > 0   \text {时})} \\ & {U n d e r \_ I n v _ {\mathrm{i,t}} = -    (  I n v _ {\mathrm{i,t}} - E x p \_ I n v _ {\mathrm{i,t}})} \\ & {(  \text {当}   I n v _ {\mathrm{i,t}} - E x p \_ I n v _ {\mathrm{i,t}} <   0   \text {时})} \end{array}
$$

## 2． 非效率投资的分类

非效率投资产生的内在机理，内含于公司运作的整个过程，本文通过深入分析不同形成机理下，非效率投资的不同表现形式，对其进行分类<sub>。</sub> 国有企业存在严重的预算软约束问题，投资活动具有充分的资金支持，即使投资失败，破产的概率也相对较低 同时，政府干预使得国有企业投资行为受到财政收入 就业 社会稳定等多方面的影响 在这样的环境下，由于管理者的收益与公司规模正相关，公司规模越大，管理者的社会地位 升迁机会及各种收入越高，国有企业管理者出于机会主义动机，非效率投资意愿更倾向于过度投资 民营企业存在较强的融资约束，缺乏投资所需的必要资金，且所有者必须为非效率投资买单 相对于高风险的过度投资，民营企业高层管理者更倾向于采用其他方式侵占公司资源，非效率投资意愿更倾向于投资不足，以避免投资活动对公司资源的大量占用，进而提高管理者可侵占资源的数量 因此投资意愿偏误对非效率投资的影响具有方向性，增加了国有企业的过度投资和民营企业的投资不足 既然意愿性非效率投资主要表现为以上两个方向，那么发生与之相反方向的非效率投资 ( 国有企业的投资不足 民营企业的过度投资) ，很可能是由于操作性因素 ( 项目评估 执行和预算失败等) 的影响较大，其作用大于意愿性因素的结果 因此，国有企业的投资不足和民营企业的过度投资主要属于操作性非效率投资<sub>。</sub> 国有企业的过度投资和民营企业的投资不足不乏操作性因素的影响，但投资意愿偏误是其主要的成因，不妨归入意愿性非效率投资

## ( 二) 公司治理的度量

公司治理包括激励和监督两大机制，本文广泛考察反映中国公司治理水平的各种因素，分别从激励和监督两方面选取相应变量 监督机制选取第一大股东持股比例( Top1) 第二至第五大股东持股比例 ( Top2 －5，第二至第五大股东持股比例之和) 独立董事比例 ( Ibr) 机构投资者持股比例 ( Ins) 董事长与总经理是否兼任 ( Ma\_t，兼任为1 非兼任为 0) 董事会规模 ( Bsize) 监事会规模 ( Susize) 董事会会议次数 ( Cdc) 监事会会议次数$\mathrm { ( { C j c } ) }$ 公司治理的激励对象主要是高层管理者，由于我国领取薪酬和持有股权的董事和监事属于执行董事和执行监事，是上市公司的实际管理者，因此对董事和监事的激励也是激励机制的重要组成部分 激励机制选取董事持股比例 ( Dis) 监事持股比例 ( Sus) 高级管理者持股比例( Mas) 领取薪酬的董事比例 ( Pad) 领取薪酬的监事比例 ( Pap) 和前三名高管薪酬 ( Masa，取自然对数) 我们借鉴白重恩等 ( 2005) 张会丽和陆正飞 ( 2012) 的研究方法，分别对激励和监督因素进行主成分分析，选取第一大主成分作为公司治理两大机制的度量指标<sub>。</sub>

## 六<sub>、</sub> 结论

本文以2007—2010 年度 A 股主板非金融类上市公司为研究对象，结合非效率投资产生的内在机理，将研究样本划分为意愿性非效率投资 ( 国有企业的过度投资和民营企业的投资不足) 和操作性非效率投资 ( 国有企业的投资不足和民营企业的过度投资) ，并在此基础上，考察了公司治理 内部控制对非效率投资的抑制作用 研究结果表明，有效的公司治理和内部控制能够抑制上市公司的非效率投资，公司治理能够显著地抑制上市公司的意愿性非效率投资，内部控制能够显著地抑制操作性非效率投资，公司治理和内部控制在抑制上市公司的非效率投资方面存在分工效应<sub>。</sub>

本文的主要贡献在于: 第一，本文在对内部控制质量进行更为有效度量的基础上，发现内部控制能够有效抑制公司的非效率投资，解决了相关的模糊认识和学术分歧第二，已有关于非效率投资的研究都没有对其形成机理进行深入分析，本文首次区分意愿性非效率投资和操作性非效率投资，依据两类非效率投资产生的不同内在机理寻求相应的解决机制，为后续研究提供了新的视角<sub>。</sub> 第三，本文首次将公司治理和内部控制纳入到同一实证研究框架中，研究它们对非效率投资的抑制作用，理清了公司治理 ( 监督机制 激励机制) 与内部控制在抑制非效率投资方面的作用差异，发现它们在此过程中存在分工效应 这对于学术界进一步厘清公司治理与内部控制之间的关系有积极的探索价值
