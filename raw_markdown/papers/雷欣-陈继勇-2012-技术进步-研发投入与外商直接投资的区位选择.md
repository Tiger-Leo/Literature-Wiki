# 技术进步<sub>、</sub>研发投入与外商直接投资的区位选择

雷 欣 陈继勇

内容提要 本文从理论和实证分析的角度探讨了技术进步<sub>、</sub>研发投入和外商直接投资的关系<sub>。</sub> 结果显示，中国各地区技术进步率 相对技术效率水平以及研发投入水平的提高，都有助于吸引更多外商直接投资的进入<sub>。</sub> 新兴的研发和技术因素逐渐取代基础设施<sub>、</sub>交通运输条件等传统因素，成为外商在华直接投资区位选择的主要决定因素<sub>。</sub> 据此本文认为，对于外资利用不足的中西部地区而言，应通过加大研发投入 培养区域自主创新能力 着力提高本地区的相对技术效率水平 加快推进本地区的技术进步幅度，以提高本地区对外商直接投资的吸引效应

关 键 词 技术进步 技术效率 研发投入 外商在华直接投资 区位选择

## 一<sub>、</sub>引言与文献回顾

改革开放以来，外商在华直接投资逐步成为推动中国经济迅猛增长的重要引擎之一<sub>。</sub> 据统计，1978 ～2011年外商在华直接投资实际利用额累计达 11 643． 94 亿美元，其中，1983 ～2008 年外商在华直接投资增长了近118 倍，年均增长率高达 27． 2% 但是，外商在华直接投资在快速发展的同时出现了明显的地区非均衡分布问题<sub>。</sub> 1990 ～2007 年，广东省累计外商直接投资额高达1777．88 亿美元，而甘肃 宁夏和新疆等省( 自治区)的累计额甚至不足 5 亿美元①<sub>。</sub> 外商在华直接投资的地区非均衡分布已经影响到中国区域经济的协调均衡发展，并对中国构建和谐社会战略的实施产生了一定的负面影响<sub>。</sub> 如何推进外商在华直接投资的地区均衡分布，是实现中国经济社会可持续稳定发展必须解决的难题 为寻找有效途径推动外商在华直接投资的地区均衡分布，首先必须明确影响外商在华直接投资的区位选择因素<sub>。</sub>

传统的国际直接投资理论认为，市场因素 贸易壁垒 成本因素和投资环境等是影响国际投资进入的重要因素( Christian Bellak，2008) <sub>。</sub> 然而，随着科技水平的不断进步，跨国公司在进行对外投资时不仅重视传统的区位因素，而且越来越重视东道国的知识技术能力等新兴因素，研发能力和生产效率日益成为影响跨国公司区位选择的重要因素<sub>。</sub> Cantwell( 1989) 提出，由于地区间在创新 教育体系以及教育机构与企业间的联系上存在差异，地区间的技术水平和生产能力也表现出不同，这使得现代企业试图通过对外直接投资来获取新知识从而对现有技术进行补充<sub>。</sub> 已有研究证实了这一观点<sub>。</sub>Serapio 和 Dalton( 1999) 通过研究在美国的外资研发实验室数据发现，企业开拓新市场的目的正逐步转向获取本地技术 <sub>。</sub> Branstetter( 2006) 利用日本企业对美国直接投资和创新活动的面板数据也证实，国际直接投资促进日本企业对美国本地知识的吸收

目前，国内学者也日益重视研究外商直接投资与本地技术的相互关系，但已有研究主要侧重于探讨外商直接投资对本地技术的促进作用<sub>。</sub> 沈坤荣(1999) 检验了外商直接投资与中国地区全要素生产率的关系，结果发现，外商直接投资有效促进了中国地区生产率的提高;

姚洋等(2001) 发现，外资企业的生产效率明显高于国内企业，外商直接投资有效促进了本地生产率的提升蒋殿春和夏良科(2005) 运用面板数据模型对中国高技术行业的创新能力进行分析后发现，外商直接投资通过示范效应和科技人员的流动促进了国内企业的研发活动，有助于提升国内企业的生产效率水平<sub>。</sub> 马野青等(2007) 基于面板回归模型的研究却发现，外商直接投资对促进中国知识技术水平和生产效率的提高作用有限 另一方面，随着研究的深入，本地技术对外商直接投资的吸引效应也逐步引起学者的关注<sub>。</sub> 李杏等(2009) 运用协整检验和误差修正模型考察了外资对中国整体技术水平的影响，结果显示外商直接投资与中国的技术水平存在长期的相互促进关系<sub>。</sub> 陈继勇等(2010) 发现，地区技术创新能力的高低是吸引外资进入的重要因素 总体而言，国内探讨本地技术这一新兴因素是否以及如何影响外商直接投资进入的研究并不多见，而且缺乏系统和深入的研究 本文致力于从理论上探讨技术进步和研发能力对外商在华直接投资的影响，进而从实证分析的角度检验二者对外商在华直接投资区位选择的影响效应<sub>。</sub>

## 二<sub>、</sub> 理论模型

## 1． 生产函数的假设

假定外商直接投资企业仅使用两类生产要素，即外商直接投资额和本地劳动力 同时，假定外商直接投资企业的生产函数符合柯布 －道格拉斯函数形式:

$$
Y _ {i t} = A _ {i t} K _ {i t} ^ {\alpha} \left(L _ {i t} h _ {i t}\right) ^ {1 - \alpha}\tag{1}
$$

其中， $J _ { i t }$ 为地区 i 的外资企业在 t 期的产出 ${ \bf \Omega } _ { \bf { 3 } } K _ { i }$ 为地区 i 的外资企业在 t 期的资本存量，即地区 i 吸收的外商直接投资存量<sub>。</sub> $A _ { i t }$ 为地区 i 在 t 期的技术水平， $\mathbf { \nabla } _ { \mathbf { \rho } } J _ { i t }$ 为外资企业在 t 期雇用的劳动力数量， $h _ { i t }$ 为地区 i 在 t 期的人力资本存量<sub>。</sub> 同时，外资企业的产出用于消费 再投资和研发，即 $Y _ { \mathrm { } \mathrm { } _ { i t } } = C _ { \mathrm { } _ { i t } } + I _ { \mathrm { } _ { i t } } + R _ { \mathrm { } _ { i t } }$

遵循 Klenow 和 Rodriguez-Clare( 2005) 的设定，假定企业的目标是通过选择研发和资本投入实现利润最大化:

$$
\max \left\{\pi = \int_ {t _ {o}} ^ {\infty} \left[ Y _ {i t} - I _ {i t} - R _ {i t} \right] e ^ {- r (t - t _ {o})} d t \right\}\tag{2}
$$

其中 ${ \bf \Pi } _ { \pmb { \lambda } } I _ { i t }$ 为外资企业再投资额，且 $\dot { K } _ { i t } = I _ { i t } - \delta K _ { i t } , R _ { i }$ 为地区 i 的研发投入 $, s r$ 为研发收益率<sub>。</sub>

## 2． 技术进步演进路径函数

随着时间的演进，地区 i 的技术水平随之发生变化，但各地区技术变动的速度和模式并不相同<sub>。</sub> 其中，研发投入规模大和既有技术水平高的地区，技术水平的提升速度也相对较快<sub>。</sub> 但是，研究发现地区 i 技术水平的提升还受该地区技术水平与技术前沿之间差距的影响 特别是，落后地区通过 <sup>“</sup>学习效应<sup>”</sup>和 <sup>“</sup>赶超效应<sup>”</sup>在技术进步上具有更大的优势 一方面，技术相对落后地区可以投入较小的成本直接学习吸收技术前沿地区的既有技术成果，使得创新的有效成本降低( Parente 和Prescott，1994) ;另一方面，对于相对落后地区而言，每项成功技术的应用对该地区技术的改进具有更大的推动作用( Howitt，2000) 遵循这一思路，将地区 i 技术水平A 的增长率设定为本地研发投入<sub>、</sub>既有技术水平及其与技术前沿差距的函数:

$$
\dot {A} _ {i t} = \left[ 1 - \mu\right) R _ {i t} + \mu \bar {R} _ {t} + \varepsilon A _ {i t} ] \left(1 - A _ {i t} / A _ {t} ^ {*}\right)\tag{3}
$$

其中，A<sup>\*</sup> 为 t 期的技术前沿水平， ${ \bf \nabla } \cdot { \bf { A } } _ { i t }$ 为地区 i 的科技水平， $\mathbf { \nabla } _ { \mathcal { R } } ^ { }$ 为平均研发水平 ${ \bf \Omega } _ { \bf { \Omega } } ^ { \bullet \mu }$ 为介于 $0 \sim 1$ 间的参数，$\varepsilon \geq 0 _ { \circ } \ \left( \ 1 - A _ { i t } / A _ { t } ^ { \ast } \ \right)$ 表示地区 i 与技术前沿的差距对其技术水平提升的影响，由( $1 / { A } ^ { * }$ ) 和( $\boldsymbol { A } ^ { * } \_ - \boldsymbol { A } )$ 相乘得到<sub>。</sub>其中， $\boldsymbol { \cdot } \boldsymbol { 1 } / \boldsymbol { A } ^ { * }$ ) 表示前沿技术水平越高，技术相对落后地区要学习或达到这一领先技术需要付出更高的成本;$\left( \boldsymbol { A } ^ { * } - \boldsymbol { A } \right)$ 则意味着技术相对落后地区与技术前沿的差距越大，通过学习和赶超效应实现的技术进步程度就越大<sub>。</sub> 假设 $g _ { i t } = \dot { A } _ { i t } / A _ { i t } , a _ { i t } = A _ { i t } / A _ { t } ^ { * }$ <sup>\*</sup> ，即设定 $g _ { i t }$ 为地区 i 的技术进步率 $\mathbf { \nabla } _ { \mathfrak { s } } a _ { i }$ 为地区 i 的相对技术效率，衡量地区 与技术前沿地区的技术差距，且 $a _ { i t } \in \left( \begin{array} { l } { 0 , 1 } \end{array} \right) \mathrm { ~ \textdegree ~ } a _ { i t }$ 值越接近于1，表明地区 i 的相对技术水平越高( 等于1 的地区为技术前沿地区) ; $a _ { i t }$ 值越接近于 0，表明地区 i 的相对技术水平越低<sub>。</sub>

## 3． FDI<sub>、</sub>研发投入与技术进步的关系

根据上述设定，将方程( 2) 改写为:

$$
\begin{array}{l} \max \left\{\pi = \int_ {t _ {a}} ^ {\infty} \left[ A _ {i t} K _ {i t} ^ {\alpha} \left(L _ {i t} h _ {i}\right) ^ {1 - \alpha} - \left(K _ {i t} + \delta K _ {i t}\right) \right. \right. \\ \left. - \frac {1}{(1 - \mu)} \left(\frac {A _ {i t}}{1 - a _ {i t}} - \varepsilon A _ {i t} - \mu \bar {R} _ {t}\right) \right] e ^ {- r (t - t _ {a})} \end{array}\tag{dt}}
$$

根据 Euler 方程:

$$
\partial \pi / \partial K _ {i t} = \mathrm{d} \left(\partial \pi / \partial \dot {K} _ {i t}\right) / \mathrm{d} t\tag{4}
$$

$$
\partial \pi / \partial A _ {i t} = \mathrm{d} \left(\partial \pi / \partial \dot {A} _ {i t}\right) / \mathrm{d} t\tag{5}
$$

结合方程( 1) ，可以得到:

$$
\begin{array}{l} \partial \pi / \partial K _ {i t} = \left[ A _ {i t} \left(L _ {i t} h _ {i t}\right) ^ {1 - \alpha} \alpha K _ {i t} ^ {\alpha - 1} - \delta \right] e ^ {- r (t - t _ {o})}, \\ \partial \pi / \partial K _ {i t} = - e ^ {- r (t - t _ {o})} \end{array}
$$

以及

$$
\partial \pi / \partial A _ {i t} = \left[ \frac {Y _ {i t}}{A _ {i t}} - \frac {1}{(1 - \mu)} \left(\frac {g _ {i t}}{1 - a _ {i t}} - \varepsilon\right) \right] e ^ {- r (t - t _ {a})},
$$

$$
\partial \pi / \partial A _ {i t} = - \frac {1}{(1 - \mu) (1 - a)} e ^ {- r (t - t _ {o})}
$$

因此有:

$$
\begin{array}{l} \mathrm{d} \left(\partial \pi / \partial \dot {K} _ {i t} / \mathrm{d} t = r e ^ {- r (t - t _ {\perp}} \right., \\ \mathrm{d} \left(\partial \pi / \partial \dot {A} _ {i t} / \mathrm{d} t\right) = \frac {r}{(1 - \mu) (1 - a)} e ^ {- r (t - t _ {\perp})} \end{array}
$$

根据上面两个导数，将方程(4) 和(5) 重新表示为:

$$
\frac {Y _ {i t}}{K _ {i t}} = \frac {\delta + r}{\alpha},
$$

$$
\frac {Y _ {i t}}{A _ {i t}} - \frac {1}{(1 - \mu)} \left(\frac {g _ {i t}}{1 - a _ {i t}} - \varepsilon\right) = \frac {r}{(1 - \mu) (1 - a _ {i t})}
$$

由此可以计算出外资企业的资本投入函数:

$$
K _ {i t} = \frac {\alpha A _ {i t}}{(\delta + r) (1 - \mu)} \left(\frac {g _ {i t} + r}{1 - a _ {i t}} - \varepsilon\right)\tag{6}
$$

对方程( 6) 求导可得:

$$
\frac {\partial K _ {i t}}{\partial A _ {i t}} = \frac {\alpha}{(\delta + r) (1 - \mu)} \left(\frac {g _ {i t} + r}{1 - a _ {i t}} - \varepsilon\right)\tag{7}
$$

$$
\frac {\partial K _ {i t}}{\partial a _ {i t}} = \frac {\alpha A _ {i t} (g _ {i t} + r)}{(\delta + r) (1 - \mu) (1 - a _ {i t}) ^ {2}}\tag{8}
$$

$$
\frac {\partial K _ {i t}}{\partial g _ {i t}} = \frac {\alpha A _ {i t}}{(\delta + r) (1 - \mu) (1 - a _ {i t})}\tag{9}
$$

此外，根据方程(3) 可以将方程(8) 式改写为:

$$
\frac {\partial K _ {i t}}{\partial R _ {i t}} = \frac {\partial K _ {i t}}{\partial a _ {i t}} \cdot \frac {\partial \alpha_ {i t}}{\partial R _ {i t}} = \frac {\partial (g _ {i t} + r)}{g _ {i t} (\delta + r)}\tag{10}
$$

根据前文 $\alpha \cdot \mu \cdot a _ { i t } \in \left( \ 0 , 1 \right)$ 且 $\varepsilon \cdot \delta > 0$ 的设定，虽无法判断(7) 式的符号，但易于判断(8) ～ ( 10) 式的取值均为正，由此表明:

( 1) $\frac { \partial K _ { i t } } { \partial a _ { i t } } > 0 ;$ 相对技术效率越高的地区，外商直接投资额越高，即外商资本更倾向于选择相对技术效率较高的地区进行投资<sub>。</sub>

( 2) $\frac { \partial K _ { i t } } { \partial g _ { i t } } > 0 ;$ 技术进步越快的地区，外商直接投资额越高，即外商资本更倾向于选择技术进步率越高的地区进行投资<sub>。</sub>

( 3) $\frac { \partial K _ { i t } } { \partial R _ { i t } } > 0 ;$ 研发投入越高的地区，外商直接投资额越高，即外商资本更倾向于选择研发投入高的地区进行投资<sub>。</sub>

## 三<sub>、</sub>变量<sub>、</sub>数据与模型

根据上文的理论分析，我们构建回归模型检验中国各省( 自治区<sub>、</sub>直辖市) 吸收外商直接投资额与该地区研发投入<sub>、</sub>技术进步率以及相对技术效率水平的关系<sub>。</sub>

## 1． 变量选取与说明

模型的因变量为各地区的实际利用外商直接投资额( FDI) <sub>。</sub> 自变量包括:

## ( 1) 相对技术效率水平

如前所述，技术效率 $\mathbf { } a _ { i t }$ 衡量的是地区 i 效率水平与技术前沿的差距，即相对技术效率水平<sub>。</sub> 我们采用DEA( 包络数据分析) 技术测度各地区的相对效率水平<sub>。</sub> 构建如下可变规模报酬的产出导向 DEA 模型:

$$
\begin{array}{l} \max a _ {j} \\ \text {s.t.} \left\{ \begin{array}{l} \sum_ {k = 1} ^ {n} \lambda_ {k} y _ {r k} \geqslant a _ {j} y _ {r j} \\ \sum_ {j = 1} ^ {n} \lambda_ {k} x _ {i k} \leqslant x _ {i j} \\ \sum_ {j = 1} ^ {n} \lambda_ {j} = 1; \lambda_ {j} \geqslant 0; \forall k = 1, \dots , n; \\ \quad \forall r = 1, \dots , s; \forall i = 1, \dots , m \end{array} \right. \end{array}\tag{11}
$$

其中，共有 $n$ 个地区，每个地区使用 m 种投 $\lambda \{ x _ { 1 }$ $x _ { 2 } , \cdots , x _ { m } ]$ ，生产 s 种产出 $\{ y _ { 1 } , y _ { 2 } , \cdots , y _ { s } \} ; \lambda$ 为权重; $a _ { j }$ 为第j个地区的技术效率得分，用于衡量第j 个地区相对于技术前沿的偏离程度<sub>。</sub> 以各地区的劳动力数量( L) 资本存量( K) 以及人力资本( H) 作为投入变量; 其中，劳动力数量( L) 用从业人员数衡量，人力资本( H) 用平均受教育年限衡量，资本存量则按照 <sup>“</sup>永续盘存法<sup>”</sup>以9．6%的折旧率计算全社会固定资产投资额得到( 张军等，2004) 同时，以各地区剔除了价格波动的 GDP作为产出变量，构建非线性规划模型(11) 并求解<sub>。</sub>

## ( 2) 技术进步率

遵循既有研究的做法，我们采用 Fare 等( 1992) 构建的基于 DEA 的 Malmquist 指数来衡量全要素生产率的变动<sub>。</sub> 具体模型如下:

$$
\begin{array}{l} M _ {i} \left(x ^ {t}, y ^ {t}, x ^ {t + 1}, y ^ {t + 1}\right) = \underbrace {\frac {D _ {v} ^ {t + 1} \left(x _ {i} ^ {t + 1} , y _ {i} ^ {t + 1}\right)}{D _ {v} ^ {t} \left(x _ {i} ^ {t} , y _ {i} ^ {t}\right)}} _ {\Delta P E} \\ \times \underbrace {\left[ \frac {D _ {c} ^ {t + 1} \left(x _ {i} ^ {t + 1} , y _ {i} ^ {t + 1}\right) / D _ {v} ^ {t + 1} \left(x _ {i} ^ {t + 1} , y _ {i} ^ {t + 1}\right)}{D _ {c} ^ {t} \left(x _ {i} ^ {t} , y _ {i} ^ {t}\right) / D _ {v} ^ {t} \left(x _ {i} ^ {t} , y _ {i} ^ {t}\right)} \right]} _ {\Delta S E} \\ \times \underbrace {\left[ \frac {D _ {c} ^ {t} \left(x _ {i} ^ {t + 1} , y _ {i} ^ {t + 1}\right)}{D _ {v} ^ {t + 1} \left(x _ {i} ^ {t + 1} , y _ {i} ^ {t + 1}\right)} \cdot \frac {D _ {c} ^ {t} \left(x _ {i} ^ {t} , y _ {i} ^ {t}\right)}{D _ {c} ^ {t + 1} \left(x _ {i} ^ {t} , y _ {i} ^ {t}\right)} \right] ^ {\frac {1}{2}}} _ {\Delta T} \end{array}\tag{12}
$$

其中， $\mathcal M _ { i } \big ( \ v x ^ { t } \ v y ^ { t } , \ v x ^ { t + 1 } \ v y ^ { t + 1 } \big )$ 为 Malmquist 指数，即全要素生产率的变动值<sub>。</sub> 其中， $D _ { c } ^ { t } \left( \ v x ^ { t } , \ v y ^ { t } \right)$ 是规模报酬不变下的距离函数， $D _ { v } ^ { t } \left( \boldsymbol { \mathscr { x } } ^ { t } , \boldsymbol { y } ^ { t } \right)$ 是规模报酬可变下的距离函数 <sub>。</sub> Malmquist 指数可以分解为 3 个部分: ΔPE 衡量纯技术效率的变化，ΔSE 衡量规模效率的变化，ΔT衡量技术进步 可以采用非参数的线性规划技术( DEA 方法) ，估计各个决策主体的距离函数，进而可以得到Malmquist 指数及各分解部分的估计量<sub>。</sub>

当 $M _ { 0 } ^ { t } \big ( \ v x ^ { t } \ v y ^ { t } , \ v y ^ { t + 1 } \ v y ^ { t + 1 } \big )$ 大于 等于 小于1 时，分别表明全要素生产率提高 不变或降低 由于本文需要研究技术进步率对外商直接投资的影响效应，因此，我们采用由 Malmquist 指数法分解得出的 ΔT累计变动率来表示地区的技术进步率<sub>。</sub> ΔT大于1 表明相对于上一年发生了技术进步，小于 1 则表明存在技术退步<sub>。</sub> 此外，在计算 Malmquist 指数的过程中，每个地区选取的投入和产出数据与上面测算技术效率时选取的投入产出保持一致<sub>。</sub>

## (3) 研发投入及其他控制变量

各地区的研发投入用该地区的研发经费支出额来衡量<sub>。</sub> 此外，既有研究表明，传统的区位因素对外商在华直接投资依旧发挥重要作用 因此，我们在模型中引入开放度 失业率 基础设施建设水平 产业结构 交通运输能力以及国有化率等变量来反映各地区的经济环境 其中，开放度用地区进出口总额与 GDP 的比值来衡量;基础设施建设水平用地方财政决算支出中基本建设支出的占比来衡量; 产业结构用第二产业增加值占GDP 的比重来表示; 交通运输能力则通过公式: ( 铁路运营里程数 + 公路里程数 + 内河航道里程数) /地区总面积计算得到;国有化率用国有工业总产值占全部工业总产值的比重来度量<sub>。</sub>

## 2． 数据来源

本文采用的是 1999 ～2009 年中国 29 个省级行政区的数据( 西藏与海南除外) 其中，国内生产总值 从业人员数<sub>、</sub>全社会固定资产投资额<sub>、</sub>人口规模<sub>、</sub>不同受教育程度的人口结构<sub>、</sub>进出口总额<sub>、</sub>第二产业增加值<sub>、</sub>国有工业总产值<sub>、</sub>财政总支出<sub>、</sub>基建支出，以及各地区铁路<sub>、</sub>公路 内河航道里程数等原始数据来自历年 《中国统计年鉴》，各地区的研发经费支出额来自 《中国科技统计年鉴》 所有以货币计值的变量都以 GDP 平减指数平减，剔除了价格波动的影响<sub>。</sub> 所有的解释变量在回归前都取对数处理

## 3． 实证模型

根据上文的理论分析构建如下面板数据回归模型，检验技术进步和相对效率水平对 FDI 的影响:

$$
\begin{array}{r l} F D I _ {i t} & = \beta_ {0} + \beta_ {1} \Delta T _ {i t} + \beta_ {2} a _ {i t} + \beta_ {3} r d _ {i t} + \beta_ {4} o p e n _ {i t} \\ & \quad + \beta_ {5} u n e m p l o y e d _ {i t} + \beta_ {6} i n f r a s t r u c u r e _ {i t} \\ & \quad + \beta_ {7} s t r u c t u r e _ {i t} + \beta_ {8} t r a n s p o r t _ {i t} \\ & \quad + \beta_ {9} s t a t e \_ o w n e d _ {i t} + \varepsilon_ {i t} \end{array}\tag{13}
$$

其中，被解释变量为各地区的实际利用外商直接投资额( FDI) <sub>。</sub> 在解释变量中，ΔT表示技术进步率，a 表示相对技术效率，rd 表示研发投入，o<sub>p</sub>en 表示开放度，unem<sub>p</sub>lo<sub>y</sub>ed 为失业率，infrastructure 为基础设施建设水平，structure 为产业结构，trans<sub>p</sub>ort 表示交通运输能力，state\_owned 表示国有化率，<sub>ε</sub> 为服从独立同分布的误差项 <sub>。</sub>

## 4． 内生性检验

根据经典的计量经济分析，内生性是指在回归模型中自变量和回归残差的协方差不为 0<sub>。</sub> 导致内生性的原因有3 种: 遗漏变量<sub>、</sub>测量误差和互为因果<sub>。</sub> 结合本文的研究对象，我们将重点分析由遗漏变量和互为因果形成的内生性问题<sub>。</sub>

## (1) 遗漏变量导致的内生性检验

由遗漏变量导致的内生性是指存在没有加以控制的变量Z 同时影响外商直接投资和本地技术进步率，导致估计结果产生偏误 对于这种内生性问题，需要寻找适合的工具变量，通过工具变量估计得到一致和无偏的估计量<sub>。</sub> 为此，我们选择 <sup>“</sup>专利授权数<sup>”</sup>和 <sup>“</sup>高校教师数<sup>”</sup>的自然对数作为工具变量，采用两阶段最小二乘法对方程(13) 进行重新估计<sub>。</sub> Hausman 内生性检验统计量的 P 值均大于0．2，由此表明工具变量估计与普通估计的结果没有显著差异，模型中并不存在遗漏变量导致的内生性问题<sub>。</sub>

## ( 2) 互为因果导致的内生性检验

外商直接投资与本地技术进步之间更有可能存在互为因果关系 如前所述，沈坤荣( 1999) 姚洋等(2001) 和李杏等(2009) 的研究均显示外商直接投资与中国的技术水平存在长期的相互促进关系<sub>。</sub> 为明确外商直接投资与地区技术进步的因果关系，我们对面板数据做去时间均值处理，再对其进行 Granger 检验，发现外商直接投资与地区技术进步率之间存在双向的因果关系<sub>。</sub> 针对这一情况，我们构建如下联立方程组模型，对外商直接投资与技术进步之间的交互影响进行识别和检验<sub>。</sub>

$$
\left\{ \begin{array}{l} F D I _ {i t} = \beta_ {0} + \beta_ {1} \Delta T _ {i t} + \beta_ {2} a _ {i t} + \beta_ {3} r d _ {i t} + \beta_ {4} o p e n _ {i t} \\ \quad + \beta_ {5} u n e m p l o y e d _ {i t} + \beta_ {6} i n f r a s t r u c u r e _ {i t} \\ \quad + \beta_ {7} s t r u c t u r e _ {i t} + \beta_ {8} t r a n s p o r t _ {i t} + \beta_ {9} s t a t e \_ o w n e d _ {i t} \\ \Delta T _ {i t} = \alpha_ {0} + \alpha_ {1} F D I _ {i t} + \alpha_ {2} a _ {i t} + \alpha_ {3} r d _ {i t} + \alpha_ {4} o p e n _ {i t} \\ \quad + \alpha_ {5} u n e m p l o y e d _ {i t} + \alpha_ {6} i n f r a s t r u c u r e _ {i t} \\ \quad + \alpha_ {7} s t r u c t u r e _ {i t} + \alpha_ {8} t r a n s p o r t _ {i t} + \alpha_ {9} s t a t e \_ o w n e d _ {i t} \end{array} \right.\tag{14}
$$

(2) 传统的区位选择因素依然对吸引外商直接投资进入发挥着不同程度的作用 具体而言，基础设施建设水平和交通运输能力对外商在华直接投资的吸引效应并不显著<sub>。</sub> 对此可能的解释是，改革开放三十多年来，各地政府无不通过大力改善本地基础设施和交通运输条件展开<sup>“</sup>招商引资<sup>”</sup>竞争，由此导致通过这两个途径吸引外资进入的边际效应在不断递减，在目前基础设施和交通条件比较完善的情况下，上述两个传统因素对外资区位选择的影响效应不再显著是可以理解的<sub>。</sub> 国有化程度对外商在华直接投资的吸引效应为负，但在统计上并不显著，这表明在市场化改革不断深化的时代背景下，地区之间在市场化进程方面的差距在不断缩小，不再是影响外商直接投资区位选择的重要因素 对外开放度<sub>、</sub>第二产业比值<sub>、</sub>失业率对外商直接投资的影响效应显著 其中，开放度越高的地区，外商直接投资流入的规模越大，反映了中国各地区对外贸易与外商直接投资的互补关系;第二产业比重与外商直接投资显著正相关，由此表明，第二产业仍然是目前外商直接投资的主要领域，第二产业发达的地区在吸引外资方面具有更大的优势;失业率越高的地区，外商直接投资的规模越小，表明外商直接投资倾向于选择劳动力市场更为发达<sub>、</sub>就业水平更高的地区进行投资<sub>。</sub>

## 五<sub>、</sub>结论与政策建议

本文从理论上探讨了技术进步<sub>、</sub>研发投入和外商直接投资的关系，进而在控制技术进步与外商直接投资内生性的基础上构建联立方程组模型，检验中国各地区技术进步<sub>、</sub>研发投入对外商直接投资区位选择的影响<sub>。</sub> 结果显示，中国各地区技术进步率<sub>、</sub>相对技术效率水平以及研发投入水平的提高，都有助于吸引更多外商直接投资的进入<sub>。</sub> 新兴的研发和技术因素逐渐取代基础设施<sub>、</sub>交通运输条件等传统因素，成为外商直接投资区位选择的主要决定因素<sub>。</sub>

根据上述研究结论，本文认为，要改变目前中国外商直接投资地区非均衡增长的现状，实现中国区域经济的协调和可持续发展，必须重视地区技术进步 技术效率以及研发能力对外商对华直接投资区位选择的影响<sub>。</sub>对于外资利用不足的中西部地区而言，应规避传统区位选择因素方面的不足，通过加大研发投入<sub>、</sub>培养区域自主创新能力<sub>、</sub>提高本地区的技术效率水平<sub>、</sub>加快推进本地区的技术进步幅度，以增强本地区对外商直接投资的吸引效应<sub>。</sub>
