# 省级文化行政部门公共文化服务绩效评估研究

□ 胡税根 李幼芸

摘要:政府的主要职能是为社会提供公共服务，公共文化服务是政府公共服务的重要内容之一 在服务型政府建设进程中，对其公共文化服务工作的绩效评估是提升政府公共文化服务能力与保障人民基本文化权益的重要途径<sub>。</sub> 本文以省级文化行政部门为对象，在对其公共文化服务职责进行分析的基础上，构建评估理论模型并设计赋权重的省级文化行政部门公共文化服务绩效评估指标体系，以期推动文化行政部门公共文化服务的绩效评估理论研究与实践发展

关键词:省级文化行政部门;公共文化服务;绩效评估;指标体系

公共文化服务是政府公共服务的重要内容之一，文化行政部门作为履行公共文化服务职责的政府部门，其履职情况和公共文化服务水平与人民群众基本文化权益的实现直接相关 而省级文化行政部门在贯彻落实中央公共文化服务政策中起到关键的作用，同时又承担着指导基层政府公共文化服务工作的重任，因此，通过绩效评估推动省级文化行政部门职责的有效发挥，对于更好地发展文化事业 更好地满足人民群众对公共文化服务的需求具有积极的意义

## 一 研究综述与问题的提出

目前，学术界已对公共文化服务绩效评估开展了一定程度的研究，对这些已有研究可以从政府公共文化服务职责 公共文化服务绩效评估 文化行政部门公共文化服务绩效评估等方面加以梳理<sub>。</sub>

关于政府公共文化服务职责的研究 陈威(2006) 指出，政府是公共文化服务体系建设的责任主体，其公共文化管理职能与职责包括确定文化发展战略与核心价值理念 制订公共文化事业发展规划与文化政策 保证公共文化服务的经费投入 对公共文化服务的实施主体进行监管与绩效考评 维护文化安全等<sup>①</sup> 周晓丽 毛寿龙(2008) 提出，公共文化服务是文化领域的公益性物品或服务，在公共文化服务中，政府需最大限度地 有组织地整合公共文化资源，实现多层次 多样化 整体性的文化利益<sup>②</sup><sub>。</sub> 陈世香(2010) 认为，文化行政部门只承担审计 监督 规划等行政职能，强调将政府职能与文化生产功能分开①<sub>。</sub> 陈立旭(2010) 对我国改革开放以来文化领域的发展趋势作出了概括: 由政府大包大揽的 <sup>“</sup>文化事业<sup>”</sup>，到把公益性文化事业和经营性文化事业区分开发展，再到十六大以后将公益性文化事业表述为 <sup>“</sup>公共文化服务体系<sup>”</sup>②<sub>。</sub> 李少惠<sub>、</sub>余君萍(2012) 在总结西方国家文化管理体制发展阶段时提到，上世纪80 年代末以来西方国家由原先的自由放任阶段 现代管理体系阶段转入了公共文化服务的转型阶段，开始进行文化管理体制改革，强调服务理念③<sub>。</sub> 虽然学者对公共文化服务的作用与呈现形式有不同的理解，对文化行政部门的职责也有不同的界定，但在文化行政部门对公共文化服务与国家公共文化服务体系建设负有重要责任这一方面达成了共识<sub>。</sub>

关于公共文化服务绩效评估的研究 陈威(2006) 提到公共文化服务绩效评估应从效率 效益 公平度三方面进行考察④ 蒋建梅( 2008) 认为政府公共文化服务绩效评价的内容应该包括三个方面，一是反映文化对经济 社会发展的反作用的总体指标，二是公共文化服务有效供给，三是公共文化服务的保障⑤ 李少惠 余君萍( 2009) 根据不同评价主体和评价对象分别设计评估指标体系，其中专家侧重对基础设施 活动 主管部门的评估，公众侧重对服务质量的评估，第三方则侧重对保障条件的评估⑥ 焦德武(2011) 对公共文化服务绩效评价指标的设置作了探讨，认为指标第一层级考虑公共文化服务对国民经济发展的贡献，另一方面从<sup>“</sup>社会公正<sup>”</sup>出发进行设计，指标权重的设置也应偏向 <sup>“</sup>社会公正<sup>”</sup>，可重点考量公众易得性<sub>、</sub> 参与性<sub>、</sub> 政府成本<sub>、</sub> 公众满意度<sub>、</sub> 社会效益⑦<sub>。</sub> 彭益民( 2013) 指出，农村公共文化服务体系由文化投入 服务项目以及服务绩效这三个方面组成，因此分别从政府投入<sub>、</sub>队伍建设<sub>、</sub>社会参与<sub>、</sub>服务项目以及服务绩效几个层面对我国农村公共文化服务水平进行评估⑧

关于文化行政部门公共文化服务绩效评估的研究<sub>。</sub> 辛玉军(2012) 从四个维度构建了针对地方政府及其文化行政部门的文化行政绩效评估指标体系，具体有包含公共图书馆，博物馆 美术馆，文化馆(站) ，影剧院，音乐厅，名胜古迹等的基础建设绩效指标;包含电影 展览，音乐会，文化节 艺术节，表演团体 文艺演出，体育比赛 健身活动等的社会参与绩效指标; 包含预算投入总量，公共设备投入年均增长量等的预算投入绩效指标; 包含出版社 杂志社，电视台 电台，网站，报社，文化协会 管理部门等的运行机制绩效指标等内容⑨ 谢媛(2012) 指出，目前我国的公共文化服务绩效评估主要以公共文化服务主管部门为评估主体，评估对象主要有主管部门 直属文化机构 文化活动以及公共文化服务体系四类瑏瑠，其中对文化机构 文化活动以及公共文化服务体系的绩效评估已开始有所探索，而对各级文化行政主管部门尤其省级文化行政主管部门公共文化服务的绩效评估相对缺乏

我国各级政府对公共文化服务绩效评估也开始进行了初步探索，如浙江省文化厅在2011 年开展的基层公共文化服务绩效挂钩奖励资金考核瑏瑡，山西省在 2011 年度全省公共文化服务绩效考核评价中提出了 <sup>“</sup>公共文化服务绩效考核评价指数<sup>”</sup>①等<sub>。</sub> 国内的公共文化服务绩效评估多为针对基层政府公共文化服务，而对文化行政部门公共文化服务职责履行绩效评估的实践相对较少，对省级文化行政部门绩效评估的实践更是空白<sub>。</sub>因此，现阶段立足于省级文化行政部门，对政府公共文化服务的绩效评估模式进行探索，重点研究评估指标体系构建，有其必要性和紧迫性<sub>。</sub>

## 二<sub>、</sub>省级文化行政部门公共文化服务绩效评估:模型设计与指标体系构建

## ( 一) 省级文化行政部门公共文化服务绩效评估模型设计

政府绩效评估指标体系构建有政府职能 政府服务承诺 行政绩效和公众满足度四种依据来源② 建立省级文化行政部门公共文化服务绩效评估指标体系之前，首先需要分析省级文化行政部门的公共文化服务职责 本文对北京 浙江 广东 黑龙江 湖北及四川等省( 直辖市) 的文化行政部门进行职责梳理发现: ①拟定文化相关政策法规及文化事业发展规划; ②指导公共文化服务体系建设; ③指导不同类型人群文化工作; ④指导公共文化事业; ⑤指导文化艺术普及; ⑥公共文化服务信息资源建设与古籍保护; ⑦组织协调重大社会文化活动与指导基层群众文化工作等是省级文化行政部门公共文化服务职责的基本内容 其工作与职责范围主要涵盖了宏观政策法规制定 公共文化事业支持 公共文化产品供给保障 公共文化服务人才队伍建设 公共文化服务资金管理和基层公共文化服务设施建设等方面，涉及公共文化服务的资金投入 人才投入 政策保障 资源管理 工作指导 设施建设与产品供给等内容

根据以上职责，我们通过借鉴 <sup>“</sup>投入 －过程 －产出 －成果<sup>”</sup>模型③ <sup>“</sup>4E<sup>”</sup>评价模型及360 度评价模型等，结合省级文化行政部门职责特点与实际情况分析，根据目标一致原则 科学性原则和可行性原则，设计如下省级文化行政部门公共文化服务绩效评估模型( 见下图) <sub>。</sub>

( 二) 省级文化行政部门公共文化服务绩效评估指标体系构建

## 1． 指标体系的初步构建

根据已设计的绩效评估模型和 SMART 原则，结合省级文化行政部门职责分析，初步构建了省级文化行政部门公共文化服务绩效评估指标体系，其中一级指标包括公共文化服务投入 公共文化服务过程 公共文化服务产出和公共文化服务效果 4 个维度，二级指标指向省级文化行政部门公共文化服务的职能与目标，包括资金投入 人才投入 科技投入 目标管理 资源管理 公共文化指导 基础设施 产品与利用<sub>、</sub> 公民满意度<sub>、</sub> 直属公共文化机构满意度 上级部门满意度等 11 项指标，三级指标基本涵盖了省级文化行政部门公共文化服务的具体工作任务与反馈，含 57 项指标<sub>。</sub>

## 2． 评估指标的实证筛选

为保证指标体系的科学性 合理性，需对初步构建的指标体系进行效度检验 指标实证筛选分两轮，第一轮采用隶属度分析法开展内容效度分析，第二轮采用因子分析法开展结构效度分析①对筛选后的指标体系采用层次分析法进行权重设计②<sub>。</sub>

## (1) 评估指标的内容效度分析

设定的指标能否有效地反映评估内容是内容效度分析需要回答的主要问题<sub>。</sub> 本研究采用隶属度分析法对其进行检验，即向相关研究人员与实务工作者发放调查问卷③，要求从一 二 三级( 共72 项) 指标中选择最具代表性的指标( 其中隶属度分析筛选针对三级指标，对一级与二级指标的评价仅作为验证性过程) 具体步骤如下: ①采用Likert5 级量表的标准形式将指标体系设计成调查问卷; ②向调查对象发放调查问卷，要求对每一项指标的重要性进行评分; ③根据调查结果计算每一项指标的平均得分，并以此作为评判隶属度的依据，各项指标按均分进行排序; ④根据排序结果筛选出最重要的指标

依据问卷数据和隶属度排序的结果对 26 项隶属度较低的三级指标予以删除 筛选后的指标体系内容包括公共文化服务投入 公共文化服务过程 公共文化服务产出和公共文化服务效果 4项一级指标，资金投入 目标管理 资源管理 公共文化指导 基础设施 产品与利用 公民满意度 直属公共文化机构满意度 上级部门满意度 9 项二级指标和31 项三级指标

通过内容效度检验后，仍需对指标体系结构进行效度检验，即通过因子分析来检验所假设的结构是否能够反映真实的结构，从而提高指标体系的结构科学性<sub>。</sub> 具体步骤如下: ①利用隶属度分析环节中的调查问卷数据，获取因子分析涉及的三级指标数据; ②使用 SPSS 软件对第一轮筛选后的31 个三级指标进行 KMO 值检验; ③借助主成分分析法提取31 项指标的公因子，同时对三级指标进行必要的结构调整或删减; ④对公因子进行解释命名，获得结构效度较高的指标体系<sub>。</sub>

初次检验的 KMO 值为 0． 798，因子分析理论上可取得较理想的效果 随后在 SPSS 软件中开展提取公因子的分析 主成分分析后的方差解释表中给出的结果是，8 个公因子解释了 31 个原有变量信息量的 70． 686%，其中前 4 个公因子累积解释力为55．321% 为进一步提高公因子的解释力，剔除在前 4 个公因子上负载较低且与其它指标比较相似的 5 个指标之后，再次进行主成分分析得到7 个公因子，其累积解释力达到71．1%，此时 KMO 值也提高到 0． 833

接着对所得的 7 个公因子进行解释，其目的是通过发现与分析公因子优化指标体系的整个结构确保该结构及指标体系本身的有效性 我们使用方差最大正交旋转因子负载矩阵，找出每个因子解释力较大即因子负载较大的指标，根据在每个公因子上负载最大的指标内容对公因子进行命名，对于明显不符合的指标予以调整或删除 F1－F7 公因子命名的结果依次为: <sup>“</sup>公共文化基础资源建设<sup>” “</sup>公民满意度<sup>” “</sup>公共图书馆使用<sup>”</sup><sup>“</sup>资金投入<sup>” “</sup>群众文化活动<sup>” “</sup>文化行政部门职责履行<sup>” “</sup>公共文化机构数量<sup>”</sup>( 见表1)

## 3． 指标体系的权重设计

确定相对科学合理的三级指标体系后，再使用层次分析法对指标进行权重设计，即通过分析问卷中专家对各项指标重要性的判断确定指标的相对重要性，赋予相应的权重<sub>。</sub>① 具体步骤如下:①采用 Likert5 级量表的标准形式，以筛选后的指标体系为基本内容制作权重设计调查问卷; ②向调查对象发放调查问卷，要求调查对象对每一项指标的重要性作出判断; ③根据调查结果计算每一项指标的相对重要程度，得到每一项指标的相对权重; ④将相对权重依次相乘，得到每一项指标的最终权重<sub>。</sub>

相对重要性的判断使用 <sup>“</sup>评价等级和<sup>”</sup>统计每项指标的重要程度:

$$
\mathrm{S} _ {\mathrm{j}} = \sum_ {\mathrm{i} = 1} ^ {\mathrm{m} _ {\mathrm{j}}} \mathrm{R} _ {\mathrm{ij}}
$$

其中 $\mathrm { , } \mathrm { \mathsf { S } _ { j } }$ 为指标j 的评价等级和; $\mathbf { m } _ { \mathrm { j } }$ 为对指标j进行评价的专家总人数; $\mathrm { R _ { i j } }$ 为专家 i 对指标 j 的评价等级 评价等级和 $\mathrm { S _ { j } }$ 越大，指标的相对重要性越高(评价等级从完全不重要到非常重要依次赋1 －5分) 根据三个层次指标的评价等级和及各层次指标的重要程度排序结果，依据 Saaty 标度得到三个层次指标的两两判断矩阵 随后进行层次单排序和一致性检验，计算每一个上层指标对应的下层指标组中的每一个指标的权值分配，具体通过计算判断矩阵的最大特征根和特征向量得到一级指标 二级指标与三级指标的权重系数，并全部通过了一致性检验 最后，将所得的相对权重按照依层相乘的方法进行转换计算，即得到各级指标的最终权重，从而获得赋权重的省级文化行政部门公共文化服务绩效评估指标体系(见表2)

## 4．绩效评估结果的统计

应用省级文化行政部门公共文化服务绩效评估指标体系时，指标评价按照5 分制进行，每项三级指标根据具体制定的赋分细则获得评估值 依据权重体系，评估对象的<sup>“</sup>最终成绩<sup>”</sup>即综合评估值的

计算公式如下:

$$
\mathrm{G} = \sum_ {\mathrm{i} = 1} ^ {\mathrm{m}} \sum_ {\mathrm{j} = 1} ^ {\mathrm{n}} \sum_ {\mathrm{k} = 1} ^ {\mathrm{p}} \mathrm{W} _ {\mathrm{ijk}} \times \mathrm{G} _ {\mathrm{ijk}}
$$

其中 $\mathbf { , G }$ 为该省级文化行政部门公共文化服务绩效的综合评估值，m 为一级指标的个数 $\mathbf { \mu } _ { \mathbf { 5 } \mathbf { n } }$ 为第 i个一级指标对应二级指标的个数 $\mathbf { \Omega } ^ { \mathbf { \Omega } , \mathrm { p } }$ 为第 j 个二级指标对应三级指标的个数， $\mathbf { W } _ { \mathrm { i j k } }$ 为第i 个一级指标中第j 个二级指标中第k 个三级指标在整个评价指标体系中所占的权重， $\mathrm { C _ { i j k } }$ 为第 i 个一级指标中第个 j二级指标中第 k 个三级指标的评估值<sub>。</sub> 根据各项三级指标的评估值，使用上述综合评估值计算公式即得到该省级文化行政部门最终的评估得分，其值域范围也在0 －5 分之间 同时，根据三级指标评估值 综合评估值 三级指标权重等已知数据也可对二级指标或三级指标进行计算分析

## 三<sub>、</sub>总 结

公共文化服务绩效评估是推动新时期我国政府公共文化服务工作的重要途径，也是建设服务型政府的必然要求<sub>。</sub> 对省级文化行政部门公共文化服务绩效评估模型和指标体系进行科学的设计，目的是了解省级文化行政部门公共文化服务绩效水平，推动文化行政部门公共文化服务质量的提升然而，评估文化行政部门公共文化服务工作的绩效水平不是评估的最终目的，文化行政部门长远发展和战略目标的实现也不可能仅通过单一的绩效评估就能实现<sub>。</sub> 因此，必须建立健全相应的保障机制，一方面可将绩效评估结果与人事制度和薪酬制度相联系，另一方面可将评估结果通过<sup>“</sup>标杆法<sup>”</sup>进行对 比 以 找 到 相 应 的 绩 效 差 距 ( Performance$\mathrm { G a p } )$ ②，总之，通过评估省级包括其他各级文化行政部门职责履行和公共文化服务绩效，总结公共文化服务的经验和存在的问题，并及时地加以改进，有助于更好地保障人民基本文化权益的实现，最终推动我国社会主义文化的大发展大繁荣 □
