# 基础设施建设打破了国内市场分割吗?

范 欣 宋冬林 赵新宇

内容提要:从理论上来说，作为社会先行资本的基础设施建设一定程度上有助于打破国内市场分割，为构建现代市场体系奠定基础 本文基于新经济地理学理论，利用1993—2012 年我国省际面板数据，采用空间面板杜宾模型对我国基础设施建设与市场分割的关系进行研究分析 实证结果表明，<sup>“</sup>以邻为壑<sup>”</sup>现象在中国仍长期存在; 基础设施建设作为打破市场分割的物质基础，可为政府加强基础设施建设提供理论支撑;基础设施建设的空间溢出效应呈现出阶段性差异;不同区域或不同区位下市场分割的策略性行为并非一致 基于此，政府应加强基础设施建设，缩小基础设施建设的区域差异;同时，加强投资主体的跨区域协作，削弱地理界限对市场的不利影响; 此外，政府应积极打造现代服务型政府，充分发挥政策导向功能，避免人为过多干预市场秩序，进而实现市场在资源配置中发挥决定性作用，以期建立现代市场体系

关键词:基础设施建设 空间溢出 市场分割 空间面板杜宾模型

## 一<sub>、</sub> 引 言

近三十多年来，中国的发展实绩得益于劳动者积极性和创造性的激发，也得益于改革开放政策及其释放的制度红利，特别是市场机制在资源配置中发挥的积极作用 历史经验表明，市场机制作用的发挥有赖于市场的整合和统一，而不是市场的分散与孤立 统一的国内市场能够促进市场竞争充分开展<sub>、</sub>规模经济发挥作用和市场规则逐步规范，使得资源可以自由流动<sub>、</sub>并最终流向最有效率的部门 因此，打破市场分割 促进市场融合，加快建立统一开放 竞争有序的现代市场体系，推动市场机制在资源配置中从基础性作用向决定性作用转变，已经成为我国市场经济发展面临的重大现实问题

自从中国明确建立社会主义市场经济体制的改革目标以来，有关中国国内市场分割的研究逐渐增多<sub>。</sub> 关于市场分割程度的测度方法主要有生产法( Young，2000; 白重恩，2004) 贸易法( Naughton，1999; Poncet，2003) 调查问卷法( 李善同等，2004) 产需法( 张昊，2014) 经济周期法( 陈昆亭等，2004) 价格法(桂琦寒等，2006;陈刚等，2013) 等 利用上述测度方法，研究者对中国国内市场分割进行了初步测度，并基本认同中国存在一定程度的市场分割<sub>。</sub> 对于一些特定市场的研究结果表明，中国的市场分割程度呈现出(波动) 降低趋势(喻闻等，1998;黄季焜等，2002;李杰等，2004)

造成中国国内市场分割的原因是值得深思的 最初的研究主要从地方保护和经济开放两个方面展开 在地方保护方面，财税体制改革实际上就是中央政府 地方政府及企业之间的契约关系( 吕冰洋等，2014) ，这种财政分权实际上是地方保护主义的一种体现( 白重恩，2004) ，若政府对市场干预过多，将明显不利于市场整合( Poncet，2005;刘小勇等，2008) 中国市场分割产生的重要原因在于赶超战略的实施( 林毅夫等，2004) ，其动机在于极强的物质利益驱动( 平新乔，2004) 在经济开放方面，理论上经济开放对市场分割的作用机制较为复杂，不同作用机制下效果不一( 陈敏等，2007) 一些经验分析发现，经济开放与市场分割呈现 <sup>“</sup>倒 U 型<sup>”</sup>关系，即当经济开放水平较低时，经济开放会加剧市场分割，但进一步扩大经济开放则能抑制市场分割( 宋冬林等，2014) 我国出口贸易之所以快速增长，主要在于市场分割严重限制了资源的跨区域流动，进而导致企业被迫出口的一种扭曲现象( 朱希伟等，2005)

一般来说，国内市场趋于统一是一个渐进的历史过程，市场分割也并非经济转轨时期的特有现象 同时，导致国内市场出现分割的影响因素具有多样性，大体可分为自然因素 技术因素和制度因素三种<sub>。</sub> 自然性市场分割是指两地受空间距离等物理因素影响，进而自然形成的 分隔的两个市场;技术性市场分割指两地因劳动者素质<sub>、</sub>技术水平的成熟度等不同，进而形成以技术水平差异为特征的两个市场;制度性市场分割是指两地受到经济 政治等人为因素影响，形成以地方保护为特征的两个市场<sub>。</sub> 由此，我们可以得到打破国内市场分割的两条有效途径: 一是通过增加交通运输信息通讯<sub>、</sub>城市公用事业等基础设施建设的资金投入，提高市场交易效率，进而降低自然性市场分割和技术性市场分割; 二是通过消除地方保护 优化制度设计减少制度性市场分割 刘生龙等(2011) 认为，国内研究者更多地从财政分权后的地方保护主义角度对中国市场分割进行解释，而忽视了交通基础设施等影响因素<sub>。</sub> 换言之，相关研究主要集中在制度性市场分割领域，而在自然性市场分割和技术性市场分割领域的文献还不多见<sub>。</sub>

事实上，即使是在评价中国经济增长的文献中，基础设施建设的作用也在一定程度上被忽视，从而表现出贬低<sup>“</sup>硬件<sup>”</sup>而更多强调<sup>“</sup>软件<sup>”</sup>的重要性( 张军等，2007) 作为一种社会先行资本，基础设施建设是经济增长的重要前提条件，它对经济增长存在外部溢出效应或正外部性( Young，1928; Rosentein-Rodan，1943; Hirschman，1958; Rostow，1960; Romer，1986; Lucas，1988; Barro，1990)近二十多年来，基础设施建设在中国获得了极大重视，并推动了中国经济的高速增长 刘生龙等(2010) 的研究表明，交通基础设施和信息基础设施的溢出效应显著<sub>。</sub> 张光南等( 2013) 的研究发现，基础设施建设的空间溢出对制造业产出的成本效应较大 张学良(2012) 的研究指出，中国交通基础设施建设对区域经济增长的空间溢出效应显著 这种溢出效应是基础设施建设对经济增长的间接作用，主要体现在交通 信息 能源 商贸等基础设施建设能够降低区域间贸易成本 扩大规模效应 促进专业分工，即通过打破国内市场分割促进经济增长

值得注意的是，我国( 省级) 政府在财政分权后对基础设施建设的重视，主要源于基础设施建设对本地经济增长的贡献( 其投资效应对经济增长产生直接拉动，其外溢效应则在于对域内市场的整合) ，而省际之间基础设施建设的接驳还有待考察 同时，基础设施建设的资金主要来自于政府的财政收入和地方融资，随着资金缺口的增大和地方融资引致的债务到期，地方政府可能不得已地采取地方保护以期实现债务平衡，这又会加剧市场分割 因此，实证研究我国基础设施建设对国内市场分割的影响具有一定的理论与现实意义，这也是本文写作的出发点和落脚点 本文余下结构安排如下: 第二部分构建基础设施建设与市场分割之间关系的理论模型;第三部分介绍基础设施建设和市场分割的演变;第四部分是构建计量模型，介绍相关变量及数据来源; 第五部分从整体阶段 分阶段及非对称比较分析基础设施建设对市场分割的影响;第六部分是本文的主要结论及政策建议<sub>。</sub>

## 二<sub>、</sub> 基础设施建设与市场分割: 一个简单的理论框架

基于陆铭等(2004，2007) 范子英等(2010) 的做法，本文试图构建一个跨期分工决策模型，其包含两个地区( A 地区和 B 地区) 两个部门( h 部门和 l 部门) 和两段时期( $t _ { 1 }$ 和 $t _ { 2 } \big )$ A 地区经济发展水平较高，其 h 部门生产产品的技术水平较高，基本以从事复杂劳动为主，在高新技术产品上具有比较优势;而 B 地区经济发展水平较低，其 l 部门生产产品的技术水平较低，基本以从事简单劳动为主，在初级产品上具有比较优势 与 l 部门相比，技能进步速度在 h 部门较快，为简化起见，假设<sup>“</sup>干中学<sup>”</sup>效应仅存在于 h 部门 为使模型求解简便，令效应函数为: $\boldsymbol { u } = \boldsymbol { c } _ { h } \cdot \boldsymbol { c } _ { l }$ ，其中 $c _ { h }$ 表示高新技术产品的消费 $\bullet ^ { c _ { l } }$ 表示初级产品的消费<sub>。</sub> 在两期的时间分配上，将其标准化为2<sub>。</sub> 在产品生产过程中，假定只有一种要素投入即劳动力资源，且不存在劳动力的跨区域流动，并将其标准化为1<sub>。</sub>与 B 地区的高新技术产品相比，A 地区的高新技术产品的相对初始技术为 $\alpha$ ，技术进步速度为 <sub></sub>，两地区在初级产品上的相对技术进步和初始技术均标准化为1<sub>。</sub> 接下来主要探讨以下两种情况:

## ( 一) 商品不跨区流动的跨期分工决策

首先，在不考虑分工的跨期决策中，我们将第一期和第二期相应变量分别用下标进行表示<sub>。</sub> 为了简化，假设 l 部门的产品的规模报酬不变，生产函数是投入时间的线性函数，时间是唯一的投入品，在此假设体现时间偏好的时间贴现因子为1 生产的收益递增只能依靠 <sup>“</sup>干中学<sup>”</sup>效应来体现我们将 B 地区的产出用 表示，而 A 地区的产出用 Y表示，其中 ${ \sf , } t _ { 1 } { \sf , } t _ { 2 } { \sf ( } \ T _ { 1 } { \sf , } T _ { 2 } { \sf ) }$ 分别表示两期中分配到 B 地区( A 地区) h 部门的时间<sub>。</sub> 当市场处于完全分割时，各地区生产的产品只能用于本地消费，因此 B 地区在两阶段的生产函数可表示为:

$$
\begin{array}{r l} c _ {1 h} & = y _ {1 h} = t _ {1} \\ c _ {1 l} & = y _ {1 l} = 1 - t _ {1} \\ c _ {2 h} & = y _ {2 h} = \left(1 + t _ {1}\right) \cdot t _ {2} \\ c _ {2 l} & = y _ {2 l} = 1 - t _ {2} \end{array}\tag{1}
$$

由此可见，B 地区实现最优规划是最大化各自的跨期效应和:

$$
\begin{array}{r l} \max _ {c _ {1 h}, c _ {2 h}} u & = c _ {1 h} \cdot c _ {1 l} + c _ {2 h} \cdot c _ {2 l} \\ \text {s.t.} & c _ {1 l} + c _ {1 h} = 1 \\ c _ {2 l} + c _ {2 h} / (1 + c _ {1 h}) & = 1 \end{array}\tag{2}
$$

针对 B 地区的效用函数分别求导，经化简可得:

$$
c _ {1 h} = \frac {5}{8} c _ {2 h} = \frac {1 3}{1 6} u _ {1} = \frac {4 1}{6 4}\tag{3}
$$

同理，A 地区实现效用最大化应满足:

$$
\begin{array}{r l} \max _ {C _ {1 H}, C _ {2 H}} U & = C _ {1 H} \cdot C _ {1 L} + C _ {2 H} \cdot C _ {2 L} \\ \text {s.t.} & C _ {1 L} + C _ {1 H} / \alpha = 1 \\ C _ {2 L} + C _ {2 H} / [ \phi A (1 + \frac {C _ {1 H}}{\alpha}) ] & = 1 \end{array}\tag{4}
$$

针对 A 地区的效用函数分别求导，可得:

$$
C _ {1 H} = \frac {\alpha}{2} \left(1 + \frac {\phi}{4}\right) \quad C _ {2 H} = \frac {\phi \alpha}{2} \left(\frac {3}{2} + \frac {\phi}{8}\right) \quad U _ {1} = \frac {\alpha}{4} \left(1 + \frac {3 \phi}{2} + \frac {\phi^ {2}}{1 6}\right)\tag{5}
$$

以上反映的是商品在跨区域市场上无法流通的情景，即完全分割的商品市场 一般而言，商品完全依赖自身技术和水平进行生产的模式并非市场主体的理性选择

## ( 二) 商品跨区流动的跨期分工决策

存在套利的分工的出现，为商品的跨区域流动提供了动力 在现实生活中，若基于比较优势进行生产，不得不考虑运输成本等因素对市场的影响 为此，对于 A 地区与 B 地区之间的运输成本，本文采用冰川成本的形式表示，即在不同地区的产品运输过程中 $\bullet ^ { d }$ 单位产品中仅有1 单位产品能抵达目的地进行交易，其中 d 表示不同地区之间的运输条件，受到自然条件 制度性障碍等因素的影响<sub>。</sub> 同时，假定 B 地区 l 部门生产的单位产品的相对价格为1，而 A 地区 h 部门生产的单位产品的相对价格为P( P ＞1) 考虑到商品在跨区域流动中会被征税，为简化起见，假定税收是定额的且其全部用于基础设施建设 基于模型为两期动态模型，以居民最大化为目标的政府，第一期将会征税，而第二期则不再征税 考虑到地区差异，我们将B 地区和A 地区的税收收入分别用f<sub>r</sub> 和FR 表示，且 $f r \neq F R$ 此外，考虑到基础设施建设与运输成本的反向关系( Bougheas et al．，1999) ，不妨假设 A 地区和 B 地区的初始运输成本分别为 $D _ { 0 }$ 和 $d _ { 0 }$ ，而第二期的运输成本分别为为 $D \big ( ~ F R \big )$ 和 d(fr) <sub>。</sub> 为简化处理，各地区在比较优势下进行生产，B 地区全部由 l 部门生产初级产品，而 A 地区全部由 h 部门生产高新技术产品<sub>。</sub> 基于上述假设，B 地区实现效用最大化应满足:

$$
\begin{array}{l} \max _ {c _ {1 h}, c _ {2 h}} u = c _ {1 h} \bullet c _ {1 l} + c _ {2 h} \bullet c _ {2 l} \\ \text { s   .   t   . } \quad c _ {1 l} + d _ {0} P c _ {1 h} = 1 - f r \\ \quad c _ {2 l} + d (f r) P c _ {2 h} = 1 \end{array}\tag{6}
$$

针对 B 地区的效用函数分别求导，经化简可得:

$$
c _ {1 h} = \frac {1 - f r}{2 d _ {0} P} c _ {2 h} = \frac {1}{2 d (f r) P} u _ {2} = \frac {(1 - f r) ^ {2}}{4 d _ {0} P} + \frac {1}{4 d (f r) P}\tag{7}
$$

同理，A 地区的消费和效应可得:

$$
C _ {1 H} = \frac {P \alpha - F R}{2 P} \quad C _ {2 H} = \frac {\phi \alpha}{2} \quad U _ {2} = \frac {(P \alpha - F R) ^ {2}}{4 D _ {0} P} + \frac {P \phi^ {2} \alpha^ {2}}{4 D (F R)}\tag{8}
$$

从上可知，无论地区经济发展水平如何，运输条件 产品的相对价格 基础设施建设等均是影响市场分割程度的重要因素<sub>。</sub> 从(7) 式和(8) 式中，不难发现，基础设施建设与市场分割之间呈现出非线性关系，可见其作用机理具有一定的复杂性 从作用机理来看，一方面基础设施建设来源于税收收入，而地方税收收入的高低将影响市场分割的程度( 沈坤荣等，2006) ; 另一方面，基础设施建设特别是交通基础设施建设，有利于提高交易效率，降低运输成本，进而影响市场分割程度 同时，地区间的策略选择存在以下四种情形: (1) 若 $u _ { 2 } < u _ { 1 }$ 和 $U _ { 2 } < U _ { 1 }$ ，即意味着 <sup>“</sup>以邻为壑<sup>”</sup>现象在各地区存在 无论是 A 地区还是 B 地区，为实现自身效用最大化，均愿意各自生产，实现自给自足，即完全分割的商品市场;(2) 若 $u _ { 2 } < u _ { 1 }$ 和 $U _ { 2 } > U _ { 1 }$ ，则意味着 B 地区则愿意采取商品自行生产的方式实现效用最大化，而 A 地区基于自身产品优势，愿加强区域之间的分工与合作，主要用于生产具有比较优势的高新技术产品<sub>。</sub> 如果 A 地区的效用增量大于 B 地区的效用减量时，则意味着整体社会福利是上升的，中央政府会鼓励两个地区共同开放，对经济相对落后地区进行转移支付( 范子英等，2010) ，以期实现社会福利的整体提升 相反，而采取不一样的政策应对 ( 3) 若 $u _ { 2 } > u _ { 1 }$ 和$U _ { 2 } < U _ { 1 }$ ，则意味着 B 地区为实现自身效用最大化，愿采取区域开放政策，主要用于生产具有比较优势的初级产品;而 A 地区则愿意采取自行生产的方式实现效用最大化 如果 B 地区的效用增量大于 A 地区的减量时，则意味着整体社会福利是上升的，中央政府会鼓励两个地区共同开放，加强区域间基础设施建设，以期实现社会福利的增大 相反，而采取不一样的政策应对 (4) 若 $u _ { 2 } > u _ { 1 }$ 和$U _ { 2 } > U _ { 1 }$ ，则意味着无论是 A 地区还是 B 地区，均愿意采取开放的姿态，基于比较优势下进行分工与生产，以期实现自身效用最大化<sub>。</sub>

## 三<sub>、</sub> 基础设施建设与市场分割的演变

在中国长期经济快速增长的背后，基础设施建设的规模效应 网络效应等发挥着不可或缺的作用 目前，基础设施建设测度暂无统一标准，研究者往往根据各自的研究主题需要，选取不同的指标进行测度<sub>。</sub> 本文基于金戈(2012) 关于基础设施建设的测算，对其统计范围进行适当修正，并尽可能剔除因统计口径变化所造成的差异性 ① 通过确定基期资本存量② 固定资产投资价格指数 折旧率(9. 6%) 等，采用 <sup>“</sup>永续盘存法<sup>”</sup>加以计算 从计算结果来看，自 1993 年以来，基础设施建设资金总额稳中有升 图1 反映的是中国及其内部四大区域基础设施建设资金总额的时间趋势<sub>。</sub>

如图1 所示，基础设施建设呈现以下特征: 第一，我国及其内部四大区域的基础设施建设趋势几近一致，基础设施建设资金总额增长迅猛 从全国层面来看，1993 年基础设施建设资金总额为2. 72 万亿元，至2012 年上升至20. 38 万亿元，年均增长11% <sub>。</sub> 从区域层面来看，在基础设施建设资金总额年均增长率方面，西部地区的增幅最大，其次是中部地区和东北地区，最后是东部地区，年均增长分别为 12. 73% <sub>、</sub>11. 04% <sub>、</sub>10. 99% <sub>、</sub>10. 91%; 在基础设施建设资金总额增长倍数方面，与1993 年相比，西部地区 中部地区 东北地区和东部地区分别增长了 8.40 倍 6.11 倍 5. 84 倍5. 93 倍 由上可见，在国家区域发展战略背景下，开始呈现出基础设施建设区域非均衡性特征第二，基础设施建设资金总额增幅存在折点 无论从全国层面还是区域层面看，自2003 年开始，基础设施建设资金总额出现较大幅度上升<sub>。</sub> 具体来说，从全国层面来看，1993—2002 年我国基础设施建设资金总额年均增长率为 5.47%，而 2003—2012 年则为 15.97% 从区域层面来看，西部地区在 1993—2002 年期间的年均增长率为 6. 93% ，而 2003—2012 年则为 17. 96% ; 中部地区在1993—2002 年期间的年均增长率为 6. 67% ，而 2003—2012 年则为 14. 97% ; 东北地区在 1993—2002 年期间的年均增长率为 3. 73% ，而 2003—2012 年则为 17. 53% ; 东部地区在 1993—2002 年期间的年均增长率为 5. 34% ，而 2003—2012 年则为 15. 93% <sub>。</sub>

加快基础设施建设有利于加速资源的跨区域流动，进而促进区域间的分工与合作 为加快不同区域间的市场一体化进程，加强基础设施建设或将成为地方政府采取的主要手段之一 市场分割的测度方法较多，本文采用较常用的相对价格指数法加以测算( 宋冬林等，2014) ，①得出全国及各区域的市场分割程度<sub>。</sub> 图2 表明，在1993—2012 年期间，全国市场虽有波折，但市场整体上呈现出整合趋势，这与既有的研究结论基本一致( 陆铭等，2007) 从峰值的时点上看，这几次较大波动与金融危机或税制改革等时点吻合，可见宏观经济形势以及制度改革等因素对全国市场的影响不容小觑 从区域层面上看，四大区域性市场整体走势与全国市场走势几近一致，仅市场分割程度在各大区域表现不一 从各区域市场分割均值来看，东北地区市场整合程度最高，其次是中部地区和西部地区，最后是东部地区 究其原因，这种区域性市场的差异性与自身实际情况密不可分 作为经济相对发达的东部地区，市场发育程度明显高于其他区域市场，但资源却相对贫瘠 经济相对落后地区的地方政府往往基于自身发展的需要，也愿意采取地方保护主义措施加以干预，以期保护本地产业的发展<sub>。</sub>

基础设施建设在时空上的整体趋势变化虽与市场分割的整体走势几近相反，但这不足以说明基础设施建设有利于打破国内市场分割 基础设施建设对国内市场分割的作用效果尚需进一步通过实证加以证实<sub>。</sub>

## 四<sub>、</sub> 计量模型构建<sub>、</sub>数据来源与说明

在既有研究中，对市场分割的影响因素分析往往重点考察制度因素，而忽视了自然因素和技术因素 本文为打破自然性市场分割和技术性市场分割，引入基础设施建设变量 当然，基础设施建设的网络效应可能产生跨区域空间溢出，即外地基础设施建设将可能会影响到本地市场分割 同时，市场分割可能存在空间溢出效应，即本地政府实施市场分割行为可能会让外地政府考虑是否需要采取同样的措施加以应对 经检验，本文将采取空间杜宾模型 ② 此外，由于市场分割往往具有持续性特征，故将市场分割的滞后项作为解释变量之一引入其中 计量模型构建如下:

$$
\operatorname{Segm} _ {i t} = \rho \sum_ {j = 1} ^ {N} w _ {i j} \operatorname{Segm} _ {j t} + \alpha \operatorname{Segm} _ {i t - 1} + \beta \sum_ {j = 1} ^ {N} w _ {i j} F R _ {j t} + \gamma F R _ {i t} + \sum_ {i} \theta_ {i} M _ {i t} + \alpha_ {0} + \varepsilon_ {i t}\tag{9}
$$

式中 ${ \pmb \rho }$ 为市场分割变量空间滞后项的系数 $\bullet \alpha$ 为滞后一期市场分割变量的系数 $\bullet$ 为基础设施建设空间滞后项的系数， $\bullet \gamma$ 为基础设施建设变量的系数， ${ \bf \Omega } _ { \bullet } \theta _ { i }$ 为控制变量的系数 $\mathbf { \Omega } _ { \bullet } \varepsilon _ { i t }$ 为随机干扰项<sub>。</sub>

显然，在模型(9) 中，由于市场分割的一阶滞后项被当做解释变量引入，从而与随机干扰项相关;同时，市场分割与其他变量之间也可能存在双向因果关系 面对内生性问题，选择合适的估计方法成为了实证估计的重点<sub>。</sub> 在空间计量模型的估计方法上，通常采用极大似然方法进行参数估计，但其依赖于对模型的具体设定，估计结果缺乏稳健性( Baltagi，2007; Conley，2003) ; 也有学者( Su ＆ Yang，2007; Yu et al．，2008) 利用拟极大似然方法( QML) 来提高估计结果的稳健性<sub>。</sub> 虽然QML 可以得到模型参数的一致性估计，但却无法解决通过计算相关估计量的稳健方差协方差矩阵，构建有效的检验统计量，确保推断过程的有效性这一问题 考虑到市场分割的动态性及稳健性，本文尝试采用 Kapoor et al． (2007) 所提出的空间面板误差模型的系统 GMM 方法对模型进行估计 工具变量的选择一般以相邻辖区中其他外生社会经济变量的空间加权作为其工具变量，当然亦有考虑市场分割的动态性，也将被解释变量的滞后项包含其中<sub>。</sub> 从市场分割的影响因素出发，本文将基础设施建设 财政支出比重①视为内生变量，而其他变量则视为外生变量

在上述模型构建中，本文采用的是线性空间模型 然而在实际生活中，基于区域发展战略或对外贸易区位优势差异等因素，不同区域或不同区位下市场分割的策略性行为可能并非一致 在此，假定同属某一区域内相邻的省市与虽相邻但分属不同区域的省市的市场分割反应系数不相同，或者假定我国地处沿海地区的省市与地处内陆地区的省市所对应的市场分割反应系数不一，引入两区制的空间杜宾模型( Elhorst ＆ Fréret，2009) :

$$
\begin{array}{l} \text {Segm} _ {i t} = \rho_ {1} \sum_ {j = 1} ^ {N} d _ {i j} w _ {i j} \text {Segm} _ {j t} + \rho_ {2} \sum_ {j = 1} ^ {N} \left(I _ {i j} - d _ {i j}\right) w _ {i j} \text {Segm} _ {j t} + \alpha \text {Segm} _ {i t - 1} \\ + \beta \sum_ {j = 1} ^ {N} w _ {i j} F R _ {j t} + \gamma F R _ {i t} + \sum_ {i} \theta_ {i} M _ {i t} + \alpha_ {0} + \varepsilon_ {i t} \end{array}\tag{10}
$$

式中 $\pmb { \mathscr { s } } \rho _ { 1 }$ 和 $\rho _ { 2 }$ 分别代表同属某一区域内相邻省市与虽相邻但分属不同区域的省市的市场分割反应系数或者地处沿海地区的省市与地处内陆地区的省市所对应的市场分割反应系数， $J _ { i j }$ 表示经过标准化处理的地理相邻的空间权重矩阵， $\bullet ^ { d _ { i j } }$ 表示是否区域内相邻或者是否地处沿海的对角矩阵，其对角元素的含义为:

$$
d _ {i j} = \left\{ \begin{array}{l l} 1; & \text { 省市 } i \text { 与省市 } j \text { 同一区域内相邻(省市 } i \text { 或省市 } j \text { 位处沿海地区)} \\ 0; & \text { 其他 } \end{array} \right.\tag{11}
$$

在控制变量选择上，参考国内外文献的做法，从中国国情出发，主要选取财政支出比重 对外开放度及其平方项 国有经济比重等 具体来看，基于地方保护是市场分割产生的主要动机之一，故财政支出比重采取扣除科教文卫支出的财政支出占国内生产总值的比重来描述; 考虑到市场分割主要是限制外地商品流入对本地产业的冲击，故对外开放度采用进口总额占国内生产总值的比重来进行衡量;关于国有经济比重变量，采用常用的各省市国有企业就业人数占各省市从业人员数的比重来衡量

在空间权重指标选取上，研究者往往根据研究需要选择或重构新的空间权重矩阵，本文主要选取以下四种空间权重指标: (1) 地理相邻空间权重矩阵，即若两区域在地理位置上相邻，则赋值为<sup>“</sup>1<sup>”</sup>;否则赋值为<sup>“</sup>0<sup>”</sup> (2) 地理距离空间权重矩阵，采用省会城市之间的铁路里程的倒数( $w _ { i j } = 1 /$ $d _ { i j } )$ 进行测度 (3) 经济空间权重矩阵，采用两地经济水平差异的比重来表示，公式为( $w _ { i j } = \big ( 1 / | x _ { i }$ $- x _ { j } \mid \big ) \ ⁄ \sum _ { j } \big ( 1 / | x _ { i } - x _ { j } | \big ) \mid$ (4) 经济社会空间权重矩阵，我们设计了一个<sup>“</sup>GDP +地理距离<sup>”</sup>的空间权重，采用两地经济水平差异的比重与省会城市之间铁路里程的倒数平方的商来进行测度 上述

四种空间权重矩阵均进行了行标准化处理<sub>。</sub>

在数据来源上，各指标的数据主要取自 《中国统计年鉴》 《新中国60 年统计资料汇编》及各省市历年统计年鉴<sub>。</sub> 鉴于经济体制差异和数据可得性等因素，剔除了港澳台地区<sub>、</sub>海南<sub>、</sub>西藏，重庆市数据合并至四川省 研究样本集包括1993—2012 年期间28 个截面的560 个样本观察值 所有变量解释及统计量描述见表1<sub>。</sub>

## 五<sub>、</sub> 实证分析

## ( 一) 市场分割的整体性分析

表2 反映的是不同设定条件下国内市场分割的空间权重矩阵模型的回归结果 从表2 中检验结果来看，不同空间权重的计量模型均通过了相关检验，表明模型选择是合理的 其中 AR(2) 统计量的结果表明，计量模型水平方程误差项并未存在序列相关 Hansen 检验的结果则意味着工具变量的选择从整体上看是有效的 通过添加或删减变量的方法，发现各控制变量的系数及显著性均变化不大，估计结果较为稳健 从表2 中计量结果来看，不同空间权重矩阵下的各变量系数出现一些非规律性变化，这意味着空间权重矩阵的选择会显著影响到实证结果，这与大多数文献保持一致( 谢贞发等，2015) 一些共同规律如下: 市场分割的空间聚集效应显著正相关，基础设施建设对市场分割的空间溢出效应效果不显著等 与不考虑空间溢出效应的模型一相比，经济社会空间权重矩阵下各变量的显著性及系数方向基本保持一致 可见，作为外生变量的经济社会空间权重矩阵的估计结果的稳健性更强，这与理论预期效果一致 ① 故此，接下来我们将重点探讨经济社会空间权重下各系数的情况，②具体来说:

首先，从模型五中 的系数值来看，市场分割存在空间聚集效应，即 <sup>“</sup>以邻为壑<sup>”</sup>现象在我国仍长期存在 在我国从计划经济体制向市场经济体制转型过程中，国家与地方 地方之间的利益相互交织，错综复杂，地方市场分割因此比较突出，曾被视为经济转轨过程中出现的特有现象( 银温泉，2001) 自20 世纪80 年代开始，市场分割的手段开始呈现多样化特征，由传统的地理距离 文化差异隔离转向设置进入壁垒 流出壁垒 技术壁垒等，这些分割形式使得国内统一市场的形成被削弱，资源配置扭曲 为此，中央政府亦或地方政府出台了相关政策措施以期打破这种地方割据的局面，试图构建现代市场体系<sub>。</sub> 近年来，随着市场发育程度的不断提高<sub>、</sub>政策制度( 如分税制改革等) 的不断完善，市场机制在资源配置过程中开始发挥决定性作用，国内市场体系逐步完善<sub>。</sub> 但历史遗留问题使得地方重复建设问题较为严重，地方利益至上原则也让行政壁垒不可能短期内消逝，<sup>“</sup>囚徒困境<sup>”</sup>使得国内市场分割问题依然突出

其次，从实证结果来看，基础设施建设有利于市场整合 与不考虑空间溢出效应的模型相比，基础设施建设的产出弹性值显著变小，这也表明若不考虑基础设施建设的溢出效应，基础设施建设对市场分割的作用效果可能会被高估 在我国，基础设施建设有利于实现本地交通的便利性 通信网络的便捷性，降低运输成本，这将有利于地方政府有动力降低本地市场准入门槛，进而推动市场一体化进程<sub>。</sub>

## ( 二) 市场分割的阶段性分析

自2003 年起，中央与地方政府纷纷加大基础设施的投资力度，致使基础设施建设呈现出阶段性特征<sub>。</sub> 这种阶段性特征的出现是否会带来市场分割的差异性变化? 为此，本文以 2003 年为界，从两个阶段分别研究基础设施建设与市场分割之间的关系

从结果上看，<sup>“</sup>以邻为壑<sup>”</sup>现象在不同阶段仍然存在 前期市场分割反应系数为0.227，而后期市场分割反应系数为0. 4242 这意味着无论在哪个阶段，一旦外地政府实施市场分割，本地政府亦会采取相应的措施加以应对 同时，通过两阶段对比分析，第二阶段的市场分割反应系数较大可见，市场在时序上虽不断趋于整合，但针对外地政府采取地方保护市场的行为时，本地政府在不同阶段采取应对措施的力度不一<sub>。</sub> 对于基础设施建设而言，前期直接效应系数为 －0. 0405，而后期直接效应系数为 －0. 0394; 前期空间溢出效应系数为 －0. 0145，但效果不显著，而后期空间溢出效应为 －0. 1192，且其效果显著，这意味着基础设施建设有利于打破市场分割，随着时间的推移，基础设施建设的作用效果不断凸显，基础设施建设的跨区域接驳将有利于市场一体化进程的推进<sub>。</sub>

## ( 三) 市场分割的非对称性比较分析

## 1． 区域发展战略下不同区域的比较分析

自国家开始实施区域发展战略以来，基础设施建设力度不断加大，城市群 城市带等建设步伐不断加快，一定程度上有利于区域内资源的自由流动，促进了市场在区域内的整合 政府可能更关注区域内省市之间的融合，而忽视跨区域之间的分工与合作<sub>。</sub> 为此，我们假设同属某一区域内相邻的省市与虽相邻但分属不同区域的省市的市场分割反应系数不相同，对其进行非对称分析<sub>。</sub> 具体做法是，将模型中的空间滞后因变量分成两个区制: 区制1 的市场分割反应系数表示同属某一区域内相邻的省市之间实施市场分割的敏感程度;区域2 的市场分割反应系数表示虽相邻但分属不同区域的省市之间实施市场分割的敏感程度

表4 中模型一至模型三分别汇报了整体阶段 分阶段下四大区域内外市场分割的非对称效应分析结果 实证结果显示: 从整体阶段上看，同属某一区域内相邻的省市的市场分割反应系数为0. 1067，而虽相邻但分属不同区域的省市的市场分割反应系数为 0. 6822; 从第一阶段来看，同属某一区域内相邻的省市的市场分割反应系数为 －0. 0077，但效果不显著，而虽相邻但分属不同区域的省市的市场分割反应系数为0. 6791，且其效果显著 从第二阶段来看，同属某一区域内相邻的省市的市场分割反应系数为0. 0266，但效果不显著，而虽相邻但分属不同区域的省市的市场分割反应系数为0. 6138，且其效果显著 基于两者的同期对比来看，无论处于哪个阶段，同属某一区域内相邻的省市的市场分割反应系数均显著小于虽相邻但分属不同区域的省市的市场分割反应系数，这意味着区域内相邻省市之间的协同作用可能在增强，而跨区域相邻省市之间的分工合作可能仍存在跨地域制度层面的约束 具体而言，国家区域发展战略的实施，促进区域内的省市共享相似的优惠政策，并为实现各自区域共同的经济发展目标而努力，这就促使地方政府在城市发展的政策制定上往往优先于本区域内省市之间的合作，而忽视了不同区域的相邻省市之间的合作<sub>。</sub>

## 2． 经济发展水平差异下不同区位的比较分析

由于我国地区间的经济发展水平差异较大 市场发育程度各异，致使地方政府往往基于自身发展之需，对地区市场的管控力度不一 与内陆地区相比，沿海地区的市场化程度较高，拥有较为先进的技术和充足的资金参与市场竞争，可能更加排斥地方政府实施贸易壁垒对市场的强行干预基于此，本文假设我国地处沿海地区的省市与地处内陆地区的省市所对应的市场分割反应系数不一，对其进行非对称分析 具体做法是，将模型中的空间滞后因变量分成两个区制: 区制1 的市场分割反应系数表示位于沿海地区的省市对相邻省市实施市场分割的敏感程度; 区域2 的市场分割反应系数表示地处内陆地区的省市对相邻内陆省市实施市场分割的敏感程度

## 六<sub>、</sub> 主要结论及政策建议

针对经济体制转轨时期中国的市场分割现象，如何打破市场分割，构建现代市场体系是当前不得不面对的一大主题 在经济高速发展的中国，基础设施建设实现跨越式发展，创造了一系列的 <sup>“</sup>中国奇迹<sup>”</sup> 基础设施建设在创造奇迹的同时能否推进市场一体化进程? 现尚无经验证据予以支持<sub>。</sub> 本文基于新经济地理学理论，利用1993—2012 年中国省际面板数据，采用空间面板杜宾模型对我国基础设施建设与市场分割的关系进行实证研究<sub>。</sub> 主要结论如下: ( 1) 市场分割空间聚集效应明显，<sup>“</sup>以邻为壑<sup>”</sup>现象在中国仍长期存在 ( 2) 基础设施建设的直接效应显著，可为政府加强基础设施建设提供理论支撑，但其贡献率在时序上变化不大<sub>。</sub> ( 3) 不同阶段下基础设施建设的空间溢出效应效果不一 从整体上看，基础设施建设的空间溢出效应不显著，但分阶段下后期基础设施建设的空间溢出效应变得显著 ( 4) 不同区域或不同区位下市场分割的策略性行为并非一致<sub>。</sub> 从区域发展战略角度看，同属某一区域内相邻的省市的市场分割反应系数均显著小于两省市虽相邻但却分属不同区域的市场分割反应系数<sub>。</sub> 从省市所处区位来看，地处内陆地区的省市的市场分割反应系数均显著大于地处沿海地区的省市的市场分割反应系数<sub>。</sub>

本文的实证结果表明，建立现代市场体系将是一个漫长而又曲折的过程，基础设施建设在打破市场分割过程中发挥着不可或缺的作用 基于此，我们提出如下对策建议: 首先，政府应进一步加强基础设施建设，缩小基础设施建设的区域差异 在加快四大区域内部基础设施建设的同时，也应注重跨区域基础设施建设 东部地区基础设施建设在兼顾量的提升的同时，应更注重质的飞跃; 中部<sub>、</sub>西部和东北地区基础设施建设规模相对较小，应加快基础设施建设，缩小区域间的差距 其次，加强投资主体的跨区域协作，削弱地理界限对市场的不利影响 <sup>“</sup>以邻为壑<sup>”</sup>现象在中国长期存在的事实，需要中央政府从政策层面进行引导，积极推进区域一体化战略，加强跨省之间的合作，实现优势互补 最后，积极构建服务型政府 地方政府应正确认清自身定位，充分发挥政府导向功能，避免人为的过多干预市场秩序，以期发挥市场在资源配置中的决定性作用<sub>。</sub>
