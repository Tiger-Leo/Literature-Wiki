## 一<sub>、</sub>引言

当前我国城市化进入快速发展阶段 城市扩展和发展催生的土地需求导致大量农村房屋被拆迁<sup>［1］</sup> 与此同时 拆迁矛盾频频爆发 尽管政府不断调整和多样化拆迁补偿政策 拆迁矛盾和被拆迁户的获得感仍未明显改善其原因除了补偿标准偏低外 还在于补偿方案的低效性 即补偿方案的制定忽视了农户对拆迁补偿政策的感知和偏好 造成一方面政府支付高额补偿另一方面农户对补偿方案仍不满意的困境<sup>［2］</sup> 可见 决定拆迁补偿满意度或获得感的关键有两方面因素 一是<sup>“</sup>量<sup>”</sup>的问题 即补偿数量的确定 其本质是拆迁利益的分配 二是<sup>“</sup>效率<sup>”</sup>的问题 即同等价值量的补偿标准下 怎样的补偿政策配置才能最大化被拆迁户效用随着房屋拆迁制度的完善 补偿的绝对数量将渐趋统一 此时<sup>“</sup>效率<sup>”</sup>问题将会成为制约补偿政策成败的关键所在 被拆迁人的感知和获得（满意度或效用）是衡量补偿政策效率的重要指标 通过被拆迁户的视角来识别人们对拆迁补偿政策的偏好程度 将对拆迁政策的有效实施以及保障拆迁户的利益起到重要作用

目前 学术界对拆迁补偿政策的农户偏好研究不足 仅从<sup>“</sup>量 效<sup>”</sup>两个角度展开论述 学术界对<sup>“</sup>量<sup>”</sup>的讨论集中在两个方面 一是补偿范围 完全补偿论认为除了针对房屋及附属物所有权 土地使用权的补偿外 还应包含对精神损失等间接损失的补偿<sup>［3］</sup> 公平合理补偿论则认为完全补偿会加重政府财政负担 政府只需完全补偿被拆迁户<sup>“</sup>直接的 物质的 确定的<sup>”</sup>损失 而对<sup>“</sup>间接的 精神的 重大的<sup>”</sup>损失只需采取有限度的 有条件的补偿<sup>［4］</sup> 二是补偿标准目前学术界存在土地补偿论（以土地的农用价值为基础进行补偿） 财权补偿论（以被征地农民的实际损失为基础进行补偿 包括农地发展权 就业权等） 人本论（完全以被征地人的社会生存成本为基础进行补偿 保障其生存发展）以及市场论（拆迁标准由拆迁双方协商 按照自由市场的原则确定补偿方案）四种观点<sup>［5］</sup>

学术界对<sup>“</sup>效率<sup>”</sup>的讨论主要集中于拆迁补偿模式的配置 董礼洁认为 现有补偿方案低效的主要原因是 <sup>“</sup>未能从被拆迁户的角度出发考虑其经济主体地位再造的成本和代价因素 仅仅孤立地考虑被拆迁户的短期利益 导致其生存权受到侵害<sup>”［1］</sup> 王晓东指出 政府应出台长期补偿政策 变一次性货币补偿为长期补偿 收取年金 或强制补偿款存入银行 用利息来解决医疗 养老保障问题等<sup>［6］</sup> 吴旭鹏等认为 应打破货币补偿和产权置换的简单模式 采取多元化补偿方式 货币补偿增加教育补偿和后期收益权补偿模式 安置补偿增加农业生产安置 择业安置 入股分红 异地移民等多种方法<sup>［7］</sup> 魏建博认为 拆迁补偿应着重解决社会保障问题建立最低收入保障 劳动就业保障以及社会养老保障<sup>［8］</sup> 丁晓丽认为 补偿方式应以金钱补偿为主 辅以实物补偿 安排就业 兴建生产设施给予生活优惠政策等 全方位保障被拆迁农户的生活<sup>［9］</sup>

众多研究虽为我国拆迁补偿体系的构建发挥了重大作用 但仍存在局限性 <sub>：</sub> 第一 对被拆迁户的政策偏好研究不足 <sub>；</sub> 第二<sub>，</sub> 缺乏定量方法 无法评价基于农户视角的拆迁方案的价值高低 基于此 本文尝试利用选择实验（ChiE<sub>xper</sub>i<sub>men</sub>tCE）的方法来定量研究被拆迁人对实物类补偿（提供拆迁安置房） 权益类补偿（就业安置 分享集体经济收益 提供养老保险）以及政策要素（拆迁政策公平性 透明性）的偏好 为政府制定拆迁补偿方案 保障被拆迁户利益提供有价值的信息

## 二 选择实验法的理论框架

选择实验法（Ch<sub>o</sub>i<sub>ce</sub>E<sub>xper</sub>i<sub>men</sub>tCE）是陈述偏好法的一种 它提供一个包含若干备选方案（Chi ）的假设情景 受访者要在一个选择集（Ch<sub>o</sub>i St）中选出他认为最优的备选方案通常情况下 每个选择集由若干备选方案和一个对照方案组成 每个备选方案由若干不同水平的属性（Att<sub>r</sub>ib<sub>u</sub>t<sub>e</sub>）组成（其中必须含有使用货币度量的属性）<sup>［10］</sup> 受访者对具有不同要素水平的方案进行权衡 根据效用最大化原则选择方案 研究者可根据选择结果分析受访者对每个要素的支付意愿 评价方案优劣

选择实验法最早被应用在市场营销和交通运输业<sub>，</sub>L<sub>ouv</sub>i<sub>ere，</sub>H<sub>ens</sub>h<sub>er</sub>和L<sub>ouv</sub>i<sub>ere，</sub>W<sub>oo</sub>d<sub>－</sub>th应用CE研究了消费者对具有不同属性商品的偏好程度<sup>［11］</sup>－<sup>［12］</sup> <sub>；</sub>W<sub>ar</sub>d<sub>man</sub> H<sub>a</sub>tfi<sub>e</sub>ld和P<sub>age</sub>研究了居民对自行车道隔离的支付意愿<sup>［13］</sup> 后来 CE拓展到生态补偿 食品安全等多个研究领域 L<sub>us</sub>k N<sub>or oo</sub>d和P<sub>ru</sub>itt研究了美国消费者对在猪肉中抗生素禁用属性的偏好及支付意愿<sup>［14］</sup> T<sub>onsor</sub>利用 CE发现 消费者对于属性的认知及偏好会影响其支付意愿市场参与 政策的有效性及消费者福利<sup>［15］</sup>H<sub>as</sub>l<sub>er</sub>L<sub>un</sub>dh<sub>e</sub>d<sub>e</sub>和 M<sub>ar</sub>ti<sub>nse</sub>利用CE评价了丹麦公众对保护水资源的强烈偏好<sup>［16］</sup> 近年来 中国学者将选择实验法引入国内 马爱慧等利用CE研究发现 市民对耕地周边景观以及生态环境属性有较高的支付意愿<sup>［17］</sup> 王文智武拉平将CE运用到猪肉质量安全属性的研究中 发现城镇居民对猪肉<sup>“</sup>绿色<sup>”</sup>认证有较高的支付意愿<sup>［18］</sup> 选择实验法主要基于2个经济学理论 一是L 的要素价值理论 即任何物品都可以被一组不同水平的特征要素来描述<sub>；</sub>二是L<sub>uce</sub>和 M<sub>c</sub>F<sub>a</sub>dd<sub>en</sub>提出的随机效用理论 假设个人偏好可以用如下效用函数所表示 <sub>：</sub>

$$
\mathrm{U} = \mathrm{V} (\mathrm{X}) + \mathrm{e} (\mathrm{X}, \mathrm{Z})\tag{1}
$$

其中 X Z为分别表示市场所提供的产品及环境物品的一组向量 由于无法观测到 X和Z中的部分物品 故将效用方程分为可观测部分 V（<sub>－</sub>）和不可观测的部分<sub>e</sub>（<sub>－</sub>） 假设受访者在方案 $\mathrm { g }$ 和h中进行选择 选择方案 $\mathrm { g }$ 的概率可以表示为 <sub>：</sub>

$$
\mathrm{P} \left[ \mathrm{U} _ {\mathrm{g}} > \mathrm{U} _ {\mathrm{h}} \right] = \mathrm{P} \left[ \left(\mathrm{V} _ {\mathrm{g}} + \mathrm{e} _ {\mathrm{g}}\right) > \left(\mathrm{V} _ {\mathrm{h}} + \mathrm{e} _ {\mathrm{h}}\right) \right] =
$$

$$
\mathrm{P} \left[ \left(\mathrm{V} _ {\mathrm{g}} - \mathrm{V} _ {\mathrm{h}}\right) > \left(\mathrm{e} _ {\mathrm{h}} - \mathrm{e} _ {\mathrm{h}}\right) \right]\tag{2}
$$

假定扰动项 服从极值分布 $\mathrm { V } = \beta _ { \mathrm { n } } \left( \mathrm { X } _ { \mathrm { n } } \right)$ 其中X是由<sub>n</sub>个可观测到的备选方案属性所组成的向量<sub>，</sub> $\boldsymbol { \cdot } \beta$ 为属性的系数向量<sub>，</sub>且假设 $\beta _ { 0 } =$ 0 最终可得选择方案<sub>g</sub>的概率为

$$
P _ {g} = \frac {e ^ {- \mu \beta (x _ {g n} - x _ {h n})}}{1 + e ^ {- \mu \beta^ {\prime} (x _ {g n} - x _ {h n})}}\tag{3}
$$

式中 $, \mu$ 是一个尺度参数 和扰动项的标准差成反比例关系 公式（3）为选择实验的基础模型———MNL 模型 （M<sub>u</sub>lti<sub>nom</sub>i<sub>a</sub>l L<sub>og</sub>it M<sub>o</sub>d<sub>－</sub>） 本文要采用的具体计量模型———随机参数模型 （ R<sub>an</sub>d<sub>om</sub> P<sub>arame</sub>t<sub>er</sub> M<sub>o</sub>d<sub>e</sub>l RPL） 模型和潜在分层模型 （ L<sub>a</sub>t<sub>en</sub>t Cl<sub>ass</sub> M<sub>o</sub>d<sub>e</sub>l LC）模型进一步发展 $\daleth$ 上述模型 RPL 模型认为消费者具有异质性偏好 每个被访者的效用系数 $\beta$ 通过密度函数 f （<sub>βi</sub>） 表现<sub>，</sub> 此时<sub>，</sub> 被访者 i选择备选方案j 的概率可被修正为如下形式

$$
P _ {i j} = \int \frac {\exp (\beta_ {i} V _ {i j})}{\sum_ {m} \exp (\beta_ {i} ^ {\prime} V _ {i m})} f (\beta_ {i}) d \beta_ {i}\tag{4}
$$

其中 $m$ 为一个选择集中的选项数 进一步地 消费者的偏好可能存在层次性 即每一层次内部 消费者的偏好大致相同 而不同层次的消费者其偏好差异较大 为此 学术界又发展出了 LC模型<sub>，</sub> 假设 N 个消费者被分为 S 层<sub>，</sub>则在该模型中<sub>，</sub> $f ( \beta )$ 是离散的<sub>，</sub> 且有 S 个不同的表达式 此时 <sub>s</sub> 层中的被访者 i 选择备选方案的j 的概率可被修正为如下形式

$$
P _ {i j} = \sum_ {S = 1} ^ {S} \frac {\exp \left(\beta_ {s} ^ {\prime} V _ {i j}\right)}{\sum_ {m} \exp \left(\beta_ {s} ^ {\prime} V _ {i m}\right)} R _ {i s}\tag{5}
$$

其中 $\beta _ { \mathrm { s } }$ 是层次 的参数向量 R 是消费者i落到层次S的概率 假设变量和常数项服从正态分布 则可直接计算支付意愿 某一属性的支付意愿 WTP为效用函数中属性变量的参数与价格变量参数的比值<sup>［22］</sup> <sub>，</sub>即 <sub>：</sub>

$$
\mathrm{WTP} = - \frac {\text { Attribute   parameter }}{\text { Cost   Parameter }}\tag{6}
$$

而各个属性组合方案相对于对照方案的价值可以用初始效用状态偏好与最终效用状态差异来表示 即

$$
\mathrm{CS} = - \frac {1}{\beta_ {T}} \left| \ln \sum_ {i} e x p V _ {1} - \ln \sum_ {i} e x p V _ {0} \right|\tag{7}
$$

式中 CS表示补偿剩余 即消费者对方案i的支付意愿 $\mathrm { V } _ { 1 }$ 表示最终效用 $\mathrm { { V _ { 0 } } }$ 表示初始效用 <sub>。</sub>

## （一）补偿方案属性的确定及选择实验设计

为了科学地测度被试对拆迁补偿方案的偏好及估值 本文构建了拆迁补偿政策体系 其基本属性及其水平设计如下

（1）货币补偿 根据以下方法测算货币补偿的属性水平 一是财权补偿法 具体计算公式如下 拆迁补偿款 房屋重置成本价＋宅基地使用权折价＋安置过渡费＋其他间接损失费 7万元＋5万元＋0<sub>．</sub>5万元＋1万元<sub>＝</sub>13<sub>．</sub>5万元（参照当地已拆迁数据） 二是人本法 按照家庭年收入的10倍进行核算 2016年日照市农村人均可支配收入为13379元 按照三口之家计算可得补偿款40<sub>．</sub>1万元 三是采用预调研方法 运用开放式问卷了解当地50名受访者的意愿 在<sup>“</sup>您期望获得的补偿款数量<sup>”</sup>一题中 均值为36<sub>．</sub>42万元 基于以上三种测算方法 本文将货币补偿属性定为10万元 20万元 30万元及40万元4个水平

（2）实物类补偿采取产权置换方法 即一户宅基地（符合村庄规划 5间房屋） 置换300平方米同一地段高层住宅 根据房屋结构 成新将房屋划分为 Ⅰ Ⅱ Ⅲ 级 分别置换中间层 顶层 底层住宅

（3）权益类补偿采取三种方式 一是购买养老保险 为农户缴纳15年养老保险统筹费 二是就业安置 为被拆迁户提供免费就业培训 实行为吸纳被拆迁户就业单位发放用工补贴或减免税收政策 实行小额创业贷款免息政策 支持自主创业 促进多渠道就业 三是分享集体经济收益 与<sup>“</sup>10％留用地制度<sup>”</sup>结合 发展集体经济 收取分红

## （一）对拆迁补偿方案偏好的估计

利用2232个观测数据 本文通过Nl<sub>og</sub>it50软件分别估计 MNL RPL和LC模型的参数其中LC模型根据参数显著化程度分为2层在传统选择试验中 用货币度量的属性表示被试需要支付的数额 而本文用货币度量的属性为<sup>“</sup>拆迁补偿金额<sup>”</sup> 是消费者<sup>“</sup>得到<sup>”</sup>的金额 为了同传统选择实验法相契合 避免歧义 本文的补偿金额在纳入模型计算时修正为负值 参数估计结果如表4所示

货币补偿的系数为负说明货币补偿越多 受访者的效用越大 同实际情况相符 养老保险 安置房 分享集体经济收益 就业安置属性的系数为正 说明被拆迁户对上述政策有积极的偏好与现实情况相符 政策透明性与公平性的系数为负 与预期情况相反 可能的原因有 第一 部分被访者表现出政策抗拒心理 对<sup>“</sup>透明 公平<sup>”</sup>承诺持怀疑态度 在决策时忽视了这两项政策属性<sub>；</sub>第二 就公平性来说 被试对政府的执行能力持怀疑态度 因为住房的异质性 价值属性的多元性导致政府无法得到准确的房屋评估价值 公平的实现缺乏技术基础 第三 就透明性而言 被访者对透明性的两个方面产生不同态度 首先 农户对拆迁补偿政策的透明化持支持态度<sub>，</sub>房屋价值的评估 安置过渡费用的计算房屋产权置换规定等方面越透明 被拆迁户的满意度越高 另一方面 最终每户享受的补偿数量 被试拒绝透明化政策 因为人们往往将家庭财产视为隐私 透明化使人们对财产安全 亲邻关系产生担忧 从而表现出拒绝透明化的倾向可见 此实验结果并非说明被试对公平 透明的抵制 而恰恰表明公众对政府执行公平 透明的能力提出了更高的要求

## 五<sub>、</sub>结论及政策启示

本文利用选择实验法分析我国农民对不同拆迁补偿政策的偏好及估值 为政府制定拆迁补偿政策奠定了理论基础 RPL模型显示农户对安置房政策的估值最高 为39<sub>．</sub>8万元 养老保险 分享集体经济收益和就业安置属性的估值分别为7<sub>．</sub>54万元 5<sub>．</sub>81万元及3<sub>．</sub>69万元此外 农户对政策透明性和公平性的估值为负反映了农户对拆迁过程公平性 透明性的更高要求 LC模型将被试分为2个层次 60<sub>．</sub>3％的受访者位于第一层 对安置房的估值达到18673万 远高于正常房屋价值 397％的受访者位于第二层 并呈现出属性支付意愿低 甚至为负值的特点 暗示被试会拒绝大部分拆迁补偿方案 是拆迁厌恶者

本研究的政策含义是 农户对实物安置房补偿政策的偏好和估值较高 因此拆迁补偿政策应以产权置换为基础 提供拆迁安置房 采取多元化权益类补偿政策 综合运用就业安置 提供养老保险 分享集体经济收益等政策保障被拆迁户的生存发展权 多渠道提高拆迁户的获得感<sub>；</sub>提高拆迁补偿政策执行的透明度和公平性 使拆迁补偿政策的福利效果最大化
