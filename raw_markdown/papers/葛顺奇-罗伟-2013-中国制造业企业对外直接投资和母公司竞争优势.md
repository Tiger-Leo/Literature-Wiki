# 中国制造业企业对外直接投资和母公司竞争优势

□葛顺奇 罗 伟

摘要：本文基于由《境外投资企业（机构）名录》和《中国工业企业数据库》合并而成的全新数据集，以一般跨国公司理论和发展中国家特殊的对外直接投资理论为基础，考察了母公司竞争优势对企业外向型对外直接投资（OFDI）决策的影响程度。研究发现，体现母公司竞争优势的因素，新产品占比、人均管理成本、人均产出、资本密集度、利润率和出口强度，对OFDI具有促进作用，体现竞争劣势的债务利息率则阻碍了企业OFDI。值得注意的是，新产品占比和出口强度对中国制造业企业OFDI影响大小及解释力均显著高于其他因素。此外，本文还发现，这些因素的作用对母公司所处行业的不同、东道国收入水平的高低和OFDI的类型均保持稳健，只是大小上存在一定的差异。

关键词：外向型对外直接投资 OFDI 母公司竞争优势 制造业企业

## 一、引言

自改革开放以来，内资企业迅速成长和外资企业不断涌入，促使中国制造业持续发展壮大，国际地位和竞争力也逐年提高。但产品增加值低、外贸依存度高和盈利空间小等问题依旧突出；同时，贸易摩擦逐渐升温、劳动力工资和原材料价格持续上涨、学习发达国家的技术空间不断缩小等新挑战也已开始凸显。解决旧问题和应对挑战都需要制造业企业采取更积极的行动。越来越多的企业选择外向型对外直接投资<sup>①</sup>（ ）作为突破贸易壁垒、开拓新的海外市场、整合全球经济资源、利用国际技术溢出或优化自身产业链结构的手段。数据显示，制造业OFDI企业数目从2004年1749家迅速攀升至2011年底的5748家，年均增速达到18.5%。然而，因数据限制和在中国OFDI存量和流量中占比小②等原因，诸如OFDI企业具有哪些共同特征，以及这些特征是否和传统竞争优势相一致等问题，却长期未受到理论和经验研究的足够重视。

本文旨在通过合并商务部提供的《境外投资企业（机构）名录》和《中国工业企业数据库》构建一个包含制造业企业的注册信息、财务特征和 情况的全新数据集，考察母公司竞争优势对制造业企业OFDI决策的影响。研究发现，新产品占比、人均管理成本、人均产出、资本密集度、利润率和出口强度愈高，债务利息率愈低的企业进行 的可能性愈大。该结论对是否控制企业年龄、所有制、行业和地区固定效应保持稳健；而且不取决于企业所处行业是轻工业、化工业、材料工业或机械制造业，投资目的地的是高收入国家（地区）还是低收入国家（地区），以及OFDI类型是非经营类、销售类、加工制造类、综合类亦或其他③。进一步的定量分析表明，一个百分点的增长，新产品占比和出口强度可使企业OFDI概率增加，资本密集度为 ，人均管理成本和人均产出为 左右，债务利息率为 ，而企业利润率对OFDI概率提升作用不显著。就对制造业企业OFDI现状的解释力而言，新产品占比和出口强度相当，高于资本密集度1.5倍左右，超出人均管理成本和人均产出 倍以上，远高于利润率和债务利息率的解释力。此外，本文也发现，在其他因素相同的情况下，年龄越大的企业进行OF⁃DI的概率越高；国有企业进行OFDI的概率高于民营和外资企业；轻工业和机械制造业企业OFDI的概率高于化工业和材料工业企业；东部地区企业OFDI的概率高于中西部地区企业。

## 二、文献回顾

## （一）跨国公司理论

跨国公司是指在两个以上国家拥有从事生产经营活动的分支机构，并将它们置于统一的治理结构之下的企业。故跨国公司理论需要解释如下两个问题：为什么生产经营分支机构需要分布在不同的国家，以及为什么需要将多国的分支结构置于统一治理结构下（Dunning and Lundan，2008）。由于现有的理论通常从宏观上国际资源配置层面回答前一问题，而本文仅关注微观企业，故在此不加详述④。对第二个问题的解答又可进一步区分为3个视角：避税、垄断和效率（Teece，1981）。下面将深入分析基于垄断视角的专有资产理论和基于效率视角的一体化理论<sup>⑤</sup>。

## 1.专有资产理论

专有资产理论，又称垄断竞争优势理论和所有权优势理论，强调跨国公司应该拥有的某些特殊资产（Hymer，1960，1970；Caves，1971；Dunning，1977；Caves，2007；Dunning and Lundan，2008）。因为与当地企业相比，跨国公司存在不熟悉东道国经济、社会、法律和文化条件等不利因素，所以只有具备能够为其在创新性、成本、财务或营销方面带来竞争优势的专有资产，才能够弥补其和当地企业竞争时的劣势。Hymer（1960，1970）认为，跨国公司的对外直接投资具有双重性质，它既是企业向另一个国家转移专有资产的工具，同时也是不同国家的企业之间的限制竞争的一种手段，因而强调专有资产的垄断特性。Dunning（1977）认为，只要能够为企业产生未来收入流的资源和能力都可能成为专有资产，而并非必然具备垄断性，但他强调企业对该资产的所有权。 （ ）对专有资产的属性进行了较为全面的总结，认为必须满足如下几个条件：（1）资产的所有权界定清晰；（2）创造利润的能力高于当地竞争对手的同类资产；（3）可以跨国境移动；（4）贬值速率不能过快。因此，他认为专有资产可包括全新的产品设计、品牌、商标、高效率的生产技术、产品造型和推广的特殊技能、企业员工共享的营销和销售技巧、创新能力、全球管理经验以及先进的管理模式等。Dunning 和 Lundan（2008）还指出，专有资产也可以是一种制度上的优势，如企业的行为守则、规范、内部文化、激励和考核机制、领导和管理的多样性等。

## 2.内部化理论

内部化理论将跨国公司和市场都视为组织协调不同国家生产经营活动的潜在方案，当跨国公司协调的效率高于市场时，分布在两个国家的经营活动将被置于同一的治理结构之下。 和son（1976）指出，现代企业在全球开展了各种各样的除货物生产和服务以外的商业活动，尤为重要的是营销、研究与开发、员工培训、管理队伍建设、财政和财产的管理等，所有这些商业活动相互依赖，通过中间产品流动而产生关联。由于国际中间产品市场可能存在交易性（transactional）市场失灵（Dunning and Rugman，1985），即市场无法以一个最理想的方式组织交易，故许多中间产品交易成本非常高。Dunning 和 Lundan（2008）认为这种失灵有三方面的原因：第一，交易的买卖双方在进入市场时都不具备完全（对称）的信息，这种认知缺陷自身或连同其他形式的制度失灵会滋生有限理性、机会主义、逆向选择和道德风险，这些不利于市场功能的实现（Teece，1981；Williamson，1985）；第二，交易存在外部经济或外部不经济情况；第三，对特殊产品的需求量不足以满足该产品的生产商充分实现规模、范围和地理多元化经济。当然，外部市场失灵并不意味着企业在组织同一交易时必定能够成功，因而内部化理论的另一组成部分是解释企业能够成功取代市场的机制。Buckley 和 Casson（1976）和（ ）认为企业内部存在一个基于影子价格的资源配置系统，即内部交易市场，可以弥补外部市场失灵或缺失。Hennart（1986）则认为，企业比

## （二）发展中国家对外直接投资理论

专有资产理论和内部化理论均是基于发达国家跨国公司的投资行为，这些理论对发展中国家对外直接投资的解释力并未得到一致认可。Buckley等（2008）指出现在存在两种相反的观点：一种观点认为，发展中国家的跨国公司作为后来者和新入者具有特殊性，因而需要另外的理论框架（Mathews，2002，2006；Moon and Roehl，2001）；多数的观点认为，主流理论依旧适用，但需要一些特殊的理论作为补充（Wells，1983；Lall，1983；Lecraw，1993；Buck⁃ley et al.，2007；Morck，Yeung and Zhao，2008）。

Wells（1983）和 Lall（1983）认为发展中国家跨国公司具有小规模技术优势。跨国公司进入东道国时通常需要针对该国的环境对产品或技术进行本土化改造。由于发展中国家的市场规模通常较小，故发达国家的大型跨国公司可能因为技术复杂度高、与当地现有技术水平差异过大，而难以在本土化改造时实现规模经济，但发展中国家的跨国企业可以凭借所具有小规模，与当地技术水平接近，且本土化改造灵活的技术，实现在当地生产的规模经济，并获得盈利。

Lecraw（1993）及 Morck、Yeung 和 Zhao（2008）认为，发展中国家的跨国公司在向其他发展中国家进行投资时，可凭借事务性优势获得比发达国家跨国公司更强的竞争力。因为习惯于在完善的市场环境下经营的西方和日本跨国公司，容易被一些发展中国家的腐败和其他功能失调的制度困扰，而发展中国家的跨国公司在母国经营时已经适应了国家直接干预、不安全的产权保护以及不透明的公司管理（Khanna and Palepu，2006），因而能够更好处理繁杂的法规和规避不透明的政治约束。此外，Buckley 等（2007）及 Morck、Yeung 和 Zhao（2008）在对中国对外直接投资的情况进行分析时发现，在不完美资本市场上以市场均衡水平以下的利率获得资金的能力可以成为对外直接投资的促进因素。

此外，在某些成熟行业，发展中国家企业的生产成本控制能力可以影响企业对发达国家的直接投资。Grossman 和 Hart（1986）指出，在将市场交易内部化时，母公司应该由不可契约活动对交易价值创造更为重要的公司担任。由于知识和技术的特性，它们的可契约程度通常低于其他资产，且是垄断利润的源泉，故技术密集度高的企业往往成为跨国公司的母公司，Antràs 和 Helpman（2004）的基本假设即为如此。然而，成熟产业的技术标准化，使得技术部分的可契约性提高，并降低技术带来的垄断利润，其价值创造的作用可能低于生产质量和严格的成本控制，此时内部化交易的母公司将由生产性企业担任。因此，随着发展中国家制造业的发展，部分产品质量和成本控制优秀的发展中国家的企业可以内部化一些技术密集型海外子公司（Morck，Yeung and Zhao，2008）。

## （三）中国的研究

中国企业对发展中国家和发达国家的直接投资的迅速增长吸引了众多学者的关注。绝大部分的研究集中在定性和案例分析，以及宏观视角的经验研究，例如：Mathews（2006）、Rugman 和 Li（2007）及 Deng（2009）等对中国 OFDI 动机的分析；Peng 等（2008）和 Peng 等（2009）等从制度视角对中国 OFDI所进行的考察；Buckley 等（2008）及 Morck、Yeung 和Zhao（2008）对中国OFDI现状背后的经济和制度环境的关注，还有许多学者对影响中国OFDI区位分布的因素所进行了实证分析（Buckley et al.，2007；Cheng and Ma，2010）。

目前，已经出现部分从微观视角对中国的研究。李泳（ ）选取 年期间 个中国跨国公司进行海外投资的 个样本，分析了中国企业对外直接投资的产出增长效应和技术提升效应。张建红等（2010）通过基于来自汤姆森金融数据库的全部中国企业海外收购的案例数据的实证分析，考察了影响中国企业海外收购成败的因素以及中国企业海外收购成功率低的原因。张建红和周朝鸿（ ）使用相似的数据对制度因素在中国企业“走出去”过程中的作用进行了理论探索和实证研究。Wang 等（2012）结合 2006 年和 2007年《中国工业企业数据库》和商务部提供中国企业在2006\~2007年间海外投资活动的详细信息，构建出一个包含667个观测的数据集，并在此基础上研究影响企业实际对外直接投资额的决定因素。

田巍和余淼杰（2012）同本文的分析方法和研究对象均最为相似。他们通过采用浙江省制造业企业对外直接投资的企业层面数据，详细考察了企业生产效率对OFDI概率和OFDI规模的影响。然而，专有资产优势和内部化优势也是解释企业OFDI决策重要因素。不可否认，生产效率高的企业在现实中通常更具专有资产优势和内部化优势。但在理论上，它们的差异明显。生产效率高表示使用相同的投入能得到较多的产品；专有资产优势反映产品在市场上所能获得的垄断收益；而内部化优势则是一个交易层面的概念，表示内部治理的效率超过匿名市场交易和长期契约交易。事实上，经济增长理论的演化过程已表明，生产效率可进一步内生化为研发成果或人力资本的积累。同时，生产效率解释企业OFDI决策的必要条件之一是海外子公司能够复制母公司的生产效率，这种复制通常需要研发成果或人力资本转移。此时，生产效率可能只是可转移的研发成果或人力资本作用于企业OFDI决策的中间环节之一。因此，为更深入剖析OFDI企业的母公司竞争优势，有必要进一步分析专有资产优势和内部化优势等因素在制造业企业OFDI决策中的作用。

本文在既有微观研究的基础上做出如下几点创新：（ ）使用由《境外投资企业（机构）名录》和《中国工业企业数据库》构建的全新数据库，考察了影响整个制造业企业OFDI概率的决定因素。（2）根据境外企业经营活动情况将OFDI企业进行了分类，并同时分析了影响企业选择各类 的因素。（ ）以跨国公司理论、发展中国家 理论和中国现阶段的特殊经济环境为背景，对影响企业OFDI决策的因素所进行的分析更为全面，包括企业的专有资产、管理专业化、生产效率、资本密集度、融资约束和出口强度，以及年龄、所有制、行业和地区因素。（4）不仅估计了上述因素对企业OFDI决策的作用方向，而且估算了它们对OFDI决策的边际效应和边际弹性，同时还对各因素在解释企业OFDI决策中的作用进行了对比分析。

## 三、数据和变量选择

## （一）数据

本文的分析主要基于两方面数据：中国商务部提供的《境外投资企业（机构）名录》<sup>⑥</sup>（以下简称《名录》）和来源于国家统计局的《中国工业企业数据库》。其中，《名录》包括境内投资主体的名称，可用于指示中国具体有哪些企业进行对外直接投资，同时它所提供的境外投资数据可用于对投资主体加以区分。为验证《名录》数据的准确性，我们将其与由中国商务部、统计局和外汇管理局联合发布的《中国对外直接投资统计公报》（以下简称《公报》）进行核对。《公报》是目前最具权威的中国对外直接投资的数据来源，提供了中国对外直接投资的总体情况。表1给出了《公报》和《名录》报告的2003\~2011年投资主体和境外企业数目的详细数据以及《公报》所报告的每年制造业占境外投资主体的比例。《公报》和《名录》的数据有较大的差异，但随时间的推进而逐渐减小，故可推断《名录》中的数据仅收录了现存的境外投资项目，并未收录那些曾经进行投资但已经终止的项目。不考虑在2011年才获得批准的投资项目，《名录》收录了中国在2010年67%的投资主体以及74%的境外企业。

## （三）变量选择

下面是文章计量分析部分所使用的被解释变量、核心解释变量和控制变量的说明及简要的统计描述。

OFDI概况。本文使用三类反映企业OFDI状况的变量。（1）是否进行OFDI（F<sup>d</sup>），当OFDI企业取1，其他取 0。（2）是否对高收入水平国家进行 OFDI（F<sup>H</sup>）和是否对中低水平国家进行OFDI（F<sup>L</sup>），进行时取 1，否则取 0。（3）企业 OFDI 的类型 F<sup>m</sup>，在{0，1，……，5}间取值，其中： $F ^ { m } { = } 0$ ，表示非OFDI企业，共计 298504 家；F<sup>m</sup>=1 表示非经营性 OFDI 企业，仅拥有非经营类境外企业，共计317家；F<sup>m</sup>=2表示销售类OFDI企业，企业在境外从事进出口贸易和产品销售<sup>⑩</sup>，但是没有任何境外企业进行产品的研发、组装、加工、制造或生产，共计1021家；F<sup>m</sup>=3表示加工类OFDI企业，即境外企业仅仅进行产品的研发、组装、加工、制造或生产，但是没有任何境外企业进行产品的销售和进出口业务，共计147家；F<sup>m</sup>=4表示综合类OFDI企业，企业在境外既有产品的销售或进出口业务，同时还进行产品的研发、组装、加工、制造或生产，共计782家；F<sup>m</sup>=5表示上述四类OFDI企业外的所有OFDI企业，共计152家。

新产品占比。本文使用新产品占比（新产品产出占销售总产出的比值）作为企业专有资产的代理变量。因为企业可以凭借对新产品的定价权获得比老产品更高的垄断利润，所以新产品占比高的企业的垄断竞争优势更强。此外，新产品通常是企业创新的产物，故新产品占比高的企业往往具有更好的创新能力。因此，可以预计新产品占比的估计系数为负。

人均管理成本。Buckley 和 Casson（1976）指出，内部化的净收益取决于企业管理内部市场的水平，以及处理多种货币计算等相关问题的能力，通常来说，这些能力取决于管理的专业化程度。Chandler（1977）对美国企业治理结构的演化历史的研究表明，企业管理专业化程度依赖于专职的管理人员和

管理部门的出现。而管理人员脱离生产的一个负面效应就是内部管理成本的提高。鉴于此，我们使用企业的人均管理成本（管理成本和从业员数的比值）作为企业内部化净收益的代理变量，预期系数符号为正。

人均产出和全要素生产率。随着异质性企业理论的发展，生产效率在企业对外直接投资决策中的作用逐步受到重视 。 Helpman、Melitz 和 Yeaple（2004）指出企业效率达到一定阈值是进行水平性OFDI的前 提 ， Antràs 和 Helpman（2004，2006）则证明，在海外采购关键中间投入品时，只有生产效率最高的企业选择通过企业内贸易（即在东道国拥有自己的中间品供应商）方式获得。Helpman、Melitz 和 Yeaple（2004），Bernard、Jen⁃和 （ ）， 和 （ ）、田巍和余淼杰（2012）也在经验上证明了OFDI企业在生产效率上的优势。本文采用企业的人均总产出（企业总产出和从业人员数的比值）来体现企业的效率水平，并预测人均总产出越高的企业进行对外直接投资的可能性越大。由于人均产出取决于资产的多寡，故不能将人均产出等同于生产效率，但在控制资本密集度的情况下，人均产出和生产效率具有严格的正向关系，预期系数符号为正。为了更精确地估计企业生产效率对OFDI概率的影响，并考察控制企业生产效率后其他变量估计系数的变动情况，本文还将使用企业全要素生产率度量企业的生产效率。企业的全要素生产率�是基于2002\~2007年的中国工业企业数据集（2008年和2009年缺少中间投入指标）中的工业总产值、从业人员数、固定资产年平均余额和中间投入数据，通过LP半参估计法逐行业（ 位）计算得到的。本文选用 年的数据进行计量回归。由于企业的退出或更名，使用2007年的全要素生产率进行回归将极大缩减样本，故基本回

归使用人均总产出作为企业效率的度量。

资本密集度。除保证人均产出和生产效率的正向关系，企业资本密集度对其OFDI决策具有直接的影响。Antràs（2003）认为，最终产品生产商较易在实物投资上同中间品供应商实现协作，却难以在雇佣员工上做到这一点，故最终产品生产商通过资产获得的剩余权利在中间产品供应中的重要性与中间产品的资本密集度正相关。由Grossman和Hart（1986）可知，最终产品生产商内部化中间品供应商的净收益与其剩余权利对中间产品供应的重要性正相关。因此，预计资本密集度与企业OFDI具有正向关系。

利润率和债务利息率。由于在进行对外直接投资时需要提前垫付一定的资金，而我国的资本市场并不完全，企业无法以市场利率获得所需资金，因而企业进行 决策时将面临不同程度的融资约束，约束程度越高，进行OFDI的难度越大。企业具有内源和外源两种融资渠道，内源融资包括企业的自有资金、利润的留存等；外源融资包括债务融资和股权融资等，本文使用企业的利润率（营业利润与销售额的比值）作为内源融资约束的代理变量，利润率越高，内源融资约束越小；使用债务利息率（利息支出和债务总和的比值）作为外源融资约束的代理变量，债务利息越高，外源融资约束越大。可以预计利润率的估计系数为正而债务利息率的估计系数为负。

出口强度。Johanson 和 Vahlne（1977，2009）指出，企业国际化的进程是一个在距离上从近及远，在形式上从简单到复杂的过程。故一个已经实现出口的企业将更倾向于进行OFDI。同时，由数据部分的简要描述可知，中国OFDI项目中的大部分都为出口辅助型，因而，企业出口量有助于这类OF⁃实现规模经济。本文使用企业的出口强度（出口

交货值和工业总产值的比重）体现出口因素对企业OFDI决策的影响，预期系数符号为正。

控制变量。我们使用企业年龄、所有制类型、行业和地区虚拟变量，分别控制企业经营经验、受政府干预和支持、行业特性，以及地区制度差异等因素对决策的影响。首先，根据企业设立时间距年的年数，企业年龄虚拟变量被分为四类：年，3\~5年，6\~10年和10年以上四类。其次，借鉴张维迎等（2003），我们将企业所有制分为：国有企业，包括国有、国有联营、国有独资公司或国有经济处于绝对控股地位的股份合作、联营或有限责任公司；外商投资企业，包括所有 港、澳、台商投资企业以及外商投资企业；民营企业，包括余下的全部企业。此外，参考Li（1997）的方法，本文在二位行业的基础上将企业所属行业分为如下四类：（ ）轻工业：农副食品加工业，食品制造业，饮料制造业，烟草制品业，纺织业，纺织服装、鞋、帽制造业，皮革、毛皮、羽毛（绒）及其制品业，木材加工及木、竹、藤、棕、草制品业，家具制造业，造纸及纸制品业，印刷业和记录媒介的复制，文教体育用品制造业和工艺品及其他制造业；（ ）化工业：化学原料及化学制品制造业，医药制造业，化学纤维制造业，橡胶制品业和塑料制品业；（ ）材料工业：石油加工、炼焦及核燃料加工业，非金属矿物制品业，黑色金属冶炼及压延加工业，有色金属冶炼及压延加工业，金属制品业和废弃资源和废旧材料回收加工业；（4）机械工业：通用设备制造业，专用设备制造业，交通运输设备制造业，电气机械及器材制造业，通信设备、计算机及其他电子设备制造业，和仪器仪表及文化、办公用机械制造业。最后，将企业所属地区分为东部、中部和西部三类，其中，东部地区包括北京、天津、河北、辽宁、上海、江苏、浙江、福建、山东、广东和海南等 个省份；中部地区包括山西、吉林、黑龙江、安徽、江西、河南、湖北、湖南；西部地区包括四川、重庆、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆、广西、内蒙古。

## 2.效应

鉴于 Probit 模型的参数大小并不能直接反映各因素对企业 概率的影响大小，更无法比较它们相对重要程度，故除进行系数估计外，本文仍关注解释变量的边际效应和边际弹性。

以变量 $x _ { k }$ 为例，如果 $x _ { k }$ 为连续变量，那么边际效应为 $\partial P$ $\scriptstyle \left( F ^ { d } _ { i } = 1 | X _ { i } \right) / \partial \ x _ { k } = \Psi ^ { \prime } \left( X _ { i } \beta \right) \beta _ { k }$ ，其中$\Psi ^ { \prime } ( \boldsymbol { y } ) = d \Psi \left( \boldsymbol { y } \right) / d y$ 表示 $\Psi \left( y \right)$ 的导函数， $\beta _ { k }$ 表示 $x _ { k }$ 的系数 $; x _ { k }$ 为虚拟变量时，边际效应为 $P ( F ^ { d } { } _ { i } =$ $1 | \boldsymbol { X } ^ { * } , \boldsymbol { x } _ { k i } { = } 1 \ ) - P \left( \boldsymbol { F } ^ { d } { = } 1 | \boldsymbol { X } ^ { * } , \boldsymbol { x } _ { k i } { = } 0 \right)$

其中X<sup>\*</sup> 表示除 $x _ { k }$ 外的解释变量集。显然，该边际效应与企业解释变量的取值相关，每个企业可能均不相同，为体现变量 $x _ { k }$ 的对中国企业OFDI概率的整体影响，本文将进一步估算所有企业的平均边际效应，其中N表示样本大小。

$$
M _ {x} ^ {d} = \left\{ \begin{array}{l} \frac {1}{N} \sum_ {i} \Psi^ {\prime} (X _ {i} \beta) \beta_ {k}, x _ {k} \text {为连续变量} \\ \frac {1}{N} \sum_ {i} [ P (F _ {i} ^ {d} = 1 | X _ {i} ^ {*}, x _ {k i} = 1) \\ - P (F _ {i} ^ {d} = 1 | X _ {i} ^ {*}, x _ {k i} = 0) ] x _ {k} \text {为虚拟变量} \end{array} \right. \tag {2}\tag{2}
$$

考虑到本文所使用的是不完全匹配数据，样本中OFDI企业数低于实际值，将导致 $x _ { k }$ 的边际效应可能低估其对企业OFDI决策的影响。为了规避这种因不完全匹配而造成的低估，我们将进一步计算$x _ { k }$ 的边际弹性，即 $x _ { k }$ 变动导致因变量 $F ^ { d }$ 变动的百分比。边际弹性在 $x _ { k }$ 为连续变量时为 $\mid \partial P ( F _ { i } ^ { d } { = } 1 | X _ { i } ) / \partial $ ${ { x } _ { k } } ] / P \left( { { F } ^ { d } } _ { i } = 1 | { { X } _ { i } } \right) = \Psi ^ { \prime } \left( { { X } _ { i } } \beta \right) { { \beta } _ { k } } / \Psi \left( { { X } _ { i } } \beta \right)$ ，虚拟变量时为$[ P \left( { F ^ { d } } _ { i } { = } 1 { | X ^ { * } } _ { i } , x _ { k i } { = } 1 \right) - P \left( { F ^ { d } } _ { i } { = } 1 { | X ^ { * } } _ { i } , x _ { k i } { = } 0 \right) ] / P \left( { F ^ { d } } _ { i } { = } 1 { | X _ { i } } \right)$ 于是 $x _ { k }$ 的平均边际弹性可写为如下形式：

$$
M _ {x} ^ {e} = \left\{ \begin{array}{l} \frac {1}{N} \sum_ {i} \frac {\Psi (X _ {i} \beta) \beta_ {k}}{\Psi (X _ {i} \beta)}, x _ {k} \text {为连续变量} \\ \frac {1}{N} \sum_ {i} \left[ \frac {P (F _ {i} ^ {d} = 1 | X _ {i} ^ {*} , x _ {k i} = 1) - P (F _ {i} ^ {d} = 1 | X _ {i} ^ {*} , x _ {k i} = 0)}{P (F _ {i} ^ {d} = 1 | X _ {i})} \right], \\ x _ {k} \text {为虚拟变量} \end{array} \right.\tag{3}

## （二）不同行业的企业对外直接投资

由于不同行业在资本密集度、技术密集度、产品的可契约程度和成熟程度等方面不尽相同，驱动企业OFDI的动机因而也将存在差异，故新产品占比、人均管理成本等因素对企业 概率的影响可能存在异质性。为了检验这种异质性的大小，我们按不同的行业分别进行回归，观测各因素对企业OFDI决策的影响是否具有异质性。表8为相应的估计结果，其中第一至四列分别对应轻工业、化工业、材料工业和机械工业。

结果显示，各解释变量在不同行业中的估计系数与全样本下的估计结果基本一致，表明新产品占比等变量的估计系数对母公司所处行业的不同保持稳健。然而，各行业的估计结果之间也存在不同程度的差异。对于轻工业企业而言，人均管理成本对 概率不再具有显著影响，可能因为轻工业跨国经营对企业管理专业化没有太多特殊要求；民营企业与国有企业和外资企业的OFDI概率无显著差异，表明所有制对企业 决策无显著影响。化工业估计结果最大不同之处在于，人均产出对企业OFDI决策无显著影响，而债务利息率对企业OFDI概率的影响远超过其他行业。与化工业相反，材料工业企业的人均产出的估计系数远超过其他行业，而债务利息率对企业OFDI决策无显著作用。因为机械行业的技术结构复杂，跨国经营对管理专业化的要求高于其他行业，故机械工业估计结果的一个显著特点是，人均管理成本对企业OFDI决策作用超过其他行业。

## （三）东道国收入水平差异

由文献综述部分的发展中国家对外直接投资理论可知，中国在对其他发展水平相似的国家进行投资时可能具有特殊的比较优势，比如Wells（1983）和Lall（1983）所认为的小规模技术和低端技术优势，Lecraw（1993）及 Morck、Yeung 和 Zhao（2008）所认为的在适应发展中国家环境上的优势。因而，企业对不同发展水平的国家的直接投资的决定因素可能不尽相同。表9的方程（1）和方程（2）分别给出了企业是否在高收入水平国家直接投资和是否在中低收入水平国家直接投资的估计结果。由于企业在高收入和中低收入水平的国家的投资决策具有相关性，故本文借鉴田巍和余淼杰（2012）的做法，采用双变量Probit回归同时对上述两种情况进行估计�。此外，第（3）列给出了前两列估计系数的差值和相应的t统计量。

## （四）不同类型的OFDI企业

在本小节，我们将考察前述解释变量与企业OFDI类型选择之间的关系。由于企业 OFDI 类型 F<sup>m</sup> 为多元变量，在{0，1，……，5}之间进行取值，而且企业选择何种类型的OFDI并无有序关系，故可使用多类别 logit（multinormial logit，MNL）模型进行估计<sup>�</sup>，估计方程如下：

$$
\begin{array}{l} P \left(F _ {i} ^ {m} = j \mid x _ {i}\right) \\ = \exp \left(x _ {i} ^ {\prime} \beta_ {j}\right) / \left[ 1 + \sum_ {h = 1} ^ {5} \exp \left(x _ {i} ^ {\prime} \beta_ {h}\right) \right] \end{array}\tag{4}
$$

式中， $, j = 1 , \cdots , 5 _ { \circ }$ 。因为企业各种选择概率之和必定等于1，所以，

$$
P \left(F _ {i} ^ {m} = 0 \mid x _ {i}\right) = 1 / \left[ 1 + \sum_ {h = 1} ^ {5} \exp \left(x _ {i} ^ {\prime} \beta_ {h}\right) \right]
$$

值得注意的是，MNL模型的边际效应非常复杂，因而不再能像式（2）和式（3）那样计算变量的边际效应，估计系数甚至不能体现变量影响企业选择类型j的方向。不过，我们可以从不同的角度对系数解释。由于：

$$
\begin{array}{l} P \big (F _ {i} ^ {m} = j | x _ {i} \big) / P \big (F _ {i} ^ {m} = 0 | x _ {i} \big) \\ = \exp \big (x _ {i} ^ {\prime} \beta_ {j} \big),   j = 1, \dots \dots , J \end{array}
$$

故 ， $\beta _ { j k } { = } { \partial } \ln [ \mathrm { P } ( F ^ { m } { = } j | x _ { i } ) / \mathrm { \cal P } ( F ^ { m } { = } 0 | x _ { i } ) ] / { \partial }$ $\ln x _ { k i \circ }$ 令 $\mathrm { P } \left( \ K ^ { m } { _ { i } = } j | x _ { i } \right) / P \left( \ K ^ { m } { _ { i } = } 0 | x _ { i } \right)$ ）表示企业选择类型j 的相对概率（相对于不进行OFDI），于是 $\displaystyle : \beta _ { j k }$ 度量了变量 $x _ { k }$ 对企业选择j类型OFDI相对于不进行OF⁃OFDI13.43) DI的概率的边际弹性。

OFDI的影响低于对其他三类OFDI的影响。由于所有OFDI类型，均涉及企业内部交易对市场交易的替代，所以企业内部交易的效率对各种类型的OF⁃DI企业都应该具有正向作用。人均管理成本对四类OFDI概率均有正向作用也的确支持该预测。然而，人均管理成本对加工类OFDI的影响并不显著，可能原因是加工类OFDI企业数太少（仅151家）而导致估计系数的标准差过大，这或许也是加工类OFDI 的人均产出和利息率的估计系数与另三类OFDI的相当，却不显著的原因，同样的解释也适用于企业年龄的估计结果。对非经营类OFDI而言，国有企业和外资企业进行OFDI概率显著低于民营企业；国有企业选择加工类OFDI概率高于民营和外商投资企业，而民营和外商投资企业之间无显著差异。行业类型变量的估计结果显示，轻工业企业成为四类 企业的概率均显著高于化工业和材料工业，而和机械工业无显著差异；例外情况是，机械工业企业选择加工类OFDI的概率显著高于轻工业企业。对于非经营类和销售类OFDI企业而言，东部地区的企业进行OFDI的倾向高于中西部地区，但企业所属区域对加工类和综合类OFDI概率无显著影响。

总体来看，在4种OFDI类型的估计结果中，体现母公司竞争优势的因素，新产品占比、人均管理成本、人均产出、资本密集度、利润率和出口强度对OFDI都具有促进作用，而体现竞争劣势的债务利息率则都阻碍了企业OFDI。

## 五、研究结论

本文通过合并商务部提供的《境外投资企业（机构）名录》和《中国工业企业数据库》构建出一个全新的数据集，该数据集包含所有国有及规模以上非国有制造业企业的注册信息、财务特征和情况。在此基础上，我们考察了企业新产品占比、人均管理成本、人均产出、资本密集度、利润率、债务利息率、出口强度、企业年龄，以及所有制、行业和地区因素对 决策的作用，并进一步分析了这些因素所起到的作用在不同行业和面向不同收入水平国家时的异同，以及它们对企业选择不同类型OFDI的影响。研究发现：

第一，企业的竞争力越强、进行OFDI的可能性越大。体现企业竞争优势的因素：新产品占比、人均管理成本、人均产出、资本密集度、出口强度和企业的年龄，与企业OFDI概率正相关，而体现企业竞争劣势的债务利息率与OFDI概率负相关。该结论对是否控制企业年龄、所有制、行业和地区固定效应保持稳健；而且不取决于企业所处行业是轻工业、化工业、材料工业或机械制造业，投资目的地的是高收入国家（地区）还是低收入国家（地区），以及OFDI类型是非经营类、销售类、加工制造类、综合类亦或其他。

第二，一个百分点的增长，新产品占比和出口强度可使企业OFDI概率增加1.8%，资本密集度为0.3%，人均管理成本和人均产出为0.2%左右，债务利息率为-0.3%，而企业利润率对OFDI概率提升作用不显著。

第三，对于制造业企业OFDI现状的解释力，新产品占比和出口强度相当，高于资本密集度1.5倍左右，超出人均管理成本和人均产出3倍以上，远高于利润率和债务利息率的解释力。

第四，在控制其他因素的情况下，年龄越大的企业进行 的概率越高；国有企业进行 的概率高于民营和外资企业；轻工业和机械制造业企业OFDI的概率高于化工业和材料工业企业；东部地区企业OFDI的概率高于中西部地区企业。
