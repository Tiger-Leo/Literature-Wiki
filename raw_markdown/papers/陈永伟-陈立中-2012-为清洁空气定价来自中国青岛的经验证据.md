# 为清洁空气定价:来自中国青岛的经验证据

陈永伟 陈立中

内容提要 本文利用青岛市2008 年商品住房交易数据，通过 <sup>“</sup>特征价格法<sup>”</sup>估计商品住房购买者对于空气质量改善的边际意愿支付，发现了清洁空气的价值<sub>。</sub> 估计结果显示，平均而言，空气污染每降低1 个指数，消费者愿意为商品住房多支付99．785 元/每平方米，相当于同期商品住房平均价格的 1． 74% <sub>。</sub> 考虑到各类消费者支付意愿的差异，我们引入分位数回归得到了各分位数商品住房价格对应的边际意愿支付水平，并据此估计出商品住房价格和边际意愿支付之间的经验关系<sub>。</sub> 我们还以案例方式，说明上述方法和结论在环境政策经济效益评估和公共环境治理融资规划中的应用<sub>。</sub>

关 键 词 特征价格法 空气污染指数 边际意愿支付 分位数回归

## 一 引言

随着环境污染问题的加剧和人们环保意识的增强，科学评价环境质量的经济价值已经引起各国政策制定者和研究人员的广泛关注 目前，不少国家已经将环境质量的经济价值纳入国民经济核算，并将其作为制定和评价经济政策的依据之一 例如，美国政府已经将空气质量的货币价值列入国会预算 ( Congressional Budget Office，

1994) ; 中国也于2002 年颁布了 《中华人民共和国环境影响评价法》，要求在相关建设项目的论证和评价过程中严格评估环境变化的经济价值<sub>。</sub>

尽管治理环境<sub>、</sub>改善环境质量已经成为一种共识，但在现实操作中，其重要性又往往被忽视，这在很大程度上是由环境质量这种 商品<sup>”</sup>本身的属性决定的<sub>。</sub> 从经济学角度看，环境属于公共品，虽然其质量的改善对于改进居民的福利至关重要，但由于缺乏直接的市场，其经济价值难以表现<sub>。</sub> 正是这种估价上的困难，使决策者往往对环境质量的重要性给以低估和轻视( Kolstad，2000; Kneese，2011) 。因此，为了帮助决策者更好地制定和实施相关的环境政策，就必须积极探索合理的环境估价方法，建立科学的环境政策成本—收益评价体系<sub>。</sub>

作为环境的重要组成部分，空气和居民生活的关系最为密切，其质量对居民福利的影响也最大，因此对其质量进行估价的理论和现实意义都十分重大 目前，国际上已有大量的文献对此进行了研究，并积累了不少较为成熟的方法<sub>。</sub> 相比之下，国内的同类研究却相对较少<sub>。</sub>

本文运用青岛市 2008 年商品住房交易登记数据，通过 <sup>“</sup>特征价格法”，对青岛市空气质量的经济价值进行估计，并在此基础上对环境政策的成本—收益进行评价

本文其余部分安排如下: 第二部分是文献综述，第三部分是数据及相关背景介绍;第四部分是模型设定和估计方法; 第五部分是估计结果与分析; 第六部分是空气质量住房价格和公共环境治理融资的案例分析; 最后是结论部分<sub>。</sub>

## 二 相关文献综述

对空气质量的经济价值进行合理评估是环境经济学的重要议题之一 至少从上世纪60 年代开始，人们已经发现房产价值和空气质量之间存在某种联系，并建议将这种联系应用于环境政策评价( Ridker 和 Henning，1967) 。由于当时技术条件的限制，这一发现并没有引起太多重视<sub>。</sub>

Rosen( 1974) 提出<sup>“</sup>特征价格法<sup>”</sup>后，关于空气质量对房产价格影响的研究开始大量涌现<sub>。</sub><sup>①</sup> 根据<sup>“</sup>特征价格法”，事实上，房价是人们对住房具有一系列特征的边际意愿支付( Marginal Willing to Pay，MWTP) 的总和，通过回归分析就能还原各种特征的MWTP <sub>。</sub> 沿着这一思路，Bender 等( 1980) 、Smith( 1978) 、Freeman( 1974 <sub>、</sub> 1982 <sub>、</sub> 1993) 、

Palmquist( 1982 <sub>、</sub> 1983 <sub>、</sub> 1991) 和 Brucato 等( 1990) 用美国 <sub>、</sub> 欧洲等地的房地产市场数据，就空气质量对房屋价格的影响进行了广泛的分析 对于这些早期的文献，Smith 和Huang( 1995) 做了一个很好的综述<sub>。</sub> 值得一提的是，Smith 和 Huang 在对相关研究结论进行综述比较的同时，还对以上文献中的模型设定作了比较<sub>。</sub> 通过 Monte Carlo 模拟发现，在不同估计方程设定形式下都能较好拟合数据的前提下，线性估计方程得到的系数最能准确刻画<sup>“</sup>特征价格模型<sup>”</sup>中的 MWTP<sub>。</sub>

最近10 年来，随着环境问题重要性的上升，对空气质量进行评估的文献开始大量增加<sub>。</sub> 从研究方法上看，最近的文献主要有三方面的突破: 第一是空间计量技术的使用<sub>。</sub> 传统的<sup>“</sup>特征价格模型<sup>”</sup>往往忽略房屋价格在空间上的相关性，造成估计结果的偏误<sub>。</sub> 针对这一问题，空间计量的创始人之一 Anselin 及其合作者( Kim 等，2003;Anselin 和 Lozano － Gracia，2009) 将空间误差修正模型<sub>、</sub>空间滞后模型等新方法引入分析，从而提升了估计的精确程度 第二是将迁移等行为引入分析，将 <sup>“</sup>特征价格法<sup>”</sup>和离散选择模型结合起来进行分析<sub>。</sub> 例如，Bayer 等( 2006) 通过对美国房地产市场的分析，发现如果迁移需要成本，那么用<sup>“</sup>特征价格法<sup>”</sup>估计的人们对清洁空气的 MWTP 将被严重低估 根据他们的研究，在考虑迁移成本后，得到的 MWTP 将是用传统估计方法所得结果的3 倍左右<sub>。</sub> 第三是将<sup>“</sup>特征价格法<sup>”</sup>同<sup>“</sup>生活满意观点<sup>”</sup>等主观评价方式结合起来，综合评价人们对清洁空气的 MWTP<sub>。</sub> 根据 Luechinger( 2009) 的研究，用 <sup>“</sup>特征价格法<sup>”</sup>估计得到的 MWTP 仅为用<sup>“</sup>生活满意观点<sup>”</sup>估计所得数值的 1/10 左右，这表明在很大程度上 特征价格法 的估计值仅仅是人们对空气质量 MWTP 的一个下界( lower bound) 。

当然，除了以上三方面的研究外，还有大量文献在传统的框架内对空气质量的估价进行了探索<sub>。</sub> Chay 和 Greenstone( 2005) 利用工具变量法对美国空气质量对房价的影响进行了研究<sub>。</sub> 当然，这类研究从本质上并没有突破<sup>“</sup>特征价格法<sup>”</sup>的框架<sub>。</sub> 在表1中，我们对近期的部分重要文献进行了总结

需要指出的是，目前关于空气质量估价的绝大多数研究都建立在 <sup>“</sup>平均 <sup>”</sup>意义上<sub>。</sub> 但在现实中，购买不同价位住房的居民对空气质量的重视程度各不相同，了解不同居民在 MWTP 上的差异不仅有重要的理论意义，而且在现实政策的制定中有重要的参考价值( 如在考虑对房产征税以进行环境治理融资时，这是个关键问题) 。

在国内，不少经济学家已经开始用 特征价格法 对公共政策进行评价 例如郝前进和陈杰( 2007) 用该方法研究了交通可达性对上海房价的影响; 谷一桢和郑思齐( 2009) 用该方法考察了北京 13 号地铁的修建对于周边房价的影响; 冯皓和陆铭界世 济经 \* 2012 第年 4期 · 142 ·

( 2010) 用该方法探讨了择校行为对上海房地产市场的影响<sub>。</sub> 在环境科学的研究中，尹海伟等( 2009) 利用<sup>“</sup>特征价格法<sup>”</sup>测算了上海绿地面积对房价的影响<sub>。</sub> 利用 <sup>“</sup>特征价格法<sup>”</sup>对空气质量进行估价的研究并不多见，本文将在一定程度上填补相关文献的空白<sub>。</sub>

## 三 相关背景和数据介绍

本文以青岛市作为研究对象<sub>。</sub> 青岛位于山东半岛南端，是全国 15 个副省级城市之一<sub>。</sub> 2008 年末，青岛市户籍总人口为 761． 56 万人，其中市区人口为 276． 25 万人( 面积1159 平方公里) ，下辖5 市( 县级) 485．3 万人<sub>。</sub><sup>①</sup> 青岛是山东省重要的旅游和工业城市，也是全国最早开放的沿海城市之一<sub>。</sub> 2008 年青岛市 GDP 总量为4436．2 亿元，其中第三产业贡献高达40% <sub>。</sub>

近年来，青岛市积极推动房地产业的发展，房地产在全市经济中的重要性逐步提高<sub>。</sub> 根据 《青岛统计年鉴》公布的数据计算，2008 年房地产投资占青岛 GDP 的比例为10．2%，高于全国平均的8．4%，而在2001 年，这一比例仅为6．5%，略低于全国平均的 6． 8% <sub>。</sub>

为配合房地产业的发展，青岛积极打造宜居城市，鼓励和吸引全国各地居民在青岛购房置业 <sup>②</sup> 在吸引居民尤其是外地居民购房的过程中，良好的环境一直是青岛的独特优势，这使得包括空气质量在内的环境因素在决定当地房价的过程中起着至关重要的作用 为突出环境优势，青岛在环境治理方面做出了巨大努力。“十一五<sup>”</sup>期间，青岛市治污减排投入资金高达 37 亿元，占地方财政收入的 10． 81% <sub>。</sub> 在空气污染治理方面，青岛市启动了空气重点污染源在线监测工作，搭建了环境监控信息系统平台同时，在城市机动车和扬尘污染防治等方面也采取了一系列举措<sub>。</sub> 这些政策措施有效地改善了青岛空气质量，以2008 年为例，全市空气质量优良天数达333 天<sub>。</sub> 基于良好的城市环境，青岛被认为是全国最理想的居住城市之一<sub>。</sub><sup>③</sup>

## 四 模型设定和估计方法

## ( 一) “特征价格法<sup>”</sup>模型

我们主要采用 特征价格法 对清洁空气的价格进行估计<sub>。</sub> 按照 Rosen( 1974) 的研究，住房的价格事实上是购房者对其所具备的各类特征的支付<sub>。</sub> 根据以上思想，考虑如下模型:

假设消费者的效用函数为 $U _ { i } ( { \cal A } P _ { i } , x _ { i } , z _ { i } , M _ { i } , m _ { i } )$ 。其中 $A P _ { i }$ 表示房屋所处位置的空气污染程度， $x _ { i }$ 是表示房屋 i 建筑特征的向量， $z _ { i }$ 是描述房屋 i 周边环境的向量，M表示住房面积， $m _ { i }$ 表示消费者 i 用于其他消费的货币<sub>。</sub> 按照常识，人们会更偏好于清洁的空气，因此 ${ \partial U _ { i } } / { \partial A P _ { i } } < 0$ <sub>。</sub> 在以上设定下，消费者的最优化问题为:

$$
\begin{array}{l} \max _ {A P, x, z, M, m} U _ {i} (A P _ {i}, x _ {i}, z _ {i}, M _ {i}, m _ {i}) \\ \text { s.t. } p _ {i} (A P _ {i}, x _ {i}, z _ {i}, M _ {i}) M _ {i} + m _ {i} \leqslant y _ {i} \end{array}
$$

其中 $p _ { i } ( \cdot )$ 表示消费者 i 购买住房的单位价格， $y _ { i }$ 是消费者可供支配的财富总额<sub>。</sub> 求解以上问题，容易得到如下关系:

$$
\frac {\partial U _ {i}}{\partial A P _ {i}} = \left(M _ {i} \frac {\partial p _ {i}}{\partial A P _ {i}}\right) \frac {\partial U _ {i}}{\partial m _ {i}}\tag{1}
$$

根据( 1) 式，为了让住宅周边的空气污染程度在边际上降低 1 个单位，消费者将愿意支付 | $M _ { i } { \partial p _ { i } } / { \partial A P _ { i } } \mid$ 单位货币，即为每平方米住房多支付 | $\partial p _ { i } / \partial A P _ { i } \mid$ 单位货币按照已有文献，| $\partial p _ { i } / \partial A P _ { i }$ | 被称为消费者对降低空气污染的边际意愿支付水平 <sup>①</sup>

基于本文的研究目的，需要对 $\partial { p _ { i } } / \partial { A P _ { i } }$ 进行估计<sub>。</sub> 一个潜在的问题是，我们并不知道 $p _ { i } ( \cdot )$ 的形式 <sub>。</sub> 根据 Cropper 等( 1988) 、Smith 和 Huang( 1995) 等文献，价格方程的设定形式将严重影响<sup>“</sup>特征价格法<sup>”</sup>的估计结果<sub>。</sub> 为保证估计结果稳健，我们将分别采用三种形式进行估计<sub>。</sub> 需要估计的价格方程如下:

$$
P = \alpha + \beta A P + X \gamma + Z \delta + \varepsilon\tag{2}
$$

$$
\ln (P) = \alpha + \beta A P + X \gamma + Z \delta + \varepsilon\tag{3}
$$

$$
P ^ {(\lambda_ {0})} = \alpha + \beta A P ^ {(\lambda_ {1})} + K ^ {(\lambda_ {1})} \xi + L \zeta + \varepsilon\tag{4}
$$

在式( 2) 、( 3) 、( 4) 中， $P = \left( p _ { 1 } , p _ { 2 } , \cdots , p _ { n } \right) ^ { \mathbf { \alpha } }$ ，表示样本中住房单位价格向量; $A P$ $\mathbf { \Omega } = \left( \mathbf { \Omega } a p _ { 1 } , a p _ { 2 } , \cdots , a p _ { n } \right)$ ＇是样本中住房所处位置空气污染程度向量 矩阵 $\boldsymbol { X } \ = \ \left( \ \boldsymbol { x } _ { 1 } , \boldsymbol { x } _ { 2 } \right.$ $\cdots , x _ { n } )$ ＇和 $Z = \left( z _ { 1 } , z _ { 2 } , \cdots , z _ { n } \right)$ ＇是分别描述住房自身特征和住房周边环境的变量，其中住房自身特征变量包括: 厅室数量<sub>、</sub>楼层<sub>、</sub>结构( 如钢混<sub>、</sub>混合<sub>、</sub>砖木等) ; 周边环境特征变量包括: 距离最近的中学<sub>、</sub>医院<sub>、</sub>超市<sub>、</sub>公园等的距离，以及是否处于市中心区等<sub>。</sub> $\varepsilon$ 是随机误差项，假定它遵从一般的正则假设<sub>。</sub>

方程( 2) 是线性方程设定形式，在得到估计系数 $\beta$ 后，就可以用 $- \beta$ 衡量购房者的MWTP<sub>。</sub> 方程( 3) 是半对数方程设定形式，在这种设定形式下，对于不同程度的空气污染，购房者的 MWTP 不同<sub>。</sub> 当住房平均价格为 $\bar { P }$ 时，购房者的 MWTP 为 $- \beta \bar { P }$ <sub>。</sub> 在后面的回归中，为捕捉空气污染程度对住房价格的非线性影响，我们还将在( 2) 、( 3) 两个回归模型中加入空气污染程度的平方项作为解释变量<sub>。</sub> 在这两种设定形式下，购买者在住房平均价格 $\bar { P }$ 和平均空气污染程度 $\bar { A P }$ 处的 MWTP 分别为: $- \left( { \boldsymbol { \beta } } + 2 { \boldsymbol { \beta } } _ { 1 } { \boldsymbol { \bar { A P } } } \right)$ 和$- \left( \beta + 2 \beta _ { 1 } \bar { A P } \right) \bar { P }$ ，其中 $\beta _ { 1 }$ 是空气污染程度平方项的系数估值

价格方程( 4) 是更为灵活的 Box －Cox 变换回归，其中 $X ^ { ( \lambda ) } ~ = ~ ( ~ X ^ { \lambda } ~ - 1 ) ~ / \lambda$ <sub>。</sub> 在估计过程中，我们允许方程的左右侧选择不同的变换形式，包含 0 元素的解释变量( 包括厅室数量以及几个虚拟变量) 将不进行 Box －Cox 变换<sub>。</sub> 在方程( 4) 中，K 表示进行过变换的变量，L 表示没有进行变换的变量 容易求得，在住房平均价格 $\bar { P }$ 以及平均空气污染程度 $\bar { A P }$ 处，购房者的 MWTP 为: $- \frac { \hat { \beta } \bar { A } \bar { P } ^ { \lambda _ { 1 } - 1 } } { \bar { P } ^ { \lambda _ { 0 } - 1 } }$ 。

Smith 和 Huang( 1995) 通过 Monte Carlo 模拟发现，在不同估计方程设定形式下都能较好拟合数据的前提下，线性估计方程得到的系数更能准确刻画 <sup>“</sup>特征价格模型<sup>”</sup>中的 MWTP，因此在后面的讨论中，我们将主要关注线性模型的估计结果，而将其他形式的估计结果作为参照<sub>。</sub>

## ( 二) 稳健性检验策略

1． 基于商品住房小区层面的平均数据回归 由于我们使用的是一手商品住房交易数据，因此，估计结果容易受本年度交易楼盘位置的限制<sub>。</sub> 例如在本文使用的样本数据中，李沧区一手商品住房交易量明显多于其他各区( 市) ，在这种情况下，利用单套住房的交易数据进行回归可能导致估计结果有偏<sub>。</sub>

为检验前面的结论是否可靠，我们将以小区为单位，考察空气质量对于小区平均住房价格的影响 当然，在这种情况下我们的样本观测值将大大减少，并且不能再考察住房个体特征对价格的影响，这是一种巨大的信息损失<sub>。</sub> 同时，由于观测值减少，也可能导致估计结果不显著<sub>。</sub> 基于以上两点原因，小区层面的回归将只被用作参考<sub>。</sub>

2． 引入空间因素<sub>。</sub> 在之前的估计模型中，我们假设随机误差项 $\varepsilon$ 服从正则假定，这保证了用 OLS 估计的结果具有优良的性质<sub>。</sub> 而在现实中，一般的正则假设并不容易得到保证，一个重要的原因是各误差之间可能存在空间相关性<sub>。</sub> Kim 等( 2003) 指出，在用特征价格模型进行房产价格估计时，人们往往忽略了房产价格在空间上的相关性，因此，他们建议用空间计量方法去重新考察上述问题<sub>。</sub>

为了考察我们在上一节中估计结果的稳健性，我们也将在小区层面上，采用上述两种空间计量模型对我们的模型进行重新估计<sub>。</sub><sup>①</sup> 具体来说，我们将估计如下两种空间模型:

( 1) 空间滞后模型( spatial lag model) 。在空间滞后模型中，假定某小区住房均价与其邻近小区的住房均价存在相关性，于是，有如下模型设定:

$$
P = \alpha + \rho W P + \beta A P + Z \delta + N \eta + \varepsilon\tag{5}
$$

这里， $\rho$ 是空间自相关系数，W是空间权重矩阵，它刻画在空间上住房价格的相关情况<sub>。</sub> AP 是小区所在区域的空气污染程度向量，Z 表示小区特征，N表示邻近小区的特征<sub>。</sub>

( 2) 空间误差模型( spatial error model) 。在空间误差模型中，并不直接假设彼此邻近的房屋之间价格存在相关性，而是假设随机误差项 $\varepsilon$ 存在空间自回归形式<sub>。</sub> 具体来说，我们需要考虑如下模型:

$$
\begin{array}{r} P = \alpha + \beta A P + Z \delta + \varepsilon \\ \varepsilon = \lambda W \varepsilon + u \end{array}\tag{6}
$$

这里，λ 是空间自回归系数，u 为服从正态分布的随机项<sub>。</sub>

在权重矩阵设定方面，我们假设在空间上彼此相距 2 公里以内的房屋是 <sup>“</sup>相邻<sup>”</sup>的<sub>。</sub> 用 $w _ { i j }$ 表示空间权重矩阵 W的第 i 行第j 列的元素，并且:

$$
w _ {i j} = \left\{ \begin{array}{l l} 1, & \text {如果} i, j \text {相邻} \\ 0, & \text {如果} i, j \text {不相邻} \end{array} \right.\tag{7}
$$

应用上述模型，我们可以在考虑空间因素的影响下，重新考察空气质量对住房价格的影响 关于模型的具体估计过程，受篇幅所限不再赘述，有兴趣的读者可以参考Lesage( 1998) 。需要指出的是，当运用空间滞后模型估计得系数 $\beta$ 和 $\rho$ 后，购房者的MWTP 为: $- \hat { \beta } ( \frac { 1 } { 1 - \hat { \rho } } )$ ，而利用空间误差模型估计得到的 MWTP 在形式上和一般线性模型相同<sub>。</sub>

( 3) 利用2007 年的空气污染指数作为解释变量<sub>。</sub> 上述估计使用2008 年的空气污染指数作为解释变量，这样的估计策略可能受到质疑<sub>。</sub> 因为对大多数人而言，购房是一项长期决策行为，最终影响其购买行为决策的可能不是当年的空气污染程度，而是基于他们对之前空气污染状况的认识<sub>。</sub>

为考察这种可能的滞后效果，我们将用2007 年空气污染指数代替2008 年的指数作为解释变量，重新考察购房者的 MWTP，以此来检验之前结论的可靠性<sub>。</sub>

( 4) “浮尘层<sup>”</sup>和 <sup>“</sup>清洁层<sup>”</sup>的回归<sub>。</sub> 有关研究表明，空气中飘浮的灰尘通常集中于距离地面30 ～40 米处，大约相当于房屋8 ～12 层的位置 而在更高或更低的楼层，空气中含有的灰尘较少<sub>。</sub> 据此，如果空气质量确实对住房价格有影响，那么对处于 8～12 层的住宅，这种影响程度将较大; 而对于 13 层及以上的住宅，应当没有显著影响<sub>。</sub> 为检验这一结论，我们将分别对这两个楼层位置的住房价格对空气质量的敏感程度进行回归分析<sub>。</sub>

## ( 三) 分位数回归

无论是应用一般回归策略，还是应用空间计量方法，估计的都是空气质量对于整个住房市场的平均影响<sub>。</sub> 而事实上，由于住房市场具有高度异质性，因此空气质量对不同价位的住房影响将不尽相同<sub>。</sub> 这种异质性对于制定相关的环境治理政策是十分重要的，而在以往的研究中，这种影响往往被忽略了 为考虑这种影响，我们将用分位数回归( quantile regression) 进行分析 <sub>。</sub>

根据 Koenker 和 Hallock( 2004) 的文献，考察空气质量对价格处于分位数 τ 上的住房影响，我们处理如下优化问题:

$$
\begin{array}{l} \Theta_ {\tau} = (\stackrel {{\square}} {{\alpha}} _ {\tau}, \stackrel {{\square}} {{\beta}} _ {\tau}, \stackrel {{\hat {\gamma}}} {{\gamma}} _ {\tau}, \stackrel {{\hat {\delta}}} {{\delta}} _ {\tau}) \\ = \underset {(\alpha_ {\tau}, \beta_ {\tau}, \gamma_ {\tau}, \delta_ {\tau})} {\operatorname{argmax}} \sum_ {n = 1} ^ {N} | y _ {n} - (\alpha_ {\tau} + \beta_ {\tau} A P _ {n} + x _ {n} \gamma_ {\tau} + z _ {n} \delta_ {\tau}) | \omega_ {n} \end{array}\tag{8}
$$

求解方程( 8) 得到的 $\beta _ { \tau }$ 就是分位数 <sub>τ</sub> 上购房者的 MWTP<sub>。</sub> 这样，至少在理论上，我们可以建立住房价格和空气质量改进 MWTP 之间的对应关系<sub>。</sub> 这为我们进行进一

步的政策分析提供了便利<sub>。</sub>

具体地，假设 $\begin{array} { r } { M W T P \ = \ g ( \ p ) } \end{array}$ ，而住房价格<sub>p</sub> 服从分布 $F ( p )$ ，对于某个在边际上降低1 个空气污染指数的环境治理项目， $Q ( p )$ 是在价格为<sub>p</sub> 的条件下房屋的交易数量，那么理论上可以从住房购买者筹集到公共环境治理的资金为:

$$
W = \int_ {p _ {\min}} ^ {p _ {\max}} g (p) Q (p) d F (p)\tag{9}
$$

依据上述计算公式，我们可以评估相关公共环境治理项目的经济效益和融资等问题 <sub>。</sub>

比例也在上升，这说明不同消费能力的购房者对于空气质量的评价存在显著差异<sub>。</sub> 一般而言，购买高价位住房的消费者对空气质量的评价也高: 在10%分位数上，购房者的 MWTP 值仅为30． 055 元 /每 平 方 米 ( 约 占该 价 位 房 屋 价 格 的 0．91%) ，而在90%分位数上，对应的数值为 233． 770 ( 约占该价位房屋价格的 2．85% ) ，后者是前者的 7． 78倍<sub>。</sub> 这种差异来自于不同价位住房购买者的不同动

机: 对于低价位住房的购买者，买方的动机主要是居住，对周边空气质量不会太敏感，他们往往不太愿意为改进空气质量而支付太高的价格; 而高价房的购买者在选购住房时更注重房屋的舒适性，因此对周边空气质量有较强的敏感性，对改进空气质量的MWTP 也较高<sub>。</sub> 根据这个结论，如果治理环境<sub>、</sub>改善空气质量，最大的受益者将是高价房购买者<sub>。</sub> 如果通过对房产征税来为改进空气质量融资，那么合理的税制设计应当随房价累进<sub>。</sub>

## 六 空气质量<sub>、</sub>住房价格和公共环境治理融资

清洁空气的最大受益者是当地居民，居民直接和便于识别的受益方式是住房<sub>。</sub> 清洁空气是典型的公共物品，为此，为改善空气质量的投资项目常常因为无法识别受益人而变得异常困难<sub>。</sub> 上一节中，我们估计了青岛住房购买者对于空气质量改进的边际意愿支付，从而为空气质量改进项目融资识别受益人和度量受益大小提供了便利，具有重要的政策和实际意义

第一，利用这一测算工具，我们可以对空气污染治理政策的经济效益进行评估2007 年青岛市( 含下属郊区 县 市) 年平均空气污染指数为 66．57，2008 年这一指数为66．18，下降了0．39<sub>。</sub> 按照我们估计的 MWTP 值，平均而言购房者愿意为空气质量改进在住房交易价格上多支付 38． 916 元/每平方米( 99． 785 元/每平方米 ×0． 39) 。2008 年青岛市一手商品住房成交总量约为340 万平方米 以此简单推算，仅此一项，

2007 ～2008 年青岛市空气质量改善产生的经济价值约为1．3 亿元<sub>。</sub><sup>①</sup>

需要指出的是，以上考虑的仅是一手商品住房的交易数据，如果我们参照以上方法，考虑因空气质量改进带来的存量住房的 <sup>“</sup>潜在升值”，那么空气质量改进的价值增值要大很多<sub>。</sub> 假设青岛市2008 年存量住房是一手商品住房成交量的5 倍，那么空气质量改善对存量住房带来的<sup>“</sup>潜在升值<sup>”</sup>约为6．5 亿元，加上一手商品住房，一共是7．8亿<sub>。</sub>该数额比2008 年青岛市用于<sup>“</sup>三废”( 废水<sub>、</sub>废气<sub>、</sub>废渣) 治理的总支出还要多<sub>。</sub>

另外，根据 Luechinger( 2009) 、Bayer 等( 2006) 等文献的结论，用 特征价格法 <sup>”</sup>估计的空气质量价值仅仅是一个下界，因此有理由认为治理空气污染所带来的实际经济受益还要高于以上估算<sub>。</sub>

第二，分位数回归结果可以为相关公共环境治理项目融资提供可能的参考 目前，以青岛为代表的一批沿海旅游城市正在积极打造宜居城市，治理城市空气污染是当务之急<sub>。</sub> 不过，空气治理需要大量投入，资金来源是各地政府面临的现实困难<sub>。</sub> 一项可供选择的融资方案是，对新建商品住房课征环境治理税，具体课征额度可根据目标城市 MWTP 值和住房价格间的经验关系征收 我们认为，利用这样的方案，可以在很大程度上缓解地方政府环保投入资金不足及其来源问题<sub>。</sub>

仍以青岛为例，该市主要空气污染是空气中的可吸入颗粒物和二氧化硫，<sup>②</sup>这两类污染主要是由燃煤引起的 为治理这类污染，2008 年青岛市总计投入1．66 亿元进行锅炉改造，取得了不错的效果<sub>。</sub> 如果投入 3 亿元左右的资金进一步加强锅炉改造，另用1 亿元左右资金加强城市的洒水抑尘，将空气污染降低 1 个指数是完全可能的，由此需要的总投入约为4 亿元 假设2008 年商品住房交易价格分布和本文使用样本一致，根据式( 9) 、( 10) 做简单外推，如果这项工作顺利完成，理论上仅在住房市场上就可以募集 4． 6 亿元的资金<sub>。</sub> 政策实践中，政府可以根据房价，采用一个略低于式( 10) 计算出的数值征收环境税，一方面用于增加环境改造投入，另一方面提升购房者总体福利，实属一举两得 当然，如果要开征环境税，其中还会涉及不少政策问题和技术细节 如究竟是应该对住户征税还是对开发商征税? 税收应当采取怎样的形式收取? 这些将是进一步讨论的问题<sub>。</sub>

## 七 总结与展望

本文利用青岛市2008 年一手商品住房交易的微观数据，通过 特征价格法<sup>”</sup>估计了购房者对于空气质量改善的边际意愿支付，发现了清洁空气的价值，并且 <sup>“</sup>资本化<sup>”</sup>在住房价格之中 估计结果表明，平均而言，购房者愿意为降低 1 个指数的空气污染而为每平方米住房支付99．785 元，该数值约占同期住房平均价格的1．74% <sub>。</sub> 为确保估计结果的可靠性，我们进行了多种稳健性检验 为刻画消费者的差异性，描述他们对清洁空气支付意愿的不同，我们还引入分位数回归得到了各分位数住房价格对应的MWTP 值，并据此估计出住房价格和 MWTP 之间的经验关系<sub>。</sub>

清洁空气是典型的公共物品，其估价是一大难题<sub>。</sub> 本文利用商品住房交易价格，估计出清洁空气的价格，为今后类似公共物品定价问题提供了范例<sub>。</sub> 更为重要的是，清洁空气价值的发现，为区域性空气污染治理融资提供了依据<sub>。</sub> 在已有的政策实践中，大多数城市空气污染治理资金主要有两种来源，一是公共财政预算资金; 二是从高污染企业收取的治污费 从成本—收益的角度看，用公共财政预算资金投入空气污染治理并不十分合理，部分居民缴纳的税收没有获得相称的回报<sub>。</sub> 从居民住房地理分布来看，高收入家庭一般居住在空气质量优良的区域，为此应当支付更多的治理费用<sub>。</sub>相反，低收入家庭一般居住在空气质量较差的区域，相应地承担较少治理费用 可见，住房价格将不同空气质量受益者区别开来，为整体空气质量改善提供了可能 当然，相关政策的应用路径及其可行性还有待探索，在以后的研究中我们将做进一步的分析<sub>。</sub>
