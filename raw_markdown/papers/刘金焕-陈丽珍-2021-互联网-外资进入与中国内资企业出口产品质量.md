# 互联网<sub>、</sub>外资进入与中国内资企业出口产品质量

刘金焕，陈丽珍

摘 要: 采用中国工业企业数据库和海关数据库的匹配数据，文章探究了外资进入与互联网的交互作用如何影响中国内资企业的出口产品质量 结果表明: 外资进入本身对内资企业出口产品质量的提升效应很小，但外资进入与互联网的交互作用具有较大的提升效应; 异质性分析显示，外商投资进入与互联网的交互作用对内资企业出口产品质量的提升效应远远大于港澳台地区投资进入与互联网的交互作用 外资进入与互联网的交互作用提升了内资企业一般贸易出口产品质量，对加工贸易无明显影响，并且对非国有和高生产率内资企业出口产品质量的提升效应更大; 中介效应检验证实外资进入与互联网的交互作用通过提升进口产品质量和促进自主创新，提升了内资企业的出口产品质量<sub>。</sub>

关键词: 互联网; 外资进入; 内资企业; 出口产品质量; 交互作用

## 一<sub>、</sub> 引言和文献综述

近年来，由于世界经济增速不断下降以及国际经贸摩擦频频发生，我国出口贸易面临着严峻的挑战，出口贸易规模增速持续下降<sub>。</sub> 据统计，仅2017～2019 年中国的出口同比增速就下降了一半<sub>。</sub> 同时，我国的出口贸易多以加工贸易为主，出口产品质量普遍较低，我国企业仍然位于全球价值链的底端 随着世界市场不确定性和竞争性的加剧，我国企业要想保住其在国际分工中的地位并进一步向全球价值链中高端攀升，就必须提高其出口产品质量 ( 余淼杰 张睿，2017)

外国直接投资 ( Foreign Direct Investment，以下简称 FDI) 一直被认为是发展中国家获得技术溢出效应的重要途径 国内外大量文献对 FDI 的技术溢出效应进行了研究，但并未得出一致结论 既有研究认为 FDI 对东道国的本土企业具有正向溢出效应 ( Xu ＆ Lu，2009) ，也有研究认为 FDI 对东道国的本土企业具有负向溢出效应或无显著影响 ( Lin et al． ，2009; Fu ＆ Gong，2011) <sub>。</sub> 之所以研究结论不一致，主要原因在于早期的相关研究忽视了 FDI 产生作用的条件 ( 沈国兵 黄铄珺，2020)

基于此，许多学者开始关注东道国的吸收能力 人力资本 基础设施以及制度环境等因素的调节作用 ( Blalock ＆ Gertler，2009; Tang ＆ Zhang，2016; Xiao ＆ Park，2018) <sub>。</sub>

当今时代，互联网已经渗透到各行各业，并成为一种新的经济驱动力 国内外大量文献都证明了互联网对出口贸易的促进效应 ( Yadav，2014; 施炳展，2016) ，并有少数研究证实互联网会对出口产品质量产生影响 ( 李兵 岳云嵩，2020) 同时，大量研究证实东道国的互联网化程度是影响外资进入的重要因素 ( Choi，2003;董有德 米筱筱，2019) 基于此，在研究外资进入对中国内资企业出口产品质量的影响时理应将互联网考虑进来<sub>。</sub>

现有相关研究仅关注了外资进入对出口产品质量的影响 ( Harding ＆ Javorick，2009; 沈国兵<sub>、</sub> 黄铄珺，2020) 或互联网对出口产品质量的影响 ( 李兵<sub>、</sub> 岳云嵩，2020) ，忽视了二者的交互效应<sub>。</sub> 本文的边际贡献如下: 第一，将外资进入<sub>、</sub> 互联网与出口产品质量置于统一的分析框架内，利用加入交互项的方法，研究了外资进入与互联网的交互作用对中国内资企业出口产品质量的影响，弥补了现有相关研究的不足; 第二，考虑到了外资异质性 贸易方式异质性和企业异质性，使得研究结论更加细化和具体; 第三，对外资进入与互联网的交互作用影响内资企业出口产品质量的理论机制进行了探讨，并利用中介效应模型进行了实证检验

## 二<sub>、</sub> 理论机制分析

如图1 所示，外资进入与互联网的交互作用会通过提升进口产品质量渠道和促进自主创新渠道提升内资企业的出口产品质量，并会通过降低技术溢出渠道和加剧市场竞争渠道抑制内资企业出口产品质量<sub>。</sub>

首先，关于正向影响渠道: 提升进口产品质量和促进自主创新 第一，互联网降低了信息搜寻成本和信息沟通成本 ( 李兵 岳云嵩，2020) ，极大地改善了信息的传播性，有利于内资企业更快地了解到外资企业更多的生产经营信息以及海外市场信息 在观察到外资企业进口先进的技术 设备或投入品后，内资企业也会进口类似的高质量产品，从而有利于内资企业出口产品质量的提升 这就是所谓的提升进口产品质量渠道<sub>。</sub> 第二，互联网能够降低外资企业的管理成本和生产经营成本( 潘家栋 肖文，2018) ，促进其将更多的资金投入到研发创新活动中去，有利于促进其在东道国进行更多的创新活动 同时，互联网还能够加速外资先进技术和知识的传播 因此，互联网提高了外资的技术溢出效应，使内资企业能够方便快捷地接触到外资的最先进技术，从而有利于内资企业的自主创新，进而有利于内资企业出口产品质量的提升 这就是所谓的促进自主创新渠道

其次，关于负向影响渠道: 降低技术溢出和加剧市场竞争 虽然互联网能够提高外资在东道国的技术溢出范围和技术溢出效率，但跨国公司在意识到这一点以后，会加强对技术和知识的保护，防止技术机密泄露，从而降低了外资的技术溢出，这就是所谓的降低技术溢出渠道; 虽然互联网能够促进外资进入 ( Choi，2003; 董有德<sub>、</sub> 米筱筱，2019) ，但也在一定程度上加剧了东道国市场的竞争，外资企业会挤占本土企业的市场份额，本土企业不得不缩小经营范围，甚至会退出某一市场，从而不利于本土企业提升其出口产品质量，这就是所谓的加剧市场竞争渠道<sub>。</sub>

## 三<sub>、</sub> 模型构建<sub>、</sub> 指标选取与数据处理

## ( 一) 模型构建与指标选取

根据以上的理论机制分析，并参考 Harding ＆ Javorcik ( 2009) 以及李坤望<sub>、</sub> 王有鑫 (2013) 的模型，本文将计量模型设定如下:

$$
\begin{array}{r l} t q u a l i t y _ {i j h t} = & \alpha_ {0} + \alpha_ {1} F D I _ {j h t} + \alpha_ {2} F D I _ {j h t} \times I n t e r _ {p t} + \alpha_ {3} I n t e r _ {p t} + \beta Z _ {h t} + \gamma X _ {j t} + \delta E _ {i j h t} \\ & + v _ {h} + v _ {j} + v _ {i} + v _ {t} + \varepsilon_ {i j h t} \end{array} \tag {1}
$$

其中，i 表示企业，h 表示城市， 表示省份，j 表示两分位行业，t 表示年份式 (1) 中被解释变量 $t q u a l i t y _ { i j h t }$ 表示第 t 年城市 h 行业j 内资企业 i 的出口产品质量; $F D I _ { j h t }$ 表示第 t 年城市 h 行业j 的外资进入程度; $I n t e r _ { p t }$ 表示第 t 年企业的互联网化程度; $F D I _ { j h t } \times I n t e r _ { p t }$ 表示外资进入与互联网的交互项， $\alpha _ { 2 }$ 为本文要关注的交互项的系数; $Z _ { h t }$ 、 $X _ { j t }$ 和 $E _ { i j h i }$ 分别代表城市特征变量<sub>、</sub> 行业特征变量和企业特征变量; $v _ { h }$ $v _ { j }$ $v _ { i }$ 和<sub>v</sub> 分别代表城市固定效应 行业固定效应 企业固定效应和年份固定效应，$\varepsilon _ { i j h t }$ 代表随机扰动项<sub>。</sub>

## 1． 被解释变量<sub>。</sub>

企业出口产品质量 $( \mathrm { \it { ~ t q u a l i t y } } _ { i j h t } )$ 是本文的被解释变量 借鉴 Hallak ＆ Sivadasan(2009) ，本文采用最前沿的反事实推理方法进行测度<sub>。</sub> 首先建立如下回归式:

$$
l n q _ {i n k t} + \sigma l n p _ {i n k t} = \mu_ {k} + \mu_ {n t} + \varepsilon_ {i n k t}\tag{2}
$$

其中， $q _ { i n k t }$ 表示企业 i 在 t 年出口到 <sub>n</sub> 国的产品 k 的数量， $p _ { i n k t }$ 表示企业 i 在 t 年出口到 <sub>n</sub> 国的产品 k 的价格， $\sigma$ 为产品间的替代弹性， $\varepsilon _ { i n k t }$ 为残差项， $\mu _ { k }$ 为产品固定效应， $\mu _ { n t }$ 为出口目的国 －年份固定效应 估计式 (2) 得到的回归残差 $\varepsilon _ { i n k t }$ 即为产品质量 $\mid \sigma - 1 \mid l n \lambda _ { i n k t }$ 的测算值 本文在HS8 分位上测算产品质量，由于出口产品价格具有内生性，参考施炳展 邵文波 (2014) 的做法，本文以出口产品在其他市场上的平均价格作为工具变量 同时，参考Fan et al． (2015) ，产品间的替代弹性取 $\sigma =$ 5<sub>。</sub> 出口产品质量如 (3) 所示:

$$
\text { quality } _ {\text { ink } t} = \ln \lambda_ {\text { ink } t} = \frac {\varepsilon_ {\text { ink } t}}{\sigma - 1}\tag{3}
$$

为了对指标进行加总和对比，本文对出口产品质量进行了线性标准化处理:

$$
\text { stdquality } _ {\text { ink } t} = \frac {\text { quality } _ {\text { ink } t} - \text { minquality } _ {\text { ink } t}}{\text { maxquality } _ {\text { ink } t} - \text { minquality } _ {\text { ink } t}}\tag{4}
$$

$m i n q u a l i t y _ { i n k t }$ 和 $m a x q u a l i t y _ { i n k t }$ 分别代表 HS8 分位产品质量在所有年份的最小值和最大值<sub>。</sub> 最后，本文按照产品出口占比进行了企业层面的加权，得到企业出口产品质量 相关数据均来源于中国海关数据库

## 2． 核心解释变量<sub>。</sub>

行业外资进入程度 $\big (  & { F D I _ { j h t } } \big )$ : 借鉴 Damijan et al． ( 2013) 的研究，本文采用第t 年城市 h 两分位行业j 中外资总资产占行业总资产的比重来衡量行业外资进入程度 本文将注册类型为210 220 230 和 240 等有港澳台投资的企业以及注册类型为310 320 330 和340 等有外商投资的企业归为外资企业，将其他注册类型的企业均归为内资企业<sub>。</sub> 相关数据来源于中国工业企业数据库<sub>。</sub>

企业的互联网化程度 $\textbf { ( } \ I n t e r _ { p t } \ )$ : 企业的互联网化程度很大程度上取决于其所处的互联网环境，因此本文以企业所在省份的互联网普及率来衡量企业的互联网化程度<sub>。</sub> 相关数据来源于 《中国互联网络发展状况调查统计报告》

## ( 二) 数据处理与匹配

本文所选取的样本时间区间都是2000～2013 年 由于本文的相关数据涉及到多个数据库，因此要对其进行匹配 由于数据混乱，在匹配前我们先对中国工业企业数据库和海关数据库进行了相关的处理 其中，我们对中国工业企业数据库的原始数据进行了如下处理: 将同一年的重复记录删除; 剔除关键性指标缺失或明显错误的记录 ( 如工业总产值 工业增加值 固定资产 固定净资产 从业人员 实收资本为0 或为负) ; 剔除企业规模较小的样本 ( 从业人数小于 8) ; 删除营业状态为停业<sub>、</sub> 筹建<sub>、</sub> 撤销或其他的样本，仅保留营业状态为营业的样本; 删除不遵循一般会计准则的样本: 流动资产大于总资产<sub>、</sub> 固定资产大于总资产的企业 ( 田巍<sub>、</sub> 余淼杰，2012) 同时，我们对海关数据库也进行了相关处理: 根据前面的企业出口产品质量测度方法对企业的出口产品质量进行了测算<sub>。</sub>

随后，本文将中国工业企业数据库和海关数据库进行了匹配 首先，借鉴 $\mathrm { U p - }$ ward et al． (2013) ，根据年份和企业名称进行匹配，再根据年份 企业邮编和电话号码的后七位进行匹配<sub>。</sub> 在此基础上，将两次匹配的结果取并集，并删除变量指标严重缺失的样本<sub>。</sub> 其次，根据年份<sub>、</sub> 四位标准城市代码和两分位行业代码将前面匹配的数据与城市 －行业的外资进入程度相匹配<sub>。</sub> 再次，根据年份和两位省份代码将前面匹配的数据与各省份的互联网普及率相匹配<sub>。</sub> 并根据年份和四位标准城市代码进一步与城市特征变量相匹配<sub>。</sub> 最后，根据两分位行业代码将前面匹配的所有数据再进一步与行业特征变量匹配<sub>。</sub> 最终，本文得到了196705 个样本数据<sub>。</sub>

## ( 三) 企业的异质性分析

大量研究表明，企业性质和企业生产率对企业出口具有重要影响 基于此，本文分别从这两个方面考察企业异质性的影响 ( 见表7)

## 1． 企业性质异质性分析

根据企业的注册类型，本文将全部内资企业划分为国有企业和非国有企业，若内资企业为国有企业，则 $s o e _ { i j h t } \ = 1$ ，否则 $s o e _ { i j h t } ^ { \ } = 0$ 表 7 中第 ( 1) 列和第 ( 2) 列分别是针对国有企业和非国有企业进行的回归，结果显示，外资进入与互联网的交互作用仅明显提升了非国有内资企业的出口产品质量，未对国有企业产生明显影响为了更好地对系数进行对比，在第 (3) 列中加入了 $F D I _ { j h t } \times I n t e r _ { p t }$ 与 $s o e _ { i j h t }$ 的三重交互项，结果显示， $F D I _ { j h t } \times I n t e r _ { p t }$ 的系数显著为正，而三重交互项 $F D I _ { j h t } \ \times \ I n t e r _ { p t }$ ×$s o e _ { i j h t }$ 的系数显著为负，这说明外资进入与互联网的交互作用对非国有内资企业出口产品质量具有更大的正向提升效应 可能的原因在于: 国有企业一般受到国家政策的特殊保护，难以受到外资进入的影响，虽然互联网提高了外资的技术溢出，但国有企业往往缺乏自主创新和技术升级的动力，并未对外资的技术溢出加以利用

## 2． 企业生产率异质性分析<sub>。</sub>

借鉴沈国兵 黄铄珺 (2020) 的做法，将全要素生产率高于行业中值的企业视为高生产率企业，有 $h t e c _ { i j h t } \ = 1$ ，否则 $h t e c _ { i j h t } \ = 0$ ，分组回归结果见表7 中第 (4) 列和第 (5) 列 结果显示，外资进入与互联网的交互作用对高生产率内资企业和低生产率内资企业的出口产品质量均具有明显的正向提升效应，但对高生产率内资企业出口产品质量的正向提升效应更大 第 (6) 列中加入 $F D I _ { j h t } \times I n t e r _ { p t }$ 与 $h t e c _ { i j h t }$ 的三重交互项进行比较分析，结果显示， $F D I _ { j h t } \times I n t e r _ { p t }$ 本身的系数显著为正，且三重交互项 $F D I _ { j h t } \times I n t e r _ { p t } \times h t e c _ { i j h t }$ 的系数也显著为正，这说明外资进入与互联网的交互作用对高生产率内资企业的出口产品质量具有更大的正向提升效应<sub>。</sub> 可能的原因在于: 一方面，高生产率内资企业与外资技术差距适中，容易对外资的先进技术进行消化吸收再创新，也更有能力模仿外资企业进口最先进的类似进口品或设备<sub>。</sub> 而低生产率内资企业与外资技术差距较大，难以对外资的先进技术进行充分的消化和吸收，反而易对外资技术形成依赖; 另一方面，互联网促进了外资的流入，加剧了本土市场的竞争程度，高生产率内资企业更有能力与外资企业相抗衡，并激励其进行自主创新，而低生产率内资企业较容易受到外资竞争带来的不利冲击<sub>。</sub>

## 六<sub>、</sub> 影响机制检验

前面的实证分析得出外资进入与互联网的交互作用明显提升了中国内资企业的出口产品质量，接下来，本文针对前文理论机制分析中的正向交互作用进行实证检验 借鉴 Baron ＆ Kenny (1986) ，本文采用中介效应分析方法实证检验了提升进口产品质量渠道和促进自主创新渠道，具体模型构建如下:

$$
\begin{array}{r l} t q u a l i t y _ {i j h t} & = \alpha_ {0} + \alpha_ {1} F D I _ {j h t} + \alpha_ {2} F D I _ {j h t} \times I n t e r _ {p t} + \alpha_ {3} I n t e r _ {p t} + \beta Z _ {h t} + \gamma X _ {j t} + \delta E _ {i j h t} \\ & \quad + v _ {h} + v _ {j} + v _ {i} + v _ {t} + \varepsilon_ {i j h t} \\ M _ {i j h t} & = \rho_ {0} + \rho_ {1} F D I _ {j h t} \times I n t e r _ {p t} + \rho_ {2} F D I _ {j h t} + \rho_ {3} I n t e r _ {p t} + \beta Z _ {h t} + \gamma X _ {j t} + \delta E _ {i j h t} + v _ {h} \\ & \quad + v _ {j} + v _ {i} + v _ {t} + \varepsilon_ {i j h t} \\ t q u a l i t y _ {i j h t} & = \sigma_ {0} + \sigma_ {1} F D I _ {j h t} \times I n t e r _ {p t} + \sigma_ {2} M _ {i j h t} + \sigma_ {3} F D I _ {j h t} + \sigma_ {4} I n t e r _ {p t} + \beta Z _ {h t} \\ & \quad + \gamma X _ {j t} + \delta E _ {i j h t} + v _ {h} + v _ {j} + v _ {i} + v _ {t} + \varepsilon_ {i j h t} \end{array} \tag {6}
$$

其中， $M _ { i j h t }$ 为中介变量，分别代表企业进口产品质量 $\textbf { ( } \ i m q u a l i t y _ { i j h t } \ )$ 和企业自主创新 $( \mathbf { \nabla } n y _ { i j h t } )$ 企业进口产品质量 $\textbf { ( } \ i m q u a l i t y _ { i j h t } \ )$ 的计算方法与企业出口产品质量一致，企业自主创新 $( \mathbf { \nabla } n y _ { i j h t } )$ 采用企业新产品产值占其总产值的比重来衡量，其他各变量的定义与前文相同，检验结果见表8<sub>。</sub> 第 (1) ～(3) 列是对提升进口产品质量渠道的检验，第 (4) ～(6) 列是对促进自主创新渠道的检验<sub>。</sub> 由于加入了企业进口产品质量和企业自主创新这两个变量，而某些企业并不具有进口，并且企业某些年份新产品产值数据缺失，导致样本量大幅度减少<sub>。</sub>

第 (1) 列和第 (3) 列中交互项的系数均显著为正，且第 (1) 列中交互项的系数绝对值明显大于第 (3) 列，这说明存在部分中介效应 同时，根据第 (1) ～(3) 列可知，外资进入与互联网的交互作用对内资企业的进口产品质量具有明显的正向提升效应，内资企业的进口产品质量对出口产品质量具有显著的正向促进效应，这说明外资进入与互联网的交互作用通过提升进口产品质量渠道促进了内资企业出口产品质量的提升<sub>。</sub>

## 七<sub>、</sub> 结论与政策启示

研究表明: (1) 行业外资进入本身对内资企业的出口产品质量具有一定的正向提升效应，但提升效应很小，行业外资进入与互联网的交互作用对内资企业的出口产品质量具有较大的正向提升效应 (2) 异质性分析显示: 外商投资进入与互联网的交互作用对内资企业出口产品质量的正向提升效应远远大于港澳台地区投资进入与互联网的交互作用; 行业外资进入与互联网的交互作用仅提升了内资企业一般贸易出口产品质量，对加工贸易出口产品质量无明显影响; 行业外资进入与互联网的交互作用对非国有和高生产率内资企业的出口产品质量具有更大的正向提升效应(3) 从影响机制来看，外资进入与互联网的交互作用通过提升进口产品质量和促进自主创新进而提升了内资企业的出口产品质量

根据本文的研究结论，得出以下几点政策启示: 第一，坚决贯彻 <sup>“</sup>网络强国<sup>”</sup>战略，进一步加强各地区的互联网基础设施建设，提高互联网普及率，利用互联网强化外资进入对内资企业出口产品质量的正向提升效应 第二，不能只注重外资数量，更要注重外资质量，多引进来源于西方发达国家的 FDI 第三，采取关税优惠措施鼓励外资企业进口先进技术 设备和投入品等，以促进内资企业向外资企业学习并进口类似的产品 同时，也要对进口先进技术 设备和投入品的内资企业实施税收减免措施，通过进口来带动内资企业出口产品质量的提升 第四，鼓励内资企业加大对外资先进技术的消化吸收再创新，对创新型企业提供税收减免 低息贷款等优惠政策措施，缓解其融资约束
