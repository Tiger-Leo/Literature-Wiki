# 我国制造业出口企业产品种类对企业加成率的影响研究

李胜旗，徐卫章

(1. 首都经济贸易大学，北京100070; 2. 上海财经大学，上海200433)

摘 要: 加成定价是衡量市场竞争和企业绩效的重要内容，但国内外一直缺乏有效的估算方法<sub>。</sub> 本文借鉴 Loecker＆Warzynski ( 2012) 对加成率估算提出的改进方法，基于 2000 － 2006 年中国工业企业数据库和海关进出口数据库匹配结果，证实了我国出口产品种类与企业的加成定价能力成负向关系，企业的过度产品种类导致出口行为的扭曲，出口企业加成率非常低 在此基础上，本文提出中国出口企业应该注重开发自身的核心产品 拳头产品，提高企业的核心竞争力 本文还发现企业生产率的提高可以显著提高加成定价能力，高生产率企业通过市场竞争效应能够获得更大的海外市场; 补贴对不同所有制企业<sub>、</sub> 进入<sub>、</sub> 退出和连续存活的企业有显著的差异性影响<sub>。</sub>

关键词: 加成率; 产品种类; 核心产品; 市场竞争效应; 利润侵蚀效应

## 一<sub>、</sub> 引言

2010 年中国制造业工业增加值达到 17568 亿美元，占世界工业增加值的 17. 58%，位居美国之后，排名世界第二位 工业增加值的主要原因来自于出口企业的 <sup>“</sup>自选择效应<sup>”</sup> 和 <sup>“</sup>出口中学习效应<sup>”</sup>，即往往那些表现好<sub>、</sub> 生产率高的企业更喜欢参与出口活动，同时企业的出口行为又进一步提高其生产率( 钱学锋等，2011) 问题是具有这些高生产率的企业能否将生产率优势转化为竞争优势，我国出口企业能否凭借本身的竞争优势保持或提高成本加成定价的能力 从封闭经济转变为开放经济后，企业通过进口来增加产量，加强垄断竞争能力，从而降低其他出口企业的加成定价能力 ( Krugman，1980) ，我国出口企业面对更加激烈的竞争，如何才能提高加成定价能力?

加成定价的定义是企业在保证一定利润水平下，通过对基准的边际成本核算加上一定的百分比，实现企业的利润最大化，企业一般通过成本利润率和资金利润率来对产品进行加成定价，价格的制定将直接影响到企业的利润，价格与边际成本的差额越多，企业的利润越多 同时市场的竞争环境也会影响到企业的加成定价，在垄断环境下企业获得更高加成率，当市场竞争激烈的时候，企业将降低产品的加成率<sub>。</sub> 从出口产品种类来看，当前中国出口企业大部分由单产品转为多产品企业，这种方式可以提高出口额的增加，但并不一定能提高企业的加成定价能力 加成定价能力过低的第一个直接影响就是企业的产品价格过低，这种低价竞争策略不利于中国出口企业的长期发展Amiti＆Freund ( 2010) 发现中国出口到美国的产品价格从统计数据对比来看降低了 1.6%，而其他国家的出口产品价格却上升，中国的低价产品将遭遇越来越多的反倾销调查 中国出口企业的低价竞争策略也挤压了其他国家的出口空间，亚洲国家的出口量由于中国的增加而减少，欧美国家由于中国低价产品的进入而转入生产资本和技术密集的产品<sub>。</sub> 在国内中国出口企业同质产品面临过度竞争，有国际影响力的品牌非常少，从加成定价的角度我们发现中国企业需要形成自己的核心产品和核心竞争力

本文的贡献的主要有以下几个方面，一是从研究方法上采用 Loecker＆Warzynski ( 2012) 最新的计量方法，更合理 科学地估算了企业的加成率<sub>。</sub> 二是本文首次从企业产品种类的微观角度来研究企业的产品加成定价能力 多产品的企业虽然具有规模效应，但更多的产品种类也会产生利润侵蚀效应 ( cannibaliz-tion effect) ，更多的同类性质的产品降低了核心产品的获利 能 力 <sub>。</sub> 从 市 场 竞 争 效 应 ( market competitioneffect) 来看，国际市场竞争更加激烈，出口市场的贸易成本增加，加成定价能力低的产品最后被淘汰，企业将选择加成定价能力强的核心产品种类出口<sub>。</sub> 而至今还没有文献从产品种类的角度来研究加成定价，特别是从微观企业的角度出发，这样既可以考虑到企业的异质性，避免用行业的结果来代表各种企业的个体效应 三是本文发现我国出口企业的当务之急为提高企业的核心竞争力，开发企业的核心产品<sub>、</sub> 拳头产品，我们认为加成定价能力高的产品种类即为企业的核心产品 四是本文发现了补贴的差异化的作用，对不同企业性质 不同的贸易方式和进入 退出的企业都有不同的效果 民营企业的补贴越多，加成率越高，国有企业补贴虽多却未显著提高企业的加成率;补贴对加工贸易企业并无显著的影响，对一般贸易的企业有促进作用，同时补贴对刚成立的进入企业有很大的促进作用<sub>。</sub>

## 二<sub>、</sub> 文献综述

关于加成定价与企业出口行为的研究，集中在从国家层面<sub>、</sub> 产业层面和企业层面来分析加成定价<sub>。</sub> 在国家层面上，Loecker＆Warzynski ( 2012) 通过企业层面的数据来估算了企业的加成率，主要通过成本最小化和中间品投入作为代理变量来计算，同时发现出口商的进入能提高加成定价能力 Emanuele ( 2010) 分析了部门分配 加成定价和资本劳动比直接的关系，发现西班牙的资本劳动替代系数要高于美国，但是加成定价使得西班牙的替代系数变高，而美国的替代系数降低的结论 <sub>。</sub> Eichengreen ( 2007) 从亚洲国家出口到 OECD 的贸易数据来分析，从产业结构来看，第一产业的出口程度不断下降，第二产业和第三产业的出口额明显上升，第二产业的产品多样化程度随着时间的推移不断提高，这种提高的程度为亚洲出口国家带来了大部分的贸易绩效 关于企业产品种类的选择和核心产品开发，Melitz ( 2003) 从异质性企业的角度分析，认为生产率越高的企业出口越多 Bernardetal(2011) 从多产品的角度分析了出口企业的行文，同时将企业模型扩展为多产品模型，出口的广度与深度与生产率正比关系，但是盈利能力更强的产品将获得更大的市场，能够占领新的出口市场，而随着时间的变化淘汰利润率低的产品 Mayer＆Melitz ( 2014) 对Melitz＆Ottaviano ( 2008) 的模型进行了扩展，模型的假设条件由单产品扩展为多产品企业，出口目的地的市场大小和地理特征将影响产品种类的规模，产品种类的选择受到竞争的激烈程度而改变，更激烈的竞争改变了加成率，导致企业出口更富竞争力的核心产品，核心产品的生产率的增加将降低其他种类产品的生产率，地理特征和贸易成本对核心产品的出口影响并不显著，企业应该更加注重核心产品的开发<sub>。</sub>

对本文的主要变量进行说明，被解释变量: 加成率 ( markup) 加成定价在经济学上之所以难以估计，主要原因是存在不可观测项边际成本 在计量经济学中一般借助工具变量法来消除遗漏变量的影响，从而得到无偏估计量 许多学者用会计数据中的利润 收入或者销售额减去企业的劳动和资本支出来计算边际成本 从经济意义上看，由于使用不同会计规则，会计数据和成本加成没有明显的时间序列相关关系，利用这些会计数据估计加成定价将会使估计出现问题 ( Loecker＆Warzynski，2012 ) Hall ( 1986 ) 所采用的 <sup>“</sup>索罗<sup>”</sup> 残差估算了不完全竞争条件下不同行业的加成率，但这种方法不能更好的解决生产率冲击 带 来 的 不 可 识 别 的 误 差， Loecker＆Warzynsik(2012) 发展了最新的模型来估算加成率，这种方法放松了规模报酬不变的假设，通过引入超越对数函数的形式来消除不可能观察的冲击带来的内生性问题，可以得到各个估计量的无偏估计 加成率计算方法为$\mu _ { i t } \ = \ \theta _ { i t } ^ { X }  \mid \gamma _ { i t } ^ { X } \} \ ^ { - 1 }$ ，其中 $\mu _ { i t }$ 表示企业层面的加成率， ${ \boldsymbol { \theta } } _ { i t } ^ { X }$ 表示可变要素 X的产出弹性， $\gamma _ { i t } ^ { X }$ 表示可变要素X的支出占企业总销售额的比重

解释变量: 全要素生产率 ( tfp) ，本文的计算方法主要参照 Levisohn＆Petrin ( 2003) 的半参数估计方法，使用中间品投入作为企业受到生产率冲击时的调整变量，解决了 OLS 回归过程的内生性问题，本文利用2000 年为基期的工业品出厂价格指数进行平减，资本采用固定资产年平均余额，劳动采用的每年的从业人数 补贴 ( subdidy) ，本文加入补贴作为一个重要的解释变量，本文的补贴率采用政府补贴除以企业销售额获得 企业负债水平 ( leverage) 由于企业负债水平会影响到企业的投资能力和财务状况，企业的负债过大会影响到获利能力，对于企业制定价格机制有很大的制约作用，因此本文加入负债水平作为一个控制变量，本文的负债水平采用企业长期和短期债务之和除以企业总资产获得 企业规模 ( size) ，本文的企业规模采用企业销售额来衡量<sub>。</sub> 资本劳动比( kl) ，本文采用价格指数平减后的固定资本年平均余额作为资本 ( k) ，劳动力采用全部从业员工总数( l) ，从而获得资本劳动比 企业年龄 ( age) ，为防止0 值出现影响选择样本的估算，本文对企业年龄进行了加1 处理<sub>。</sub> 本文的数据来源为 2000 －2006 年中国工业企业大样本数据库 ( CIFD) 和中国海关进出口大样本数据库 ( CCTS) 在对中国工业企业数据库处理的时候，参照聂辉华等 ( 2012) 和戴觅和余淼杰 ( 2013) 的方法 <sub>。</sub>

## 四 检验结果及分析

为了检验解释变量与被解释变量的关系，我们利用2000 －2006 年中国工业企业数据库和海关数据库匹配后的面板数据进行了估计 首先我们利用总体样本的混合效应和固定效应进行估计，并对基本结果进行详细的分析，从而得出本文的基本结论，所有的估计都控制了行业 －时间固定效应和省份 －时间固定效应，以控制这些因素对加成定价的影响; 其次，通过分位数回归，考虑不同的分位点产品种类与企业加成定价之间关系的稳健性; 再次，我们通过不同企业所有权性质和不同时间标准进行再度量，进一步的证明了结论的稳健性，同时也加深理解了不同变量在不同条件下对加成定价影响的差异性; 最后，考虑到进入 退出和持续经营企业的情况下，从产品种类对加成定价的影响进行了检验和分析，同时对持续经营的企业通过 IV 工具变量方法进行了内生性的检验，保

证了结果的稳健<sub>。</sub>

## ( 一) 基本回归结果分析

表3 分别呈现了基于不同计量模型的估计结果，各模型的主要区别在于估计方法和控制变量选取的不同，估计的结果显示产品种类对企业的加成定价有着显著的负向作用，这说明企业产品种类的增加导致了产品加成率的下降<sub>。</sub> 第一，从利润侵蚀效应来看，企业进行产品出口和投资的时候，取决于是目的地市场和产品种类的利润侵蚀效应，某一市场的产品能够为企业带来投资溢价，企业有更强的支付意愿 ( 马捷等，2012) 如果产品种类过度开发，产品之间的利润侵蚀将更大，这将降低产品的利润，只有拥有核心技术的产品才会提高企业的利润率 ( Mayer＆Melitz，2014) 利用法国出口企业的数据分析，目的国市场规模越大，核心产品的出口越多，企业供给潜力越大核心产品出口越多，激烈的市场竞争导致企业产品范围的减少，企业转而生产具有核心竞争力的产品，这些观点与本文不谋而合 第二，从国际分工的地位来看我国还处于不利地位，出口种类数量非常多的产品主要分布在纺织 服装 家具 日用品等劳动密集型行业，这些行业部门相对齐全，但大多为低技术含量 低附加值产品，随着产品种类的增多，行业内的产品价格会降低，原本比较低的利润率进一步减少，利润率的减少降低了企业的加成定价 第三，从市场竞争效应来看，产品种类越多，市场竞争更加激烈，企业会主动根据市场的情况选择降低产品价格，除非该产品拥有自己的核心竞争力，面对不断增加的产品种类才会对其出口影响很小，越是竞争激烈的产品增多，加成率越低，越是核心产品种类，加成率越高生产率对加成定价有显著的正向作用，生产率越高企业的加成定价能力越强<sub>。</sub> 补贴对加成定价有显著的正向作用，在其他的控制变量的估计结果中，负债率与加成率有负向作用，企业规模越大加成定价能力越强，说明我国出口企业规模越大的企业越能够形成自己的核心产品，越能够提高产品的加成定价，资本劳动比与加成定价能力为显著的正向关系，资本密集型企业比劳动密集型企业拥有更高的加成能力，这与我们的预期相符，资本密集型企业的产品种类并不多，却可以为企业带来更多的利润，而劳动密集型企业的利润率也低很多企业年龄越长加成定价能力越强，一方面企业的自身学习能力的积累提高了企业的加成定价能力，企业在长期的经营过程中，积累了更多的产品的核心技术，拥有更多的营销经验，在出口目的国建立了更多的长期联系，企业存活时间越长越有利于企业的加成定价; 另外一方面，企业在长期的出口中，能够选择更多有利于自身加成提高的产品，淘汰竞争非常激烈利润率非常低的产品

## ( 二) 稳健性分析

1. 分位数回归 样本的分布如果不能满足残差正态分布的要求就会使得 OLS 回归的结果变得有偏，分位数回归是在古典 <sup>“</sup>条件均值<sup>”</sup> 的基础上对 OLS方法的延伸 在古典理论中如果随机扰动项来自均值为零同时方差分布相同，这个时候可以达到最优的无偏估计，即 BLUE，或者随机扰动项能够服从正态分布，这个时候回归结果的最大似然估计为最小方差无偏估计，即 MVUE，但是如果这些条件无法满足，存在异方差或者尖峰 厚尾的分布的时候，我们的 OLS回归结果将变得非常不稳健 采用分位数回归对比普通的回归方法能够获得精确的结果，对于解释变量的局部变化，比如左偏或者右偏，都能捕捉到分布的结果，因此采用分位数回归来做稳健性检验非常有用

本文采用 10% 30% 50% 70% 90% 五个分位点来估计整体的模型，可以看出解释变量对被解释变量在这几个不同的分位点的边际效应，产品种类对加成定价有显著的负向作用，全要素生产率对加成定价显著的正向作用，补贴对加成定价有显著的正向作用<sub>。</sub> 在控制变量中，负债率与加成定价有显著的负向作用，企业规模 资本劳动比 企业年龄都与加成定价有正向作用，回归结果表明，在不同分位数情况下结果非常稳健，虽然不同分位数下产品种类的系数大小出现了一定的波动，但符号并未变化，显著性也未变化，系数的大小并未出现大幅度的变化 总体来说，估计结果与本文的结论保持了一致性，其他控制变量的结果也是非常稳健的，所有的回归结果并不随分位数的变化而变化

3. 进入 退出和连续企业检验和内生性检验由于我国出口企业每年都有大量比例的进入和退出，要稳定企业的出口行为，必须降低企业频繁的进入和退出市场，那么我国出口企业的进入和退出与加成定价之间有什么关系呢? 一是市场选择机制，即国际市场的竞争使加成率低的企业退出，高加成率的企业进入，企业进入和退出使资源在不同产业重新配置，高加成率的企业进入获得市场份额实现资源优化配置，二是从产品种类来看，在出口市场能够连续存活的企业，都应该具有自己的核心产品种类，同时，并不轻

对于企业的进入与退出，借鉴周黎安等 (2006)的经验，假如企业 i 在 t － 1 期不存在而在第 t 期存在，我们认定企业 i 为进入; 假如企业 i 在第 t 期存在而在第 t －1 期不存在，我们认定为退出; 假如企业在第t －1 期存在，同时在t 期也存在，我们认定为连续存活企业 这样从 2000 －2006 年，连续存货的企业数量为 32811 家，占到总样本的 15% 而企业的加入和退出率在 7 年的平均值为 24% <sub>。</sub> 表 6 中(1) 列为存在企业，用当年并未进入的企业作为虚拟变量，进入企业取值为 1，而存在企业取值为 0，(2) 列为进入企业，(3) 列为退出企业，(4) 列为连续存活企业<sub>。</sub>

从结果来看，产品种类对企业加成率的影响的绝对值从大到小分别是连续企业 存在企业 退出企业 进入企业 对于连续存活企业来看，产品种类越少加成能力越多，再次验证了企业必须拥有自己的核心产品才能长期存活<sub>。</sub> 对于退出企业来说，如果一个行业竞争过于激烈，即使生产更多的产品也不能提高自身的加成率，达到一定的边界值将会选择退出<sub>。</sub> 而对于进入企业来说，一方面是新进入的企业盈利能力并不强，面对进入的行业只能采取低价竞争策略，企业并没有形成自己的核心产品<sub>。</sub> 从 ( 4) 列的结果来看，补贴对于连续存活企业并没有显著的影响，这说明连续存活企业并不依赖于补贴提高自己的利润，同时也说明，我国的补贴政策并没有带来连续存活企业的加成定价能力的提高<sub>。</sub>

## 五<sub>、</sub> 结论与建议

本文结合2000 －2006 年高度细化的中国工业企业数据库和海关进出口数据库，从企业多产品的视角来研究了加成定价问题，包括不同企业所有制 加入

WTO 进入退出和连续存活企业，进而从市场竞争效应和利润侵蚀效应两个维度刻画了出口企业的加成定价能力 结论主要为: 出口企业的多产品途径并未形成企业的核心产品，不利于企业的加成定价，产品种类与加成率成负向关系; 企业的生产率对加成定价有正向的促进作用; 补贴对加成定价有促进作用，但是补贴的作用机制不同，对国有企业作用不显著，对民营企业能起到非常显著的促进作用，对连续存活的企业影响还不显著，对进入企业有促进作用; 负债率对加成定价有负向作用，资本密集<sub>、</sub> 企业规模和企业年龄有利于企业的加成定价<sub>。</sub> 这些结论使我们从微观角度来解释中国出口企业的加成定价<sub>。</sub>

在分析了当前中国出口产品种类和加成定价的关系之后，针对这些问题我们提出以下政策建议: 第一 发展核心产品 拳头产品，提高核心竞争力 企业集中生产和研发核心产品种类，一方面可以通过技术创新，培育企业的技术优势，提高出口产品的技术含量，核心产品竞争力的增强也扩大了产品的需求量，通过增加生产规模获得规模效应，同时也避免了同类产品的激烈竞争，降低企业的生产成本，保持竞争优势，增强企业对国际市场各种风险的抵抗力; 另外一方面，核心产品可以为企业获得更大的利润，提高企业加成定价能力，增强企业开发品牌产品和提高产品质量的动力，一旦形成品牌优势，产品的价格才会提高，中国出口企业实现由 <sup>“</sup>中国制造<sup>”</sup> 到 <sup>“</sup>中国创造<sup>”</sup> 的转变，实现由 <sup>“</sup>量<sup>”</sup> 的到 <sup>“</sup>质<sup>”</sup> 的提高第二 提高企业全要素生产率 调整出口产业结构，注重企业的技术水平进步，加快经济的转型升级，从依靠劳动力和资本投入转变为依靠技术进步和效率提高的转变 第三 实行隐性差异化补贴政策 加强对生产率高的企业的补贴，关注民营企业和创业企业的补贴，重点补贴核心产品<sub>、</sub> 有核心竞争力的产品<sub>。</sub>
