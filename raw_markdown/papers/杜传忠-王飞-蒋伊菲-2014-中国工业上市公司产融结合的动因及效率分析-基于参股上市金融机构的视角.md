# 中国工业上市公司产融结合的动因及效率分析基于参股上市金融机构的视角

杜传忠 王飞 蒋伊菲

内容提要 本文以2003 2012 年间中国参股上市金融机构的工业上市公司为研究对象，运用序列 DEA 方法分析了这一产融结合方式的基本动因及效率表现，进而使用 T<sub>o</sub>bit 回归模型考察了被参股金融机构的类型<sub>、</sub>参股比例对产融结合效率的影响<sub>。</sub> 研究发现:融资需求<sub>、</sub>资产保值<sub>、</sub>发展转型等是中国工业企业参股金融机构的主要动因，被参股金融机构类型及参股比例对工业企业产融结合效率影响显著<sub>。</sub> 为此，应进一步健全有关法律法规，培育资本市场，适度提高结合程度，加强对产融结合的监管

## 一<sub>、</sub>引言

产融结合是产业部门与金融部门为实现发展目标 提高整体效益，通过资金 资本和人事渗透等方式，相互融合形成产融实体的经济现象，是市场经济条件下企业经营的重要战略选择 随着中国资本市场的日趋完善，产融结合的步伐也在不断加快，并且相继涌现出多种产融结合形式 在中国，出于产业安全和维护经济运行秩序的考虑，金融资本投资于产业受到严格限制，而产业资本介入金融领域所受到的限制相对较少，因而这种类型的产融结合发展较为迅速<sub>。</sub>

随着中国产融结合的不断推进，关于产业资本向金融部门渗透的动因以及产融结合对企业效率的影响等问题也逐渐成为近年来学术界关注的热点<sub>。</sub> 蔺元<sup>［1］</sup>使用Lo it 模型分析了2001 <sub>～</sub>2007 年间参股非上市金融机构上市公司产融结合的动因，指出上市公司实施产融结合的动因在于借助金融资本实现产业扩张 支燕 吴河北<sup>［2］</sup>基于竞争优势内生的全新视角，从资源外取<sub>、</sub>能力整合和路径刚性突破三个方面对动态竞争环境下产融结合的动因进行了剖析<sub>。</sub>李革森<sup>［3］</sup>利用2001 年截面数据研究证明金融企业参股比例与上市公司经营绩效呈正相关，并提出了产融结合临界值假说<sub>。</sub> 张庆亮和孙景同<sup>［4］</sup>则认为虽然金融企业参股比例与上市公司绩效之间存在正相关，但对企业经营绩效的提高作用并不显著，中国产融结合存在大量的危机和负效性<sub>。</sub> 姚德权等<sup>［5］</sup>对2001 <sub>～</sub>2009 年的产融结合型上市公司进行了效率评价，认为产融结合型上市公司运营效率较低，并因参股金融企业的类型不同而呈现出差异

总体上看，现阶段中国对产融结合动因及效率的研究尚处于起步阶段，研究结论也存在一定分歧<sub>。</sub> 本文拟从工业企业上市公司参股上市金融机构的角度，以2003 2012 年数据为样本实证考察中国工业企业上市公司产融结合后的综合效率 生产效率和投资效率等的变动情况，进而分析被参股金融机构类型和参股比例的变化对工业企业上市公司生产 投资和综合效率的影响，以拓展和深化中国产融结合问题的研究<sub>。</sub>

## 二<sub>、</sub>中国产业资本向金融资本渗透的动因分析

资本追逐利润的本性是产业资本向金融部门渗透的根本动力，对中国现阶段产业资本来说也不例外 产业部门与金融部门在资源上的互补性以及产融结合所带来的交易成本节约 效率提升 要素重构等多重效益，有利于促进大型工业企业节约交易成本 实现资产保值 促进发展转型 具体表现在以下几个方面:

第一，通过产融结合节约企业融资成本，更好地满足融资需求 目前，在中国金融体系尚不完善 资本市场有待发展 信用担保机制不够健全等多重因素共同作用下，企业金融需求得不到满足，而产融结合能够拓宽企业融资渠道，将企业外部的借贷关系转变为内部产权关系，这种产权关系的变更有利于企业外部融资所付出的履约谈判等交易费用内在化，从而显著降低企业融资成本<sub>。</sub>

第二，通过产融结合使企业获取协同效应，提升内部效率 产业资本和金融资本所处行业的异质性和业务互补性，使得产融结合能够产生管理和财务等方面的协同效应 研究显示，2011 年中国各类企业税收占利润的比率为99 9%，民营企业更是高达119 6%，企业税负较重① 而产融结合产生的财务协同效应有利于企业实现合理避税，这无疑对实体企业形成了巨大的吸引力 管理协同是指业务互补 规模经济和成本降低带来的效率提升以中石油为例，组建财务公司后，公司有息债务由1444 亿下降至698 亿元，资本负债率从40 7%下降至10 55%，资本利用效率显著提升<sup>②</sup>

第三，通过产融结合有利于企业优化资产配置，实现保值增值 当企业发展到一定阶段，需要对资产在安全性 收益性和流动性等方面做出更为合理的配置，以实现资产的保值增值 在中国，金融领域本身具有良好的流动性，并因高度垄断 严格监管而具有远高于产业领域的收益性和安全性<sub>。</sub> 这对企业尤其是国有企业进行资产配置产生了巨大的吸引力<sub>。</sub> 据统计，2011 年央企控制的金融子企业达到 160 家，总资产超过 20000 亿，其中部分已实现金融全牌照运行<sup>③</sup>

第四，通过产融结合有利于企业规避行业风险，促进企业转型发展 当前，中国有色金属 钢铁 航运等多个行业均存在着较为严重的周期性 结构性和体制性产能过剩 而产融结合是企业规避过剩风险，顺利实现发展转型的有效途径，有利于企业通过业务多元化分散，为企业创造新的利润增长点 此外，产融结合后资本 知识 技术 服务等稀缺性要素的大量流入改变了企业原有的要素结构 要素结构的这种基础性变动，有利于企业学习能力 竞争能力的提升，促进企业实现转型发展

## 三<sub>、</sub>中国现实产融结合效率的实证分析

## ( 一) 方法选择 变量选取及数据来源

为克服传统 DEA 存在的<sup>“</sup>技术退步<sup>”</sup>缺陷，本文运用序列 DEA 方法，即每一年的参考技术由当期及其前期所有可得到的投入产出值决定<sup>［6］</sup>，计算2003 <sub>～</sub>2012 年中国工业企业上市公司产融结合后的生产效率 投资效率及综合效率 根据工业上市公司特征，选取以下指标: 投入指标方面，以企业资产合计( x ) 衡量企业规模对产融结合效率的影响;以长期股权投资( x ) 反映各工业企业参股金融企业的资金投入量;以员工数( x ) 考察其对产业效率的影响<sub>。</sub> 产出指标方面，以营业收入( <sub>y</sub> ) 衡量工业企业在业务上的资金收入量，以投资收益( $y _ { 2 } \rfloor$ 衡量工业企业投资的资金收入量<sub>。</sub> 并以指标 $x _ { 1 } \ : \pmb { \mathscr { s x } } _ { 2 } \ : \pmb { \mathscr { s y } } _ { 1 }$ 计算生产效率，以指标 $x _ { 3 } \thinspace { \bullet } y _ { 2 }$ 计算投资效率，以指标 $x _ { 1 } \bullet x _ { 2 } \bullet x _ { 3 } \bullet y _ { 1 } \bullet y _ { 2 }$ 计算综合效率<sub>。</sub> 基础数据来源于 RESSET 金融研究数据库及和讯网( htt<sub>p</sub>: //stock hexun com/) 公布的各工业企业上市公司各年年报数据 在进行数据筛选时，剔除了投资收益为负 ST 等异常样本，以保持数据的可靠性和一致性数据处理采用 Matlab 7<sub>．</sub> 0 软件 <sub>。</sub>

## 3 参股比例对工业企业上市公司效率的影响

由于 DEA 模型得到的效率值是介于0 <sub>～</sub>1 之间的离散值，如果采用 OLS 进行回归无法保证参数估计值的无偏性和一致性<sub>。</sub> 因此，本文运用 Tobit 回归模型对2003 <sub>～</sub>2012 年的工业企业上市公司混合面板数据进行分析，以考察参股比例对上市公司产融结合效率的影响 为此，建立如下回归模型:

$$
Y _ {1} = \alpha + \alpha_ {1} r a t i + \alpha_ {2} e m p l + \alpha_ {3} i n v e + \alpha_ {4} e a r n + \alpha_ {5} r e v e + \varepsilon_ {1}\tag{1}
$$

$$
Y _ {2} = \beta + \beta_ {1} r a t i + \beta_ {2} a s s e + \beta_ {3} e m p l + \beta_ {4} r e v e + \varepsilon_ {2}\tag{2}
$$

$$
Y _ {3} = \gamma + \gamma_ {1} r a t i + \gamma_ {2} i n v e + \gamma_ {3} e a r n + \varepsilon_ {3}\tag{3}

## 四<sub>、</sub>主要结论及对策建议

本文以中国2003 <sub>～</sub>2012 年间参股上市金融机构的工业企业上市公司为样本，运用序列 DEA 及 Tobit 回归模型对产融结合的效率变动进行分析，得到以下研究结论: 第一，资本形成能力的提高对工业企业上市公司核心业务发展具有明显的推动作用，产融结合的收益来源于产业资本与金融资本的深层互动带来的综合效率提升 第二，被参股金融机构的类型对工业企业上市公司的产融结合效率具有重要影响 第三，参股比例的提高对工业企业上市公司生产效率提升具有显著的正效应，当参股比例超过5%时，参股比例与综合效率 生产效率均呈现出显著的正相关性，产融结合综合效益开始凸显

为促进中国大型工业企业产融结合向更广<sub>、</sub>更深层次发展，进一步提高产融结合的效率，应采取以下主要对策:第一，产融结合监管不仅涉及金融监管( 主要是金融控股公司的监管) ，还涉及国有金融资产的监管体制，这对国资的<sup>“</sup>分业监管<sup>”</sup>构成了巨大挑战 因此，在未来监管体制设计中，应注意完善国有资产监管体制，加强金融行业监管部门与国有资产监管部门的协调和沟通<sub>。</sub> 第二，培育资本市场，适度提高产融结合程度<sub>。</sub> 为了实现产融结合的有效发展，必须继续大力发展股票市场 国债市场，实现货币市场与股票市场有效率的连接，培育高效率的资本市场体系 需要指出的是，产融结合程度并非越深越好，而是应该根据监管体制 金融发展水平 企业规模及能力 行业属性等因素进行适度结合，以实现企业资本的战略扩张与竞争力的同步提升 第三，工业企业进一步强化发展核心业务 盲目追求短期经济效益和获取融资便利可能会带来巨大风险，并危及企业主业 考虑与主业密切相关的金融企业进行结合，防止资源分散导致的企业效率降低，并对产融结合进行周详地考虑 计划和整合第四，进一步提高金融风险防控能力和水平 当金融业收益显著的 长时间的高于产业收益时，产融结合易导致产业资本过度金融化，诱使资本<sup>“</sup>脱实向虚<sup>”</sup>，带来产业空心化和产业虚拟化风险 对此，国家应制定相关政策，对企业行为予以规范和指引，控制总体风险水平<sub>。</sub> 企业应加强资本充足率管理，建立良好的风险评估体系，提高风险管理水平，防范和控制产融结合可能带来的各项风险
