## 一<sub>、</sub>引 言

以时下最火热的ChatGPT为代表的通用人工智能技术引发了产业组织形态的深刻变革 因此数字技术创新推动数字经济和实体经济的深度融合<sup>①</sup> 将成为新时期我国产业升级的必然要求近年来我国数字经济发展取得了长足的进步 2016－2021年我国产业数字化规模从17．4万亿元增加至37．2万亿元 涨幅高达113．79％<sup>②</sup> 与此同时 我国数字经济和实体经济的融合也收获了良好成效<sup>③</sup> 但由于我国的数字化转型尚处于起步阶段 故数字经济和实体经济的深度融合仍面临着诸多制约 这些制约集中表现在以下三个方面 第一 数字技术在实体经济发展进程中的地位不够清晰 学界关于数字技术革新应对实体经济的再生产过程起引领作用（张于喆 2018 史丹 2022）还是补充作用（张昕蔚 蒋长流 2021）暂无定论 第二 实体经济如何在生产过程中有效运用数字技术和数字化场景亟待实践探索（张于喆 2018 黄阳华 2023） 第三 数字经济监管问题日渐凸显 例如数字资本的无序扩张（王维平 汪钊 2022） 数字平台和市场的垄断（孙晋 2021 周文 韩文龙 2021） 数字经济引发的<sup>“</sup>脱实向虚<sup>”</sup> （周小亮 宝哲 2021<sub>；</sub> 钟凯等 2022）等 妥善解决这些问题已成为数字经济和实体经济深度融合的当务之急

有鉴于此 本文拟基于我国现有生产—消费网络 选取产业关联作为研究的切入点 探究数字技术创新影响我国数字经济和实体经济深度融合的模式 并廓清数字技术创新影响产业融合的逻辑机制 从而为产业深度融合的新发展格局提供研究支撑 本文的创新点体现在以下三个方面首先 本文尝试在一般均衡分析框架中引入社会网络分析方法 并将流通因素纳入社会网络模型从而更加贴近我国社会再生产的现实 其次 本文根据我国产业演进的事实建立了产业关联的<sup>“</sup>中心—外围<sup>”</sup>模式 为数字技术创新带来的产业间关联效应提供了较为合理的理论解释 最后 本文识别并论证了数字技术创新通过生产 消费和劳动力供给网络影响产业关联效应传导的机制 进而为数字经济和实体经济的协同创新和深度融合提供了新的视角

## 二<sub>、</sub>文献综述

为探寻数字技术创新推动我国数字经济和实体经济融合的模式 本文拟对研究数字经济基本概念界定 我国数字经济现状以及数字经济和实体经济融合的文献进行梳理

正如联合国贸易和发展会议在《数字经济报告（2021） 》中指出的一样 数字经济的概念不是一成不变的 它的内涵随着数字技术的变革在不断地拓展和丰富 因此本文首先尝试对已有研究中数字经济的各类定义及范畴进行归纳 通过文献梳理 本文发现数字经济的常见定义主要分为两类<sup>①</sup> 其中国务院 国家统计局以及联合国贸易和发展会议 G20峰会 BEA等侧重于将数字经济定义为一种或一系列带有数字技术革新意义的经济活动 而中国信息通信研究院和 OECD则将数字经济定义为一种新的经济形态或生态系统 可以看出 上述两类数字经济的概念在核心内涵上是一致的 二者仅存在范围的差别 有鉴于此 本文基于这两类概念从社会再生产的角度为数字经济给出更一般化的定义 即数字经济是由数字技术主要推动实现并具有相对独立性的社会再生产过程 在此定义下 数字经济首先在生产力层面表现为一种数字领域的技术创新 并且这种技术创新产生的数字产品具有自己独立的生产 分配 交换和消费过程 此即<sup>“</sup>数字产业化<sup>”</sup>的基本逻辑 同时 数字技术创新还会影响到实体经济的社会再生产 这便对应了<sup>“</sup>产业数字化<sup>”</sup>中数字产业和实体产业融合的过程 上述双重影响可以表明 数字经济一方面扩充了社会再生产过程的新时代内涵 同时对实体经济的既有再生产过程具有重塑作用

## 三<sub>、</sub>理论模型

为更好地刻画生产—消费网络下数字经济与实体经济的社会再生产过程 本文拟综合Eaton和Kortum（2002）刻画随机技术水平以及Liu（2019）刻画生产网络的方法 围绕产业关联效应构建一般均衡结构化模型 以展现新时期数字技术创新赋能数字经济和实体经济深度融合的逻辑机制

## （一）模型假设

## 1．市场和主体

假设模型由三类市场主体构成 分别是一个代表性家庭 H 一个中央计划者O以及若干产业假设代表性家庭 H 的效用为可分型效用函数 即

$$
U _ {t} = \int_ {0} ^ {1} \theta_ {i t} u (c _ {i t}) d i - v (n _ {t})
$$

其中 $c _ { i t }$ 表示第t 期代表性家庭消费 $\vec { J } ^ { \pm }$ 品i 的数量 $u ( \cdot )$ 则相应表示 $c _ { i t }$ 的效用 $u ( \cdot )$ 满足二阶连续可微且 $u ^ { \prime } ( \bullet ) \geq 0 , u ^ { \prime \prime } ( \bullet ) \leq 0$ 同时假设 关于 $c _ { i t }$ 是 $D \left( 0 < D < 1 \right)$ 次齐次的 $\mathbf { \nabla } _ { \theta _ { i t } }$ 为 $\vec { J } ^ { \pm }$ 品i 的生产 —消费网络完备性系数 可用于刻画代表性家庭消费 $\vec { J } ^ { \pm }$ 品i的便捷程度的边际效用大小 即当代表性家庭能够越容易地购买到产品 i 时 产品 i 给代表性家庭带来的边际效用越高 反之则越低 $, n _ { t }$ 表示代表性家庭在第 期提供的总劳动时长 $\boldsymbol { \cdot } \boldsymbol { \cdot } ( \cdot \cdot )$ 为提供劳动时长带来的负效用 $\boldsymbol { \cdot } \boldsymbol { \upsilon } ( \cdot )$ 也满足二阶连续可微且 $v ^ { \prime } ( \bullet ) \geq 0 , v ^ { \prime \prime } ( \bullet ) \geq 0$ 同时假设v关于 $n _ { t }$ 是 $E ( E > 1 )$ 次齐次的 假设代表性家庭H的预算约束为

$$
\int_ {0} ^ {1} p _ {i t} c _ {i t} d i \leq w _ {t} n _ {t}
$$

其中 $\phi _ { i t }$ 表示第t 期 $\vec { J } ^ { \pm }$ 品i 的市场价格 $\mathcal { W } _ { t }$ 表示劳动力要素的工资水平

在生产领域 假设所有产业是［01］ 上的连续统 且各产业均有一个代表性厂商 i 其生产函数假设为<sub>，</sub>

$$
y _ {i t} = \theta_ {i t} Q (n _ {i t})
$$

与代表性家庭相似的是 θ 作为 $\vec { J } ^ { \pm }$ 品i 的生 $\vec { J } ^ { \pm }$ — 消费网络完备性系数 也可以刻画产业 i获取劳动力便利程度的异质性 若 $\vec { \boldsymbol { J } ^ { \pm } }$ 业 i 能越方便地从代表性家庭处获取到劳动力 其产出则相应更高 $n _ { i t }$ 表示产业i 投入生产的劳动力要素数量<sub>，</sub>Q（ · ） 则为 $n _ { i t }$ 的要素产出函数<sub>，</sub>假设 $Q ( \cdot )$ 二阶连续可微<sub>，</sub>满足 $Q ^ { \prime } ( \bullet ) \geq 0 , Q ^ { \prime \prime } ( \bullet )$ ≤0 且 Q（ · ） 关于 $n _ { i t }$ 是 $K \left( 0 < K < 1 \right)$ 次齐次的 就成本而言 产业的成本函数为

$$
G _ {i t} = w _ {t} n _ {i t} + T _ {i t}
$$

其中 $T _ { i t }$ 表示中央计划者O对于产业 i 的转移支付<sub>。</sub>

对于中央计划者O而言 假设其通过产业间转移支付最大化社会总供给 社会总供给定义为各产业产出的CES型加总函数 即

$$
Y _ {t} = \left(\int_ {0} ^ {1} y _ {i t} ^ {\frac {\varepsilon - 1}{\varepsilon}} d i\right) ^ {\frac {\varepsilon}{\varepsilon - 1}}, \varepsilon > 1
$$

其中 <sub>ε</sub> 表示在社会总供给中各产品的替代弹性 中央计划者的预算约束可表示为

$$
\int_ {0} ^ {1} T _ {i t} d i = 0
$$

上式表明中央计划者O在各期均不占有资源<sub>，</sub>只通过产业间的转移支付最大化社会总供给

由此可知 代表性家庭 H 消费产品 i 的便捷程度 不仅直接取决于网络 C 而且间接地受到网络 N 和Y 的影响 同理 $\vec { J } ^ { \pm }$ 业 i 的生产过程也不完全由网络Y 决定 C 和 N 也会对产业i 的生产具有间接作用 因此每个子网络的便宜和完善程度会相互制约 共同决定整个生 $\vec { \cal J } ^ { \pm }$ —消费网络的完备性 进而影响到代表性家庭的效用和各产业的实际产出 进一步对生产—消费网络完备性系数 $\theta _ { i t }$ 进行刻画 假设

$$
F _ {\theta_ {i t} ^ {S}} (\theta) = 1 - e x p \left(- \lambda_ {t} B _ {i t} ^ {S} \theta^ {R}\right), S \in \{C, Y, N \}\tag{2}
$$

其中 R 为常数且 $R { > } 1 , B _ { i t } ^ { s } { > } 0 ( S \in \{ C , Y , N \} )$ 为各子网络概率分布的完备性参数 $\Phi , \lambda _ { t } > 0$ 为整个生产—消费网络的结构参数<sub>。</sub> 进一步假设 $B _ { i t } ^ { S }$ 为产业 的平均技术水平 $Z _ { i t }$ 的函数<sub>，</sub>即<sub>，</sub>

$$
B _ {i t} ^ {S} = B ^ {S} \left(Z _ {i t}\right), S \in \{C, Y, N \}
$$

此时 $\mathbf { \nabla } , \theta _ { i t }$ 的分布函数可表示为<sub>，</sub>

$$
F _ {\theta_ {i t}} (\theta) = 1 - e x p \left(- \lambda_ {t} B _ {i t} \theta^ {R}\right)\tag{3}
$$

其中 $\begin{array} { r } { B _ { i t } = \sum _ { s } B _ { i t } ^ { s } < \infty } \end{array}$ <sub>，</sub>易知 $B _ { i t }$ 也是 $\vec { \boldsymbol { J } ^ { \pm } }$ 业i 的平均技术水平 $Z _ { i t }$ 的函数<sub>，</sub>给定其他条件不变时<sub>，</sub>$B _ { i t }$ 越大则 $F _ { \theta _ { i t } } \left( \theta \right)$ 的凹性越明显 根据式（3）可知 ${ \bf \nabla } \cdot \theta _ { i t }$ 的期望为

$$
\mathbb {E} _ {\left(\theta_ {i t}\right)} = \left(\lambda_ {t} B _ {i t}\right) ^ {- \frac {1}{R}} \Gamma \left(1 + \frac {1}{R}\right)
$$

其中 Γ（ · ）为 Γ 函数 从上式可知 产业 i 的完备性参数 $B _ { i }$ 与其自身的生产—消费网络完备性系数 $\theta _ { i t }$ 的均值负相关

## （二）均衡与比较静态分析

根据代表性家庭 H 的效用函数和预算约束方程可知 其效用最大化的一阶条件为

$$
\frac {\theta_ {i t} u ^ {\prime} \left(c _ {i t}\right)}{p _ {i t}} = \frac {\theta_ {j t} u ^ {\prime} \left(c _ {j t}\right)}{p _ {j t}} = \frac {v ^ {\prime} \left(n _ {t}\right)}{w _ {t}}, \forall i, j \in [ 0, 1 ]\tag{4}
$$

由于代表性家庭效用函数和预算约束关于 $( c _ { i t } , n _ { t } )$ 是凹的 因此以上最优化条件即充分条件将式（4） 代入均衡预算约束可得

$$
\int_ {0} ^ {1} \theta_ {i t} \frac {u ^ {\prime} (c _ {i t})}{v ^ {\prime} (n _ {t})} \frac {c _ {i t}}{n _ {t}} d i = 1\tag{5}
$$

为求解显示解 猜测 $c _ { i t }$ 和 $n _ { i t }$ 分别为标量 $\theta _ { i }$ 的M 和W次齐次函数 故根据式（5） 可知等式左侧应是向量 $\{ \theta _ { i t } , \forall i \in [ 0 , 1 ] \}$ 的零次齐次函数 即

$$
1 + D M - E W = 0\tag{6}
$$

同时根据劳动力市场出清条件 $\int _ { 0 } ^ { 1 } n _ { i t } d i = n _ { i }$ 可知<sub>，</sub>n 也是向量 $\{ \theta _ { i t } \}$ 的 $W$ 次齐次函数

基于 $\vec { J } ^ { \pm }$ 业 i 的生 $\vec { J } ^ { \pm }$ 函数和成本函数 $\cdot \vec { p } ^ { z }$ 业 i 利润最大化的一阶条件为

$$
Q _ {(n _ {i t})} ^ {\prime} = \frac {w _ {t}}{p _ {i t} \theta_ {i t}}\tag{7}
$$

由于 $\vec { J } ^ { \pm }$ 业 i 的利润函数关于 $n _ { t }$ 是凹的 因此以上最优化条件也是充分条件 记 $q ( n _ { i t } ) =$ $Q ^ { \prime } ( n _ { i t } )$ <sub>，</sub>由于 $Q ^ { \prime } ( \bullet ) \geq 0 , Q ^ { \prime \prime } ( \bullet ) \leq 0$ <sub>，</sub> 故 $q ( \cdot )$ 的反函数 $q ^ { - 1 } ( \cdot )$ 存在<sub>，</sub>且<sub>，</sub>

$$
n _ {i t} = q ^ {- 1} \left(\frac {\omega_ {t}}{p _ {i t} \theta_ {i t}}\right)\tag{8}
$$

根据 $Q ( \cdot )$ 是 $n _ { i t }$ 的K 次齐次函数可知 $\cdot q ^ { - 1 } ( \cdot )$ 是自变量的 $\frac { 1 } { K - 1 }$ 次齐次函数 劳动力市场出清时 <sub>，</sub>

$$
\frac {1}{n _ {t}} \int_ {0} ^ {1} q ^ {- 1} \left(\frac {v ^ {\prime} (n _ {t})}{u ^ {\prime} (c _ {i t})} \cdot \frac {1}{\theta_ {i t} ^ {2}}\right) d i = 1\tag{9}
$$

故根据式（9） 可知 等式左侧也应是向量 $\{ \theta _ { i t } \}$ 的零次齐次函数 即

$$
\frac {(E - 1) W - (D - 1) M - 2}{K - 1} - W = 0\tag{10}
$$

联立式（6） 和式（10） 可解得

$$
\left\{ \begin{array}{l} M = \frac {E + K}{E - D K} \\ W = \frac {1 + D}{E - D K} \end{array} \right.
$$

由于 $E > 1 , D \in \left( 0 , 1 \right) , K \in \left( 0 , 1 \right)$ <sub>，</sub> 故 $M > 1$ 且 $W > 0$ 。

产品市场出清时<sub>，</sub>各产品的 $\vec { J } ^ { \pm }$ 量与代表性家庭的消费量相等<sub>，</sub>即 $y _ { i t } = c _ { i t }$ <sub>，</sub>且中央计划者O的最优化条件为 $\frac { \partial Y _ { t } } { \partial T _ { i t } } = \mu , \forall i \in [ 0 , 1 ]$ 其中 $\mu$ 为拉格朗日乘子 表示 $T _ { i t }$ 的边际价值 亦即 $T _ { i t }$ 的影子价格<sub>，</sub>这意味着中央计划者在任意两个产业之间进行转移支付时<sub>，</sub> 始终保持转移支付在两个产业内分别带来的社会总产品的边际效用相等

当模型达到一般均衡时 由于 $y _ { i t } = c _ { i t }$ 故 $y _ { i t }$ 是θ 的M次齐次函数 再根据总产出的定义可知$Y _ { t }$ 是向量 $\{ \theta _ { i t } \}$ 的 M次齐次函数<sub>，</sub>因此根据齐次函数的性质可知<sub>，</sub>均衡时产业 i的产出 $y _ { i t } ^ { * }$ 和社会总产出 $\boldsymbol { Y } _ { t } ^ { * }$ 分别满足<sub>，</sub>

$$
\frac {d y _ {i t} ^ {*}}{d \theta_ {i t}} \theta_ {i t} = M y _ {i t} ^ {*}, \forall i \in [ 0, 1 ]\tag{11}
$$

$$
\int_ {0} ^ {1} \frac {\partial Y _ {t} ^ {*}}{\partial \theta_ {i t}} \theta_ {i t} d i = M Y _ {t} ^ {*}\tag{12}
$$

联立式（11） 和式（12） 的特征方程可得

$$
\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}} = M \frac {y _ {i t} ^ {*}}{\theta_ {j t}}, \forall i \neq j, \text {且} i, j \in [ 0, 1 ]\tag{13}
$$

$$
M > 1
$$

$$
\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}} > 0
$$

生产 — 消费网络下实体经济和数字经济之间存在正向的关联效应 即当数字产业面临的生产 —消费网络因其自身的技术创新而日益完善时 实体产业的均衡产出会上升 反之亦成立 因此 式（13） 不仅较好地验证了技术创新具有的正外部性特征 并且可以发现这一正外部性效应主要是通过生产—消费网络在产业之间进行传导的 值得一提的是 韩君 高瀛璐（2022） 使用投入产出方法测算了我国省际产业关联效应 本文与之最大的不同在于运用结构化建模的方法为我国现有生产— 消费网络中的产业关联效应提供了完整的微观基础 故本文可在一般均衡的框架下探讨数字产业与实体产业深度融合的绩效及机制

接下来本文拟探讨产业技术创新对式（13） 中产业关联效应强度的影响 假设 $\vec { \cal J } ^ { \pm }$ 业 i 的均衡 $\vec { \cal J } ^ { \pm }$ 出 ${ y } _ { i t } ^ { * }$ 和产业 $j ( i \neq j )$ 网络完备性参数 $\theta _ { j t }$ 在分布上是相互独立的 故 $\frac { d y _ { i t } ^ { * } } { d { \theta _ { i t } } }$ 的均值为

$$
\mathbb {E} \left(\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}}\right) = L M \lambda_ {t} ^ {\frac {1 - M}{R}} B _ {i t} ^ {- \frac {M}{R}} B _ {j t} ^ {\frac {1}{R}}
$$

其中 $L = \Gamma \big ( 1 + { \frac { M } { R } } \big ) \Gamma \big ( 1 - { \frac { 1 } { R } } \big ) > 0$ 此时有

$$
\frac {\partial}{\partial Z _ {i t}} \left(\mathbb {E} \left(\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}}\right)\right) = - \frac {L M ^ {2}}{R} \lambda_ {t} ^ {\frac {1 - M}{R}} B _ {i t} ^ {- \frac {M}{R} - 1} B _ {j t} ^ {\frac {1}{R}} \frac {\partial B _ {i t}}{\partial Z _ {i t}}, \forall i \neq j\tag{14}
$$

$$
\frac {\partial}{\partial Z _ {j t}} \left(\mathbb {E} \left(\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}}\right)\right) = \frac {L M}{R} \lambda_ {t} ^ {\frac {1 - M}{R}} B _ {i t} ^ {- \frac {M}{R}} B _ {j t} ^ {\frac {1}{R} - 1} \frac {\partial B _ {j t}}{\partial Z _ {j t}}, \forall i \neq j\tag{15}
$$

由式（14）和式（15）可知 某一产业的技术创新对产业间关联效应的影响方向将主要取决于技术创新对其自身生产—消费网络完备性参数的影响方向 若 $\cdot \frac { \partial B _ { i t } } { \partial Z _ { i t } } { \le } 0 , \forall i$ 则如图2a所示 当其他条件不变时 如果数字产业技术水平出现提升 则实体 $\vec { \boldsymbol { J } ^ { \pm } }$ 业对数字产业的平均关联效应将增强 从而产生<sup>“</sup>边缘服务中心<sup>”</sup>的<sup>“</sup>引力<sup>”</sup>效应 相应地 式（15）则意味着数字产业技术水平的提升将削弱其对实体产业的平均关联效应 从而出现<sup>“</sup>中心挤出边缘<sup>”</sup>的<sup>“</sup>斥力<sup>”</sup>效应 由于 i 的选取具有任意性 故实体产业的技术创新会产生相同的效果 因此本文将这两种效应概括为 $\vec { \cal J } ^ { \pm }$ 业关联效应的<sup>“</sup>中心—外围<sup>”</sup>模式

反之<sub>，</sub>若 $\frac { \partial B _ { i t } } { \partial Z _ { i t } } { \geq } 0 , \forall i$ 则产业自身的技术创新将使得其对其他产业的关联效应增强（参见图2b） 此时产业关联效应即为典型的<sup>“</sup>技术溢出<sup>”</sup>模式 由此 式（14）和式（15）较好地解释了同一生产—消费网络内部不同产业的相对竞合关系以及关联效应的有向性特征

基于式（13） 本文拟进一步探讨产业的技术创新对特定产业间关联效应的影响 根据Fisher－Tippett－Gnedenko定理 在适当的参数条件下 $m a x \left\{ { \frac { d y _ { i t } ^ { \star } } { d \theta _ { j t } } } \right\}$ 的均值可表示为

$$
\mathbb {E} \left(\max \left\{\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}} \right\}\right) = L M \lambda_ {t} ^ {\frac {1 - M}{R}} B _ {i t} ^ {- \frac {M}{R}} B _ {t} ^ {\frac {1}{R}}
$$

其中 $B _ { t } = \int _ { 0 } ^ { 1 } B _ { i t } d i < \infty$ <sub>。</sub>此时有<sub>，</sub>

$$
\frac {\partial}{\partial Z _ {i t}} \left(\mathbb {E} \left(m a x \left\{\frac {d y _ {i t} ^ {*}}{d \theta_ {j t}} \right\}\right)\right) = - \frac {L M ^ {2}}{R} \lambda_ {t} ^ {\frac {1 - M}{R}} B _ {i t} ^ {- \frac {M}{R} - 1} B _ {t} ^ {\frac {1}{R}} \frac {\partial B _ {i t}}{\partial Z _ {i t}}, \forall i \neq j\tag{16}
$$

与关联效应类似地 式（16） 表明关联效应的最大值关于产业技术创新的变动方向也直接取决于 $\cdot \frac { \partial B _ { i t } } { \partial Z _ { i t } }$ 的符号 <sub>，</sub>因此在<sup>“</sup>中心 — 外围<sup>”</sup> 模式下 <sub>，</sub>数字产业的技术创新将使其自身获得的来自实体产业的最大关联效应提升 <sub>，</sub> 相反在<sup>“</sup>技术溢出<sup>”</sup> 模式下 <sub>，</sub> 数字产业获得的最大关联效应将下降 <sub>。</sub>

综上所述 本文通过在一般均衡的框架下引入生产—消费网络结构 详细刻画了数字技术创新背景下代表性家庭 实体产业 数字产业以及中央计划者的最优化决策及其相互关联作用 进而得出了以下三点主要结论 ①在生产—消费网络下 产业的技术创新将通过网络内部产品和要素的生产流通之间的相互作用进行传导 因此生产—消费网络是创新正外部性的重要实现形式 ②生产—消费网络中的产业关联效应具有<sup>“</sup>中心—外围<sup>”</sup>或<sup>“</sup>技术溢出<sup>”</sup>模式 无论是数字产业还是实体产业 其内部技术创新通过生产—消费网络传导之后 将改变各产业相对于网络中心的位置 作用方向则取决于技术创新引致的生产—消费网络完备性的变动方向 这也直接体现了同一生产—消费网络下数字产业和实体产业之间的竞合关系 ③在<sup>“</sup>中心—外围<sup>”</sup>模式下 产业技术创新将增强该产业与特定产业之间的联系 而在 技术溢出<sup>”</sup>模式下 技术创新则会增强产业与生产—消费体系整体的联系

## 1．工资替代效应

部分学者指出数字技术创新会对其他产业劳动力需求产生替代效应 从而使得其他产业的工资总支出和劳动者工资权益降低（柏培文 张云 2021 张国胜 2022） 因此本文考虑将工资替代效应作为第一种投入产出表平衡方式 即对于所有其他产业而言 其总增加值中的工资会因数字产品中间需求投入的增加而等量下降 以使投入产出表重新平衡

从表4模型 （1） 中的反事实模拟结果可知 此时制造业和服务业的总产出将分别上升约13．12％和37．37％ 故二者关于数字产业技术创新的平均弹性分别为2．4％和6．9％ 服务业的平均反应弹性较制造业更高 这一结果较好地印证了式（13）的结论 表明数字产业的技术创新对实体产业的生产具有显著的正外部性 与此同时 制造业对数字产业的平均关联效应及其最大值将分别增长24．15和1011．01倍 而数字产业对制造业的关联效应将显著下降88．82％ 对于服务业而言 这三个数字则分别是22．690．26和87．49％ 制造业和服务业的模拟结果共同表明 在2011－2021年间 我国数字产业和实体产业之间总体呈现出<sup>“</sup>中心—外围<sup>”</sup>的分布模式 即数字产业的技术创新推动其自身迅速向整个生产—消费网络的中心靠近 从而使得实体产业对其关联效应显著提升 而反向关联效应则大幅下降

## 2．需求引致效应

在工资替代效应之外 也有不少学者认为数字经济可以通过提升企业全要素生产率 改善就业结构 改变劳资分配关系等方式提高劳动者收入（戚聿东等 2020 肖土盛等 2022） 因此本文拟采用需求引致效应作为第二种投入产出表的平衡方式 具体而言 数字技术创新不是替代实体产业劳动者的工资 而是提升实体产业的总投入 为平衡这一变动 实体产业的消费需求将等量增加 故此时数字产业总产出的提升最终引致了实体产业新的消费需求

从表4的模型（2）可知 在需求引致效应平衡方式下 数字产业的发展将分别推动制造业和服务业产出提升40．52％和1．50％ 二者的平均反应弹性分别为7．5％和0．3％ 与工资替代效应平衡方式不同的是 此时制造业产出的拉升幅度显著高于服务业 这说明相对于工资替代而言 数字技术创新引致的新需求对于制造业发展的促进作用更明显 在关联效应方面 制造业和服务业对数字产业的关联效应及其最大值 以及数字产业对制造业和服务业的关联效应均与工资替代效应平衡方式模拟结果的方向相同 并且服务业对数字产业关联效应的最大值得到了大幅提升 因此可以认为需求引致效应下生产—消费网络内数字产业与实体产业之间的<sup>“</sup>中心—外围<sup>”</sup>模式依然能够保持

## 3．混合平衡效应

在前两种平衡方式下 数字技术创新带来的实体产业产出的提升或对劳动者工资形成替代抑或引致消费需求的上升 一个自然的思考是这两种平衡方式是否可能同时存在 也就是说数字产业发展既使实体产业劳动者的工资出现部分下降 同时使得实体产业的消费需求出现部分上升 本文将这种平衡方式称为混合平衡效应 为模拟混合平衡效应的现实 本文尝试了两组不同比例的情形 表4的模型（3）中实体产业工资的降低量和消费需求的增加量分别占实体产业的数字产品中间投入增加量的80％和20％ 模型（4）则为20％和80％

基于以上分析 本文探讨了数字技术创新影响产业关联效应的具体机制 并发现尽管数字技术创新可以带动实体产业产出增加 且在总体上显著增强了实体产业对数字产业的关联效应 但在具体产业层面 各实体产业的网络完备性关于数字技术创新的反应仍存在较大差异 同时各产业内部对产业关联效应起主要的推动或制约作用的子网络也互相区别 这对于精准识别数字产业发展对实体产业的边际影响及评估产业政策具有重要意义

## 六<sub>、</sub>结论与展望

本文构建了一个包含代表性家庭 实体产业 数字产业和中央计划者等主体在内的一般均衡结构化模型 并在其中引入了关于生产—消费网络的刻画 以此研究了数字技术创新对于产业关联效应的实际绩效 研究结果表明 第一 在生产—消费网络下 数字技术创新对实体产业的产出具有正外部性影响 当数字产业的技术水平每上升1％时 制造业产出会上升约2．4％－7．5％ 而服务业产出则会上升0．3％－6．9％ 第二 在生产—消费网络下 数字产业与实体产业之间存在明显的<sup>“</sup>中心—外围<sup>”</sup>分布结构 数字技术创新使其自身获得的来自实体产业的关联效应及其最大值大幅提升 是为<sup>“</sup>边缘服务中心<sup>”</sup>效应 同时使得实体产业从数字产业获得的产业关联效应明显下降 是为<sup>“</sup>中心挤出边缘<sup>”</sup>效应 二者之间的这种竞合关系主导了新时期我国产业演进的历程 第三 数字技术创新主要通过生产—消费网络中生产 消费和劳动力供给等子网络的完备性影响产业间的关联效应 数字产业 运输仓储和租赁服务等产业的完备性随数字技术创新不断提升 而其他实体产业的完备性还有待进一步增强

基于以上所有研究 本文拟针对新时期我国数字产业和实体产业的深度融合提出三点政策建议 首先 加大数字技术基础创新扶持 不断增强产业升级的源动力 在当前 数字技术创新对我国实体产业的升级提供了强有力的技术支撑 因此新时期数字技术革新应得到足够的政策倾斜其次 充分认识并尊重产业融合路径规律 避免产业盲目融合与极化脱钩 在我国现阶段的生产—消费网络下 数字产业和实体产业表现出明显的<sup>“</sup>中心—外围<sup>”</sup>特征 数字产业正在迅速向网络中心靠近 这势必造成实体产业传统网络中心地位的下降 因此产业政策应充分把握二者之间此消彼长的演进趋势 在融合过程中给予数字经济以更大的权重 但同时数字技术的创新速率明显高于实体产业也是不争的事实 故引导数字产业更好地服务和带动实体产业发展 避免产业极化脱钩亦是二者深度融合的应有之义 最后 厘清数字技术创新的产业差异 推动生产 消费和劳动力供给网络的协调发展 对于不同产业而言 数字技术创新对其自身网络的影响不尽相同 机械设备和金融中介产业需借助数字技术完善其消费和劳动力供给等流通网络 而电子设备 办公设备 汽车运输 批发零售 酒店餐饮 不动产等产业则需进一步夯实生产体系 从而实现数字经济和实体经济融合绩效的最优化 □
