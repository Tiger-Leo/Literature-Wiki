# 资本深化、结构转型与技能溢价

郭凯明 杭 静 颜 色

内容提要: 如何理解收入分配演化机制，对政府调节不同群体间收入分配关系、改善收入分配矛盾具有重要意义。本文在多部门动态一般均衡模型中引入了不同技能劳动力，研究了结构转型在技能溢价变动中的作用。本文发现在产业部门间产品替代弹性较低时，随着资本深化或资本密集型产业技术水平更快提高，生产要素将流向劳动密集型产业; 如果劳动密集型产业同时也是技能密集型，那么技能溢价将上升，反之亦然。劳动力数量增长后，如果资本密集型产业同时也是技能密集型，那么即使高技能和低技能劳动力之比提高，技能溢价也可能会上升。本文提出即使不假设资本技能互补或技能偏向型技术等生产特征，结构转型也会改变技能溢价，这为理解收入分配提供了新的理论视角。

关键词: 资本深化 结构转型 技能溢价 收入分配

## <sub>一</sub>、引 言

改革开放以来中国经济快速发展 人均收入增幅超过了20 倍 但是当前发展不平衡不充分问题仍然突出 收入分配差距较大。如何有效实现效率和平等的动态平衡已经成为中国经济高质量发展的 个重要目标<sub>，</sub>十九届四中全会也把按劳分配为主体、多种分配方式并存上升为了社会主义基本经济制度。那么 影响收入分配演化的经济动因又是什么呢? 值得注意的是 造成中国收入不平等程度变化的 个重要原因是劳动力市场技能溢价 即高技能和低技能劳动力的工资差距在持续扩大( Zh<sub>ang e</sub>t <sub>a</sub>l<sub>．</sub>，2005; 宋冬林等，2010; 徐舒，2010; 陆雪琴和文雁兵，2013; 杨飞，2017; 卢晶亮 2017) 。而在技能溢价上升的同时 中国产业结构也发生了快速转型。如果生产过程中不同技能劳动力的密集程度在不同产业之间存在差别 那么产业相对规模的变动就必然会影响对不同技能劳动力的相对需求 进而导致技能溢价变动。从这 视角出发 本文在 个多部门动态 般均衡模型中引入不同技能劳动力 将结构转型和技能溢价同时内生化 提出结构转型也是影响技能溢价的重要因素 为理解中国收入分配演化提供了新的理论视角。

本文提出 资本深化、劳动力增长和技术进步等因素都会推动结构转型 其影响方向取决于产业部门的产品替代弹性。通过影响结构转型 这又进 步导致了技能溢价变动 其变动方向取决于产业部门的产品替代弹性和生产要素密集程度。本文详细展示了结构转型和技能溢价变动方向的前提条件 并分析了背后的理论机制。之后使用中国宏观经济数据校准了模型参数 对模型的动态转移过程进行了数值模拟 发现本文提出的理论机制在定量上是显著且稳健的。

现有研究通常将技能溢价上升现象解释为技能偏向型技术或资本技能互补等生产特征<sub>，</sub>这些特征使高技能劳动力的相对需求随着资本深化或技术进步而提高 从而推动技能溢价上升( A l <sub>，</sub>1998<sub>;</sub> K ll <sub>t</sub> l<sub>，</sub>2000<sub>;</sub> 董直庆等<sub>，</sub>2014) 。这些研究忽略了结构转型对技能溢价的影响。B i ＆ V l( 2017) 和 C i ＆ S l ( 2019) 等研究提出 国际贸易使不同国家发挥比较优势<sub>，</sub>集中在不同技能密集程度的产业进行生产<sub>，</sub>从而影响了技能溢价。H <sub>t</sub> l( 2012) <sub>、</sub>张明志等( 2015) 的实证研究表明<sub>，</sub>国际贸易对中国技能溢价的确有重要影响。除了国际贸易外<sub>，</sub>B＆ K<sub>a</sub>b<sub>os</sub>ki( 2012) 提出<sub>，</sub>对技能密集型服务的相对需求上升<sub>，</sub>在扩大服务业整体比重的同时也提高了技能溢价。B l( 2018) 提出 技能密集型产业的相对规模扩大会提高技能溢价。这些文献部分说明了结构转型对技能溢价的影响 但是并没有在存在资本深化和技术进步的多部门动态<sub>一</sub>般均衡模型中将结构转型和技能溢价同时内生化。本文利用这样<sub>一</sub>个模型<sub>，</sub>强调了即使不引入资本和技能的互补性或技术进步的方向性等假设<sub>，</sub>资本深化和技术进步带来的结构转型本身也会推动技能溢价变动 因而为技能溢价和工资收入不平等提供了新的理论解释。

本文还发展了结构转型与收入分配的关系研究。本世纪以来<sub>，</sub>在 K<sub>ongsamut et a</sub>l<sub>．</sub>( 2001) <sub>、</sub>N<sub>ga</sub>＆ Pi id ( 2007) 和 A l ＆ G i i( 2008) 等文献推动下，结构转型领域形成了以现代宏观经济学多部门增长模型为理论和实证研究工具的标准范式 在结构转型的形成动因和经济影响等领域发展迅速 取得了 系列重要成果。但是 直接关注结构转型对收入分配特别是技能溢价的影响的研究还处于起步阶段。C<sub>ase</sub>lli ＆ C<sub>o</sub>l<sub>eman</sub>( 2001) 提出<sub>，</sub>美国劳动力从农业具有比较优势的南部地区流向制造业具有比较优势的北部地区<sub>，</sub>需要首先积累技能<sub>，</sub>这就形成了天然的劳动转移成本。如果这 成本下降 就会推动结构转型 进而缩小地区收入差距。A l ＆ G i i( 2008)和 Al C d d l( 201 ) 提出 资本深化过程会推动结构转型 从而影响了资本和劳动的相对收入。郭凯明( 2019) 提出 人工智能等新 代技术也会通过影响结构转型 进而导致劳动收入份额变动。B ＆ K b ki( 2012) 和 B l( 2018) 也提出了结构转型会影响技能溢价。但是<sub>，</sub>这些研究要么没有直接关注技能溢价<sub>，</sub>要么没有全面展示资本深化或技术进步等因素通过结构转型影响技能溢价的理论机制<sub>，</sub>本文深入分析了这 理论机制的影响方向和前提条件<sub>，</sub>从这 角度发展了结构转型的收入分配影响的理论研究。

本文余下部分安排如下<sub>:</sub> 第二部分建立基本模型<sub>，</sub>第三部分对模型的静态均衡进行理论分析<sub>，</sub>第四部分对模型的动态均衡进行定量分析 第五部分对模型做拓展讨论 第六部分总结。

## 二、理论模型

这 部分建立 个多部门动态 般均衡模型。生产部门由 个最终品生产部门和两个中间品生产部门构成。最终品用于消费或投资<sub>，</sub>中间品用于生产最终品。用下标 t 表示时间<sub>，</sub>下标 $j = \left\{ 1 \right\}$ 2} 区分两个中间品生产部门。最终品生产部门由 个代表性厂商在完全竞争市场下生产。该厂商按照价格 $P _ { j t }$ 购买中间品 $Y _ { \mathit { \Pi } _ { \mathit { \Pi } _ { \mathit { \Pi } } } }$ <sub>，</sub>以常替代弹性型生产技术生 $\vec { y } ^ { \pm }$ 最终 $\vec { \cal J } ^ { \pm }$ 出 $Y _ { _ t }$ <sub>，</sub>即<sub>:</sub>

$$
Y _ {t} = \left[ \omega_ {1} ^ {1 / \varepsilon} Y _ {1 t} ^ {(\varepsilon - 1) / \varepsilon} + \omega_ {2} ^ {1 / \varepsilon} Y _ {2 t} ^ {(\varepsilon - 1) / \varepsilon} \right] ^ {\varepsilon / (\varepsilon - 1)}\tag{1}
$$

其中<sub>，</sub> $\ b , 0 < \omega _ { 1 } , \ b \omega _ { 2 } < 1$ 是常数<sub>，</sub>满足 $\omega _ { 1 } + \omega _ { 2 } = 1 \circ \varepsilon > 0$ 为常数<sub>，</sub>衡量了两类中间品的替代弹性。将最终品价格标准化为1。该厂商利润最大化问题的 阶最优性条件给出

$$
\frac {Y _ {1 t}}{Y _ {2 t}} = \frac {\omega_ {1}}{\omega_ {2}} \left(\frac {P _ {1 t}}{P _ {2 t}}\right) ^ {- \varepsilon}\tag{2}
$$

两个中间品生产部门分别由 个代表性厂商在完全竞争市场下生产。两个中间品生产厂商分别按照价格 $R _ { t } \setminus W _ { t } ^ { h }$ 和 $\boldsymbol { W } _ { t } ^ { l }$ 使用资本 $K _ { j t }$ 、高技能劳动力 $\boldsymbol { N } _ { \dot { \mu } } ^ { h }$ 和低技能劳动力 ${ \cal N } _ { j t } ^ { l }$ ，以 C<sub>o</sub>bb<sub>-</sub>D<sub>oug</sub>l<sub>as</sub> 型生产技术生产中间品 $Y _ { j t }$ 即<sub>:</sub>

$$
Y _ {j t} = A _ {j t} K _ {j t} ^ {\alpha_ {j} ^ {k}} \left(N _ {j t} ^ {h}\right) ^ {\alpha_ {j} ^ {h}} \left(N _ {j t} ^ {l}\right) ^ {\alpha_ {j} ^ {l}}\tag{3}
$$

其中 $. A _ { j t }$ 为中间品生产部门的全要素生产率 衡量了技术水平。 $0 < \alpha _ { j } ^ { k } , \alpha _ { j } ^ { h } , \alpha _ { j } ^ { l } < 1$ 均为常数<sub>，</sub>分别衡量了资本、高技能劳动力和低技能劳动力的产出弹性<sub>，</sub>满足 $\alpha _ { j } ^ { k } + \alpha _ { j } ^ { h } + \alpha _ { j } ^ { l } = 1$

中间品生产厂商利润最大化问题的<sub>一</sub>阶最优性条件给出<sub>:</sub>

$$
R _ {t} K _ {j t} = \alpha_ {j} ^ {k} P _ {j t} Y _ {j t}\tag{4}
$$

$$
W _ {t} ^ {h} N _ {j t} ^ {h} = \alpha_ {j} ^ {h} P _ {j t} Y _ {j t}\tag{5}
$$

$$
W _ {t} ^ {l} N _ {j t} ^ {l} = \alpha_ {j} ^ {l} P _ {j t} Y _ {j t}\tag{6}
$$

注意到最终品生产部门只使用中间品进行生产<sub>，</sub>并不创造增加值。于是<sub>，</sub>两个中间品生产部门的名义产出之和就是最终品生产部门的产出 也就是整个经济的总产出。因此 本文使用两个中间品生产部门的相对比重衡量产业结构。

家庭部门由 个存活无穷期的代表性家庭在完全竞争市场下进行跨期选择 以最大化效用。虽然劳动力分为高技能和低技能两类<sub>，</sub>且工资收入不相等<sub>，</sub>但仍然可以用 个代表性家庭模型化家庭部门。这是因为在产业部门之间劳动工资存在差别的结构转型模型中<sub>，</sub>通常用<sub>一</sub>个代表性家庭把需求结构模型化 就能够很好匹配需求数据( D kl ＆ V d b k 2012 C ＆ Bi h ll2013 C i 2015) 。并且根据 C lli ＆ V t ( 2000) 和 H d f t l ( 2013) 的研究 只要个体间偏好都相同 即使收入和财富水平存在差别 也可以用 个代表性个体来模型化整体经济。

给定初始资本 $K _ { 0 }$ 家庭在( 7) 和( 8) 式约束下 最大化效用

\max _ {C _ {t}, I _ {t}, K _ {t + 1}} \sum_ {t = 0} ^ {\infty} \beta^ {t} \frac {C _ {t} ^ {1 - \sigma} - 1}{1 - \sigma}

其中<sub>，</sub> $\phantom { + } 0 < \beta < 1$ 和 $\sigma > 0$ 均为常数。求解这 动态最优化问题<sub>，</sub>得到欧拉方程<sub>:</sub>

## 三、静态均衡分析

这 部分对模型静态均衡进行理论分析。静态模型中 每 期总资本被视为外生变量。给定生产要素禀赋和技术水平 就可以计算均衡下的生产要素的产业分布和价格。通过比较静态分析得出生产要素禀赋和技术水平等外生变量如何影响结构转型和技能溢价。虽然动态均衡中资本动态路径是内生的 但这部分关于静态均衡的定性结论不会改变 下 部分将对模型动态均衡进行定量分析。

## ( 二) 生产要素增长的影响

首先关注生产要素增长 即资本深化、高技能和低技能劳动力数量上升对结构转型的影响。由于资本和劳动等比例扩大不会改变产业结构和技能溢价<sub>，</sub>对资本进行比较静态分析即可以得出资本深化的影响。将( 14) <sub>、</sub>( 15) 和( 18) 式代入( 17) 式后进行比较静态分析<sub>，</sub>得到如下结论。

结论1 生产要素增长对结构转型的影响取决于产业部门的产品替代弹性。在两个生产部门的产品替代弹性小于1 时 资本深化后 资本产出弹性低的产业部门的生产要素比重和产出比重将提高<sub>;</sub> 高( 低) 技能劳动力数量上升后<sub>，</sub>高( 低) 技能劳动产出弹性低的产业部门的生产要素比重和产出比重将提高。反之亦然 即

$$
\frac {d \log x _ {t} ^ {k}}{d \log K _ {t}} > 0 \Leftrightarrow \frac {d \log x _ {t} ^ {h}}{d \log K _ {t}} > 0 \Leftrightarrow \frac {d \log x _ {t} ^ {l}}{d K _ {t}} > 0 \Leftrightarrow \frac {d \log x _ {t} ^ {\gamma}}{d K _ {t}} > 0 \Leftrightarrow (1 - \varepsilon) (\alpha_ {2} ^ {k} - \alpha_ {1} ^ {k}) > 0
$$

$$
\frac {d \log x _ {t} ^ {h}}{d \log N _ {t} ^ {h}} > 0 \Leftrightarrow \frac {d \log x _ {t} ^ {h}}{d \log N _ {t} ^ {h}} > 0 \Leftrightarrow \frac {d \log x _ {t} ^ {l}}{d N _ {t} ^ {h}} > 0 \Leftrightarrow \frac {d \log x _ {t} ^ {\gamma}}{d N _ {t} ^ {h}} > 0 \Leftrightarrow (1 - \varepsilon) (\alpha_ {2} ^ {h} - \alpha_ {1} ^ {h}) > 0
$$

$$

## ( 三) 技术进步的影响

最后关注两个产业部门技术进步对结构转型和技能溢价的影响。联立( 14) —( 19) 式后进行比较静态分析<sub>，</sub>可以得到如下结论<sub>:</sub>

结论4 技术进步对结构转型的影响取决于产业部门的产品替代弹性。在两个生产部门的产品替代弹性小于1 时 技术进步相对更快的产业部门的生产要素比重和产出比重将降低 反之亦然。技术进步对技能溢价的影响取决于产业部门的产品替代弹性和生产要素密集程度。在两个生产部门的产品替代弹性小于1 时 如果技术进步相对更慢的产业部门同时也是技能密集型产业部门<sub>，</sub>那么技能溢价将提高<sub>;</sub> 如果技术进步相对更快的产业部门同时也是技能密集型产业部门<sub>，</sub>那么技能溢价将降低。反之亦然 即<sub>:</sub>

$$
\begin{array}{l} \frac {d \log x _ {t} ^ {k}}{d \log (A _ {1 t} / A _ {2 t})} <   0 \Leftrightarrow \frac {d \log x _ {t} ^ {h}}{d \log (A _ {1 t} / A _ {2 t})} <   0 \Leftrightarrow \frac {d \log x _ {t} ^ {l}}{d \log (A _ {1 t} / A _ {2 t})} <   0 \Leftrightarrow \frac {d \log x _ {t} ^ {y}}{d \log (A _ {1 t} / A _ {2 t})} <   0 \Leftrightarrow \varepsilon <   1 \\ \frac {d \log (W _ {t} ^ {h} / W _ {t} ^ {l})}{d \log (A _ {1 t} / A _ {2 t})} <   0 \Leftrightarrow (1 - \varepsilon) (\alpha_ {1} ^ {h} / \alpha_ {1} ^ {l} - \alpha_ {2} ^ {h} / \alpha_ {2} ^ {l}) > 0 \end{array}
$$

结论4 背后的经济含义是技术进步通过影响产业部门产品的相对价格进而影响了结构转型而结构转型过程改变了技能溢价。因为技术进步更快的产业部门产品的相对价格会下降 对结构转型和技能溢价产生了类似于资本深化的作用机制。在两个生产部门的产品替代弹性较低时 相对价格下降的产品很难替代相对价格上升的产品 导致产品相对价格上升的产业部门的支出比重提高 从而拉动了生产要素流向该产业部门。如果技术进步相对更慢的产业部门同时也是技能密集型产业部门 那么该产业部门比重上升就意味着需要更多高技能劳动力进行生产 从而扩大高技能劳动力的相对需求 提高技能溢价。反之 如果该产业部门并不是技能密集型产业部门 那么低技能劳动力的相对需求就会扩大<sub>，</sub>从而降低技能溢价。

结论 也可以应用于分析要素扩展型技术进步的影响。考虑两个产业部门要素扩展型技术进步速度相同的情形。资本扩展型技术进步降低了资本密集型产业部门的产品相对价格 这等价于资本密集型产业部门全要素生产率更快增长的情形。在两个生产部门的产品替代弹性小于1 时 资本密集型产业部门的比重就会倾向于降低。如果该部门同时也是技能密集型部门 那么技能溢价也会随之下降 反之亦然。同理 高( 低) 技能扩展型技术进步降低了高( 低) 技能劳动产出弹性更大的产业部门的产品相对价格<sub>，</sub>在两个生产部门的产品替代弹性小于 1 时<sub>，</sub>该产业部门的比重就会倾向于降低。如果该部门也是技能密集型部门 那么技能溢价也会随之下降。反之亦然。

注意到高技能劳动扩展型技术进步实际上也是技能偏向型技术进步。解释技能溢价的经典理论强调了技能偏向型技术进步的影响 但影响方向依赖于高技能和低技能劳动力之间的替代弹性而没有考虑产业部门之间的产品替代弹性。在本文模型中 产业部门内部两类劳动力的替代弹性始终是1<sub>，</sub>但产业部门之间的产品替代弹性不等于1<sub>，</sub>后者才决定了技能偏向型技术进步的影响方向<sub>，</sub>这是有别于现有文献的。

## 五、进<sub>一</sub>步讨论

现有研究表明 收入增长和国际贸易等因素也会对结构转型产生影响。这 部分进 步拓展模型 分别讨论这两类因素对结构转型和技能溢价的影响。

## ( <sub>一</sub>) 收入增长的影响

现有文献通常以非位似消费偏好的设定引入收入增长影响结构转型的经济机制。但是 本文模型的需求方面不仅包括消费需求 还包括投资需求。颜色等( 2018) 研究表明 投资需求结构也具有非位似特征。因此<sub>，</sub>这里不直接引入非位似消费偏好<sub>，</sub>而是通过在最终品生产部门改变 $\omega _ { 1 }$ 和$\omega _ { 2 }$ 取值来模型化不同产业部门产品需求收入弹性的差异性。如果伴随着收入增长 取值提高 ${ \bf \nabla } _ { \bf \Omega } \omega _ { 1 }$ 那么易知生产部门1 的产品需求收入弹性大于1 而生产部门2 的产品需求收入弹性小于1。反之亦然。此时，( 1) 、( 2) 和( 18) 式中 $\omega _ { 1 }$ 和 $\omega _ { 2 }$ 变为 $\omega _ { 1 t }$ 和 $\omega _ { 2 t }$ <sub>，</sub>意味着其取值可以随着时间变化。将( 14) <sub>、</sub>( 15) 和( 18) 式代入( 17) 式后进行比较静态分析<sub>，</sub>得到如下结论<sub>:</sub>

结论5<sub>:</sub> 当不同产业部门的产品需求收入弹性存在差异时<sub>，</sub>收入增长改变了产业部门的产品相对需求 产品需求收入弹性更高的产业部门的生产要素比重和产出比重将提高 对技能溢价的影响方向取决于产业部门的生产要素密集程度。如果产品需求收入弹性更高的产业部门同时也是技能密集型产业部门 那么技能溢价将提高 如果产品需求收入弹性更低的产业部门同时也是技能密集

型产业部门<sub>，</sub>那么技能溢价将下降。即<sub>:</sub>

$$
\begin{array}{c} \frac {d \log x _ {t} ^ {k}}{d \log (\omega_ {1 t} / \omega_ {2 t})} > 0, \frac {d \log x _ {t} ^ {h}}{d \log (\omega_ {1 t} / \omega_ {2 t})} > 0, \frac {d \log x _ {t} ^ {l}}{d \log (\omega_ {1 t} / \omega_ {2 t})} > 0, \frac {d \log x _ {t} ^ {y}}{d \log (\omega_ {1 t} / \omega_ {2 t})} > 0 \\ \frac {d \log (W _ {t} ^ {h} / W _ {t} ^ {l})}{d \log (\omega_ {1 t} / \omega_ {2 t})} > 0 \Leftrightarrow \alpha_ {1} ^ {h} / \alpha_ {1} ^ {l} > \alpha_ {2} ^ {h} / \alpha_ {2} ^ {l} \end{array}
$$

结论5 背后的经济机制类似于前文结论。产品需求收入弹性更高 意味着收入增长后 对该产业部门产品的需求更快提高。于是 生产要素将向该产业部门集中 其相对规模也会随之扩大。这就会进 步影响技能溢价。如果该产业部门同时也是技能密集型产业部门<sub>，</sub>那么这 结构转型过程就会提高对高技能劳动力的相对需求 从而使技能溢价上升。反之 如果产品需求弹性更低的产业部门同时也是技能密集型产业部门 那么其相对规模的缩小就会降低高技能劳动力的相对需求从而促使技能溢价下降。

## ( 二) 国际贸易的影响

这里引入国际贸易 假设此时中间品不再全部用于生产最终品 其中 部分用于出口。最终品生产所使用的中间品也不再全部由本国生产 其中 部分来自于进口。国际贸易份额视为外生。这里仍然使用 $Y _ { j t }$ 表示本国两个中间品生产部门的产出<sub>，</sub>但最终品生产过程的中间品投入变为了$Y _ { j t } ^ { \prime }$ 。用 $X _ { j t }$ 表示两类中间品生产部门的净出口<sub>，</sub>即<sub>:</sub>

$$
Y _ {j t} = Y _ {j t} ^ {\prime} + X _ {j} = z _ {j t} Y _ {j t} ^ {\prime}\tag{23}
$$

其中<sub>，</sub>引入变量 $z _ { j t }$ <sub>，</sub>可以衡量外国对本国产品的净需求。如果 $z _ { j t } > 1$ <sub>，</sub>则相应产业部门的产品是贸易顺差<sub>，</sub>否则是贸易逆差。 $z _ { j t }$ 取值越大<sub>，</sub>外国对本国产品的净需求越大。

此时相对于封闭经济<sub>，</sub>( 1) 和( 2) 式中的 $Y _ { j t }$ 变为了 $Y _ { j t } ^ { \prime }$ <sub>，</sub>其他模型表达式均未变化。重新求解静态均衡<sub>，</sub>可知此时( 14) —( 17) 式和( 19) 式在形式上仍然不变<sub>，</sub>只是( 18) 式变为<sub>:</sub>

$$
\Omega_ {t} = \left(\frac {\alpha_ {1} ^ {k}}{\alpha_ {2} ^ {k}}\right) ^ {\varepsilon / (\varepsilon - 1)} \left(\frac {\omega_ {1}}{\omega_ {2}}\right) ^ {1 / (\varepsilon - 1)} \left(\frac {z _ {1 t}}{z _ {2 t}}\right) ^ {1 / (\varepsilon - 1)} \left(\frac {A _ {1 t}}{A _ {2 t}}\right) K _ {t} ^ {\alpha_ {1} ^ {k} - \alpha_ {2} ^ {k}} (N _ {t} ^ {h}) ^ {\alpha_ {1} ^ {h} - \alpha_ {2} ^ {h}} (N _ {t} ^ {l}) ^ {\alpha_ {1} ^ {l} - \alpha_ {2} ^ {l}}\tag{24}
$$

将( 14) <sub>、</sub>( 15) 和( 24) 式代入( 17) 式<sub>，</sub>并进行比较静态分析<sub>，</sub>得到如下结论。

结论6<sub>:</sub> 国际贸易改变了产业部门的产品相对需求 国外需求上升更快的产业部门的生产要素比重和产出比重将提高 对技能溢价的影响取决于产业部门的生产要素密集程度。如果国外需求上升更快的产业部门同时也是技能密集型产业部门 那么技能溢价将提高 如果国外需求上升更慢的产业部门同时也是技能密集型产业部门 那么技能溢价将下降。即

$$
\begin{array}{c} \frac {d \log x _ {t} ^ {k}}{d \log (z _ {1 t} / z _ {2 t})} > 0, \frac {d \log x _ {t} ^ {h}}{d \log (z _ {1 t} / z _ {2 t})} > 0, \frac {d \log x _ {t} ^ {l}}{d \log (z _ {1 t} / z _ {2 t})} > 0, \frac {d \log x _ {t} ^ {y}}{d \log (z _ {1 t} / z _ {2 t})} > 0 \\ \frac {d \log (W _ {t} ^ {h} / W _ {t} ^ {l})}{d \log (z _ {1 t} / z _ {2 t})} > 0 \Leftrightarrow \alpha_ {1} ^ {h} / \alpha_ {1} ^ {l} > \alpha_ {2} ^ {h} / \alpha_ {2} ^ {l} \end{array}
$$

结论6 背后的经济机制类似于前文结论。如果国际贸易提高了产业部门产品的相对需求那么就会导致生产要素向该产业部门集中 其相对规模随之扩大。这就会进 步影响技能溢价。如果该产业部门同时也是技能密集型产业部门 那么这 结构转型过程就会提高对高技能劳动力的相对需求 从而促使技能溢价上升。反之 如果国外需求上升更慢的产业部门同时也是技能密集型产业部门 那么其相对规模的缩小就会降低高技能劳动力的相对需求 从而促使技能溢价下降。

结论6 意味着 些影响贸易差额的因素也会影响结构转型和技能溢价。比如 在当前保护主义上升、世界经济低迷、全球市场萎缩的外部环境下<sub>，</sub>中国寻求通过畅通国内大循环为经济发展增添动力。在研发关键技术、生产核心资本和中间品的产业部门 对国外进口的依赖程度可能会持续降低<sub>，</sub>国内这些产业部门的相对规模就会扩大。如果这些产业部门同时也是高技能密集型产业<sub>，</sub>那么技能溢价就会上升 反之亦然。

## 六、总 结

本文建立了 个包含不同技能劳动力的多部门动态 般均衡模型 通过理论分析和定量模拟 发现在产业部门间产品替代弹性较低时 随着资本深化或资本密集型产业技术水平更快提高 生产要素将流向劳动密集型产业 如果劳动密集型产业同时也是技能密集型 那么技能溢价将上升 反之亦然。本文提出即使不假设资本和技能的互补性或技术进步的方向性 资本深化和技术进步带来的结构转型过程本身也会改变技能溢价<sub>，</sub>因此为技能溢价提供了新的经济理论解释。

本文研究对于中国改善收入分配格局和推动产业结构升级具有两点政策参考意义。首先 在中国经济高质量发展阶段产业结构优化升级的过程中 应当认识到效率和平等之间可能存在 定的客观矛盾。由于不同产业部门使用生产要素的密集程度存在天然差别 无论是服务业比重的上升<sub>，</sub>还是制造业或服务业内部的结构升级<sub>，</sub>只要结构转型过程扩大了高技能密集型产业的相对规模<sub>，</sub>那么就会形成推动技能溢价上升的 股经济力量。比如<sub>，</sub>在高技术制造业和生产性服务业中<sub>，</sub>企业对高技能劳动力的相对需求通常也较高 这些行业规模扩大的同时就必然会扩大不同技能劳动力的工资收入差距。因此<sub>，</sub>中国持续快速的产业优化升级在提高生产效率的同时<sub>，</sub>可能也会恶化收入平等 收入差距趋于扩大的分配矛盾将长期成为中国经济发展中的重要特征 仅依靠市场力量难以同时实现效率和平等的双重目标。

其次 政府在推动产业结构优化升级的同时 改善劳动力市场供给结构的针对性政策需要同时到位、与之配合。由于产业结构转型升级导致了生产要素在不同产业部门之间的再配置 这有助于在资本深化或技术进步过程中更好地提升生产要素使用效率 因此政策上不宜通过税收等形式直接干预不同技能劳动力的市场定价 否则很可能会阻碍结构转型和要素配置 降低生产效率和经济增速。比如 如果政府提高对于高收入者的税收 企业面临的高技能劳动力的真实雇佣成本就会上升 这将在高技能密集型产业体现得更为明显 因此也就不利于这些产业扩张 反之 如果政府降低对于高收入者的税收 虽然能够更大幅度降低高技能密集型产业的生产成本 但是却进 步恶化了收入分配矛盾。因此 更优的政策选项应当是改善劳动力供给结构 以顺应产业结构优化升级趋势。 方面 政府降低劳动力教育成本、放松劳动力教育融资约束 能够有效激励不同技能劳动力持续投资人力资本 从而不断增加高技能劳动力的相对供给 这将有利于降低技能溢价、改善收入分配 另 方面 政府消除劳动力流动壁垒 提高劳动力公共服务均等化程度 能够有助于劳动力与不同产业更好地匹配 从而改进不同技能劳动力的配置效率 这将有利于优化产业布局 推动产业升级。特别是在国际环境日趋复杂 不稳定不确定性明显增强的背景下 中国更应当集中力量办好自己的事 通过深化劳动力市场化配置改革释放改革红利 以对冲全球化遭遇逆流的阻力 为中国高质量发展增添新动能。

在本文研究的基础上还可以做如下两方面拓展<sub>:</sub> 方面 本文模型中不同产业部门高技能和低技能劳动力的替代弹性都等于1 下 步可以研究如果这 替代弹性在不同产业部门中存在差别结构转型会如何影响技能溢价<sub>，</sub>此时高技能劳动力的相对供给和产业内部技术进步的方向性可能会起着重要作用。另 方面 本文只是初步讨论了国际贸易的影响 下 步可以建立 个开放经济的多部门动态 般均衡模型 研究内生的国际贸易模式对结构转型和技能溢价的影响 此时影响国际分工模式的要素禀赋和贸易政策可能就会起着重要作用。
