# 服务业开放对企业加成率的影响基于中国制造业企业微观数据的经验研究

李方静（湖北经济学院 经济与贸易学院，湖北 武汉 430205）

摘 要：采用中国制造业企业的生产数据、服务业 FDI 以及对外直接投资数据，深入考察了服务业开放对制造业企业加成率的影响以及机制 研究发现：服务业开放对制造业企业加成率存在显著正向提升作用，且服务业走出去对企业加成率的提升作用更大 在细分行业上，租赁和商务服务，交通运输、仓储和邮政服务，信息通信服务走出去对制造业企业加成率的影响较大，而批发零售服务、金融服务、科学研究和技术服务引进来的影响较大 机制检验结果则表明，服务业开放通过促进企业新产品创新和提升企业生产率两种渠道影响企业加成率

关 键 词：服务业开放 ；企业加成率 ；创新效应；生产率

## 一、引言

回顾改革开放以来所取得的经济成就，“中国制造”享誉全球，为我国持续的经济增长提供了强劲动力 然而，随着中国进入经济增速换挡期、结构调整阵痛期和前期刺激政策消化期“三期叠加”的特定阶段，原先依仗廉价劳动力和过度消耗自然资源环境的比较优势已日渐式微，中国制造业面临的挑战和困难正逐渐增多 如何全面提升中国制造业的竞争力，实现以创新为驱动的转型升级，是事关经济高质量发展全局的战略性问题 现阶段，服务业是我国全面提高开放型经济水平、开创对外开放新格局的重点领域，服务业主导的经济转型将引领经济新常态，成为中国经济高质量增长的新动能（李平等，2017） <sup>[1]</sup>

引进来和走出去是服务业发展要达到的更高层次的双向开放模式 （陈明和魏作磊，2018）<sup>[2]</sup>那么，服务业开放能够有效促进制造业企业竞争力升级吗？服务业引进来和走出去是否存在异质性影响？以及其背后蕴藏着怎样的影响机制呢？加成率是企业动态竞争能力的重要体现（任曙明和张静，2013），<sup>[3]</sup>在当前以服务业开放为重中之重的供给侧结构性改革、全面推进开放新格局的宏观背景下，本文通过考察服务业开放与制造业企业加成率之间的相关关系，不仅可以客观评估服务业开放对制造业企业的经济效应，还可以为提升制造业企业竞争力提供全新的视角

本文的边际贡献主要体现在以下几个方面：第一，丰富了评估服务业开放经济成效的相关研究不同于国内现有文献主要从经济增长 （陈景华，2010）、技术进步 （李眺，2016）、产业结构升级 （陈明和魏作磊，2016）、企业生产率提升 （张艳等，2013） 等方面来评估服务业开放的经济效应，<sup>[4-7]</sup>本文则从企业加成率这一独特视角来评估服务业开放的经济成效，并提出了服务业开放影响企业加成率的作用机制<sub>。</sub>第二，进一步补充了企业加成率影响因素的相关研究<sub>。</sub>关于中国企业加成率的影响因素，既有文献从中间品贸易自由化 （毛其淋和许家云，2017）、产品创新 （刘啟仁和黄建忠，2016）、中国企业对外直接投资 （毛其淋和许家云，2016） 等方面考察企业加成率的影响因素，<sup>[8-10]</sup>本文从当前全面开放新格局出发，深入考察服务业开放对企业加成率的影响和作用机制，是对现有研究文献的有益补充<sub>。</sub>第三，本文还考察了服务业细分行业双向开放对企业加成率的异质性影响，并通过采用不同的企业加成率测算指标、基于企业多重异质性分样本回归以及探究地区制度环境的作用，验证了本文核心结论的稳健性<sub>。</sub>

余下部分结构安排如下：第二部分是变量、计量模型与数据，主要涉及变量的测算与选取、计量模型的设定以及数据处理说明；第三部分是基准回归与服务业行业异质性影响分析；第四部分是稳健性检验；第五部分是作用机制检验；第六部分是研究结论

## 二、变量、计量模型与数据

## （<sub>一</sub>） 变量的测算与选取

## 1. 企业加成率的测算

会计法和生产函数法是现有文献测度企业加成率的两种主要方法 （钱学锋等，2016）<sup>[11]</sup>Domowitz等 （1988） 提出的会计法将加成率表示为企业价格与边际成本的比值，计算公式简便，但是使用的前提条件颇为严格，只有在规模报酬和资本使用成本不变条件下计算出来的加成率才等于真实的加成率（刘啟仁和黄建忠，2016）<sub>。</sub><sup>[12，9]</sup>生产函数法则是从企业要素投入和产出信息中，通过估计生产函数测算加成率 其中，De Loecker 和 Warzynski （2012） （简称 DLW） 在 Hall 等 （1986） 的加成率基准模型基础之上，进一步放松假设条件，考虑生产率内生性问题，采用半参数估计方法优化处理因不可观测因素导致的加成率测算偏差，给出了基于企业层面数据估算加成率的方法，该方法在新近企业加成率的相关研究中被国内学者广泛借鉴并拓展 （诸竹君等，2016；余淼杰和袁东，2016；赵瑞丽等，2018）<sup>[13-17]</sup>因此，本文采用 DLW方法估算企业加成率，企业f在 t 期的加成率的测算公式如下：

$$
M K P _ {f t} = \psi_ {f t} ^ {X} / \nu_ {f t} ^ {X}\tag{1}
$$

其中， $\psi ^ { X }$ 表示企业某种可变投入要素X （劳动力或中间投入） 的产出弹性， $\upsilon ^ { x }$ 表示该种可变投入要素的支出份额 由于中间投入的支出份额可以从工业企业数据库中直接得到，而且中间投入要素的调整在生产过程中相对自由 （赵瑞丽等，2018）<sup>[17]</sup>因此企业加成率的测算关键在于通过估计生产函数得到中间投入的产出弹性 关于生 $\vec { J } ^ { \pm }$ 函数，在这里采用比 C-D 函数更具灵活性和适用性的超越对数形式，具体设定如下：

$$
\begin{array}{r l} \ln y _ {f t} = & \beta_ {l} \ln l _ {f t} + \beta_ {k} \ln k _ {f t} + \beta_ {m} \ln m _ {f t} + \beta_ {l l} (\ln l _ {f t}) ^ {2} + \beta_ {k k} (\ln k _ {f t}) ^ {2} + \beta_ {m m} (\ln m _ {f t}) ^ {2} + \beta_ {l k} \ln l _ {f t} \ln k _ {f t} + \beta_ {l m} \ln l _ {f t} \ln m _ {f t} + \\ & \beta_ {k m} \ln k _ {f t} \ln m _ {f t} + \beta_ {l k m} \ln k _ {f t} \ln l _ {f t} \ln m _ {f t} + \phi_ {f t} + \xi_ {f t} \end{array}\tag{2}
$$

其中， 为工业总产值，l、k 和 分别表示劳动力、资本和中间投入要素， $y$ $\phi$ 指代企业异质性生产率， $\xi$ 为随机误差项 在这里，借鉴刘啟仁和黄建忠 （2016） 的思路，<sup>[9]</sup>沿用 ACF 两步法对式（2） 展开估计，具体步骤如下：第一步基于非参数方法对模型进行估计，得到产出的估计值；第二步采用GMM方法进行参数估计得到中间投入的产出弹性系数，其表达式如下：

$$
\psi_ {f t} ^ {m} = \beta_ {m} + 2 \beta_ {m m} \ln m _ {f t} + \beta_ {l m} \ln l _ {f t} + \beta_ {k m} \ln k _ {f t} + \beta_ {l k m} \ln l _ {f t} \ln k _ {f t}\tag{3}
$$

最后，采用估计得到的中间投入产出弹性和中间投入产出份额，根据式 （1） 计算得到企业可变成本加成率<sub>。</sub>

2. 服务业开放 服务业开放是我国“十三五”时期深化市场改革、推进自由贸易进程和供给侧结构性改革的重头戏 在学术界，国内学者重点关注开放的某一方面，如服务贸易自由化 （张艳等，2013；舒杏和王佳，2018）、服务业 FDI 流入 （王恕立和胡宗彪，2010）<sub>。</sub><sup>[7，17-18]</sup>如何准确衡量服务业开放是难点 陈明和魏作磊 （2018） 认为同时包含“走出去”和“引进来”两种模式是服务业更高层次的双向开放模式，并采用服务业实际 FDI 存量数据和服务业对外直接投资额分别表示服务业引进来（SFDI） 和走出去 （SODI）<sup>[2]</sup>囿于服务产品的微观统计数据获取难度大等特征，本文借鉴该方法衡量服务业开放<sup>①</sup><sub>。</sub>另外，基于本文的研究目标，如何建立服务业与制造业之间的关联至关重要<sub>。</sub>在这里，我们沿用 Arnold 等 （2016）、刘斌等 （2016）、许和连等 （2017） 的思路，<sup>[20-22]</sup>基于 2000—2014 年世界投入产出表的最新数据，利用计算得到完全消耗系数指代制造业对服务业的依赖程度，计算公式如下：

$$
\text { service } _ {m s} = a _ {m s} + \sum_ {k = 1} ^ {n} a _ {s k} a _ {m k} + \sum_ {c = 1} ^ {n} \sum_ {k = 1} ^ {n} a _ {s c} a _ {c k} a _ {m k} + \dots\tag{4}
$$

其中， $m$ 表示企业所属制造业，<sub>s</sub> 表示服务业， $s e r v i c e _ { m s }$ 表示制造业 <sub>m</sub> 的投入服务化水平， $a _ { \scriptscriptstyle m s }$ 表示制造业行业 <sub>m</sub> 对服务业 <sub>s</sub> 的直接消耗， $\sum _ { k = 1 } ^ { n } a _ { { } _ { s k } } a _ { { } _ { m k } }$ 表示第一轮间接消耗，第 <sub>n</sub>+1 项表示第 n 轮间接消耗<sub>。</sub>

然后，我们将服务业实际 FDI 和对外直接投资流量与服务业细分行业对应的完全消耗系数相乘，得到服务业引进来和走出去的渗透率，测算公式如下：

$$
S F D I _ {m t} = \sum_ {s} \text { service } _ {m s t} \times F D I _ {s t}\tag{5}
$$

$$
S O D I _ {m t} = \sum_ {s} \text { service } _ {m s t} \times O D I _ {s t}\tag{6}
$$

其中， $F D I _ { s t }$ 和 $O D I _ { s t }$ 分别表示服务业细分行业在 t 年引进来和走出去的值， $s e r v i c e _ { { \scriptscriptstyle m s t } }$ 表示制造业对服务业细分行业的完全消耗系数， $S F D I _ { m t }$ 和 $S O D I _ { { _ m t } }$ 分别表示服务业引进来和走出去对制造业的渗透率 与此同时，为了考察不同服务业细分行业对制造业企业加成率的异质性影响，按照 《中国统计年鉴》 以及世界投入产出表的服务业分类情况，选取批发零售 （WR）、租赁和商务 （LB）、交通运输、仓储和邮政（TP）、信息通信 （IT）、金融（FS）、科学研究和技术 （ES） 6 大类服务，构建服务业细分行业的渗透率<sub>。</sub>

3. 其他控制变量 企业加成率与自身特征是密切关联的，借鉴已有文献，选取如下企业层面的控制变量： （1） 企业规模 （ln<sub>sca</sub>l<sub>e</sub>）：用企业销售额的对数表示 （2） 资本强度 （lnKLR）：采用固定资产总额与从业总人数的比值表示，并取对数，资本强度高的企业可能带来高的加成率 （3） 融资约束程度 （lnFi<sub>na</sub>）：采用利息支出与企业销售额的比值表示，并取对数<sub>。</sub> （4） 企业年龄 （lnA <sub>e</sub>）：

①严格来讲，源自 《中国统计年鉴》 和 《中国对外直接投资统计公报》 的服务业实际 FDI 数据和对外直接投资数据体现的是服务业开放的结果，而不是过程，但是，由于服务的无形性，即时性等特征，衡量服务业开放的过程存在微观统计数据获取难度大等问题 相较之下，陈明和魏作磊（2018） 的方法较为合理 <sup>[2]</sup>

采用企业当期年份与企业成立年份之间的差值表示，并取对数 （5） 企业的出口状态 （EXP）：即企业是否出口，国外文献研究表明，相较于非出口企业，出口企业的加成率更高，然而国内学者却认为，中国非出口企业的加成率更高，即出口企业存在“低加成率”陷阱<sub>。</sub>因此，本文控制了企业是否出口这一变量，企业出口交货值大于零则为 1，反之为零<sub>。</sub> （6） 企业所有权：国有企业虚拟变量（SOE） 和外资企业虚拟变量 （FORE），如果企业所有制类型是国有企业 （外资企业） 时，SOE（FORE） 赋值为 1 ，否则赋值为 0 除此之外，还选取 4 位码行业层面的赫芬达尔指数 （HHI），用来衡量行业的垄断程度<sub>。</sub>其计算公式如下： $\begin{array} { r } { { H H I } _ { j t } = \sum _ { f \in I N D _ { j } } \big ( s a l e _ { f t } \big / s a l e _ { j t } \big ) ^ { 2 } = \sum _ { f \in I N D _ { j } } S _ { f t } ^ { 2 } } \end{array}$ ，其中 $s a l e _ { f _ { \mathit { t } } }$ 表示企业f在t年的销售额， $s a l e _ { j t }$ 表示行业j在t年的总销售额， $S _ { f t }$ 表示企业f在t年的市场占有率<sub>。</sub>

## （二） 计量模型

在考察中国服务业开放与制造业企业加成率之间的因果效应时，内生性问题是不容忽视的 一方面，提升服务业开放水平能够提高制造业企业竞争力，反过来市场竞争力强的制造业企业将更有动力去影响政府政策，推进服务业开放 另一方面，服务业开放渗透率对企业加成率发挥作用可能存在时滞<sub>。</sub>基于此，设定以下计量模型：

$$
\ln M K P _ {f t} = \alpha_ {0} + \alpha_ {1} \ln S O D I _ {m, t - 1} + \alpha_ {2} \ln S F D I _ {m, t - 1} + \alpha_ {3} X _ {f, t - 1} + \gamma_ {p} + v _ {m} + y e a r _ {t} + \varepsilon_ {f m p t}\tag{7}
$$

其中，下标f、t、m 分别表示企业、年份、企业所处的制造业行业<sub>。γ</sub> 、 $\gamma _ { _ { p } }$ $\nu _ { { _ m } }$ 、year 和 $\varepsilon _ { \it f m p t }$ 分别表示地区、行业、年份固定效应和随机误差项<sub>。</sub>将核心解释变量和企业层面控制变量 （企业年龄、企业出口状态、所有权虚拟变量和赫芬达尔指数除外） 均滞后一项，以缓解可能存在的内生性问题<sub>。</sub>

## （三） 数据来源与处理

本文的数据主要来源于世界投入产出数据库 （WIOD）、中国工业企业数据库、 《中国统计年鉴》《中国对外直接投资统计公报》，选取的时间跨度为 2004—2011 年<sup>①</sup><sub>。</sub>其中，SFDI、SODI的原始数据分别来源于 《中国统计年鉴》 《中国对外直接投资统计公报》，均以亿美元为单位 对于部分缺失数据，我们采用线性插值法补齐 我们参照 Upward 等 （2013）、许家云等 （2017） 的做法对工业企业数据进行筛选处理<sub>。</sub><sup>[23-24]</sup>

此外，对工业企业数据库中工业总产值、工业增加值、中间投入以及工资总额等指标按照对应的价格指数，以 1999 年为基期进行平减，剔除通货膨胀因素 另外，还需要说明的是，由于 WIOD 采用的是国际标准行业分类，而企业数据库采用的中国国民经济行业分类，本文参考许和连等 （2017）的做法，将世界投入产出表与国内制造业行业分类整合为 18 个制造业细分行业，通过行业代码实现数据库间的衔接<sub>。</sub><sup>[22]</sup>

## 三、基准回归与服务业行业异质性影响分析

## （<sub>一</sub>） 基准回归结果分析

## 四、稳健性检验

为了检验基准模型结论的稳健性，本文通过采用不同的加成率测算指标和分样本回归进行稳健性检验，发现基准结论非常稳健，不受测算指标变更的影响，同时服务业开放的加成率提升效应对东部企业、外资企业作用最大 此外，本文还考察了省域的制度环境对服务业开放与企业加成率之间因果关系的影响，计量结果表明地区制度环境强化了服务业开放对企业加成率的正向提升效应 <sup>①</sup>

## 五、作用机制检验

## （<sub>一</sub>） 作用机制

企业加成率刻画的是企业将产品价格维持在边际成本之上的能力，因此任何改变产品价格和边际成本的因素都会对企业加成率产生影响 （孙辉煌和韩振国，2010）<sup>[27]</sup>如果服务业开放能够影响产品价格和边际生产成本，自然也就能影响企业加成率 当前制造业服务化发展新趋势日益凸显，服务成为制造业越来越重要的中间投入品，那么服务业开放所引致的知识技术的渗透扩散，势必会对制造业企业的研发、生产、运营管理产生多方面的影响

## 1. 服务业开放所引致的双向技术溢出效应将显著促进企业新产品创新活动

服务业 FDI流入将带来国外的先进知识技术和经验，替代国内低水平的服务，对制造业企业的研发活动产生显著的技术溢出效应，改善企业的研发水平和研发效率，提高企业新产品创新能力 与此同时，服务业对外直接投资通过并购、研发合作、学习交流等多种方式掌握东道国的先进知识技术，一方面通过充分吸收消化提高本国服务业的服务效率，另一方面将其掌握的研发成果以及知识技术逆向转移到国内，对母国制造业企业的创新活动产生显著的逆向技术溢出效应 随着服务业与制造业的深度融合发展，制造业企业将充分吸收服务业开放的技术溢出效应和逆向技术溢出效应，并运用到新产品研发过程中，产品创新将显著提升企业加成率 （刘啟仁和黄建忠，2016）<sup>[9]</sup>

## 2. 服务业开放通过提高企业生产率，降低生产边际成本，从而影响企业加成率

服务业提供的服务品是下游制造业企业重要的中间投入 上游服务业开放将引致大量国外先进服务品涌入，从而为制造业企业各个环节的生产运营提供更为优质高效的服务，替代本土低效服务品，促进企业生产率的提升 （Arnold 等，2016），削减企业出口成本 （Bas，2014）<sup>[20，28]</sup>同时，服务业对外直接投资通过学习效应，掌握东道国的先进知识技术，将逆向影响本国服务业 国外服务品的竞争效应和服务业对外直接投资的逆向技术溢出效应，都会刺激本土服务业进行服务技术水平的革新，从而为制造业企业提供更为高效的服务，促进企业生产率的提升，从而降低生产边际成本

$$

$$

## 六、研究结论

本文全面深入考察了服务业开放对制造业企业加成率的影响，并揭示了其中的作用机制 本文的主要结论如下：第一，服务业开放显著促进了中国制造业加成率的提升，其中服务业走出去对制造业企业加成率的影响略大于服务业引进来对制造业企业加成率的影响 第二，服务业细分行业的双向开放对制造业企业加成率存在异质性影响 其中，交通运输、仓储和邮政服务，金融服务，科学研究和技术服务对制造业企业加成率影响的显著性要大于批发零售服务、租赁和商务服务、信息通信服务的影响<sub>。</sub>同时租赁和商务服务，交通运输、仓储和邮政服务，信息通信服务走出去对制造业企业加成率的影响要大于这些细分行业引进来带来的影响，批发零售服务、金融服务、科学研究和技术服务走出去的影响则要小于这些细分行业引进来的影响<sub>。</sub>第三，机制检验结果表明，一方面，服务业开放促进了企业新产品创新，增强自身产品在市场上的差异化程度，降低产品需求弹性，从而提高了企业加成率；另一方面，服务业开放为本国制造业企业提供优质高效的服务产品，降低企业生产边际成本，提高了企业加成率<sub>。</sub>

本文从企业加成率的独特视角评估了服务业开放的经济效应，并为促进制造业企业竞争力升级提供了新思路<sub>。</sub>本文的研究结论具有丰富的政策启示：鉴于服务业开放可以显著提升制造业企业加成率，而且服务业对外直接投资的促进作用更大，因此中国政府应该进一步深入推进服务业开放，既要放宽服务业外资准入限制，充分利用先进的服务要素促进本国经济高质量发展，更要积极鼓励和引导服务业走出去，融入全球价值链网络，吸收国外先进的知识技术 同时，服务业开放也要注重不同细分行业的差异性，兼顾企业的异质性
