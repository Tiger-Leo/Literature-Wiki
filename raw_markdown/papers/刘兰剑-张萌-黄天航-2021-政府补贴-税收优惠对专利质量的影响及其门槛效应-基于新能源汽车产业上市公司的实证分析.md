# 政府补贴<sub>、</sub>税收优惠对专利质量的影响及其门槛效应———基于新能源汽车产业上市公司的实证分析

刘兰剑<sup>1，2</sup>，张 萌<sup>1，2</sup>，黄天航<sup>3</sup>

(1<sub>.</sub> 长安大学人文学院，陕西 西安 710064;2<sub>.</sub> 陕西省公众科学素质与公共政策研究中心，陕西 西安 710064;3<sub>.</sub> 中国科学院大学公共政策与管理学院，北京 100049)

摘要:政府补贴和税收优惠既是推动创新的重要政策工具，也是世界各国扶持幼稚产业的重要手段 本文选取2010—2018 年中国新能源汽车产业上市公司数据，在考察两种财税政策对专利质量影响的基础上，构建面板门槛模型，从政策工具组合使用绩效分析的视角，检验政府补贴和税收优惠组合使用时对专利质量的门槛效应 研究发现:第一，两种政策均对专利质量产生了正向的激励作用，且政府补贴的激励效果更胜一筹; 第二，补贴并非越多越好，而是存在一定阈值，在该阈值范围内时，税收优惠作用最佳; 第三，同样，税收优惠也存在相应的阈值，当优惠超过该值时，更有利于显现政府补贴的作用，识别并充分利用该阈值，才能实现两种政策工具的最优组合<sub>。</sub>

关键词:政府补贴;税收优惠;专利质量;新能源汽车;门槛效应

## 0 引言

2020 年10 月，国务院发布 《新能源汽车产业发展规划( 2021—2035) 》，鼓励新能源汽车领域高质量专利的研发，力争在2035 年实现新能源汽车关键技术达到国际领先水平 自主打造质量品牌的发展愿景<sup>［1］</sup> 在此背景下，我国为了激励新能源汽车企业攻破技术难关，采用政府补贴和税收优惠等政策工具来支持企业创新发展 其中，政府补贴作为政府无偿支出项，具有较强的资金专用性，获得补贴的企业往往将这部分资金列为研发投入，作为技术创新的储备资金 而税收优惠则是企业创新成果经过市场检验以后获得的税后收益，不仅可以抵消一部分研发成本，一定程度上也能缓解企业创新风险 这两种政策分别起到<sup>“</sup>事前激励<sup>”</sup>与<sup>“</sup>事后激励<sup>”</sup>的作用，两者的恰当组合运用能够实现政策的优势互补<sub>。</sub>

关于政府补贴与税收优惠政策是否能有效激励创新的问题，学者们尚未得出一致的结论 在政府补贴效应方面，周珊珊等<sup>［2］</sup>认为政府补贴可以刺激市场容量较大 边际成本较低的产业从事突破式技术创新 而白旭云等<sup>［3］</sup>则持相反的意见，认为政府补贴容易使企业过度依赖公共资金，降低企业的创新积极性，从而对创新质量产生抑制作用<sub>。</sub> 也有学者认为政府补贴对企业创新活动的影响具有非线性特征，例如李晓钟等<sup>［4］</sup>发现政府补贴对民营企业的创新绩效产生了门槛效应，当补贴强度处在最优区间时，激励效应呈现递增的态势 而在税收优惠效应方面，C it ki D 等<sup>［5］</sup>肯定了税收优惠对企业创新的持续激励作用，认为税收抵免等政策可以降低企业创新扭曲的风险，政府在选择政策工具时应逐渐从直接补助转向税收优惠<sub>。</sub> 潘孝珍<sup>［6］</sup>则引入股权集中度 国有股比重等门槛变量，发现当门槛区域不同时，税收优惠的创新激励效应会表现出差异性

文献可见，已有很多研究分析了单项财税政策对企业创新的激励效果，而现实情况是政府常常组合运用多种政策工具来支持技术创新，而不是采用某种单一政策 如果不同政策之间缺乏合理的政策联动与组合配置，使得政策工具<sup>“</sup>单打独斗”，就无法充分发挥政策优势，造成财政资源浪费 而现阶段不同政策组合方式产生的效果缺乏理论研究，循证研究也不多，无法为政府有效运用 <sup>“</sup>政策组合拳<sup>”</sup>提供更为精准的理论支持 基于此，本文从政策组合的视角出发，探讨政府补贴 税收优惠对专利质量的影响效应，并构建面板门槛模型进一步分析如何将不同的政策进行科学配比，从而实现政府资源的有效配置，为提高我国政府干预效率提供重要依据

## 1 研究设计

## 1. 1 研究假设

新能源汽车产业具有研发投入规模大 产业关联性强 创新风险高等特点，投入的资金在短时期内难以获得相应的回报，此时需要政府运用补贴 税收优惠等政策工具来加以引导 其中，补贴是政府发放给企业的无偿经济补偿，这部分资金可以增加企业的营业外收入<sup>［7］</sup>，是政府给予企业的<sup>“</sup>事前激励<sup>”</sup>措施 而税收优惠则是政府为企业降低税收或免除税负的一种措施，减免的税收可作为企业的期望收益<sup>［8］</sup>，是一种 <sup>“</sup>事后激励”。当企业获得政府支持后，申领到的公共资金可以转化为后期的研发投入，不仅能补偿技术创新的成本，也能为企业免去资金匮乏的担忧，以充足的资金研发创新产品<sup>［9］</sup><sub>。</sub> 据此可以推断:

假设1<sub>a</sub>: 政府补贴在提升企业额外收益的同时，也能鼓励企业增加研发投入，从而有效提升专利质量;

假设1b: 税收优惠能够弥补创新风险，增强企业创新信念，从而激励企业研发高质量专利<sub>。</sub>

由于新能源汽车企业规模 发展潜力存在差异，政府会发放不同程度的补贴金额，但补贴过低对企业专利质量的激励作用较为有限<sup>［10］</sup>，容易使企业倾向于从事低成本低风险的专利研发，这部分专利往往缺乏应用性与经济性 而补贴过高则容易引发道德风险 一方面，补贴使企业获得固定的超额收益，但政府难以追踪实际的资金用途，企业很可能将补贴资金挪作他用 另一方面，较之税收优惠政策，政府补贴具有信号功能<sup>［11］</sup>，获取补贴的企业相当于拥有政府 <sup>“</sup>担保”，更有利于得到金融机构或其他投资者的青睐<sup>［12］</sup> 同时，也容易诱使企业生产<sup>“</sup>短平快<sup>”</sup>的专利来迎合政府高额的补贴，从而获得更多的外部融资 因此，过高或过低的政府补贴都不利于高质量的专利产出 据此可以推断:

假设2: 政府补贴能够释放利好信号，但影响企业专

利质量时具有门槛效应，存在补贴的<sup>“</sup>最优区间”。

税收优惠作为间接激励方式，能够与政府补贴等直接支出进行替换 互补 或叠加<sup>［13］</sup> 由于专利研发具有较高的技术风险和市场风险，加上高昂的税款又容易给企业造成额外的创新压力，企业创新动机受到抑制，从而难以专心研发技术专利<sub>。</sub> 因此，政府将税收优惠增加到一定幅度，则有利于减轻企业的税收负担，也间接降低企业的风险顾虑<sup>［14］</sup> 此外，税收优惠政策更具灵活性，企业可以自主运用税收减免的资金进行高质量的技术创新<sub>。</sub> 并且鉴于政策时滞性影响<sup>［15］</sup>，税收优惠的激励效应往往会比程序复杂的政府补贴更为及时 据此可以推断:

假设3: 当税收优惠达到一定门槛区间时，有利于弥补政府补贴的不足，提升企业专利质量<sub>。</sub>

## 1.2 数据来源 变量选择与模型构建

## 1. 2. 1 数据来源

新能源汽车作为我国战略性新兴产业之一，是承载着未来各种关键技术应用的朝阳产业 因此，本研究选取2010—2018 年沪深两市新能源汽车产业上市公司数据为研究样本 在选取样本时，首先，在问财网的财经频道中键入<sup>“</sup>新能源汽车概念”，共检索到 247 家上市公司，人工剔除具有 ST \* ST 标识的公司，并参考百度百科词条剔除主营业务为物流服务 纺织 互联网 房地产等公司 其次，在国泰安 CSMAR 数据库 <sub>w</sub>i<sub>n</sub>d 数据库收集企业相关的财务指标数据，由于门槛模型对数据的平稳性要求较高，因此剔除年份不齐 数据缺失的企业，最终选用 60 家新能源汽车公司作为本文的研究对象，共计540 个样本观测值 最后，将筛选后的公司名称作为申请人信息在智慧芽专利数据库进行专利检索，年份限制在 2010—2018，共计 64 090 条专利

## 2.3 稳健性检验

根据以往学者的研究以及实际来看，企业交易规模也是影响企业综合专利质量的一个重要因素 本文借鉴杨继生和阳建辉<sup>［21］</sup>新增控制变量的检验方法，以营业收入和企业总资产的比值来测度企业交易规模( i ) ，将其作为新增变量纳入以上模型进行稳健性检验，检验结果的回归系数方向与全样本回归结果相同，显著性也基本保持一致，说明本文结论具有良好的稳健性和可靠性 限于文章篇幅，此处不再展示结果

## 3 主要研究结论

现阶段，政府补贴与税收优惠是我国政府鼓励新能源汽车发展的重要政策工具，二者搭配使用有利于企业进行资金积累和技术创新<sub>。</sub> 本文主要探讨了两种政策对新能源汽车企业专利质量的创新激励效应，以及二者搭配使用时政策的最佳投入区间 实证检验发现:

第一，政府补贴与税收优惠均能激励企业专利质量的提升，相比税收优惠，政府补贴的政策效应更胜一筹 第二，以政府补贴为门槛时，税收优惠对专利质量产生了双重门槛效应 即政府补贴强度低于门槛值0 016 时，税收优惠对企业专利质量的激励作用较为微弱; 而补贴强度处于门槛值0 016 0 021 之间时，能够配合税收优惠实现效用最大化; 当补贴强度超过门槛值 0 021 时，税收优惠的激励效应表现出较大幅度下降的趋势<sub>。</sub> 第三，以税收优惠为门槛时，政府补贴对专利质量同样存在双重门槛效应<sub>。</sub> 即税收优惠低于门槛值0<sub>.</sub>002 时，政府补贴能够激励专利质量的提升; 而税收优惠介于门槛值 0<sub>.</sub>002 <sub>～</sub>0<sub>.</sub>018之间时，会使补贴的激励作用有所弱化; 当税收优惠提升到门槛值0 018 时，此时政府补贴的激励效果最优

本文的研究结论对政府合理配置财政资源具有一定的实践意义: 首先，政府补贴和税收优惠组合配置的门槛效应表明，要充分结合政府补贴的直接优势与税收优惠的间接优势，实现两者的最优配合 当两种财税政策搭配使用时，仍然要注重适度的政策倾斜，实证表明过高的政府补贴会弱化税收优惠激励效用的发挥，因此需要把握好对新能源汽车企业补贴的适度性 其次，相比政府补贴，税收优惠更具灵活性，也有着更广泛的使用范围，政府应进一步开放新能源汽车企业税收优惠政策，发挥税收优惠在创新激励方面的补给功能，以此实现两种政策的优势互补，提升新能源汽车领域关键技术的创新质量
