# Model Research on the Emergence of Industrial Convergence

Hu Jinxing

(School of Business, East China of Normal University, Shanghai 200241)

Abstract: According to the self-organization theory, the emergence process of industrial convergence can be divided into two stages, that is, from the non-existing to existing and from the emergence to realization of industrial convergence with the emergence of convergent product. Considering the model of industrial development, this paper constructs the emergence process model of industrial convergence. Based on the foundation, it testifies the emergence process model with the Mathematical 4 software. The result shows the rationality of the model, and that substitution effect of products play a more important role in the process of realization of industrial convergence.

Key words: industrial convergence; process model; substitution effect

产业融合是20世纪70年代以来，由技术变革、产业管制放松、不同产业企业间的竞争与协同等多种因素互动导致的一个新兴产业产生的过程。产业融合现象最早出现在计算机、通信、广播电视和印刷等产业。20世纪90年代以来，数字技术、通讯技术的深入发展和个人电脑的普及，特别是互联网技术的发展和广泛应用，进一步促进了出版、电影、音乐、广告、教育、金融、保险和物流等产业的融合。产业的融合对产业自身的发展、产业管制政策及企业发展战略都产生了深远的影响，引起了国内外学者的关注。其中，一些学者从多个视角对产业融合的产生过程进行了研究，取得了较多的研究成果。但现有的研究主要集中在定性的描述上，对产业融合产生过程的研究仍然不够深入。本文在对现有文献进行简要回顾分析的基础上，从产品创新视角对产业融合的产生过程进行具体分析，构建出产业融合产生过程的数学模型，并运用数值模拟软件进行验证，以进一步丰富产业融合理论，为产业政策及企业发展战略的制定提供借鉴和思考。

## 一、文献回顾

产业是由技术、企业、产品与市场等构成的系统，每个产业都有各自的产业链。当产业的构成要素或产业链发生变化时，产业本身的性质也会发生变化。一些学者分别从产业构成要素或特征的变化来研究产业融合的产生过程，总体上可以分为微观与宏观视角。微观视角包括技术与产品，宏观视角包括产业链、产业结构和产业创新等。

从技术的视角来看，融合是新技术不断替代以前技术的过程；从产品视角来看，产业融合主要是通过产品的替代型融合或互补型融合来实现的；从供给与需求角度来看，产业融合是产品融合与技术融合共同演进的结果，它是一个内在的动态发展过程，这个过程由三个阶段构成。在第一阶段，从需求与供给角度来看，两个已经存在的产业是不相关的。在第二阶段，产业边界、市场结构和公司战略的变化进一步推动了产业融合。在第三阶段，从技术或产品视角来看，两个产业是相关的，产业结构会稳定下来，或者朝着新的产业融合过程发展；从价值链视角来看，产业融合的过程包括价值链的分解和价值链的重构两个阶段；从产业结构视角来看，产业融合的过程就是从传统纵向产业结构向横向产业结构发展的过程；从产业创新视角来看，产业融合的过程是从技术融合、业务与管理融合到市场融合的过程。

现有文献从不同视角对产业融合过程进行了分析，取得了较多的成果，但仍存在一些不足之处。从微观视角来看，现有文献对产业融合产生过程中的影响因素进行了具体分析，但忽视了具体的产生过程；从宏观视角来看，现有文献从定性视角对产业融合产生过程进行了分析，但比较抽象且难以量化。因此，只有把定量与定性研究相结合，才能丰富产业融合理论，并为产业政策与企业发展战略制定提供指导。

## 二、产业融合的产生过程

产业的主体是企业，而企业实现价值的主要途径是提供能满足消费者需求的产品，技术、市场和制度等产业构成要素主要是通过对产品的影响体现出来的。因此，产品是产业形成和发展过程中的一个重要影响因素。从产品的创新即融合型产品的视角，可以把产业融合分为从无到有、从出现到实现两个阶段，如图-1所示。

## （一）产业融合从无到有的阶段

产业融合从无到有的阶段是指产业融合首次出现的过程，其根本标志是融合型产品的创新。在产业融合产生之前，不同产业都有各自特定的技术、产品、企业和市场，共同构成了一个产业的边界。如图-1中的产业1、产业2和产业3，分别对应企业A、企业B和企业C等，企业1从事产业1的生产经营活动，企业2从事产业2的生产经营活动等。

多个产业在从封闭系统向开放系统转变的过程中（如产业管制的放松），会促进不同产业企业主体间的相互渗透即从事多元化行为，促进技术和业务的扩散，引起不同产业的技术融合和企业融合。但多元化行为并没有改变产业的属性，并不能促进产业融合的出现。只有当企业把不同产品整合到一个新产品中，并首次实现商业化时即融合型产品的创新，并随着越来越多企业（如图-1中的企业4）从事融合型产品的研发和生产等，才能改变原有产业的属性，促进产业融合的出现。

可见，产业融合从无到有的过程是一个产业构成要素的扩散与整合的过程。其中，技术融合、产业系统的开放性和模块化分工的演进起着关键作用。产业系统的开放性为不同产业企业间的互动创造了一个开放的环境，扩大了企业进行搜寻与选择的范围；技术融合促进了不同产业具有相似的技术基础，为企业进行相似的经营活动创造了条件：模块化分工的盛行、特别是模块的创新会打破现有产业的纵向结构，这些因素共同为企业整合不同产业要素创造了条件，促进了企业的融合及产品的创新。

## （二）产业融合从出现到实现的过程

产业融合从出现到实现的过程是指融合型产品产生后，像“序参量”一样（哈肯，2001），发挥“役使”功能，役使着技术、产品、企业、制度和市场等构成要素向同一个方向发展，并对现有多个产业中的产品进行替代，促进原有产品退出市场，形成以融合型产品为主导的新兴产业，并促进新兴产业发展进入稳定发展期。

在产业融合出现到实现的过程中，标准融合、融合型产品功能的完善及价格的降低、市场融合等对产业融合的实现起着非常重要的作用。

1．标准融合。由于不同产业企业在整合其它产业产品功能的过程中是以原有产业为基础的，这会引起融合型产品的非兼容性问题即不同产品尽管具有相似的功能，但由于产品间的不兼容性会导致产品市场规模有限，并进而影响产品市场的融合及相关产业的发展。如目前我国广播电视产业提供的数字电视采用的传输技术是广电系统自主标准STiMi，而通信产业提供的网络电视（IPTV）采用的传输技术是无线移动通信网络的技术标准，这样就引起了同一服务产品的不兼容性和相互之间的替代能力，直接影响了产品的融合及市场的融合进程。

2．融合型产品功能的完善与价格的降低。在融合型产品出现的早期，由于价格偏高、产品功能不完善以及消费者消费行为的“惯性”，影响了融合型产品对现有产品的替代能力。只有进一步完善融合型产品的功能，降低产品生产成本和产品价格，增强融合型产品对其它产品的替代能力，才能加快市场融合的速度，促进产业融合的实现。

3．市场融合是不同产业系统所服务的对象（消费者）向同一点汇合，市场融合的结果扩大了融合型产品的市场规模，为不同企业整合其它产业资源提供了规模经济的内生性激励。

## 三、产业融合产生过程的数学模型

在产业发展模型中，单个产业发展的基本模型可用式（1）来表示。

$$
\frac {d X}{d t} = a X (N - X)\tag{1}
$$

其中，a为产业增长速率，N为市场中潜在的最大用户量，X为市场中实际购买使用的用户数量。产业融合是由多个产业间的相互作用所引起的，一个产业的发展会对另一产业发展产生影响，这种影响可通过两个产业间的替代系数或效应来表示。假定市场中存在的产业X 与产业X 两者是竞争关系，当企业整合两个产业属性并进行融合型产品创新时，会促进产业X 的出现，这样，产业融合产生过程可用以下数学模型来表示。

$$
\left\{ \begin{array}{l} \frac {d X _ {1}}{d t} = a _ {1} X _ {1} \left(N _ {1} - X _ {1} - c _ {1 2} X _ {2} - c _ {3 1} X _ {3}\right) \\ \frac {d X _ {2}}{d t} = a _ {2} X _ {2} \left(N _ {2} - X _ {2} - c _ {2 1} X _ {1} - c _ {3 2} X _ {3}\right) \\ \frac {d X _ {3}}{d t} = a _ {3} X _ {3} \left(N _ {3} - X _ {3} - c _ {1 3} X _ {1} - c _ {2 3} X _ {2}\right) \end{array} \right.\tag{2}
$$

其中， $\begin{array} { c c c c c c } { C _ { 1 2 \setminus } } & { C _ { 2 1 \setminus } } & { C _ { 1 3 \setminus } } & { C _ { 3 1 \setminus } } & { C _ { 3 2 \setminus } } & { C _ { 2 3 } } \end{array}$ 等为替代系数。

从式（2）中可以看出，当 $a _ { 3 } \textrm { , } N _ { 3 } \textrm { } c _ { 1 3 } \textrm { } c _ { 3 1 } \textrm { , } c _ { 2 3 }$ 等由原来的0值变成正值时意味着产业融合的出现。而当产业X 的出现并对产业X 和产业X 进行替代导致$N _ { 1 }$ 、N 变成0时，则意味着产业融合的实现。

对方程组（2）进行求解

$$
f _ {1} = \frac {d X _ {1}}{d t} = a _ {1} X _ {1} \left(N _ {1} - X _ {1} - c _ {1 2} X _ {2} - c _ {3 1} X _ {3}\right)\tag{3}
$$

$$
f _ {2} = \frac {d X _ {2}}{d t} = a _ {2} X _ {2} \left(N _ {2} - X _ {2} - c _ {2 1} X _ {1} - c _ {3 2} X _ {3}\right)\tag{4}
$$

$$
f _ {3} = \frac {d X _ {3}}{d t} = a _ {3} X _ {3} \left(N _ {3} - X _ {3} - c _ {1 3} X _ {1} - c _ {2 3} X _ {2}\right)\tag{5}
$$

$f _ { 1 } = 0 , f _ { 2 } = 0 , f _ { 3 } = 0$

计算方程组的特征矩阵A:

$$
\mathrm{A} = \left| \begin{array}{l} \frac {\partial f _ {1}}{\partial X _ {1}}, \frac {\partial f _ {1}}{\partial X _ {2}}, \frac {\partial f}{\partial X _ {3}} \\ \frac {\partial f _ {2}}{\partial X _ {1}}, \frac {\partial f _ {2}}{\partial X _ {2}}, \frac {\partial f _ {2}}{\partial X _ {3}} \\ \frac {\partial f _ {3}}{\partial X _ {1}}, \frac {\partial f _ {3}}{\partial X _ {2}}, \frac {\partial f _ {3}}{\partial X _ {3}} \end{array} \right| = \left( \begin{array}{l} a _ {1} (N _ {1} - 2 X _ {1} - c _ {1 2} X _ {2} - c _ {3 1} X _ {3}), - a _ {1} c _ {1 2} X _ {1}, - a _ {1} c _ {3 1} X _ {3} \\ - a _ {2} c _ {2 1} X _ {1}, a _ {2} (N _ {2} - 2 X _ {2} - c _ {2 1} X _ {1} - c _ {3 2} X _ {3}), - a _ {2} c _ {3 2} X _ {2} \\ - a _ {3} c _ {1 3} X _ {3}, - a _ {3} c _ {2 3} X _ {3}, a _ {3} (N _ {3} - 2 X _ {3} - c _ {1 3} X _ {1} - c _ {2 3} X _ {2}) \end{array} \right)\tag{6}
$$

这里只对（0，0，N<sub>3</sub>）进行求解，因为它代表着第一个产业、第二个产业的消亡以及实现第三个产业的融合。把 $X _ { 1 } = 0 , \ X _ { 2 } = 0 , \ X _ { 3 } = N _ { 3 }$ 代入式（6）有

$$
\mathrm{A} = \left( \begin{array}{l} a _ {1} (N _ {1} - c _ {3 1} N _ {3}), 0, - a _ {1} c _ {3 1} N _ {3} \\ 0, a _ {2} (N _ {2} - c _ {3 2} N _ {3}), 0 \\ - a _ {3} c _ {1 3} N _ {3}, - a _ {3} c _ {2 3} N _ {3}, - a _ {3} N _ {3} \end{array} \right)\tag{7}
$$

特征方程： $\operatorname* { d e t } { \left| \lambda E - A \left( A _ { 1 } \right) \right| } = 0$ 有解

$$
\lambda_ {1} = a _ {1} \left(N _ {1} - c _ {3 1} N _ {3}\right), \quad \lambda_ {2} = a _ {2} \left(N _ {2} - c _ {3 2} N _ {3}\right), \quad \lambda_ {3} = - a _ {3} N _ {3}
$$

$$
\text { 由于 } \lambda_ {3} = - a _ {3} N _ {3} <   0,
$$

当满足

$\lambda _ { 1 } = a _ { 1 } \big ( N _ { 1 } - c _ { 3 1 } N _ { 3 } \big ) < 0$ ，即 $N _ { 1 } { < } c _ { 3 1 } N _ { 3 }$ ，或 $c _ { 3 1 } > \frac { N _ { 1 } } { N _ { 3 } }$

$$
\lambda_ {2} = a _ {2} \left(N _ {2} - c _ {3 2} N _ {3}\right) <   0, \text {即} N _ {2} <   c _ {3 2} N _ {3}, \text {或} c _ {3 2} > \frac {N _ {2}}{N _ {3}}
$$

这说明当产业X 对产业X 的替代系数大于产业X 与产业X 最大潜在市场容量之比且产业X对产业X替代系数大于产业X与产业X最大市场容量之比时，三个产业会出现产业融合的情况，其结果是新出现的新兴产业替代前两个产业，促进产业融合的实现。

## 五、小结

产业融合产生过程模型说明，融合型产品的出现对新兴产业的产生、发展及产业结构的升级等都有着非常重要的影响。在这个过程中，企业是产业融合的主体，创新是企业促进产业融合的根本动力，企业要加强创新文化的培育和创新战略的实施，而不仅仅是采取多元化发展战略。而政府对产业融合的影响主要是通过创新环境体现出来。在融合型产品出现前，最主要的是放松产业管制政策，激励企业尽快树立创新为导向的发展战略；在融合型产品出现之后，政府可以通过培育融合型产品市场、加大融合型产品消费政策的供给力度和加强质量监管等途径，加快新兴产业的产生和发展，进而推动我国产业结构的升级。
