# 外商直接投资对中国企业嵌入全球价值链稳定性的影响研究

刘会政，韩 琪

( 北京工业大学 经济与管理学院，北京 100124)

摘要: 利用中国企业微观数据，通过对企业嵌入全球价值链持续时间的测度，探究外商直接投资对中国企业嵌入全球价值链稳定性的影响 研究结果表明: 外商直接投资对于增强企业嵌入全球价值链的稳定性具有积极的促进作用，其作用主要体现为行业内的水平溢出效应 外商直接投资可增强外资企业以及民营企业嵌入全球价值链的稳定性<sub>。</sub> 无论企业是否涉及中间品，外商直接投资均能在水平关联上促进其嵌入全球价值链的稳定性; 在前向关联上，虽然会增强未涉及中间品的企业嵌入全球价值链的稳定性，但却会抑制涉及中间品的企业嵌入全球价值链的稳定性;在后向关联上，仅能增强未涉及中间品的企业嵌入全球价值链的稳定性<sub>。</sub> 在传导机制上，外商直接投资通过提升出口产品质量增强企业嵌入全球价值链的稳定性<sub>。</sub>

关键词: 外商直接投资; 全球价值链; 嵌入稳定性; 持续时间; 溢出效应

## 引 言

全球价值链 ( Gl b l V l Ch i ，GVC) 分工已经成为当今国际分工的重要形式，越来越多的新兴经济体嵌入 GVC 中 然而，嵌入 GVC 往往伴随着外部风险的增加 嵌入 GVC 的稳定性，即面对外部经济冲击时，企业嵌入 GVC 的稳定性和市场生存能力，直接影响到一国对外贸易发展的稳定性 目前全球经济增速放缓，不确定性因素增多，影响了企业嵌入 GVC 的稳定性 ( 王开和佟家栋，2019) 新冠肺炎疫情以及国内外经济环境的变化对世界各国的产业链 供应链造成了极大威胁，某些产业的供应链出现断链风险<sub>。</sub> 而外国资本凭借自身的独特优势，能够在很大程度上加强中国企业嵌入 GVC 的深度 ( 罗伟和吕越，2019) 在此背景下，深入探究外商直接投资( F<sub>ore</sub>i<sub>gn</sub> Di<sub>rect</sub> I<sub>nvestment</sub>，FDI) 对中国企业嵌入 GVC 稳定性的影响，具有重要的现实意义<sub>。</sub>

笔者从引入外商投资的视角探究中国企业嵌入 GVC 的稳定性<sub>。</sub> 采用 2000<sub>～</sub>2007 年中国微观企业的面板数据，构建离散时间的 Cl l 生存分析模型，分析外商直接投资对中国企业嵌入 GVC 稳定性的影响，并检验了 FDI 对企业嵌入 GVC 稳定性的影响机制<sub>。</sub>

## 一<sub>、</sub> 文献回顾与理论机制

## ( 一) 文献回顾

与本研究密切相关的文献主要有以下两个方面<sub>。</sub>

## 1<sub>.</sub> 关于价值链稳定性的研究

(1) 关于价值链稳定性的具体界定 鲜有文献涉及此问题，但已有学者对经济稳定性的内涵进行阐述 经济稳定性指经济系统受到扰动后的恢复能力，体现为经济波动与经济增长的契合，即一国经济在面临外部冲击后恢复其原增长状态的能力 ( 何剑和张梦婷，2017) 在中国经济发展的转型阶段，需要增强经济系统的稳定性 ( 苏杭，2015)

(2) 关于价值链稳定性的衡量 现有文献通常采用持续时间这一指标来衡量价值链的稳定性，并采用生存分析法进行测度 价值链持续时间越长，表明稳定性越强 冯等田等 (2020) 利用生存分析方法，考察了 1999 2005 年中国出口贸易关系的稳定性，发现此期间内中国的出口平均持续时间较短，贸易关系稳定性不高

(3) 关于 GVC 的稳定性<sub>。</sub> 目前涉及 GVC 稳定性的文献较少<sub>。</sub> 吕越等 ( 2017)探究了 GVC 持续时间以及相关决定因素，发现中国企业嵌入 GVC 的持续时间普遍较短，稳定性较差; 孙华平和魏伟 ( 2020) 认为，新冠肺炎疫情的全球蔓延极大地考验了中国价值链的稳定性，新冠肺炎疫情与中国嵌入 CVC 的稳定性呈负相关<sub>。</sub>

## 2<sub>.</sub> 关于 FDI 对全球价值链影响的研究

关于引入 FDI 对嵌入 GVC 影响的研究成果较为丰富，且大多集中于探究外商直接投资对价值链嵌入度的影响 A d 和 S <sub>t</sub>h l d ( 2015) 对加拿大 FDI 数据进行分析研究，发现FDI 能够提升加拿大国内经济水平，优化产业结构，有效提升加拿大在 GVC 中的地位 李强和郑江淮 ( 2013) 发现 FDI 对中国制造业价值链地位的提升具有显著的促进作用，且对劳动密集型企业所起的促进作用比对资本技术密集型企业的促进作用更大

FDI 的引入会产生一定的溢出作用，其产生方式主要有两种: 一是行业内溢出效应，即水平溢出效应 ( Bl <sub>t</sub> ＆ K kk ，1994) ; 二是行业间溢出效应，即垂直溢出效应 ( J ik，2004) 李磊等 (2017) 探究 FDI 能否提高中国内资企业的GVC 嵌入度，发现 FDI 的水平溢出对企业嵌入 GVC 有积极影响<sub>。</sub> Y<sub>uan</sub> ( 2018) 分析了9 个发展中国家的相关数据，发现从总体上看，FDI 能够促进发展中国家 GVC嵌入度的提升，且其提升促进作用主要通过垂直溢出方式来实现<sub>。</sub>

上述文献奠定了本研究的基础，其不足和未尽之处，为笔者提供了深入探究的空间 本研究的边际贡献主要有以下几方面: ( 1) 与目前有关国际贸易持续时间的研究视角不同，从引入外商直接投资的视角研究 FDI 对中国企业嵌入 GVC 稳定性的影响，丰富了中国嵌入 GVC 的相关理论研究成果 (2) 借鉴吕越等 (2015)采用的企业出口国外增加值率 ( F i V l Add d R <sub>t</sub> ，FVAR) 的测算方法，将产品按照嵌入GVC 的方式进一步细分为涉及中间品企业与未涉及中间品企业，填补了未涉及中间品企业未被纳入研究范围这一空缺，使研究内容更为全面 ( 3) 在考察了 FDI 对企业嵌入 GVC 稳定性影响的基础上，根据企业性质及产品生产类型进行分类考察，并以产品质量为传导路径，探究 FDI 对企业嵌入 GVC 稳定性的影响，为企业持续经营 稳定全球价值链地位 降低价值链断链风险提供理论支持

## ( 二) 理论机制

不少学者就FDI 对企业产品质量产生的影响进行过细致的研究 大多数学者认为，FDI 的进入具有提升本土企业产品质量的作用<sub>。</sub> 李坤望和王有鑫 ( 2013) 发现，FDI 通过水平和垂直联系，促使本土企业学习先进知识 提升技术水平，从而促进本土企业出口产品质量的提升 徐美娜和彭羽 ( 2016) 发现，下游 FDI 通过技术支持 管理培训 质量控制和标准化等方式将技术转移给当地供应商，有利于上游本土企业降低产品成本 提髙产品质量 另外，H h 和 S h i<sub>t</sub> ( 2002)提出 GVC 升级的四种方式中包含产品升级 而产品质量的提升属于产品升级的一种，是带动企业嵌入 GVC 地位提升的有效方法之一，所以也有不少学者探究了产品质量与价值链升级之间的关系 程凯和杨逢珉 ( 2020) 发现进口中间品质量升级可促使企业吸收先进的技术手段以进行模仿学习与自主创新，从而提升制造业企业嵌入全球价值链的地位; 王兵 (2020) 认为企业产品质量的提升过程可以对接价值链的各个环节，从而促进价值链链条全方位的提升

理论分析表明，FDI 对于企业产品质量的提升可以通过行业内的水平溢出和行业间的垂直溢出来实现 从行业内作用方向来讲，FDI 进入后可为同行企业带来更为先进的生产技术和管理经验，进而提高同行业企业投入产出率和产品质量 从行业间来看，上游FDI 可以通过为下游企业提供更为优质的中间产品，使下游企业拥有更多的资源，并将这些资源用于更高质量的中间品投入及产品研发，进而提高下游企业的产品质量 下游FDI 为获取上游企业更符合标准的中间品，对上游企业进行相应的技术指导以及人才支援，促使上游企业提升产品质量 更高的企业产品质量将提升企业在国际市场中的竞争力，减弱企业产品的可替代性，从而稳定企业在GVC 中的地位，增强企业嵌入 GVC 的稳定性 据此，提出如下假设: FDI 可通过提升产品质量来增强企业嵌入 GVC 的稳定性

## 二<sub>、</sub> 指标测度与典型事实分析

## ( 一) 相关指标测度

## 1 嵌入全球价值链稳定性的测度

用企业嵌入 GVC 的持续时间来反映企业嵌入 GVC 的稳定性 具体衡量标准为企业从开始进入价值链至退出价值链的时间长度<sub>。</sub> 进行数据处理时，样本数据会存在 <sup>“</sup>左删失<sup>” “</sup>右删失<sup>”</sup> 的问题 <sup>“</sup>左删失<sup>”</sup> 是指在观察期的第一年企业就已嵌入GVC 当中，因为无法确定该企业嵌入 GVC 的具体时间，所以在实际操作中一般会剔除该类数据<sub>。</sub> <sup>“</sup>右删失<sup>”</sup> 是指在样本期的期末，企业尚未退出 GVC<sub>。</sub> 在 <sup>“</sup>右删失<sup>”</sup> 下，无法确定企业退出 GVC 的时间，但生存分析法能够较好地解决这一问题笔者利用中国工业企业数据库和中国海关数据库，将 2000<sub>～</sub>2007 年相关企业数据进行匹配整理，并剔除了存在 <sup>“</sup>左删失<sup>”</sup> 问题的企业数据

在企业嵌入 GVC 持续时间的测度中，如果某企业在第 n<sub>－</sub>1 年未嵌入 GVC，在第 n 年已嵌入 GVC，则认为该企业从第 n 年开始嵌入 GVC; 若某企业在第 m 年嵌入 GVC，在 m<sub>+</sub>1 年未嵌入 GVC，则认为该企业于第 m 年退出 GVC，该企业嵌入GVC 的持续时间为 m+1<sub>－</sub>n 年<sub>。</sub> 为进行生存分析，笔者参考吕越等 ( 2017) 的做法为企业退出 GVC 事件构造了虚拟变量 Censor，并进行二元赋值，0 代表企业嵌入GVC，1 代表企业退出GVC 存在 <sup>“</sup>右删失<sup>”</sup> 的企业，其每年Censor 变量均取值为0; 数据完整 ( 不存在 <sup>“</sup>左删失<sup>”</sup> 或 <sup>“</sup>右删失<sup>”</sup> ) 的企业，其嵌入 GVC 的最后一年记为1，其余年份为0 由于较多企业进出国际市场较为频繁，企业可能会存在多个嵌入 GVC 持续时间段 借鉴冯等田等 ( 2020) 研究出口贸易持续时间的方法，仅针对多个嵌入时间段中的第一段持续时间进行研究

## 2<sub>.</sub> 企业嵌入全球价值链模式的测度

根据联合国工业发展组织对 GVC 的定义<sup>①</sup>，GVC 不仅涉及用于生产其他商品和服务的中间产品，还包括无须再次加工利用的其他商品 按广泛经济类别分类( Cl ifi <sub>t</sub>i b B d E i C <sub>t</sub> i ，BEC) 将国际贸易商品分为中间品 资本品和消费品三种基本货物类别<sub>。</sub> 这三大类产品均参与了 GVC 网络，故笔者在考虑企业嵌入价值链稳定性问题时将该三类产品均纳入研究范围 将包含进出口数据即嵌入 GVC 的企业分为两种: 一种为涉及中间品进出口的企业，一种为未涉及中间品进出口的企业 前者为存在出口国外增加值率的企业，后者为存在进出口数据但不存在出口国外增加值率的企业 在此基础上，进一步测算 GVC 不同嵌入模式的持续时间 关于出口国外增加值率的算法借鉴了吕越等 ( 2015) 的方法，具体如下:

$$
F V A R = \frac {V _ {A F}}{X} = \frac {\left\{M _ {A} ^ {p} + X ^ {o} \left[ M _ {A m} ^ {o} / (D + X ^ {o}) \right] \right\} + 0 . 0 5 \left\{M ^ {T} - M _ {A} ^ {p} - M _ {A m} ^ {o} \right\}}{X}\tag{1}
$$

式 ( 1) 中，O 指一般贸易; P 指加工贸易; M<sub>、</sub> X<sub>、</sub> D 分别表示企业进口<sub>、</sub> 出口与国内销售额; $M ^ { T }$ 为企业中间投入额，式 ( 1) 相当于假定企业有 5%的国内中间投入为海外增加值; $M _ { A } ^ { p }$ 与 $M _ { A m } ^ { o }$ 分别为企业实际加工贸易进口额和一般贸易中间投入进口额， $M _ { A } ^ { p } = \sum _ { i } \frac { M ^ { p } } { 1 - m ^ { i } } , \ M _ { A m } ^ { o } = \sum _ { i } \frac { M _ { m } ^ { o } } { 1 - m ^ { i } }$ ，其中， $m ^ { i }$ 为企业产品进口额中来自中间贸易商的累计进口占总进口的比重， $1 - m ^ { i }$ 为通过海关的直接进口比例<sub>。</sub>

## 3<sub>.</sub> 外资溢出效应的测度

借鉴 J<sub>avorc</sub>ik ( 2004) 以及毛其淋和许家云 ( 2018) 的方法测度 FDI 的溢出效应，并从行业层面分别考察行业内与行业间的溢出<sub>。</sub> 具体测算方法如下:

(1) 水平溢出系数 ( FDIh) 用水平溢出系数衡量外资企业进入后对同行业企业产生影响而形成的水平溢出<sub>。</sub> 具体表现为行业 m 内企业 FDI 比例的加权平均值，权重为行业内企业的产出占比，如式 (2) 所示<sub>。</sub>

$$
F D I h = \sum_ {n \in \triangle m} \left(F D I _ {n t} \times Y _ {n t} / \sum_ {n \in \triangle m} Y _ {n t}\right)\tag{2}
$$

式 ( 2) 中， $\triangle m$ 表示行业 m 内包含的所有企业; $F D I _ { n t }$ 代表企业 n 的 FDI 占比，用企业n 中外国资本占企业总实收资本的比重来衡量 $Y _ { n t }$ 表示t 年企业n 的总产出

(2) 前向关联溢出系数 ( FDIf) 前向关联溢出系数是衡量位于行业上游的外资企业 n 通过向其下游行业 m 提供中间投入品而形成的前向溢出 具体测算方法如式 ( 3) 所示<sub>。</sub>

$$
F D I f = \sum_ {s \neq m} \varphi_ {m s t} \times \left[ \sum_ {n \in \Delta s} F D I _ {n t} \times \frac {\left(Y _ {n t} - E X _ {n t}\right)}{\sum_ {n \in \Delta s} \left(Y _ {n t} - E X _ {n t}\right)} \right]\tag{3}
$$

式 (3) 中，s 代表上游行业; $\varphi _ { m s t }$ 代表下游行业m 从上游行业s 购买的中间投入品比重 (通过2002 年中国投入产出表计算而得<sup>①</sup>) ; $E X _ { n t }$ 代表t 年企业n 的总出口<sub>。</sub>

(3) 后向关联溢出系数 ( FDIb ) 后向关联溢出系数是衡量位于行业下游的外资企业 n 通过向其上游行业 s 购买中间投入品而形成的后向溢出<sub>。</sub> 具体测算方法如式 ( 4) 所示<sub>。</sub>

$$
F D I b = \sum_ {m \neq s} \psi_ {s m t} \times F D I _ {m t} ^ {h}\tag{4}
$$

式 (4) 中，s 代表上游行业; $\psi _ { s m t }$ 代表上游行业s 的中间品投入到下游行业 m 的比重 (通过2002 年中国投入产出表计算而得) ; $F D I _ { m t } ^ { h }$ 代表下游行业的 m 在 t 年的外资水平; 后向关联溢出系数FDIb 由上游行业s 的所有下游行业FDI 比重加权而得<sub>。</sub>

匹配整理2000 2007年工业企业数据库与海关统计数据库数据并进行相关指标测算，测度该段时间企业进出 GVC 状况以及嵌入 GVC 的持续时间 对数据进行处理后，最终获得79 535 家企业层面数据

## 五<sub>、</sub> 结论及建议

## ( 一) 结论

笔者通过匹配 2000<sub>～</sub>2007 年中国工业企业数据库与海关数据库的企业微观数据，探究了引入 FDI 对中国企业嵌入 GVC 稳定性的影响，得出以下结论<sub>。</sub>

( 1) 目前中国企业嵌入GVC 的平均持续时间为2 21 年，稳定性较低<sub>。</sub> 东部企业<sub>、</sub> 加工贸易企业<sub>、</sub> 外资企业以及涉及中间品的企业嵌入 GVC 相对稳定，嵌入GVC 持续时间较长

(2) FDI 有助于提高中国企业嵌入 GVC 的稳定性，其促进作用主要体现为行业内的水平溢出，进而通过提升产品质量增强企业嵌入 GVC 的稳定性<sub>。</sub> 在对不同性质企业嵌入 GVC 的影响方面，FDI 的引入能显著促进外资企业以及民营企业嵌入 GVC 的稳定性<sub>。</sub>

(3) 无论企业是否涉及中间品，FDI 均提高了其嵌入 GVC 的稳定性，但作用渠道不同 FDI 主要通过水平关联增强涉及中间品的企业嵌入 GVC 的稳定性 前向关联会抑制企业嵌入 GVC 的稳定性，而后向关联对企业嵌入 GVC 的稳定性则无显著影响; 对未涉及中间品的企业，FDI 可通过水平及前后向关联增强企业嵌入GVC 的稳定性

## ( 二) 建议

(1) 继续加大FDI 引入力度<sub>。</sub> 政府要加强国内企业项目储备工作，利用企业优势，打通国际渠道，加强企业引资项目的宣传推广，同时提高引资过程各个环节的服务质量，为企业营造良好的引资环境，促进外资引入 企业要结合自身特点实现对口资金引入，加大包含新兴技术及服务的外资流入，实现高质量引资<sub>。</sub>

(2) 促进企业产品质量的提升<sub>。</sub> 建立企业质量文化，贯彻全员质量意识，从产品材料源头入手，主动提升质检标准<sub>。</sub> 加大企业员工培训力度，提高员工学习能力，制定合理的评奖制度，激励员工进行产品创新，全面提升产品质量<sub>。</sub>

(3) 加快加工贸易转型升级 进一步优化国内投资环境，包括基础设施的改善以及政策法规等投资软环境的优化，为跨国公司产业转移创造有利环境 企业需提高自主创新能力，积极引进和吸收国外先进技术，结合企业自身优势，进行二次创新 政府也应对加工贸易企业的技术创新给予一定的政策扶持，加快国内加工贸易企业改革创新的步伐
