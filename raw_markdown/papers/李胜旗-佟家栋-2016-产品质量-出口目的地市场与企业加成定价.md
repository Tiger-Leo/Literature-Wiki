# 产品质量 出口目的地市场与企业加成定价

李胜旗1 佟家栋2

<sub>（</sub>1．首都经济贸易大学金融学院 北京 100070<sub>；</sub> 2．南开大学经济学院 天津 300071<sub>）</sub>

摘 要 加成定价是研究中国出口产品价格和市场竞争环境的重要内容 文章在对中国出口企业基于边际成本加成率进行测算的基础上 分析了产品质量 出口目的地市场 汇率和其它变量对加成率的影响 分析发现产品质量与加成率之间有显著的正向关系 距离对中国企业出口加成率产生负向影响 而人民币实际有效汇率升值对中国制造业出口企业的加成率有显著抑制作用 特别是对创业企业和退出企业的影响更大 在此基础上 本文提出中国出口企业需要加强技术创新提高产品质量 在 <sup>“</sup>走出去<sup>”</sup> 的背景下不断拓展产品的国际销售市场 同时 人民币实际有效汇率升值不利于出口企业加成定价 出口企业需要预防汇率波动所带来的风险

## 一<sub>、</sub> 引言

随着中国出口市场的不断繁荣 对中国出口贸易的研究不断深入到微观企业研究发现中国出口产品的技术复杂度不断上升 <sub>（</sub>Rodik and Dani 2006 杨汝岱和姚洋 2008<sub>）</sub> 中国出口产品的质量和价格问题越来越受到关注 施炳展 <sub>（</sub>2013<sub>）</sub> 认为<sup>“</sup>中国制造<sup>”</sup> 往往和低价格 低质量联系起来 打折促销最厉害的商品往往是<sup>“</sup>Made in China<sup>”</sup> 中国出口产品在国际市场甚至成为 <sup>“</sup>低价劣质<sup>”</sup> 代名词 在出口市场 由于中国企业的过度竞争带来了许多负面后果 那么 现阶段中国出口市场一个重要环节是全面提升中国出口产品的质量 在产品质量提高的同时提高中国出口产品在国际市场的定价能力 否则在定价能力缺失下 出口产品价格过低 导致中国出口产品屡受反倾销调查 <sub>（</sub>盛丹和王永进 2012<sub>）</sub> 现在需要思考中国出口产品价格过低其背后的原因究竟是什么<sub>？</sub> 我们认为提高出口产品的质量是一个急需解决的问题 不仅关系到中国出口贸易发展的长久之策 而且制定合理的产品价格更是维持与进口国经贸关系的关键 因此 本文从产品质量和出口目的地市场出发 分析中国出口企业的加成定价问题 这对中国出口企业非常具有现实意义

产品质量与企业定价是国外新新贸易理论的一个重要研究内容 以 Melitz<sub>（</sub>2003<sub>）</sub>为代表的新新贸易理论认为只有生产率高的企业才选择出口 Ku<sub>g</sub>ler M Verhoo<sub>g</sub>en<sub>（</sub>2009<sub>）</sub> 将产品质量加入到异质性企业模型中 发现了高生产率的企业更易生产高质量的产品 但产品的价格与质量并不存在简单的对应关系 由于市场的选择导致价格差异 出口企业会根据产品质量的高低和市场竞争环境调整产品的加成定价 国内文献有关中国出口产品质量的变化对企业加成定价影响的研究相对不足 较多文献研究了中国出口产品质量的影响因素以及中国出口产品质量的变化趋势 <sub>（</sub>施炳展2013<sub>）</sub> 那么中国不同企业生产的同样的产品由于质量的差异对出口的加成有多大的影响呢<sub>？</sub> 中国哪些产品由于高质量而获得了更高的加成呢<sub>？</sub> 加成定价的定义是企业在保证一定利润水平下 通过对基准的边际成本核算加上一定的百分比 实现企业的利润最大化 企业一般通过成本利润率和资金利润率来对产品进行加成定价 价格的制定将直接影响到企业的利润 价格与边际成本的差额越多 企业的利润越多在对产品加成定价的研究上 企业进行加成定价主要考虑边际成本和加成率 加成率过低直接导致产品价格过低 从而导致出口企业受到更多的反倾销调查 同时跨国公司之所以能主导行业发展格局 根本原因在于形成了 <sup>“</sup>高加成率 高利润持续创新<sup>”</sup> 的动态竞争能力 <sub>（</sub>任曙明和张静 2013<sub>）</sub> 加成率的高低从另外一个角度反映出企业的经营状况的好坏与市场的竞争情况 过低的加成率不利于企业的长期发展 因此 从基于边际成本上的加成率来研究企业的加成定价能力很有意义

本文的贡献主要有以下几个方面 一是通过出口目的地市场分析 发现了产品质量是决定中国出口产品定价的关键环节 二是从出口目的地市场来研究企业加成定价 虽然近距离国家是中国出口数量最多的地区 但中国出口企业需要进一步拓展远距离的发达国际市场 三是从企业层面的汇率来看 本文认为汇率的波动对企业加成定价有显著影响 出口企业需要预防汇率波动所带来的风险 本文结构安排如下 第二部分是阐述如何测算出口企业的加成率 第三部分是实证模型 变量设定和数据说明 第四部分是计量结果分析 最后是总结与政策建议

## 二 企业层面加成定价的测算方法

加成定价在经济学上之所以难以估计 主要原因是存在不可观测项边际成本在计量经济学中一般借助工具变量法来消除遗漏变量的影响 从而得到无偏估计量许多学者用会计数据中的利润 收入或者销售额减去企业的劳动和资本支出来计算边际成本 从经济意义上看 由于使用不同会计规则 这仅仅代表着企业的平均成本而无法替换边际成本 利用这些会计数据估计加成定价将会使估计出现问题<sub>（</sub>Loecker<sub>j</sub> Warz<sub>y</sub>nsik 2012<sub>）</sub> Hall et al． <sub>（</sub>1986<sub>）</sub> 所采用的 <sup>“</sup>索罗 <sup>”</sup> 残差估算了不完全竞争条件下不同行业的加成率 但这种方法不能更好的解决生产率冲击带来的不可识别的误差 更无法对异质性企业进行测算 Loecker <sub>j</sub> Warz<sub>y</sub>nsik <sub>（</sub>2012<sub>）</sub> 发展了最新的模型来估算加成率 这种方法放松了规模报酬不变的假设 通过引入超越对数函数的形式来消除不可能观察的冲击带来的内生性问题 可以得到各个估计量的无偏估计

假设企业 i 在 <sub>t</sub> 时期的生产函数为

$$
Q _ {i t} = Q _ {i t} \left(X _ {i t} ^ {1}, X _ {i t} ^ {2}, X _ {i t} ^ {3}, \dots \dots , X _ {i t} ^ {N}, K _ {i t}, \omega_ {i t}\right)\tag{1}
$$

其中 $X _ { i t } ^ { ~ N }$ 为企业 <sub>t</sub> 时期的各种可变要素的投入量 $K _ { i t }$ 代表资本存量 生产函数$Q _ { i t }$ 为连续二阶可微函数 企业追求利润最大化 在产量一定的情况下实现成本最小化 因此上式的拉格朗日函数为

$$
L (X _ {i t} ^ {1}, \dots , X _ {i t} ^ {n}, k _ {i t}, \lambda_ {i t}) = \sum_ {n} ^ {N} X _ {i t} ^ {n} + r _ {i t} k _ {i t} + \lambda_ {i t} [ Q _ {i t} - Q _ {i t} (X _ {i t} ^ {1}, \dots , X _ {i t} ^ {n}, k _ {i t}, \omega_ {i t}) ]\tag{2}
$$

其中 ${ p _ { i t } } ^ { X ^ { n } }$ 代表企业可变要素的价格 $r _ { i t }$ 代表资本价格 通过对可变要素求一阶导数 我们得到

$$
\frac {\partial L _ {i t}}{\partial X _ {i t} ^ {n}} = p _ {i t} ^ {X ^ {n}} - \lambda_ {i t} \frac {\partial Q _ {i t} (\cdot)}{\partial X _ {i t}} = 0\tag{3}
$$

其中 <sub>，</sub> $\lambda _ { i t } = \frac { \partial L _ { i t } } { \partial Q _ { i t } }$ 为单位产出水平下的边际成本 对上式两端同时乘以 $\frac { X _ { i t } } { Q _ { i t } }$ 可以得到<sub>：</sub>

$$
\frac {\partial Q _ {i t} (\cdot)}{\partial X _ {i t}} \frac {X _ {i t}}{Q _ {i t}} = \frac {1}{\lambda_ {i t}} \frac {p _ {i t} ^ {X ^ {n}} X _ {i t} ^ {n}}{Q _ {i t}}\tag{4}
$$

从成本最小化可以得出 企业在最优的条件的投入产出弹性为 $\frac { \partial Q _ { i t } ( \cdot ) } { \partial X _ { i t } } \frac { X _ { i t } } { Q _ { i t } }$ <sub>，</sub> 等于企业在成本中所占的份额 $\frac { 1 } { \lambda _ { i t } } \frac { p _ { i t } ^ { \ X ^ { n } } X _ { i t } ^ { \ n } } { Q _ { i t } }$ 设价格的加成率设定为 $\mu _ { i t }$ 则 $\mu _ { i t } = \frac { P _ { i t } } { \lambda _ { i t } }$ 代入到 <sub>（</sub>4<sub>）</sub> 式可以得到<sub>：</sub>

$$
\theta_ {i t} ^ {X} = \mu_ {i t} \frac {P _ {i t} ^ {X}}{P _ {i t}} \frac {X _ {i t}}{Q _ {i t}}\tag{5}
$$

其中 $\theta _ { i t } ^ { X }$ 为可变要素 X 的产出弹性 由于可变投入支出和总销售额的份额可以在工业企业数据库中查询获得 从而测算企业的加成定价转换成估算企业可变要素的产出弹性 由 <sub>（</sub>5<sub>）</sub> 式可以得到 $\mu _ { i t } = \frac { \theta _ { i t } ^ { X } } { \alpha _ { i t } ^ { X } }$ （ 6 ）

其中 $\alpha _ { i t } ^ { \ X }$ 表示 $X _ { i t }$ 的成本与总收益 $( P _ { \dot { u } } \ : Q _ { \dot { u } } )$ 之比 因此要估算一家企业的加成率 只需要计算出产出弹性和 $\alpha _ { i t } ^ { \ X }$ 值即可 那么接着就是要估算 $\theta _ { i t } ^ { X }$ 首先假设生产函数为希克斯中性 技术参数相同 这 <sub>（</sub>2<sub>）</sub> 个限制条件下生产函数变为

$$
Q _ {i t} = F (X _ {i t} ^ {1}, \dots , X _ {i t} ^ {N}, K _ {i t}; \beta) e x p (\omega_ {i t})\tag{7}
$$

公式 <sub>（</sub>7<sub>）</sub> 意味着生产函数中有一个相同的技术参数为 $\beta$ 并且企业的生产率用$\omega _ { i t }$ 来表示 由于生产函数不仅受到生产率的冲击 同时生产率也与生产要素有相关性 因此对于这些不可观察的因素必须控制 才能获得一致性的估计结果 现在主要的方法为 OP LP 和 ACF 来进行估计 OP 用投资来作为生产率的代理变量 但是投资变动调整的难度大 同时投资也包含零值和负值 用 OP 来估算有一定困难LP 主要采用中间投入作为生产率的代理变量 相对 OP 来说 LP 用中间投入能较好的衡量生产率的变动 而用劳动投入作为中间投入的函数 由于劳动是先于中间投入做出决策 这样可以更好的作为生产率的代理变量 根据 ACF 方法 我们假定超越对数生产函数为

$$
y _ {i t} = \beta_ {l} l _ {i t} + \beta_ {k} k _ {i t} + \beta_ {l l} l _ {i t} ^ {2} + \beta_ {k k} k _ {i t} ^ {2} + \beta_ {l k} l _ {i t} k _ {i t} + \omega_ {i t} + \varepsilon_ {i t}\tag{8}
$$

$$
\mathrm{假定}: y _ {i t} = \varphi_ {t} (l _ {i t}, k _ {i t}, m _ {i t}, z _ {i t}) + \varepsilon_ {i t}\tag{9}
$$

$$
\varphi_ {i t} = \beta_ {l} l _ {i t} + \beta_ {k} k _ {i t} + \beta_ {l l} l _ {i t} ^ {2} + \beta_ {k k} k _ {i t} ^ {2} + \beta_ {l k} l _ {i t} k _ {i t} + h _ {t} (m _ {i t}, k _ {i t}, z _ {i t})\tag{10}
$$

借鉴 L<sub>ev</sub>i<sub>nso</sub>h<sub>nj</sub>P<sub>etr</sub>i<sub>n （</sub>2003<sub>）</sub> 的计算方法和 STATA 程序 可以估算出产出弹性和误差项 $\varepsilon _ { i t }$ 从而可以得到估计值 那么我们的计算公式换算成 $\hat { a } _ { i t } X = { P _ { i t } ^ { X } X _ { i t } } / ( { P _ { i t } Q _ { i t } } / { e x p \left( { \hat { \varepsilon } _ { i t } } \right) } )$ 这样就可以计算出每家企业加成率的估算公式为 $\mu _ { i } = \hat { \theta } _ { i t } ^ { X } \pmb { \theta } _ { i t } ^ { l } \alpha _ { i t } ^ { ~ l } / \hat { \alpha } _ { i t } ^ { ~ X } ($ 在计算加成率的时候本文选取劳动投入量来计算 其中 $\theta _ { i t } ^ { X }$ 表示劳动产出弹性 $\hat { \theta } _ { i t } ^ { ~ l } , ~ \hat { \alpha } _ { i t } ^ { ~ X }$ 表示劳动成本与总收益的比值 $\alpha _ { i t } ^ { \phantom { \dagger } l }$ 这样我们通过上面的计算过程求出劳动产出弹性和要素的支出份额可以获得最终结果 企业层面的数据均来自 2000<sub>～</sub>2006 年我国工业企业数据库 其主要变量为 工业增加值 劳动投入 固定资产年均余额以及中间投入 通过计算获得 $\alpha _ { i t } ^ { \textit { l } }$ 最后求得 2000<sub>～</sub>2006 年企业层面的加成率

## 三 实证模型 变量设定和数据说明

从中国出口企业的加成定价能力来看 在中国出口企业加成率存在普遍缺失的基础上 <sub>（</sub>盛丹和王永进 2012 任曙明和张静 2013<sub>）</sub> 本文将从产品质量 地理和汇率等其他变量来揭示这些因素对企业加成率的影响 本文的基准计量模型参照B<sub>a</sub>ld<sub>w</sub>i<sub>n</sub> R H<sub>arr</sub>i<sub>gan j （</sub>2011<sub>）</sub> 的计量模型 从产品质量的角度出发 随着中国出口的产品多样化 出口到一个目的地有多种产品 这些产品种类的质量也有差异 本文将选择多种产品中出口额最大的产品种类作为企业的质量代表 本文的计量模型设定如下

$$
\ln \text {   markup } _ {i d t} = \alpha_ {0} + \alpha_ {1} \ln q l t y _ {i d t} + \alpha_ {2} \ln \text { dist } _ {i d t} + \alpha_ {3} \ln g d p _ {i d t} + \beta X _ {d t} + \gamma_ {i} + \gamma_ {t} + \varepsilon_ {i d t}\tag{11}
$$

其中 i d <sub>t</sub> 分别表示企业 进口国和时间 $\ln m a r k u p _ { i d t }$ 表示企业的加成率$\ln q l t y _ { i d t }$ 表示产品质量 在多产品出口中选择出口额最大的产品来衡量企业的生产质量 l<sub>n</sub> $\mathop { d i s t } _ { i d t }$ 表示国家之间的距离变量 $\ln { { g d p } _ { i d t } }$ 表示市场规模的大小 $X _ { d t }$ 表示控制变量 $\gamma _ { i }$ 表示行业固定效应 反映随着行业变化而产生影响到因素 $\gamma _ { t }$ 表示时间固定效应 反映只随时间变化的因素 $\varepsilon _ { i d t }$ 表示未被观测的随机误差项

其中控制变量 $X _ { i d t }$ 包括<sub>：</sub>

$$
\begin{array}{r l} X _ {d t} & = \beta_ {1} \ln r e e r _ {d t} + \beta_ {2} t d i f f _ {d t} + \beta_ {3} c o n t i g _ {d t} + \beta_ {4} \ln p o p _ {d t} + \beta_ {5} a r e a _ {d t} + \beta_ {6} c o m l a n g _ {d t} + \\ & \quad \beta_ {7} c o l o n y _ {d t} + \beta_ {8} c o m l e g _ {d t} + \beta_ {9} g a t t o _ {d t} + \beta_ {1 0} g a t t d _ {d t} \end{array}\tag{12}
$$

控制变量分别为 <sub>：</sub> 企业实际有效汇率 <sub>（reer） 、</sub> 出口在港口的通关时间 <sub>（t</sub>diff<sub>） 、</sub>是否接壤 <sub>（cont</sub>i<sub>g ） 、</sub> 进口国的人口数量 <sub>（ pop ） 、</sub> 进口国的面积 <sub>（ area ） 、</sub> 是否有共同语言 <sub>（</sub> comlan<sub>g ） 、</sub> 是否曾为殖民地 <sub>（</sub> colon<sub>y ） 、</sub> 是否有共同的法律来源 <sub>（</sub> comle<sub>g ） 、</sub> 出口国是否加入 WTO <sub>（g</sub>atto <sub>） 、</sub> 进口国是否加入 WTO <sub>（g</sub>attd <sub>） 。</sub>

核心解释变量产品质量的测算 产品质量有很多替代指标 比较合适的主要有三种方法来衡量 一种是将出口产品价格作为产品质量的度量 认为产品质量越高带给消费者的满足程度也就越大 从而产品的价格越高 <sub>（</sub>Schott PK 2004<sub>）</sub> 第二种为将出口技术复杂度作为产品质量的替代 采用各国或地区的出口产品的显示比较优势指数作为权重 如果该地区的产品技术复杂度指数越高则产品质量越好<sub>（</sub>Hausman et al． 2007<sub>）</sub> 这种方法无法衡量异质性企业的产品质量差异 第三种方法为对出口产品进行回归的方法 采用时间和国家为虚拟变量 利用产品的数量对产品价格的回归 残差作为产品质量的衡量 由于这种方法综合考虑了产品的价格和产品的数量 同时也考察了微观企业产品的质量 因此很好的体现了企业产品在质量上的差别 <sub>（</sub>施炳展 2013<sub>）</sub> 本文则采用第三种方法来衡量产品质量 首先 借鉴 Hallak and Sivadasan <sub>（</sub> 2009 <sub>）</sub> 和施炳展 <sub>（</sub> 2013 <sub>）</sub> 的理论模型 出口产品按照 HS8位数来确定产品的种类 产品质量是按不同出口目的地和不同价格来衡量的 首先假设消费者效用函数为

$$
u _ {s} = \left[ \sum_ {c} \sum_ {z} \left(\varepsilon_ {z} \lambda_ {s} ^ {c} x _ {z} ^ {c}\right) ^ {\frac {\sigma s - 1}{\sigma s}} n _ {z} ^ {c} \right] ^ {\frac {\sigma s - 1}{\sigma s}}, \sigma_ {s} > 1\tag{13}
$$

其中 ${ n _ { z } } ^ { c }$ 表示国家 $c$ 生产的产品 <sub>z</sub> 的数量 ${ x _ { z } } ^ { c }$ 表示消费的每个产品种类的数量 $\mathbf { { \sigma } } _ { \mathbf { { 0 } } _ { \mathrm { { s } } } }$ 表示消费不同产品种类之间的替代弹性 表示不同的产品种类之间的选择 $\varepsilon _ { \mathrm { z } }$ 它代表产品的价格和消费者对某类产品的估值 $\lambda _ { s } ^ { ~ c }$ 表示不同的国家和生产部门 它代表产品的质量并且包含产品所拥有的差异性

我们定义 $\overline { { n } } _ { s } ^ { \ c }$ 为国家 $c$ 在部门 <sub>s</sub> 生产的某个产品种类的平均数量

$$
\bar {n} _ {s} ^ {c} = \frac {1}{Z _ {s}} \sum_ {z} n _ {z} ^ {c}\tag{14}
$$

并且定义 $n _ { z }$ 为全球所有的国家生产的产品种类 <sub>z</sub> 的平均数量

$$
\bar {n} _ {z} = \frac {1}{C} \sum_ {c} n _ {z} ^ {c} \frac {\bar {n} _ {s} ^ {o}}{\bar {n} _ {s} ^ {c}}\tag{15}
$$

上式代表着全球所有的国家的一个均值 如果这个均值为 $o$ 单位 那么每个国家的生产量与世界的均值为 单位和 单位之差 因此 我们定义 $\widetilde { n } _ { z } ^ { c }$ 为国家 $c$ 生产的相对于全球所有的国家来说超过均值的产品种类 <sub>z</sub>

$$
\widetilde {n} _ {z} ^ {c} = n _ {z} ^ {c} \frac {\overline {{n _ {s} ^ {o}}}}{\overline {{n _ {s} ^ {c}}}} - n _ {z}\tag{16}
$$

对于所有的产品种类 $c$ 来说 我们定义如果超过的均值产品的产品种类的数量为 0 即 <sub>：</sub>

$$
\sum_ {z} \tilde {n} _ {z} ^ {c} = 0
$$

（ 17 ）

那么我们定义国家 $c$ 的部门 <sub>s</sub> 生产的产品种类 <sub>z</sub> 的产品价格为

$$
P _ {s} ^ {c} = \left[ \sum_ {z} n _ {z} \varepsilon_ {z} ^ {\sigma_ {s} - 1} (p _ {z} ^ {c}) ^ {1 - \sigma_ {s}} \right] ^ {\frac {1}{1 - \sigma_ {s}}}\tag{18}
$$

假设对于一个产品种类 <sub>j</sub> 由生产国 $\mathrm { c }$ 出口到不同目的地的所有市场需求量为

$$
q _ {j} = p _ {j} ^ {- \sigma_ {s}} \theta_ {j} ^ {\sigma_ {s} - 1} \frac {M}{P}\tag{19}
$$

其中 M 表示消费者的总支出 借鉴 G<sub>erva</sub>i<sub>s</sub> A <sub>（</sub>2011<sub>）</sub> 的做法 我们在该式的基础上构建产品质量的测试 在产品市场中 消费量同时取决于产品质量和产品的价格 那么 在年份<sub>－</sub>企业<sub>－</sub>出口国<sub>－</sub>产品的四个维度下 我们构建了对于每一个 HS8位的产品种类的产品质量的测度公式

$$
\ln q _ {i m t} = \chi_ {m t} - \sigma p _ {i m t} + \varepsilon_ {i m t}\tag{20}
$$

其中 $\chi _ { m t } - \sigma p _ { i m t }$ 为出口国<sub>－</sub>时间虚拟变量 它随着时间和出口国不同而变化 可以控制随着出口国变化的变量 比如地理距离 表示企业 i 在 <sub>t</sub> 年对 $p _ { i m t }$ $m$ 国出口产品 HS8 的价格 $\varepsilon _ { i m t } = ( \sigma - 1 ) \ln \theta _ { i m t }$ 可以测度企业 i 在 <sub>t</sub> 年对 国出口产品 HS 的产品质量 作为残差项处理 因此 在产品层面上 我们获得产品质量为式

$$
q l t y _ {i m t} = \ln \hat {\theta} _ {i m t} = \frac {\ln q _ {i m t} - \ln \hat {q} _ {i m t}}{\sigma - 1}\tag{21}
$$

从而可以测度每个企业 i 每年 <sub>t</sub> 在每个出口市场 $m$ 中的某个 HS 产品的质量 利用中国海关进出口数据库来进行处理的过程中 利用这种回归的方法获得出口产品的质量 我们获得 2000<sub>～</sub>2006 年 210692 家企业 <sub>（</sub>7 年累加<sub>）</sub> 对 193 个国家和地区出口3298 种产品的数据 但在本文的使用过程中 由于中国大部分出口企业已经由单产品出口转变成多产品出口 <sub>（</sub>钱学锋等 2013<sub>）</sub> 因此本文选取企业出口的多产品种类中质量最好的产品种类作为企业产品质量的代表 在以往的文献研究中 产品质量越高产品的价格越高 产品越能够出口到更富裕的国家 <sub>（</sub>H<sub>umme</sub>l<sub>s</sub> D ＆ Kl<sub>enow</sub> 2005<sub>）</sub>

企业实际有效汇率 <sub>（reer）</sub> 本文利用 《世界银行数据库》 中 采用间接法来表示汇率 以各国货币表示成美元为准 借鉴 B<sub>a s et a</sub>l<sub>． （</sub>2009<sub>）</sub> 的经验 利用企业出口额的比重来作加权 衡量企业在进口国受到的汇率冲击 首先 将国家 k 在 <sub>t</sub>期的实际有效汇率表示为 $r e r _ { k t } { = } E _ { k \mathcal { L } N Y _ { t } } * ( P _ { c t } / P _ { k t } )$ 其中 $E _ { k , C N Y _ { t } }$ 表示名义汇率 $P _ { c t }$ 表示 <sub>t</sub>期的中国的居民消费价格指数 <sub>（</sub>1999<sub>＝</sub>100<sub>）</sub> $P _ { k t }$ 表示国家 $k$ 在 <sub>t</sub> 期的居民消费价格指数 <sub>（</sub>1999<sub>＝</sub>100<sub>）</sub> 然后以 1999 年为基期计算出每个国家的实际有效汇率 最后企业i 在 <sub>t</sub> 期的实际有效汇率表示为

$$
\operatorname{reer} _ {k t} = \sum_ {k = 1} ^ {n} \left(X _ {i k} / \sum_ {k = 1} ^ {n} X _ {i k}\right) * \operatorname{rer} _ {k t}\tag{22}
$$

其中 $( \mathrm { X _ { i k } } / \sum _ { k = 1 } ^ { n } \mathrm { X _ { i k } } )$ 表示企业 i 在 <sub>t</sub> 期与国家 k 的贸易额占其当期总贸易额的比值 已有的文献表明汇率的波动会影响到出口产品的价格 在新开放宏观经济学框架下汇率通过传递效应会引起出口产品价格的波动 <sub>（</sub>Ob<sub>st</sub>f<sub>e</sub>ld <sub>et a</sub>l<sub>．</sub> 1995<sub>）</sub> 出口企业在公司进行定价决策的时候采取针对性的措施 会回避汇率变动引致的产品价格波动 也有企业在出口贸易中对汇率的波动反应非常敏感 那么 在企业的加成率由于受到汇率波动的直接影响 如果人民币汇率上升将会使得企业出口产品在国外市场变得更加便宜 预计将导致企业的加成率降低

本文的数据来源为 2000<sub>～</sub>2006 年中国工业企业大样本数据库 <sub>（</sub>CIFD<sub>）</sub> 中国海关进出口大样本数据库 <sub>（</sub>CCTS<sub>）</sub> 和 CEPII 地理数据库 在对中国工业企业数据库处理的时候 该主要借鉴参照聂辉华等 <sub>（</sub>2012<sub>）</sub> 的经验 接着我们对中国工业企业数据库和中国海关进出口大样本数据库进行匹配 这两套数据库虽然都有企业编码但编码系统完全不一样 参照戴觅和余淼杰 <sub>（</sub>2014<sub>）</sub> 的方法 第一步 通过年份和企业名称来匹配 年份这一变量对于匹配很重要 因为一些企业可能在不同年份进入或者退出 并且新进入的企业有可能采用他们原来的名称 第二步 对企业的邮政编码和电话号码的后七位进行匹配 这样我们最后获得 2000<sub>～</sub>2006 年七年总共98965 家企业 最后我们根据企业出口产品的目的国家 将国家变量 CEPII 数据库进行合并 这样就完成了本文数据的匹配

## <sub>（</sub>二<sub>）</sub> 分样本和稳健性检验

由于不同国家经济发展情况不一样 距离 市场规模 汇率水平 通关时间和环境因素等也都有差异 为了检验出口企业对目的国的选择 本文将目的国按照经济发展水平和距离远近进行分类检验 本文采用国际通用的标准 将 188 个出口目的国分成两类 其中发达国家 44 个 发展中国家 144 个 在表 2 中 <sub>（</sub>1<sub>）</sub> 表示发展中国家的回归结果 <sub>（</sub>2<sub>）</sub> 表示发达国家的回归结果 <sub>（</sub>3<sub>）</sub> 表示距离小于 7000 千米的样本 <sub>（</sub> 4 <sub>）</sub> 表示距离介于 7000 到 1 0000 千米 <sub>（</sub> 5 <sub>）</sub> 表示距离大于 1 0000 千米

在发展中国家与发达国家之间 产品质量的回归系数为 0 023 0 037 距离的回归系数为－0 025 －0 034 系数绝对值依次递增 系数方向和显著性不变 这说明两点 首先 企业出口到发达国家的产品质量影响程度要高于发展中国家 从发达国家的消费者来看 其对产品质量的要求要高于发展中国家 发达国家消费者对产品的选择质量更高 这就促使了出口企业向这些地区出口更高质量的产品 其次由于企业的利益驱动 出口到发达国家的产品获得了更高的加成率 提高了企业的利润和产品销售的回报 这样企业更有动力将质量高的产品出口到发达国家

当距离为小于 7000 千米 7000<sub>～</sub>10000 千米 大于 10000 千米样本时 随着距离的增加 产品质量的回归系数分别为 0 025 0 031 0 037 距离的回归系数为－0 018 －0 041 －0 029 系数方向和显著性不变 质量对企业的加成定价影响程度在增加 且均在 1％显著性水平下显著为正 这和连续的样本变量结果基本保持一致 同时 其他变量的变化也几乎一致 这也证明了结果的稳健性 地理距离的系数都显著为负 说明随着地理距离的增加出口企业的加成率会降低 贸易成本的上升降低了企业的加成率 这也说明在出口市场上虽然距离降低了企业的加成率但企业必须依靠质量的提升来获得市场 对于中国出口企业来说 不断提高产品质量是其拓宽国家市场的必由之路

## <sub>（</sub>三<sub>）</sub> 进入退出企业来分以及内生性检验

回归结果分析如下 第一 从产品质量来看 持续经营的企业产品质量对加成的影响程度要高于其他企业 出口企业要在市场中获得生存机会 必须提高产品质量 只有高质量的产品才能维持企业的长远发展 第二 从地理距离来看持续经营的企业的负向影响较小 其原因可能是持续经营的企业由于出口规模的发展 距离所带来的运输成本平均下来获得了降低 第三 从汇率的角度来看汇率的波动对退出企业的影响最大 对于退出企业来说 如果企业的加成率过低的话 汇率的波动幅度超过企业所能承受的范围则无法在出口市场生存 因此企业从产品质量出发提高企业的加成率非常必要 第四 其他的变量保持了结果的稳定性

为防止解释变量和被解释变量之间的双向因果关系 我们采用工具变量来处理可能产生的内生性问题 用产品质量的滞后一期作为工具变量来对回归进行内生性检验 也就是说企业加成率可以影响到当期或者未来的产品质量 但是却不能影响到前一期的产品质量 从第 <sub>（</sub>5<sub>）</sub> 列报告的 IV 估计的结果 从符号和显著性来看结果是非常稳健的 消除了产品质量与加成定价之间的双向因果关系 产品质量对加成率之间有正向的显著影响

## 五 总结与政策建议

本文结合中国工业企业数据库 海关数据库和 CEPII 地理数据库 研究了产品质量 出口目的地市场与企业加成定价之间的关系 主要结论为 一是出口产品质量与加成率之间有显著的正向关系 质量越高企业获得的加成率越高 对不同出口目的国来看 在发达国家市场质量对加成率的影响程度较大 从企业的出口时间来看 连续经营的企业相比于进入或退出的企业质量对加成率的影响程度较大 二是距离对中国出口企业加成定价能力有着差异性影响 距离对中国企业出口加成率产生负向影响 企业需要通过质量的提高获得更高加成率 只有这样才能克服距离带来的出口成本的增加 三是市场规模与企业的加成定价有正向关系质量更高的产品能从规模大的市场获得更多的加成 四是汇率对于中国出口企业来说非常重要 特别是利润率非常低的企业来说 人民币实际有效汇率升值对中国制造业出口企业的加成率有显著抑制作用 特别是对创业企业和退出企业的影响更大 通过对不同样本的选择本文的结论依然稳健 同时本文也解决了变量之间的内生性问题

本文提出以下几点政策建议 首先 我们出口企业在整体加成定价能力缺失的情况下 产品质量是一个关键的环节 质量与企业加成率有显著正向关系 中国出口产品的质量不高导致加成低下 企业必须从产品质量出发 提高产品的技术含量加强企业的创新能力 面对激烈的市场竞争 只有不断提高产品质量才能获得更多的加成定价能力 其次 从出口目的地市场的分析来看 在市场选择方面中国企业应该不断拓展国际销售市场 对于远距离的发达市场 虽然距离带来成本的增加但通过高质量的产品能够克服这些困难 在中国企业大规模 <sup>“</sup>走出去<sup>”</sup> 的背景下根据不同国家的地理 市场规模 汇率制度和环境因素等差异性 企业应该根据不同的目的地制定不同的出口销售目标 只有因地制宜 采取不同的措施 才能在不同的目的地获得更好的收益 最后 企业应该加强防范汇率波动给企业带来的冲击特别是对于创业企业来说 在加成率比较低的情况下 汇率的冲击可能让企业无法在出口市场生存 企业需要在选择出口行为前 防范汇率波动对企业的影响 维持企业在出口市场的稳定 因此综合来看 只有不断提高中国出口产品的质量 提升出口企业的国际竞争力 提高中国出口企业的产品加成定价能力 才能保持中国出口市场的长期稳定的繁荣
