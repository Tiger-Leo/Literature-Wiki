# 外商直接投资、全要素生产率与出口产品质量升级———基于中国企业层面微观数据的研究

曹 毅 陈 虹

内容提要 本文借鉴了新新贸易理论的研究成果，通过对中国企业出口产品质量在微观数据层面的梳理测算，获得出口产品质量标准化的量化结果。 再通过中国海关数据库和中国工业企业数据库的进一步匹配，对中国企业全要素生产率进行测算，并对数据库中企业接受外商直接投资情况进行梳理，构建起 <sup>2000</sup>—<sup>2007</sup> 年跨年度的企业面板数据，以期分析外商直接投资和全要素生产率等因素对企业出口产品质量的影响。 结论发现，中国企业出口产品质量呈不断提升的趋势，而外商直接投资和全要素生产率对企业出口产品质量具有显著的促进作用，同时，政府补贴和无形资产对出口产品质量提升也具有明显的效果，但在企业规模和区域分布上具有一定差异，而来自国外的直接投资比来自港澳台的投资对出口产品质量更具明显的推动作用。 从政策层面上，推动企业通过增效提质，加大开放引进高质量国际投资，通过政府符合市场竞争前提下的补贴，将对提升企业出口产品质量具有积极作用。

## 一<sub>、</sub>引言及文献综述

随着新新贸易理论的发展，近年来，对企业出口产品质量的研究逐渐增多。 新新贸易理论强调，国际贸易带来了社会资源在一个行业内部不同企业之间重新分配，使得社会资源从行业中的低效率企业转向高效率企业，并开创性地将产品质量纳入了异质性企业模型。 直观地看，随着国际分工的不断深化，出口产品质量的高低，将直接体现出一个企业乃至一个国家在产业链价值链上的分工地位。 经过几十年的高速发展，中国已经成为世界最大的贸易国，特别是从<sup>2001</sup> 年加入 <sup>WTO</sup> 开始，中国的贸易规模快速增长，出口额从<sup>2001</sup> 年的<sup>2660</sup> 亿美元增加到<sup>2020</sup> 年的 <sup>2．59</sup> 万亿美元，在近 <sup>20</sup> 年的时间内增长了近 <sup>10</sup> 倍。 然而，在中国出口产品的附加值上，学术界和社会上一直以来都存在争议，关于制造业大而不强，产品质量不高 附加值低的忧虑较为普遍。 特别是随着近年来国际贸易保护主义抬头、国内劳动力成本上升和资源环境约束加大的背景下，提升产品质量、提高附加值水平迫在眉睫 <sup>《</sup>中华人民共和国国民经济和社会发展第十四个五年规划和<sup>2035</sup> 年远景目标纲要<sup>》</sup>中也提出要推动制造业产品 <sup>“</sup>增品种、提品质、创品牌<sup>”</sup>，要优化出口商品质量和结构，稳步提高出口附加值。 因此，如何推动中国制造业企业转型升级，提升出口产品质量，增强出口竞争力，以及政府在其中所能发挥的作用和扮演的角色，是一个值得深入研究的问题。

## 二<sub>、</sub>文献综述和理论机制分析

根据新新贸易理论的异质性企业贸易模型，随着国际贸易所带来的竞争加剧，会损害那些生产率低下 表现不佳的企业，它们将被迫退出市场，而生产率高、表现好的企业，会迅速扩张并出口，也即通过国际贸易来推动资源在异质性的不同企业之间重新分配 在异质性企业贸易模型中，生产率是决定企业出口与否的决定<sub>性因素 。 然而，</sub>Baldwin <sub>和</sub> Harrigan<sub>(</sub> 2011<sub>) 在对美</sub>国出口产品做实证研究时发现，高生产率的企业生产高质量、高价格的产品，并不会因为出口距离的增加而降低其价格，这与 <sup>Melitz</sup>( <sup>2003</sup>) 假设的高生产率降低生产成本进而降低产品价格 提升其出口竞争力产生了矛盾。 而造成这一差异的原因，就在于不同企业之间还存在着出口产品质量的差异，正是由于产品质量的差异化决定了其价格的高低。

## ( 一) 关于生产率与出口产品质量的关系

<sup>Melitz</sup>( <sup>2003</sup>) 将企业的生产率看成是一个固定的外生参数，而近年来的研究表明，实际上，企业的生产率应当是内生的、可变的。 一般而言，企业的生产率主要通过三个方面来提升，包括进口高质量的中间品投入、采用新技术、通过多元化生产来实现内部产品转换。 如 <sup>Con-</sup>stantini <sub>和</sub> Melitz<sub>(</sub> 2007<sub>) 认为，企业预期到即将到</sub>来的贸易自由化之后，会在进入出口市场之前，提前采用新技术，以适应即将面临的市场竞争。Bernard <sub>和</sub> Jensen<sub>(</sub> 1999<sub>) 指出，高的生产率是企</sub>业出口的原因，而不是结果。 但是对于中国企业生产率提升问题，学术界一直没有定论，譬如<sup>Young</sup>( <sup>2003</sup>) 就对中国企业的生产率提升持消极的态度，认为中国经济的增长主要来源于企业外部投入的增加而产生的 <sup>“</sup>粗放式<sup>”</sup>增长，并非是企业内部生产率提升的 <sup>“</sup>集约式<sup>”</sup>增长。

关于企业生产率对出口产品质量的影响，大量的研究集中在分析企业生产率和出口产品质量这两个因素共同作用下对产品价格的影响，将生产率和产品质量作为同一个维度，而将产品质量作为解释变量纳入异质性企业模型，用来解释 <sup>Meltiz</sup>( <sup>2003</sup>) 模型所不能解释的出口价格与企业生产率成正比的实证发现，而直接对企业生产率和出口产品质量之间的关系进行的研究相对较少。 如 <sup>Gervais</sup>( <sup>2015</sup>) 研究认为，企业生产率通过两个渠道影响出口产品价格，一方面，高生产率的企业边际成本更低，因此可以设定更加低的价格; 另一方面，高生产率企业生产高质量的产品，因而设定的价格更高。 而企业生产率对产品价格的最终影响是由以上两个方面的共同作用决定的。 同时，<sup>Hallak</sup> 和<sup>Sivadasan</sup>( <sup>2009</sup>) 假设企业在生产率与生产质量的能力方面均存在异质性，并认为现实中存在小企业出口、大企业反而不出口的企业规模与出口地位的非单调关系现象。

## ( 二) <sup>FDI</sup> 与出口产品质量的关系

研究表明，企业的产品质量和外部技术溢出密不可分，而技术溢出的直接途径是通过外商直接投资( <sup>FDI</sup>) 如李坤望和王有鑫( <sup>2013</sup>)利用中国 <sup>1999</sup>—<sup>2007</sup> 年的数据实证发现，来自国外的外商投资对产品质量的提升要显著强于港澳台投资，且 <sup>FDI</sup> 在资本密集型行业和高外资行业中对产品质量升级有促进作用。 <sup>FDI</sup> 的技术溢出实质上来自于其技术联系或者技术外部性，在 <sup>FDI</sup> 技术溢出效应的途径与机制研究<sub>方面，</sub>Blomstrom <sub>和</sub> Kokko<sub>(</sub> 1998<sub>) 将技术溢出途</sub>径总结为竞争效应和模仿效应，在此基础上，张建华和欧阳轶雯( <sup>2003</sup>) 进一步将技术溢出途径归结为竞争效应 示范效应 人员培训效应和关<sub>联</sub> <sub>效</sub> <sub>应 。</sub> <sub>此</sub> <sub>外，</sub>Hayakawa <sub>、</sub> Mukunoki <sub>和</sub> Yang( <sup>2020</sup>) 针对服务业 <sup>FDI</sup> 进行了研究，结果发现放松对服务业外商直接投资的管制能够为外资提供更多的优质服务，这种高质量服务会促使制造业出口企业提高其出口产品质量。 与此同时，<sup>FDI</sup> 的技术溢出可以分为水平( 产业内) 溢出和垂直( 产业间) 溢出，徐美娜和彭羽( <sup>2016</sup>)发现外资对中国本土企业出口产品质量的正向贡献主要表现为垂直溢出效应，特别是通过后向溢出效应来实现，即下游外资参与程度提高对上游本土企业出口产品质量提升存在显著的促进作用，而前向溢出效应仅部分存在，且同行业外资参与程度对本土企业出口产品质量没有显著的影响，即水平溢出效应并不存在。

## ( 三) 关于出口产品质量的测度

对于出口产品质量测度的研究，实践中主要包括单价法、产品特征法、需求信息推断法和供需信息加总法。 以往的一些微观研究中，大多简单使用产品单价来近似度量产品质量，但单价法有可能存在严重的误导，因为除了产品质量还有很多其他因素会影响到产品的价格目前学术界较为广泛应用的是需求信息推断法，认为消费者在决定每种商品的购买量时，实际上是在比较每种产品的性价比，如果两个企业设定的产品价格相同，但最终获得的市场份额不同，那么必定是由于其产品质量存在差异，即市场份额越高的产品，其质量应该更高 参<sub>照</sub> Hallak <sub>和</sub> Sivadasan<sub>(</sub> 2009<sub>) 的研究方法，可以</sub>构建常替代弹性模型，假设消费者效用函数如下:

$$
U = \left[ \sum_ {i} \left(\lambda_ {i} q _ {i}\right) ^ {\frac {\sigma - 1}{\sigma}} \right] ^ {\frac {\sigma}{\sigma - 1}}\tag{1}
$$

其中，<sup>i</sup> 表示消费者消费的产品种类， $\lambda _ { \mathrm { i } }$ 和$\mathbf { q } _ { \mathrm { i } }$ 分别代表产品种类的质量和数量， $\mathbf { \sigma } _ { \mathbf { { \sigma } } \mathbf { { \sigma } } } \mathbf { { \sigma } } _ { \mathbf { { \sigma } } \mathbf { { \sigma } } } \mathbf { { \sigma } } _ { \mathbf { { \sigma } } } \mathbf { { \sigma } } _ { \mathbf { { \sigma } } } \mathbf { { \sigma } } _ { \mathbf { { \sigma } } } \mathbf { { \sigma } } _ { \mathbf { { \sigma } } } \mathbf { { \sigma } } _ { \mathbf { { \sigma } } }$ 表示产品种类间的替代弹性。

同时，对应的价格指数为:

$$
P = \sum_ {i} p _ {i} ^ {1 - \sigma} \lambda_ {i} ^ {\sigma - 1}\tag{2}
$$

产品种类 <sup>i</sup> 对应的消费数量为:

$$
q _ {i} = p _ {i} ^ {- \sigma} \lambda_ {i} ^ {\sigma - 1} \frac {E}{P}\tag{3}
$$

将企业的生产成本分为边际成本和固定成本，分别用 <sup>mc</sup> 和 <sup>F</sup> 来表示，其中:

$$
m c (\lambda , \varphi) = \frac {c}{\varphi} \lambda^ {\beta}, \quad F (\lambda , \xi) = F _ {0} + \frac {f}{\xi} \lambda^ {\alpha}\tag{4}
$$

研究认为，企业通过对产品价格和质量的选择来最大化其进入市场后的利润，实现运营利润与固定成本的差额最大化。 通过对 <sup>CES</sup> 需求函数求一阶导后得到的 $\mathrm { p _ { d } } = \frac { \sigma } { \sigma ^ { - 1 } } \frac { \sigma } { \phi } \lambda _ { \mathrm { d } } ^ { \beta }$ ，再通过一阶导计算出相应的质量函数:

$$
\lambda_ {d} (\varphi , \xi) = \left[ \frac {1 - \beta}{\alpha} \left(\frac {\sigma - 1}{\sigma}\right) ^ {\sigma} \left(\frac {\varphi}{c}\right) ^ {\sigma - 1} \frac {\xi F}{f P} \right] ^ {\frac {1}{\alpha}}\tag{5}
$$

上式中， $\scriptstyle \mathbf { 3 } \alpha ^ { \prime } = \alpha - ( \ 1 - \beta ) \ ( \ \sigma - 1 )$ <sub>。</sub> 相对于其他<sub>学者的研究，</sub>Hallak <sub>和</sub> Sivadasan<sub>(</sub> 2009<sub>) 的最大</sub>区别是，不再仅限于生产率 <sup>φ</sup> 来决定生产质量，还引入了质量生产能力 <sup>ξ</sup>，将企业的异质性扩展到了两个维度的差异。 从( <sup>4</sup>) 式可以看出，企业的可变成本 <sup>mc</sup> 取决于产品质量 <sup>λ</sup> 和生产率 <sup>φ</sup>，企业的固定成本 <sup>F</sup> 取决于产品质量<sup>λ</sup> 和质量生产能力 <sup>ξ</sup>，企业生产率和质量生产能力越高，越能够降低企业的生产成本，从而影响企业行为。 而从( <sup>5</sup>) 式可以进一步直观地看到，在市场需求既定的情况下，企业的最优产品质量取决于两个方面的水平: 企业生产率<sup>φ</sup> 和质量生产能力 <sup>ξ</sup>。 其中: 企业生产率 <sup>φ</sup> 可以用企业自身的全要素生产率 <sup>TFP</sup> 来近似代替，一般通过企业自身的技术改造等方式实现; 而质量生产能力<sup>ξ</sup> 主要取决于创新和改进，包括企业通过技术、市场营销、管理模式等方面创新带来的提升等，而在开放经济背景下通过吸引外部 <sup>FDI</sup> 所带来的技术溢出是这一创新和改进过程的重要渠道。

综上所述，本文提出如下假设: 对企业而言，内部的生产率提升和外部获得的外商直接投资所带来的技术溢出能够共同推动提升企业出口产品质量。 本文研究框架如图<sup>1</sup> 所示。

通过梳理，在研究出口产品质量方面的文献虽然较为丰富，但对于企业生产率所起的作用，更多关注的是其与出口产品质量共同作用影响产品最终定价，将两者放在同一个维度上研究，而对于 <sup>FDI</sup> 和出口产品质量的关系，更多集中在 <sup>FDI</sup> 的技术溢出效应的研究，对 <sup>FDI</sup> 变化和产品质量提升的直接影响分析较少，还存在一定的拓展空间，本文的主要贡献在于: ( <sup>1</sup>)采用学界广为认可的方法从中国微观企业数据层面计算出口产品质量和企业<sup>TFP</sup>，并从趋势上分析近年来中国出口产品质量的变化情况; ( <sup>2</sup>)从理论上推导 <sup>TFP</sup> 和 <sup>FDI</sup> 对企业出口产品质量的影响机制，从而分析提升企业出口产品质量的方式和途径; ( <sup>3</sup>) 从企业规模大小、所处区域位置、<sup>FDI</sup> 来源等方面进行异质性分析，研究不同企业之间出口产品质量受相关因素影响程度的差异性; ( <sup>4</sup>) 分析政府补贴行为对企业出口产品质量的影响，为政府决策提供参考。

## 三<sub>、</sub>模型<sub>、</sub>数据与描述性分析

## ( 一) 出口产品质量的测算模型

在对出口产品质量的测算过程中，本文参考施炳展( <sup>2013</sup>) 的做法，构建了 <sup>“</sup>年份—企业—进口国—产品<sup>”</sup>四个维度的计量模型，根据前文中的( <sup>3</sup>) 式，将企业 <sup>i</sup> 在 <sup>t</sup> 年对 <sup>m</sup> 国出口数量表示如下:

$$
q _ {i m t} = p _ {i m t} ^ {- \sigma} \lambda_ {i m t} ^ {1 - \sigma} \frac {E _ {m t}}{P _ {m t}}\tag{6}
$$

对( <sup>6</sup>) 式两边取自然对数:

$$
L n q _ {i m t} = \chi_ {m t} - \sigma L n p _ {i m t} + \varepsilon_ {i m t}\tag{7}
$$

其中 $\mathsf { \Omega } _ { \mathsf { 0 } } \mathsf { X } _ { \mathrm { m t } } = \mathsf { E } _ { \mathrm { m t } } - \mathsf { P } _ { \mathrm { m t } }$ ，为 <sup>“</sup>进口国—年份<sup>”</sup>的二维虚拟变量 $\mathbf { \Omega } _ { \mathbf { \theta } } , \mathrm { L n p } _ { \mathrm { i m t } }$ 为企业出口产品的价格， $\alpha _ { \mathrm { i m t } } =$ $\big ( \sigma { - } 1 \big ) \lambda _ { \mathrm { i m t } }$ 是包含了企业出口产品质量信息的残差项。 由于对上式的回归是在产品层面进行的，因此控制住了产品在技术复杂度上的差异性特征，从而进一步定义了产品的出口质量:

$$
\text { quality } _ {i m t} = L n \hat {\lambda} _ {i m t} = \frac {\hat {\varepsilon} _ {i m t}}{(\sigma - 1)} = \frac {L n q _ {i m t} - L n \hat {q} _ {i m t}}{(\sigma - 1)}\tag{8}
$$

通过( <sup>8</sup>) 式可以测度 <sup>i</sup> 企业在对 <sup>m</sup> 国市场 <sup>t</sup>年出口的某个 <sup>HS</sup> 产品共四个维度定义的产品质量，同时，经过( <sup>9</sup>) 式的标准化处理为( <sup>0～1</sup>)的区间，使得不同产品质量之间得以可比。 为了便于计算更高层面的产品质量，可以通过( <sup>10</sup>) 式计算，进一步从企业、地区乃至整个国家层面获得标准化的质量指标:

$$
r - q u a l i t y _ {i m t} = \frac {\text { quality } _ {i m t} - \text { minquality } _ {i m t}}{\text { maxquality } _ {i m t} - \text { minquality } _ {i m t}}\tag{9}
$$

$$
\text { Totalquality } = \frac {v _ {i m t}}{\sum_ {i m t \in \Omega} v _ {i m t}} \times (r - q u a l i t y _ {i m t})\tag{10}
$$

## ( 二) 全要素生产率的计算

针对全要素生产率的计算，学术界的争议和方法都比较多，一般广泛使用的有 <sup>OLS</sup> 法、<sup>FE</sup>固定效应估计法、 <sup>Olley</sup> <sup>－</sup> <sup>Pakes</sup> 半参数估计法<sub>(</sub> OP <sub>法) 和</sub> Levinsohn－Petrin <sub>半参数估计法(</sub> LP法) <sub>。</sub> 与其他方法相比，半参数估计法可以避免样本的选择偏差与共时性偏差，近年来应用得更为广泛。 考虑到 <sup>OP</sup> 法的假定中，需要代理变量( 投资) 与总产值始终保持单调关系，也就意味着投资值必须始终大于零，而事实上并非所有的企业每一年投资都是正值，这将导致计算过程中会有大量数据被丢弃，为了提高数据的利用率，本文使用 <sup>LP</sup> 法，将中间品投入指标作为代理变量。 同时，参考鲁晓东和连玉君( <sup>2012</sup>) 的方法，为客观反映资本和劳动对于企业经营增长的贡献，将样本中的名义变量以<sup>1999</sup> 年为基期计算实际值，其中，对企业的工业增加值使用企业所在地的工业品出厂价格指数( <sup>PPI</sup>) 进行平减，实际资本( 固定资本存量) 则使用企业所在地的固定资产投资价格指数( <sup>IPI</sup>)平减，其中，对于部分地区缺失的指数数据，参考张军、吴桂英和张吉鹏( <sup>2004</sup>) 的估算做法，将西藏缺失的相关指数数据使用居民消费价格指数( <sup>RPI</sup>) 代替，广东 <sup>2000</sup> 年数据采取与其相近的福建省数据代替。 构建了以下半参数法模型:

L n Y _ {i t} = \beta_ {0} + \beta_ {k} L n K _ {i t} + \beta_ {l} L n L _ {i t} + \beta_ {m} L n m a t e r i a l _ {i t} + \varphi_ {i t}
$$

$$

$$

$$

## 五<sub>、</sub>结论和建议

随着 <sup>“</sup>十四五<sup>”</sup>时期的开启，高质量发展将成为中国经济发展的主方向，国家 <sup>“</sup>十四五<sup>”</sup>规划纲要中也明确提出，要 <sup>“</sup>优化出口商品质量和结构，稳步提高出口附加值<sup>”</sup> 本文首先借助理论推导分析了影响企业出口产品质量的两个主要因素: 质量生产能力 <sup>ξ</sup> 和企业生产率 <sup>φ</sup>，并假设质量生产能力主要受 <sup>FDI</sup> 的技术溢出效应影响，企业生产率由 <sup>TFP</sup> 来反映，与此同时，利用中国海关数据库和中国工业企业数据库的微观数据匹配，通过测算中国出口制造业企业的出口产品质量，使用非参数估计法对这些企业的<sup>TFP</sup> 进行了估计，并在此基础上进行了实证分析，发现 <sup>TFP</sup> 和 <sup>FDI</sup> 均对提升企业的出口产品质量具有显著的推动作用，同时，政府补贴 企业无形资产也有利于出口产品质量的提升。 总体来看，<sup>TFP</sup> 对不同企业出口产品质量都具有显著提升作用，但 <sup>FDI</sup> 的技术溢出效应在不同企业之间存在一定差别。 分企业看，<sup>FDI</sup> 的技术溢出效应对规模越小的企业作用越显著; 分区域看，内陆地区 <sup>FDI</sup> 的技术溢出效应更为显著;此外，从投资来源看，来自国外的投资比来自港澳台的投资技术溢出效应作用更显著。 相应地，为推动中国出口产品优化升级，本文提出政策建议如下:

首先，从企业内部出发，应着力提升生产率，从决定出口产品质量的理论中可以看到，全要素生产率对出口产品质量具有正向推动作用，经过本文的实证检验也确实发现，企业全要素生产率的提升对企业出口产品质量的升级十分显著，可见，<sup>“</sup>提质<sup>”</sup>和 <sup>“</sup>增效<sup>”</sup>具有紧密的关联关系，生产率的提升是企业出口产品质量升级的重要途径。

其次，从企业外部环境看，要坚持 <sup>“</sup>引进来<sup>”</sup>的策略，特别是引入其他国家具有产业带动作用的外商直接投资，通过发挥好外商直接投资的技术溢出作用，带动出口产品质量的稳步提升。 同时，要积极帮助中西部地区引入外资，优化其经济外向程度，提升外资对当地产业的带动作用，这也将有利于推动中西部地区出口产品的优化升级。

最后，政府在推动出口商品升级中同样发挥着积极作用 一方面，世界各国对于支持企业特别是中小企业参与市场竞争前研发等方面的政府支持是通行的做法，因此，在符合国际惯例和竞争中性的原则下，政府的补贴尤其是对中小企业的支持仍然是推动产品质量优化升级的可行和有效的做法 另一方面，政府要注重保护企业知识产权等无形资产权利，本文研究表明，无形资产可以稳健地提升企业出口产品质量，因此，政府在企业知识产权、商标权等方面需要加大保护力度，同时，要帮助企业更有效地管理和运用好无形资产，这将有利于推动其不断提升其产品质量。
