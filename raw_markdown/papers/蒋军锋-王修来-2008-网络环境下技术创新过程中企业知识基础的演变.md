技术创新日益成为国家和企业用以获取竞争优势的源泉，纳尔逊<sup>［</sup>1<sup>］</sup>指出通过技术创新来获取经济利润的能力差异更多的是来源于实施技术创新的组织能力。 网络环境下企业技术创新过程是一个非常复杂的知识应用与知识创造过程。 任何技术创新都涉及对知识的获取和创新，无论对于专业技术知识还是管理知识，不同企业的拥有状况都是有所不同的，这与企业自身独特的生成历史相关，企业知识在知识空间所具有的时空特征是企业在技术创新过程中创造的知识和接受的知识扩散的综合结果。

当代成功的技术创新活动是建立在技术创新网络不同成员之间以知识转移和知识共享为基础的信息流交换过程的基础上的，技术创新过程实质上是参与创新企业之间交换知识以实现知识创造的过程<sup>［</sup>2<sup>，</sup>3<sup>］</sup>。 指出，技术创新网络中的信息交换行为对跨组织学习的促进作用<sup>［</sup>4<sup>］</sup>。 等<sup>［</sup>5<sup>］</sup>的研究在某种程度上说明了技术创新网络环境对知识创造、知识扩散、知识利用的作用。 等<sup>［</sup>6<sup>］</sup>认为，网络合作和关键资源、促进知识转移相联系，网络不仅促进网络中的知识转移，还促进新知识的产生，融入了知识创造衍生于知识扩散的观念。 等<sup>［</sup>7<sup>］</sup>通过对市场中学习的研究，表明通过创造知识交易的渠道和降低学习的风险，技术创新网络形成了知识转移和学习过程。

等<sup>［8］</sup>从创新网络的结构影响其潜在的知识创造出发，得出嵌入网络的企业，依据其高聚集性和高密度性，比没有嵌入联盟网络的企业具有更多的创新产出。 <sup>［</sup>9<sup>］</sup>通过对现有创新网络理论及复杂技术创新的传播速度的研究，得出每一项复杂技术的产生，都有其独特的时间和空间动态的网络发挥作用的结论，此项研究注意到了技术创新网络的时空关系。从而可以看出，技术创新网络促进了知识扩散和转移，进而促成了知识创造，而在这一过程中，知识扩散、转移和创造也推动了技术创新网络的发展。

知识在技术创新中的扩散和转移总是要借助于信息流来实现的<sup>［</sup>10<sup>～</sup>12<sup>］</sup>。 等<sup>［</sup>13<sup>］</sup>回顾了50年来在“ ”上关于信息流研究的文章，指出技术创新网络中的信息交换是技术扩散的主要途径，企业之间的信息联系是企业之间进行知识传递的基本途径<sup>［</sup>14<sup>，</sup>15<sup>］</sup>。党兴华等<sup>［</sup>10<sup>，</sup>11<sup>］</sup>从信息流角度出发，将知识转移的动力因素分为两大部分：在创新企业没有任何有意识活动时知识传播的影响因素 即知识扩散 与知识传播中由于创新企业的有意识的活动而带来的附加相关因素，并对知识转移的动机进行了研究。 党兴华等<sup>［</sup>16<sup>］</sup>从知识位势的角度出发，认为在网络环境中，进行企业技术创新合作的所有企业组成一个知识场，其中每个企业都可以看作是一个知识主体，拥有特定的知识势能。 蒋军锋等<sup>［</sup>17<sup>］</sup>进一步利用现代理论在理论上定量化了技术创新网络中行为主体的知识特征，构造了指征知识流动性与特异性的知识动能与知识势能 个概念，用以探讨知识在技术创新过程中的特征。 韩维贺等<sup>［</sup>18<sup>］</sup>从经验层面上针对知识的创造、组织、转移和应用 个基本过程提出了研究知识转移的测量工具。 蒋军锋等<sup>［12］</sup>在以往对技术创新网络中企业知识特征与信息流之间的数量关系研究的基础上，利用张量分析从理论上 以数学公理化形式 对信息流概念加以严密化，奠定了技术创新中行为主体的知识时空与信息流的定量关系的理论基础，并与 <sup>［9］</sup>对于技术创新网络时空形态的关注一致。既有研究表明，技术创新网络中知识扩散与知识创造和信息流动是紧密联系的，知识扩散与知识创造也正是借助于信息流的存在而完成的。

同时， <sup>［</sup>2<sup>］</sup>曾指出企业不应看作是知识扩散的结果，而应是知识占有的结果，其含义在于指出企业的边界及其功能性活动是由知识基础决定的，但他认为企业的边界与知识扩散没有联系则是有待商榷的。 企业在技术创新过程中创造的知识肯定会带来企业边界的变化，但知识在技术创新过程中的扩散带来的同样也是企业边界的变化，若仅从静态的视角来看，其观点无疑是正确的，但若从动态的视角来看，网络环境下企业技术创新过程中知识基础的演变则决定了企业的边界，从而也决定了企业在技术创新过程中所参与的活动范围。

## 3 知识基础演变的微观分析

设在技术创新过程中的任意时刻，企业i 对信息输入 $\boldsymbol { X } _ { t } ^ { n ^ { + 1 } } = ( \mathbf { \Psi } _ { x ^ { 1 } } , \mathbf { \Psi } _ { x ^ { 2 } } , \cdots , \mathbf { \Psi } _ { x k _ { i } } ; t ^ { _ { 0 } } ) ^ { \mathrm { ~ T ~ } }$ 的处理变换在时刻 $\boldsymbol { T } = _ { t }$ 为 $T _ { i , t } : S _ { i , t } {  } S _ { i , t } + { \triangle } , \triangle > \mathrm { 0 } _ { \circ }$ 这就意味着在时刻 $\boldsymbol { T } = _ { t }$ ，企业对信息输入 $\boldsymbol { X } _ { t } ^ { n ^ { + 1 } }$ 所适用的变换是在集合

$$
T _ {i, t} = \bigcup_ {k = 1} ^ {n} \boldsymbol {w} _ {t, k}\tag{15}
$$

中选择。 对应地，利用

$$
\Omega_ {i} ^ {k} = \left\{\boldsymbol {w} _ {t, k}; \boldsymbol {p} _ {t, k}, k \in (1, 2, \dots , m) \right\}\tag{16}
$$

来刻画企业i 的知识时空的内部构造。 其中，任意 $\begin{array} { r } { \pmb { w } _ { t } , } \end{array}$ ，k在 $\boldsymbol { T } = _ { t }$ 时刻被企业选择用来变换输入信息 $\boldsymbol { X } _ { t } ^ { n + 1 } ( i ) , i = 1 , 2 , \cdots , m 1$ 的概率为 $\rho _ { t } , _ { k } ,$ ，这样，企业的知识基础●<sup>k</sup>i 就是定义在空间 $\begin{array} { l } { { \bf \chi } _ { i } ^ { n + 1 } } \\ { \ ~ i \mathrm { ~ } } \end{array}$ 上一定区域的映射变换集合： $T _ { i , t } = \bigcup _ { k = 1 } ^ { n } \pmb { w } _ { t , k }$

在前述条件下，变换 $w _ { t } , k$ 的作用表现为

$$
\boldsymbol {X} _ {t ^ {i}} ^ {k _ {i} + 1} = \boldsymbol {X} _ {t ^ {+} \Delta} ^ {k _ {i} + 1} w _ {i, k}, \quad k = 1, 2, \dots , m _ {\circ}\tag{17}
$$

以概率 $\cdot p _ { \ i } , _ { k }$ 出现。 在空间 $\boldsymbol { \mathrm { I R } } ^ { n ^ { + 1 } }$ 中，这就是 $\begin{array} { r } { \pmb { w } _ { t } , } \end{array}$ ，k对点 $\boldsymbol X _ { t } ^ { k _ { i } + 1 }$ 的迭代作用 $\textcircled{1}$ ，信息流的轨迹是由 $\begin{array} { r } { \pmb { w } _ { t } , } \end{array}$ ，k完全决定的。在给定的信息输入为式 的条件下，根据计算法则，总可以构造出：

$$
\begin{array}{c} \boldsymbol {C} _ {\text {output}, t} = (X _ {t ^ {+}} ^ {n + 1} \Delta (1), \dots , X _ {t ^ {+}} ^ {n + 1} \Delta (m ^ {2})) = \\ (X _ {t} ^ {n + 1} (1), \dots , X _ {t} ^ {n + 1} (m ^ {1})) w _ {t, 1} \dots w _ {t, k}. \end{array}\tag{18}

以上运算只要满足

$X _ { t } ^ { n ^ { + 1 } } ( i ) w _ { i j } = 0 , \quad i \ne j ; \quad i , j = 1 , 2 , \dots , n ,$ （19）就是可行的。 在此条件下， $\mathbf { \Phi } _ { T _ { i , t } } : \mathbf { \Phi } _ { S _ { i , t } } \mathbf { \Phi } ^ {  } S _ { i , t } \mathbf { + } \mathbf { \Phi } _ { \Delta }$ 就被裂解为

这个过程实质上可以简单地做以下理解：将输入矩阵中的信息通过适当的旋转或者平移变换总可以分解为线性不相关的分量，这些分量在依次由仅对其单个信息分量具有变换作用的矩阵 $w _ { t } , k$ 序列作用下，最终得到信息输出矩阵，这个矩阵的向量同样具有线性不相关的特性，然后通过适当的旋转或者平移变换将其变换为输出信息矩阵中的信息向量。因而，可以在企业i 的知识基础空间中分离出一类特殊的变换 $w _ { t } , k$ ，使其仅对 $\boldsymbol { \mathrm { I R } } ^ { n ^ { + 1 } }$ 空间中的最大线性无关组中的单一元素变换其作用的部分，并记为

$$
T _ {i, t} ^ {*} = \{\pmb {w} _ {t, 1}, \pmb {w} _ {t, 2}, \dots , \pmb {w} _ {t, k} \},\tag{21}

式中， $\smash { T _ { i , t } ^ { * } }$ 为知识基础空间的基本范畴。 由此，企业i 一旦选择 $\pmb { w } _ { t k }$ 来变换时，在经历时间长度 $\pmb { \triangle }$ 后，企业知识基础空间 $\Omega ^ { \ddagger }$ 中的 ${ \boldsymbol w } _ { t k }$ 必然已吸收此次作用的结果，体现在 $w _ { t } + \triangle , k$ 的数学形式上为

上述 $\mathbf { I F S P } _ { i }$ 即是一个分形<sup>［</sup>22<sup>］</sup>，其具有良好的自相似特性，可以显示企业i 的知识基础的演变行为。企业i 的知识基础的演化不是取决于企业预先计算的结果，而是受制于社会网络选择的结果，因而，在微观层面上，企业在技术创新过程中的知识基础的演变不仅与自身的知识基础紧密相关，而且与外界的信息输入密切相关。此处显示的是，知识基础是一个不停地基于输入信息的扩张过程，其扩张的基础由信息输入给定，而既有的知识基础是知识扩张的生成结构元素。

## 5 结论

当代技术创新过程都是基于网络环境下的企业知识基础扩张的过程，相互联系的技术创新合作使得以企业为基本节点的技术创新网络得以出现与演变。 网络环境提供了企业技术创新发展的知识基础背景，企业之间的交互信息流动使得任意企业都存在机会，通过捕获及解释与信息相伴的知识因素而扩张自身的知识占有，而实现自身的知识创造与创新，并同时完成自身的技术创新活动，从而为整体技术创新网络的技术创新过程奠定基础。 本研究的主要结论有：

企业技术创新活动的本质就是企业自身的知识基础的扩张。没有知识基础的扩张，就不存在真正意义上的技术创新；网络环境实质上提供了一个给定了时空的知识空间，并随同企业的知识基础扩张而扩张，企业之间的合作实质上是由于网络知识基础时空分布不均匀导致的，并且，这种不均匀还由于技术创新的频繁化而加剧。一般意义上，网络环境日益使得企业单独完成技术创新变得不可想象，技术创新网络或技术创新合作是实现技术创新的必要条件。

在技术创新过程中的知识基础演变的微观过程中，企业技术创新活动就是一个定义在知识时空上面的从n 维的空间到一个 维空间的变换。 企业的知识基础就是由企业间合作出现的信息流动而带来的知识边界的移动，而这种知识边界的迭代就构成了企业知识基础演变的微观基础；这种知识边界间的迭代序列就构成了技术创新过程中知识基础的迭代，从而，技术创新过程的知识基础就可以裂解为参与技术创新合作的企业知识基础边界的迭代过程。

宏观上，结合最大熵定律，技术创新过程中的信息流动途径决定了知识基础演变的宏观表现：知识创造及其直接输出的后果－－信息输出，式 和式 清楚地显示了技术创新过程中信息流动途径决定了输出的信息熵和企业自身熵；考察网络环境，则企业的知识架跨于知识加厚的具体经验事实也清楚地得到了体现。

（4） 网络环境下的技术创新过程中的知识演变还有以下方面需要继续研究：本文第 部分所说的网络整体的知识基础的演变需要解决知识的集成、扩散与传播的相关问题，同样需要考虑其宏观与微观表现；关于知识基础演变更为公理化的数学模型；网络知识基础的演变在时间上是不可逆的，利用现代域的扩张理论来模型化技术创新过程的知识扩张应该是一个可以尝试的方法。
