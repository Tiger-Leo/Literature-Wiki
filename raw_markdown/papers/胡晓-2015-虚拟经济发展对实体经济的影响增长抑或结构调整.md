# 虚拟经济发展对实体经济的影响: 增长抑或结构调整

胡 晓

［内容摘要］ 虚拟经济在现代经济中的重要性不断上升，如何让虚拟经济有效服务于实体经济是当前关注的重要论题，而虚拟经济发展影响实体经济的方式则是问题的关键，本文对此进行了深入研究<sub>。</sub> 结果表明，虚拟经济发展对实体经济的影响方式及其程度与其发展水平密切相关，随着虚拟经济的不断发展，它对实体经济产业结构的影响越来越强，而对实体经济增长的促进作用越来越小，超过一定水平后，甚至会抑制实体经济增长<sub>。</sub>

［关键词］ 虚拟经济; 实体经济; 经济增长; 经济结构

## 一<sub>、</sub> 引 言

虚拟经济是经济发展到一定阶段的产物，它是与实体经济相对应，以金融系统为依托，通过对虚拟资产<sup>①</sup>的持有和交易活动实现价值增值的经济运行形态<sub>。</sub> 简单地说，虚拟经济就是直接以钱生钱的活动<sub>。</sub> 虚拟经济在现代经济中的重要性日益上升，引发了理论界和实务界的广泛关注 特别是美国金融危机和欧债危机发生后，如何让虚拟经济发展有效服务于实体经济更是成为关注的热点问题

关于虚拟经济发展对实体经济的影响，已有相关文献对此进行了研究和探讨国内方面，王爱俭认为，虚拟经济的发展可以创造货币，带动服务业的发展; 虚拟经济的财富效应也能够推动经济的发展 <sup>［1］</sup>赖文燕认为，虚拟经济过度发展会导致泡沫经济产生，从而不利于实体经济的发展，因而虚拟经济的发展要适度 <sup>［2］</sup>吴德礼研究表明，虚拟经济并未对实体经济产生明显的促进作用 <sup>［3］</sup>沐年国认为，虚拟财富扩张的财富效应 q效应等对居民和企业的消费和投资行为有重要的影响，从而对实体经济的增长产生重要的影响 <sup>［4］</sup>周莹莹和刘传哲研究认为，在虚拟经济发展过程中，虚拟资本随着社会闲散资金的不断聚集得到有效积累，其中一部分资金用于实体经济领域的投资，进而促使了实体经济投资规模的扩张<sub>。</sub><sup>［5］</sup>国外方面，由于很少明确提及虚拟经济的概念，相关的研究主要体现在经济金融化方面<sub>。</sub> 阿瑞基( Arrighi) <sup>［6］</sup>克瑞普纳 ( Krippner) <sup>［7］</sup>和佩蕾丝 ( Perez) <sup>［8］</sup>等学者基于长波理论，<sup>②</sup> 对资本主义经济的金融化分析认为，在经济金融化阶段，经济积累机制发生了变化，利润主要来源于金融渠道，而不是通过贸易和商品生产渠道产生的，这种变化对整个资本主义体系具有重要的影响 埃芒兹 ( Emunds) 认为， <sup>“</sup>羊群效应<sup>”</sup> 和 <sup>“</sup>权益要求<sup>”</sup> 的外生增加使投资者的兴趣从实物投资转向金融资产，限制了实物资产投资，最终会制约实体经济发展<sub>。</sub><sup>［9］</sup>

对文献的梳理发现，一方面，已有研究的重点在于虚拟经济发展对实体经济增长的影响以及虚拟经济过度发展引致的泡沫或危机对实体经济的危害，而就虚拟经济发展对经济结构的影响则鲜有涉及; 另一方面，已有关于虚拟经济对实体经济增长的影响的结论并不一致，因此，需要进一步拓展现有的研究 本文将在一个统一的框架下探讨虚拟经济发展对实体经济增长与结构的影响，期望能深化对虚拟经济功能的认识，更好地发挥虚拟经济服务实体经济的作用

本文其余部分的结构安排如下: 第二部分是理论部分，分析虚拟经济发展对实体经济的影响机制; 第三部分是经验实证分析，对理论分析的结论进行检验; 第四部分是本文的研究结论<sub>。</sub>

## 二 虚拟经济发展对实体经济的影响: 一个理论模型

实体经济系统的资金循环必须经过生产或服务环节，或者说，生产或服务环节是资金在实体经济实现价值增值的必要环节，因此实体经济直接创造 GDP，而且根据生产的产品或提供服务性质的不同，可以把实体经济分为很多产业部门 与实体经济不同的是，虚拟经济系统中的资金循环没有经过生产或服务环节 也就是说，虚拟经济并不直接创造物质产品或提供服务，即它不直接创造 GDP，因此现有一些研究把一些产业部门如金融部门归为虚拟经济是不恰当的<sub>。</sub> 农业部门 制造业部门和服务业部门是实体经济三大主要产业部门，参照已有研究产业结构调整的一些文献的做法和根据本文研究需要，不考虑农业部门，进一步把服务业部门分为一般性服务业部门和金融服务业部门 金融服务业部门是广义的概念，主要包括金融 房地产和保险部门; 把除金融服务业之外的其他服务业归入一般性服务业部门，并假设一般性服务业部门是非贸易品部门<sub>。</sub> 为了分析的方便，把一般性服务业部门简称为服务业部门，把金融服务业部门简称为金融业部门 因此，本文把实体经济分为制造业部门 服务业部门和金融业部门三个部门，分析一个国家虚拟经济发展对实体经济的影响机理，并假设资本和劳动力能够在不同部门间自由流动，劳动力市场和资本市场出清

用S M F 分别表示服务业部门 制造业部门和金融业部门， $\alpha$ 表示虚拟经济发展水平， $\mathrm { P _ { i } }$ 表示i 部门的价格， $\mathrm { C _ { i } }$ 表示对i 部门的消费， $\mathrm { X } _ { \mathrm { i } }$ 表示i 部门的产出<sub>。</sub>

杠杆交易是虚拟经济的重要特征之一 虚拟经济发展会导致私人部门资产负债表的扩张，从而导致社会债务规模和财富规模的扩张，而财富规模的扩张对消费具有促进作用，这是虚拟经济发展的支出效应<sub>。</sub> 用 W 表示社会财富规模，则有 W<sup></sup>$\mid \alpha \mid = \frac { \mathrm { d } \mathrm { W } \big ( \ : \alpha \big ) } { \mathrm { W } \big ( \ : \alpha \big ) } = \mathrm { f } \big ( \ : \dot { \alpha } \big )$ 且 $\mathrm { f } ^ { \prime } \vert \ \dot { \alpha } ) \ > 0$ ，即社会财富规模与虚拟经济发展水平正相关<sub>。</sub> 因此，对服务业部门和制造业部门的需求可分别表示为:

$$
\dot {C} _ {\mathrm{s}} = - \varepsilon_ {\mathrm{s}} \dot {P} _ {\mathrm{s}} + \eta_ {\mathrm{s}} \dot {W} (\alpha)\tag{1}
$$

$$
\dot {C} _ {M} = - \varepsilon_ {M} \dot {P} _ {M} + \eta_ {M} \dot {W} (\alpha)\tag{2}
$$

其中，变量上面加点表示变量的变化率; <sub>ε</sub> 和 $\boldsymbol { \mathsf { \Pi } } ^ { \mathsf { \Pi } }$ 分别表示需求的价格和财富弹性，且有 $\eta _ { \mathrm { s } } > 0 , \ \eta _ { \mathrm { { M } } } > 0$

服务业部门和制造业部门的价格主要体现在生产要素成本，则它们的价格可分别表示为:

$$
\begin{array}{r} \dot {\mathrm{P}} _ {\mathrm{S}} = \theta_ {\mathrm{LS}} \dot {\omega} + \theta_ {\mathrm{KS}} \dot {\mathrm{r}} \\ \dot {\mathrm{P}} _ {\mathrm{M}} = \theta_ {\mathrm{LM}} \dot {\omega} + \theta_ {\mathrm{KM}} \dot {\mathrm{r}} \end{array}\tag{3}
$$

其中，r 表示利率，也即资本成本或资本报酬率， $\boldsymbol { \omega }$ 表示工资，也即劳动力成本， $\theta _ { \mathrm { i j } }$ 表示 $\mathrm { j }$ 部门产出中要素 i 的份额，也即是j 部门要素 i 的产出弹性<sub>。</sub>

虚拟经济是以金融系统为依托，它的发展将会直接导致金融业部门的快速扩张，即 $\mathrm { d } \dot { \mathrm { X } } _ { \mathrm { F } } / \mathrm { d } \dot { \alpha } > 0$ <sub>。</sub> 这意味着虚拟经济发展会导致一部分劳动力和资本从制造业部门和服务业部门向金融业部门转移，这是虚拟经济发展的直接资源转移效应

对金融业部门来说，一方面，虚拟经济具有网络外部性，这决定了它的价格与其规模密切相关 因而，虚拟经济发展所导致的金融规模的扩张会导致金融业部门价格降低; 另一方面，金融业部门需要投入生产要素，因而它的价格也反映要素的成本，因此可把金融业部门的价格表示为:

$$
\dot {\mathrm{P}} _ {\mathrm{F}} = \theta_ {\mathrm{LF}} \dot {\omega} + \theta_ {\mathrm{KF}} \dot {\mathrm{r}} - \delta \dot {\alpha}\tag{5}
$$

其中，δ 表示虚拟经济发展对金融业部门价格的影响系数<sub>。</sub>

制造业部门是可贸易部门，其价格由世界市场决定，一个国家虚拟经济的发展不会对其价格产生很大的影响，因此假设 $\dot { \mathrm { P } } _ { \mathrm { M } } = 0 ;$ 对于金融业部门，由于全球金融市场一体化的加强和国际资本流动管制的放松，一个国家金融业部门的价格很大程度上由世界金融市场决定，因此进一步假设 $\dot { \mathrm { P } } _ { \mathrm { F } } = 0$ ，结合 (4) 式和 ( 5) 式，可以得到:

$$
\begin{array}{l} \dot {\omega} = \frac {\delta \times \theta_ {\mathrm{KM}} \times \dot {\alpha}}{\theta_ {\mathrm{LF}} \theta_ {\mathrm{KM}} - \theta_ {\mathrm{KF}} \theta_ {\mathrm{LM}}} \\ \dot {\mathrm{r}} = - \frac {\delta \times \theta_ {\mathrm{LM}} \times \dot {\alpha}}{\theta_ {\mathrm{LF}} \theta_ {\mathrm{KM}} - \theta_ {\mathrm{KF}} \theta_ {\mathrm{LM}}} \end{array}\tag{6}
$$

( 7)

一般说来，服务业部门和金融业部门相对于制造业部门来说，是劳动密集型的行业，所以 $\theta _ { \scriptscriptstyle \mathrm { L F } } \theta _ { \scriptscriptstyle \mathrm { K M } } - \theta _ { \scriptscriptstyle \mathrm { K F } } \theta _ { \scriptscriptstyle \mathrm { L M } } > 0 , \frac { \theta _ { \scriptscriptstyle \mathrm { L S } } \theta _ { \scriptscriptstyle \mathrm { K M } } - \theta _ { \scriptscriptstyle \mathrm { K S } } \theta _ { \scriptscriptstyle \mathrm { L M } } } { \theta _ { \scriptscriptstyle \mathrm { L F } } \theta _ { \scriptscriptstyle \mathrm { K M } } - \theta _ { \scriptscriptstyle \mathrm { K F } } \theta _ { \scriptscriptstyle \mathrm { L M } } } > 0$ ，则根据 (6) 式和 (7) 式可知，虚拟经济发展将会导致工资上涨<sub>、</sub> 利率下降，因此虚拟经济发展将会导致要素相对价格的变化

将 ( 6) 式和 ( 7) 式代入 ( 3) 式，得到:

$$
\dot {P} _ {\mathrm{s}} = \frac {\left(\theta_ {\mathrm{LS}} \theta_ {\mathrm{KM}} - \theta_ {\mathrm{KS}} \theta_ {\mathrm{LM}}\right) \times \delta \times \dot {\alpha}}{\theta_ {\mathrm{LF}} \theta_ {\mathrm{KM}} - \theta_ {\mathrm{KF}} \theta_ {\mathrm{LM}}}\tag{8}
$$

根据 (8) 式可知，服务业部门的价格变化 $\big ( \mathrm { \vec { P } _ { s } } \big )$ 与虚拟经济发展水平 ( <sub>α</sub><sup></sup> )同向变动，说明虚拟经济发展将会导致服务业部门价格上涨，而根据前面的假设，$\dot { \mathrm { P _ { M } } } = 0$ 和 $\dot { \mathrm { P } } _ { \mathrm { F } } = 0$ ，因而虚拟经济发展将导致各产业部门相对价格的变化

虚拟经济发展会导致要素相对价格的变化和实体经济各产业部门相对价格的变化，因而虚拟经济发展对实体经济具有资源配置功能，这将深刻地影响实体经济增长和结构 下面对此进行具体分析

由于假设服务业部门为不可贸易部门，根据国内服务市场出清，把 (8) 式代入 (1) 式，得到:

$$
\mathrm{X} _ {\mathrm{S}} = \mathrm{C} _ {\mathrm{S}} = \mathrm{W} (\alpha) \times \eta_ {\mathrm{S}} - \varepsilon_ {\mathrm{S}} \times \frac {\left(\theta_ {\mathrm{KS}} \theta_ {\mathrm{LM}} - \theta_ {\mathrm{LS}} \theta_ {\mathrm{KM}}\right) \times \delta \times \dot {\alpha}}{\theta_ {\mathrm{LF}} \theta_ {\mathrm{KM}} - \theta_ {\mathrm{KF}} \theta_ {\mathrm{LM}}}\tag{9}
$$

(9) 式说明了虚拟经济发展对服务业部门产出的影响机制<sub>。</sub> 由 (9) 式可以得到命题1:

命题1:在开放经济条件下，虚拟经济发展对服务业部门产出增长具有促进作用

(9) 式右边第一项即为虚拟经济发展对服务业部门产出的支出效应 因为 W<sup></sup>$\begin{array} { r l } { | \mathbf { \alpha } \propto } & { { } = \mathbf { f } \mathbf { \beta } \left( \mathbf { \alpha } \dot { \alpha } \right) } \end{array}$ 且 $\mathrm { ~ f ~ } ^ { \prime } \mid \dot { \alpha } ) > 0$ ，所以 (9) 式右边第一项为正，这说明虚拟经济展的支出效应对服务业部门产出增长有正向影响; ( 9) 式右边第二项 $- \varepsilon _ { \mathrm { s } }$ ×$\frac { ( \theta _ { \mathrm { K S } } \ \theta _ { \mathrm { L M } } - \theta _ { \mathrm { L S } } \theta _ { \mathrm { K M } } ) \quad \times \delta \times \dot { \alpha } } { \mathrm { ~ \Omega ~ } \mathrm { ~ \Omega ~ } }$ 为虚拟经济发展对服务业部门产出的资源转移效应，根$\theta _ { \mathrm { L F } } \theta _ { \mathrm { K M } } - \theta _ { \mathrm { K F } } \theta _ { \mathrm { L M } }$ 据前面的分析，一般情况下有 $\frac { \cdot \theta _ { \mathrm { L S } } \theta _ { \mathrm { K M } } - \theta _ { \mathrm { K S } } \theta _ { \mathrm { L M } } } { \theta _ { \mathrm { L F } } \theta _ { \mathrm { K M } } - \theta _ { \mathrm { K F } } \theta _ { \mathrm { L M } } } > 0$ ，则右边第二项的符号为负，这说明虚拟经济发展的资源转移效用对服务业部门产出增长有负向影响，因此虚拟经济发展对服务业部门产出增长的总体影响取决于支出效应和资源转移效应之间的比较<sub>。</sub>

虚拟经济发展导致工资上涨的同时也提高了服务业部门的价格，因而虚拟经济发展对其资源转移效应比较小，特别是高端服务业，由于其附加值较高，虚拟经济发展对其资源转移效应会更小; 而虚拟经济发展的财富效应会刺激对服务业部门的需求，因而虚拟经济发展对服务业部门的支出效应比较强<sub>。</sub> 因此，一般说来，虚拟经济发展对服务业部门的支出效应会大于资源转移效应，进而虚拟经济发展对服务业部门产出增长具有促进作用，即 $\mathrm { { d } } \dot { \mathrm { X } } _ { \mathrm { s } } / \mathrm { { d } } \dot { \alpha } > 0$ ，命题1 得证<sub>。</sub>

下面进一步分析虚拟经济发展对制造业部门产出的影响 假设劳动力的供给是固定的，由于虚拟经济发展对利率即资本报酬率有影响，因而资本的形成 ( 投资)与虚拟经济发展水平有关，这是虚拟经济发展的投资效应 虚拟经济发展导致的利率降低到一定水平之前将会促进投资，但随着利率的不断降低，实体经济投资报酬率的下降又会导致资金撤离实体经济而流向虚拟经济追逐较高的货币利润，因而虚拟经济发展对投资的影响是非线性的<sub>。</sub> 结合前面的分析，有 (10) 式和 (11) 式:

$$
\alpha_ {\mathrm{LS}} \mathrm{X} _ {\mathrm{S}} + \alpha_ {\mathrm{LM}} \mathrm{X} _ {\mathrm{M}} + \alpha_ {\mathrm{LF}} \mathrm{X} _ {\mathrm{F}} = \mathrm{L}\tag{10}
$$

$$
\alpha_ {\mathrm{KS}} \mathrm{X} _ {\mathrm{S}} + \alpha_ {\mathrm{KM}} \mathrm{X} _ {\mathrm{M}} + \alpha_ {\mathrm{KF}} \mathrm{X} _ {\mathrm{F}} = \mathrm{K} (\alpha)\tag{11}
$$

其中，L 表示劳动力，K 表示资本， $\alpha _ { \mathrm { { L i } } }$ 和 $\alpha _ { \mathrm { { K i } } }$ 分别表示 i 部门单位产出所使用的劳动力和资本<sub>。</sub> 对 (10) 式和 (11) 式分别全微分并整理可得到:

$$
\mathrm{K} _ {\mathrm{S}} \times \dot {\mathrm{X}} _ {\mathrm{S}} + \mathrm{K} _ {\mathrm{M}} \times \dot {\mathrm{X}} _ {\mathrm{M}} + \mathrm{K} _ {\mathrm{F}} \times \dot {\mathrm{X}} _ {\mathrm{F}} = \mathrm{dK} (\alpha) - \left(\mathrm{X} _ {\mathrm{S}} \mathrm{da} _ {\mathrm{KS}} + \mathrm{X} _ {\mathrm{M}} \mathrm{da} _ {\mathrm{KM}} + \mathrm{X} _ {\mathrm{F}} \mathrm{da} _ {\mathrm{KF}}\right)\tag{12}
$$

$$
\mathrm{L} _ {\mathrm{S}} \times \dot {\mathrm{X}} _ {\mathrm{S}} + \mathrm{L} _ {\mathrm{M}} \times \dot {\mathrm{X}} _ {\mathrm{M}} + \mathrm{L} _ {\mathrm{F}} \times \dot {\mathrm{X}} _ {\mathrm{F}} = - \left(\mathrm{X} _ {\mathrm{S}} \mathrm{da} _ {\mathrm{LS}} + \mathrm{X} _ {\mathrm{M}} \mathrm{da} _ {\mathrm{LM}} + \mathrm{X} _ {\mathrm{F}} \mathrm{da} _ {\mathrm{LF}}\right)\tag{13}
$$

$$
\text { 其中， } \mathrm{L} _ {\mathrm{i}} = \mathrm{a} _ {\mathrm{Li}} \times \mathrm{X} _ {\mathrm{i}}, \mathrm{K} _ {\mathrm{i}} = \mathrm{a} _ {\mathrm{Ki}} \times \mathrm{X} _ {\mathrm{i}}, \dot {\mathrm{X}} _ {\mathrm{i}} = \frac {\mathrm{d} \mathrm{X} _ {\mathrm{i}}}{\mathrm{X} _ {\mathrm{i}}} = \mathrm{d} \ln \mathrm{X} _ {\mathrm{i}}, \mathrm{i} = \mathrm{S}, \mathrm{M}, \mathrm{F} 。
$$

( 12) 式中的 $\mathrm { X } _ { \mathrm { s } } \mathrm { d } \mathrm { a } _ { \mathrm { K S } } + \mathrm { X } _ { \mathrm { M } } \mathrm { d } \mathrm { a } _ { \mathrm { K M } } + \mathrm { X } _ { \mathrm { F } } \mathrm { d } \mathrm { a } _ { \mathrm { K } { \mathrm { f } } }$ 即为三个部门每单位产出中资本投入的变化 ( 实际上就是资本的投入产出关系的变化) 所引起的总资本投入的变化，即$\Delta \mathrm { K } = \mathrm { X } _ { \mathrm { s } } \mathrm { d } { \mathrm { a } } _ { \mathrm { K S } } + \mathrm { X } _ { \mathrm { M } } \mathrm { d } { \mathrm { a } } _ { \mathrm { K M } } + \mathrm { X } _ { \mathrm { F } } \mathrm { d } { \mathrm { a } } _ { \mathrm { K F } } ;$ ( 13) 式右边的 $\mathrm { X _ { s } d a _ { \mathrm { L S } } + \mathrm { X _ { M } d a _ { \mathrm { L M } } + \mathrm { X _ { F } d a _ { \mathrm { I } } } } }$ 即为三个部门每单位产出中劳动力投入的变化 ( 实际上就是劳动力投入产出关系的变化)所引起的总劳动力投入的变化，即 $\Delta \mathrm { L } = \mathrm { X } _ { \mathrm { s } } \mathrm { d } { \mathrm { a } _ { \mathrm { L S } } } + \mathrm { X } _ { \mathrm { M } } \mathrm { d } { \mathrm { a } _ { \mathrm { L M } } } + \mathrm { X } _ { \mathrm { F } } \mathrm { d } { \mathrm { a } _ { \mathrm { L F } } }$

用 $\frac { \omega } { \mathrm { ~ r ~ } }$ 表示工资 － 利率比，则 $\mathrm { E _ { \mathrm { { L } } } = - \frac { \Delta \Delta \Delta L / L } { \Delta \Delta \mathrm { \Lambda } ( \frac { \omega } { r } ) \mathrm { ~ \Lambda ~ / \frac { \omega } { r } ~ } } , ~ \mathrm { E _ { \mathrm { { K } } } = \frac { \Delta \Delta \Delta \Delta \Delta \Delta ( \frac { \omega } { r } ) \Delta \mathrm { ~ \Lambda ~ / \frac { \omega } { r } ~ } } { \Delta \mathrm { ~ \Lambda ~ / \frac { \omega } { r } ~ } } } }$ 分别表示

劳动力的工资 － 利率比弹性和资本的工资 － 利率比弹性<sub>。</sub> 因此对 ( 12) 式 和(13) 式变形整理有:

$$
\lambda_ {\mathrm{KS}} \times \dot {X} _ {\mathrm{S}} + \lambda_ {\mathrm{KM}} \times \dot {X} _ {\mathrm{M}} + \lambda_ {\mathrm{KF}} \times \dot {X} _ {\mathrm{F}} = \dot {K} (\alpha) - E _ {\mathrm{K}} (\dot {\omega} - \dot {r})\tag{14}
$$

$$
\lambda_ {\mathrm{LS}} \times \dot {X} _ {\mathrm{S}} + \lambda_ {\mathrm{LM}} \times \dot {X} _ {\mathrm{M}} + \lambda_ {\mathrm{LF}} \times \dot {X} _ {\mathrm{F}} = E _ {\mathrm{L}} (\dot {\omega} - \dot {r})\tag{15}
$$

其中， $\lambda _ { \mathrm { i j } }$ 表示要素 i 在j 部门中使用的比例，即 ${ \boldsymbol { \lambda } } _ { \mathrm { { L i } } } = { \frac { \mathrm { { L } } _ { \mathrm { { i } } } } { \mathrm { { L } } } } , \ { \boldsymbol { \lambda } } _ { \mathrm { { K i } } } = { \frac { \mathrm { { K } } _ { \mathrm { { i } } } } { \mathrm { { K } } } }$ ，K<sup></sup> ( <sub>α</sub>) 表示资本总量的变化率，即 K<sup></sup> $\begin{array} { r l } { \left( \mathbf { \alpha } \right) } & { { } = \mathbf { d K } \left( \mathbf { \beta } \boldsymbol { \alpha } \right) \mathrm { ~ \textit ~ { ~ \ / ~ } ~ } / \mathrm { ~ K ~ } \left( \mathbf { \beta } \boldsymbol { \alpha } \right) } \end{array}$ 根据前面对虚拟经济发展的投资效应的分析， $\dot { \mathrm { ~ K ~ } } \left( \alpha \right)$ 的符号不确定<sub>。</sub>

\begin{array}{l} \mathrm{B} = \frac {\lambda_ {\mathrm{KF}} \lambda_ {\mathrm{LS}} - \lambda_ {\mathrm{LF}} \lambda_ {\mathrm{KS}}}{\lambda_ {\mathrm{KF}} \lambda_ {\mathrm{LM}} - \lambda_ {\mathrm{LF}} \lambda_ {\mathrm{KM}}} \\ \mathrm{C} = \frac {\left(\mathrm{E} _ {\mathrm{L}} \lambda_ {\mathrm{KF}} + \mathrm{E} _ {\mathrm{K}} \lambda_ {\mathrm{LF}}\right) \left(\theta_ {\mathrm{KM}} + \theta_ {\mathrm{LM}}\right)}{\left(\lambda_ {\mathrm{LF}} \lambda_ {\mathrm{KM}} - \lambda_ {\mathrm{KF}} \lambda_ {\mathrm{LM}}\right) \left(\theta_ {\mathrm{LF}} \theta_ {\mathrm{KM}} - \theta_ {\mathrm{KF}} \theta_ {\mathrm{LM}}\right)} \\ \mathrm{D} = \frac {\lambda_ {\mathrm{LF}}}{\lambda_ {\mathrm{LF}} \lambda_ {\mathrm{KM}} - \lambda_ {\mathrm{KF}} \lambda_ {\mathrm{LM}}} \end{array}
$$

(16) 式说明了虚拟经济发展对制造业部门产出的影响机制<sub>。</sub> 从 (16) 式可以得到命题2:

命题2: 虚拟经济发展对制造业部门产出具有非线性影响，当虚拟经济发展到一定水平之前，虚拟经济发展对制造业部门产出增长有促进作用; 当虚拟经济发展超过一定水平后，虚拟经济发展对制造业部门产出增长有负向影响<sub>。</sub>

服务业是劳动密集型行业，因此服务业部门在总劳动力中的占比要远远高于在总资本中的占比，而金融业部门的特点决定其劳动力占比和资本占比都比较低，因而一般情况下 B 的分子大于0 对制造业部门来说，其不仅在总资本和劳动力中的占比都比较大，而且在总资本中的占比要高于在总劳动力中的占比，因而 B 的分母一般情况下小于0，所以一般情况下有 $\mathrm { \bf ~ B } < 0$ 根据命题1，则 (16) 式右边第一项是负的，这是虚拟经济发展导致的服务业部门产出的快速增长使生产要素转移到服务业部门而对制造业部门产生的间接资源转移效应; (16) 式右边第二项表示虚拟经济发展对制造业部门的直接资源转移效应 按照相关变量的定义，C 的分子大于0，而C 的分母根据前面的分析大于0，因而有 $\mathrm { C } > 0$ ，则 (16) 式右边第二项中<sub>α</sub><sup></sup> 的系数符号总是负的，说明虚拟经济发展的资源转移效应对制造业部门的产出增长有负向影响; (16) 式右边第三项表示虚拟经济发展的投资效应对制造业部门产出的影响<sub>。</sub> 根据前面的分析，一般情况下 $\mathrm { D } > 0$ ，由于虚拟经济发展对投资的影响是非线性的，则 (16) 式右边第三项的符号不确定 因此，虚拟经济发展对制造业部门产出增长的影响取决于直接资源转移效应 间接资源转移效应和投资效应的综合比较 由于虚拟经济发展的直接资源转移效应对制造业部门产出增长的影响总是负的，虚拟经济发展对服务业部门产出增长的促进作用而产生的间接资源转移效应对制造业部门产出增长的影响也是负的 如果虚拟经济发展能够促进投资，并且投资效应大于直接资源转移效应和间接资源转移效应，则虚拟经济发展对制造业部门的产出增长有促进作用; 相反，当虚拟经济发展的投资效应很小甚至会抑制投资的时候，则虚拟经济发展将对制造业部门产出增长产生负向影响 因而，虚拟经济发展对制造业部门产出增长的影响是非线性的，从而命题2 得证<sub>。</sub>

综合起来，虚拟经济发展到一定水平之前，它能够促进实体经济各部门快速增长，因而虚拟经济发展能够促进实体经济增长，对产业结构的影响较小; 随着虚拟经济的不断发展，它在促进金融业部门和服务业部门增长的同时，对制造业部门产出的促进作用越来越小，甚至产生负作用，因而虚拟经济发展对实体经济增长的促进作用越来越弱，而对实体经济产业结构调整的作用越来越强; 而当虚拟经济发展超过一定水平，虚拟经济发展对服务业部门和金融业部门的促进作用小于对制造业部门的负作用时，它将会抑制实体经济增长并将导致产业结构空心化和服务化<sub>。</sub> 虚拟经济发展对实体经济增长和产业结构调整的效应见表1

## 三<sub>、</sub> 实证分析: 来自美国的证据

美国从20 世纪80 年代以来，虚拟经济快速发展，经济虚拟化程度不断提高，当前的美国经济已是一个高度虚拟化的经济<sub>。</sub> 以下事实说明了美国虚拟经济发展的进程和水平: 首先，美国虚拟资产的规模不断膨胀<sub>。</sub> 经济危机爆发之前的2006 年，美国的虚拟资产规模达到904772 亿美元，而1977 年仅为69533 亿美元，30 年间虚拟资产的规模扩张了13 倍，虚拟资产与 GDP 的比值也扩张了1 倍左右 其次，虚拟资产与生产性资产<sup>③</sup>的比值越来越大，2007 年相比 1977 年增加了 1 倍，说明虚拟资产的扩张速度远远大于生产性资产的扩张速度 最后，在美国公司利润中，与虚拟经济活动密切相关的金融部门的利润占比呈振荡上升趋势，从 1977 年的18.16%上升到2010 年的 35.38%，几乎翻了一番，而制造业部门的利润比重从45.19%下降到15. 52%，下降了近30 个百分点 而且制造业部门中虚拟经济活动收益占利润的比重在最高时达到 57.8%，即使在金融危机时期也超过 20% <sup>④</sup> 因此，本部分利用美国1980—2010 年度数据对理论分析的结论进行实证检验，相关数据来源于美国相应年份的资金流量表和美国经济分析局 ( BEA) 网站并经整理<sub>。</sub>

## ( 一) 模型构建

1. 被解释变量: 为了在一个统一的框架下对理论分析的结论进行实证检验，本文选取制造业部门的 GDP 占 GDP 的比重 ( 简称制造业部门的比重) 作为被解释变量，用 M GDP 表示 根据理论分析的过程，虚拟经济对经济增长和结构的非线性影响以及增长效应和结构调整效应强弱转换的关键在于虚拟经济发展对制造业部门产出的非线性影响 如果实证分析发现虚拟经济发展对制造业部门比重的影响由正变负存在的话，即可证明理论分析的结论与事实相一致<sub>。</sub>

2. 解释变量: 虚拟经济发展的直接表现就是虚拟资产规模的不断扩张，因此本文选择虚拟资产的规模来衡量虚拟经济的发展水平，作为计量模型的解释变量，以 FE 表示，并把它的二次项引入模型

3. 控制变量: 基于理论模型和已有的文献资料，本文选取经济发展阶段和国际分工两个变量作为控制变量<sub>。</sub> 以人均 $\mathrm { G D P \ ( \ A V G D P ) }$ 表示经济所处的发展阶段，以对外直接投资 ( FINVE) 衡量国际分工<sub>。</sub>

因此，本文构建的计量模型如下:

$$
\mathrm{M} _ {-} \mathrm{GDP} _ {\mathrm{t}} = \mathrm{C} + \beta_ {1} \times \mathrm{FE} _ {\mathrm{t}} + \beta_ {2} \times \mathrm{FE} _ {\mathrm{t}} ^ {\wedge} 2 + \sum \alpha_ {\mathrm{i}} \times \mathrm{X} _ {\mathrm{it}} + \mu_ {\mathrm{t}}
$$

其中，X 为控制变量<sub>。</sub>

## 四<sub>、</sub> 研究结论和政策含义

本文就虚拟经济发展对实体经济的影响进行了理论和实证研究 研究发现: 在开放经济条件下，一个国家虚拟经济发展通过支出效应 资源转移效应和投资效应导致要素相对价格变化和实体经济各产业部门相对价格的变化，从而对实体经济的增长和产业结构产生深刻影响<sub>。</sub> 在虚拟经济发展到一定水平之前，虚拟经济发展将主要促进实体经济增长，对实体经济产业结构的影响较小 但随着虚拟经济不断发展，它对经济增长的促进作用将逐渐减弱，而对产业结构的影响越来越强，当超过一定水平后，虚拟经济发展将会抑制实体经济的增长，并导致产业结构的深度调整，使产业结构空心化和服务化

本文的研究结论深化了对虚拟经济及其功能的认识，为虚拟经济发展如何有效服务于实体经济的需要提供了思路，具有较强的政策含义<sub>。</sub>

第一，虚拟经济虽然不直接创造 GDP，但它对资源配置有重要的影响，从而会间接影响 GDP 的增长速度和结构，因此需要重视虚拟经济在现代经济运行系统中的重要作用

第二，要让虚拟经济发展有效服务于实体经济的需要，关键问题是要把虚拟经济发展控制在恰当的水平区间 虚拟经济发展不足，实体经济的增长潜力将不能得到充分发挥，而虚拟经济过度发展将会抑制实体经济增长并导致产业结构调整，因此需要根据实体经济发展的阶段及目标，把虚拟经济发展控制在相应的水平区间，充分发挥虚拟经济在促增长和调结构方面的积极作用<sub>。</sub>

第三，虚拟经济导致金融危机或经济危机的深层次原因在于虚拟经济过度发展导致的其与实体经济增长的背离和产业结构严重失衡，使虚拟经济失去了实体经济的支撑<sub>。</sub> 它与传统的经济危机形成原因及其治理存在根本的区别，经济危机过后的经济复苏过程比较缓慢和艰难，因为它涉及产业结构的重构，因此需要防范虚拟经济的过度发展<sub>。</sub>

第四，对我国来说，适度发展虚拟经济对经济转型升级具有积极的促进作用当前我国面临消费 －投资失衡和产业结构转型升级缓慢的发展困境，适度发展虚拟经济可能是走出困境的有效途径之一 美国金融危机和欧洲债务危机使虚拟经济的负面影响被放大，很多国家对发展虚拟经济持怀疑态度<sub>。</sub> 但是本文的研究表明，只要把虚拟经济发展控制在一定水平以内，虚拟经济发展在促进实体经济增长的同时，还能促进产业结构转型升级 ☆

# The Effects of the Fictitious Economy Development on Real Economy<sup>:</sup> Promoting Growth or Adjusting Structure

Hu Xiao

Abstract<sup>:</sup> The importance of the fictitious economy is rising in modern economy，and how to make the fictitious economy to serve the real economy effectively is an important topic concerned in current． The key to the problem is the way in which the fictitious economy development affected the real economy and this paper study it deeply． The research results showed that impacts of fictitious economy development on real economy growth and structure is closely related to the level of fictitious economy development，with the continued development of the fictitious economy，its effects on industrial structure become stronger， but the effects on economic growth become smaller，when beyond a certain level，its development will curb real economic growth．
