## 一<sub>、</sub>引 言

2018年11月9日上午11时 为期三天的第五届世界互联网大会在浙江乌镇闭幕 这场大会以<sup>“</sup>创造互信共治的数字世界———携手共建网络空间命运共同体<sup>”</sup>为主题 就互联网 大数据 5G人工智能等问题进行了讨论

互联网与数字技术的发展塑造了全球现代生产网络 《2017年世界投资报告》指出 互联网与数字技术在商品和服务的生产贸易中的应用 已日益成为全球经济活动增长和发展的关键影响因素 各个行业与产业向数字经济转型可以提升其竞争力 提供新形式的商业机遇和创业活动 拓展进入海外市场的新渠道 有利于各个国家和地区经济活动的可持续发展和包容性发展 报告重点探讨了数字经济的发展对全球范围内的投资模式产生的重大影响 并提出数字经济发展与促进直接投资之间的相互促进作用 根据《二十国集团数字经济发展与合作倡议》中对<sup>“</sup>数字经济<sup>”</sup>所作出的定义 即使用数字化知识和信息作为经济活动中的关键生产要素 以现代信息网络的建设作为重要载体 以信息通信技术的高效使用作为重要推动力的一系列经济活动 数字经济及其相关领域的发展所带来的机遇与挑战对部分发展中国家尤其重要 随着经济全球化的建设与推进 越来越多的发展中国家逐步参与到对外直接投资的行列中来 但是这些国家和地区的数字经济水平明显不高 相关基础设施建设也不完善 并且逐渐显现出与发达经济体之间的数字鸿沟 若能及时提升这些国家和地区的数字经济水平 <sub>，</sub>不仅对这些国家和地区的国内经济发展有很大的帮助 <sub>，</sub> 同时也对中国在该地区的OFDI大有裨益 因此 各个国家和地区急需共同研究和探讨数字经济发展的相关特征 大力发展数字经济并将其作为自身经济发展过程中新的比较优势 同时中国也应积极推进数字经济的发展与我国对这些国家和地区的直接投资深度结合 <sub>，</sub>为我国经济的持续发展提供新的动能与增长点

## 二<sub>、</sub>文献综述

目前 我国对东道国和地区的直接投资与数字经济的发展已经成为学界研究的热点问题 已有文献分别对其进行了研究

## （一）中国对外直接投资相关文献

越来越多的中国企业参与到对外直接投资活动的行列中 我国资本输出的规模和影响力逐渐凸显 随着投资主体和投资行业的日益多元化 以及受到国内结构调整和经济转型的影响 中国对外直接投资发生了一些重要变化（王碧珺 2016） 中国对外直接投资受多方面因素影响 投资潜力巨大 投资区位具有较多的选择（陈伟光 郭晴 2016） 现阶段我国进行对外直接投资时会受到东道国的经济规模 自然资源禀赋 技术水平 东道国的内部冲突 贸易自由度 投资自由度以及东道国国内基础设施建设的影响（胡浩 金钊 谢杰 2017） 东道国的互联网覆盖率有利于促进我国的对外直接投资活动（任晓燕 杨水利 2016） 东道国的问责机制 政治稳定 政府服务效率 监管力度 法治水平以及腐败监察等均对我国的对外直接投资有一定程度的影响 （王永钦 杜巨澜王凯 2014） 国内生产总值 劳动力规模 自然资源禀赋 双边投资协定和投资便利化对中国对外直接投资有显著促进作用 税负水平 距离成本呈现出显著的负向作用（张亚斌 2016） 中国对东道国和地区的直接投资具有显著的市场型和资源型寻求动机 对高收入国家的直接投资以市场寻求为主 对低收入国家的直接投资则以资源寻求为主 此外 东道国的市场规模 对中国的进口依赖度和东道国的资源密集度均影响了中国对其直接投资的规模（刘来会 2017） 东道国和地区的市场发展潜力越大 基础设施情况越好 自然资源越充裕 中国企业越倾向于绿地投资模式 东道国和地区技术水平越高 中国企业越倾向于跨国并购模式（华欣 盛红艳 2016） 因此 在推动经济建设的过程中 这些国家和地区应当充分利用自身的比较优势 发挥该地区核心城市的战略引领 桥梁纽带和辐射带动作用 注重国家和地区之间的均衡发展以及经贸合作区建设等 确保我国近年来提出的对外倡议和举措落地生根和开花结果 以产生全球性的示范效应和带动作用（权衡张鹏飞 2017）

## （二）数字经济相关文献

数字经济及其相关领域的发展势头极为迅猛 中国在全球数字经济蓬勃发展的形势下 应牢牢抓住这一机遇 利用自身的显著优势多措并举 构造弥合数字鸿沟的有效工具 积极应对数字经济发展在国际竞争中所面临的挑战 （王灏晨 李舒沁 2018） 数字经济的发展可以带动<sup>“</sup>一带一路<sup>”</sup>沿线国家信息基础设施建设 促进经济和社会领域的资源优化配置 实现<sup>“</sup>一带一路<sup>”</sup>全面互联互通的建设目标（张伯超 沈开艳 2018） 已有研究通过对数字经济概念的起源和传播历程 研究成果和存在问题进行梳理 辨析了数字经济与相近概念的关系（李长江 2017） 数字经济在我国之所以能够高速发展并实现<sup>“</sup>弯道超车<sup>”</sup> 是因为它依托我国人口众多的消费红利（杨新铭 2017）发展数字经济对中国具有特殊意义 将成为新常态下经济发展的新动能 我国具有网民多的数量优势 实现跨越式发展的后发优势和组织体系保障的制度优势（张新红 2016） 数字经济及其相关领域的发展可以促进各国三大产业的融合发展 有利于实现国民经济的可持续增长 （逄健朱欣民 2013） 美国在数字经济发展方面的布局更早 更全面 并且积极推行大数据与云计算战略 互联网应用等 相比较而言 我国数字经济发展在总量 创新能力 产业发展和监管方面与美国存在较大差距（钟春平 刘诚 李勇坚 2017） 英国政府《数字经济战略（2015－2018） 》提出的数字经济框架下的五大战略目标 分析了数字经济发展存在的挑战与机遇 （丁声一 谢思淼 刘晓光2016） 通过对OECD国家数字经济战略的分析发现 这些国家的一些先进理念以及成功经验对我国数字经济发展具有一定的启示和借鉴意义（陈璋 阚凤云 胡国良 2017） 数字经济的发展创造了大量新型的商业形态 数字技术及其相关领域的新兴产业技术已经成为国际投资过程中越来越重要的区位决定因素（詹晓宁 欧阳永福<sub>，</sub>2018） 我国应该积极完善与数字经济发展相匹配的企业经营模式和市场环境 <sub>，</sub>加快企业和市场的数字化创新 <sub>，</sub>建设服务型数字政府 <sub>，</sub>充分调动数字资源<sub>，</sub>从而提升我国数字经济的国际竞争力（何枭吟<sub>，</sub>2013）

在数字化的浪潮中 大数据 互联网 云计算等数字技术日新月异 对世界经济发展的影响越来越深刻<sub>，</sub>但现有文献大多从数字经济的定义 内涵 发展 现状等方面进行叙述与分析 <sub>，</sub>并没有对东道国和地区的数字经济发展水平情况进行阐述 学者们研究中国在东道国和地区的直接投资时 少有考虑东道国和地区数字经济发展水平的因素 目前将数字经济和对外直接投资相结合的实证研究还比较少

与已有研究相比 本文构建了中国近几年OFDI增长较快的东道国和地区的<sup>“</sup>互联网成熟度<sup>”</sup>测度指标体系 通过均值主成分分析法 从综合指数及三个方面指数较全面地测度了这些国家和地区的数字经济发展水平 并将这一指标纳入到拓展的投资引力模型中 进一步实证分析在数字经济背景下我国对东道国和地区的直接投资选择 得出相应的结论

## 三 东道国和地区数字经济发展水平测度与分析

## （一）构建互联网成熟度（NRI）指标体系

随着互联网信息技术的蓬勃发展 大数据 人工智能 云计算 3D打印等数字技术在商业模式和经济活动中的地位越来越重要 所涉及的社会经济领域也越来越广泛 若单纯采用某一个或某几个因素作为代理变量则难以全面准确地衡量东道国和地区的数字经济发展水平因此 本文结合联合国贸发会议发布的《2017年世界投资报告 》 商务部 国家统计局 国家外汇管理局联合发布的历年《 中国对外直接投资统计公报 》 世界经济论坛发布的历年《 全球信息技术报告》以及《 全球竞争力报告》中的最新内容 从数字经济发展的本质内涵和基本架构出发 基于数字经济相关的制度及创新环境 基础设施建设 信息技术应用三个方面 构建了互联网成熟度（NRI） 测度指标体系 并将以上三个一级指标细分为20个二级指标 从而涵盖了东道国和地区数字经济发展的基本方面 鉴于数据的准确性与一致性 本文采用2009年－2016年的《 全球信息技术报告》 对中国近年来 OFDI增长较快的东道国和地区的数字经济发展水平进行测度与分析 相应指标见表1

## 四 东道国和地区数字经济发展水平对中国直接投资的实证分析

## （一）模型与数据

Tinber<sub>g</sub>en（1962）和Po<sub>y</sub>honen（1963）最早将引力模型用于研究国际贸易 <sub>，</sub>他们分别使用该模型分析了双边贸易流量 并得出了相同的结果 即两国双边贸易规模与两国的经济总量成正比 与两国之间的距离成反比 随着引力模型的不断完善与拓展 <sub>，</sub>其在相关经济活动中的应用也越来越广泛 因此 本文根据数字经济背景下中国近年来 OFDI增长较快的东道国和地区的实际经济情况 建立了以下拓展的投资引力模型

$$
\begin{array}{r l} \ln O F D I _ {t} = & \beta_ {0} + \beta_ {1} \ln N R I _ {t} + \beta_ {2} \ln G D P _ {t} + \beta_ {3} \ln p G N I g r _ {t} + \beta_ {4} \ln L a b o r _ {t} + \beta_ {5} \ln R e s o u r c e _ {t} + \\ & \beta_ {6} \ln T e c h _ {t} + \beta_ {7} \ln D i s t _ {t} + \beta_ {8} \ln T r a d e O p e n _ {t} + \beta_ {9} \ln F d i O p e n _ {t} + \xi_ {t} \end{array}\tag{5}
$$

（t表示年份<sub>，</sub>t＝2009<sub>，</sub>2010<sub>，</sub> … <sub>，</sub>2016）

以上模型中各解释变量的说明如下 <sub>：</sub>

1．OFDI表示中国对东道国和地区的直接投资流量 根据历年《中国对外直接投资统计公报》中的统计数据可以发现 我国对一些国家的直接投资并非全部为正值 有些年份也存在负值和零值 若直接剔除这些数据样本 不仅减少了数据量 同时也导致了模型估计结果存在更大的偏差 因此根据Busse和 Hefeker（2007）的方法 $\mathrm { { ; y = l n } } ( \boldsymbol { x + } \sqrt { \boldsymbol { x } ^ { 2 } + 1 } )$ 对统计数据中的负值和零值进行相应处理

2．NRI表示互联网成熟度指标体系 该变量为核心解释变量 除互联网综合水平指标外 依次将该变量替换为数字经济相关的制度及创新环境 基础设施建设和信息技术应用三个方面指数并纳入模型 从而分析数字技术不同方面的发展水平对中国进行对外直接投资的影响

3．GDP 表示东道国的国内生产总值 该解释变量测度东道国的市场规模 市场规模越大 越有利于中国对其进行直接投资 即中国对外直接投资具有市场寻求型动机

4．<sub>p</sub>GNIr 表示东道国的人均GNI年增长率 该解释变量测度东道国的市场潜力 市场潜力越大 该国经济的未来发展空间越大 同样也会吸引更多的直接投资

5．Labor 表示东道国的劳动力规模 该解释变量衡量效率寻求型动机 东道国的劳动力人数越多 其相应的劳动力成本就会越低 更有利于中国对其进行直接投资

6．Resource 表示东道国的自然资源禀赋 该解释变量衡量自然资源寻求型动机 用矿石 金属和燃料出口之和占该国商品总出口的百分比来测度 <sub>，</sub> 东道国的资源禀赋越充裕 <sub>，</sub> 也就能吸引更多的外商直接投资 即中国的对外直接投资具有资源寻求型动机

7．Tech 表示东道国的技术水平 该解释变量衡量东道国的战略资产 用东道国的研发支出占该国GDP的百分比来测度 东道国的技术禀赋越高 其他国家在该国进行投资时能更好地利用投资创造收益 同时也能更加充分地促进国家之间的技术交流与学习 即中国的对外直接投资具有技术获取型的动机

8．Dist表示中国首都北京与东道国首都之间的距离

9．TradeOen 表示东道国的贸易开放度 该解释变量用东道国出口与进口之和占 GDP的百分比来测度 更高的贸易开放度能够促进国家之间的经贸往来 更有利于中国的直接投资活动

10．FdiO<sub>p</sub>en 表示东道国的投资开放度 该解释变量用东道国对外直接投资与引进外资之和占GDP的百分比来测度 更高的投资开放度可以促进中国对东道国的直接投资活动

## 五<sub>、</sub>结论与启示

通过构建互联网成熟度指标体系 测度中国近年来OFDI增长较快的东道国和地区的数字经济发展水平 并将其纳入拓展的投资引力模型 实证分析东道国和地区的数字经济发展水平对中国进行对外直接投资的影响 主要得出以下结论 1．东道国和地区的数字经济发展水平存在较显著差异 欧洲地区的综合水平高于亚洲地区 但是根据国家具体排名来看 排名靠前的不一定都是欧洲发达国家 部分亚洲发展中国家的排名也较靠前 从时间和地区来看 多数东道国和地区的数字经济发展水平 整体上呈现上升式发展 而且普遍有很大的提升空间 2．东道国和地区的市场规模 市场潜力 劳动力要素 自然资源 技术水平 贸易和投资开放度对中国的对外直接投资有显著正向促进作用 而中国首都北京与东道国首都之间的距离则呈现出显著的负向影响 3．东道国和地区数字经济相关制度与设施的发展水平越高 会增加中国的直接投资流量 东道国和地区的制度及创新环境 数字基础设施建设和信息技术应用对中国在该地区的直接投资具有显著的正向影响

根据以上结论可以得出如下启示 1．中国近年来 OFDI增长较快的东道国和地区应该大力推进与数字经济发展相配套的基础设施建设 推广数字信息技术的应用与普及 加快改进和完善现有的制度体系等软环境 顺应数字经济浪潮 2．本文所选取的实证检验数据中恰好有部分属于<sup>“</sup>一带一路<sup>”</sup>倡议所涉及的国家和地区 在<sup>“</sup>一带一路<sup>”</sup>倡议提出五年多以来 沿线国家和地区数字基础设施的建设与加强就显得正当其时 因此<sub>，</sub>本文的研究结论对于中国未来对<sup>“</sup>一带一路<sup>”</sup>沿线国家和地区的直接投资活动也具有一定的参考意义 随着东道国和地区数字经济发展水平的提升 可以更好地实现<sup>“</sup>一带一路<sup>”</sup>倡议所提出的共商 共建 共享发展原则 □
