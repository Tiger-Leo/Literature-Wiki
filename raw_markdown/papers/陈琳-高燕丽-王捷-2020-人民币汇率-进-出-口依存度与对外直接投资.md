# 人民币汇率<sub>、</sub>进( 出) 口依存度与对外直接投资

陈 琳 高燕丽 王 捷

( 华东师范大学 经济学院，上海 <sup>200062</sup>)

摘 要:基于中国对各国对外直接投资数据，实证考察人民币汇率变动 进( 出) 口依存度对对外直接投资的影响 结果表明: 人民币升值显著促进对外直接投资，并且，中国对东道国的进( 出)口依存度越高，人民币升值对对外直接投资的促进作用越大 异质性分析表明，因为国别差异，人民币升值对流向发达国家和发展中国家的对外直接投资作用效应不同; 在不同的汇率升( 贬) 值区间，作用效果也有所不同 对于中国这样一个对外贸易和对外投资大国，不仅需要关注汇率变动对进( 出) 口以及对外投资单方面的影响，还需关注汇率变动对于进( 出) 口和对外投资的交互协同作用。

关键词:人民币汇率; 进口依存度; 出口依存度; 对外直接投资

## 一、引言

汇率是一国货币与另一国货币的兑换比率，是两国之间要素与商品相对价格的体现，直接影响着企<sub>业对外投资的成本 。 那么，作为企业对外直接投资(</sub> Outward Foreign Direct Investment<sub>，</sub>OFDI<sub>) 决策中必</sub>然要加以考虑的汇率因素，其和 <sup>OFDI</sup> 之间的关系究竟如何，又是通过怎样的机制来起作用，这是本文所要研究的问题。

出口和对外投资是企业国际化的两种方式，二者存在替代关系。 <sup>20</sup> 世纪<sup>80</sup> 年代，美日贸易摩擦加剧，日本被迫签署<sup>“</sup>广场协议<sup>”</sup>后日元出现快速升值，随后日本的对外投资大幅增长，通过在美国开展直接投资取代对美国的出口贸易，美日贸易摩擦得到缓解。 中国当前面临的中美贸易摩擦，和<sup>20</sup> 世纪<sup>80</sup>年代的日美贸易摩擦有诸多相似之处，人民币升值对中国的出口和对外投资是否有相似影响是值得深入研究的现实问题 从理论研究意义上看，有关汇率变动和出口的研究已经形成十分丰富的前期成果，<sub>代表性的有</sub> Berman et al．<sub>(</sub> 2012<sub>)</sub> Amiti et al．<sub>(</sub> 2014<sub>) 毛日昇等(</sub> 2017<sub>) 盛丹等(</sub> 2017<sub>) 等 。 相对而言，汇</sub>率变动与对外投资的研究比较缺乏，近年来尽管出现一些关于汇率和 <sup>OFDI</sup> 的研究，比如 <sup>Liu et al</sup>( <sup>2016</sup>) 孙文莉等( <sup>2016</sup>) 田巍等( <sup>2017</sup>) 张夏等( <sup>2019</sup>) 和陈琳等( <sup>2020</sup>) 等，有关汇率变动影响 <sup>OFDI</sup>的作用机制、汇率变动对对外投资和进( 出) 口之间交互作用的影响等更深层次的研究仍然欠缺，有必要继续进行探索

## 二、相关文献回顾

已有有关汇率对 <sup>OFDI</sup> 的影响研究主要集中在两个方面: 一是汇率的水平变动( 贬值或升值) 对<sup>OFDI</sup> 的影响，二是汇率波动( 波动程度) 对 <sup>OFDI</sup> 的影响。 母国货币升值可以促进一国的 <sup>OFDI</sup>，已有研究有三种解释: 一是相对成本论 如，<sup>Cushman</sup>( <sup>1985</sup>) 基于购买力平价理论提出，母国货币升值，意味着东道国货币相对贬值，这就使得在东道国投资建厂的成本降低，从而提高了母国公司在东道国投资的回报率，更能吸引外资流入 二是相对财富论 如，<sup>Froot et al．</sup>( <sup>1991</sup>) 提出，母国货币升值，以母国货币计价的财富会增加，因此本国投资者有更大的动力进行对外直接投资。 三是企业专有资产论。 如，<sup>Bloni-</sup><sup>gen</sup>( <sup>1997</sup>) 认为，海外特定的专有资产如专利等一般需要以并购的方式获得，当东道国货币贬值时，相对于东道国本土的企业，外国投资者在进行并购时将处于一个更有利的地位，从而促进对外投资特别是并购方式的对外投资流入。 已有实证研究基本支持上述观点，即本国货币升值有利于促进 <sup>OFDI</sup>。 如，<sup>Ko-</sup>steletou et al．<sub>(</sub> 2000<sub>) 运用欧盟各国以及美国的对外投资数据，以及</sub> Lord et al．<sub>(</sub> 2017<sub>) 运用加纳</sub> OFDI <sub>数</sub>据，均发现母国货币升值与 <sup>OFDI</sup> 之间显著正向关联。 就国内研究而言，于津平( <sup>2007</sup>) 分析了跨国公司的 <sup>OFDI</sup> 行为，发现东道国货币升值会减少资源导向型直接投资，但增加了市场导向型的直接投资，汇<sub>(</sub> 2012<sub>)</sub> 1% <sub>，</sub>的 <sup>OFDI</sup> 增长<sup>0．205%</sup> 田巍等( <sup>2017</sup>) 研究了企业实际有效汇率与企业 <sup>OFDI</sup> 的关系，认为贸易服务型投资和企业出口有互补关系。 毛海鸥等( <sup>2019</sup>) 的研究发现，中国对 <sup>“</sup>一带一路<sup>”</sup>沿线国家的 <sup>OFDI</sup> 能够显著促进互补贸易关系的形成，而对非沿线国 <sup>OFDI</sup> 没有显现相应的促进作用 <sup>“</sup>一带一路<sup>”</sup>倡议的提出使得中国的 <sup>OFDI</sup> 对中国与沿线国贸易互补性的影响有很大的提高

有关汇率波动对<sup>OFDI</sup> 的影响，理论和实证研究都没有一致结论 以灵活生产理论( <sup>Goldberg et al．</sup>，<sup>1995</sup>) 为典型的<sup>“</sup>促进论<sup>”</sup>认为<sup>OFDI</sup> 与出口之间有替代关系，当汇率波动加大，企业会选择扩大<sup>OFDI</sup> 以替代出口，因为出口面临的汇率风险更大 以风险规避理论( <sup>Campa</sup>，<sup>1993</sup>) 为代表的<sup>“</sup>抑制论<sup>”</sup>则提出了相反的观点，认为汇率波动对 <sup>OFDI</sup> 有负向影响，也就是说，当汇率波动较大时，风险厌恶型企业会因为面临更大的收益不确定性和投资风险，预期利润降低，从而选择不投资 上述理论研究得出的不同结论在各类实证研究中均有验证

有关 <sup>OFDI</sup> 与贸易之间的关系，不同的 <sup>OFDI</sup> 动机对贸易的作用效应不一 以突破关税壁垒或绕过贸易保护为目标的 <sup>OFDI</sup> 与出口贸易有替代关系( <sup>Belderbos</sup>，<sup>1998</sup>) ，而当母国企业 <sup>OFDI</sup> 是为降低生产成本或者寻求资源( <sup>Brainard</sup>，<sup>1997</sup>) ，<sup>OFDI</sup> 又会促进国际贸易，即 <sup>OFDI</sup> 与贸易是互补关系。 <sup>Head et al</sup>(<sup>2001</sup>) 认为两者之间是替代还是互补，取决于跨国公司是选取垂直形式投资还是水平形式投资。 <sup>Liu et al</sup>( <sup>2016</sup>) 认为，<sup>OFDI</sup> 与出口是替代还是互补，取决于 <sup>OFDI</sup> 的发展阶段，早期阶段两者呈现互补关系，随着 <sup>OFDI</sup> 的成熟，两者呈现替代关系。 针对中国的研究，则结论不一。 余毅等( <sup>2009</sup>) 发现 <sup>OFDI</sup> 与初级产品出口、工业制成品进口有显著的替代效应，与初级产品进口、工业制成品出口有明显的互补效应。毛其淋等( <sup>2014</sup>) 采用双重差分模型，发现 <sup>OFDI</sup> 与出口贸易的互补性体现在 <sup>OFDI</sup> 提高了企业出口在其销售中的占比，也提高了企业出口的概率。

以上文献尽管通过理论研究以及相关国家的数据验证了汇率变动与对外投资的关系，但鲜有分析其中的作用机制 贸易和投资是企业国际化的两种方式，二者之间互相影响，或互相替代或互相促进，取决于不同的条件，以往研究同样也较少将这两者的关系与汇率变动协同考察 本文认为，汇率变动对于进出口以及对外投资不应是割裂地单独起作用，而更可能是一种协同作用 本文可能的增量贡献主要体现在：一是在当前中国推进汇率市场化改革、国内外不确定因素叠加，从而可能引发汇率变动不确定性加大的背景下，本文从汇率水平变动和波动两个维度考察汇率与中国 <sup>OFDI</sup> 的关系，具有重要的现实意义; 二是深入挖掘了汇率变动如何通过出口和进口渠道对中国 <sup>OFDI</sup> 起作用，这一渠道研究在以往文献中较少涉及; 三是本文关于汇率与 <sup>OFDI</sup> 的研究，是在模型构建基础上进行相应经验研究，可为中OFDI <sub>，</sub> <sup>“ ” “ ”</sup>供有力的决策参考

## 三、理论模型

借鉴 <sup>Helpman et al．</sup>( <sup>2004</sup>) 田巍等( <sup>2017</sup>) 的研究，本文区分出口和进口企业，给出不同情境下的企业利润函数，并解出相应的生产率临界点，从而判断汇率变动、进( 出) 口依存度对于企业 <sup>OFDI</sup> 决策的影响。

为简化模型，假设企业只生产一种产品，生产过程中只投入劳动力，给定企业的生产率为 $\boldsymbol { \Phi }$ ，则 $1 / \varphi$ 为单位产出所需的劳动力投入。 若本国( <sup>i</sup> 国) 在东道国( <sup>j</sup> 国) 进行 <sup>OFDI</sup>，则需承担较高的固定成本$\mathrm { f } ^ { \mathrm { o f d i } }$ ，即本国劳动力成本。 令 $\varepsilon _ { \mathrm { i j } }$ 为 <sup>i</sup> 国和 <sup>j</sup> 国双边名义汇率 ${ \mathfrak { s o } } _ { \mathrm { i } }$ 为 <sup>i</sup> 国工资水平 $\bullet \omega _ { \mathrm { j } }$ 为 <sup>j</sup> 国工资水平，则双边实际汇率 $\mathrm { q _ { i j } = \frac { \varepsilon _ { i j } \omega _ { j } } { \omega _ { i } } }$

假设 <sup>j</sup> 国消费者对产品的总需求为 $( 2 , ) ^ { \tt m }$ 品的价格为 $\mathrm { p _ { j } }$ ，企业 <sup>OFDI</sup> 的利润可表示为:

$$
\pi^ {\text { ofdi }} = \mathrm{p} _ {\mathrm{j}} \mathrm{Q} - \frac {\omega_ {\mathrm{j}}}{\varphi^ {\text { ofdi }}} \mathrm{Q} - \frac {\mathrm{f} ^ {\text { ofdi }} \omega_ {\mathrm{j}}}{\mathrm{q} _ {\mathrm{ij}}}\tag{1}
$$

由 $\pi ^ { \mathrm { { \mathrm { ~ o f d i } ~ } } } = 0$ ，可求出企业在 <sup>j</sup> 国 <sup>OFDI</sup> 的生产率临界点:

$$
\stackrel {\wedge} {\varphi^ {\mathrm{ofdi}}} = \frac {\omega_ {\mathrm{j}} Q q _ {\mathrm{ij}}}{p _ {\mathrm{j}} Q q _ {\mathrm{ij}} - f ^ {\mathrm{ofdi}} \omega_ {\mathrm{j}}}\tag{2}
$$

由式( <sup>2</sup>) 可知， $\frac { \stackrel { \wedge } { \partial } \varphi ^ { \mathrm { o f d i } } } { \partial \mathrm { q } _ { \mathrm { i j } } } < 0$ ，意味着当双边实际汇率 ${ \mathfrak { q } } _ { \mathrm { i j } }$ 上升时，即本国货币升值时， $\hat { \varphi } ^ { \mathrm { o f d i } }$ 下降，OFDI 的临界生产率下降，从而促进了 <sup>OFDI</sup> 由此，得到:

命题<sup>1</sup>:本币升值显著促进了 <sup>OFDI</sup>。

对于出口企业来说，假设本国( <sup>i</sup> 国) 企业出口产品到 <sup>j</sup> 国需承担贸易成本，包含企业出口运输中产生的冰山成本和关税，其总和为每单位最终销售的产品共需本国生产 $\boldsymbol { \tau } _ { \mathrm { i j } }$ 单位产品 $\big ( \tau _ { \mathrm { i j } } > 1 \big )$ ，出口所需固定成本 <sup>fe</sup>，为本国劳动力表示的成本 此外，<sup>Oldenski</sup>( <sup>2012</sup>) 指出，没有 <sup>OFDI</sup> 的企业需要为其出口支付额外的跨国沟通与销售成本。 假设每单位产品需要 $\boldsymbol \eta _ { \mathrm { j } }$ 个 <sup>j</sup> 国劳动力来进行跨境信息沟通。 则企业出口利润可表示为:

$$
\pi^ {\mathrm{e}} = \mathrm{p} _ {\mathrm{j}} Q - \left(\frac {\tau_ {\mathrm{ij}}}{\mathrm{q} _ {\mathrm{ij}} \varphi^ {\mathrm{e}}} + \frac {1}{\mathrm{q} _ {\mathrm{ij}} \varphi^ {\mathrm{e}}} + \eta_ {\mathrm{j}}\right) \omega_ {\mathrm{j}} Q - \frac {\mathrm{f} ^ {\mathrm{e}} \omega_ {\mathrm{j}}}{\mathrm{q} _ {\mathrm{ij}}}\tag{3}
$$

由 $\pi ^ { \mathrm { ^ e } } = 0$ ，可求出企业在本国生产并对 <sup>j</sup> 国出口的生产率临界点:

$$
\stackrel {\wedge} {\varphi^ {e}} = \frac {\left(\tau_ {i j} + 1\right) \omega_ {j} Q}{\left(p _ {j} - \eta_ {j} \omega_ {j}\right) q _ {i j} Q - f ^ {e} \omega_ {j}}\tag{4}
$$

对于同时进行出口和 <sup>OFDI</sup> 的企业来说，由于可以与国外客户直接联络，则不会产生跨国沟通与销售成本。 定义 <sup>x</sup> 为出口占总需求的比例，<sup>x</sup> 可代表企业的出口依存度。 则企业同时进行出口和 <sup>OFDI</sup> 的利润可表示为:

$$
\pi^ {\mathrm{ei}} = \mathrm{p} _ {\mathrm{j}} \mathrm{Q} - \left(\frac {\tau_ {\mathrm{ij}}}{\mathrm{q} _ {\mathrm{ij}} \varphi^ {\mathrm{e} ^ {\prime}}} + \frac {1}{\mathrm{q} _ {\mathrm{ij}} \varphi^ {\mathrm{e} ^ {\prime}}}\right) \omega_ {\mathrm{j}} \mathrm{xQ} - \frac {\omega_ {\mathrm{j}}}{\varphi^ {\mathrm{ofdi} ^ {\prime}}} (1 - \mathrm{x}) \mathrm{Q} - \frac {\mathrm{f} ^ {\mathrm{e}} \omega_ {\mathrm{j}} + \mathrm{f} ^ {\mathrm{ofdi}} \omega_ {\mathrm{j}}}{\mathrm{q} _ {\mathrm{ij}}}\tag{5}
$$

同时出口和 <sup>OFDI</sup> 需要支付两笔固定成本 <sup>fe</sup> 和 $\mathrm { f } ^ { \mathrm { o f d i } }$ ，该企业的临界生产率 $\varphi ^ { \mathrm { { \scriptstyle \alpha \bigwedge } } }$ <sup>'</sup>大于仅从事出口的企业的临界生产率 $\hat { \varphi } ^ { \mathrm { e } }$ 。 因此，为求出同时进行出口和 <sup>OFDI</sup> 的企业的临界生产率 $\varphi ^ { \mathrm { { \scriptstyle \alpha \bigwedge } } }$ <sup>'</sup>，将式( <sup>4</sup>) 代入式( <sup>5</sup>) ，可得:

$$
\varphi^ {\wedge_ {\text { ofdi}}} = \frac {(1 - x) \omega_ {j} Q}{(1 - x) \left(p _ {j} Q - \frac {f ^ {e} \omega_ {j}}{q _ {i j}} - \eta_ {j} \omega_ {j} Q\right) - \left(\frac {f ^ {\text { ofdi }} \omega_ {j}}{q _ {i j}} - \eta_ {j} \omega_ {j} Q\right)}\tag{6}
$$

由式( <sup>6</sup>) 可得，当 $\mathrm { \ p \frac { f ^ { \mathrm { o f d i } } \omega _ { j } } { q _ { i j } } - \eta _ { j } \omega _ { j } Q > 0 }$ 时，即企业 <sup>OFDI</sup> 的固定成本高于企业出口所需的跨境信息沟通费用时， $\frac { \stackrel { \wedge } { \partial } ^ { 2 } \stackrel { \mathrm { o f d i } ^ { \prime } } { \partial } < 0 } { \partial \mathrm { q _ { i j } } \partial \mathrm { x } } < 0$ 成立，这表明企业的出口依存度越高，即企业出口占其总销售的比重越高，本币升值越能促进其 <sup>OFDI</sup>。 由此，得到:

命题<sup>2</sup>:企业的出口依存度越高，本币升值越能促进其 <sup>OFDI</sup>

对于进口企业来说，为简化模型，本文考虑加工贸易企业，从 <sup>j</sup> 国进口中间品在本国( <sup>i</sup> 国) 生产后再销往i国。假设一单位中间品生产一单位最终品，进口中间品的价格为 $\mathrm { p _ { i l } }$ ,中间品在i国当地售价为$\mathrm { p } _ { \mathrm { i } 2 }$ ，即为 <sup>OFDI</sup> 企业所需支付的中间品成本，可知 $\mathrm { p } _ { \mathrm { i } 1 } > \mathrm { p } _ { \mathrm { i } 2 }$ 进口中间产品的贸易成本( 包含运输过程中的冰山成本及关税) 由对方出口商承担，无须本国进口企业承担，但企业生产的最终品出口到 <sup>j</sup> 国仍然需要支付贸易成本，其总和为每单位销售的中间品共需 <sup>i</sup> 国生产 $\tau _ { \mathrm { i j } }$ 单位产品( $\tau _ { \mathrm { i j } } > 1 \rceil$ 此外还需承担固f<sup>im</sup><sub>， ，</sub> OFDI成本与信息沟通成本，假设每单位产品需要 个 <sup>j</sup> 国劳动力来进行搜寻与跨境信息沟通 其余假定与 $\eta _ { \mathrm { j } }$ 关于出口企业理论推导的假定一致 则进口加工贸易企业的利润可表示为:

$$
\pi^ {\mathrm{im}} = \mathrm{p} _ {\mathrm{j}} \mathrm{Q} - \mathrm{p} _ {\mathrm{i} 1} \mathrm{Q} - \frac {\tau_ {\mathrm{ij}} + 1}{\mathrm{q} _ {\mathrm{ij}} \varphi^ {\mathrm{im}}} \omega_ {\mathrm{j}} \mathrm{Q} - \eta_ {\mathrm{j}} \omega_ {\mathrm{j}} \mathrm{Q} - \frac {\left(\mathrm{f} ^ {\mathrm{e}} + \mathrm{f} ^ {\mathrm{im}}\right) \omega_ {\mathrm{j}}}{\mathrm{q} _ {\mathrm{ij}}}\tag{7}
$$

由 ${ \boldsymbol { \pi } } ^ { \mathrm { i m } } = 0$ ，可求得加工贸易企业的生产率临界点:

$$
\hat {\varphi} ^ {\mathrm{im}} = \frac {\left(\tau_ {\mathrm{ij}} + 1\right) Q \omega_ {\mathrm{j}}}{\left(p _ {\mathrm{j}} - p _ {\mathrm{i} 1}\right) Q q _ {\mathrm{ij}} - \eta_ {\mathrm{j}} \omega_ {\mathrm{j}} Q q _ {\mathrm{ij}} - \left(f ^ {\mathrm{e}} + f ^ {\mathrm{im}}\right) \omega_ {\mathrm{j}}}\tag{8}
$$

对于同时进口中间品进行加工贸易和 <sup>OFDI</sup> 的企业来说，定义 <sup>x</sup> 为进口占总需求的比例， $\mathbf { \mu } _ { \mathbf { 5 } } \mathbf { X }$ 即为进口依存度。 则同时进口和 <sup>OFDI</sup> 企业的利润可表示为:

$$
\pi^ {\mathrm{mi}} = \mathrm{p} _ {\mathrm{j}} \mathrm{Q} - \mathrm{p} _ {\mathrm{i} 1} \mathrm{xQ} - \mathrm{p} _ {\mathrm{i} 2} (1 - \mathrm{x}) \mathrm{Q} - \frac {\tau_ {\mathrm{ij}} + 1}{\mathrm{q} _ {\mathrm{ij}} \varphi^ {\mathrm{im}}} \omega_ {\mathrm{j}} \mathrm{xQ} - \frac {\omega_ {\mathrm{j}}}{\varphi^ {\mathrm{ofdi}}} (1 - \mathrm{x}) \mathrm{Q} - \frac {\mathrm{f} ^ {\mathrm{e}} + \mathrm{f} ^ {\mathrm{im}} \omega_ {\mathrm{j}}}{\mathrm{q} _ {\mathrm{ij}}} - \frac {\mathrm{f} ^ {\mathrm{ofdi}} \omega_ {\mathrm{j}}}{\mathrm{q} _ {\mathrm{ij}}}\tag{9}
$$

进一步地，为求得同时进口和 <sup>OFDI</sup> 的临界生产率 $\hat { \varphi } ^ { \mathrm { o f d i } ^ { \prime } }$ ，与上文对出口企业的处理相同，界定本国进口企业的临界生产率 $\hat { \varphi } ^ { \mathrm { i m } }$ ，将式( <sup>8</sup>) 代入式( <sup>9</sup>) 式可得:

$$
\varphi^ {\wedge_ {\text { ofdi} ^ {\prime}}} = \frac {\omega_ {j} (1 - x) Q}{(1 - x) \left[ \left(p _ {j} - p _ {i 2}\right) Q - \eta_ {j} \omega_ {j} Q - \frac {\left(f ^ {e} + f ^ {\text { im }}\right) \omega_ {j}}{q _ {i j}} \right] - \left(\frac {f ^ {\text { ofdi }} \omega_ {j}}{q _ {i j}} - \eta_ {j} \omega_ {j} Q\right)}\tag{10}
$$

由式( <sup>10</sup>) 可得，当 <sup>OFDI</sup> 所需的固定成本大于企业进出口所需的跨境信息沟通成本时， $\frac { { \stackrel { \wedge } { \partial } } ^ { 2 } \varphi ^ { \mathrm { \tiny ~ \alpha ~ } } } { \partial \ P _ { \mathrm { i j } } \partial \mathrm { x } } < 0$ 成立，意味着当本国对东道国进口依存度越高时，本币升值越能促进 <sup>OFDI</sup> 由此，得到:

命题<sup>3</sup>:企业的进口依存度越高，本币升值越能促进其 <sup>OFDI</sup>。

由此，本文得到关于汇率 进( 出) 口依存度和 <sup>OFDI</sup> 的三个命题，后续将基于以上三个命题，进行实证检验。

## 四、实证研究设计

## ( 一) 计量模型

参考 <sup>Buckley et al．</sup>( <sup>2007</sup>) 吴国鼎等( <sup>2015</sup>) 的研究，结合前文汇率 进出口和对外投资的理论分析，构建如下计量模型

汇率变动通过出口渠道影响 <sup>OFDI</sup> 的计量方程:

$$
\mathrm{Ln} \text { ofdi } _ {\mathrm{ct}} = \alpha + \beta_ {1} \mathrm{Ln} \mathrm{er} _ {\mathrm{ct}} + \beta_ {2} \mathrm{ex} _ {\mathrm{ct}} + \beta_ {3} \mathrm{ex} _ {\mathrm{ct}} \times \mathrm{Ln} \mathrm{er} _ {\mathrm{ct}} + \theta \mathrm{X} _ {\mathrm{ct}} + \varphi_ {\mathrm{c}} + \gamma_ {\mathrm{t}} + \varepsilon_ {\mathrm{ct}}\tag{11}
$$

汇率变动通过进口渠道影响 <sup>OFDI</sup> 的计量方程:

$$
\mathrm{Ln} \text { ofdi } _ {\mathrm{ct}} = \alpha + \beta_ {1} \mathrm{Ln} \mathrm{er} _ {\mathrm{ct}} + \beta_ {2} \mathrm{im} _ {\mathrm{ct}} + \beta_ {3} \mathrm{im} _ {\mathrm{ct}} \times \mathrm{Ln} \mathrm{er} _ {\mathrm{ct}} + \theta \mathrm{X} _ {\mathrm{ct}} + \varphi_ {\mathrm{c}} + \gamma_ {\mathrm{t}} + \varepsilon_ {\mathrm{ct}}\tag{12}
$$

其中: $\mathrm { L n e r } _ { \mathrm { c t } }$ 表示 <sup>t</sup> 时期人民币兑 <sup>c</sup> 国货币的双边名义汇率与基期( <sup>2005</sup> 年) 双边名义汇率的比值( 取对数) ; $\mathbf { e x } _ { \mathrm { c } }$ 和 $\mathrm { i m } _ { \mathrm { c t } }$ 分别表示中国对东道国 <sup>c</sup> 在 <sup>t</sup> 年的出口依存度和进口依存度; <sup>X</sup> 为其他控制变量，具体包括 <sup>t</sup> 时期东道国的<sup>GDP</sup>、人均<sup>GDP</sup>、资源禀赋、总税率、经济结构、与中国的地理距离及制度差异; $\varphi _ { \mathrm { c } }$ 和 $\gamma _ { \mathrm { t } }$ 分别表示国家( 地区) 固定效应和时间固定效应， $\bullet \varepsilon _ { \mathrm { c t } }$ 为随机误差项 另外，模型还加入了进( 出) 口依存度与汇率变量的交互项，以衡量汇率变动是否通过出口与进口渠道影响中国的 <sup>OFDI</sup>

## ( 二) 变量选取

## <sup>1．</sup> 被解释变量

<sup>OFDI</sup> 是被解释变量，用 <sup>ofdi</sup> 表示。 本文使用<sup>2005</sup>—<sup>2017</sup> 年中国对<sup>131</sup> 个国家和地区的对外直接投资数据，数据来源于商务部 国家统计局 国家外汇管理局联合发布的各年度中国对外直接投资公报为保证数据的平稳性，模型中做对数处理

## <sup>2．</sup> 解释变量

( <sup>1</sup>) 汇率 用 $\mathrm { e r _ { c t } }$ 表示，代表 <sup>t</sup> 时期人民币与 <sup>c</sup> 国货币的双边名义汇率( 以<sup>2005</sup> 年为基期) ，用间接标价法表示 数据来源于国际货币基金组织( <sup>IMF</sup>) 国际金融统计数据库( <sup>IFS</sup>) 该变量大于 <sup>1</sup> 表示人民币汇率与基期相比升值，数值越大代表升值幅度越大; 小于<sup>1</sup> 表示人民币汇率与基期相比贬值，且数值越小，表示贬值程度越大 为保证数据的平稳性，模型中做对数处理

( <sup>2</sup>) 进( 出) 口依存度。 分别用 <sup>im</sup> 和 <sup>ex</sup> 表示。 本文构建进( 出) 口依存度指标表示中国对某个国家出口或进口的依赖程度，以分析汇率影响<sup>OFDI</sup> 的渠道，用该国的出( 进) 口额占中国总出( 进) 口额的比重衡量。值越大，表示中国对东道国的出(进)口依赖程度越高。数据来源于国家统计局。为保证数据的平稳性，模型中做对数处理

## <sup>3．</sup> 控制变量

参考 <sup>OFDI</sup> 动机的相关研究( <sup>Buckley et al．</sup>，<sup>2007</sup>; 王永钦 等，<sup>2017</sup>) ，本文选取如下控制变量:

( <sup>1</sup>) 东道国市场规模。 以各东道国的 <sup>GDP</sup> 总量衡量市场规模，市场获取是中国 <sup>OFDI</sup> 的重要动机。

( <sup>2</sup>) 东道国生活水平。 以各东道国人均 <sup>GDP</sup> 来衡量。

( <sup>3</sup>) 东道国资源禀赋。 以燃料 金属和矿石出口占总出口的比重衡量，获取能源资源是中国企业对外投资的另一个主要动机。

(4)东道国总税率。以东道国所有企业缴税额占商业利润的比例表示，以衡量东道国的投资商业环境和经济自由度

以上数据均来自于世界发展指标( <sup>WDI</sup>) 数据库

( <sup>5</sup>) 经济结构 以东道国第三产业产值占比表示

( <sup>6</sup>) 地理距离。 参考张夏等( <sup>2019</sup>) ，以中国与东道国最大城市人口加权的地理距离表示。

( <sup>7</sup>) 中国与东道国的制度差异 全球治理指标( <sup>WGI</sup>) 构建了衡量制度质量的六大指标体系，分别为话语权与问责 政治稳定与无暴力<sup>/</sup>恐怖主义 政府效率 监管质量 法治水平 腐败控制，每一维度指<sub>标范围在</sub> － 2． 5 ～ 2． 5 <sub>借鉴</sub> Kogut et al．<sub>(</sub> 1988<sub>) 许家云等(</sub> 2017<sub>) 李建军等(</sub> 2019<sub>) ，本文采用</sub> KSI <sub>指数</sub>法来测算中国与东道国的制度距离 计算公式如下:

$$
\mathrm{WGIdist} _ {\mathrm{ct}} = \frac {1}{\mathrm{N}} \sum_ {\mathrm{k} = 1} ^ {\mathrm{N}} \left(\mathrm{I} _ {\mathrm{kt}} - \mathrm{I} _ {\mathrm{ckt}}\right) ^ {2} / \mathrm{V} _ {\mathrm{k}}\tag{13}
$$

其中， $\mathbf { \sigma } _ { \mathbf { \lambda } ^ { \mathrm { { J } } } } ^ { } , \mathrm { { I } } _ { \mathrm { { k t } } }$ 是 <sup>t</sup> 年中国在第 <sup>k</sup> 个制度质量维度上的得分， ${ \bf \Omega } _ { \sf { 1 } _ { c k t } }$ 是<sup>t</sup> 年<sup>c</sup> 国在第 <sup>k</sup> 个制度质量维度上的得分， $\mathrm { \Delta V _ { k } }$ 为第<sup>k</sup> 个制度质量维度分数的方差，<sup>N</sup> 表示维度个数 据此，可以得到中国与东道国之间的制度距离指标，该指标越大，表明中国与东道国之间的制度差异越大 数据来源于世界银行的全球治理指标( <sup>WGI</sup>)

## ( 二) 内生性问题

汇率变动与中国对东道国直接投资之间可能存在内生性问题 基准回归控制了东道国市场规模生活水平 资源禀赋 总税率 产业结构等一系列特征变量以及中国与东道国之间的地理距离 制度差异，以缓解遗漏变量偏误 但汇率变动本身与中国的 <sup>OFDI</sup> 之间可能存在因果关系 一方面，汇率变动会影响企业 <sup>OFDI</sup> 的成本，从而影响着中国企业在东道国投资建厂的决策选择。 另一方面，假如某一时期出现较大规模的资本外流，人民币汇率将会承受贬值压力。 为解决上述内生性问题，借鉴张夏等( <sup>2019</sup>) 的研究，本文先引入滞后一期的汇率变动指标进行回归，结果见表<sup>4</sup> 的列( <sup>1</sup>) ( <sup>3</sup>) ( <sup>5</sup>) ; 再将滞后一期的汇率变动指标作为工具变量，用两阶段最小二乘法<sup>2SLS</sup> 进行工具变量回归，结果见表<sup>4</sup> 的列( <sup>2</sup>) ( <sup>4</sup>) ( <sup>6</sup>) 总体来看，汇率变量的系数仍然在<sup>1%</sup>显著性水平上为正，且汇率变量与进( 出) 口依存度的交互项系数的正负和显著性水平无变化。 表明考虑了内生性问题之后，回归结果没有发生改变，本文的研究结论稳健。

中国对不同经济发展水平国家的 <sup>OFDI</sup> 无论是在投资的动机还是投资模式上均存在很大差异，因此，有必要分样本分析人民币汇率水平变动对不同国家( 地区) 投资的差异性。 本文将中国对外投资的东道国区分为发展中国家和发达国家两组，回归结果如表<sup>5</sup> 和<sup>6</sup> 所示

## 六、结论和政策建议

随着<sup>“</sup>走出去<sup>”</sup>战略持续推进，中国的 <sup>OFDI</sup> 屡创新高 伴随着人民币汇率形成机制市场化改革，汇率变动成为常态，波动幅度不断加大，本文考察其中的作用机制 为此，本文首先构建了一个理论模型，发现本币升值促进对外直接投资，并通过出口依存度和进口依存度两个渠道发挥协同作用 其次，基于中国对<sup>131</sup> 个国家<sup>2005</sup>—<sup>2017</sup> 年 <sup>OFDI</sup> 的面板数据，实证研究了人民币汇率变动对中国 <sup>OFDI</sup> 的影响，<sub>: ，</sub> OFDI<sub>，</sub>且，对东道国的出口依存度或进口依存度越高，人民币升值越能促进对该国的 <sup>OFDI</sup> 第二，汇率变动对中国 <sup>OFDI</sup> 的影响存在国别差异。 汇率升值没有通过进出口渠道对投资于发达国家的 <sup>OFDI</sup> 产生影响，但却对发展中国家的 <sup>OFDI</sup> 有正向作用。 这可能与中国对不同经济发展程度国家的 <sup>OFDI</sup> 有不同的投资动机有关。 第三，对于汇率波动和中国对外投资的研究表明汇率波动与 <sup>OFDI</sup> 显著负相关，即汇率波动对中国的对外投资有抑制作用，但这一关系与中国对该东道国进( 出) 口依存度无关，意味着人民币汇率波动不会通过进、出口渠道影响中国的 <sup>OFDI</sup>。

本文的研究对于协调中国的 <sup>“</sup>走出去<sup>”</sup>战略和汇率制度改革有重要的政策启示意义。 人民币汇率升值尽管不利于出口贸易，却可以推动中国 <sup>OFDI</sup> 的增加，特别是，当中国对东道国的出口依存度越高，人民币升值对流向该国的 <sup>OFDI</sup> 促进作用越明显。 这说明，不应仅关注汇率变动对出口及对外投资的单方面作用，更应关注对二者的协同影响，政府对外汇市场的调控应注意汇率变动对出口及对外投资二者的协调。 对于那些与中国贸易往来密切的国家来说，双边汇率变动对投资的影响会加倍放大，这是政府在调控外汇市场时需要特别注意的 汇率市场化是未来中国汇率制度改革的方向，波动不可避免，未来可以通过开发和推广系列规避汇率风险的产品，降低汇率波动对企业对外投资的负面影响。
