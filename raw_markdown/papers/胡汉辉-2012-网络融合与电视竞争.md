# 网络融合与电视竞争

胡汉辉

摘 要 信息与通信技术的发展带来了电信 广电等泛通信产业的融合 这一融合带来了具有颠覆性创新的数字电视产品，这种创新要求电信与广电产业的规制制度做出相应调整，也会导致市场结构与企业行为的相应变化 课题 <sup>“</sup>网络融合与电视竞争<sup>”</sup> 正是在泛通信产业融合的背景下，分析变化中的电视产业 本课题期望以现代产业组织理论等为基础进行规范的经济学与管理学研究，试图建立电视产业竞争与规制的分析框架，探寻电视产业的演化规律这一课题既是主持人与其团队多年来致力于泛通信产业及产业融合领域研究的理论应用与探索，也是主持人近年来通过为企业与政府提供决策咨询等方式参与产业实践的经验总结与思考

关键词 网络融合 电视竞争 数字电视 产业实践

## 二 现实背景

自 20 世纪 70 年代以来，信息及通信技术 ( information and communicationtechnolo ，ICT) 取得了迅猛发展，推动了宽带通信网 数字电视网以及下一代互联网的融合，即 <sup>“</sup>三网融合<sup>”</sup> 这种以三网融合为代表的网络基础设施的融合具有以下基本特点 第一，一网多用: 一个网络能够提供多种服务，相对应的一个网络终端将具有多功能的属性 比如有线电视网可以提供电视宽带和电话服务 第二，多种提供来源: 相同的服务或内容能够由不同类型的网络 ( 基础设施或媒介) 来提供 比如电视服务可以由有线电视网提供，可以从卫星接收，也可以由宽带网提供 第三，功能组合: 厂商可以组合不同服务，从而提供更加有效的服务 ( 或更复杂的) 内容 以 IPTV 为例，运营商可以将电视的功能和互联网的功能相结合，比如对电视实时表演进行在线投票 第四，协同工作: 不同的基础设施协同工作，从而执行一种功能或拓展功能 比如宽带网和有线电视网可以协同工作，前者提供互动或点播服务，后者提供广播服务 ( 顾成彦 胡汉辉，2008)

数字电视是在网络融合的背景下发展起来的 目前传播数字电视的方式有多种，包括与传统模拟电视相似的，地面 ( terrestrial) 有线 ( cable) 卫星 ( cable) 传输方式，也包括由电信运营商所提供的 IPTV ( 基于互联网协议的电视传输) 如果深入电信<sub>、</sub> 电视等媒体以及互联网产业的内部，我们可以发现融合不仅仅限于作为基础设施的网络，由数字技术所推动的网络融合将 <sup>“</sup>融合<sup>”</sup> 沿着通信产业链向上游和下游扩散 ( 胡汉辉 邢华，2003)

下游出现了终端的融合，比如智能手机兼具通话 上网以及游戏功能，甚至可以通过手机收看电视 终端融合使得消费者可以通过一个终端享受到 <sup>“</sup>一站式服务<sup>”</sup> 的优点，消费者可能会选择一家运营商提供一揽子服务，这无疑将加剧市场竞争 上游的内容提供也会出现融合的趋势，同样的内容可以采取相同或不同的形式展现在电视 个人电脑以及手机终端上，我们不仅可以通过相关播放软件在电脑上收看传统的电视内容，也可以通过电视收看原来专在电脑上播放的内容如 flash 在上游服务环节，我们也可以看到许多融合的现象，比如即时通服务 ( Instant Messa e) 原来只是针对个人电脑用户，但是随着互联网产业和移动通信产业的融合，这项服务也扩散到手机用户，比如中国移动的飞信业务，移动 QQ 等<sub>。</sub> 综上所述，融合不仅仅发生在产业的基础设施环节，而且是逐渐遍布电信 广播 互联网等产业的所有环节 ( 如图1 所示) 自1996 年美国颁布新 《电信法》 以来，西方发达国家已经拥有十多年三网融合的实践，但产业的融合还远远没有结束<sub>。</sub> 究其原因，三网融合涉及不同产业链上的相关企业，不同政府部门，以及广大消费者 只有利益相关人相互协调，共同努力，三网融合才能为人类经济与社会带来更大福祉 ( Wan，Hu，Wu，2009) 下文将简述世界范围内三网融合的趋势以及中国三网融合的进展

## ( 一) 世界范围内三网融合的趋势

自20 世纪90 年代末以来，世界范围内兴起了一波三网融合的发展浪潮<sub>。</sub>围绕着数字传输网络，出现了大量的新兴业务，如 IP 电话 ( V<sub>o</sub>i<sub>ce over</sub> I<sub>n</sub>t<sub>er-</sub>net Protocol，简称 VoIP) IPTV 网络电视 ( Broadband TV) 超移动宽带( Ultra Mobile Broadband) 移动电视 ( Mobile TV) ，等等 对于世界各国的网络运营商而言，这些都将是一次前所未有的机遇与挑战: 在网络融合时代，传统的业务将不足以维持网络运营商的竞争优势和市场地位; 在日新月异的新兴业务面前，传统的网络运营商将持续面临新兴业务运营商的挑战，其在网络融合的进程中稍有怠慢便有可能被新进入者完全替代 事实上，各国政府都已注意到了网络的融合化发展趋势，他们都在积极谋划如何把握住此次网络融合的发展契机，以进一步推动经济的高速发展<sub>。</sub> 以英国为例，其政府机构为促进本国的网络融合发展，于2003 年推出了新的 《通信法》，将原有的五家主要的规制机构: 电信管理局 ( OFTEL) 无线电通信管理局( RCA) 独立电视委员会 ( ITC) 无线广播管理局 ( RA) 播放标准委员会( BSC) 进行了整合，成立了新的规制机构———通信管理局 ( OFCOM) ，由其全面负责电信 电视和无线电的市场监管<sub>。</sub>

在网络融合的趋势下，电视业得到长足的发展 ( 见表1) 电信网络运营商和有线网络运营商可以利用自身的网络媒介相互进入对方的业务市场，此时便产生了IPTV 业务和VoIP 业务，即电信网络运营商可以通过 IPTV 业务进入数字电视市场，而有线网络运营商可以通过 VoIP 业务进入固定电话市场<sub>。</sub>通常而言，有线运营商开展的数字视频播放业务为 DTV ( Di<sub>g</sub>ital TV) ; 而所谓的 IPTV 业务，一般泛指通过 IP 网络传输用电视机收看的视频内容业务与 DTV 不同，IPTV 业务通常是由电信运营商通过提供 VDSL 的传输从而进入广播级的视频服务

## ( 二) 三网融合下的电视企业行为与市场结构

三网融合催生了新的产品和市场，运营商开始提供跨市场的产品和服务表2 显示，英国八大通信运营商都提供基于融合的捆绑服务，其中前四个运营商提供的捆绑服务中包括了电视服务 越来越多的用户不再是分别仅从电信运营商那里购买电信服务，和仅从电视运营商处购买电视服务，而是从某个运营商处购买捆绑的电信和电视服务 这种捆绑的服务一般包括固定电话，宽带以及多频道电视，即三合一服务 ( <sup>“</sup>tri<sub>p</sub>le － <sub>p</sub>la<sub>y</sub><sup>”</sup>) <sub>。</sub> 2009 年，英国有44%的家庭购买捆绑的通信服务，这比2005 年的12%提高了32 个百分点<sub>。</sub>

## ( 三) 中国三网融合的进展

网络融合受到了我国政府的高度重视，国家 <sup>“</sup>十一五<sup>”</sup> 规划纲要中明确指出: <sup>“</sup>加强宽带通信网 数字电视网和下一代互联网等信息基础设施建设，推进 <sup>‘</sup>三网融合<sup>’ ”</sup> 但与世界发达国家相比，我国的三网融合进程明显滞后，且受到了多种因素的共同制约 其中最根本的制约因素在于政府设置于电信运营商和有线运营商之间的相互进入的政策壁垒 在我国现行的政策体制下电信是产业部门，追求的是经济效益; 广电是宣传部门，按事业体制运行，强调公共福利 这一定位直接造成了我国电信网络和有线网络市场化改革上的种种差异 在进入规制政策方面，到2009 年年底电信系统和广电系统仍处于互不准入状态: 一方面，电信运营商无法获得视频播放许可证，从而无法开展视频传输业务; 另一方面，有线运营商无法获得号码频谱资源，从而无法开展语音传输业务 在此大背景下，电信系统的网络运营商与广电系统的网络运营商在开展融合业务时只能各显其能 打擦边球，这极大地抑制了融合业务市场的发展和三网融合进程的整体推进 下文将简述中国三网融合的进展

1999 年国务院下发 《关于加强广播电视线网络建设管理的意见》，该文件禁止电信和广电两大行业相互渗透，并明确网络融合利用的试点只在上海进行该文件将有线网络限于广播电视业务，将电信网络限于互联网与语音业务 该政策人为限制了网络的技术功能与商业价值，导致了广电运营商与电信运营商的十多年的不对称发展，并给未来数字电视产业的发展留下了不利因素

2008 年国务院第一号文件 ( 国办发 〔2008 〕 1 号) 要求加强宽带通信网 数字电视网和下一代互联网等信息基础设施建设，推进 <sup>“</sup>网络融合<sup>”</sup>虽然该文有利于进一步推动我国数字电视产业的发展，但并未解决 <sup>“</sup>谁来规制数字电视产业<sup>”</sup> 这一问题，并且没有提出三网融合的具体措施

2010 年1 月13 日国务院常务会议决定加快推进宽带通信网<sub>、</sub> 数字电视网和下一代互联网的融合 ( 简称 <sup>“</sup>三网融合<sup>”</sup> 或 <sup>“</sup>网络融合<sup>”</sup>) 会议提出了推进三网融合的阶段性目标，2010—2012 年重点开展广电和电信双向进入的试点，2013—2015 年全面实现三网融合发展 一号文件的出台和国务院常务会议的召开体现了数字电视产业和三网融合的战略意义，也说明数字电视产业的发展仍然任重而道远 这标志姗姗来迟的三网融合终于进入实质性阶段 2010 年7 月1 日，国务院公布了第一批三网融合试点城市名单 至此，三网融合在全国拉开序幕<sub>。</sub> 图3 显示，到2010 年年底，中国有线数字用户超过 8800 万户，IPTV 用户也达到了 800 万户<sub>。</sub>

2010 年前上海和哈尔滨等地的实践表明，我国电信网和有线网两大实体网络融合的端倪出现在电信运营商借助IPTV 业务对数字电视市场的进入和渗透<sub>。</sub> 三网融合丰富了数字电视市场中的竞争主体，使电信运营商和有线运营商之间得以展开交叉媒介竞争<sub>。</sub> 上海作为全国首个三网融合试点城市，政府部门的不介入政策造就了上海特殊的网络渗透与融合的市场环境 在以固定电话 数字电视和互联网三大业务形态组成的复合市场中，中国电信上海市分公司 ( 简称 <sup>“</sup>上海电信<sup>”</sup>) 和原隶属于广电系统的 <sup>“</sup>东方有线网络有限公司<sup>”</sup> ( OCN，简称 <sup>“</sup>东方有线<sup>”</sup>) 是两家竞争性的网络平台运营商 其中，上海电信在开展固定电话和宽带接入业务的同时，还利用其自身与上海文广集团合资组建的 <sup>“</sup>百视通网络电视公司<sup>”</sup> 的 IPTV 业务进入了数字电视市场;而东方有线在主营有线数字电视的同时，还推出了 <sup>“</sup>有线通<sup>”</sup> 业务进入了宽带接入市场 截至 2009 年年底，上海电信的数字电视用户数达到 80 万户，宽带用户数达307 万户; 东方有线的数字电视用户数达到85 万户，宽带用户数达30 万户<sub>。</sub>

## 三 课题的相关实践

在本课题的有关前期与研究过程中，课题主持人主持或作为技术负责人完成了如下相关企业委托课题: <sup>“</sup>城市数字电视竞争模式与发展策略研究<sup>”</sup>(2007) <sup>“</sup>江苏省有线电视数字化工程规划研究<sup>”</sup> (2008) <sup>“</sup>中国广播电视的市场化转型与服务创新<sup>”</sup> ( 2009) 以及 <sup>“</sup>中国有线重组方案预研究<sup>”</sup>(2010) 等，受到了委托方的重视和认可<sub>。</sub>

<sup>“</sup>城市数字电视竞争模式与发展策略研究<sup>”</sup> 以我国城市数字电视产业的发展为现实背景，以产业组织理论等为理论基础，采用调查研究<sub>、</sub> 案例分析等方法研究了城市数字电视运营商的发展模式和竞争策略命题，指出了处于产业周期不同阶段的平台运营商可能的发展模式选择<sub>。</sub> 本课题成员调研了南京 上海 杭州等地的城市数字电视运营商，在总结国内外电视运营商运营经验的基础上，结合目前中国电视产业的市场结构与相关制度，为委托方提出了如下建议: 实施网络融合趋势下的市场渗透策略，发展互动电视的付费盈利模式，基于捆绑销售实现差别化营销，利用双边市场发展自身的平台优势<sub>。</sub>

<sup>“</sup>江苏省有线电视数字化工程规划研究<sup>”</sup> 课题，正值江苏有线电视产业的发展期 当时省有线网络的整合基本完成， <sup>“</sup>一省一网<sup>”</sup> 的基础架构，使推进全省数字化 做大做强广电产业 促进广播电视网络占据未来多媒体运营服务市场的制高点成为可能 《规划研究》 论证了江苏省网络公司 <sup>“</sup>模拟电视数字化 数字电视互动化 互动电视市场化<sup>”</sup> 发展战略的合理性和可行性 认为模拟电视数字化是数字技术革命对电视产业的要求 完成由模拟电视到数字电视的跳跃，广播电视产业将成为现代媒体，为自身的发展开辟新的宽阔道路 通过数字化，有线网络公司可以提供语音 视频和文本三位一体的多媒体服务，具备跨产业竞争的基本条件 数字电视互动化将传统电视从信号接收工具变成了一个家庭智能的多媒体学习和娱乐终端 在网络融合的时代，数字电视的互动功能是跨市场竞争的现实要求 实现数字电视的互动化要求在有线电视网络的升级化改造中统筹规划 一步到位 有线数字电视要将互动化竞争优势转化为胜势就必须以市场为导向，深入研究用户需求的特点，基于自身的资源和能力，不断开发与创新合适的商业模式 建议有线运营商深入挖掘互动电视的优势，寻找高端业务，妥善处理产业链的关系，建立自身的核心竞争力

<sup>“</sup>中国广播电视的市场化转型与服务创新<sup>”</sup> 围绕两个方面的主题展开:新中国广播电视业的发展和市场化转型，以及因市场化转型而引发的服务创新问题 市场化转型主要从产业演化的视角进行讨论 既有时间维度的延伸，也有空间维度的展开 就时间维度而言，简略回顾了国内广播电视业从50 年代末以来的发展过程; 就空间维度而言，讨论了电视产业的数字化转换和国内有代表性城市广播电视的市场化转型 市场化转型部分重在发掘广电产业市场化转型的趋势，研究政策制定者的逻辑，分析运营商所面临的市场环境，剖析在三网融合背景下广电运营商的运营模式，特别关注数字化转换过程中及转换后，中国广播电视业如何实现自身的市场化转型 该项目还聚焦广电产业市场化转型中的内容创新与服务创新<sub>。</sub> 有线电视数字化带来的不仅是技术上的变化，更重要的是服务理念 服务方式 服务内容和体制机制的变化在网络融合的交叉竞争时代，建设与数字化发展相适应的内容制作与集成体系以及电视市场服务体系成为该产业发展的重中之重

## 四 本课题主要内容与观点

## ( 一) 主要内容

《网络融合与电视竞争》 ( 以下简称 《电视竞争》) 一书将构成本课题的主要成果 本书可分为: 网络融合前的电视竞争 网络融合的理论与实践以及网络融合后的电视竞争三部分<sub>。</sub> 下文将逐一介绍<sub>。</sub>

## 1. 网络融合前的电视竞争

信息与通信技术的发展使得电视从模拟时代跨入数字时代 数字电视是一项颠覆性创新，从此电视可以提供模拟时代所没有的产品与服务，比如视频点播 ( video on demand，VOD) 高清电视 ( hi h － definition TV，HDTV)网上购物 时移电视等 必须指出，数字电视产品与服务并不是在真空中提供的 数字电视的实施主体———电视运营商虽然吸纳了基于IPTV 的电信运营商，但是传统电视运营商，包括有线电视与卫星电视运营商迄今为止仍然是数字电视运营的主力军<sub>。</sub> 数字电视的消费者习惯了模拟电视的消费方式，比如被动看电视等 同时无论是在西方的公共电视制度，还是中国的公益性电视制度下，大量消费者习惯了免费看电视，这与数字电视运营商的巨额投资构成了矛盾<sub>。</sub> 从数字电视的规制看，虽然信息与通信产业的融合使得许多国家纷纷改组其规制机构，但是模拟时代的一些政策仍然在发挥作用，模拟时代的规制思维仍然具有巨大的影响力 就中国而言，由于缺乏 《电信法》 或《广播电视法》，电视规制仍然是国家广电总局为主导的多头规制 因此，数字时代的电视规制被深深地打上了模拟时代的烙印

综上所述，数字电视相对模拟电视是一种颠覆性创新，但是模拟电视产业的制度 市场结构与企业行为却很难在短时间内发生根本性改变，它们仍然深深影响着数字电视产业的制度 市场结构与企业行为 《电视竞争》 第一章从制度层面上分析了模拟电视产业，着重分析了1983 年出台的 <sup>“</sup>四级办广电<sup>”</sup> 政策以及1999 年出台的 <sup>“</sup>82 号<sup>”</sup> 文件 <sup>“</sup>四级办广电<sup>”</sup> 政策调动了地方政府投资广电产业的积极性，但是也造成了广电地方垄断的市场格局在网络融合的时代，广电分散的网络难以与电信的全程全网展开竞争 <sup>“</sup>82号<sup>”</sup> 文件规定电信和广电部门保持各自分工，彼此业务不得交叉 该文件虽然暂时稳定了市场秩序，却有悖产业长期发展的趋势，限制了企业的战略空间，降低了消费者福利

《电视竞争》 第二章剖析了模拟电视产业的技术 经济特点 电视节目属于信息产品，因此具有信息产品所具有的一些共性特征，比如，生产的高成本与复制的低成本，以及需求的异质性 除此以外，模拟电视还有其自身的某些特征，包括垄断性，准公共产品特性，网络经济特征以及双边市场特征 《电视竞争》 第三章基于双边市场理论建立数理模型分析了有线电视产业中存在的落地费现象

《电视竞争》 第一部分最后一章建立了 <sup>“</sup>状况—规制—结构—行为—绩效<sup>”</sup> ( conditions-re<sub>g</sub>ulation-structure-conduct-<sub>p</sub>erformance，CRSCP) 框架用以分析中国有线模拟电视产业 传统产业分析常常采用结构—行为—绩效 ( struc-ture-conduct- erformance，SCP) 的分析框架 该框架着眼于市场结构 企业行为和市场绩效的相互作用，具有较好的解释力 然而 SCP 框架对垄断产业或新兴产业缺乏解释力<sub>。</sub> 新兴产业往往伴随新技术和新的市场需求，而 SCP框架较少考虑技术进步和需求变化给产业带来的影响 同时由于没有考虑政府规制对产业的影响，SCP 框架也不适用于垄断产业的分析 ( Sti ler，1971;

Peltzman，1976) 电视产业既是垄断产业，同时也是面临技术迅速变化的产业 作为新兴产业，新技术改变了该产业中企业供给行为，新技术带来的新产品和服务也逐渐改变消费者的需求行为 作为垄断产业，一方面市场结构与企业行为受制于规制机构的政策，另一方面规制政策势必影响消费者福利

## 2. 网络融合的理论与实践

数字电视产业的发展是在 ICT 产业融合的大背景下展开的<sub>。</sub> ICT 产业的融合使得原有的电视市场边界变得模糊，以电信运营商为代表的新业者可以进入该市场提供 IPTV 移动电视等新形式的数字电视<sub>。</sub> 同时传统的有线电视运营商也可以凭借自己升级的有线网络，开展语音或宽带这样的电信业务这一网络型产业融合的过程本质上是技术创新<sub>、</sub> 产品/服务创新以及伴随的制度创新过程<sub>。</sub> 在这一过程中，后来者以创新的产品与服务进入市场，其产品与服务与原来市场中传统意义上的产品与服务存在较大差别 比如IPTV 可以实现与观众的互动功能，电视此时已经不是广播 ( broadcastin<sub>g</sub>) 性质的公共产品，而是窄播 ( narrowcastin ) 性质的私人产品 在这个意义上，ICT 产业的融合并不是简单意义上原有两个或多个产业的融合，融合后的新产业出现了新的产品与服务，这其实也是市场创造的过程<sub>。</sub> 这一过程是理解数字电视产业的大背景，也是 《电视竞争》 第一部分的重点

《电视竞争》 第一部分旨在通过对产业融合的分析，为第二部分 ( 网络融合下的市场竞争) 提供现实背景和理论基础 《电视竞争》 第二部分第一章 ( 《电视竞争》 初稿三部分的章节各自单独排序，正式出版时可能有所变动) 描述了包括国外以及中国网络融合的典型现象 在此基础上，第二章探讨了网络融合的相关理论，涉及网络型产业融合的定义 分类 融合与企业战略 政府规制以及消费者需求之间的关系 第三章讨论了产业融合下数字电视产业的经济和技术分析，重点分析了有线数字电视和IPTV 的竞争 从供给侧角度分析了有线数字电视与 IPTV 的技术特点与商业模式，从需求侧角度，该章还讨论了两者的目标市场以及共同面临的问题 他山之石，可以攻玉，第四章则分析了英国与美国数字电视产业的制度与市场竞争，希望通过这两个典型国家的数字电视产业分析为中国发展数字电视产业提供借鉴

尽管任何国家都有可能采用相似的技术，但由于不同的国家之间有不同的制度禀赋 市场结构以及人口特征，因而电视媒体重塑的过程和结果有可能大不相同 在这一过程中，发展中国家不仅将面临难以获得先进技术以及资金不足的问题，而且面临一些软环境的约束，比如缺乏独立的规制机构市场经济不健全 立法效率不高等 第五章则以中国为例，分析在网络融合环境下，中国模拟电视向数字电视转换过程中的相关问题

中国模拟电视向数字电视的过渡采用了政府主导下整体转换的形式 这种形式有利于推动模拟电视向数字电视的迅速过渡，可以解决因为消费者预期带来的转换延迟问题 然而由于缺乏有效的市场机制配合，整体转换也带来了收视率下降 价格上升 消费者投诉增加等问题<sub>。</sub> 本文认为，即使是政府主导下的整体转换也应该引入竞争 首先， <sup>“</sup>三网融合<sup>”</sup> 提供了竞争的可能性 ( 胡汉辉 沈华，2007) 其次，数字电视产业自身的发展提出了竞争的必要性 最后，从产业生命周期动态演化的角度看，原来的模拟电视产业已经成熟并走向衰退，数字电视产业还处于导入期<sub>。</sub> 在产业导入期，引入竞争不仅让产品的价格恢复正常，而且将新的产品和工艺引入市场，市场进入其实是一种市场创造过程

## 3. 网络融合后的电视竞争

第三部分聚焦网络融合后的市场竞争与规制问题 网络融合前的竞争是模式内竞争，网络接入是研究的重点 网络融合后的竞争是模式间的多平台竞争<sub>。</sub> 不同的平台运营商提供差异化的产品和服务，包括纵向差异化与横向差异化竞争，这是 《电视竞争》 第一章研究的重点 在多平台竞争中，运营商通常会采取捆绑的策略，以将自身在某个市场的市场势力延伸到另一市场，同时捆绑也可帮助运营商通过价格歧视增加利润 捆绑将是 《电视竞争》 第二章研究的重点<sub>。</sub>

网络融合使得传统的单用途网络向高级的多用途平台转变 网络融合带来了新的市场竞争形式，这种竞争不同于网络融合前的市场竞争 网络融合后，企业可以利用自己已有的资产，包括基础设施和客户资源，进入相关市场<sub>。</sub> 而网络融合前的市场竞争往往不是基于设施的 ( facilit<sub>y</sub> － based) 而是基于服务 ( service －based) 的，基于服务的竞争需要租用在位者提供的非绑定网元，这需要规制者的介入 而基于设施的竞争主要是市场问题，这要求放松与调整规制 因此，网络融合对现有的规制安排提出了巨大的挑战 这种挑战不仅涉及具体规制内容方面的重新考量，比如跨产业的兼并规制 ( 第三章) 和多产品的定价规制 ( 第四章) ，也涉及对来自不同产业的企业的不对称规制问题 ( 第五章)

规制挑战也涉及规制机构本身的改革与重建问题 ( 第六章) 网络融合下的规制重建除了规制内容体系调整之外 ( 模式间竞争的交叉进入规制 同时提供多个替代性产品的运营商的多产品定价规制以及具有过渡性质的扶持新进入者的不对称规制) ，可以说，规制机构调整是网络融合下规制重建的另一项重要任务，以从根本上解决目前泛通信规制中存在的机构重叠 多头管理以及网络融合下规制的 <sup>“</sup>真空区域<sup>”</sup> 等问题 胡汉辉 沈华 (2007) 指出，在技术融合的基础上，网络融合的程度进一步深化，一些产业的边界开始模糊甚至消失，市场中出现许多跨产业边界的新服务和新产业，原先基于分立产业的传统规制框架已不适应产业发展的要求 网络融合对规制机构重建至少存在两点影响: 一是产业边界的模糊导致监管内容的变化，而多数国家对这些产业的规制分别属于不同的部门 因此，规制内容的重叠限制了这些产业之间的信息交流 二是网络的融合导致监管权利的融合 政府规制机制的选择从本质上看是一种多委托人 多代理人和单一委托人 多代理人模式之间的选择

信息技术革命已经走过了个人电脑时代，目前正处于互联网时代 互联网的发展具有融合化与移动化的特点 第三部分的前六章在网络融合的背景下分析了泛通信产业现有的竞争与规制问题<sub>。</sub> 未来的网络融合不仅涉及目前的电视网络与电信网络，还将涉及物联网<sub>。</sub> 智能手机不仅可以作为移动互联网的终端，而且也是物联网的终端 基于智慧物体的物联网技术与应用已经初见端倪<sub>。</sub> 同时电视这一传统的媒介工具也将从模拟电视 数字电视发展到智能电视<sub>。</sub> 在这一历史背景下，第七章对物联网进行了初步的前瞻性研究，通过与互联网的类比，分析了物联网的经济性质<sub>、</sub> 价值来源以及基于物联网的商业模式，以站在一个更长的时间维度上考虑网络融合与电视竞争问题

## ( 二) 主要观点

基于上述三部分的主要内容，本课题的主要观点如下<sub>。</sub>

第一，有线电视和电信的互联互通问题是三网融合的基本问题和技术前提<sub>。</sub> 我国推动三网融合的战略举措势必对电视<sub>、</sub> 电信以及其他产业的发展产生深远的影响

第二，无论在模拟还是数字电视时代，电视产业都具有公益性和商业性两大基本特点 这两大特点将影响电视产业的市场格局，包括电视产业的市场进入 横向关系和纵向关系，将影响到电视产业的规制方式，并进一步影响到电视产业的绩效

第三，网络融合改变了数字电视产品/服务的基本特性 数字电视是在继承模拟电视的市场结构基础上发展起来的，但是数字电视具有不同于模拟电视的技术经济特点要求: 数字电视可以实现个性化的消费，电视的商业化特征将更加明显; 数字电视同时具有直接网络外部性和间接网络外部性; 数字电视具有多产品/服务范围经济的特点 这些特点要求与之相适应的新产业结构与规制制度

第四，在三网融合的背景下，原来的多个垄断产业将演化为多个寡头垄断产业，这种竞争有别于原来垄断产业中基于服务的模式内竞争，而是不同平台的模式间竞争; 在多市场竞争中，不同平台会选择差异化 混合捆绑等战略，企业也可能在不同市场中选择不同的商业模式，双边市场模式将日趋重要<sub>。</sub>

第五，三网融合给产业规制带来了巨大的挑战 首先，过去按照产业分设的规制机构需要重组以适应产业融合的要求; 其次，不断发展的网络融合与产业融合要求规制机构重视跨期影响，垄断的市场结构可能比竞争更能促进动态效率的实现; 最后，规制机构需要关注产业链的不同环节间的互动，包括内容制作 集成与传输环节

第六 数字电视和电信产业的互联互通 双向进入势必给物联网的发展创造契机<sub>。</sub> 因此，研究电视竞争是深化电信竞争研究<sub>、</sub> 探讨多网融合与发展的突破口之一，具有明显的理论和实践意义

## 五 结语

自2000 年拉丰和泰勒尔合作出版 《电信竞争》 ( 该书的中文版 2001 年出版，于2002 年获第13 届 <sup>“</sup>中国图书奖<sup>”</sup>，本课题主持人是该中文版的主译者) 以来，电信 电力 航空等具有 ( 或部分具有) 自然垄断特性的产业的竞争和垄断状况发生了很大的变化<sub>。</sub> 其中，网络融合现象越发受到人们的关注，从多个角度开拓了人们的视野，较大地改变了人们以往对自然垄断产业竞争与规制问题的传统看法<sub>。</sub> 作为网络之间的需求功能整合过程，网络融合从纵向看可以被视为网络运营商之间商业模式的融合过程; 从横向看，可以被看做网络运营商的平台包络市场进入过程<sub>。</sub>

在传统具有 ( 或部分具有) 自然垄断特性的产业的竞争和垄断状况发生变化的同时，电视产业，尤其是有线电视产业的发展加深了人们对自然垄断产业的理解: 有线电视的网络产业和内容产业的融合 ( 网台合一) 使得网络产业的垄断和规制问题更加复杂，同时也给网络产业的发展以巨大的空间<sub>。</sub>

随着国务院2010 年1 月13 日常务会议做出的有关决定，我国实际开始了大力推进三网融合 ( 即宽带通信网 数字电视网和下一代互联网的融合)的过程，本课题 《网络融合与电视竞争》 以现实中涌现出的网络融合现象为背景，通过分析国内外电视产业发展的典型化事实，提炼并探讨电视产业发展与改革中的有关经济与管理问题，特别是三网融合过程中数字电视产业发展的若干问题 本课题主要从产业组织的角度分析电视产业的 <sup>“</sup>状况—规制—结构—行为—绩效<sup>”</sup> 特征，讨论在替代性 ( 颠覆性) 技术的冲击下，模拟电视产业如何向数字电视产业演化，以及这种演化相应带来的与传统电信产业的竞争与合作关系<sub>。</sub> 通过对电信网 互联网 物联网等融合发展环境下的合作 竞争 规制等关系的研究，较系统地总结了 《电信竞争》 出版十年来电信 有线电视等网络型产业的改革和发展问题，为寻求具有中国特色的网络型产业的发展模式提供了理论支持 课题成果将为相关政府管理部门的产业政策制定和规制决策提供参考，为包括电视产业在内的泛通信产业的企业战略和战术决策提供帮助
