# 生产性服务进口能否提高企业加成率

李宏亮，谢建国，葛阳琴

(南京大学经济学院，南京210093)

摘 要: 生产性服务进口是制造业企业获取中间投入的重要渠道<sub>。</sub> 利用联合国贸发会议数据和中国工业企业匹配数据系统考察了生产性服务进口对企业加成率的微观影响及其作用机制<sub>。</sub> 研究发现，生产性服务进口显著提高了企业加成率; 细分行业的异质性检验显示，金融<sub>、</sub> 运输和通讯以及科技服务业进口对企业加成率的促进效应更为明显; 进一步地研究表明，高服务使用率企业 东中部企业和民营企业从生产性服务进口中获益更大; 最后，中介效应模型检验表明，生产效率和研发水平提升是生产性服务进口提高企业加成率的可能渠道

关键词: 生产性服务进口; 企业加成率; 中介效应模型

## 一<sub>、</sub> 引言

中国自2001 年加入 WTO 以来，积极推进服务部门贸易自由化，在经历了2002 －2006 年5 年的过渡期之后，在运输及通讯 金融 科技服务等许多重要领域实现了不同程度的开放，由此也引起了服务进口的快速增长 2001 年中国生产性服务进口规模为242.76亿美元，2007 年增加至 965. 64 亿美元，2016 年达到1798. 70 亿美元; 从增速来看，入世后 (2002 － 2007年) 年均增长率为 26.58%，远高于入世前 (1999 －2001 年) 的 14.36% 那么，中国生产性服务进口的大幅增加是否会影响企业的服务要素投入进而引起其市场竞争能力的变化? 由于加成率反映了企业将其产品或服务的价格维持在边际成本之上的能力，能否保持较高加成率是企业动态竞争能力的重要标志之一(任曙明和张静，2013)<sup>［1］</sup> 生产性服务进口不仅为制造业企业提供 <sup>“</sup>质优价廉<sup>”</sup> 的服务进口中间品，而且其带来的国外技术和资本含量更高的服务要素能够有效提高企业研发和生产效率，进而影响企业的市场竞争和定价能力 因此，研究生产性服务进口与企业加成率的内在联系，可以为中国更好地推进服务贸易体制改革和持续提升企业竞争能力提供有益的政策启示<sub>。</sub>

与本文密切相关的一类文献是研究生产性服务进口与制造业绩效的关系 这类文献大多认为生产性服务进口有利于提高制造业生产率和技术进步 (Francois和 Woerz<sup>［2］</sup>，2007; Nordas<sup>［3］</sup>，2008) <sub>。</sub> 在以中国为研究对象时，唐保庆等 (2011)<sup>［4］</sup>运用跨国面板数据研究表明，生产性服务进口通过技术溢出效应促进了中国制造业技术进步; 戴翔和金碚 (2013)<sup>［5］</sup>的研究认为，技术含量更高的生产性服务进口有利于中国工业经济发展方式转变; 陈启斐和刘志彪 (2014)<sup>［6］</sup>通过测算制造业使用的生产性服务进口含量分析对制造业技术升级的作用，他们的研究结论支持了唐保庆等(2011)<sup>［4］</sup>的观点; 姚星等 (2017)<sup>［7］</sup>利用 <sup>“</sup>一带一路 <sup>”</sup>沿线国家数据，研究表明生产性服务进口显著提高了制造业出口技术复杂度<sub>。</sub>

与本文相关的另一类文献是关于企业成本加成的影 响 因 素 研 究 <sub>。</sub> 理 论 方 面， Melitz 和 Ottaviano(2008)<sup>［8］</sup>通过构建异质性企业垄断竞争模型，首次证明了在开放经济条件下生产率越高的企业具有越高的加成率的结论; Kugler 和 Verhoogen (2012)<sup>［9］</sup>通过将生产要素和产品质量纳入异质性企业贸易模型，分析表明，在其他条件相同的情况下，出口高质量产品的企业可以索取更高的加成率 相比之下，更多的文献是从实证角度考察成本加成的影响因素 Tybout(2003)<sup>［10］</sup>从市场竞争角度讨论对企业加成率的影响，研究发现面临进口竞争越激烈的行业其企业具有越低的加成率; 钱学锋等 (2016)<sup>［11］</sup>利用中国企业数据也得出类似的结论; Konings 和 Vandenbussche (2005)<sup>［12</sup>使用欧盟制造业企业反倾销案例数据研究了贸易政策的作用，结果发现，一国实施的反倾销保护政策促进了本 国 企 业 加 成 率 的 提 高; De Loecker 和 Warzynski(2012)<sup>［13］</sup>利用斯洛文尼亚制造业企业数据考察了贸易自由化政策的影响，实证结果表明，贸易自由化有利于提高出口企业的加成率; Bellone et al. (2016)<sup>［14］</sup>则考察了产品质量对企业加成率的影响，他们的研究认为，出口产品质量越高的企业可以索取越高的加成率另外一些学者在研究中国企业加成率问题时却得出了相佐的结论，比如盛丹和王永进 (2012)<sup>［15］</sup> 刘啟仁和黄建忠 (2015)<sup>［16］</sup>等的研究发现，中国企业的出口产品价格远低于国内价格，导致出口企业陷入 <sup>“</sup>低加成率陷阱<sup>”</sup>，他们将这种现象归咎于政府长期实施的出口退税和补贴政策，国内市场分割以及出口企业之间的过度竞争

通过上述文献梳理不难发现，学者们对生产性服务进口与制造业技术升级的关系以及成本加成的影响因素进行了大量研究，但是甚少有文献研究生产性服务进口对企业成本加成的作用 鉴于此，本文利用联合国贸发数据库和中国工业企业匹配数据，系统考察生产性服务进口对企业成本加成率的作用，并进一步利用中介效应模型检验其影响路径 本文可能的创新之处在于: 第一，尽管有不少文献对成本加成的影响因素进行了深入研究，但是忽视了服务贸易的作用，本文从生产性服务进口角度直观探讨了对企业加成率的影响机制，为研究成本加成问题提供了新的视角和思路; 其次，从研究内容来看，本文全面考察了生产性服务及其细分行业进口对企业加成率的异质性影响，并且利用中介效应模型检验生产性服务进口对企业加成率的可能渠道，得到了更为丰富的结论，这在一定程度上拓展和深化了现有研究; 最后，本文采用超越对数生产函数形式测算企业加成率，弥补了传统会计方法存在人为调整会计利润导致估计结果偏差的不足，可以得到一个更为可靠的结果

## 二<sub>、</sub> 理论分析与研究假设

加入 WTO 以来，中国积极推进服务贸易领域开放，服务贸易呈现快速增长态势，其中生产性服务进口规模由2001 年的242.76 亿美元，增加到 2007 年的965. 64 亿美元，年均增长率达 26. 58% 那么，生产性服务进口如何影响企业加成率? 由于企业加成率被定义为产品价格对其边际成本的偏离，因此任何引起产品价格和边际成本变动的因素至少在短期内都有可能对 企 业 加 成 率 产 生 作 用 ( 孙 辉 煌 和 韩 振 国，2010)<sup>［17］</sup><sub>。</sub> 理论上分析，生产性服务进口可通过以下渠道影响企业的产品定价和边际成本: 首先，生产性服务进口通过提升生产效率影响企业的边际成本 原因在于，生产性服务进口不仅为制造业企业提供了<sup>“</sup>质优价廉<sup>”</sup> 的国外服务要素投入，节约商务活动<sub>、</sub>融资<sub>、</sub> 分销等生产和运输成本 (Bas，2014)<sup>［18］</sup>; 同时也会加剧国内服务供给商竞争，促使国内服务供给商不断改进服务质量，有利于降低企业经营成本 (Ar-nold et al. ，2011)<sup>［19］</sup>，从而提高企业生产效率; 而生产效率的提高可以有效降低单位产品生产成本 (Melitz和 Ottaviano，2008)<sup>［8］</sup>，进而促进企业成本加成 <sub>。</sub>

其次，生产性服务进口可通过促进企业研发影响企业的产品创新和定价能力<sub>。</sub> 这是因为，生产性服务具有较高的技术和资本含量，使用较多的该类服务投入，能够有效促进企业改进生产工艺 管理方式和技术革新 ( Arnold et al. <sup>［19］</sup>，2011; 张艳等<sup>［20］</sup>，2013)，从而增强企业创新和提高产品质量，提升其产品定价能力; 另一方面，企业在研发过程中通常有大量资金需求，增加使用金融保险等生产性服务进口可以在一定程度上缓解企业外部融资压力，为其研发活动提供资金支持和风险保障，从而激励企业提高研发水平，最终影响企业的成本加成定价能力<sub>。</sub> 因此，综合以上分析，我们提出以下两个待检验研究假设:

假设1: 在其他条件不变的情况下，生产性服务进口有利于提高企业加成率

假设2: 生产性服务进口通过提高企业生产率和促进研发等渠道影响企业加成率

## 三 计量模型设定 指标和数据说明

## (一) 计量模型设定

为了检验假设1，本文将基准计量方程设定为:

$$
\begin{array}{r l} \ln m k p _ {i j k t} & = \alpha_ {0} + \alpha_ {1} \ln F H _ {j, t - 1} + \delta X _ {i j k, t - 1} + \eta_ {j} + \zeta_ {k} + \xi_ {t} \\ & + \varepsilon_ {i j k t} \end{array} \tag {1}
$$

其中，i <sub>、</sub> j <sub>、</sub> k <sub>、</sub> t 分别表示企业<sub>、</sub> 行业<sub>、</sub> 地区和年份，被解释变量 mkp 为企业加成率，FH 指数为核心解释变量，表示制造业使用的生产性服务进口含量，具体测算方法见下节<sub>。</sub> $X _ { i j k , t }$ 表示影响企业加成率的其他控制变量，主要包括: 企业规模 (size)，用企业年均从业人数表示; 企业经营年限 (age)，用 <sup>“</sup>观测年份 －注册成立时间 +1<sup>”</sup> 表示; 资本劳动比 ( kl )，用企业总固定资产与年均从业人数的比值表示; 资本产出比 (kc)，用固定资产合计与工业总产值的比值表示; 中间投入要素比 (pinput)，用中间要素投入合计与工业总产值的比值表示; 平均工资 (pwage)，使用本年应付工资总额与年均从业人数比值表示; 行业集中度 (hhi)，用 2 分位行业的赫芬达尔指数表示，计算公式为: $h h i \ = \ \sum _ { j \mathop { = } 1 } ^ { n } \ \left( s a l e _ { i j } \Big / \ \sum _ { i \mathop { = } 1 } ^ { n } s a l e _ { i j } \right) ^ { 2 }$ ; 企业出口密集度 (expint)，用企业出口额占销售额的比重表示<sub>。</sub>考虑到样本期间内中国进行国有企业改革和放松外资管制对企业加成率的可能影响，这里引入国有企业占比 (soeshare) 和外资进入 ( fdi) 进行控制，分别使用国有企业数量占内资企业数量比重<sub>、</sub> 各行业外资企业数目表示<sub>。</sub> $\xi _ { j } \setminus \eta _ { k } \setminus \gamma _ { t }$ 分别为行业<sub>、</sub> 地区和年份固定效应，用于控制所有非观测的随时间变动的行业特征地区特征以及时间冲击; $\mathcal { E } _ { i j k t }$ 表示随机扰动项<sub>。</sub> 为了避免内生性问题，将核心解释变量和企业控制变量均滞后一期<sub>。</sub>

## (二) 核心指标测度

## 1. 生产性服务进口含量测算

如何准确地测算制造业使用的生产性服务进口含量 是 一 大 难 点， 本 文 参 考 Feenstra 和 Hanson(1997)<sup>［21］</sup>的测算方法构建制造业生产性服务进口指数(以下简称 FH 指数)① 计算公式为:

$$
F H _ {j t} = \sum_ {f} \frac {X _ {j f}}{Y _ {j}} \left(\frac {M _ {f}}{P _ {f} + M _ {f} - E _ {f}}\right)\tag{2}
$$

其中， $X _ { j f }$ 为制造业j 的中间服务品f的投入量，用制造业j 中间服务f的投入量占服务业f总产出的比重乘以每年服务业f产出表示; $Y _ { j }$ 为制造业j 的中间品总投入量，用制造业j 中间投入量占制造业j 总产出的比重乘以每年制造业j 的产出表示; $M _ { f }$ 为服务品f的总进口量; $E _ { f }$ 为服务品f的总出口量; $P _ { f }$ 为服务品f的总产出量<sub>。</sub>

为了测算该指数，需要匹配两组数据: 第一，制造业使用的服务中间投入数据<sub>。</sub> 我们将投入产出表的数据与统计年鉴中的制造业行业分类数据进行匹配由于中国投入产出表每五年编制一次，为了保持样本期内测算的统一性和研究数据可比性，本文统一使用2002 年投入产出数据，最终匹配获得28 个制造业细分行业投入产出数据② 第二，服务贸易数据与制造业使用的服务中间投入分类数据 细分行业的服务贸易数据可从联合国贸发会议数据库 (UNCTAD) 获取，但是该数据库与中国统计年鉴中的服务业行业分类标准有所差异，我们参照陈启斐和刘志彪 (2014)<sup>［6］</sup> 的方法，将服务贸易数据与制造业中间服务投入数据进行匹配，共获得六大类细分行业生产性服务贸易数据③，分别为运输及通讯服务业; 信息服务业; 金融服务业; 科技服务业; 个人服务业和其他商业服务业<sub>。</sub>

## 2. 企业加成率的测算

关于企业加成率的估计方法有很多，归纳起来主要有两种: 会计估计法和生产函数估计法 会计估计法主要利用工业增加值<sub>、</sub> 应付工资总额和中间投入成本进行计算，测算方法为: $( \frac { p \ - \ M C } { p } ) _ { _ i t } \ = \ 1 \ - \frac { 1 } { m a r k u p _ { i t } }$ $= ~ ( { \frac { v a \ - \ p a y } { v a \ + z j t r } } )$ <sub>。</sub> 其中， $m a r k u p _ { i t } $ 为企业 i 在 t 年的加成it率， $p$ 为产品价格，MC 为边际成本，va 为企业工业增加值， $p a y$ 为本年应付工资总额， $z j t r$ 为中间投入成本<sub>。</sub> 上述计 算 方 法 简 单 且 数 据 易 得，盛 丹 和 王 永 进(2012)<sup>［15］</sup>在研究中国企业加成率问题时采用了该方法 <sub>。</sub>

生产函数估计法则通过估计生产函数和可变要素的产出弹性来测算企业加成率，进而突破了依赖会计数 据 的 局 限 性 ( Hall， 1988 )<sup>［22］</sup> <sub>。</sub> De Loecker 和Warzynski (2012 )<sup>［13］</sup> 在 此 基 础 上，采 用 两 步 估 计 法(以下简称 DLW 法) 估算企业加成率，其基本原理是从成本最小化角度构建拉格朗日函数，运用利润最大化条件解出企业加成率的表达式，然后通过估计生产函数法估算出企业加成率的具体数值 加成率的具体

表达式为:

$$
\mu_ {i t} ^ {m} = \theta_ {i t} ^ {m} \left(\gamma_ {i t} ^ {m}\right) ^ {- 1}\tag{3}
$$

其中， $\gamma _ { i t } ^ { m }$ 表示中间投入要素支出 $( \it X _ { i t } ^ { m } P _ { i t } ^ { m } \it X _ { i t } ^ { m } P _ { i t } ^ { m } )$ 占企业总销售收入 $\left( \begin{array} { l l } { P _ { i t } } \end{array} \boldsymbol { Q } _ { i t } \right)$ 的比重，可从工业企业数据库中直接计算得到 这里只需估计出中间投入要素的产出弹性 ${ \boldsymbol { \theta } } _ { i t } ^ { m }$ 即可求出企业加成率 $\mu _ { i t } ^ { m }$ <sub>。</sub> DLW 法提供了使用超越对数生产函数的估计方法，具体设定如下:

$$
\ln y _ {i j t} = \beta_ {l} \ln l _ {i j t} + \beta_ {k} \ln k _ {i j t} + \beta_ {m} \ln m _ {i j t} + \beta_ {l l} (\ln l _ {i j t}) ^ {2} + \beta_ {k k}
$$

$$
\left(l n k _ {i j t}\right) ^ {2} + \beta_ {m m} \left(l n m _ {i j t}\right) ^ {2} + \beta_ {l k} l n l _ {i j t} l n k _ {i j t} + \beta_ {l m} l n l _ {i j t} l n m _ {i j t} +
$$

$$
\beta_ {k m} \ln k _ {i j t} \ln m _ {i j t} + \beta_ {l k m} \ln l _ {i j t} \ln m _ {i j t} \ln k _ {i j t} + \omega_ {i j t} + \varepsilon_ {i j t}\tag{4}
$$

其中， $l n y _ { i \dot { \mu } }$ 为企业工业总产值的对数， $\omega _ { i j t }$ 为企业生产率， $\varepsilon _ { i j t }$ 为随机误差项 首先，估计被解释变量根据中间投入要素与资本 生产率和其他潜在变量的单调关系以及生产率满足希克斯中性假定，即 $\begin{array} { r l } { m _ { i j t } } & { { } = } \end{array}$ $m _ { i j t } ( k _ { i j t } , \omega _ { i j t } , Z _ { i j t } )$ ，求逆函数得到生产率代理方程: $\omega _ { i j t }$ $\mathbf { \Psi } = h _ { _ t } \big ( k _ { _ { i j t } } , m _ { _ { i j t } } , Z _ { _ { i j t } } \big )$ ，将其代入式 (4)，可得到:

$$
\ln y _ {i j t} = \Psi_ {t} \left(l _ {i j t}, m _ {i j t}, k _ {i j t}\right) + h _ {t} \left(k _ {i j t}, m _ {i j t}, Z _ {i j t}\right) + \varepsilon_ {i j t} =
$$

$$
\varphi_ {t} \left(l _ {i j t}, m _ {i j t}, k _ {i j t}, Z _ {i j t}\right) + \varepsilon_ {i j t}\tag{5}
$$

对 (5) 式进行二次多项式逼近拟合，即可得到被解释变量的无偏估计 $\overset { \wedge } { \boldsymbol { \varphi } } _ { t }$ <sub>。</sub> 其次，采用 GMM 估计方法对 (4) 式进行参数估计 最后可得到中间投入要素产出弹性估计值为:

$$
\theta_ {i t} ^ {m} = \beta_ {m} + 2 \beta_ {m m} l n m _ {i j t} + \beta_ {l m} l n l _ {i j t} + \beta_ {k m} l n k _ {i j t}
$$

$$
\beta_ {l k m} l n l _ {i j t} l n m _ {i j t}\tag{6}
$$

将其代入 (3) 式，即可得到企业加成率 $\mu _ { i t } ^ { m }$ 。本文在基准模型中使用生产函数法估计得到的企业加成率 $\mu _ { i t } ^ { m }$ 分析，而使用会计方法测算的加成率进行稳健性检验<sub>。</sub>

## (三) 数据说明

本文使用的数据主要有两组 第一组来自联合国贸发会议数据库 (UNCTAD) 我们从该数据库中得到历年细分行业的生产性服务进口数据，并根据当年平均汇价折算成人民币计价的生产性服务进口额 第二组数据来自中国工业企业数据库 由于统计误差 统计口径不一致等原因，该数据库中存在部分指标和数据缺失<sub>、</sub> 错误<sub>、</sub> 异常等问题，我们参照谢千里等(2008)<sup>［23］</sup> Feenstra (2014)<sup>［24］</sup> 等的做法，首先剔除了职工人数少于 8 人 (或缺失)<sub>、</sub> 总资产小于固定资产<sub>、</sub> 实收资本小于等于零<sub>、</sub> 工业总产值小于零的样本;其次，对于匹配成功的数据，还做了如下处理: 剔除工业增加值 企业销售额 平均工资 中间投入合计固定资产 企业年龄小于等于零的样本; 对于数据库中的所有名义变量，我们均选择以1999 年为基期的价格指数进行平减 最后，我们以 1997 年为基期④，后续年份的系数值都与基期值对比，构造出历年的 FH指数<sub>。</sub>

## (三) 稳健性分析

为了验证上述基准结果的可靠性和稳定性，本文采用多种方法进行稳健性检验

1. 替代变量回归<sub>。</sub> 首先，本文采用以会计方法计算得到的企业加成率 (mkpkj) 替代被解释变量进行估计; 其次，基准回归中使用制造业行业层面的 FH 指数作为关键解释变量，这里我们换一种思路，从产出角度，即使用历年企业工业总产值占该行业总产值的比重作为权重，构建企业层面的 FH 指数 (firmFH)进行固定效应估计; 最后，由于 FH 指数可能存在<sup>“</sup>相似比例假定<sup>”</sup> 缺陷 (蔡宏波等<sup>［25］</sup>，2013)，这里参考 Daveri 和 Jona － Lasinio (2008)<sup>［26］</sup>的做法，构建 DJ指数替代 FH 指数进行估计，计算公式为: $D J = \sum _ { f } \frac { m _ { j } ^ { f } } { Y _ { j } }$ ，其中，m<sup>f</sup>为制造业j行业第f种服务中间品的进口量，Y 为制造业j 行业中间品总投入量<sub>。</sub> 表 3 第 (1) －(3) 列分别给出了替代变量回归结果<sub>。</sub> 可以发现，无论是更换被解释变量还是对解释变量进行替代，关键变量的估计系数符号和显著性始终未发生实质性改变，表明生产性服务进口促进企业加成率这一结论稳健，假设1 再次得到了验证<sub>。</sub>

2. 分行业类型<sub>。</sub> 由于不同行业使用服务中间投入存在差异，这里遵循张艳等 (2013)<sup>［20］</sup>的思路，将样本划分为高服务使用率行业和低服务使用率行业⑤，并通过构造 FH 指数与高服务投入企业的交互项考察行业异质性对企业加成率的影响，估计结果列于表 3第 (4) 列<sub>。</sub> 从中可以看到，交互项系数显著为正，表明高服务使用率企业对生产性服务进口更为敏感，这是因为该类企业具有较强的知识溢出吸收能力和学习能力 (王俊，2013)<sup>［27］</sup>，增加使用国外先进的生产性服务要素有利于提高企业生产率和降低单位生产成本，从而对企业加成率有促进作用<sub>。</sub>

3. 地域分布和所有制类型 首先，根据省域代码将样本分为东部企业 中部企业和西部企业，并以西部企业作为基础类别; 其次，根据登记注册类型将企业分为国有企业 外资企业和民营企业，并以民营企业作为基础类别，回归中分别使用 FH 指数与地域分布的虚拟变量 所有制虚拟变量交叉相乘，形成交互项，估计结果列于表 3 第 (5) － (6) 列 结果显示，在地域分布方面，生产性服务进口对东部地区和中部地区企业加成率的促进作用大于西部企业，可能的原因在于，较之西部地区而言，东中部地区服务部门开放水平较高，这些地区企业可以使用更多的国外服务要素，从而显著提高企业加成率; 在所有制结构方面，国有企业与 FH 指数的交互项系数显著为负，说明生产性服务进口对国有企业加成率的促进作用有限，甚至为负，并且外资企业未通过显著性检验，这意味着，相比国有企业和外资企业，生产性服务进口更有利于促进民营企业加成率

## 六<sub>、</sub> 结论与启示

本文利用联合国贸发会议和中国工业企业匹配数据系统分析了生产性服务进口对企业加成率的微观影响，并得到以下结论: (1) 生产性服务进口显著提高了企业加成率，在进行了多种稳健性检验后，这一结论依然成立; (2) 细分行业的异质性检验发现，金融运输和通讯以及科技服务等生产性服务进口对企业加成率的促进作用更为明显; 同时我们进一步考察了行业 地域分布和所有制结构差异的潜在影响，发现高服务使用率企业 东中部地区企业和民营企业从生产性服务进口中受益更多; (3) 中介效应检验结果表明生产效率和研发水平提升是生产性服务进口促进企业加成率的可能渠道

本文的研究结论表明，生产性服务进口显著提高了企业加成率，这意味着继续推进服务贸易自由化，加大生产性服务进口是提升企业市场势力的有效途径对此，政府应进一步深化服务贸易领域开放，通过谈判磋商等方式逐步降低服务贸易壁垒，尤其要大力推进金融 科技 运输和通讯等服务部门开放力度，促进企业更多使用生产性服务进口中间品，从而通过提升生产率和研发强度等途径提高企业竞争力; 另一方面，中国还需进一步强化国内金融保险等服务部门体制改革和加强知识产权保护，为企业进行技术创新活动创造良好的融资和法制化环境，从而增强企业自主创新和市场竞争能力，促进产业结构升级和国民经济健康发展<sub>。</sub>
