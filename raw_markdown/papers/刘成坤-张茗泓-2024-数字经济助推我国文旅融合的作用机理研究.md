# 数字经济助推我国文旅融合的作用机理研究

刘成坤,张茗泓(江西财经大学 统计与数据科学学院,江西 南昌 )

[摘 要]数字经济是推动我国经济高质量发展的新动力,文化产业、旅游产业的发展提高了人们生活的幸福感和归属感,但是数字经济对文旅融合的影响和作用机制尚未明确。文章在构建文化产业、旅游产业和数字经济指标体系的基础上,采用纵横向拉开档次法,计算出它们的综合发展水平,采用双向固定效应模型、面板分位数回归和面板平滑转换模型,研究数字经济影响文旅融合的作用机理,结果显示:()数字经济能促进文旅融合的发展,在处理内生性问题后结论依然成立,且随着文旅融合水平的提高,数字经济对文旅融合影响幅度递减。()以人力资本作为门槛变量时,数字经济对文旅融合存在显著的非线性影响,影响方式为“倒 型”,且区域创新存在显著的中介效应。()划分区域和数字经济一级指标后得出,数字基础设施对东部、中部和西部的文旅融合均存在显著的促进作用,数字产业化对东部和西部的文旅融合存在显著的促进作用,而产业数字化对东部的文旅融合存在显著的抑制作用。研究表明,数字经济促进文旅融合主要体现在数字基础设施和数字产业化上。

## 1 文献综述

针对数字经济的测度和影响因素 文旅融合的测度和探索性分析、数字经济对产业和城乡等方面融合发展影响的实证研究,国内外已有非常丰富的文献。

第一 文旅融合的测度和探索性分析通过研究黑龙江省各地级市的环境和旅游业耦合协调,发现该省各地级市的耦合协调度呈上升趋势。其中 经济效益和生态质量对耦合系统的影响最大是宏观决策中需要考虑的关键因素[1]。 等引入了系统动力学的研究方法 分析了经济 资源和环境 者内部的因果关系并进行仿真,得出经济情景在短期内的协调效果最差 环境情景在短期内的协调效果最好 资源情景在长期内的协调效果显著的结论<sup>[</sup>2<sup>]</sup> 洪学婷等通过研究文化资源与旅游产业耦合协调 得出耦合时空分异 耦合协调度动态演变较少的结论<sup>[</sup>3<sup>]</sup> 赵嫚等选取了 个一级指标 分析文旅融合发展的动力 认为我国仍处于中等耦合 并且存在显著的空间集聚效应<sup>[</sup>4<sup>]</sup> 于秋阳认为 文旅产业的综合发展水平较高,但耦合协调度整体仍较低,且围绕省域核心城市呈现增长极效应,在空间上存在显著的关联性,旅游产业的发展对文旅融合的影响作用要强于文化产业<sup>[</sup>5<sup>]</sup> 可以看出 耦合协调模型在产业融合研究领域的运用已经非常成熟,并且关于融合机制的研究也比较完善 但是鲜有关于数字经济影响文旅融合的研究,有少数学者研究数字经济对文化和旅游单方面的影响。冀雁龙等构建了数字化基础设施建设指标,在考虑内生性的基础上实证研究了数字化基础设施对旅游经济增长的影响[6]。

第二,针对数字经济对产业和城乡等方面融合发展影响的研究。在理论层面上,王冲从数字经济对传统产业的效率变革机制 动力变革机制和质量变革机制论述了数字经济促进产业融合的机理[7]。在实证研究层面上,张岳等实证证明数字金融推动了农村产业融合的发展,传统金融起到一定的调节作用 并且数字金融具体业务对产业融合存在一定的异质性[8]。台德进等实证得出数字经济显著促进了城乡经济融合 并且考虑了农业劳动力转移和市场规模扩大的中介效应,农业劳动力转移的门槛效应以及数字经济的空间溢出效应<sup>[</sup>9<sup>]</sup> 周明生等研究发现数字技术发展对制造业和服务业的融合有显著影响 并且存在区域和产业结构异质性 在进行了内生性处理和稳健性检验后结论仍然成立[10]。可以看出,针对数字经济对产业融合发展影响的研究已经取得了一定的成果

综上所述 现有文献针对数字经济和文旅融合的单独研究已经不少 但针对数字经济对文旅融合影响的研究仍然不多 从现有的相关文献来看 詹绍文等从数字经济细分维度上 对文旅融合的影响进行了研究<sup>[</sup>11<sup>]</sup> 杨利等则研究了产业结构优化和科技创新的中介效应,以及数字经济自身的门槛效应[12]。而刘英基等则从文旅融合高质量发展的视角进行了研究<sup>[</sup>13<sup>]</sup> 因此 本文可能的边际贡献在于 从测度方法来看 本文立足中国发展现状 构建文化产业 旅游产业和数字经济的综合指标 并综合纵横向拉开档次法和耦合协调度模型测算文旅融合和数字经济水平;()从研究内容来看,本文对区域创新的中介效应 人力资本的门槛效应及数字经济子维度的区位异质性进行研究 在一定程度上弥补了已有研究的不足之处。

## 理论分析和研究假设

## 数字经济对文旅融合发展的推动作用

数字经济是以数据信息为关键生产要素,以互联网为支撑 将新技术赋能旧产业的一种经济模式吴琴等认为 产业融合主要体现为技术融合 业务融合和市场融合等方面的协调发展<sup>[</sup>14<sup>]</sup> 本文基于此产业融合类型划分来论述数字经济对文旅融合的影响。

其一,数字经济能显著推动文化产业和旅游产业的技术融合。杨永根等认为,数字经济加速了数字技术的扩散,为大数据、物联网和云计算等新技术发展提供了支持,加强了文化产业和旅游产业间的关联[15]。大数据的出现为文化和旅游产业提供了发展契机 但也不可避免地出现了 数据孤岛 的问题,而数字经济的发展有利于打破“数据孤岛”,实现不同企业,甚至不同产业之间的数据共享,模糊了文化产业和旅游产业的边界。比如:智能化的酒店、旅游线路的推荐和语音导览等,都能让游客在旅途中享受更加便捷 舒适的服务 同时 数字经济也为旅游产业带来了更多文化、历史和自然等元素的纵深融合,进一步丰富了旅游产品。其二,赵云辉等认为,数字经济能显著推动文化产业和旅游产业的业务融合<sup>[</sup>16<sup>]</sup> 数字经济基于平台建设 通过共享的服务和基础设施为生产提供了场所 数字平台通过互联网将生产者和消费者连接起来,降低了参与者的交易成本和搜寻成本 此外 通过数字平台 文化产业和旅游产业能够接触到更广泛的受众 为双产业的融合发展和协同创新提供了基础 其三 数字经济能显著推动文化产业和旅游产业的市场融合 陈晓红等认为 数字经济扩大了原有市场的规模 促使消费者的需求不断增加 促进新的商业模式出现<sup>[</sup>17<sup>]</sup> 比如 虚拟现实技术 和增强现实技术( )等数字技术的出现,使得游客可以通过虚拟的方式体验和探索各种旅游目的地 在旅游的过程中感受当地的文化和历史,为实地旅游做好准备。因此,本文提出假设:

假设 数字经济能有效推动文旅融合发展

## 区域创新的中介效应

数字经济通过促进区域创新 从而推动文化产业的技术融合 业务融合和市场融合 最终推动文旅产业融合发展。其一,韩松等认为,数字经济为文化产业和旅游产业提供了丰富的技术手段和工具 例如,基于大数据和人工智能技术的智能化管理系统可以优化旅游资源的规划和管理 提高旅游服务的质量和效率。同时,利用数字技术和互联网平台,文化产业可以进行数字化转型,创造新的数字产品和服务[18]。其二,武潇等认为,通过数字化平台,旅游产业可以提供与文化产业相关的旅游产品和体验,如文化主题旅游 文化演艺表演等 同时 文化产业也可以与旅游产业合作,如文化企业可以为旅游景点提供演出、展览和文化活动等,丰富旅游体验,吸引游客[19]。其三,数字经济为文化产业和旅游产业带来了全新的市场机遇。通过线上平台和移动支付等技术手段,文化产品和旅游服务可以更加便捷地传播和售卖 拓展了市场规模和受众 同时 数字经济也促进了文化和旅游产品的个性化定制和差异化竞争 满足消费者多样化需求 此外 从生产要素的视角来看, 提出了传统的内生增长理论,即生产要素包括劳动 物质资本 人力资本和技术水平,而数字经济的出现使得数据成为重要的增长动力[20]。不同于传统生产要素,数字经济硬件投入的边际成本随着用户数量的增加而递减 因此边际效益的递增节约了创新成本,促进区域创新。企业运用电子商务和移动支付技术 提高了消费者的体验节约了消费者信息搜寻成本 推动文化和旅游产业的需求,促进文旅融合的发展。因此,本文提出假设:

假设 :数字经济促进区域创新,从而推动文旅融合发展。

## 人力资本的门槛效应

文旅融合的新产业本身作为高附加值,以第三产业为主的产业 创新显得尤为重要 而人力资本的水平影响了产业创新能力 其一 当人力资本水平较低时,文旅融合的创新动力不足,难以盘活市场上潜在的巨大需求,新产品和新服务的供给能力存在一定的瓶颈,但当人力资本不断提升时,文化和旅游产业的创新能力就被不断激活 使得市场在一个更高层次的水平上实现供需平衡,并且不断涌现新需求,促使两大产业实现融合发展。当人力资本继续提升时 产业的创新也达到了瓶颈 消费者对文化和旅游产业的需求难以继续提高 市场供需出现失衡从而对文旅融合起到了一定的抑制作用。其二,消费者受教育水平的提高 使得他们从物质需求转向精神需求 市场需求实现多样化 促进产业供给水平的提高。因此,本文提出假设:

假设 :当人力资本小于某一门槛值时,数字经济会促进文旅融合的发展;当人力资本大于某一门槛值时,数字经济对文旅融合的影响方向不确定。

## 指标评价与实证设计

## 3.1 指标评价

纵横向拉开档次法能克服熵权法不同年份权重不一致的问题,动态反映其变化趋势。本文首先采用该方法测度各年度各省份数字经济、文化和旅游产业的指标权重。参考郭亚军的做法[21],具体过程如下:假设有 n 个省份,每个省份有 m 个指标,k 个测算年度。先对各年份 m 个变量进行标准化处理,记标准化后的数据为 $x _ { i j } \left( t _ { s } \right)$ ),为了测算 t 各省份综合指标的水平,设定综合评价函数

$$
y _ {i} \left(t _ {s}\right) = \sum_ {i = 1} ^ {m} w _ {j} x _ {i j} \left(t _ {s}\right).\tag{1}
$$

其中, $, i = 1 , 2 , \cdots , n ; j = 1 , 2 , \cdots , m ; s = 1 , 2 , \cdots , k$ 按最大可能体现出各评价对象之间的差异来确定权重 $\boldsymbol { \omega } _ { j }$ ,即对 ${ \bf y } _ { i } \left( t _ { s } \right.$ 的总离差平方和取最大值

$$
e ^ {2} = \sum_ {s = 1} ^ {k} \sum_ {i = 1} ^ {n} \left[ y _ {i} \left(t _ {s}\right) - y \right] ^ {2}.\tag{2}
$$

其中 $\mathbf { \boldsymbol { y } } = \frac { \sum \boldsymbol { y } _ { i } \left( t _ { s } \right) } { n k }$ 由于进行了标准化处理 因此$y = \frac { \sum y _ { i } \left( t _ { s } \right) } { n k } = 0$ ,从而( )可简化为 $e ^ { 2 } = \ w ^ { T }$ ∑$H _ { s } { \ w }$ 其中 表示权重 $\boldsymbol { H } _ { s } = [ \boldsymbol { x } _ { i j } \ ( \boldsymbol { t } _ { s } ) ] ^ { T } \left[ \boldsymbol { x } _ { i j } \right.$ t H H 当 $\boldsymbol { \omega }$ 取矩阵 H 最大特征值对应的特征向量时 $\bullet e ^ { 2 }$ 取最大值 另外 w 也可由如下规划问题确定。

$$
\mathsf {m a x} \boldsymbol {\omega} ^ {T} \boldsymbol {H} \boldsymbol {\omega}.\tag{3}
$$

$$
\text { s.t. } \| w \| = 1, w > 0.\tag{4}
$$

在得出数字经济、文化 $\vec { \cal J } ^ { \pm }$ 业和旅游 $\vec { \cal J } ^ { \pm }$ 业的发展水平之后 本文采用耦合协调模型计算文旅融合水平 已有文献广泛采用耦合协调度来测算两个或多个产业的融合发展水平,比如王晶晶等采用耦合协调模型测度了农业与旅游产业的融合发展<sup>[</sup>22<sup>]</sup> 孙梅采用耦合协调模型测度了农业和餐饮服务业的融合发展<sup>[</sup>23<sup>]</sup> 因此 参考已有研究的方法 本文也使用耦合协调度模型对我国文旅融合的耦合协调度进行计算 分别计算文化产业和旅游产业的发展水平记文化产业的发展水平为 $G _ { 1 }$ 旅游产业的发展水平为 $G _ { 2 }$ 。文化产业和旅游产业同等重要,因此赋权均为 ,得出文化产业和旅游产业的协调指数 T,如式():

$$
T = 0. 5 G _ {1} + 0. 5 G _ {2}.\tag{5}
$$

得到协调度的计算式如式():

$$
C = \sqrt {\frac {G _ {1} \cdot G _ {2}}{(\frac {G _ {1} + G _ {2}}{2}) ^ {2}}}.\tag{6}
$$

可以计算出耦合协调度,计算式如式():

$$
D = \sqrt {C \cdot T}.\tag{7}
$$

## 变量说明

## 数字经济

参考关会娟等<sup>[</sup>27<sup>]</sup>以及王军等<sup>[</sup>28<sup>]</sup>的研究 同时考虑到数据的可得性 本文构建的数字经济发展水平指标体系包括数字基础设施 数字产业化 产业数字化以及发展环境等 个一级指标

数字经济是以数字技术为主要载体,利用信息通信技术推动经济结构优化和效率提升 数字基础设施是必不可少的要素 数字基础设施包括个人电脑端 端 和移动端两大方面

随着数字技术的发展 数字应用已经渗透到我们生活的方方面面 在信息技术与传统产业相互融合 产生了数字经济发展的融合应用 按照 年中国信息通信研究院的数字产业划分方法,数字产业分为数字产业化和产业数字化两个方面 数字产业化即信息通信产业,是数字经济发展的先导产业,为数字经济的发展提供技术、产品、服务和解决方案等,包括电子信息制造业、电信业、软件和信息技术服务业及互联网行业等。本文在数字产业化方面的指标包括电信业务与信息技术服务规模、软件业发展规模及状况两个层面。

产业数字化 是指传统产业由于应用数字技术所带来的生产数量和生产效率的提升,其新增产出构成数字经济的组成部分,或指在新一代数字科技支撑和引领下 以数据为关键要素 以价值释放为核心,以数据赋能为主线,对产业链上下游的全要素数字升级、转型和再造的过程。本文产业数字化的指标包括互联网信息化情况和企业电子商务情况两个层面。

数字经济的良好发展不仅需要完善和领先的数字技术,同时也需要良好的发展环境作为支撑,并且需要一定的物力与人力 这也是数字经济得以快速发展的一大关键。本文数字经济发展环境指标主要有科研产出和数字化人才两个层面。

## 中介效应模型

由于区域创新和文旅融合存在高度相关性和双向因果关系,并且两者可能存在测量误差,所以使用温忠麟等<sup>[</sup>33<sup>]</sup>提出的三步法可能会导致统计显著性降低 造成系数结果的偏误 并且本文不关注中介效应的大小,只检验是否存在中介效应。因此,参考江艇[34]提出的做法,只进行三步法的第一步和第二步 观察数字经济的系数是否显著 从而判断是否存在区域创新的中介效应。第一步已在基准回归中进行,第二步的具体形式如下:

$$

其中:变量 为区域创新,是本文的中介变量。

数字产业化对东部和西部的文旅融合水平有显著的正向影响,并且影响程度呈西部 东部。可能的原因在于 数字产业化主要体现在信息技术的发展。第一,信息技术变革带来的新业态和新模式,使得产业融合成为新潮流,实现用户需求透明化,让信息技术贯穿生产链和价值链的全过程 第二 信息化有利于指定相应的产业政策,有利于政府对文化和旅游产业的监管,实现生产要素,尤其是资本要素的“脱虚向实”。第三,信息化的应用可以及时发现生产过程中的缺陷 减少资源错配 及时挖掘市场潜在的需求。西部地区通常拥有丰富的自然资源和独特的文化底蕴,这为发展文旅融合提供了良好的土壤 通过数字产业化 西部地区可以更充分地利用数字技术和平台,推动旅游产业向数字化、智能化和创新化方向发展,提高旅游服务的质量和效率,推动文旅融合 东部地区相对于西部地区而言 在经济和基础设施发展方面整体水平更好 也普遍具有较高的数字产业化水平。虽然东部地区的文旅融合水平可能已经相对较高,但数字产业化仍然可以进一步促进其文旅融合的提高。

产业数字化对东部地区的文旅融合存在显著的抑制作用 而对中部和西部地区的文旅融合的影响不显著 原因在于 东部地区的数字产业化程度已经达到一定的规模 并且数字产业化为文旅融合提供了发展动力 降低了时空的影响 使得消费者能够随时了解相关信息。但是随着规模的不断扩大,对文旅融合的影响呈现递减趋势 而产业数字化的转变过程比较困难 在转变的过程中 不可避免地会遇到一些阻碍,因此对文旅融合会有一定的抑制作用。

## 6.1 结论

本文首先构造文化产业、旅游产业和数字经济的综合指标,采用纵横向拉开档次法和耦合协调模型对文旅融合和数字经济进行测度。然后,采用面板固定效应进行基准回归, 、 估计和面板分位数回归进行模型内生性处理和稳健性检验,采用面板平滑转换模型分析人力资本作为门槛时模型的非线性情形,讨论了区域创新的中介渠道效应。最后将全国分为 个区域,并划分数字经济的 个一级指标作为核心解释变量进行异质性分析,用两种方法进行稳健性检验 得出了如下结论 数字经济显著促进文旅融合的发展,主要体现在数字基础设施和数字产业化上。随着文旅融合水平的提高,数字经济对文旅融合的促进作用递减。()随着人力资本水平的提高,数字经济对文旅融合的促进作用先递增后递减,并且存在区域创新的中介效应。()在划分区域和数字经济一级指标之后,数字基础设施对东部、中部和西部的文旅融合均存在显著的促进作用 数字产业化对中部和西部的文旅融合存在显著的促进作用,而数字产业化对东部的文旅融合存在显著的抑制作用。

## 建议

进一步加强我国数字基础设施建设 各地区应结合当地的发展现状和民生需求提前部署和推进数字中心和云计算中心等关键基础设施 充分发挥政府 市场和投资主体功能 为吸引投资提供良好的市场环境 强化监督评价 处理好数字基础设施和文化 旅游产业的协同发展的步伐 重视风险管理 解决好安全生产和技术问题 兼顾效率和风险管控 强化文化和旅游产业链的基础设施建设 使基础设施建设成为文旅融合的重要推动力。
