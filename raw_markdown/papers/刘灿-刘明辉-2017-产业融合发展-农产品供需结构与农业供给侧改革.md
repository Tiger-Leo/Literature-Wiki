# 产业融合发展<sub>、</sub>农产品供需结构与农业供给侧改革

刘 灿，刘明辉

( 西南财经大学 经济学院，成都 611130)

摘要:农产品价格保护制度下，产业融合不畅会导致产业间关联效应发挥受限和农产品 <sup>“</sup>供需反馈<sup>”</sup>机制瓦解，这是农产品供需结构性矛盾出现的重要原因<sub>。</sub> 从国际和我国省际的产业融合指数测度结果来看，我国工农产业融合指数相对较高，包括机械 化肥等中间投入品对农业生产有较强的正向促进作用，是农业生产力提升的重要推手，而服务业与农业融合度偏低，但服务业中间投入品产出弹性提升较快，是提高农业生产效益的重要动能 因此，产业融合发展是转变农业增长方式，满足社会农产品消费需求的关键，现阶段农业发展需以提升农业的综合效益与国际竞争力为导向，以工业与服务业延伸农业产业链<sub>、</sub>以生产要素融合及发展理念契合等为路径，以创新农业经营体系 健全农业社会化服务体系为纽带，寻求推动我国农业供给侧结构性改革的新突破<sub>。</sub>

## 一<sub>、</sub>引 言

供给侧结构性改革是适应我国经济发展新常态提出的调结构 转方式的重大举措 2015 年年底的中央农村工作会议 2016 年中央一号文件以及 2016 年 12 月召开的中共中央政治局会议均明确强调要推进农业供给侧结构性改革，指出2017 年为供给侧改革的 <sup>“</sup>深化之年<sup>”</sup>，并认为农村产业融合发展是培育农村新经济 培植农村新动能的重要内容 根据2016 年11 月发布的 《全国农产品加工业与农村一二三产业融合发展规划(2016 ～2020 年) 》以及2017 年中央一号文件精神，加快产业融合已成为构建现代农业体系 转变农业发展方式的必然要求 近年来，我国粮食出现 <sup>“</sup>三量齐增<sup>”</sup>现象，农业生产与市场需求结构错配 农业生产成本高企 中高档农产品供给不足等问题严重，引致农业生产可持续区间收窄构建农业现代化体系，推动农业供给侧结构性改革势在必行

现阶段，农业供给侧结构性改革的基本含义是在经济全球化背景下提高农业的综合效益与国际竞争力，是以农民增收 保障有效供给为主要目标，以提高农业供给质量为主攻方向，以体制改革和创新为根本途径的<sup>“</sup>农业供给侧结构调整 +改革<sup>”</sup>发展思路，而农村一二三产业融合发展是推动农业供给侧结构性改革的重要着力点<sub>。</sub><sup>［1</sup> <sup>－</sup> <sup>3］</sup>产业融合发展利于强化关联效应，扩大波及效果，降低农业生产经营成本和提升农业竞争力，是补足农业发展短板的主要支撑，是农业供给侧结构性改革的本质要求<sub>。</sub> 历史语境下，工农业产品价格<sup>“</sup>剪刀差<sup>”</sup>强力推动了我国工业化发展，工业化中后期阶段，工业经济和服务经济的持续繁荣推动了农业规模化<sub>、</sub>机械化和信息化<sub>。</sub><sup>［4］</sup>2015 年我国农业机械总动力相当于土地流转初期(2002 年) 的1<sub>.</sub> 93 倍，同时，农业经营模式不断创新，乡镇企业与农业旅游业持续发展，<sup>“</sup>互联网 + 农业<sup>”</sup> 农村电子商务等农村新兴业态加速成长，农业生产力显著提升 舒尔茨( Schultz) 提出农业生产力的提升来源于土地 资本 劳动等的要素投入和技术革新两个方面，农业生产所必须的要素投入和科技创新则依托于工业和服务业的中间品投入<sub>。</sub><sup>［5］</sup>因此，要实现农业现代化，应着力改善要素供给渠道，推动家庭农场等新型农业经营主体开展适度规模经营，扩大农业社会化服务规模，将 <sup>“</sup>新技术 新业态 新模式<sup>”</sup>嵌入农业生产，推动农业供给侧结构性改革<sub>。</sub>

产业融合是农业供给侧结构性改革的主要抓手，利于提升农业综合效益 发挥农业多功能性，<sup>［6］</sup>一二三产业融合发展有其必然性与可能性，应鼓励农业技术和农业商业模式的创新<sub>。</sub><sup>［7］</sup>有关我国农业发展的研究主要集中在农业产业集群<sup>［8</sup> <sup>－</sup> <sup>9］</sup> 农业产业链<sup>［10］</sup> 农业产业结构<sup>［11］</sup>等方面，也有一些学者关注农业与工业的<sup>“</sup>互哺<sup>”</sup>关系，<sup>［12</sup> <sup>－</sup> <sup>15］</sup>而涉及农业与服务业的研究较少<sub>。</sub> 随着 <sup>“</sup>互联网 + <sup>”</sup>技术的加速运用，一些学者验证了<sup>“</sup>互联网 + <sup>”</sup>对农业产业集群<sup>［16］</sup><sub>、</sub>农业产业链<sup>［17］</sup>以及农业转型<sup>［18］</sup>的促进作用，尤其突出了对休闲农业和都市农业的研究<sub>。</sub><sup>［19］</sup>供给侧结构性改革提出以来，有关农业的研究尚不充分，多数围绕农业供给侧结构性改革的内涵<sup>［20］</sup> 金融支持农业<sup>［21］</sup> 农业发展经验<sup>［22</sup> <sup>－</sup> <sup>23］</sup> 农业供给侧结构性改革的发展思路与方向<sup>［24</sup> <sup>－</sup> <sup>25］</sup>等方面展开研究<sub>。</sub>

农业供给侧结构性改革致力于推动农业产业提质增效 满足社会不断变化的农产品需求，着力点在于以产业融合发展为依托推动农业 <sup>“</sup>去产能<sub>、</sub>降成本<sub>、</sub>补短板<sup>”</sup>，然而，现有农业供给侧结构性改革的研究较少关注产业融合路径<sub>。</sub> 本文借助工业与服务业对农业生产 农业流通和销售等环节的关键作用构建分析框架，认为要推进农业供给侧结构性改革，提升农业供给体系质量和效率，需要以产业融合发展为支撑 因此，本文以产业融合发展为切入点阐释农业供给侧结构性改革的出路，辨明农业供给侧结构性改革的政策落脚点，为深化推进农业供给侧结构性改革和农业现代化建设提供资政建议

## 二<sub>、</sub>产业融合发展与社会农产品供需结构形成机理

产业融合发展是延伸农业产业链 搞活农产品市场的重要推手，是提高农产品供给质量 满足农产品消费需求的重要手段 工业和服务业为农业产业化 农业信息化和农业 <sup>“</sup>产 <sub>－</sub> 供 <sub>－</sub> 销<sup>”</sup>一体化提供了重要渠道，利于发挥农业的多功能性 为了对产业融合发展与社会农产品供需的关系做进一步说明，假定社会存在两个生产部门，第一部门为农业生产部门，规模报酬不变，第二部门为与农业部门存在关联效应的部门，分属工业和服务业，且规模报酬递增，为此我们有两部门的生产函数:

$$
y _ {a} = A _ {a} K _ {a} ^ {\alpha_ {a}} L _ {a} ^ {1 - \alpha_ {a}}, 0 <   \alpha_ {a} <   1\tag{1}
$$

$$
y _ {i} = A _ {i} K _ {i} ^ {\alpha_ {i}} L _ {i} ^ {\beta_ {i}}, \alpha_ {i} + \beta_ {i} > 1\tag{2}
$$

## 1<sub>．</sub> 农产品供给短缺

从历史语境来看，农产品交易会出现卖方市场和买方市场，在经济发展初期，多会出现农产品供给短缺 此时，政府甚至会通过配给制等手段调节社会农产品需求，工业化处于起步阶段，居民生活水平也较低，整个社会追求的是农产品 <sup>“</sup>量<sup>”</sup>的增长 考察( 1) 式，我们可以看出全要素生产率( A ) 资本$\left( \mathrm { ~ K _ { a } } \right)$ 和劳动( $\mathrm { L } _ { \mathrm { a } } )$ 决定着农业生产，而全要素生产率和资本的 <sup>“</sup>短板<sup>”</sup>在短期尤其是经济发展初期很难补足，农业生产则只能依靠更多的劳动投入 遗憾的是，农业生产对生产资料的投入存在最优配置，多余的劳动投入与产出不成比例，劳动的边际产出递减，因此，农业在社会经济落后的情况下增产困难<sub>。</sub> 待到经济发展到较好程度后，第二部门开始为第一部门装备机械和提供资本( 为 <sub>y</sub> 的一部分) ，第一部门全要素生产率( A ) 和资本( $\left. \mathrm { K } _ { \mathrm { a } } \right.$ 开始出现提升，从而第一部门产品产量又开始出现增长势头，劳动对农业的贡献逐渐弱化<sub>。</sub>

## 2<sub>．</sub> 农产品供过于求

农业生产力的进步使得多数农产品处于供过于求的状态，出现买方市场与新的卖方市场并存的现象 随着资本注入农业部门以及农业机械化的普及推广，农业土地生产率得到了较大提升，并且在政府农业保护制度下一些农产品数量剧增甚至出现结构性过剩，过剩的农产品市场转化为买方市场，其余一些农产品市场由于 <sup>“</sup>数量<sup>”</sup>或<sup>“</sup>质量<sup>”</sup>的<sup>“</sup>供给不足<sup>”</sup>，导致农产品市场形成 <sup>“</sup>新<sup>”</sup>的卖方市场<sub>。</sub> 此外，第二部门就业吸纳能力显著增强，农村涌现出的大量剩余劳动力开始转入第二部门，农业劳动生产率开始提高，居民收入增多，加之社会保障体系的不断完善，居民生活理念发生跃迁，更加注重农产品质量 这时社会就面临着如何调整农业产能以及如何满足居民农产品消费需求结构转换的问题 结合我国实际，农业供给侧结构性改革的目标就在于由农产品 <sup>“</sup>数量<sup>”</sup>向农产品<sup>“</sup>质量<sup>”</sup>转型，提高农业的国际竞争力<sub>。</sub>

以我国为例，现阶段我国处于工业化向后工业化发展的过渡时期，随着技术进步和分工深化，第二部门的就业容纳能力不断提升，尤其是服务业发展拉动就业的成效显著，而技术进步在农业部门的作用则更多地表现为机械对劳动力的替代，因此，农业劳动力 $\mathrm { { L } _ { a } ) }$ 会出现转向第二部门就业的趋势<sub>。</sub> 我们假定第二部门拥有的资本( $\mathrm { K _ { \mathrm { i } } } )$ 为全部投入生产，随着第二部门规模的不断扩大，所需资本数额也逐渐上涨，这时第二部门需从银行获得贷款，由于我们假定( $\mathrm { K _ { i } } )$ 为第二部门的全部资本，故而这些贷款是农业部门所储蓄的，我们假定储蓄份额占农业部门收入的比例为 $\mathrm { S } \big ( 0 < \mathrm { S } < 1 \big )$ ，贷款利率为 i，两部门工资差距导致的劳动力流动弹性为 <sub>τ</sub>，农业部门和第二部门的产品价格分别为 $\mathrm { { P _ { a } } }$ 和 $\mathrm { P _ { i } }$ ，那么第二部门的生产函数会转化为:

$$
y _ {i} = A _ {i + 1} \left(K _ {i} + S ^ {*} P _ {a} * y _ {a}\right) ^ {\alpha_ {i + 1}} \left[ L _ {i} + \tau \left(w _ {i} - w _ {a}\right) L _ {a} \right] ^ {\beta_ {i + 1}}, \alpha_ {i + 1} + \beta_ {i + 1} > 1\tag{3}
$$

由此，我们可以得出第二部门的利润函数:

$$
z = p _ {i} A _ {i + 1} \left(K _ {i} + S ^ {*} P _ {a} * y _ {a}\right) ^ {\alpha_ {i + 1}} \left[ L _ {i} + \tau \left(w _ {i} - w _ {a}\right) L _ {a} \right] ^ {\beta_ {i + 1} - S _ {i} *} i \left(S _ {d}, S _ {i}\right) * p _ {a} * y _ {a} - p _ {a} * y _ {a} (4)
$$

通过上式，我们可以看出农产品价格( P ) 农产品产量 $\cdot ( \mathrm { \ y _ { a } } )$ 劳动力要素 储蓄 利率等因素影响第二部门行业利润，由此可以得出以下结论: 第一，如果农产品价格 $\mathrm { ~ ( ~ P ~ ) ~ }$ 下降，则第二部门购买生产原材料的支出将减少，且减少幅度小于由于价格下降所导致的借贷资金减少所引致的收入减少幅度 尤其是在资本相对缺乏的情况下，资本产出弹性增大，也会增加第二部门利润; 第二，农产品产量增多，第二部门利润则会增加<sub>。</sub> 农业产量不断攀升的情况下，农民收入在一般情况下也会随之增加( 考虑价格保护因素) ，社会储蓄开始上升，当储蓄供给大于贷款需求，理论上会出现利率下滑和融资成本下降的现象，第二部门利润上升;第三，第二部门和农业部门间的收入差距达到一定程度，会引起被机械替代的闲置劳动力流入第二部门，从而在第二部门引发 <sup>“</sup>劳动力池效应<sup>”</sup>，同时农业产区农民收入的增加为第二部门融资提供了稳定的资金流;第四，第二部门利润变化也受诸多因素影响，随着市场对某种农产品的需求下降，那么厂商就会减少该种农产品的收购，在价格规律下农产品市场价格会出现波动，然而由于农产品价格保护制度的存在，一些农产品价格失去了市场的 <sup>“</sup>信号灯<sup>”</sup>作用，使得农产品价格具有粘性，导致农业经营<sup>“</sup>反馈机制<sup>”</sup>的缺失

图1 刻画了农业需求冲击以及供给侧结构性改革下的农业增长模式，其中，<sup>“</sup>d<sup>”</sup>所在的作用线为需求侧，<sup>“</sup><sub>s</sub><sup>”</sup>所在的作用线是供给侧，本文认为这较为符合当下农业增长的两种路径 需求侧方面，农业生产最初是保障居民的基本温饱水平，这时候由于技术水平限制，农业一般富余较少或者由于居民收入不高无暇顾及农产品供给质量，因此呈现<sup>“</sup>生产资料 <sub>－</sub>农业生产 <sub>－</sub>农产品消费<sup>”</sup>的线性模式，而消费者需求则很少受到生产资料供应商和农业生产厂商关注，他们之间的反馈是割裂开来的 供给侧下的农业增长更加关注的是<sup>“</sup>反馈效应<sup>”</sup>的作用，市场主体之间的作用往往是双向的，依据农产品消费需求，通过生产资料和生产部门的技术革新<sub>、</sub>绿色生产等手段，生产出满足消费者需要的农产品<sub>。</sub> 现阶段，农产品需求侧不断升级，而供给侧结构并未与之对称，导致农产品市场出现供给不足与产能过剩 销路不畅等并存现象，亟需推进供给侧结构性升级 三产融合发展利于强化农业产业的关联效应，关联效应是产业融合发展影响农产品供需结构的关键，具体可以概括为: 第一，后向关联效应<sub>。</sub> 农业生产经营情况的变化对农业生产的中间要素投入产生新的需求，通过后向关联效应影响中间投入品部门发展; 第二，前向关联效应<sub>。</sub> 通过农产品供给的变化影响农业下游产业发展，决定农业最终消费品质量<sub>。</sub> 第三，旁侧关联效应 尤其是其他产业对农业的旁侧效应，如产业融合发展利于发挥服务业对农业的带动效用，以上三点均直接或间接对农产品的供给结构和供给质量产生影响<sub>。</sub> 三产融合发展在调整农产品供需结构的基础上推动农业供给侧结构性改革: 第一，前向和后向关联效应通过农业生产<sub>、</sub>农业技术等方面的变革影响农产品生产质量和生产结构，如农业机械的更新换代 农产品精深加工等决定着农业生产 <sup>“</sup>去产能<sup>” “</sup>补短板<sup>” “</sup>降成本<sup>”</sup>等重点任务的推进进程，对生产资料 农产品的供给质量和供给结构有重要影响; 第二，以<sup>“</sup>互联网 + <sup>”</sup>为代表的服务业的兴起利于提高信息共享程度，提升农产品供需动态反馈能力，及时矫正农产品供需扭曲局面 因此，真正实现产业间的无缝融合，才能助力生产资料供给 农产品供应和农产品需求反馈的有序跃迁，形成农业增长良性态势，达到降低农产品生产成本 提高农产品有效供给能力的目的 因此，产业融合发展是转变农业增长方式，满足社会农产品消费需求的关键

## 三<sub>、</sub>产业融合发展水平测度及经验比较

学界在产业融合的测度方面进行了诸多尝试，如陶长琪等 翁钢民等构建的耦联评价模型<sup>［26</sup> <sup>－</sup> <sup>27］</sup> 汪芳等采用的投入产出法等 <sup>［28］</sup>本文认为，投入产出法以总产出中其他产业的中间投入比重衡量产业间的融合程度，可以更有效的测度产业融合发展水平 遗憾的是，我国及省际的 《投入产出表》以五年为单位进行公布，不能保证时间上的连续性，而 WIOD 数据相对较为连贯 因此，本文结合国际和我国省际两个方面进行产业融合发展水平的比较分析

我国内地30 省( 市<sub>、</sub>自治) 产业融合发展水平的测度结果表明: 第一，2002 ～2007 年我国内地多数省( 市 自治区) 的农业与工业 服务业的融合发展水平出现较大幅度的提高，表明土地流转制度实施以来，我国工业反哺农业 服务业支撑农业的力度逐渐增大，农业生产规模化 机械化 信息化水平得到了切实提升<sub>。</sub> 同时，新型农业经营体系持续完善，新型农业经营主体不断壮大，农机作业<sub>、</sub>农资供应<sub>、</sub>农业技术信息等服务成效显著 第二，2007 <sub>～</sub>2012 年，农业与二三产业的融合指数提高受限或出现不同程度的下降，其中农业与工业的融合度普遍高于农业与服务业的融合度，因此随着农业社会化服务业体系的逐渐完善，我国农业与服务业的融合发展水平仍有较大的提升空间 此外，产业融合度指数表现出两个明显的地理特征: 第一，东部地区农业和二三产业融合度排名前位的省份居多 西部地区农业与工业融合度在2007 年表现最好，2012 年下降明显<sub>。</sub> 第二，我国内地农业产业融合度较高的省份相对稳定<sub>。</sub> 黑龙江省农业与二三产业的融合度均较高，在全国处于较高水平，西部地区内蒙古 新疆自治区等地融合度也较高，中部地区则以安徽<sub>、</sub>湖南等地排名靠前，东部地区如北京<sub>、</sub>山东<sub>、</sub>江苏<sub>、</sub>上海等地在一些年份位居前列<sub>。</sub>

## 五<sub>、</sub>结论及政策启示

农业与二三产业的深度融合才能再现农业发展良态<sub>。</sub> 政府保护价格下的农业生产由于缺乏市场反馈机制，农业生产结构受政府补贴等财税政策诱导，往往与市场需求相矛盾，出现结构性供需矛盾，在此架构下，本文重点剖析了农业与二三产业的融合指数及其与相关投入要素对农业产出的弹性效应<sub>。</sub> 结果表明，我国农业与工业融合度较高，甚至高于美国，达到21<sub>.</sub>24%，农业与服务业融合度偏低，甚至低于印度，为4<sub>.</sub> 6% <sub>。</sub> 分地区来看，农业与二三产业融合度位居前列的省份多数为东部地区，中西部地区内蒙<sub>、</sub>新疆等省份产业融合度也较高<sub>。</sub> 投入要素中，土地<sub>、</sub>机械等要素对农业产出弹性系数较大，而劳动投入对农业产出弹性偏小<sub>。</sub> 因此，深化农业供给侧结构性改革要激活产业融合市场，紧抓产业融合红利培育农业产业新业态，优化农业投入要素培植农业发展新动能，推动农业现代化建设<sub>。</sub> 综合理论与经验分析，可通过以下三种途径推动农业产业融合发展: 一是生产方式融合，即以工业和服务业延伸农业产业链，形成市场主导的区域化种植<sub>、</sub>规模化生产的一体化经营模式; 二是生产要素融合，以现代技术改善要素供给质量和供给结构，推进农业技术创新<sub>、</sub>产品创新与价值提升; 三是发展理念融合，以可持续发展理念为指引，深入发展绿色<sub>、</sub>生态<sub>、</sub>低碳农业<sub>。</sub>

综上，农业供给侧结构性改革需以产业融合发展为支撑，从创新农业产业融合模式<sub>、</sub>优化配置农业要素 构建新型农业经营体系与健全农业社会化服务体系等方面推进 (1) 创新农业产业融合模式，延伸农业产业链<sub>、</sub>价值链<sub>。</sub> 农业与二三产业融合发展主要有两种方式: 第一，二三产业 <sup>“</sup>走进来<sup>”</sup>，即以服务业为主，将其引入农业生产流程，丰富农业生产内容，拓展农业经营模式;第二，农产品 <sup>“</sup>走出去<sup>”</sup>，实施农产品深加工战略，巩固开发品牌农业<sub>、</sub>绿色农业<sub>、</sub>信息农业<sub>。</sub> 前者更加注重<sup>“</sup>短链农业<sup>”</sup>，后者则强调的是<sup>“</sup>长链农业<sup>” “</sup>短链农业<sup>”</sup>强调的农业生产与农业消费一体化，通过引入农业消费新方式，既增加了农业附加值，也省去了农产品的加工 运输等环节，较好的实现了农产品产销一体化，是低碳农业发展的重要形式，如发展乡村休闲旅游 运用<sup>“</sup>生态 +<sup>” “</sup>旅游 + <sup>”</sup>等模式将农林业与旅游 文化 康养等产业深度融合等，符合中央一号文件中大力壮大新产业新业态的发展思路 <sup>“</sup>长链农业<sup>”</sup>着重突出农产品的深加工，实现农产品多样化以及通过品牌 国际化等战略提升农产品附加值 随着<sup>“</sup>互联网 + <sup>”</sup>技术的加速应用，该类产业融合模式日益丰富: 垂直一体化企业模式; 合同制联合模式; 电商平台模式; 农协组织模式等，信息化在催生新兴融合模式的同时正在不断培育出农业产业发展的新动能 (2) 优化配置农业要素要逐步深化农业要素市场改革: 落实农民土地财产权，盘活农村土地资源; 培育新型职业农民，增强农村人力资本积累;合理引入社会资本下乡，健全服务体系; 加强科技创新，培育优质品种，供给生态绿色农产品 通过健全农产品市场与要素市场，释放要素配置红利，实现农业发展由要素驱动向全要素生产率驱动转变，推动农业转型升级 (3) 创新农业经营体系 健全农业社会化服务体系 一方面要注重家庭农场 专业大户 农民合作社 农业龙头企业 <sup>“</sup>新农民<sup>”</sup>等新型经营主体的成长，同时通过发展农业生产性服务业为农业经营主体提供产业化 专业化 社会化的服务 同时，积极有序推进土地流转制度改革，扩大农业社会化服务规模，拓展农业规模经营实现形式，调顺和优化农业生产方式 资源要素配置方式，保障有效供给，推动农业供给侧结构性改革<sub>。</sub>
