# 市场导向 迭代式创新与新产品开发

李全升 苏 秦

（西安交通大学管理学院<sub>；</sub> 机械制造系统工程国家重点实验室<sub>；</sub>过程控制与效率工程教育部重点实验室）

摘要 基于资源基础观 探究不同市场导向通过迭代式创新影响新产品开发的作用机制以及沉淀性冗余资源和非沉淀性冗余资源的差异化调节效应 通过对国内316份制造企业样本数据的实证分析 发现相较于响应型市场导向 前瞻型市场导向对新产品开发的促进作用更强 前瞻型市场导向通过基于持续改进的迭代式创新影响新产品开发水平 响应型市场导向通过基于快速试错的迭代式创新影响新产品开发水平<sub>；</sub>非沉淀性冗余资源在两种市场导向与迭代式创新之间 及其与新产品开发之间均起正向调节作用<sub>；</sub>沉淀性冗余资源在响应型市场导向与基于快速试错的迭代式创新之间 及其与新产品开发之间均起正向调节作用 而在前瞻型市场导向与基于持续改进的迭代式创新之间 及其与新产品开发之间均起负向调节作用

关键词 市场导向 迭代式创新 新产品开发 非沉淀性冗余资源 沉淀性冗余资源

## 1 研究背景

以大数据 云计算 物联网等为代表的先进信息技术迅速发展 使得制造企业旧的研发生产方式和商业运营模式面临较大冲击 在新产品开发管道中 通过资源－能力分析可以量化开发项目对于资源的需求和资源的可获得性 而新产品开发的成功与否 与关键领域的有限资源分布有关 企业将有限的关键资源投放到成本较低的低风险项目上 往往会导致真正的创新项目被搁置或者得不到有效的资源保障 鉴于此 如何通过与客户持续交互和快速试错 将有限的关键资源用来满足客户需求 实现新产品开发成功 引起了学术界和管理人员的广泛关注<sup>［1］</sup> 多样化的市场需求和运营模式的涌现 要求制造企业转变运营逻辑 创新产品开发理念 强调客户需求为中心的创新思维 以满足短期和长期市场需求<sup>［2］</sup> 并提高新产品开发的成功率<sub>。</sub>

以往研究探索了市场导向与新产品开发之间的关系 认为二者之间可能存在线性关系<sup>［3］</sup>非线性关系<sup>［4］</sup> 抑或没有直接关系<sup>［5］</sup> 尚未形成统一的研究结论 平衡或分别探究两种市场导向的作用机制及其情境效应 也是形成二者关系不一致的主要原因 一方面 NARVER等<sup>［3］</sup>采取二分法 将市场导向划分为前瞻型市场导向和响应型市场导向 回应了上述争论 认为关注于客户的当下需求会使企业陷入<sup>“</sup>研发近视症<sup>”</sup> 降低企业创新活力 而满足客户尚未清晰表达的长期需求 则有助于提升企业的长期绩效水平 SLATER等<sup>［6］</sup> 研究发现 组织学习可以通过改善企业的市场导向行为质量而提升绩效水平 从能力视角出发 企业的能力整合 资源配置及协调能力对战略导向的实现具有促进作用 另一方面 有学者认为市场导向对新产品开发的影响依赖于情境 从权变观点出发 不同市场导向在新产品开发过程中的作用效果受到需求不确定性的影响<sup>［7］</sup>

综上所述 尽管已有学者开始探究不同市场导向对于新产品开发的影响 但该问题的探索仍存在缺口 不同市场导向对新产品开发影响的差异化 作用机理以及情境条件仍值得深入探究 鉴于此 本研究拟基于资源基础观 以国内进行或者完成战略转型的制造企业为研究对象 实证检验前瞻型市场导向和响应型市场导向对新产品开发的差异化影响和迭代式创新的作用路径 以及沉淀性冗余资源和非沉淀性冗余资源对上述关系的情境化作用

## 2 文献回顾与研究框架

## 2．1 市场导向的类型

对于市场导向的研究主要形成了两种代表性观点 分别是 NARVER 等<sup>［3］</sup> 的组织文化观以及 KOHLI等<sup>［8］</sup>的组织行为观 参考 NARV－ER等<sup>［3］</sup>的系统研究和后续学者的改进研究 前瞻型市场导向和响应型市场导向提供了两种不同的战略思维 具有既相对独立又优势互补的特性 但在保障组织战略实现和资源部署上需要考虑二者的差异性和平衡性<sup>［9］</sup> 前者强调面向客户的潜在需求 关注客户尚未表达的需求和竞争者的未来动态 引导企业开展探索性的资源开发活动 进而提供全新的产品和服务 而后者强调面向客户已表达的需求信息和竞争者显性策略表达 有助于企业理解 利用并及时响应客户的显性需求

以往研究大多关注响应型市场导向 认为企业只有通过挖掘现有市场上的客户资源与信息 采取跨边界 跨部门协作的方式 对市场变化及潜在市场机会做出响应 进而持续为客户创造价值并提升创新绩效水平 但这种<sup>“</sup>市场短视<sup>”</sup>行为逐渐受到学者们的抨击 他们认为面向市场的资源配置过程不仅能够识别并满足客户的现有需求 同时也能发现和满足客户尚未明确表达的需求 仅依赖客户明确提出的要求 很难在新产品开发过程中创造新的价值机会<sup>［10］</sup> 市场导向作用结果的不一致 表明需要探索不同形式的市场导向发挥作用的差异化机制 NARVER等<sup>［3］</sup>认为 只有前瞻型市场导向能够提升企业的产品创新能力 单纯依赖客户提出的需求来改进或者开发新产品 容易使企业陷入<sup>“</sup>创新近视症<sup>”</sup> 难以捕获新价值的创造机会 戴万稳等<sup>［11］</sup> 指出 前瞻型市场导向的企业采用探索式学习的方式 从客户尚未清晰表达或者尚未意识到的需求出发 追求差异化 先动性的市场行为 进而获得领先的竞争优势伍勇等<sup>［12］</sup>指出 市场导向能够提升企业的创新绩效 主要是由于其能够及时发现并响应客户的需求 从客户的现有需求出发进行分析 处理 响应型市场导向能够促使企业内部的信息共享和传播 以一种更加精准化的方式将新产品快速推向预期市场 产品／服务的周期比较短

从发现和响应客户需求的角度出发 本研究认为前瞻型市场导向更能够促进新产品开发 ①具有前瞻型市场导向的企业对客户需求有着更深的理解和应对能力 能够在客户提出新要求之前就预测或探索其需求变化趋势来提供解决方案 尤其在转型背景下 采用先进技术激活企业的休眠资源来实现客户的潜在需求持续不断地改良产品 以深化和加强对客户需求的理解和判断 推动新产品开发快速面向市场 响应型市场导向容易使企业陷入<sup>“</sup>成功陷阱<sup>”</sup> 囿于短期效益 在产业转型过程中丧失市场敏锐性 因而对新产品开发作用有限 ②具有前瞻型市场导向的企业能够通过整合市场资源来及时预测市场需求和变化 通过持续创新来引领市场 主动应对客户需求 使得新产品开发的速度 数量得以提升 进而提升新产品开发水平 相比于响应型市场导向 前瞻型市场导向关注企业的长期效益 致力于在转型背景中对高不确定性做出积极反应 持续改进产品和服务 形成更加具有市场潜力的新产品 具有响应型市场导向的企业则关注短期回报 聚焦客户的现有需求 客户关系维持在快速满足市场中表现出的需求上 <sub>，</sub> 并不强调企业的持久创新能力 对于新产品开发的影响存在局限性 基于此 提出如下假设

假设1 相比于响应型市场导向 前瞻型市场导向对于新产品开发的促进作用更大

## 2．2 迭代式创新

迭代式创新不同于以往的<sup>“</sup>瀑布流<sup>”</sup>产品开发模式 在开发过程和结果受到新技术的冲击及不确定环境的影响下 企业纷纷尝试转型 采取快速试验 持续迭代的微创新模式来提高新产品开发的成功率<sup>［13］</sup> 聚焦于产品开发过程迭代式创新的相关研究聚焦在3个方面 <sub>：</sub> ①迭代式创新的概念探索 指出迭代式创新具有参与广泛性 创新快速性 改进持续性 反馈及时性的4个基本特性<sup>［14］</sup> ②迭代式创新的主要特质 指出需要关注三方面的特质 即迭代实验用户实时反馈 创新时机与速度<sup>［15］</sup> ③迭代式创新的实施策略<sup>［16，17］</sup> 其中概念探索与实施策略已初步形成共识 而对于迭代式创新的主要特质存在多元化认识

以往研究关注于迭代式创新的关键特质与作用能力 对其中介作用进行了相关研究 林琳等<sup>［18］</sup>发现 互联网情境下战略试验能够通过体验 试错等实践过程来获取一手数据和信息而传统情境下基于市场导向 企业往往通过市场调研等方式获得二手数据 导致在互联网情境下市场导向对企业战略试验没有显著的直接影响 鲁诚至等<sup>［19］</sup>从区域层面上检验了试错创新的中介作用 构建了<sup>“</sup>市场发现－试错创新－创新价值实现<sup>”</sup>的区域创新过程演化模型 宁烨等<sup>［20］</sup>研究了跨文化情境下的组织试错学习机理 构建了试错学习的过程机理模型 尽管已有研究开始探究市场导向与迭代式创新之间的作用关系 但仍存在较大的研究空间 如传统企业转型背景下的迭代式创新的作用机制有何不同？如何定量化检验迭代式创新与新产品开发的关系？市场导向型企业如何通过迭代式创新来提升新产品开发水平仍有待深入探讨

为廓清迭代式创新对不同市场导向的企业在新产品开发过程中的作用路径 本研究借鉴朱晓红等<sup>［10］</sup>的观点 认为快速试错和持续改进是企业实现与客户实时交互 迭代开发的关键构面 从迭代式创新的特点出发 迭代式创新强调快速行动和不断试错 形成基于持续改进的迭代式创新和基于快速试错的迭代式创新两种方式 针对客户需求及时响应并做出调整 以快速推出新产品开发原型 据此 企业在转型背景下采取<sup>“</sup>先开枪 后瞄准<sup>”</sup>的市场导向和产品开发逻辑 借助与客户的频繁交互 快速推出并更迭产品原型 满足客户的现有需求和潜在需求 形成具有强产品粘性和高市场接受度的新产品 增强新产品开发的效率和响应能力

具体来看 响应型市场导向的企业一方面立足现有客户尚未完全解决的需求 基于客户体验的反馈优化产品创意 整个过程受客户需求和意见的引导 通过分析和应用市场信息拓展产品新功能 在与客户交流中快速试错 实现新产品开发的商业化决策 另一方面 针对既有的客户需求表达 成立专门的讨论小组 对客户需求表达中的技术不确定和市场环境模糊性的突出痛点进行试错更迭 获得反馈后采取针对性 专业化的分析和优化措施 进一步交互后识别其尚未满足的需求 以进行快速试错直至商业化 从而拓展市场 提升新产品开发成功率由此 具有响应型市场导向的企业聚焦现有客户的需求表达 采取快速试错的迭代式创新来提升新产品开发水平 基于此 提出如下假设

## 2．3 沉淀性冗余资源和非沉淀性冗余资源

根据资源的流动性 可将组织内的资源划分为 沉 淀 性 冗 余 资 源 和 非 沉 淀 性 冗 余 资源<sup>［21，22］</sup> 作为 组 织 显 性 或 隐 性 资 源 的 缓 冲器<sup>［23］</sup> <sub>，</sub>沉淀性冗余资源和非沉淀性冗余资源能够通过内部调整和外部协调来响应变革压力 <sub>，</sub>使组织战略适时调整以保障新产品开发水平二者与市场导向型企业的新产品开发之间的关系大致可以分为两类 ①线性关系 认为沉淀性冗余资源和非沉淀性冗余资源均能够提升企业的新产品开发水平<sup>［24］</sup> <sub>；</sub> ②非线性关系 最新的研究表明 沉淀性冗余资源和非沉淀性冗余资源与市场导向型企业的新产品开发水平之间存在倒 U型关系 过高或者过低水平的冗余资源水平 都会影响企业的市场导向形成 进而影响新产品开发水平<sup>［25］</sup>

对于沉淀性冗余资源 一方面其依赖于现有的战略市场规划和市场需求应对方案 能够保障企业在应对短期市场需求和环境挑战时更加可行 另一方面 沉淀性冗余资源具有路径依赖的特性 这使得企业内维持现有业务水平对资源的利用 进而以较小的资源争夺水平来实现合作快速试错 促进响应型市场导向对迭代式创新的影响 但这种路径依赖和锁定效应使企业受到客户的牵引 而失去对市场的主动性判断 持续改进客户的潜在需求面临较大的风险 企业内部会加剧对资源的争夺和抵制 不利于前瞻型市场导向与迭代式创新之间的关系形成 基于此 提出如下假设

假设3a 沉淀性冗余资源正向调节响应型市场导向与迭代式创新之间的关系 而负向调节前瞻型市场导向与迭代式创新之间的关系 <sub>。</sub>

非沉淀性冗余资源可谓<sup>“</sup>资源屏障<sup>”［26］</sup> 以往研究表明 非沉淀性冗余资源正向影响企业的创新绩效 能够帮助企业有效应对开发新产品和新市场所面对的挑战 非沉淀性冗余资源在不同市场导向的企业进行新产品开发的过程中承担必要的资源消耗 不仅可以通过整合企业内部的<sup>“</sup>休眠资源<sup>”</sup>来满足现有市场需求和客户体验 提供快速试错的资源支撑 还能够从外部获取所需的资源 提升资源的利用效率 探索潜在的市场需求 通过重配和利用资源进行风险性高的探索性活动 推动企业持续改进产品开发来响应客户的潜在需求 非沉淀性冗余资源水平越高 企业越能够发掘有用的客户关系来拓展市场 为响应客户的现有需求和潜在需求提供必要的资金等资源支持 应对新产品开发过程中的不确定性和风险性 不断试错持续改进 对产品开发进行迭代式创新 基于此 提出如下假设 <sub>：</sub>

假设3b 非沉淀性冗余资源正向调节响应型市场导向及前瞻型市场导向与迭代式创新之间的关系

## 2．4 被调节的中介效应

基于假设2a和假设3a以及假设2b和假设3b 本研究一方面假定响应型市场导向 （前瞻型市场导向）通过快速试错（持续改进） 的迭代式创新来促进新产品开发 另一方面 假定沉淀性冗余资源水平越高 有助于增强响应型市场导向与基于快速试错的迭代式创新之间的关系 <sub>，</sub>而削弱前瞻型市场导向与基于持续改进的迭代式创新之间的关系 综合而言 沉淀性冗余资源可能会对响应型市场导向 （前瞻型市场导向） 基于快速试错的迭代式创新 （基于持续改进的迭代式创新） 新产品开发的整个中介关系起调节作用 即本研究认为可能存在被调节的中介效应 具体而言 沉淀性冗余资源水平越高 响应型市场导向的企业可以提升储备的生产能力空间 加强负载利用效率 实现快速调整现有产品 加深对现有顾客与市场的了解 通过对客户需求和市场反馈做出极速响应 以较短的迭代周期来实现对现有的设计 开发 技术轨道进行迭代式创新 进而迅捷地将新产品推向市场<sup>［27］</sup> 相比于响应型市场导向 前瞻型市场导向在转型背景中 很难快速调用这些沉淀性冗余资源来满足持续改进的创新需求 这是由于沉淀性冗余资源作为一种组织成本嵌入在流程中 企业不愿意将沉淀性冗余资源应用到不确定性高的新产品开发过程中 进而囿于这种<sup>“</sup>锁定依赖<sup>”</sup> 而在与客户的持续交互中新产品开发活动受阻 基于此 提出如下假设

假设4a 沉淀性冗余资源正向调节基于快速试错的迭代式创新在响应型市场导向与新产品开发间的中介作用 且负向调节基于持续改进的迭代式创新在前瞻型市场导向与新产品开发间的中介作用

同样 非沉淀性冗余资源水平越高 响应型市场导向的企业可以充分利用这些富足的资金 资源等来进行大量的改进和优化行为 并且只有将非沉淀性冗余资源转化为沉淀性冗余资源 才能够为企业带来更多收益机会 推动企业在新产品开发过程中的快速试错创新 通过局部调整和快速响应来赢得确定性的回报 以促进新产品开发<sup>［28］</sup> 前瞻型市场导向的企业从长期目标出发 借助非沉淀性冗余资源来探索和挖掘资源的应用范围和识别使用范围 与客户建立长期交互关系 通过持续改进的产品需求迭代式创新和设计 投入到高需求不确定性 高市场和技术不确定性的创新探索过程中 进而开发出具有差异化和新颖性的产品来满足客户的潜在需求 基于此 提出如下假设

假设4b 非沉淀性冗余资源正向调节基于快速试错的迭代式创新在响应型市场导向与新产品开发之间的中介作用 且正向调节基于持续改进的迭代式创新在前瞻型市场导向与新产品开发间的中介作用

综上所述 本研究从资源基础观视角出发以基于快速试错的迭代式创新和基于持续改进的迭代式创新为中介变量 沉淀性冗余资源和非沉淀性冗余资源为调节变量 构建了制造企业转型背景下市场导向对新产品开发影响机制的概念模型（见图1）

## 3 研究设计

## 3．1 样本选择与数据收集

本研究采取问卷调研的方法 收集转型背景下市场导向型企业的新产品开发相关数据之所以选择制造企业转型背景 一方面 由于传统制造企业受到先进技术的冲击而产生的研发创新活动较为频繁 尤其是新产品的迭代式创新周期短 交互性强 另一方面 转型过程中强调面向客户需求聚焦客户价值实现 有利于收集和分析不同市场导向的企业采取何种迭代式创新方式和创新逻辑来响应客户需求 进而提升新产品开发的效率和效果

在预调研阶段 面向从事新产品开发和服务提供领域的 MBA学员展开 随机选取10名学员对初始问卷进行测试和评价 并根据反馈意见进行修正 形成最终问卷 在正式调研阶段 为避免同源偏差 每家企业填写两份问卷外生变量来自同一问卷 内生变量取自另一问卷 数据收集分两步进行 ①通过两化融合服务平台 （http<sub>：</sub> ／／cspiii．com／） 网站 <sup>“</sup>融合应用模块<sup>”</sup> 选取转型企业 主要集中于生物医药 电子信息技术 高端装备制造 新能源／材料开发领域 并筛选研发活动频繁 强调与客户进行交互的制造企业形成初始样本名单 ②采取滚雪球抽样的方式 借助电话邀约和发送电子邮件的方式 向企业高管阐明研究目的与意义 并随机发放500份问卷 分别由企业负责新产品／服务开发的高管（包含总经理 分管运行管理 财务管理 生产质量 技术产品开发的副经理 总工或总监等）填写 剔除缺失项较多 存在相互矛盾答案 填写时间过短（少于两分钟） 或只返回一份的无效问卷184份 最终回收有效问卷316份 有效回收率为63．2％

本研究对企业年龄和企业规模进行 T 检验 <sub>，</sub>结果表明 <sub>，</sub>未收回偏差尚未对抽样结果的有效性带来严重威胁 未回收样本与回收样本之间不存在显著的统计差异 样本企业的基本特征与分布为 <sub>：</sub> ①参与调查的企业高管年龄集中在35～45岁的占比为41．6％ 教育背景集中在本科（37．9％） 和研究生 （21．3％） 两个类别平均工作年限为5．1年 ②从企业存续时间来看 样本企业成立年限在 4～6 年的比率为45．7％ 7～10年的比率为30．4％ <sub>；</sub> ③从企业规模看 员 工 人 数 小 于 10 人 的 样 本 企 业 占21．6％ <sub>，</sub>员工人数在10～50人的样本企业占38．4％ 51～100人的企业数占34．8％ ④被调查行业中 生物医药行业占24．37％ 高端装备制 造 行 业 占 18．35％ 电 子 信 息 行 业 占32．64％ 新能源／材料开发行业占24．64％ ⑤样 本 企 业 类 型 中 国 有 企 业 21 家 占 比13．29％ 集体企业18家 占比11．39％ 民营企业84家 占比53．16％ 综上可知 遴选出的样本企业多为处于转型期的中小企业 以民营企业和国有企业为主 这也和现有研究与实践中中小型企业进行创新发展的转型需求相匹配

## 3．2 变量测量

本研究中所有变量均采用 Likert5级量表 1表示完全不符合 5表示完全符合 所有量表都参考了国内外具有代表性的文献

（1）新产品开发 参考 WEI等<sup>［27］</sup>开发的量表 新产品开发 （N ） 采用4个题项 主要测度新产品开发的成功率 响应市场的时间 开发周期以及市场潜力的程度

（2）市场导向 参考 NARVER 等<sup>［3］</sup> 开发的经典量表 前瞻型市场导向 $( P _ { \mathrm { ~ M ~ } } )$ 采用5个题项来测度 具体刻画企业预测市场趋势 持续关注客户需求 提前识别客户隐性需求等方面的程度 响应型市场导向 $( R _ { \mathrm { M } } )$ 也由5个题项测度 <sub>，</sub>具体反映企业快速识别 灵活相应 追踪客户需求以及满足客户显性需求等的程度

（3）迭代式创新 借鉴 DOU等<sup>［16］</sup> 的研究根据国内制造企业转型的背景 参考朱晓红等<sup>［10］</sup> 张腾等<sup>［15］</sup> 的研究 将迭代式创新划分为快速试错和持续改进2个维度 其中快速试错$( T _ { \mathrm { E } } )$ 采用3个题项反映超前性 具体通过对于用户需求 市场反馈的快速响应 较短迭代周期 对现有设计 开发 技术轨道等迭代超越来刻画 持续改进 $( C _ { \mathrm { { I } } } )$ 采用4个题项反映交互性具体通过用户主导 深度交互获取需求创意和解决方案 持续改进问题和需求 不断优化和改进创新结果等持续活动来刻画

（4）沉淀性冗余资源和非沉淀性冗余资源

参考李晓翔等<sup>［28］</sup> 的测量量表 沉淀性冗余资源（A ）用2个题项来测度 反映企业的生产能力和负荷运营能力水平 <sub>；</sub> 非沉淀性冗余资源$( U _ { \mathrm { s } } )$ 采用3个题项来测度 反映企业在未分配利润 客户保持 财务储备方面的水平

根据以往研究 企业规模 ${ ( F _ { \mathrm { s } } ) }$ 企业年龄$( F _ { \mathrm { A } } )$ 行业发展阶段 $( D _ { \mathrm { { s } } } )$ 环境不确定性 $( E _ { \mathrm { { T } } } )$ 对企业新产品开发影响较大 本研究同时将这些因素作为控制变量 其中企业规模采用企业员工总数取自然对数来测度 <sub>；</sub> 企业年龄采用调研年份减去成立时间再取自然对数来测度 行业发展阶段采取Likert5级量表来刻画 从1～5分别代表投入 初创 成长 成熟 衰退5个阶段 <sub>；</sub>以往研究认为 环境不确定性会影响新产品开发的创意表达和需求转化 因此 本研究将环境不确定性也作为重要的控制变量

## 5 研究结论与展望

通过以上研究 得到如下结论 ①相较于响应型市场导向 前瞻型市场导向对新产品开发的影响更大 ②不同市场导向的企业采取差异化的迭代式创新方式来促进新产品开发 即响应型市场导向通过基于快速试错的迭代式创新促进新产品开发 而前瞻型市场导向通过基于持续改进的迭代式创新来促进新产品开发 ③非沉淀性冗余资源在两种市场导向与迭代式创新之间及其与新产品开发之间均起正向调节作用 沉淀性冗余资源在响应型市场导向与基于快速试错的迭代式创新之间及其与新产品开发之间均起正向调节作用 而在前瞻型市场导向与基于持续改进的迭代式创新之间及其与新产品开发之间均起负向调节作用

本研究可以为转型背景下市场导向型企业开发新产品的实践提供如下管理启示 <sub>：</sub> ①面对快速更迭的技术和多样化的客户需求 企业在新产品开发的过程中应侧重于前瞻型市场导向 将新产品开发的重心调整于识别 整合 开发和探索市场的潜在需求 先于竞争对手领先市场 <sub>，</sub>进而获取持续的竞争优势 <sub>；</sub> ②企业需要综合其战略导向和市场趋势 从客户的短期与长期需求出发 将市场导向与迭代式创新进行匹配 以提升新产品开发水平 ③合理配置企业的沉淀性冗余资源和非沉淀性冗余资源 有助于提升新产品开发水平 由于新产品开发活动的不确定性较大 在中小型企业资源有限的条件下 发挥非沉淀性冗余资源可配置性高的优势可以为企业进行大量新产品开发探索和创新提供<sup>“</sup>失败屏障<sup>”</sup> 进而创造更多的新产品开发收益

本研究同时存在以下局限性 ①以迭代式创新作为关键中介路径 探究市场导向对新产品开发的影响 尽管采用二分法将其维度进行划分 但对于迭代式创新的重要使能机理仍有待进一步拓展 鉴于迭代式创新探索过程可能存在非线性效应 未来研究可以探索有关迭代式创新在二者关系中的非线性中介效应 ②从资源基础观出发 廓清了沉淀性冗余资源和非沉淀性冗余资源在市场导向与新产品开发之间的情境效应 但未进一步探究不同冗余资源水平的组合情境研究 未来研究中可以尝试将沉淀性冗余资源和非沉淀性冗余资源进行组合划分不同的研究组合情境来进行讨论 ③本研究是在制造企业转型背景下展开的研究 未来可以将研究对象拓展到服务型企业范围 <sub>；</sub> 同时可以尝试纵贯数据收集方法 为研究结论提供更加精确化的支持
