# 区域技术进步与国内国际双重价值链嵌入

何雅兴 a，余 婕 b

（西南财经大学 <sub>a.</sub> 统计学院；<sub>b.</sub> 公共管理学院，四川 成都 <sub>611130</sub>）

摘 要：技术进步是经济增长的重要动力，对发挥新发展格局构建过程中双重价值链嵌入的推动作用至关重要 从理论和实证两方面研究技术进步对双重价值链嵌入的影响，研究发现：第一，技术进步通过单一国内价值链分工 国内价值链和全球价值链融合的双重分工推动了国内价值链的深化 第二，技术进步的影响具有区域和部门异质性 西部地区的技术进步有利于抑制其嵌入浅层全球价值链分工；东部地区的技术进步对国内价值链嵌入的作用途径与全样本一致 高技术制造业部门的技术进步并没有使其更深入地嵌入价值链分工，特别是最为复杂的双重分工；其他部门的技术进步有利于抑制其嵌入浅层全球价值链分工，促进其更深入地参与国内价值链分工 第三，技术效率增长是技术进步影响双重价值链分工的主要途径

关 键 词：技术进步；国内价值链；全球价值链

## 一<sub>、</sub> 引言

十三届全国人大四次会议通过的 《中华人民共和国国民经济和社会发展第十四个五年规划和<sub>2035</sub> 年远景目标纲要》 （简称 <sup>“</sup>十四五<sup>”</sup> 规划） 明确指出，推动高质量发展必须 <sup>“</sup>坚持扩大内需这个战略基点……以创新驱动 高质量供给引领和创造新需求，加快构建以国内大循环为主体 国内国际双循环相互促进的新发展格局<sup>”</sup> 自 <sub>2001</sub>年中国加入世界贸易组织以来，通过出口导向型加工贸易嵌入全球价值链，中国在全球价值链中的参与度逐渐提高，成为世界第一大货物出口国和第二大经济体 然而，受国内要素禀赋结构的制约，中国制造业受困于全球价值链 <sup>“</sup>微笑曲线<sup>”</sup> 的底部 （<sub>F</sub><sub>d St k</sub>和 <sub>G ffi</sub>，<sub>2019</sub>）[1]在经贸摩擦逐渐加剧的现实背景之下，构建新发展格局，助力高质量发展，需要回答以下问题：随着产品分工的细化和全球价值链的国内延伸，中国各地区在参与国际分工和区域间协作中究竟获得了多少收益？技术进步作为推动经济增长的重要动力，能否改善中国各地区的双重价值链分工格局？回答这些问题，不仅有助于缓解中国在国际贸易中的被动局面，还有利于中国形成强大的国内市场，构建新发展格局 因此，本文立足国内价值链 （<sub>National Value Chain</sub>，<sub>NVC</sub>） 和全球价值链 （<sub>Global Value Chain</sub>，<sub>GVC</sub>） 的双重价值链分工，系统考察技术进步作为推动创新的重要动力对中国各地区双重价值链嵌入的影响

现有文献关于技术进步对价值链分工影响的研究主要集中在技术创新 技术升级 研发投入以及全要素生产率等对进出口贸易总值 贸易增加值以及价值链分工位置的影响 第一，技术创新 技术升级以及全要素生产率会影响进出口贸易，这主要体现在其对出口产品质量 出口额 出口收益等方面的影响 如，<sub>Bas</sub> 和 <sub>Strauss-Kahn</sub>（<sub>2015</sub>） 的研究表明技术进步能够提高企业的生产率，提升企业出口产品质量 [2]还有学者认为，发展中经济体的制造业技术进步会损害自身的出口额和出口收益（<sub>B d</sub> 等，<sub>2011</sub>）[3]但大部分研究发现，不同类型 不同渠道的技术进步对贸易流量存在一定的正向影响 如，<sub>B k</sub> 和 <sub>E</sub> （<sub>2013</sub>） 胡小娟和陈欣 （<sub>2017</sub>） 发现自主创新对出口具有明显的正向促进效应 [4- 5]第二，技术创新 研发投入 全要素生产率还会影响贸易增加值与价值链分工 技术和效率的提升将使得增加值率上升 （夏明和张红霞，<sub>2015</sub>），自主创新会动态改进企业出口中的国内增加值率 （诸竹君等，<sub>2018</sub>）[6- 7]技术进步还会改变主体参与全球价值链分工的位置 企业全要素生产率是影响企业全球生产链位置变动的重要原因 （唐宜红和张鹏杨，<sub>2018</sub>），提升技术效益和提高全要素生产率是改善中国制造业在全球价值链中不利地位的重要路径 （肖宇等，<sub>2019</sub>），研发强度带来的技术成果转化也会促进全球价值链位置的提升 （耿晔强和白力芳，<sub>2019</sub>）[8- 10]目前虽有部分研究从技术创新研发投入等方面分析了其对进出口贸易总值 贸易增加值以及价值链分工位置的影响，但这些概念与技术进步存在一定差别且本质不同 同时，这些研究更多的是探讨国际贸易或全球价值链分工，往往忽略了国内价值链分工

研究技术进步对双重价值链嵌入的影响必然涉及技术进步和双重价值链的测度 第一，对于技术进步的测度，基于内生增长理论和外生增长理论，学者们提出了多种技术进步的测算方法，主要包括基于 <sup>“</sup> 余值 <sup>”</sup> 思想的测算方法 （<sub>Olley</sub> 和 <sub>Pakes</sub>，<sub>1996</sub>；<sub>Levinsohn</sub> 和 <sub>Petrin</sub>，<sub>2003</sub>；<sub>Ackerberg</sub> 等，<sub>2006</sub>） 基于 <sup>“</sup>生产前沿面<sup>”</sup> 思想的测算方法 （<sub>Farrell</sub>，<sub>1957</sub>；<sub>Aigner</sub> 等，<sub>1977</sub>） 以及代理指标法 （郝楠和李静，<sub>2018</sub>）[11- 16]第二，对于双重价值链的测度，目前大量研究集中于对国内价值链或全球价值链的单独度量 价值链分工的测算依据研究视角的不同可以分为垂直专业化指数 （<sub>H l</sub> 等，<sub>2001</sub>）<sub>、</sub> 增加值贸易测算法 （<sub>Johnson</sub> 和 <sub>Noguera</sub>，<sub>2012</sub>；<sub>Koopman</sub> 等 ，<sub>2014</sub>） 和 上 下 游 度 测 算 法（<sub>A t</sub> à 等，<sub>2012</sub>；<sub>W</sub> 等，<sub>2017</sub>） 三类 [17- 21]然而，从总出口出发的分解方法复杂，结果也难以解释，特别是对出口国外增加值的重复计算部分，其经济含义并不明确，还可能存在错误 （<sub>B i</sub> 和<sub>M i i</sub>，<sub>2017</sub>）[22]从已有文献来看，基于投入产出模型的价值链分工研究已逐渐成熟，而有关国内价值链及其一国内部的区域异质性的研究还有待完善

本文从理论和实证两个方面深入分析技术进步对双重价值链嵌入的影响，致力于从技术进步和双重价值链分工的视角为构建新发展格局提供思路 可能的改进之处在于：第一，从投入产出视角提出了技术进步影响价值链嵌入的理论分析框架，从投入和产出视角考察了技术进步对价值链嵌入的影响 第二，在分析思路上，不再局限于对国内价值链和全球价值链的单一考量，而是将二者划分为更为细化的分工方式，纳入统一的分析框架，探索技术进步对不同价值链分工的影响 第三，在研究视角上，本文从整体 区域 部门的角度研究了技术进步对不同价值链分工嵌入程度的影响及其异质性，并从技术进步的构成分析了技术进步对价值链嵌入的作用机制

## （一） 无技术进步下的价值链嵌入

总产出可以分为中间产品和最终产品，技术进步体现在直接消耗系数矩阵 （A） 中，可分解为本国生产技术联系矩阵 $\mathfrak { q } ^ { \mathfrak { g } }$ 和国家间技术联系矩阵 $\mathit { \Omega } _ { \mathrm { ~ ( 4 ) ~ } }$ ） 那么，总产出可表示为式 （<sub>1</sub>）：

$$
\left[ \begin{array}{c} X _ {1} \\ X _ {2} \\ X _ {G} \end{array} \right] = \underbrace {\left[ \begin{array}{c c c c} a _ {1 1} & 0 & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & a _ {G G} \end{array} \right]} _ {A ^ {p}} \left[ \begin{array}{c} X _ {1} \\ X _ {2} \\ X _ {G} \end{array} \right] + \underbrace {\left[ \begin{array}{c c c c} 0 & a _ {1 2} & \cdots & a _ {1 G} \\ \vdots & \vdots & \ddots & \vdots \\ a _ {G 1} & a _ {G 2} & \cdots & 0 \end{array} \right]} _ {A ^ {r}} \left[ \begin{array}{c} X _ {1} \\ X _ {2} \\ \vdots \\ X _ {G} \end{array} \right] + \left[ \begin{array}{c} Y _ {1} \\ Y _ {2} \\ \vdots \\ Y _ {G} \end{array} \right]\tag{1}
$$

为便于表示，将上式简写为： $\stackrel { , } { X } = A ^ { D } X + A ^ { F } X + Y = \left( I - A ^ { D } \right) ^ { - 1 } Y + \left( I - A ^ { D } \right) ^ { - 1 } A ^ { F } X$ ，对应的增加值向量可以表示为式 （<sub>2</sub>）：

$$
V a ^ {\prime} = \hat {V} X = \hat {V} \left(I - A ^ {D}\right) ^ {- 1} Y + \hat {V} \left(I - A ^ {D}\right) ^ {- 1} A ^ {F} X\tag{0}
$$

其中， $\hat { V } \left( { \cal I } { - } A \right) ^ { D } \hat { \cal Y }$ 表示国内外最终产品需求带来的国内增加值，不涉及跨区域分工，因此不属于价值链分工<sub>。</sub> $\hat { V } ( { I } { - } A ) ^ { D } ) ^ { - 1 } A ^ { F } X$ 表示本国 （或地区） 生产中间产品后出口至其他国家 （或地区） 进入下一环节的生产，反映了中间产品的跨区域生产，属于价值链分工 本文将价值链分工带来的国内 （或区域内） 增加值与总产出之比作为价值链嵌入度（EMB），计算如下：

$$
E M B = \left(\hat {X}\right) ^ {- 1} \left[ \hat {V} \left(I - A ^ {D}\right) ^ {- 1} A ^ {F} X \right] = \left[ \frac {\sum_ {j \neq 1} ^ {G} V _ {1} a _ {1 j} X _ {j}}{\left(1 - a _ {1 1}\right) X _ {1}} \quad \frac {\sum_ {j \neq 2} ^ {G} V _ {2} a _ {2 j} X _ {j}}{\left(1 - a _ {2 2}\right) X _ {2}} \dots \frac {\sum_ {j \neq G} ^ {G} V _ {G} a _ {G j} X _ {j}}{\left(1 - a _ {G G}\right) X _ {G}} \right]\tag{3}
$$

由式 （<sub>3</sub>） 可知，国家 （或地区） <sub>1</sub> 的价值链嵌入度受两类因素的影响：一是投入因素，即本国（或地区） 和其他国家（或地区） 的直接消耗系数 $\mathsf { \Delta } \mathsf { G } _ { \mathrm { 1 1 } }$ 和 $a _ { 1 } )$ ） 以及本国（或地区） 的增加值系数（V）二是产出因素，即本国（或地区） 和其他国家（或地区） 的总产出 （X 和X）

## （二） 投入视角下考虑技术进步的价值链嵌入

从投入角度，技术进步可能表现为：第一，如果本国 （或地区） 中间投入与其他国家 （或地区）中间投入之间存在替代关系，生产等量产出使用的国内 （或地区内） 的投入比例有所增大 同时，相较于无技术进步的情况下，技术进步会使得等量产出下使用的所有投入更少（张红霞和夏明，<sub>2018</sub>）[23]第二，如果本国 （或地区） 与其他国家 （或地区） 的中间投入存在互补关系，生产等量产出使用的中间投入同比例减少 对于第二种情况，反映国家 （或地区） 间技术经济联系的直接消耗矩阵并不会发生变化<sub>。</sub> 因此，在接下来的分析中仅考虑第一种情况<sub>。</sub>

假设国家 （或地区） <sub>1</sub> 存在技术进步，直接消耗矩阵从A 转变为 $A _ { i n }$ ，如式 （<sub>4</sub>）：

$$
A _ {i n} = \left[ \begin{array}{c c c c} s _ {i n, 1} a _ {1 1} & a _ {1 2} & \dots & a _ {1 G} \\ \vdots & \vdots & \ddots & \vdots \\ s _ {i n, G} a _ {G 1} & a _ {G 2} & \dots & a _ {G G} \end{array} \right]; s _ {i n, k} \in \left\{ \begin{array}{l l} [ 1, \infty) & k = 1 \\ (0, 1) & k \neq 1 \end{array} \right.\tag{4}
$$

其中， $s _ { i n , k }$ 表示技术进步带来的投入修正系数<sub>。</sub> 如果国家 （或地区） <sub>1</sub> 存在技术进步，在生产等量产出的情况下，本国 （或地区） 的投入使用比例将有所增加， $s _ { i n , 1 } \geq \ 1 , \ d s _ { i n , 1 } \biggl / d T \dot { F } P _ { 1 } \geq \ 0$ 使用其他国家（或地区） 的中间投入比例将因为替代效应有所下降， $0 { < s _ { i n , k } < 1 \ r , \ d s _ { i n , k } \mathord { \left/ { \vphantom { \ d { \sum _ { i n , k } ^ { \prime } } } } \right. \kern - delimiterspace } } d T \dot { F } P _ { 1 } { < 0 \ ( k \ne \ 1 ) }$ <sub>。</sub> 技术进步还会使得等量产出下使用的投入更少，即 $\begin{array} { r } { \sum _ { k = 1 } ^ { G } s _ { i n , k } a _ { k , 1 } + s _ { i n , 1 } V _ { 1 } < \sum _ { k = 1 } ^ { G } a _ { k , 1 } + V _ { \mathrm { ~ 1 ~ } ^ { \circ } } \ { A } ^ { D } \ { _ \mathrm { ~ \setminus ~ } } \ { A } ^ { F } } \end{array}$ V 分别转变为 $A _ { i n } ^ { D } \setminus A _ { i n } ^ { F }$ $V _ { i n }$ ，如式 （<sub>5</sub>）：

$$
A _ {i n} ^ {D} = \left[ \begin{array}{c c c c} s _ {i n, 1} a _ {1 1} & 0 & \dots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & a _ {G G} \end{array} \right]; A _ {i n} ^ {F} = \left[ \begin{array}{c c c c} 0 & a _ {1 2} & \dots & a _ {1 G} \\ \vdots & \vdots & \ddots & \vdots \\ s _ {i n, G} a _ {G 1} & a _ {G 2} & \dots & 0 \end{array} \right]; V _ {i n} = \left[ s _ {i n, 1} V _ {1} \quad V _ {2} \quad \dots \quad V _ {G} \right]\tag{6}
$$

在国家 （或地区） <sub>1</sub> 存在技术进步的情况下，增加值向量 $V a$ 转变为 $V _ { \boldsymbol { a } _ { i n } }$ ，见式 （<sub>6</sub>）：

$$
V a _ {i n} ^ {'} = \hat {V} _ {l n} X = \hat {V} _ {l n} \left(A _ {i n} ^ {D} + A _ {i n} ^ {F}\right) X + \hat {V} _ {l n} Y = \hat {V} _ {l n} \left(I - A _ {i n} ^ {D}\right) ^ {- 1} Y + \hat {V} _ {l n} \left(I - A _ {i n} ^ {D}\right) ^ {- 1} A _ {i n} ^ {F} X\tag{6}
$$

那么，投入视角下的价值链嵌入度（EMB ） 可表示为式（<sub>7</sub>）：

$$
E M B _ {i n} = \left[ \frac {s _ {i n , 1} V _ {1} \sum_ {j \neq 1} ^ {G} a _ {1 j} X _ {j}}{(1 - s _ {i n , 1} a _ {1 1}) X _ {1}} \frac {V _ {2} (s _ {i n , 2} a _ {2 1} X _ {1} + \sum_ {j \neq 1 , 2} ^ {G} a _ {2 j} X _ {j})}{(1 - a _ {2 2}) X _ {2}} \dots \frac {V _ {G} (s _ {i n , G} a _ {G 1} X _ {1} + \sum_ {j \neq 1 , G} ^ {G} a _ {G j} X _ {j})}{(1 - a _ {G G}) X _ {G}} \right]\tag{6}
$$

$$

其中， $p$ 表示地区， 表示部门，<sub>t</sub> 表示时间， $T F \dot { P } _ { p s t }$ 表示技术进步， $E M B _ { l , p s t }$ 表示第 l 种分工形式的价值链嵌入度，l<sub>=</sub> （VC GVC NVC PGVC PNVC NGVC），分别表示价值链分工 <sub>GVC</sub> 分工 <sub>NVC</sub> 分工 单一 <sub>GVC</sub>分工 单一 <sub>NVC</sub>分工以及 <sub>NVC</sub>和 <sub>GVC</sub>融合的双重分工 $c o n t r o l _ { _ { p t } }$ 、 $c o n t r o l _ { s t }$ $c o n t r o l _ { p s t }$ 依次表示时间-地区 时间-部门以及时间-地区-部门层面的控制变量 <sub>ε</sub> 表示随机误差项， $\varepsilon _ { p s t }$ $\alpha _ { 0 }$ $\beta _ { \iota }$ 为待估参数， $\beta _ { 2 }$ $\beta _ { 3 }$ $\beta _ { 4 }$ 为待估参数向量

## <sub>2.</sub> 变量说明

（<sub>1</sub>） 被解释变量：不同分工形式的价值链嵌入程度 参考何雅兴等 （<sub>2021</sub>） 的做法，从特定区域的增加值出发，按照分工形式对其进行分解 [25]进一步结合理论模型，计算不同类型分工的价值链嵌入程度， $E M B _ { l , p s t } = V a _ { l , p s t } / X _ { p s t }$ $E M B _ { l , p s i }$ 和 $V a _ { l , p s t }$ 分别表示第 <sub>t</sub> 年地区 $p$ 部门 <sub>s</sub> 参与 l 类型的分工对应的价值链嵌入程度和增加值， $X _ { p s t }$ 表示第 $t$ 年地区 $p$ 部门 的总产出

（<sub>2</sub>） 核心解释变量：技术进步 技术进步由随机前沿生产函数模型测算的全要素生产率的增长来表示 （余泳泽， ）[26]选择此方法的原因在于：该方法不仅考虑了随机误差，而且能够进一步考察其构成，与传统的做减法的全要素生产率研究相比，更加深入和详尽 （王志平，<sub>2010</sub>）[24]

（<sub>3</sub>） 控制变量 地区层面控制了：各地区的高速公路里程；各地区到港口的距离的倒数；县域经济差距和市场分割度，县域经济差距为县级边界间的 <sub>GDP</sub> 之比，将其控制在 <sub>0 1</sub>，该值越大经济差距越小 市场分割度参照吕越等 （<sub>2018</sub>） 的价格法计算 [27]部门层面控制了产业集中度 地区部门层面控制了：固定资产合计 从业人数 平均工资水平；平均企业年龄；补贴收入 为减缓可能存在的异方差问题，对所有变量进行对数化处理

## <sub>2</sub> 稳健性检验<sup>①</sup>

本文从三个方面进行了稳健性检验：第一，更换核心解释变量 中国部分产业的相对产能过剩问题可能影响全要素生产率估计的准确性，借鉴余泳泽 （<sub>2017</sub>） 的研究，测算考虑产能利用率的技术进步，进行稳健性检验 [26]第二，更换被解释变量 将价值链嵌入度中的分母替换为流出和出口的中间产品，以反映价值链嵌入度，进行稳健性检验 第三，考虑内生性问题 考虑到技术进步与价值链嵌入之间可能存在的双向因果关系，此外也可能存在遗漏变量问题，因此需要考虑潜在的内生性问题将部门技术进步和各省级行政区到港口的距离倒数的平均水平作为工具变量，采用两阶段贝叶斯模型平均法进行回归 以上检验均验证了结果的稳健性

## 五<sub>、</sub> 结论与政策含义

本文从理论和实证两个方面分析了技术进步对双重价值链嵌入的影响，致力于从技术进步和双重价值链分工视角探索构建新发展格局推动中国高质量发展的可行路径 分析发现：技术进步有利于推动各区域更加深入地嵌入单一国内价值链分工 <sub>NVC</sub>和 <sub>GVC</sub>融合的双重分工，进而实现国内价值链的深化；技术进步对双重价值链的影响具有区域异质性和部门异质性；技术效率增长是技术进步影响双重价值链分工的主要途径 这些结论具有以下政策含义：

第一，促进国内价值链分工有效进行的前提是国内区域间生产要素 商品和服务的顺利流通，这就要求降低地区间的贸易壁垒，如强化数字技术配套基础设施建设，充分应用数字技术推动流通新业态 新模式健康有序发展 确保具有良好的区域贸易环境，优化各地区产业布局 第二，国内价值链和全球价值链融合的双重分工涉及国内区域间分工和其他国家间的全球价值链分工，东部地区和中低技术制造业部门作为中国参与全球价值链分工的主要地区和部门，应充分发挥它们在中西部地区与其他国家之间的桥梁作用 第三，西部地区要注重价值链分工结构的改善，避免过度嵌入或被动锁定于浅层全球价值链分工，应基于自身的资源禀赋优势和良好的区域贸易环境，加强其与东部地区的生产分工联系，带动西部地区更加深入地参与国内价值链分工，协调区域均衡发展，促进形成强大的国内市场
