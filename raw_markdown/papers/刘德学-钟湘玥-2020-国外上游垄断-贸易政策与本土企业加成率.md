# 国外上游垄断 贸易政策与本土企业加成率

刘德学，钟湘玥（暨南大学 经济学院，广东 广州 <sub>510632</sub>）

摘 要：考察国外上游垄断的经济效应对全面理解企业嵌入全球价值链的利弊具有重要意义 基于企业纵向关系论证国外上游垄断对企业加成率的影响及其作用机制，并进一步揭示贸易政策应对国外上游垄断问题的效果 研究结果表明：国外上游垄断与企业加成率呈倒 <sup>“</sup><sub>U</sub><sup>”</sup> 型的非线性关系，即国外上游垄断对企业加成率具有 <sup>“</sup>先促进，后抑制<sup>”</sup> 的作用；国外上游垄断通过 <sup>“</sup>生产成本<sup>”</sup> 效应直接作用于企业加成率；创新在国外上游垄断与企业加成率之间发挥中介作用，即国外上游垄断通过影响企业创新行为对其成本加成产生间接作用；不同性质贸易政策对国外上游垄断的加成率效应存在明显的异质性调节作用，关税措施对国外上游垄断效应产生弱化作用，而非关税措施具有强化作用

关 键 词：上游垄断；投入产出；企业加成率；贸易政策

## 一<sub>、</sub> 引言

自 <sub>20</sub>世纪 <sub>90</sub> 年代以来，随着生产和通信技术的不断发展，设计 研发 生产 营销及售后服务等产品增值环节逐渐实现在全球范围内的优化配置，以此为核心特征的全球价值链已经成为促进世界贸易和经济发展的国际分工主要模式 全球价值链分工对一国经济究竟产生什么影响？已有学者从宏微观层面 基于不同研究方法对这一问题进行相关研究 一些研究认为全球价值链有利于促进发展中国家的技术创新及生产率提升 （Bartel 等，2007；孙学敏和王杰，2016；Montalbano 等，2018） [1- 3]然而，全球价值链 <sup>“</sup>俘获<sup>”</sup> 理论表明，由于发达国家的阻碍，发展中国家面临着自主创新和价值链升级的困境，进而被 <sup>“</sup>俘获<sup>”</sup> 于价值链中低端位置 （Humphrey和 Schmitz，2002；张杰和郑文平，2017）[4- 5]

上述研究对本文开展国外上游垄断与发展中国家经济发展关系的研究具有借鉴意义，但既有研究鲜有直接讨论国外上游垄断对发展中国家本土企业盈利能力的影响 事实上，全球价值链分工环节的市场垄断程度具有差异性 其中，核心中间产品的研发 生产配置等高端环节进入门槛较高，长期由技术优势较强的少数发达国家掌控，呈现高度集中的市场垄断格局；加工 装配等中低端环节分散于广大发展中国家，市场垄断程度较低 在全球价值链中，发展中国家企业的技术创新与发展容易受制于发达国家科技含量较高的上游产品 中国作为参与全球价值链的主要发展中国家，虽然已成为世界制造业中心，但高端芯片 传感器 数控机床等核心中间产品仍然对国外上游行业具有较大的依赖性，企业绩效提升和产业转型升级长期受到国外上游行业的影响 因此，本文关注上游行业的国外垄断势力与中国本土企业盈利能力的关系 由于成本加成率是企业盈利能力的重要标志之一，本文重点探讨国外上游垄断对本土企业加成率的影响及作用机制 另外，既有研究表明贸易政策是影响企业生产及贸易行为的重要因素 （<sub>Feenstra</sub>和 <sub>Weinstein</sub>，<sub>2017</sub>），[6] 因此本文将贸易政策与国外上游垄断 企业加成率相联系，进一步讨论贸易政策对国外上游垄断效应的作用

相比已有研究，本文可能的边际贡献在于：第一，以国外上游垄断为切入点，讨论全球价值链嵌入对企业加成率的影响，更为贴近全球价值链分工格局 治理机制及上下游市场结构的客观现实 第二，基于上下游企业纵向关系构建国外上游垄断影响企业加成率的理论框架，识别国外上游垄断对企业加成率的影响及作用机制 第三，为了回答现有贸易政策措施是否有利于应对国外上游垄断这一问题，进一步分析不同类型的贸易政策对国外上游垄断效应的异质性作用，这对国外上游垄断情形下的贸易政策选择具有启示意义

## 二<sub>、</sub> 文献综述

中间产品进口是联系国外上游行业与本土企业发展的重要纽带，关于中间产品进口对企业绩效影响的研究与本文研究主题最为密切相关 这类文献最为丰富的是研究中间产品进口对企业生产率的影响<sub>Goldberg</sub>等 （<sub>2010</sub>） 研究较早指出，中间产品贸易开放对企业生产率乃至经济增长具有促进作用 [7]此后，相关研究采用微观企业数据为中间产品进口的生产率效应提供了经验证据 （<sub>Halpern</sub> 等，<sub>2015</sub>；Zaclicever <sup>和</sup> Pellandra，2018<sup>） [8-</sup> <sup>9]从中国企业相关的经验研究来看</sup>，<sup>张杰等 （</sup>2015<sup>） 魏浩等 （</sup>2017<sup>）</sup>发现中间产品进口有利于提高企业技术水平，进而促进生产率的提升 [10- 11]生产率并不能充分反映企业盈利能力，为了进一步揭示中间产品进口对企业盈利能力和市场竞争力的影响，已有研究关注中间产品进口对企业加成率的直接作用 <sub>Fan</sub> 等 （<sub>2018</sub>） 证实中间产品进口通过降低边际成本对企业加成率产生促进作用 [12]

但是中国企业多通过加工贸易嵌入全球价值链，价值链地位普遍处于中低端位置，由此中间产品进口并不必然促进中国企业加成率的提升 毛其淋和许家云 （<sub>2017</sub>） 以中国加入 <sub>WTO</sub>为准自然实验分析中间产品进口对企业加成率的影响，研究指出中间产品进口对企业加成率的促进作用在长期存在递减趋势 [13] 黄先海等 （<sub>2016</sub>） 的研究发现中间产品进口企业相比于非进口企业具有更低的成本加成率，证实了中间产品进口对中国企业加成率的负向效应 [14] 诸竹君 （<sub>2017</sub>） 的研究表明，中间产品进口使企业加成率显著下降，尤其是加工贸易和混合贸易企业呈现明显的负向效应，处于全球价值链中低端位置是企业未从中间产品进口获得正向加成率效应的主要原因；从不同所有制和行业要素密集度异质性来看，非国有制企业及劳动密集型行业的全球价值链地位较低，从而企业加成率在进口中间产品之后出现更大程度的下降 [15]

与本文相关的第二类文献是贸易政策对企业市场行为及市场结构的影响研究 从关税措施方面来看，关税下降扩大了相对市场范围，进而导致本土企业的竞争对手增加，即关税削减具有<sup>“</sup>促进市场竞争<sup>”</sup> 效应 （<sub>De Loecker</sub> 等，<sub>2016</sub>）[16]一方面，关税措施的 <sup>“</sup>促进市场竞争<sup>”</sup> 效应对企业产品价格具有抑制作用 钱学锋等 （<sub>2016</sub>） 的研究表明，关税下降带来进口竞争压力，本土企业选择降低产品价格以应对同类产品竞争 [17] 另一方面，关税措施的 <sup>“</sup>促进市场竞争<sup>”</sup> 效应还有利于促进企业降低生产成本 产品价格随关税下降而降低是企业短期决策的结果，而在长期，关税下降会提升企业进入市场的临界生产率水平，企业需及时调整生产过程，采取成本降低策略才能在竞争更为激烈的市场中存活（<sub>Melitz</sub>和 <sub>Ottaviano</sub>，<sub>2008</sub>）[18]此外，关税下降对本土企业存在 <sup>“</sup>成本节省<sup>”</sup> 效应和 <sup>“</sup>质量促进<sup>”</sup> 效应 祝树金等 （<sub>2018</sub>） 研究表明，中间产品关税下降直接降低了企业中间投入成本，同时，高质量中间产品价格的降低有利于鼓励企业进行研发创新，提高企业产品质量水平 [19]

从非关税措施的既有文献来看，<sub>Fernandes</sub> 等 （<sub>2019</sub>） 研究认为非关税措施增大了国外企业进入本土市场的沉没成本，市场份额向生产率较高的企业转移 [20] 非关税措施对市场份额的影响进一步对中间产品种类产生作用，从而非关税壁垒的降低有利于增加中间产品多样性 （<sub>Felbermayr</sub> 和 <sub>Jung</sub>，<sub>2011</sub>）[21]非关税措施对贸易既有消极影响，也存在积极作用 <sub>Chakraborty</sub>等 （<sub>2020</sub>） 的研究表明，技术性非关税措施的实施同时增加了来源于合规企业产品的进口 [22] 非关税措施的实施会增大本土企业进口中间产品的成本，这与关税措施效应相一致，但上述研究局限于非关税措施与关税措施的相似之处，未识别非关税措施相对于关税措施的异质性影响 由于非关税措施的实施以 <sup>“</sup>非歧视性<sup>”</sup> 原则为准，无论国外企业还是国内企业，在非关税措施实施后均会面临更高服从成本，只有竞争力较强的企业才能在本土市场幸存并获得更大的市场份额，<sub>Asprilla</sub> 等 （<sub>2019</sub>） 由此认为国外企业相对国内企业更具竞争力，非关税措施助长了国外企业市场势力，反而不利于国内企业的发展 [23]

比较国外上游垄断的质量效应和价格效应：质量效应 $\left| \frac { \partial M a r k u p _ { s } } { \partial c _ { s } } \frac { \partial c _ { s } } { \partial c _ { 3 s } } \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \partial \eta } { \partial N } \right|$ 与价格效应$\frac { \partial M a r k u p _ { s } } { \partial c _ { s } } \frac { \partial c _ { s } } { \partial p _ { F } } \frac { \partial p _ { F } } { \partial N } \Bigg |$ 之差的约简式为 $|  \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \eta } { c _ { 3 s } } | - 1$ ，已知 $\frac { 1 } { \partial { c } _ { 3 s } }$ 为国外中间产品的边际生产率，$\left| \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \eta } { c _ { 3 s } } \right|$ 为中间产品边际生产率的质量弹性 若 $\left| \ \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \eta } { c _ { 3 s } } \right| > 1$ ，即企业的国外中间产品边际生产率富有质量弹性，国外中间产品质量提高引致生产效率提升的幅度较大，正向的质量效应大于负向的价格效应，此时国外上游垄断对本土企业加成率形成正向的总效应；反之，若 $0 < \left| \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \eta } { c _ { 3 s } } \right| < 1$ ，即企业的国外中间产品边际生产率缺乏质量弹性，国外中间产品质量提高引致企业生产率提升的幅度较小，正向的质量效应小于负向的价格效应，此时国外上游垄断对本土企业加成率形成负向的总效应 进一步地，对式 （<sub>1</sub>） 和式 （<sub>2</sub>） 求N的偏导数可得国外上游垄断的质量效应和价格效应的变化速率，由此可知，质量效应随着垄断程度的升高而减小，价格效应随着垄断程度的升高而增大 在初始水平时，若正向的质量效应大于负向的价格效应 $( \left. \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \eta } { c _ { 3 s } } \right| > \mathfrak { h }$ ，国外上游垄断对本土企业加成率有促进作用，但这一促进作用趋于减小并在垄断程度升高至一定水平时转变为抑制作用；反之，若负向的价格效应大于正向的质量效应 $\wp < \left| \frac { \partial c _ { 3 s } } { \partial \eta } \frac { \eta } { c _ { 3 s } } \right| < \hbar$ ，国外上游垄断对本土企业生产率有抑制作用且趋于增大

理论假设 <sub>1</sub>：国外上游垄断对企业加成率有两种作用相反的生产成本效应，其一是正向的质量效应，质量效应有利于生产成本下降，从而促进企业加成率的提升 其二是负向的价格效应，价格效应

导致生产成本上升，不利于企业加成率的提升

理论假设 <sub>2</sub>：在质量正效应和价格负效应的双重生产成本效应作用下，国外上游垄断对企业加成率的总效应表现为 <sup>“</sup>先促进，后抑制<sup>”</sup> 的作用或纯粹的抑制作用，即国外上游垄断与企业加成率之间存在倒 <sup>“</sup><sub>U</sub><sup>”</sup> 型的非线性关系或负向相关关系

## 六<sub>、</sub> 拓展性分析：贸易政策的作用

贸易政策在稳定国内经济和增强对外适应性方面具有重要作用 而对于国外上游垄断问题，贸易政策能否起到趋利避害 改善本土企业外部发展环境的作用？本文通过检验两种贸易政策措施对国外上游垄断效应的异质性影响来尝试回答这一问题 其中，关税措施 （T<sub>ar</sub>i<sub>ff</sub>） 由中间产品关税 i<sub>ntertar</sub>i<sub>ff =</sub>∑<sub>w</sub> i<sub>ntertar</sub>i<sub>ff</sub> 衡量，其中<sub>f</sub>i<sub>na</sub>lt<sub>ar</sub>i<sub>ff</sub>为上游行业的最终产品关税， $w _ { i j t }$ 为 i 行业占<sub>j</sub> 行业中间投入的比重；参照 Cadot和 Gourdon（2016） 的方法量化非关税措施 （N -t iff），通过 $\ln v _ { j k } { = } \alpha { + } \beta _ { _ 1 } N _ { j k } { + } \beta _ { _ 2 } \ln \left( 1 { + } t _ { j k } \right) { + } X _ { j } { + } Z _ { j } { + } \varepsilon _ { j k }$ 估计非关税措施对贸易产品平均价值的影响系数，计算得到非关税措施等价当量 $\scriptstyle A V E s = { \beta _ { 1 } } { \gamma _ { j } ^ { - 1 } }$ ，<sub>γ</sub> 为产品需求弹性 [28]相关数据来源于联合国贸易与发展会议 （<sub>UNCTAD</sub>） <sub>TRAINS</sub>数据库

<sub>1.</sub> 关税措施的调节作用 从表 <sub>4</sub> 列 （<sub>1</sub>） 的回归结果来看，交互项 T<sub>ar</sub>i<sub>ff×</sub>FU<sub>mono o</sub>l 的系数显著且与国外上游垄断的回归系数方向相反，由此可见，国外上游垄断对中间产品进口关税水平较高企业的成本加成影响较小，即关税措施对国外上游垄断对成本加成率的质量正效应和价格负效应同时具有削减作用 主要原因可能在于：进口关税直接抬高国外上游产品的进口价格，这不仅增加了企业对于国外上游产品的直接使用成本，还通过国内价值链传导机制增加了企业间接使用国外上游产品的成本 国外上游产品使用成本的提升一定程度上造成国内上游产品对国外上游产品的替代，从而本土企业成本加成受到国外上游垄断的影响变小

<sub>2.</sub> 非关税措施的调节作用 从表 <sub>4</sub> 列 （<sub>2</sub>） 的回归结果来看，交互项 N<sub>on</sub>-t<sub>ar</sub>i<sub>ff×</sub>FU<sub>mono o</sub>l 的系数显著且与国外上游垄断的回归系数方向一致 一方面，非关税措施实施力度的增强增大企业获得高质量国外上游产品的可能性，有利于加强国外上游垄断对企业加成率的质量正效应 本文对此可能的解释在于：非关税措施尤其是技术性措施有利于激励国外企业进行研发创新 提高产品质量水平，而产品创新需要企业付出高昂的研发投入成本，产品质量的维续还会产生持续性成本，规模较大 资金基础较雄厚的企业更可能从产品创新中获利 因此，非关税措施所致产品质量的提升大概率上来源于国外上游垄断企业，这表明非关税措施有利于发挥国外上游垄断的质量正效应 另一方面，非关税措施对国外上游垄断的价格负效应也具有强化作用 非关税措施的实施同时增大了国内企业和国外企业于本土市场的进入成本，而规模较大 技术水平较高的企业才更可能进入或留存于本土市场 由于上游行业的国外垄断企业相比于其他企业不仅具有规模和技术方面的优势，还具有市场地位上的优势，非关税措施会对国外上游垄断企业及其他企业的相对市场份额产生马太效应，即强者越多，弱者越少 因此，非关税措施增强国外上游垄断企业相对于本土企业的市场势力，增强了国外上游垄断对企业加成率的抑制作用

## 七<sub>、</sub> 结论与政策启示

本文构建了国外上游垄断影响本土企业加成率的理论框架，并就此采用中国工业企业数据和<sub>Osiris</sub> 全球企业数据考察国外上游垄断对企业成本加成率的作用机理，主要研究结论是：<sub>(1)</sub>国外上游垄断与本土企业加成率之间存在显著的倒 <sup>“</sup><sub>U</sub><sup>”</sup> 型关系 <sub>(2)</sub>国外上游垄断对企业加成率的直接影响机制在于 <sup>“</sup>生产成本<sup>”</sup> 效应，国外上游垄断对边际生产成本 <sup>“</sup>先降后升<sup>”</sup> 的作用直接对成本加成率形成<sup>“</sup>先促进，后抑制<sup>”</sup> 的效应 <sub>(3)</sub>创新是国外上游垄断影响企业加成率的间接渠道，国外上游垄断<sup>“</sup>先促进，后抑制<sup>”</sup> 的效应部分通过创新作用于成本加成率 <sub>(4)</sub>不同贸易政策措施具有异质性调节作用，关税措施对国外上游垄断效应存在弱化作用，非关税措施则对国外上游垄断效应产生了强化作用

## 基于上述研究结论，本文得到如下启示：

第一，正确看待国外上游垄断与企业盈利能力的关系 国外上游垄断势力是企业嵌入全球价值链利弊得失的重要影响因素，虽然国外上游垄断势力对企业盈利能力具有抑制作用，但当垄断程度较低时，参与全球价值链分工 获取国外高质量中间产品和先进技术仍然是本土企业增强盈利能力的有效途径

第二，积极发挥创新中介作用 创新是国外上游垄断影响企业盈利能力的重要渠道 一方面，较高的创新和吸收能力有助于企业在国外中间产品使用中实现技术进步，进而强化创新对国外中间产品正向效应的传导作用 另一方面，自主创新可以降低本土企业对国外中间产品的依赖程度，弱化国外上游垄断对企业创新活动及其绩效提升的消极影响，有利于企业在国外上游垄断下实现持续发展

第三，灵活制定和实施贸易政策 尽管贸易政策无法改变价值链格局和上下游市场结构，但对国外上游垄断的影响具有重要调节作用，因此政府可以通过实施贸易政策来有效地应对国外上游垄断问题 不同性质贸易政策措施的应对效果存在差异，当国外上游垄断程度较低时，采取非关税措施可以强化国外中间产品对企业盈利能力的促进作用 随着国外上游垄断程度越过临界值达到较高水平时，要通过关税措施来抵御国外上游垄断的消极作用

第四，实施行业差异化政策并适时动态调整 不同行业所面临的国外上游市场结构存在差异，各个行业对国外上游垄断的敏感性也有所不同，因此要根据各行业自身发展特点和国外上游具体情况采取针对性应对策略，尤其要对国外上游垄断程度越过临界值的行业给予重点关注 同时，随着行业价值链地位 国外上游市场结构以及国内外竞争格局的变动，国外上游垄断对企业盈利能力的影响不断发生变化，制定国外上游垄断的应对策略要具有前瞻性，与时俱进地调整创新 贸易等相关政策

# Foreign Upstream Monopoly, Trade Policy and Local Firm's Markup Ratio

LIU De-xue, ZHONG Xiang-yue

(Jinan University, Guangzhou 510632, China)

To investigate the economic effects of foreign upstream monopoly is of great significance for an overall understanding of the pros and cons of enterprises embedding in global value chains. Based on the longitudinal relationship of enterprises, this paper expounds and verifies the impact of foreign upstream monopoly on enterprises <sup>’</sup> markup ratio and its action mechanism, then it further reveals the effects of trade policies in addressing the problems of foreign upstream monopoly. The results suggest that foreign upstream monopoly and firm <sup>’</sup> s markup ratio present an <sup>“</sup> inverted U-shaped<sup>”</sup> nonlinear relationship, that is, foreign upstream monopoly has the <sup>“</sup>first promoting then inhibiting<sup>”</sup> effect on the firm <sup>’</sup> s markup ratio. Foreign upstream monopoly directly affects the corporate markup ratio through the <sup>“</sup> production cost<sup>”</sup> effect. Innovation plays an intermediary role between the foreign upstream monopoly and the corporate markup ratio, that is, through affecting enterprises <sup>’</sup> innovative behavior, the foreign upstream monopoly exerts an indirect effect on their cost plus. Trade policies of different natures have obvious heterogeneous adjustment effects on the markup ratio of the foreign upstream monopoly. Tariff measures have a weakening effect on foreign upstream monopoly effects, while non-tariffs measures have a strengthening effect.
