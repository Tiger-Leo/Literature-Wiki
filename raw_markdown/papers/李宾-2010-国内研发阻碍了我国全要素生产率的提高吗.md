# 国内研发阻碍了我国全要素生产率的提高吗?

李 宾( 湖南科技大学商学院，湖南湘潭 411201)

摘 要:研发活动促进生产率的提高似是一个常识，但对于我国，这一常识受到了质疑 文献中出现了两种不同的看法，一方认为我国国内研发对 TFP 的提高没有起到应有的促进作用，甚至起着阻碍的作用 这里以近期文献对 TFP 的重新测算为基础，观察了国内研发和国外技术溢出对我国 TFP 的影响<sub>。</sub> 在分析过程中，考虑了序列平稳性 内生性 残差序列相关性等细节 所得的结果支持质疑这一方的观点 进而，通过对比国内外研发状况，对这一悬疑给出了一个直觉解释

关键词:全要素生产率;研发;技术溢出;基础研究

中图分类号: F204

文献标识码:A

研发投入可促进生产率的进步，这是一个常识，但这一常识在我国却存在争议<sub>。</sub> 鉴于全要素生产率( TFP) 被视为可测量的技术进步的表现形式，所以常以它来代表生产率的进步 在研究是什么因素促进了我国 TFP 的提高时，可区分出两种途径，一是国内的自主创新，二是国外的技术转移或技术外溢已有的研究大多并不否认国外技术溢出的正面作用，但在国内研发对我国 TFP 提高的影响上，则形成了两种不同的观点 一种观点支持研发对生产率有显著正向影响<sup>［1</sup> <sup>－</sup> <sup>4］</sup>，另一种观点则认为我国研发对生产率的提高没有显著的正向效果或者影响不稳定<sup>［5</sup> <sup>－</sup> <sup>8］</sup>，甚至，国内研发的作用是负面的<sup>［9］</sup> 前者与常识相符，故无需解释; 后一种观点与常识相悖，而相关文献并未给出充分的解释<sub>。</sub> 那么，我国的国内研发是否阻碍了生产率的提高呢? 若无法拒绝这一判断，它背后的机制又是怎样的呢? 这两个问题构成此文观察研究的出发点

鉴于通过对宏观总量数据的分析就足以回答上述问题，故研究的方法是采用单方程的计量回归，以我国 TFP 的变动率为因变量，以研发投入和国外技术溢出为解释变量 这一看似简单的思路实则牵涉到许多技术处理上的问题<sub>。</sub> 首先，在计量模型的设定上，同时考虑国内研发投入与国外技术进步的传入，可更好地覆盖 TFP 提高的来源 其次，TFP 是需要测算的，测算结果准确与否对后面的回归分析至关重要 这里沿用近期的一个新测算<sup>［10］</sup>，其中历年资本存量采用新增固定资产数据序列来计算，这比采用固定资产净值 固定资本形成额 全社会固定资产投资额的数据更合理 再者，在回归分析中注重规范性，在回归之前先判断数据序列的平稳性，也考虑了研发与 TFP 之间相互影响的内生性问题 下面将先说明计量模型和数据的准备，再列出回归分析过程，然后通过对比中国 美国 日本的研发状况给出直觉分析，最后是结束语

## 1 计量模型与数据准备

为了判别我国生产率提高的来源，这里以国内TFP 增长率为因变量，以国内研发指标 国外技术溢出 国内 TFP 增长的滞后项为解释变量，做最小二乘回归( OLS) 相应的计量模型表示如下:

$$
\begin{array}{r l} \mathrm{CTFP} _ {\mathrm{t}} & = \beta_ {0} + \beta_ {1} \times \mathrm{S} _ {\mathrm{t}} + \beta_ {2} \times \mathrm{R} _ {\mathrm{t}} + \beta_ {3} \times \mathrm{CTFP} _ {\mathrm{t-1}} + \\ \beta_ {4} \times \mathrm{CTFP} _ {\mathrm{t-2}} + \varepsilon_ {\mathrm{t}} & (1) \end{array}
$$

其中， $, \mathrm { C T F P _ { t } }$ 代表我国在第t 年全要素生产率的变动率， $\mathsf { \beta } _ { 0 } \cdot \mathsf { \beta } _ { 1 } \cdot \mathsf { \beta } _ { 2 } \cdot \mathsf { \beta } _ { 3 } \cdot \mathsf { \beta } _ { 4 }$ 是待估计系数， $\mathrm { S } _ { \mathrm { t } } \boldsymbol { \cdot } \mathrm { R } _ { \mathrm { t } } \boldsymbol { \cdot } \varepsilon _ { \mathrm { t } }$ 分别代表国外技术溢出项 国内研发项和随机扰动项 下面说明对各指标数据的选取与准备

## 1.1 我国全要素生产率的变动率

文献中对我国 TFP 的估算结果，差异较大<sub>。</sub> 这里选用近期的一个修正结果<sup>［10］</sup> 它较大地调整了早期文献所做的估计，得出了我国 TFP 增长率在2000 年前后不接近于零的判断，而这一判断与我国近年来持续的高速增长事实相一致 因它的估算结果只提供到 2007 年，故需延展到 2008 年<sub>。</sub> 计算的方法是采用 Tornqvist 指数法，即要素收入份额是可变的，计算公式为:

$$
\begin{array}{r l} \Delta \mathrm{A} / \mathrm{A} & = \Delta \mathrm{Y} / \mathrm{Y} - (1 - \eta_ {\mathrm{t}}) \times \Delta \mathrm{K} / \mathrm{K} - \eta_ {\mathrm{t}} \times \\ \Delta \mathrm{L} / \mathrm{L} & \end{array} \tag {2}
$$

其中，A 代表技术水平，即全要素生产率，Y 代表当年的总产出 GDP，K 为资本存量，L 为劳动投入，符号 $\triangle$ 代表一个变量在当年相对于上一年的变动; 另外， $\eta _ { \mathrm { t } } = \mathrm { ~ ( ~ } \alpha _ { \mathrm { L } } \big ( \mathrm { ~ t - 1 ~ } \big ) \ + \alpha _ { \mathrm { L } } \big ( \mathrm { ~ t ~ } \big ) \ \mathrm { ~ ) ~ } / 2 , \alpha _ { \mathrm { L } } \big ( \mathrm { ~ t ~ } \big )$ 代表 t 期劳动收入在产出中的份额<sub>。</sub>

延展所需的新数据，在 《2009 －中国统计摘要》中均可找到 而且发现，国家统计局对近年的部分宏观数据做了更新 所以，在延展过程中也一同对近年的估算进行了更新 再考虑到 2008 年发生了冰灾 四川大地震等特大灾害，大量物质资本被破坏，所以在估算2008 年实际资本存量时，在2007 年资本存量的基础上额外扣减了千分之一 更新了的TFP 变动率序列见表1 从中注意到，虽然我国 TFP增长率在2000 年前后并没有接近0，但在2008 年却触及到了零点，当年 TFP 变动率是 －0.06% 这是否意味着我国的经济发展到了阶段性转折点，还有待观察<sub>。</sub>

## 1. 2 国外技术溢出

关于国外技术溢出的设定，文献中有多种不同的方式，这儿结合两种典型的处理方法<sup>［11］［12］</sup>，用国外技术进步率乘以我国的对外开放度，代表国外的技术进步对我国的传入<sub>。</sub> 这又涉及到两个问题，一个是国外技术进步率的指标怎样选取，另一个是我国的对外开放度指标如何构造

关于前者，有的文献使用国外研发数据<sup>［11］</sup>，有的则使用国外 TFP 增长率<sup>［12］</sup><sub>。</sub> 考虑到从研发到新技术的成型，通常要经过数年的时间，而一国 TFP变动率指标，是已经成型了的技术进步，时效性要好一些，所以本文采用后一种方式 具体而言，因美国基本上一直是世界经济和科技的领头羊，所以取美国的 TFP 变动率作为国外技术进步的来源<sub>。</sub> 而在测算美国 TFP 时，为了与中国的计算方法一致，也采用 Tornqvist 指数法<sub>。</sub> 对其劳动的度量，采用就业1994-2023China Academic lourn于Electronic人数指标 所有必要的数据，均取自于美国商务部经济分析局的网站<sub>。</sub>

对于开放度指标，有的文献强调国际贸易渠道，使用进口额除以 $\mathrm { G D P } ^ { \mathrm { \scriptsize ~ [ 1 ] } }$ <sup>］</sup>;有的文献则强调外商直接投资渠道( FDI) ，用 FDI 除以 GDP<sup>［5］</sup> 由于难以明确判断哪个指标更好，所以将两个都采用，并额外考虑进口额与 FDI 之和占 GDP 的比例，即总共观察三种开放度指标<sub>。</sub> 我国的名义 GDP<sub>、</sub>进口额<sub>、</sub>外商直接投资额及人民币对美元的汇率，都来自历年 《中国统计年鉴》和 《2009 －中国统计摘要》

## 1. 3 国内研发

研发投入是一国推动自己技术前沿的一条重要途径，在分析 TFP 提高的来源上是一个必需考虑的因素 但在计量回归中，如何选取研发指标却是一件难事 其原因在于，从后文的技术分析看，无论是研发投入本身还是研发强度( 即一国研发投入额与该国 GDP 的比值) ，都不是平稳序列，从而不能直接用于对平稳变量的回归 笔者考虑四种指标，分别是研发强度的对数 研发强度的直接差分 研发强度的一阶对数差分和实际研发投入增长率 决定某个指标能否被使用的前提，是看该序列是否平稳 具体的研发数据序列来自中国科技部网站，涵盖 1987－ 2008 年 。

## 1.4 内生性控制

在由(1) 式所代表的计量模型中加入国内 TFP变动的滞后项的做法，其作用主要是控制潜在的内生性问题 单方程的回归模型都暗含了一个假设，即解释变量是外生于被解释变量的，但这样的假设在现实中常常不一定成立，被解释变量也能反过来通过某种渠道影响到解释变量，此即内生性问题在这里，虽然研发推动技术进步是一个直接的逻辑关系，但是技术进步可通过 GDP 的提高来迂回地影响到研发变量 这一点已在文献中有证据<sup>［8］</sup>

解决内生性问题的方法有多种，使用被解释变量的滞后项是其中较为简便的一种 本文在这一处理方法上的主要参考文献是Cameron<sup>［12］</sup><sub>。</sub> 不同之处在于，它观察的是分行业的面板数据，使用固定效应的设定;而这里仅观察总量数据，并且需要先判别数据是否平稳 对于单方程回归，还需特别关注回归残差是否存在序列相关性 若的确存在，则表明有一部分解释因素被放入了随机项中，从而模型的设定不合适<sub>。</sub> 回归所需的主要数据，见表1<sub>。</sub>

## 3.3 国内研发阻碍我国 TFP 提高的直觉解释

中国基础研究强度的过低，与以市场换技术的科技政策相结合，可能就造成了我国研发在促进国内 TFP 提高方面作用不显著甚至为负向影响的结果 在以市场换技术的策略下，国外先进技术的流入更多地在市场层面发生 中外巨大的技术落差，使得外企进入国内市场是有竞争优势的 然而，外企会以什么样的策略来进入中国市场呢? 显然，它们不会使用国际市场上最先进的技术，否则在我国国内知识产权保护不力的现实下，难以阻止其它企业造出模仿品;它们也不会使用和国内企业相同的技术，因为内资企业拥有许多低成本的优势，外企在竞争中不一定有胜算

外企的合适策略是，针对中国国内市场的技术水平，仅以稍高一级的技术切入 国内企业在借助模仿来参与竞争的过程中，因涉及到新技术的学习研究 厂房设备的购置或生产过程的改造，总需要一定的时间，外企可趁这段时间赚取一定程度的超额利润 当国内企业在此级技术上开始有竞争力时，外企再引入稍微更高一点的技术，再次形成技术优势 由于中外技术落差大，外企可用这种策略维持长期的竞争优势 国内企业虽然投入了一些研发资金，但在市场上已有更先进技术的前提下，自行另辟蹊径一般是不可取的<sub>。</sub> 因此，研发投入的目标通常是消化 吸收国外的先进技术 但由于我国基础研究投入比例过低，造成技术储备不足，这种愿望难以真正达成，国内企业多是停留在依葫芦画瓢的阶段

可以构想这样一幅图景:当外企通过投资将一种先进技术带入我国后，新产品的上市给内资企业造成竞争压力，后者开始投入应用型的研发，学习 模仿，然后投资于设备改造以推出模仿品 当外企见到模仿品出现后，开始实施更先进的技术，这使得国内为模仿所投入的研究努力在相当大程度上被报废，并带来另一轮的投资和模仿 持续不断的技术引入，带来持续不断的投资，使得经济增长的业绩在很大程度上表现为投资的贡献<sub>。</sub> 国内被动的模仿行为，其研发投入的成果总是被国外不断阶梯进入的先进技术所报废，从而研发没有起到推动我国技术前沿的应有作用;而且，因为它耗费了经济系统里的资源，却未获得明确的回报，形成为一种资源的漏出<sub>。</sub> 两个方面结合起来，使得国内研发对我国TFP提高的作用呈现为负面的影响

不过，从另一个方面看，如果没有国内的研发投入，即内资企业完全不学习外企的先进技术，那么外企也没有在中国市场上提升技术等级的激励 它们会把较低级的技术维持很多年，这将出现 TFP 提升缓慢的结果 鉴于我国 TFP 的提高速度并不慢，国内研发可能仍然通过竞争效应对我国 TFP 的提高起到了间接的促进作用

## 4 结束语

借助较为规范的实证分析可发现，来自国外的技术溢出对我国的技术进步起到了正面的积极作用 这一点易于理解，但让人困惑的是，国内研发这一因素在多数回归情形下对我国 TFP 的提高起着显著的负向作用 这意味着研发不仅没有推动我国技术前沿的外移，反而拖了后腿 笔者给出了理解这一反常结果的形成机制，即: 在我国基础研究强度偏低的事实和以市场换技术的科技发展策略下，外企的最优策略是把先进技术细分为多个等级，梯度引入到中国;在内资企业与外企的竞争过程中，虽然内资企业通过研发迫使外企不断实施新技术，从而推动了我国 TFP 的提高，但另一方面外企的行为也使得国内的研发投入表现为资源从经济系统的一种ina Academic Jour nal Electronic漏出，从而使得国内研发对 TFP 的提高呈现出负向

的影响<sub>。</sub>

从未来发展的角度看，一方面中外之间的技术差距越来越小，不能永远指望别人拉着我们跑，迟早要依靠自主创新来推动技术进步 另一方面，由气候变化压力日益增大所带来的低碳化变革，势必对包括经济 技术等各方面的社会生活产生深远的影响 而发达国家因路径依赖，在低碳技术上并不见得比我国高出多少<sub>。</sub> 这意味着在低碳经济时代，我们无技术可借鉴的时间会比以前更早地到来，西方的许多技术将因能耗高 排放大而不再具有先进性从这个角度看，及早加大基础研究投入的强度，从源头上增强自主创新的能力，应是政策选择上有待调整的优先方向<sub>。</sub>
