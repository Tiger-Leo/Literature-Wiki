# 中国城镇发展中的就业问题

丁 守 海

摘 要 <sub>：</sub> 乡镇层面的城镇化与以城市为中心的城市化不同<sub>，</sub> 它除了从需求角度影响存量劳动力的就业外 还会从多个维度冲击农村劳动力的劳动供给意愿 并改变劳动力蓄水池的容量 基于河南 湖南等五省的调查发现 城镇化普遍提高了各类劳动力的非农供给意愿 但并没有绝对改善非农产业的劳动需求 因而导致了不同的就业后果 依托中心城市辐射效应来推动城镇发展的地区 工业化与城镇化协调推进 非自愿型失业明显减少 在那些脱离周边城市的协同效应而孤立推动城镇化的地区 非农产业的发展滞后 非自愿型失业现象反而加剧 因此 在乡镇层面推动城镇化迫切需要解决产业融合的问题<sub>，</sub> 这有待于对城镇化推进模式进行更系统的整体设计

关键词 <sub>：</sub> 城镇化 工业化 失业风险 产业融合

作者丁守海<sub>，</sub> 经济学博士<sub>，</sub> 中国人民大学经济学院副教授 （北京 100872）

## 一<sub>、</sub> 问题的提出

城市化 （<sub>ur</sub>b<sub>an</sub>i<sub>za</sub>ti<sub>on</sub>） 是一国经济发展不可逾越的阶段 系指人口从农村向城市集中的过程 外来语 <sup>“</sup>U<sub>r</sub>b<sub>an</sub><sup>”</sup> 作为形容词 其所指既包括传统意义上的城市（<sub>c</sub>it<sub>y</sub>） <sub>，</sub> 也包括规模更小的城镇 （t<sub>own</sub>） 城市化既可能表现为人口向城市集中的过程<sub>，</sub> 也可能表现为乡镇层面的城镇人口扩张与规模膨胀<sub>。</sub> ① 既有研究表明<sub>，</sub> 改革后中国的城市化进程<sub>，</sub> 对于促进就业特别是转移劳动力的就业发挥了重要作用 <sub>，</sub> 但这一般都是针对传统意义上的城市化 对于乡镇层面的城镇化会对就业带来怎样影响的问题<sub>，</sub> 人们还很少进行研究<sub>，</sub> 当然也没有形成共识性的结论 鉴于就业问题在国民经济中的重要性<sub>，</sub> 在新一轮城镇化背景下澄清这一问题正变得越来越迫切<sub>。</sub>

本文将致力于探讨乡镇层面城镇化的就业影响<sub>。</sub> 我们认为<sub>，</sub> 这一分析范式将在很大程度上区别于传统意义上的城市化 城市化只是在城市范围内通过非农产业的发展 满足转移劳动力的就业需求 由于中心城市或大中城市的集聚效应明显 其就业带动功能是毋庸置疑的 而且由于受市场信号的调节 （如托达罗模型中就业概率的调节） <sub>，</sub> 劳动力流入数量乃至劳动力供给总量基本能维持均衡的格局 但在乡镇城镇化过程中 集聚效应和供求均衡这两个因素都将面临更大的不确定性 首先农村劳动力的非农劳动供给意愿将受到巨大冲击 不仅失地农户亟待就业务工 非失地农户的意愿也因种种因素的作用而有所提高 这些新增的边际劳动力多为过去农村留守劳动力的主力<sub>，</sub> 要么年龄偏大<sub>，</sub> 要么属于家庭生产型 （如妇女） <sub>，</sub> 离乡的意愿不高 吸纳这部分人口主要靠本地非农部门的发展 如果城镇化不能促进非农产业发展<sub>，</sub> 这些劳动力的非自愿型失业将会增加 那么<sub>，</sub> 城镇化到底能不能反推非农部门的发展呢？对这个问题 并没有一致的答案 因为相对于传统意义上的城市化乡镇城镇化的产业发展后果具有更大的不确定性 <sub>，</sub> 它取决于城镇化的推进方式<sub>，</sub> 在不恰当的方式下就可能会酝酿失业风险

基于河南 湖南等五省调查数据 我们检验了上述逻辑推理 研究发现 乡镇城镇化普遍提高了各类劳动力的劳动供给意愿<sub>；</sub> 但与此同时 城镇化并没有绝对地反推非农产业的发展<sub>，</sub> 或为新增劳动力提供新的就业机会<sub>。</sub> 不同的城镇化模式<sub>，</sub> 出现了不同的就业后果 在那些依托中心城市辐射效应而推进城镇扩张的地区 <sub>，</sub> 非农部门呈同步发展的势头<sub>，</sub> 非自愿型失业率明显下降<sub>；</sub> 但在那些远离周边城市的辐射效应而单独推进城镇化的地区 非农产业的发展滞后 非自愿型失业率明显上升

上述结论提醒我们 相对于传统意义上的城市化 乡镇城镇化将面临更迫切的产业支撑问题 只有实现工业化带动城镇化 城镇化反推工业化的良性互动 才能解决好就业问题 这需要对城镇化推进模式进行更系统的设计 并妥善处理好城镇与城市之间 城镇与城镇之间的关系 避免盲目冒进地推动城镇化

## 二<sub>、</sub> 文献综述

可能是由于西方国家较早地实现了城市化的缘故 西方学者研究城市化过程的文献并不是很多<sub>，</sub> 而且大都是以传统意义上的城市化为研究对象 <sub>，</sub> 样本也集中在较早时期或发展中国家 它们零星地讨论了城市化的就业效应问题

这些文献的讨论维度大致包括两个方面 <sub>：</sub> 一是宏观层面<sub>，</sub> 城市化对劳动力分布结构特别是在三次产业间分布的影响<sub>，</sub> ①② 城市化对劳动力供给<sub>、</sub> 就业吸纳乃至非正规部门就业吸纳能力的影响 ①② 在一篇以中国为样本的文献中 人们还讨论了城市规模结构的影响 并证明了城市规模对农民迁移决策的正向作用 ③ 从一些早期文献开始<sub>，</sub> 人们就注意到城市化的就业影响与工业发展问题密切相关 ④ 二是在微观层面 人们讨论了城市化对劳动者个体求职行为或雇主行为的影响 如城市化对年轻人职业流动性的影响 ⑤ 对雇主提供的就业岗位类型的影响 ⑥

由于缺少对乡镇层面城镇化的考察 特别是对中国背景下乡镇城镇化的考察这些文献很难为本文的研究主题提供直接的参考<sub>。</sub> 这个问题在国内研究文献中也同样存在 国内学者对城市 （镇） 化就业问题的考察大致分成以下两个分支

一是直接考察了城市化的就业影响 从结论上看<sub>，</sub> 他们大多是持肯定态度的 <sub>，</sub>即城市化是促进就业 缓解就业压力特别是农村转移劳动力就业压力的重要途径 <sub>；</sub> ⑦如果忽视城市化建设<sub>，</sub> 就会造成严重的经济社会后果<sub>，</sub> 并对就业造成巨大的冲击 ⑧这些研究文献与西方研究范式类似 都是以一般意义上的城市化为研究对象 既可能包括以城市为中心的城市化<sub>，</sub> 也可能包括以乡镇为基础的城市化<sub>，</sub> 它们即便能证明城市化带动了就业 也未必能说明乡镇城镇化也是如此

至少可以说<sub>，</sub> 相对于传统意义上的城市化<sub>，</sub> 乡镇城镇化的就业效应并不是那么容易识别 这种差异可以通过人们对中国城市化道路选择的争论折射出来 改革以来<sub>，</sub> 人们就中国究竟应选择以大中型城市为主导<sub>，</sub> 还是以小城镇为主导的城市化道路 进行了激烈的辩论 ⑨ 尽管在早些时候 随着乡镇企业崛起 一些学者强调小城镇模式在中国特色城市化建设中的特殊作用<sub>，</sub> ① 但随着时间推移<sub>，</sub> 人们逐渐认识到小城镇模式的不足<sub>，</sub> 并开始重视大中城市发展的必要性<sub>，</sub> 以发挥其辐射带动的作用 ② 这种认识上的转变也反映到政策调整上<sub>，</sub> 从十一五规划开始<sub>，</sub> 我国对城市化规模结构的定位 从片面强调小城镇优先发展 转向大中小城市与小城镇协调发展对既有的小城镇发展模式<sub>，</sub> 人们也进行了反思<sub>，</sub> 强调要对其进行功能改造与升级 <sub>，</sub> ③以顺应农村城镇化 城镇城市化 城市现代化的中国版城市化逻辑次序 ④

上述转变反映了人们对小城镇经济功能的担心 至少 它不如城市那么明显后者的规模效应 集聚效应 辐射效应及经济效率已得到诸多研究的证明 ⑤⑥ 但对小城镇来说 人们还很少能明确地证明其经济效率就一定是高的或低的 人们也很少通过系统的实证分析 为此提供判断证据 更重要地 在中国特色城镇化模式下 行政机制经常取代市场机制 成为重要的资源配置力量 它是否会违背客观规律并损害城镇化的内在效率 也是值得关注的 ⑦ 就业是引致性需求 小城镇经济效率的不确定性必然延伸到就业领域 我们有理由对其就业效应持谨慎态度

另一些学者则直接考察了乡镇层面城镇化的影响 它们可以为本文的研究提供一定的参考<sub>，</sub> 但价值有限<sub>，</sub> 因为它们有两个重要缺陷 一是在考察维度上<sub>，</sub> 只侧重从劳动供给角度分析城镇化影响 如城镇化过程中相关主体的迁移决策 ⑧ 失地农民劳动供给的影响因素等 ⑨ 而忽视了对劳动需求变化的考察 我们知道 就业是劳动供给和劳动需求共同作用的结果 只考察城镇化对劳动供给的影响 而不考察它对劳动需求的影响 就难以洞察城镇化对就业影响的全貌 第二个缺陷则源于考察对象的狭隘性<sub>。</sub> 有些文献虽然直接考察了城镇化的就业影响 <sub>，</sub> 但研究对象多集中于失地农民或失地农民中的某一特定群体 如妇女 瑏瑠 这就限制了研究的视野

不可否认 城镇化的一个重要表征就是空间扩张 它必然涉及征地的问题 失地农民的就业问题理应成为城镇化就业效应的一个重要组成部分 但城镇化只会影响失地农民的就业吗？答案显然是否定的 城镇化是个系统工程<sub>，</sub> 通常会与其他的政策举措相配套 产生出很多间接影响因素 例如 在土地增减挂钩政策的引导下很多地方的城镇化是与新农村建设并行推进的<sub>，</sub> 集中居住后的农户往往离农田更远<sub>，</sub>耕作变得更不便利 这会引导他们放弃农业生产 转向非农领域谋生 就业状况也会随之改变<sub>。</sub> 再如<sub>，</sub> 过去很多留守劳动力之所以困守农村而不能转移<sub>，</sub> 很大程度上源于家庭分工的制约 ① 城镇化可能会改变这一状况 随着城镇的发展 饭店 幼儿园 养老机构等也会兴起 在一定程度上 它们能将留守劳动力从繁重的家庭生产任务中解放出来<sub>，</sub> 劳动供给与就业也可能会发生变化

综上所述 目前国内外文献尚未系统地阐释乡镇城镇化的就业效应问题 它们要么定位于一般意义上的城市化 要么不能综合权衡供求两方面因素的影响 抑或只局限于狭隘的考察对象<sub>，</sub> 而不能通览全体 对于中国城镇化的就业影响问题<sub>，</sub> 还要结合实际情况展开更系统的专门研究 在这一过程中不仅需要理论上的辨析 更要利用有代表性的调研数据<sub>，</sub> 通过实证考察<sub>，</sub> 揭示问题的真实面貌

## 三<sub>、</sub> 理论辨析与研究假说

首先来看城镇化对劳动供给的影响<sub>。</sub>

我们知道 劳动供给决策并非完全取决于个体理性 在相当程度上 它取决于家庭理性 ② 因此 我们将以家庭为单位进行分析 令农户的时间禀赋可以配置于四个领域 <sub>：</sub> 务工 农业生产 家庭生产 闲暇 除务工时间外<sub>，</sub> 其余三个领域的时间通常都有很大的重合性 留守农村的时间往往既用于农业生产活动 也用于家务劳动或闲暇 很难严格区分 同时也考虑到本文主要考察的是非农劳动供给问题我们只对时间禀赋T做二分处理<sub>，</sub> 即非农部门的务工时间L和留守农村的时间h

时间配置原则是家庭效用 U的最大化<sub>，</sub> 家庭效用主要取决于总收入I和家庭生产活动的产出G<sub>：</sub> 前者决定了家庭的消费水平 <sub>；</sub> 后者对生活质量也有很大的影响至于闲暇<sub>，</sub> 它与家庭生产活动相互交融<sub>，</sub> 如陪伴孩子的过程既可以视作家庭生产 <sub>，</sub>也可以视作享受闲暇 因此不再单独列出 令工业工资为 W 农业生产的单位收益为 A （它也可以视作务工的机会成本） <sub>，</sub> 那么<sub>，</sub> 当配置 L于务工时<sub>，</sub> 工资收入为

WL 进一步<sub>，</sub> 令消耗于务工地点与家庭之间的往返时间为 R<sub>，</sub> 那么留守时间为 <sub>：</sub> h$= \mathrm { T } - \mathrm { L } - \mathrm { R }$ 对应的农业生产收益为 $( \mathrm { T } - \mathrm { L } - \mathrm { R } ) \ \mathrm { ~ A ~ }$ 与工资收入合并后可得到家庭总收入 <sub>：</sub> $\mathrm { I } { = \ \mathrm { ( T { - } R ) } \ \mathrm { A } { + } \ \mathrm { ( W { - } A ) } \ \mathrm { I } }$ 家庭生产活动的产出也同样取决于留守时间h 令生产函数为 ${ \mathrm { G } } { = } { \mathrm { g } } { \mathrm { ~ ( h ) } }$ 基于上述条件 可构建家庭的时间配置模型

$$
\begin{array}{r l} \text {s.t.} & I = (T - R) A + (W - A) L \\ & G = g (T - R - L) \\ & 0 \leqslant L \leqslant T - R \end{array}
$$

令拉格朗日因子为 λ<sub>，</sub> 可构建如下的拉格朗日方程 <sub>：</sub>

$$
Z = U ((T - R) A + (W - A) L, g (T - R - L)) + \lambda (T - R - L)\tag{1}
$$

根据变量L的边际条件 非负约束以及互补松弛条件<sub>，</sub> 可得 <sub>：</sub>

$$
\frac {\partial \mathrm{Z}}{\partial \mathrm{L}} = \mathrm{U} _ {\mathrm{I}} ^ {\prime} \mathrm{W} - \mathrm{U} _ {\mathrm{G}} ^ {\prime} \mathrm{g} ^ {\prime} - \lambda \leqslant 0; \mathrm{L} \geqslant 0; \mathrm{L} \frac {\partial \mathrm{Z}}{\partial \mathrm{L}} = 0\tag{2}
$$

再根据 λ 的边际条件<sub>、</sub> 非负约束以及互补松弛条件<sub>，</sub> 得到 <sub>：</sub>

$$
\frac {\partial Z}{\partial \lambda} = T - R - L \geqslant 0; \lambda \geqslant 0; \lambda \frac {\partial Z}{\partial \lambda} = 0\tag{3}
$$

任何家庭都必须配置一定时间于家庭生产活动 <sub>，</sub> 因此有 <sub>：</sub> $\mathrm { h } { = } \mathrm { T } { - } \mathrm { R } { - } \mathrm { L } { > } 0$ <sub>，</sub> 对应于 （3） 式 <sub>，</sub> $\frac { \partial Z } { \partial \lambda } { > } 0$ <sub>，</sub> 从其互补松弛条件可得 <sub>：</sub> $\lambda = 0$ <sub>，</sub> 代回 （1） 式<sub>，</sub> 则拉格朗日方程退化为原目标函数<sub>，</sub> （2） 式的边际条件也退化为普通的极值条件 <sub>：</sub>

$$
\frac {\partial \mathrm{U}}{\partial \mathrm{L}} = \mathrm{U} _ {\mathrm{I}} ^ {\prime} \mathrm{W} - \mathrm{U} _ {\mathrm{G}} ^ {\prime} \mathrm{g} ^ {\prime} = 0\tag{4}
$$

考虑到边际替代率为 <sub>：</sub> $\mathrm { M R S } _ { \mathrm { G , I } } = \frac { - \mathrm { U ^ { \prime } } _ { \mathrm { G } } } { \mathrm { U ^ { \prime } } _ { \mathrm { I } } }$ <sub>，</sub> 边际转换率为 <sub>：</sub> $\mathrm { M R T _ { G , I } = \frac { - p _ { G } } { p _ { I } } = }$ $\frac { - \mathrm { { W } } } { \mathrm { { g ^ { ' } } } }$ <sub>，</sub> 其中 <sub>，</sub> ${ \mathrm { p } } _ { \mathrm { I } } \setminus { \mathrm { ~ \ p _ { G } ~ } }$ 分别代表收入和家务劳动价格<sub>，</sub> 即家庭生产的边际产出 $\mathrm { g } ^ { \prime }$ 及工资 W<sub>。</sub> 于是 <sub>：</sub>

$$
\mathrm{MRS} _ {\mathrm{G}, \mathrm{I}} = \mathrm{MRT} _ {\mathrm{G}, \mathrm{I}}\tag{5}
$$

上述原理可用图1表示 图中第三象限为时间预算线<sub>，</sub> 它满足 $\mathrm { L } + \mathrm { h } = \mathrm { T } - \mathrm { R }$ ；第二象限为收入线<sub>，</sub> 它满足 $\mathrm { I } { = \ \mathrm { ( T - R ) } \ \mathrm { A } { + } \ \mathrm { ( W - A ) } \ \mathrm { ~ I } }$ <sub>；</sub> 第四象限为家庭生产函数<sub>，</sub> 它满足 ${ \mathrm { G } } { = } { \mathrm { g } } ( { \mathrm { h } } )$ 假设对应于时间预算线上的 $\mathrm { Q } _ { \mathrm { 0 } }$ 点<sub>，</sub> 家庭配置时间 $\mathrm { L } _ { \mathrm { 0 } }$ 于务工<sub>，</sub> 并配置 $\mathrm { h } _ { \mathrm { 0 } }$ 于留守农村<sub>，</sub> 那么<sub>，</sub> 从第二象限可以看出<sub>，</sub> 此时的总收入为I<sub>，</sub> 家庭生产活动的产出为G<sub>，</sub> 二者在第一象限交汇到 A点 依此类推<sub>，</sub> 可得若干个组合点<sub>，</sub>它们构成家庭生产可能性边界S 进一步<sub>，</sub> 令无差异曲线如 U所示<sub>，</sub> 它与S相切于E点 这时边际替代率与边际转换率相等 即满足 （5） 式 这就是家庭选择的均衡点收入与家务劳动的产出分别为I<sup>＊</sup>和G<sup>＊</sup> <sub>，</sub> 务工和留守的时间分别为L<sup>＊</sup>和h<sup>＊</sup>

第三<sub>，</sub> 征地 其影响包括两个方面 首先是因为耕地减少<sub>，</sub> 单位农业生产的收益将下降 如从A降为A′ 它使第二象限的收入预算线变得更陡 其次是征地补偿款 如 M 总体上应该使收入预算线的截距上移 并达到I′<sub>＝</sub> （T<sub>－</sub>R） A′＋ （W<sub>－</sub>A′） L＋ M的位置 经过类似的推导 生产可能性边界也应该外移 如移至S′′均衡点也会外移到E′′ 但由于收入预算线I′上移 E′′点对应的务工时间L不一定增加<sub>，</sub> 也可能减少<sub>，</sub> 其原因就在于征地补偿款使预算约束软化了 最终结果取决于家庭偏好 如果家庭更偏好于收入 那么 MRS 较小 无差异曲线更平缓 E′′点的位置更高<sub>，</sub> 务工时间就会增加<sub>；</sub> 相反<sub>，</sub> 如果家庭更偏好于闲暇或家庭生产<sub>，</sub> 务工时间就会减少

## 假设1<sub>：</sub> 城镇化会使各类劳动力的非农劳动供给意愿增加<sub>。</sub>

由于农村精壮劳动力多已外出务工 <sub>，</sub> 城镇化释放的边际劳动力多为留守人员 <sub>，</sub>他们要么年龄偏大 要么是家庭生产型 （如妇女） 由于种种因素的限制 他们的离乡意愿并不高 要消化这部分新增劳动力 主要靠发展当地的非农产业来进行 那么 城镇化是否一定能促进非农产业的发展并扩大劳动需求呢？

对这个问题 我们很难像考察劳动供给那样 构建一个系统的框架进行分析但通过对既有文献的梳理以及对经验事实的考察 还是可以得出一些有益结论的从文献梳理的角度看 <sub>，</sub> 正如前面所提到的 <sub>，</sub> 既有研究并不能确定城镇化的经济效率及产业发展后果 它带有一定的不确定性 从经验事实的角度看 我们也可以找到正反两方面的证据 正面的以日本为例 日本在城市化进程中非常注重与工业化的协同 东京 大阪 名古屋等城市群的人口快速膨胀 于20世纪80年代初 <sub>，</sub> 就集聚了全国总人口的40％以上 <sub>，</sub> ① 与此同时<sub>，</sub> 这些城市也快速发展为日本最重要的工业带 由于工业化与城市化良性互促 工业发展为新增人口提供了大量的就业岗位 所以在日本城市化进程中并没有出现大的失业问题 相对而言 发展中国家更容易出现城市化不能带动产业发展及劳动需求扩张的非良性循环 如巴西1980年城市化率已达到52％<sub>，</sub> 但工业部门只能提供20％的就业岗位<sub>，</sub> <sup>“</sup>城市病<sup>”</sup> 由此而生<sub>。</sub> ②

既然传统意义上的城市化与产业发展的关系存在正反两种可能 <sub>，</sub> 而城镇化特别是行政机制主导的城镇化的经济绩效<sub>，</sub> 具有更大的不确定性<sub>，</sub> 由此推出第二个假设<sub>。</sub>

假设2<sub>：</sub> 城镇化的产业发展后果具有不确定性<sub>，</sub> 它未必能扩大非农劳动需求<sub>。</sub>

模型1<sub>：</sub> 检验城镇化对农村劳动力非自愿型失业的影响

利用这三轮调查<sub>，</sub> 我们构建如下基于面板数据的离散选择模型 <sub>：</sub>

$$
\begin{array}{l} \mathrm {p (y_ {\mathrm{it}} = 1) = \frac {e^ {y_ {\mathrm{it}} *}}{e^ {y_ {\mathrm{it}} *} + 1}} \\ \text {s.t.} \quad \mathrm {y_ {\mathrm{it}} ^ {*} = \beta_ {0} + (\beta_ {1} +\varphiIND_ {\mathrm{it}} +\gammaLOS_ {\mathrm{ij}}) URBAN_ {\mathrm{it}} +\sum\gammaZ_ {\mathrm{it}} + e_ {\mathrm{it}}} \end{array}
$$

其中<sub>，</sub> 下标i代表各受访者<sub>；</sub> t代表2009年<sub>、</sub> 2011年和2012年<sub>。</sub>

被解释变量<sub>y</sub>为二元离散选择变量 在问卷中凡回答 <sup>“</sup>在过去一年里想到非农部门找一份工作<sup>”</sup> <sub>，</sub> 但又 <sup>“</sup>找不到这样的工作机会的<sup>”</sup> 的<sub>，</sub> 视为非自愿失业<sub>， y</sub>取1<sub>；</sub>没有这样经历的 （包括已在非农部门工作的和自愿失业的） 则 取0

为了考察城镇化与工业化协同的情形 并比较不同情形下城镇化的就业影响我们专门设置哑元变量IND 具体地<sub>，</sub> 我们用各乡镇非农产业在总增加值中的比重<sub>，</sub>表示工业化程度<sub>，</sub> 然后用它除以城镇化率得出一个系数<sub>，</sub> 反映工业化相对于城镇化的水平 再对各乡镇计算该系数的平均值 对于那些系数小于该平均值的乡镇来说代表城镇化受工业化支撑的程度相对较小<sub>，</sub> IND取0<sub>，</sub> 并作为基准组<sub>；</sub> 相反<sub>，</sub> 如果大于平均值<sub>，</sub> 代表城镇化受工业化支撑的程度相对较大<sub>，</sub> IND取1<sub>，</sub> 作为比较组<sub>。</sub>比较组和基准组城镇化对非自愿型失业的影响差异<sub>，</sub> 反映在系数 $\boldsymbol { \varphi }$ 上 <sub>。</sub>

类似地 为比较城镇化对被征地农户和非征地农户的就业影响 我们再设置哑元变量LOS 对于未征地农户 LOS取0 作为基准组 对于被征地农户 LOS取1<sub>，</sub> 作为比较组<sub>。</sub> 城镇化对两组样本非自愿型失业的影响差异反映在 <sub>γ</sub> 上<sub>。</sub>

Z为控制变量 即可能对非自愿型失业造成影响的其他一些因素 非自愿失业作为一种就业后果取决于供求两个方面因素 <sub>，</sub> 其中<sub>，</sub> 供给因素包括以下七项 （1）家庭抚养比RAISE 研究表明 家庭人口结构会对劳动供给产生重要影响 例如抚养比越高 家庭经济压力越大 劳动供给压力也越大 但家务劳动负担也会越重并制约劳动供给特别是妇女的劳动供给 所以影响是多重的 ① 我们用16岁以下孩子与60岁以上老人占家庭人数的比重表示抚养比 （2） 家庭人均耕地面积 （亩） 的对数LAND<sub>。</sub> 它越大<sub>，</sub> 农业生产所需要的劳动力越多 <sub>，</sub> 越会制约非农劳动供给<sub>。</sub>（3） 农业收益的对数 AGRI 按刘易斯模型的预测 ② 务农收益作为机会成本 会对工业劳动供给产生重要影响 我们用家庭农业生产的净收益<sub>，</sub> 除以以农业为主要职业的劳动力人数<sub>，</sub> 得到劳均务农收益 （4） 工业工资的对数 WAGE 它与农业收益结合起来<sub>，</sub> 可以反映务工的比较收益<sub>，</sub> 进而会对农村劳动力务工决策产生影响实际上 作为成本 它也会影响工业部门的劳动需求 因此也可以作为一个需求因素来看待<sub>。</sub> 对于未务工的受访者<sub>，</sub> 用当地小工工资来代替工资<sub>。</sub> （5） 家庭财富的对数 WEAL 它会影响到家庭预算约束的松紧程度 进而影响到劳动供给决策 我们用家庭资产总价值来表示 （6） 家务劳动的替代手段 APPL 如家用电器的使用能减轻家务劳动负担 并刺激劳动供给 我们用农户是否有洗衣机作为其替代指标（7） 农村生活的社会化服务网络CARE 我们以附近是否建有幼儿园来代表

至于非农劳动需求 最好是用非农产业增加值来表示 但这样可能会与城镇化指标发生相关性 并产生内生性问题 因此我们用如下指标来替代 即在本乡镇外务工的人数与本乡镇劳动力总数之比OUT 一般认为 农村劳动力向工业部门的转移 涉及成本收益的核算 距离越远 交通成本等费用就会越大 显然 如果本地就业机会多<sub>，</sub> 人们更愿意就近务工而不是外出<sub>，</sub> 外出务工的比例应该更小 因此它既能反映本地对非农劳动的需求 与城镇化指标之间也没有直接的关联

还有一些人力资本方面的变量<sub>，</sub> 会同时影响劳动供给和需求<sub>，</sub> 主要有以下几项（1） 年龄 AGE （2） 婚姻状况 MARR 已经结婚的 取1 尚未结婚的 取0（3） 是否担任过村队干部LEAD<sub>：</sub> 担任过干部的<sub>，</sub> 取1<sub>；</sub> 未担任干部的<sub>，</sub> 取0 它反映了受访者的社会能力 （4） 教育年限EDU （5） 是否拥有技术等级证书SKILL（6） 曾经外出务工的年数EXPER<sub>，</sub> 这可以视作工作经验<sub>。</sub> 上述指标会对企业是否录用受访者产生影响 如一些企业更愿意招青年未婚工人 而不招大龄或已婚劳动力<sub>；</sub> 同时 这些指标也会对受访者自身的非农供给意愿产生影响 如对于年纪较大的受访者来说<sub>，</sub> 通常更愿意做点家务或农活<sub>，</sub> 而不是出去打工

模型2<sub>：</sub> 检验城镇化对农村劳动力非农劳动供给意愿的影响

模型3<sub>：</sub> 检验城镇化对非农产业发展的影响

人们希望通过城镇化<sub>，</sub> 促进非农部门发展并扩大劳动需求<sub>，</sub> 以解决城镇化释放出来的劳动力的就业问题<sub>。</sub> 我们将设置如下模型来检验这一情况 <sub>：</sub> ①

$$
\mathrm{G} _ {\mathrm{it}} = \alpha_ {0} + (\alpha_ {1} + \delta \text { NEAR } _ {\mathrm{it}}) \text { URBAN } _ {\mathrm{it}} + \sum \xi \mathrm{V} _ {\mathrm{it}} + \mathrm{u} _ {\mathrm{i}} + \lambda_ {\mathrm{t}} + \varepsilon_ {\mathrm{it}}

其中<sub>，</sub> 下标i代表各乡镇<sub>；</sub> t代表2009年<sub>、</sub> 2011年和2012年

在上述模型中<sub>，</sub> 被解释变量 G为反映各地非农产业发展状况的指标 具体地<sub>，</sub>我们参照常用的度量工业化程度的指标方法 用非农产业在当地GDP中所占比重来表示 核心解释变量为城镇化率 URBAN 它与模型1的计算方法相同

## 七<sub>、</sub> 结论性评语

区别于传统意义上以城市为中心的城市化模式 本文探讨了乡镇层面上的城镇化的就业影响 理论分析和基于河南 湖南等五省调研数据的实证分析都证明<sub>，</sub> 乡镇城镇化的就业效应具有较大的不确定性 它并不是静态地满足存量劳动力的就业需求 还会通过各种渠道冲击农村各类劳动力的非农劳动供给意愿 并改变劳动力蓄水池的容量 可以说 它将使城镇面临更大的就业压力 这种压力将传导到非农产业的发展上 但相对于传统意义上的城市化 乡镇城镇化并不足以保证非农产业的发展<sub>，</sub> 其经济效率和产业发展的后果因不同的推进模式而不同 我们发现<sub>，</sub> 在依托周边城市而推进城镇化的地区 非农产业发展较快 农村劳动力的非自愿型失业率也较低 但在远离周边城市的地区 城镇化与非农产业发展脱节的现象更为明显非自愿型失业现象也更为普遍

上述结论提醒人们 城镇化是一个系统工程 在实现城镇规模扩张 人口膨胀的同时 必须寻求产业发展的支撑点 只有真正实现了工业化促进城镇化 城镇化反推工业化<sub>，</sub> 才能妥善解决农村劳动力的就业问题<sub>，</sub> 才能真正实现十八届三中全会所提出的 <sup>“</sup>推进以人为核心的城镇化<sup>”</sup> 以及 <sup>“</sup>产业和城镇融合发展<sup>”</sup> <sub>。</sub> 这就需要在整体上设计好城镇化的推进模式 正确处理城镇与城市之间 城镇与城镇之间的关系问题<sub>。</sub>

虽然城镇化的人口集聚效应 为发展第二 第三产业创造了一定的条件 但鉴于乡镇产业基础的薄弱性<sub>，</sub> 要发展非农产业<sub>，</sub> 必须借助中心城市 周边城市甚至其他乡镇的外力 利用它们的辐射效应和带动作用 通过产业链的分工 配套和互补等前后向关联效应和技术溢出 弥补自身产业发展基础的不足 例如 承接周边城市的产业或加工环节的转移 发展本地的制造业 一些中西部地区城镇甚至可以越过周边城市<sub>，</sub> 与东部地区发达城市直接对接 <sub>，</sub> 承接飞地转移项目 在这一过程中<sub>，</sub>各乡镇企业应结合自身禀赋条件的比较优势 规划本地的产业项目 避免主导产业的雷同与恶性竞争 在差异化产业格局下<sub>，</sub> 各地之间才能展开互补性的合作 总之<sub>，</sub>乡镇城镇化的推进 不能闭门造车 更不能盲目冒进 要通过嵌入或延伸已有的产业链<sub>，</sub> 整合更多的产业资源<sub>，</sub> 处理好与其他城市及城镇的产业关系<sub>，</sub> 才能为城镇化提供更强的产业动力 也唯有如此 城镇化的发展才不会出现大的失业问题
