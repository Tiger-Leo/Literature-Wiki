# 企业并购后整合对创新影响的实证研究

基于资源整合产生协同效应角度的分析

鲍新中，陶秋燕，盛晓娟

（北京联合大学 管理学院，北京 <sub>100083</sub>）

摘要：文章研究了企业合并后资源整合效果对创新的影响。选取了信息技术行业 个样本进行了实证检验，结果表明，信息系统整合、文化整合和技术整合产生的经营协同效应以及战略整合产生的管理协同效应都对企业的创新产生显著的正向影响；财务协同效应和一些企业运营方面的协同效应对创新没有非常显著的正向作用。因此，企业在实现合并后应加强资源整合，实现最大程度的协同效应，特别是合并为了增强创新能力的企业，应加强信息系统、企业文化、技术和战略方面的整合。

关键词：创新；资源整合；协同效应

# An Empirical Study on the Impact of Post-merger and Acquisition Resources Integration on Innovation

—Based on the Perspective of Synergy Effect

BAO Xin-zhong<sup>，</sup>TAO Qiu-yan<sup>，</sup>SHENG Xiao-juan

（Management College，Beijing Union University，Beijing 100083，China）

<sup>Abstract：</sup>The paper makes a study of the effect of post-merger and acquisition resources integration on innovation. It carries out an empirical test by collecting and selecting 129 samples of information technology industry. The results show that a significant positive effect on innovation comes from operational synergy which is generated by the integration of information system, corporate culture and technology, together with management synergy which is generated by the integration of corporate strategy, while financial synergy and other operational synergy do not have a remarkable positive effect on innovation. Therefore, enterprises should strengthen the resources integration after mergers and acquisitions to achieve maximum synergy effect, espe cially for the enterprises which intend to strengthen innovation capacity<sup>，</sup> should enhance the integration of information system<sup>，</sup>corporate culture<sup>，</sup>technology and corporate strategy.

<sup>Keywords：</sup>innovation<sup>；</sup>resources integration<sup>；</sup>synergy effect

企业竞争的实质就是创新能力的竞争，包括在知识的生产。占有和有效利用方面、新产品的产出以及创新效率的提高都可以增加企业在市场中的竞争力。许多学者致力于研究企业特征和公司行为对于创新的影响，包括企业冗余资源、公司治理特征、资本结构和企业规模等几个方面。

企业合并是企业发展到一定阶段为了不断增强自身的创新能力和竞争力，吸收外部知识所乐于采用的方式，借此也能减少竞争对手对自身的威胁。企业合并这种企业行为会不会对创新绩效产生影响？如果有影响，会是正向的还是负向的影响？一些研究通过协同效应和知识溢出效应对企业合并后形成的企业集团内的创新绩效进行了分析。在协同效应方面主要从战略协同、组织文化协同、人力资源协同、研发协同等方面进行更为细分的研究；基于企业合并形成的企业集<sup>［</sup>1-2<sup>］</sup>知识溢出效应方面，主要是 投资通过企业合并的方式对东道国企业投资，对被投资企业的创新效果产生一定的促进作用<sup>［3-4］</sup>。也有学者对企业战略联盟和企业集群对创新的影响进行了研究<sup>［5-6］</sup>。

企业间的合并行为会使参与合并的企业之间获得协同效应，在有形资源和无形资源的利用方面将更加高效，创新效率和效果也可能得到改善。但相关研究结论却并非如此。许多合并事件发生后，企业绩效并未取得之前预想的表现，这与企业资源的整合能力和效果不无关系。因此本文从企业合并后资源整合的不同方面，探究不同方面资源整合后产生的协同效应有何不同，并如何进一步影响到合并后企业的创新绩效。

## 一、文献综述

关于企业合并和创新之间关系的研究，国内文献较少，

大部分都是外文文献在做相关的研究。

## （一）企业合并和创新关系理论研究

传统的企业合并的动机有：进入目标市场、公司成长、提高绩效、获得多元化和减少风险，本文研究企业合并与创新的关系。理论上看，企业合并可以在以下几个方面促进创新： 由于产权保护的存在，企业的独有技术不能在企业间传递，那么企业合并这一企业行为就打破了这层障碍； 避免高额的转换成本，通过企业合并，企业可以解决取得外部技术付出高昂代价的难题。而且，企业合并会使公司的研发总投入增加，企业可借此达到规模经济。因此企业合并会促进企业的研发效率，获得更高效的创新。

企业合并对于企业创新也有一些弊端。参与合并的各方在合并后需要花费大量的时间和精力来对资源进行整合，这样就可能忽视了创新活动。因此合并后绩效就算有所改善也可能只是短期效果，有的公司甚至在合并了几年之后都还没有实现完全的资源整合，合并后的整合工作并不容易。在创新环境方面，创新绩效在少数几个企业发生合并时表现可能更好，如果合并后企业规模过大，原来的优势就无法体现。

## （二）企业合并对创新影响实证研究

有关企业合并和创新关系的研究大致可以分为两类：第一类研究的是企业合并对研发相关指标的直接影响，第二类研究的是在特定背景下的企业合并将如何改善创新绩效。

第一类研究中，研发的相关指标主要是投入和产出。因为考虑到企业合并之后转换成本降低，因此创新投入可能会大幅降低。可现实情况却不一定如此。另外，创新绩效的衡量方面有待精确化。有研究表明：用产出指标来衡量创新绩效的时候，企业合并对创新的影响是负向的，但是用创新投入的指标衡量的时候，企业合并对创新没有显著影响。目前还没有研究表明企业合并对企业的创新绩效有显著的正向作用。

第二类研究中，研究的特定背景主要有企业规模和行业差异。在企业规模方面， <sup>［7］</sup> 和 <sup>［8］</sup> 的研究发现，当大企业在和相同规模的企业发生合并时创新绩效表现得更好。不同行业背景方面，有一些研究用的是高新技术产业的数据，有的用的是工业企业的数据等，但是没有比较不同行业的研究。

企业在合并发生之后要进行各个方面的资源整合，在企业的不同方面产生协同效应。现有的研究对企业合并和创新之间的关系结论不一，因此本文将探究企业合并后不同的协同效应对创新产生的影响。首先阐述企业合并后进行资源整合的方面，包括企业战略、企业文化、企业结构、人力资源、信息系统、技术和财务方面的整合并将其个部分产生的协同效应进行归类，在此基础上进行变量设计，将相应因素量化加以衡量并建立实证模型，然后选择样本并进行实证检验，得到相关的研究结论。

## 二、研究思路

企业合并之后，管理者就需要花费大量的时间精力对参与合并的企业进行资源整合，包括战略整合、文化整合、结构整合、人力整合、信息系统整合、技术整合和财务整合等等。在以往的研究中，对于企业合并后资源整合的效果只是进行了定性研究，或者只是建立一些整合模型，并未对整合的效果进行定量衡量，以及合并后产生的协同效应到底有没有达到合并预期。特别是对于一些有特定目的进行合并的企业，为了获得更多的创新资源或者较低的转换成本，更关注在企业合并后资源的整合效果以及为了达到合并目的应加强哪些方面的整合，获得最大的协同效应（见图 ）。

## （一）企业资源整合

## <sub>1.</sub>企业战略整合

战略整合是对并购后企业的方向性调整，决定了企业未来发展定位，因此这个方面的整合至关重要。战略整合中的要点包括： 重视运用新企业愿景； 保持对客户的关注；灵活的整合过程。现实中的收购都是建立在不完全信息的条件下，因此在企业整合过程中会遭遇一些困难，进行一些妥协，因此在制定整合计划和进行整合的过程中要为例外事件留有一定余地，进行灵活的整合。

## <sub>2.</sub>企业文化整合

企业文化整合的目的是要达到企业所有员工所遵循的价值观一致，形成统一的企业目标并为该目标做出最大的努力，这将对企业的创新产生一定的积极作用。廖泉文<sup>［9］</sup>提出了三种不同的企业文化整合模式：一体化模式、吸融式模式和隔离式模式。企业可根据参与合并企业文化差异程度和成熟度选择采用。

## 人力资源整合

很多研究和实践都表明，人力资源整合是并购整合成功的关键。 和 <sup>［10］</sup> 在对以色列合并企业的研究中指出，在整合过程中人力资源方面存在的问题会影响协同效应的效果。如果企业合并后员工所获得的信息是，他们的技术传递模式不同和对合并后产生的企业形象认知不同，那么他们会拒绝知识共享。这样就会严重影响企业在创新方面的协同，从而影响创新绩效。

## 企业结构整合

企业结构整合是指企业发生并购后，在组织机构和制度上进行必要的调整和重建，以实现组织上的协同。企业结构的变化受战略变化的驱使，而战略变化又与企业面临的外部状况相联系，因此根据并购后企业内外部环境的变化必须对组织结构进行有效整合。整合时仍应从管理组织一体化的角度考虑，以避免局部调整导致整体不协调，造成管理中的冲突与矛盾。

## 信息系统整合

信息系统的整合包括对信息系统的人事、程序兼容性、信息共享度等方面进行很好的融合，影响信息系统整合效果的因素有组织因素和信息系统因素。组织因素中主要有：公司规模、员工总数、行业特征、组织结构、集权度、合并与被合并企业的关联关系、历史合并经验等等；信息系统因素包括：信息系统员工数、员工技能水平、数据共享、合并。信息系统的成功整合在信息共享方面所起到的作用至关重要，能够极大促进企业研发活动的进程，产生更多的创新成果。

## <sub>6.</sub> 技术整合

企业合并重要动机之一就是获得外部技术。企业合并能够使企业间获得研发协同，并且可以使生产链条更加完整。技术整合就是把参与企业合并的各方的技术利用方式进行调整，为异质的技术建立一个通用的平台使技术能够自由传递。 <sup>［11］</sup> 采用灰色关联度的研究方法进行了个例研究，根据灰色关联度的检验结果可以找出对创新绩效最为核心的技术资产以及不同技术之间的关联程度。据此在技术整合的过程中就可以根据技术对创新绩效所起作用的大小来考虑通用平台的设计，重视核心技术的方便获取，促进技术的有效整合。

## <sub>7.</sub>财务整合

企业进行并购，动机总是少不了节约财务费用，降低生产经营成本。企业并购后，为了保证并购各方在财务上的稳定性及其在金融市场和产品市场上的形象，并购各方在财务制度上互相连通，资金管理和使用上协调一致是必需的。

## （二）企业资源整合产生的协同效应

企业合并后进行资源整合的目的是为了达到协同效应以促进创新，协同效应是创新绩效的源泉。许多研究者的研究中指出，资源整合和创新能力之间存在着显著的相关关系。那么，资源整合效果的好坏也将影响到创新绩效的高低。饶扬德<sup>［12］</sup> 认为资源整合决定着资源效能充分发挥的程度，以及竞争优势的形成。企业通过合并获取一定的资源，所获取的资源经过整合为己所用，将会提高创新效率，加强创新能力，增加创新成果。胡挺<sup>［13］</sup> 通过工商银行连续并购东亚银行的经验证明了企业的并购能力与价值创造之间的关系。林健<sup>［14］</sup> 的研究通过对文献的回顾，提出了创新资源整合、团队互动和协同创新绩效之间关系的假设模型，并通过 个团队的问卷调查对该模型进行了验证，研究结果表明，资源整合本身就是一种创新，可以直接有效地促进协同创新的绩效；另外，创新资源整合也通过团队互动间接对创新绩效产生影响。

根据以上对企业并购中进行的若干方面的资源整合，运用平衡记分卡的分类方法对这些整合效果产生的协同效应进行分类和量化。

结构整合和技术整合的效果反映在经营的过程中，但又不直接体现在企业盈利方面，因此我们可以用一些反映企业运营能力的资产周转率的指标来对其反映，最终形成一个财务综合数据。信息系统整合、文化整合和人力资源整合的效果主要体现在期间费用的规模，如果这些方面的整合效果良好，企业就不需花费大量资金用于调节员工之间因为企业文化不同、公司待遇差距或者信息沟通不畅等引起的矛盾和冲突，那么企业的营业费用率就会降低。战略整合的效果体现在企业整体的管理工作中，关联企业整体业绩，需要用一个较能综合反映企业情况的效用指标。财务整合效果产生的财务协同主要是表现在投资和融资技能提高上，在财务指标上表现为投资融资成本的下降，这个显而易见。

那么，企业并购后产生的哪些协同效应对创新有重要影响呢？一些学者的研究结果是企业合并并未对创新产生积极的影响，从理论上看不应出现这样的结果，因此我们就不同方面资源整合产生的协同效应为切入点来研究企业合并对创新的影响。

企业合并后无形资产的整合产生的协同效应是非常巨大的。协同效应的效果取决于公司内部资源的共享程度以及知识传递的通畅程度。无形资产有低成本的传递性和重复性，所以协同效应最容易通过无形资产的共享和传递产生。

其次，经营协同方面的变量，主要是费用占收入的比例。

## （二）指标的标准化处理

首先运用极差变换法对指标无量纲化处理。本综合评价体系所采用指标分三类，需要按以下办法进行标准化处理。

对于正向指标和逆向指标，处理公式分别为：

$$
\begin{array}{l} x _ {i j} ^ {\prime} = \frac {x _ {i j} - \min \left(x _ {i j} , \cdots , x _ {n j}\right)}{\max \left(x _ {i j} , \cdots , x _ {n j}\right) - \min \left(x _ {i j} , \cdots , x _ {n j}\right)} \\ x _ {i j} ^ {\prime} = \frac {\max \left(x _ {1 j} , \cdots , x _ {n j}\right) - x _ {i j}}{\max \left(x _ {1 j} , \cdots , x _ {n j}\right) - \min \left(x _ {1 j} , \cdots , x _ {n j}\right)} \end{array}
$$

对于适度指标，其处理公式为

$$
\text {当} x _ {i j} <   x \text {时，} x _ {i j} ^ {\prime} = \frac {x _ {i j} - \min \left(x _ {1 j} , \cdots , x _ {n j}\right)}{x - \min \left(x _ {1 j} , \cdots , x _ {n j}\right)}
$$

当 $x _ { i j } = x$ 时， $x _ { i j } ^ { \prime } = 1$

当 $\mathscr { X } _ { i j } > \mathscr { X }$ 时， $\boldsymbol { x ^ { \prime } } _ { i j } = \frac { \operatorname* { m a x } \bigl ( \boldsymbol { x } _ { 1 j } , \cdots , \boldsymbol { x } _ { n j } \bigr ) - \boldsymbol { x } _ { i j } } { \operatorname* { m a x } \bigl ( \boldsymbol { x } _ { 1 j } , \cdots , \boldsymbol { x } _ { n j } \bigr ) - \boldsymbol { x } }$

## （三）运用熵权法对资源整合效果进行综合评价

本文中，管理协同和财务协同分别由单位资产人均主营业务收入和资本成本的单个指标来衡量，而财务综合和经营协同是由多个指标来衡量的，这里采用熵权法对其进行综合评价。运用熵权法可以比较客观真实地反映企业合并后资源整合效果以及创新绩效。

设有n个样本，m个指标，则 $\mathscr { X } _ { i j }$ 为第i 个样本的第j个指标的观测值，i<sub>=1</sub>，…，n；j<sub>=1</sub>，…，m。

得到矩阵： $\left( \begin{array} { c c c } { x _ { 1 1 } } & { \ldots } & { x _ { 1 m } } \\ { \vdots } & { \ddots } & { \vdots } \\ { x _ { n 1 } } & { \cdots } & { x _ { n m } } \end{array} \right)$ ，每行为每个样本的指标值，每列为不同样本同一个指标的值。对i个指标进行标准化以后，可以计算各指标的信息熵H：

$$
H _ {i} = - k \sum_ {j = 1} ^ {m} f _ {i j} \ln f _ {i j}
$$

其中， $f _ { i j } = \frac { x _ { i j } ^ { \prime } } { \sum _ { j = 1 } ^ { m } x _ { \ i j } ^ { \prime } } , k = \frac { 1 } { \ln n }$

假定：当 $f _ { i j } = 0$ 时， $f _ { i j } \ln f _ { i j } = 0$ ，那么熵权：

$$
\mathcal {W} _ {i} = \frac {1 - H _ {i}}{m - \sum_ {i = 1} ^ {m} H _ {i}}
$$

计算各个个体的综合得分 $s _ { i } = \sum _ { j = 1 } ^ { m } w _ { i } f _ { i j } \ , \ i = 1 , \ \cdots , \ n _ { \circ }$

根据熵权法，代入数据后可以得到财务综合和经营协同的综合指标。

## 五、结 论

企业合并是企业取得竞争优势的有利途径，合并之后的资源整合是一项至关重要的工作，资源整合产生的协同效应可以为企业带来 的效果，企业因此能够加强自身的竞争力，特别是对于信息技术产业来说，创新就是企业的核心任务。本文针对不同方面的资源整合，对其产生的协同效应进行量化，检验各个方面对创新的影响。结果表明：经营协同效应，也就是文化、信息系统和技术方面的整合，以及战略整合产生的管理协同效应都显著促进创新，而财务方面的整合对创新的影响不大。因此，如果企业在合并后如果想要突出创新方面的优势，增加企业核心竞争力，就必须要加强企业文化、信息系统、技术、战略等经营和管理方面的资源整合，以创造更好的协同效应，而不能仅仅注重于并购后的财务整合。

本文也存在一些局限性。首先，在指标体系的设计方面，都是一些财务类的指标，这些指标容易被管理层操控，因此有待进一步的改进；其次，创新绩效的指标用单一指标，迫于数据能否得到，目前只能检验研发投入与协同效应的关系，如果能够把创新绩效也用多指标熵权法进行改进，那么检验结果会更加科学与精确。
