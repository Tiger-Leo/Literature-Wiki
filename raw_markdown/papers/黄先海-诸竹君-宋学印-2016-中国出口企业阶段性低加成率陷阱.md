# 中国出口企业阶段性低加成率陷阱

黄先海 诸竹君 宋学印

内容提要 本文基于扩展的 M-O 模型，提出了出口企业阶段性 <sup>“</sup>低加成率陷阱<sup>”</sup>现象 通过引入产品质量，对这一现象的微观机制进行了深入探索 本文认为，企业低加成率出口正是较低生产率水平下 <sup>“</sup>最优出口产品质量选择<sup>”</sup>所带来的一种阶段性现象，采用中国工业企业数据和海关交易数据进行的经验研究结果显示: 中国出口企业普遍处于 <sup>“</sup>低加成率陷阱<sup>”</sup>区间; 出口企业加成率关于生产率的<sup>“</sup>U 型<sup>”</sup>曲线的门槛值约为6. 93，约25%的企业已经跨越了 <sup>“</sup>低加成率陷阱<sup>”</sup>区间;东部企业面临的<sup>“</sup>质量升级效应<sup>”</sup>更强烈，<sup>“</sup>质量升级<sup>”</sup>意愿较强; 中国具有比较优势的劳动密集型行业更多处于 <sup>“</sup>低加成率陷阱<sup>”</sup>区间，而技术密集型行业出口负向影响相对较弱

关 键 词 低加成率陷阱 质量选择 竞争加剧效应 质量升级效应

## 一 引言

扩大出口规模是中国对外开放初期以及加入 WTO 十余年来的主要目标，随着中国于2013 年成为世界第一货物贸易大国，提高出口质量和出口附加值成为中国开放型经济发展新阶段面临的主要议题<sub>。</sub> 长期以来，<sup>“</sup>低质量<sub>、</sub>低价格<sup>”</sup>是中国出口产品在国际市场上难以摆脱的标签，令人难解的是，中国出口的产品不仅在国际市场上和国外同类产品相比价格较低，甚至普遍低于仅在国内市场销售的同类产品价格，这正是盛丹和王永进(2012) 提出的<sup>“</sup>中国企业低价出口之谜<sup>”</sup>

<sup>“</sup>中国企业低价出口之谜<sup>”</sup>不仅违背国际贸易理论的预期，也导致了国际产业界对中国各类贸易激励政策的广泛批评<sub>。</sub> 根据 Melitz(2003) 的新新贸易理论，出口企业是可以克服较高出口固定成本的高生产率企业，因此出口企业的加成率一般应高于非出口企业 <sup>“</sup>中国企业低价出口之谜<sup>”</sup>的特殊性在于伴随着生产率的提高，出口产品加成率却不断下滑<sup>①</sup>

由于理论上难以解释，国内学术界对<sup>“</sup>中国企业低价出口之谜<sup>”</sup>的解读更多转向现实层面，目前可主要分为两种观点: 第一种认为广泛的出口退税等贸易政策降低了企业对国际市场价格竞争的敏感度，即使制定低于国内市场的价格，也可以因出口退税获得经补贴调整后较高真实加成率; 第二种观点认为中国

企业并不具有出口定价权，广泛存在的加工贸易企业实际上是被动接受国际发包方的订单式价格( 李秀芳和施炳展，2012) ，这也呼应了李春顶(2010) 等所刻画的 <sup>“</sup>生产率悖论<sup>”</sup>，即中国企业出口与高生产率并非稳定对应，因此，出口企业并不一定意味着高加成率<sub>。</sub>

然而上述解读更多是一种现实考虑或者经验研究，不仅缺少企业微观机制支撑，而且忽略了一个重要的潜在可能: <sup>“</sup>低质量 低价格<sup>”</sup>是企业由不出口转向出口环境下的内生最优选择，并且与企业所处的生产率阶段相关联，即低加成率只是出口企业面临的阶段性陷阱，当生产率跨过该阶段时，企业将内生选择 <sup>“</sup>高质量 高价格<sup>”</sup> 这是本文对<sup>“</sup>中国企业低价出口之谜<sup>”</sup>更具理论解释力的新解读，其重大现实含义在于: 即使消除出口退税 出口战略等来自国家贸易政策方面的激励环境，以 <sup>“</sup>低质量 低价格<sup>”</sup>进入出口市场仍是企业的内生选择，只有生产率跨越 <sup>“</sup>低加成率陷阱<sup>”</sup>门槛值后，出口企业才会在国际市场上选择 <sup>“</sup>高质量<sub>、</sub>高价格<sup>”</sup> <sub>。</sub>

## 二 文献回顾

围绕本文的研究主题主要梳理如下三类文献: 第一类是早期静态加成率影响机制研究 第二类是最近十余年来对开放条件下加成率动态化及其与出口行为互动机制的研究<sub>。</sub> 第三类是关于生产率 出口行为与加成率关系的经验研究<sub>。</sub> 经济学理论表明在完全竞争的市场结构下，企业定价将等于成本 因此不足为怪，第一类文献是从产业组织角度对企业加成率进行研究<sub>。</sub> Eaton 和 Grossman(1986) 提出，如果行业内企业能将产出减少至合谋状态下的数量，从而避免同行企业间的激烈竞争，便可在市场上维持较高的加成率 Hall(1988) 受规模报酬不变 完全竞争思路启示，创造性地通过产业层面数据证明存在递增报酬，从反面证实加成率的存在<sub>。</sub> 在 Eden 和 Griliches( 1991) 提供理论模型基础后，Caballero 和 Lyons( 1992) Konings 等( 2005) 均认为在非完全竞争市场，加成率一般大于1 加成率越高，企业可以获得的垄断利润越高

第二类研究的奠基性文献———Melitz 和 Ottaviano( 2008) ( 以下简称 M-O 模型) 开创性地引入企业在出口市场的定价进而将出口加成率内生化 M-O 模型表明，企业生产率越高，越容易克服出口所面临的固定成本，即出口企业通常比不出口企业具有更高的加成率 随后，以生产率和出口行为对企业加成率影响机制的研究快速发展，并成为当前新新贸易理论的热点 Kugler 和 Verhoogen(2011) 认为出口企业一般具有比国内企业生产更高品质的产品，在其他条件相同时，出口企业的加成率就会较高<sub>。</sub>Antoniades(2015) 则进一步将产品质量纳入到扩展的 M-O 模型中，认为出口市场的竞争不仅提高最低生产率门槛值，而且提高了产品质量差异<sub>。</sub>

第三类文献主要开展企业加成率与生产率及出口行为相互关系的经验研究，其前提和难点是设计一个衡量企业加成率的可靠估计方法，这一困难因 De Loecker 和Warzynski(2012) 提出的企业加成率估计方法得到解决后，相关文献也迅速丰富起来如 De Loecker 和 Warzynski(2012) 利用斯洛文尼亚企业数据库，在微观层次估算了企业加成率，并认为竞争政策和贸易政策都能作用于加成率 Bellone 等(2014) 运用法国工业企业数据，对 M-O 模型的结论进行了计量检验，结果表明企业加成率和生产率成正向关系

上述文献多数以发达国家出口行为与加成率的关系作为研究对象，其理论分析和经验研究的一致结果是出口企业的加成率高于不出口企业，但这一结论似乎与中国出口企业的现实相违背<sub>。</sub> 盛丹和王永进(2012) 指出，中国出口企业的加成率普遍低于不出口企业，并认为出口退税等贸易政策以及出口企业内部竞争是导致这一现象的重要原因<sub>。</sub>

与上述文献相比，本文可能的创新之处在于: (1) 本文在 M-O 模型基础上，构建了一个可以兼容出口与不出口企业生产率与加成率内生变化机制的统一框架，该框架解释了中国所面临的低加成率出口现象，并进一步提出了出口企业加成率和生产率存在的<sup>“</sup>U 型<sup>”</sup>曲线关系 (2) 目前，国内关于企业加成率的研究相对较少，现有研究大都基于收入法加成率的测度方法 本文在国内较早使用数量法对企业加成率进行估计，相较于收入法更好地解决了价格因素对加成率估计的影响 (3) 本文通过引入扩展的 M-O 模型，进一步挖掘出口企业面临该阶段性 <sup>“</sup>低加成率陷阱<sup>”</sup>背后的经济逻辑，为上述质量选择机制提供了来自中国的经验证据，并证实产品质量和企业加成率之间的作用关系<sub>。</sub>

## 三 理论模型

借鉴 Melitz 和 Ottaviano(2008) 的模型，本文试图从理论上论证中国出口企业存在的阶段性<sup>“</sup>低加成率陷阱<sup>”</sup>现象，并解释造成这种现象的可能机制

假定仅存在两个国家，本国 H和外国 F，他们都生产并消费一种传统商品和一类工业品 传统商品市场是完全竞争的，将其标准化为等价物 工业品市场是垄断竞争的，其种类 $\chi \in \varOmega$ 是分布在 $\varOmega$ 上的连续统 假定本国 H 和外国 F 的消费者偏好 厂商生产技术相同，外国 F 的市场规模大于本国市场 $L ^ { F } > L ^ { H }$ 。

1. 需求与消费者偏好 两个国家的代表性消费者拥有以下拟线性效用函数:

$$
U = q _ {0} ^ {c} + \alpha \int_ {\chi \in \Omega} q _ {\chi} ^ {c} d \chi - \frac {1}{2} \gamma \int_ {\chi \in \Omega} \left(q _ {\chi} ^ {c}\right) ^ {2} d \chi - \frac {1}{2} \eta \left(\int_ {\chi \in \Omega} q _ {\chi} ^ {c} d \chi\right) ^ {2}\tag{1}
$$

其中 $\bullet q _ { 0 } ^ { c }$ 表示传统商品 $\bullet q _ { \chi } ^ { c }$ 表示第 $\dot { \chi }$ 种工业品<sub>。</sub> 参数 $\alpha \gamma \gamma \eta$ 均大于0，刻画商品之间的替代弹性，其中 $\gamma$ 表示工业品之间的替代弹性， $\alpha$ 和 $\boldsymbol { \mathsf { \Pi } } ^ { \mathsf { \Pi } }$ 表示工业品与传统商品之间的替代弹性<sub>。</sub>

根据(1) 式，可以求得在每个市场工业品 $\chi$ 的线性需求函数:

$$
q _ {\chi} \equiv L ^ {\nu} q _ {\chi} ^ {c} = \frac {\alpha L ^ {\nu}}{\eta N ^ {\nu} + \gamma} - \frac {L ^ {\nu}}{\gamma} p _ {\chi} ^ {\nu} + \frac {\eta N ^ {\nu}}{\eta N ^ {\nu} + \gamma} \frac {L ^ {\nu}}{\gamma} \bar {p} ^ {\nu}\tag{2}
$$

其中， $\mathbf { \nabla } _ { \mathbf { \rho } } v = H$ 或 $F , N ^ { v }$ 表示一国所有商品种类， $\bar { p } ^ { v } = \frac 1 { N ^ { v } } \int _ { \chi \in \varOmega ^ { * } } p _ { \chi } ^ { v } d \chi | \varOmega ^ { * } ^ { v } \subseteq \varOmega )$ 是一国生产商品的平均价格<sub>。</sub> 令消费者需求为0，可以求得一国市场上商品的最高价格<sub>。</sub>

$$
p _ {\max} ^ {\nu} \equiv \frac {1}{\eta N ^ {\nu} + \gamma} \left(\gamma \alpha + \eta N ^ {\nu} \bar {p} ^ {\nu}\right)\tag{3}
$$

假定外国市场竞争比本国市场更加激烈，即外国市场平均价格更低 $\bar { \bullet ^ { p ^ { F } } } < \bar { \overline { { p } } } ^ { H }$ <sub>。</sub> 根据 M-O 模型中一般均衡结果可知: $\hat { p } _ { m a x } ^ { F } < \hat { p } _ { m a x } ^ { H }$ 。

2. 供给与生产者行为<sub>。</sub> 同 M-O 模型基本假定，只有劳动力一种生产要素，单位工资标准化为1 传统商品生产规模报酬不变，而工业品生产是规模报酬递增的，企业需要支付国内生产的固定成本 $f _ { E }$ ，并随机抽取一个边际成本 $c ^ { \textregistered }$ 代表性企业的成本函数是:

$$
C (q _ {i}) = c q _ {i}\tag{4}
$$

企业根据利润最大化原则选择自身产量，以满足国内市场 部分企业除供应国内市场外，还会出口到外国市场，出口需要支付冰山运输成本 $\tau > 1$ ，因此企业的边际成本变为 $\tau c .$ 企业内销和出口的临界成本 $c ^ { H } = p _ { \mathrm { m a x } } ^ { H }$ 和 $c ^ { F } = p _ { \operatorname* { m a x } } ^ { F } / \tau ,$ ，由于 $p _ { \operatorname* { m a x } } ^ { F } < p _ { \operatorname* { m a x } } ^ { H } \cdot \tau > 1$ ，所以$c ^ { H } > c ^ { F }$ 根据上述分析，可以将企业的生产行为进行分类: $c > c ^ { H }$ 的企业退出市场， $\bullet ^ { c ^ { F } } < c$ $\leqslant c ^ { H }$ 的企业仅供应本国市场 $\bullet c < c ^ { F }$ 的企业既供应本国市场又出口到外国市场

根据企业的最优化决策，可以求得企业在本国市场 H 和外国市场 F 生产商品的价格和数量:

$$
p ^ {H} (c) = \frac {1}{2} \left(c ^ {H} + c\right) q ^ {H} (c) = \frac {L ^ {H}}{2 \gamma} \left(c ^ {H} - c\right)\tag{5}
$$

$$
p ^ {F} (c) = \frac {\tau}{2} \left(c ^ {F} + c\right) q ^ {F} (c) = \frac {L ^ {F}}{2 \gamma} \tau \left(c ^ {F} - c\right)\tag{6}
$$

由(5) (6) 式可得，企业在本国市场和外国市场的绝对加成率:

$$
\mu^ {H} (c) = \frac {1}{2} (c ^ {H} - c)\tag{7}
$$

$$
\mu^ {F} (c) = \frac {\tau}{2} \left(c ^ {F} - c\right)\tag{8}
$$

3. 企业平均加成率计算 在本文的经验部分，将对企业的加成率进行测算 由于数据所限，无法区分企业在本国市场和外国市场的加成率，因此有必要构造一个加权平均的企业加成率 $\mu ( \boldsymbol { c } )$ 对于仅供应本国市场的企业 $\mu ( \boldsymbol { c } ) \ = \mu ^ { H } ( \boldsymbol { c } )$ ，对于出口企业来说，平均加成率可以按产量为权重求加权平均值 具体形式为:

$$
\mu (c) = \left\{ \begin{array}{l} \frac {1}{2} \left(c ^ {H} - c\right), c ^ {F} <   c \leqslant c ^ {H} \\ \frac {L ^ {H} \left(c ^ {H} - c\right) ^ {2} + L ^ {F} \tau^ {2} \left(c ^ {F} - c\right) ^ {2}}{2 L ^ {H} \left(c ^ {H} - c\right) + 2 L ^ {F} \tau \left(c ^ {F} - c\right)}, 0 <   c \leqslant c ^ {F} \end{array} \right.\tag{9}
$$

由(9) 式可知，企业的平均加成率与生产率( 这里以 c 体现) 并不是完全单调的关系，还受到企业出口行为的影响 为了研究的直观和方便，对(9) 式进行量化分析，对各参数进行赋值: 令 $L ^ { F } / L ^ { H } = 1 0 , c ^ { H } = 2 , c ^ { F } = 1 . 2 , \tau = 1 . 2 5 ^ { \textregistered }$ ，可以得到 $\mu ( \boldsymbol { c } )$ 关于 c 的函数图像，如图2 所示: 这里 $c ^ { T }$ 表示左侧曲线最低点，<sup>“</sup>低加成率陷阱<sup>”</sup>表现在拥有更高生产率的企业 $c ^ { T } < c < c ^ { F } )$ ，其加成率却小于生产率更低 仅供应本国市场的企业 在$c ^ { T } < c < c ^ { F }$ 上出口企业陷入了<sup>“</sup>低加成率陷阱<sup>”</sup>，出口行为扭曲了生产率和加成率的单调关系<sub>。</sub> 因此企业出口行为与加成率的关系取决于 c 的分布 $G ( \boldsymbol { c } )$ ，如果较多企业分布在 $c ^ { T } < c < c ^ { F }$ 这一<sup>“</sup>低加成率陷阱<sup>”</sup>区间，那么出口行为会导致企业加成率的下降反之，出口会促进企业加成率水平的提高<sub>。</sub>

综上所述，可得以下两条命题:

命题1:控制企业出口行为，企业加成率与生产率成正相关<sub>。</sub>

命题2:出口企业生产率在 <sup>“</sup>低加成率陷阱<sup>”</sup>区间( $c ^ { T } < c < c ^ { F } )$ 时，出口行为会导致加成率下降<sub>。</sub> 反之则会提高企业加成率<sub>。</sub>

4. 引入产品质量的机制解释<sub>。</sub> 理论模型已经得到了出口企业生产率对加成率的作用关系，这种<sup>“</sup>U 型<sup>”</sup>关系表明只有生产率水平较高的企业( $0 < c < c ^ { T } )$ 出口才会获得更高的加成率根据 Antoniades ( 2015 ) Bellone等( 2014) 对 M-O 模型的改进，将企业最优产品质量选择引入模型，作者认为这种扩展会更有

利于分析这种<sup>“</sup>U 型<sup>”</sup>关系的微观机制<sub>。</sub>

该扩展模型的经济逻辑是: 国外市场规模更大，企业质量升级带来的利润上升更容易克服所需要的成本，即出口市场的质量升级更为容易，出口企业面临 <sup>“</sup>质量升级效应<sup>”</sup> 企业的最优产品质量选择取决于不同市场质量差异斜率和企业边际成本 c 出口企业在外国市场面临两种效应的叠加，一种是 <sup>“</sup>竞争加剧效应<sup>”</sup> 一种是 <sup>“</sup>质量升级效应<sup>”</sup>，出口企业是否提升产品质量取决于两种效应的相对大小 当企业进入出口市场，但由于生产率水平相对较低，无法克服质量升级带来的成本上升，此时 <sup>“</sup>竞争加剧效应<sup>”</sup>大于 <sup>“</sup>质量升级效应<sup>”</sup>，企业最优选择是 <sup>“</sup>低质 低价 低加成率出口<sup>”</sup>; 当企业生产率水平相对更高，能够克服质量升级带来的成本上升，此时<sup>“</sup>质量升级效应<sup>”</sup>大于 <sup>“</sup>竞争加剧效应<sup>”</sup>，企业最优选择是 <sup>“</sup>高质 高价 高加成率出口 <sup>”</sup> <sub>。</sub>

根据扩展 M-O 模型，可得下面两个命题:

命题3:企业加成率与产品质量正相关，企业加成率与出口行为的关系是由最优产品质量选择决定的<sub>。</sub>

命题4:较高生产率企业 $\displaystyle { \big ( } 0 < c < c ^ { T } { \big ) }$ 在出口市场表现为 <sup>“</sup>质量升级效应<sup>”</sup>大于 <sup>“</sup>竞 争加剧效应<sup>”</sup>，会提高其加成率水平; 反之，较低生产率企业 $\displaystyle \ : \big ( \boldsymbol { c } ^ { T } < \boldsymbol { c } < \boldsymbol { c } ^ { F } \big ) \ :$ ，出口会降低 其加成率水平<sub>。</sub>

## ( 三) 企业层面的加成率估计

企业层面的加成率估计，本文借鉴 De Loecker 和 Warzynski( 2012) 的成果采用结构模型的方法对中国企业加成率进行估算( 以下简称收入法) De Loecker 等(2014)在收入法的基础上进一步构造了基于产品数量的加成率测算方法( 以下简称数量法) ，解决了收入法隐含的价格问题以及多产品企业加成率估计的问题，因而优于收入法 考虑到数据的可得性和代表性，本文同时运用两种方法估计企业加成率，但是仍然使用收入法作为基准，数量法作为稳健性检验的重要依据<sub>。</sub>

下面主要介绍数量法估计中国企业加成率的原理<sup>③</sup> 考虑企业产品 b 的生产函数为:

$$
Y _ {i b t} = F _ {t} \big (A _ {i b t} \big) e x p \big (\omega_ {i t} \big)\tag{10}
$$

其中 $Y _ { i b t }$ 和 $A _ { i b t }$ 表示企业 i 产品 b 的产量和所投入的要素 $\mathit { \Pi } _ { \left. \right\} ^ { ' } A _ { i b t } = \left\{ \right. L _ { i b t } , K _ { i b t } , M _ { i b t } } \ : )$ ，$\omega _ { i t }$ 表示企业特定的对数生产率冲击 假定 $\omega _ { i t }$ 是希克斯中性的，且该冲击等价于企业生产特定产品的生产率冲击( Bernard 等，2010) 中国企业的实际情况是，劳动力还未能实现充分流动，不应将劳动力视为企业可以充分调整的投入要素 因此，本文认为中间品投入是没有调整成本的生产要素 考虑一个成本最小化问题:

$$
L \left(A _ {i b t}, \lambda_ {i b t}\right) = P _ {i b t} ^ {L} L _ {i b t} + P _ {i b t} ^ {K} K _ {i b t} + P _ {i b t} ^ {M} M _ {i b t} + \lambda_ {i b t} \left[ Y _ {i b t} - Y _ {i b t} \left(A _ {i b t}, \omega_ {i t}\right) \right]\tag{11}
$$

其中， $P _ { i b t } ^ { \phantom { \dagger } L } \cdot P _ { i b t } ^ { \phantom { \dagger } K } \cdot P _ { i b t } ^ { M }$ 分别表示劳动力<sub>、</sub>资本和中间品投入的价格， $\mathbf { \nabla } \cdot \lambda _ { i b t }$ 是拉格朗日乘子，企业选择 $M _ { i b t }$ 最小化成本，由一阶条件可得: $\frac { \partial L _ { i b t } } { \partial M _ { i b t } } = P _ { i b t } ^ { M } - \lambda _ { i b t } \frac { \partial Y _ { i b t } ( . ) } { \partial M _ { i b t } }$ ，简单整理可得( 12) 式: $\lambda _ { i b t }$ 此时表示产品 b 的边际成本<sub>。</sub>

$$
\frac {\partial Y _ {i b t} (\cdot)}{\partial M _ {i b t}} \frac {M _ {i b t}}{Y _ {i b t} (\cdot)} = \lambda_ {i b t} ^ {- 1} \frac {P _ {i b t} ^ {M} M _ {i b t}}{Y _ {i b t}}\tag{12}
$$

定义企业产品 b 的加成率 $\mu _ { i b t } = P _ { i b t } / \lambda _ { i b t }$ ，其中 $P _ { i b t }$ 表示产品b 的市场价格，令 $\alpha _ { i b t } ^ { M } =$ $P _ { i b t } ^ { M } M _ { i b t } / P _ { i b t } Y _ { i b t }$ ，根据(12) 式可得:

$$
\mu_ {i b t} = \theta_ {i b t} ^ {M} \big (\alpha_ {i b t} ^ {M} \big) ^ {- 1}\tag{13}
$$

其中 $\theta _ { i b t } ^ { M }$ 和 $\alpha _ { i b t } ^ { M }$ 分别表示产品 b 所需中间品投入的产出弹性和占收入份额<sub>。</sub> 下面我们将(10) 式取对数:

$$
y _ {i b t} = f \left(a _ {i b t}, \beta\right) + \omega_ {i t} + \varepsilon_ {i b t}\tag{14}
$$

(14) 式中小写字母均表示相应变量的对数值，其中 $\varepsilon _ { i b t }$ 表示随机误差项和不可观测的产出冲击<sub>。</sub> 由于缺乏产品层面投入要素价格的数据，因而无法确定特定产品所需要素占整体份额<sub>。</sub> 设产品 b 所需要素 A 份额的对数值为 ${ \rho _ { i b t } } ^ { A }$ ，易得 ${ \rho _ { i b t } } ^ { A } = a _ { i b t } - a _ { i t }$ ，将( 14) 式改写为:

$$
y _ {i b t} = f (a _ {i t}, \beta) + B _ {i b t} (\rho_ {i b t} ^ {A}, a _ {i t}, \beta) + \omega_ {i t} + \varepsilon_ {i b t}\tag{15}

$$
\hat {\omega} _ {i b t} = B _ {i b t} \big (\rho_ {i b t}, a _ {i t}, \hat {\beta} \big) + \omega_ {i t} = \hat {\varphi} _ {1 b t} \rho_ {i b t} + \hat {\varphi} _ {2 b t} \rho_ {i b t} ^ {2} + \omega_ {i t}\tag{16}
$$

$$

$+ m _ { i t } \} , \hat { \varphi } _ { 2 b t } = \hat { \beta } _ { l l } + \hat { \beta } _ { k k } + \hat { \beta } _ { m m } + \hat { \beta } _ { l k } + \hat { \beta } _ { l m } + \hat { \beta } _ { k m }$ <sub>。</sub> 假定 $\sum _ { b } \rho _ { i b t }$ 等于企业出口强度( 总出口/总产出) ，我们可以得到企业产品层面加成率的测算公式:

\hat {\mu} _ {i b t} = \hat {\theta} _ {i b t} ^ {M} P _ {i b t} Y _ {i b t} / e x p (\hat {\rho} _ {i b t}) P _ {i t} ^ {M} M _ {i t}\tag{17}
$$

其中 $P _ { i b t }$ 表示产品 b 的价格， $\hat { \boldsymbol { \theta } } _ { i b t } ^ { M }$ 表示产品 b 生产所需中间品的产出弹性， $\hat { \theta } _ { i b t } ^ { M } = \hat { \beta } _ { r }$ m$+ \ 2 \hat { \beta } _ { m m } \big ( \hat { \rho } _ { i b t } + m _ { i t } \big ) \ + \hat { \beta } _ { l m } \big ( \hat { \rho } _ { i b t } + l _ { i t } \big ) \ + \hat { \beta } _ { k m } \big ( \hat { \rho } _ { i b t } + k _ { i t } \big )$ 根据销售额的比重 $\Psi _ { \mathrm { h } }$ 将产品层面加成率汇总，可得企业层面加成率:

## ( 六) 企业产品质量

本文测度出口企业产品质量是基于 <sup>“</sup>需求残差<sup>”</sup>的原理( Gervais，2009; Joel，2011;施炳展和邵文波，2014) 其基本思想是企业的出口量受到两个主要变量的影响: 一是产品价格，二是产品质量 控制其他变量不变，企业产品出口量不能用价格解释的部分就可以认定为产品质量 其数学表达式为:

$$
\text { quality } _ {b m t} = \ln \hat {\lambda} _ {b m t} = \frac {\hat {\varepsilon} _ {b m t}}{\sigma - 1} = \frac {\ln q _ {b m t} - \ln \hat {q} _ {b m t}}{\sigma - 1}\tag{20}
$$

对(20) 式进行标准化可得出口产品的标准质量指数，如(21) 式<sub>。</sub>

$$
r _ {-} q u a l i t y _ {b m t} = \frac {\text { quality } _ {b m t} - \text { minquality } _ {b m t}}{\text { maxquality } _ {b m t} - \text { minquality } _ {b m t}}\tag{21}
$$

其中 $\mathsf { \bullet } q u a l i t y _ { b m t }$ 表示t 年b 产品在m 市场的质量， $\hat { \bullet } \hat { \varepsilon } _ { b m t }$ 表示质量方程回归的残差项，$q _ { b m t }$ 表示该种产品的实际出口额， $\hat { \boldsymbol { q } } _ { b m t }$ 表示该种产品的预计出口额，<sub>σ</sub> 表示需求弹性(21) 式中max 和min 分别表示最大值和最小值，该种标准化所得的 $r \_ q u a l i t y _ { b m t }$ 保证产品质量指标介于［0，1］之间，且不具有测度单位，因此可以进行加总分析和跨期比较研究<sub>。</sub>在此基础上，根据企业出口产品的销售额比例可得加权平均的企业产品质量 $q u a l i t y _ { i t } \textcircled { 1 }$

## ( 六) 分所有制类型回归结果

根据表5 第(1) (3) (5) (7) 列的回归结果显示，出口行为对港澳台企业 外资企业影响较大，对私营 国有企业的影响较小 进一步利用其他各列的结果计算各所有制类型行业的条件关系曲线门槛值: 国有企业为5. 38，私营企业为6.32，外资企业为6. 75，港澳台企业为6.71 外资和港澳台企业<sup>“</sup>质量升级效应<sup>”</sup>最弱，这主要是源于其产品质量升级较于发达国家市场难度更大 外资和港澳台企业主要是通过 <sup>“</sup>全球价值链治理<sup>”</sup>，利用中国相对低廉的要素成本进行生产<sub>。</sub> 由于其相对于国内企业的技术 质量优势，故在中国国内的加成率相对较高，但是在出口市场更容易偏向 <sup>“</sup>低质低价 低加成率出口<sup>”</sup>模式，两种力量相互作用使其出口行为对加成率的负向作用最为明显<sub>。</sub>

## ( 七) 稳健性检验

为了使经验部分的结果更加稳健，本文在上述计量结果的基础上，还进行了以下2 种稳健性检验 其中稳健性检验1 主要验证理论部分提出的命题是否正确; 稳健性检验2 主要减少内生性对计量结果的影响

1. 面板门限效应检验<sup>②</sup> 为进一步确定企业出口与加成率的条件关系以及出口产品质量与企业生产率之间可能存在的非线性关系，本文引入面板门限效应检验，选取 lntfp\_lp 作为门限变量<sub>。</sub> 为确定门限的个数，依次对模型进行单一<sub>、</sub>二重<sub>、</sub>三重等门限效应检验，根据 F 值和自举法( bootstrap) 所得 P 值来判断应选择的门限效应模型<sub>。</sub>从面板门限效应自抽样检验中可以观察到以下两点: 一是出口对于企业加成率的作用受到生产率影响，二是生产率对企业产品质量选择的作用也受制于生产率高低，都表现为非线性的作用形式 进一步的回归结果可知生产率影响的方向和大小 结果表明，当企业生产率低于门限值( lntfp\_lp ＜6.851) 时，出口对企业加成率有负向作用，表现为<sup>“</sup>出口低加成率陷阱<sup>”</sup> 当生产率超过该门限值时出口会提高企业的加成率，甚至当生产率超过7.514 时这种正向作用还会被放大<sub>。</sub> 这就验证了出口对企业加成率的作用关于生产率呈现条件关系

面板门限效应自抽样检验结果还表明出口企业质量选择机制受到生产率的影响<sub>。</sub>当企业生产率低于6.991 时，企业的生产率对产品质量没有显著影响，当生产率超过该门限值时，企业生产率对产品质量会有正向作用 这一结果显示，出口企业的产品质量选择确实受到生产率的影响 当企业生产率低于门限值时，<sup>“</sup>质量升级效应<sup>”</sup>低于<sup>“</sup>竞争加剧效应<sup>”</sup>，因此生产率对企业产品质量并不能产生显著作用; 当企业生产率超过门限值时，<sup>“</sup>质量升级效应<sup>”</sup>大于<sup>“</sup>竞争加剧效应<sup>”</sup>，因此生产率对企业的产品质量起到显著正向作用 作为稳健性检验，这两种面板门限回归的门限值非常接近(6.851 和6.991) ，与基准回归中估算的 <sup>“</sup>低加成率陷阱<sup>”</sup>临界值6. 93 也较为吻合<sup>①</sup>因此，该检验从<sup>“</sup>质<sup>”</sup>( 条件关系及其作用机理) 和<sup>“</sup>量<sup>”</sup>( 生产率门限值) 对理论部分的命题进行了充分验证<sup>②</sup>

2. 倾向得分匹配( PSM) 为进一步减少内生性对计量结果的影响并验证出口企业加成率与生产率之间存在的条件关系<sup>③</sup>，本文采用 Rosenbaum 和 Rubin(1983) 提出的倾向得分匹配，对不同生产率的出口企业和不出口企业加成率差异进行比较 选取2007 年的截面数据作为样本<sup>④</sup>

基本步骤是: 第一步，区分两组需要匹配的对象 前文的经验结果表明: 当出口企业的生产率大于6.93 时就会跨越 <sup>“</sup>低加成率陷阱<sup>”</sup>，其门槛值经检验较为稳健<sup>①</sup> 据此将出口企业分为低生产率组( $\ln t \ f p \_ l p \leqslant 6 . 9 3 )$ 和高生产率组 $\ln t \ f p \_ l p > 6 . 9 3 )$ 分别与不出口企业进行匹配，寻找两种情境下的 <sup>“</sup>反事实<sup>”</sup>; 第二步，选取影响企业特性的因素②，使用 logit 模型进行回归，得到每个样本的倾向性得分; 第三步，采用最近邻匹配法( Nearest-Neighbor Matching) 对样本进行倾向得分匹配; 第四步，分别计算匹配前和匹配后的低生产率出口( 处理组) 和不出口企业( 控制组) ，以及高生产率出口( 处理组) 和不出口企业( 控制组) 的加成率均值差距<sub>。</sub> 第五步，检验变量的平衡性<sub>。</sub>

## 六 结论与政策含义

本文基于扩展的 M-O 模型，深入研究了企业出口行为对加成率变化的影响及其微观机制，理论部分得到了 4 个关键命题 在现有文献的基础上，提出出口企业加成率与生产率呈现的 <sup>“</sup>U 型<sup>”</sup>曲线关系，进而对出口企业的阶段性低加成率现象做出了理论解释 在此基础上，通过引入扩展的 M-O 模型，论证了企业低加成率出口的可能机制，提出出口企业面临的 <sup>“</sup>竞争加剧效应<sup>”</sup>和 <sup>“</sup>质量升级效应<sup>”</sup> 本文认为低加成率出口企业正是较低生产率水平下 <sup>“</sup>最优出口产品质量选择<sup>”</sup>带来的阶段性现象<sub>。</sub>

在理论分析的基础上，本文还进行了经验研究，得到了下列计量结果: 第一，控制出口行为，企业加成率与生产率成正相关;第二，出口企业产品质量选择与生产率之间存在非线性关系;第三，中国出口企业普遍处于 <sup>“</sup>低加成率陷阱<sup>”</sup>区间，这一点在总体分地区 分行业要素密集度和分所有制的回归中都很显著;第四，出口企业加成率关于生产率的<sup>“</sup>U 型<sup>”</sup>曲线关系得到验证，计量结果显示<sup>“</sup>U 型<sup>”</sup>曲线的门槛值近似为6. 93，约25%的企业已经跨越了 <sup>“</sup>低加成率陷阱<sup>”</sup>区间; 第五，东部企业面临的 <sup>“</sup>质量升级效应<sup>”</sup>更强烈，<sup>“</sup>质量升级<sup>”</sup>意愿较强，中部企业 <sup>“</sup>质量升级<sup>”</sup>意愿居中，西部企业则因为<sup>“</sup>质量升级效应<sup>”</sup>最弱，缺乏 <sup>“</sup>质量升级<sup>”</sup>意愿 第六，一般意义上认为，中国具有比较优势的劳动密集型行业更多地处于 <sup>“</sup>低加成率陷阱<sup>”</sup>，而技术密集型行业负向影响相对较弱;第七，出口行为对港澳台企业 外资企业加成率负向影响最大，本文认为这与部分港澳台企业<sub>、</sub>外资企业<sup>“</sup>低质<sub>、</sub>低价<sub>、</sub>低加成率出口<sup>”</sup>模式有关<sub>。</sub>

内生增长理论指出技术水平提升的关键来源于技术创新( Romer，1990) 因此破解中国企业阶段性 <sup>“</sup>低加成率陷阱<sup>”</sup>的有效路径是: 技术创新→效率增进→质量提升 盈利增加 其基本逻辑是: 技术创新引致生产率提升，更高的生产率水平使企业跨越<sup>“</sup>低加成率陷阱<sup>”</sup>门槛值;当其面临出口市场 <sup>“</sup>竞争加剧效应<sup>”</sup>和 <sup>“</sup>质量升级效应<sup>”</sup>叠加时，选择<sup>“</sup>高质 高价 高加成率<sup>”</sup>的出口模式 对政府而言，一是要鼓励企业的技术创新行为，对技术创新予以奖励和功能性补贴;二是要优化产业政策，积极引导技术密集型的新兴产业出口，改变原有的劳动密集型行业出口过于集中的局面; 三是针对企业存在的空间异质性，要落实<sup>“</sup>中部崛起<sup>”</sup>和<sup>“</sup>西部大开发<sup>”</sup>战略，增强中部和西部企业的质量提升意愿;四是要优化外资引进模式，从战略角度出发引入生产率较高 盈利能力较好的外资企业

由于数据限制本文未能分离出口企业 <sup>“</sup>质量升级效应<sup>”</sup>和 <sup>“</sup>竞争加剧效应<sup>”</sup>的净值<sub>。</sub> 企业在全球价值链中所处的地位也可能影响其加成率( Manova 和 Yu，2012) 这些问题还存在进一步的研究空间，也将是我们后续研究的主要方向
