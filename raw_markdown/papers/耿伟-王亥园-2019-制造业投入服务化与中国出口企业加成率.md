# 制造业投入服务化与中国出口企业加成率

耿 伟 王亥园

摘要: 本文将制造业投入服务化纳入扩展的 M-O 模型，分析了制造业投入服务化对出口企业加成率的影响及其作用机制，制造业投入服务化水平的提高通过促进产品质量升级进而提升出口企业加成率; 在此基础上，本文利用世界投入产出表<sub>、</sub> 中国工业企业数据和海关进出口数据的匹配数据，实证分析了制造业投入服务化对出口企业加成率的影响，证实了本文的理论命题; 回归结果显示制造业投入服务化对于劳动密集型行业<sub>、</sub> 竞争行业<sub>、</sub> 非国有企业<sub>、</sub> 退出企业和持续出口企业的加成率的影响尤为显著; 本文构建中介效应模型，检验了二者的作用机制<sub>。</sub>

关键词: 制造业投入服务化; 出口企业加成率; 产品质量

## 引 言

随着互联网 信息及通讯技术的突破性进步和广泛普及，服务要素投入在制造业活动中占据了越来越重要的地位，全球制造业呈现出由 <sup>“</sup>生产型制造业<sup>”</sup> 向<sup>“</sup>服务型制造业<sup>”</sup> 转型的趋势<sub>。</sub> 制造业服务化一词由 Vandermerwe 和 Rada 于1988<sup>［1］</sup>年最早提出，包括制造业投入服务化和制造业产出服务化，分别指投入和产出活动中服务要素占比不断提升的趋势 制造业服务化是实现制造业提质升级的重要途径，由于服务要素的投入能够使得生产性服务业所内含的知识资本 技术资本和人力资本融合在制造业中，继而提高制造业的全要素生产率，降低生产成本和交易成本，使传统的制造业逐渐向知识技术密集型转变 ( Szalavetz，2003)<sup>［2］</sup>，从而推动制造业提质升级，提升制造业企业的国际竞争力

中国虽为制造业大国，但制造业 <sup>“</sup>大而不强<sup>”</sup>，长期处于全球价值链的低端，出口产品的技术含量和附加值较低，出口产品主要以量取胜，而不是以质取胜( 裴长洪和刘洪愧，2017)<sup>［3］</sup>，为此中国制造业亟需提质升级，获取动态竞争优势

衡量企业动态竞争力的一个重要指标是企业加成率 ( 任曙明和张静，2013)<sup>［4］</sup>，加成率定义为产品价格对边际成本的偏离 由于中国生产性服务业发展相对滞后，制造业中服务要素渗透率较低，出口产品的技术含量和附加值较低，出口企业在面临国际市场的激烈竞争时，只能采取低价竞争策略，盛丹和王永进(2012)<sup>［5］</sup>最早提出了中国出口企业加成率低于非出口企业这一悖论，由此关于中国出口企业加成率影响因素的研究成为国内学者关注的焦点 ( 钱学锋等，2015<sup>［6］</sup>;刘啟仁和黄建忠，2015<sup>［7］</sup>; 祝树金和张鹏辉，2015<sup>［8］</sup>; 黄先海等，2016<sup>［9］</sup>) 本文主要关注制造业投入服务化，即生产活动中服务要素投入的不断增加<sub>。</sub> 在生产过程中，企业除了增强自身的核心服务业务能力外，会将非核心服务业务外包给服务部门，实现优势互补，从而提高生产效率 ( Amiti and Wei，2009)<sup>［10］</sup><sub>。</sub> 那么，制造业投入服务化这一新趋势是否促进了中国出口企业加成率的提升呢? 其影响机制又如何? 对上述问题的深入探究，将有助于我们从加成率的视角考察制造业投入服务化对中国出口企业动态竞争力的影响，为提升中国出口企业整体加成率水平提供有益启示<sub>。</sub>

与本文密切相关的一类文献是关于企业加成率影响因素的文献，在这类文献中，学者们从市场竞争 ( Konings et al. ，2005<sup>［11］</sup>; Tybout，2003<sup>［12］</sup>; Altomonte andBarattieri，2015<sup>［13］</sup>) 政府政策 ( Goldar and Aggarwal，2005<sup>［14］</sup>; Noria，2013<sup>［15］</sup>;Hagemejer and Popowski， 2014<sup>［16］</sup>; De Loecker et al. ， 2016<sup>［17］</sup> ) 企 业 生 产 率( Arkolakis et al. ，2019) <sup>［18］</sup> 目的地市场 ( Melitz and Ottaviano，2008) <sup>［19］</sup>等视角研究了对加成率的影响 此外，也有学者从产品质量角度加以分析，Kugler 和 Ver-hoogen (2012)<sup>［20］</sup>认为企业通过提高产品质量在市场竞争中取得领先优势，进而提升加成率 许明和邓敏 (2016)<sup>［21］</sup>基于中国数据，也得到了类似结论 在此基础上，诸竹君等 (2017)<sup>［22］</sup>的研究显示，产品创新通过质量升级提升了企业加成率<sub>。</sub>

另一类文献是关于制造业投入服务化对企业绩效的影响 具体而言，部分学者考察了制造业投入服务化对企业生产率的影响，Raa 和 Wolff ( 2001)<sup>［23］</sup> Arnold等 ( 2006) <sup>［24］</sup> Wolfmayr ( 2008) <sup>［25］</sup>分别采用美国 非洲和奥地利的数据研究发现中间服务投入促进了企业生产效率的提升; 吕越等 (2017)<sup>［26］</sup>基于中国数据，也指出制造业服务化有利于提高企业的全要素生产率，尤其是在全球价值链中嵌入程度较高的企业 此外，刘斌和王乃嘉 ( 2016)<sup>［27］</sup> 刘斌等 ( 2016)<sup>［28］</sup> 许和连等(2017)<sup>［29］</sup>分别考察了制造业投入服务化对企业出口二元边际 价值链升级和出口国内增加值的影响，其中，刘斌等 ( 2016) 进一步研究发现，制造业投入服务化通过垂直效应 ( 产品质量) 和水平效应 ( 产品技术复杂度) 提升了企业出口产品品质 White 等 ( 1999) <sup>［30］</sup> Robinson 等 ( 2002) <sup>［31］</sup>的研究表明，人力资本 研发等服务要素投入的增加能提升产品质量 尽管目前已有一些文献考察了制造业投入服务化对企业绩效的影响，但鲜有涉及制造业投入服务化对出口企业加成率影响的研究，因此，本文将考察制造业投入服务化对出口企业加成率的影响及其作用机制<sub>。</sub>

本文可能的边际贡献主要体现在以下方面: 第一，从研究视角上，已有文献虽从多个方面考察了企业加成率的影响因素，但鲜有文献涉及到制造业投入服务化这一视角，本文丰富了制造业投入服务化与加成率的相关文献; 第二，本文将制造业投入服务化纳入扩展的 Melitz 和 Ottaviano ( 2008) 的模型 ( 下文简称 M-O 模型) ，揭示了制造业投入服务化对出口企业加成率的影响机理; 第三，本文构建中介效应模型，验证了产品质量升级是制造业投入服务化对中国出口企业加成率的影响渠道，由此加深了对制造业投入服务化与出口企业加成率关系的认识<sub>。</sub>

## 一<sub>、</sub> 理论模型

## ( 一) 消费者

依托 Antoniades ( 2015)<sup>［32］</sup>的研究，本文在 M-O 模型的基础上引入内生质量选择模型<sub>。</sub> 假设本国 ( H) 和外国 ( F) 均生产并消费一种同质性商品和一系列异质性商品，消费者效用函数如下:

$$
\begin{array}{l} U = q _ {0} ^ {c} + \alpha \int_ {i \in \Omega} q _ {i} ^ {c} d i + \alpha \int_ {i \in \Omega} z _ {i} d i - \frac {1}{2} \gamma \int_ {i \in \Omega} \left(q _ {i} ^ {c}\right) ^ {2} d i - \frac {1}{2} \gamma \int_ {i \in \Omega} \left(z _ {i}\right) ^ {2} d i + \\ \gamma \int_ {i \in \Omega} \left(q _ {i} ^ {c} z _ {i}\right) d i - \frac {1}{2} \eta \left(\int_ {i \in \Omega} \left(q _ {i} ^ {c} - \frac {1}{2} z _ {i}\right) d i\right) ^ {2} \end{array}\tag{1}
$$

其中， $\boldsymbol { q } _ { 0 } ^ { c }$ 为同质性商品消费量， $\boldsymbol { q } _ { i } ^ { c }$ 为异质性商品消费量，<sub>α</sub> 和 $\eta$ 代表同质性商品和异质性商品之间的替代弹性， $\gamma$ 则为各异质性商品种类之间的替代弹性，且$\alpha \ : , \ \eta \ : , \ \gamma { > } \ : 0 \ : _ { \circ } \ z _ { i }$ 为产品质量，Ω 是消费产品种类 $\Omega ^ { * }$ 的子集<sub>。</sub>

商品 i 的需求可表示成价格和质量的线性函数 $\textstyle { \left( \ v = H , \ F \right) }$ :

$$
q _ {i} = L ^ {v} q _ {i} ^ {c} = \frac {\alpha L ^ {v}}{\eta N ^ {v} + \gamma} - \frac {L ^ {v}}{\gamma} p _ {i} ^ {v} + L ^ {v} z _ {i} + \frac {\eta N ^ {v}}{\eta N ^ {v} + \gamma} \frac {L ^ {v}}{\gamma} \bar {p} ^ {v} - \frac {1}{2} \frac {\eta N ^ {v} L ^ {v}}{\eta N ^ {v} + \gamma} \bar {z}\tag{2}
$$

其中，N为消费产品种类，L 为一国市场规模， $\bar { p } \setminus \bar { z }$ 分别为平均价格和质量<sub>。</sub>

## ( 二) 生产者

本文将制造业投入服务化水平 $\rho$ 引入企业的成本函数:

$$
T C = q _ {i} c _ {i} + \theta (\rho) z _ {i} ^ {2}\tag{3}
$$

在成本函数中， $\theta \ \left( \rho \right) \ z _ { i } ^ { 2 }$ 为企业产品质量升级所需的成本，θ 为企业产品质量升级难度系数，产品质量升级能力越强，所需成本越小<sub>。</sub> 借鉴 Vandermerwe 和Rada ( 1988) White 等 ( 1999) Robinson 等 ( 2002) 的研究，人力资本 <sub>、</sub> 研发等服务要素投入的增加会引致产品质量升级，由此可得 $\frac { \partial \theta } { \partial \rho } { < } 0$ ，即制造业投入服务化水平越高，其产品质量升级能力越强<sub>。</sub>

企业内销临界成本为 $c ^ { H }$ ，出口临界成本为 $c ^ { F }$ ，出口冰山成本为 $\tau$ ，则出口产品的边际成本为 $\tau { \bf c }$ ，企业在本国和外国市场上的最优价格和产量分别为:

$$
p ^ {H} = \frac {1}{2} (c ^ {H} + c) + \frac {\gamma}{2} z ^ {H}, q ^ {H} = \frac {L ^ {H}}{2 \gamma} (c ^ {H} - c) + \frac {L ^ {H}}{2} z ^ {H}\tag{4a}
$$

$$
p ^ {F} = \frac {\tau}{2} (c ^ {F} + c) + \frac {\gamma}{2} z ^ {F}, q ^ {F} = \frac {L ^ {F}}{2 \gamma} \tau (c ^ {F} - c) + \frac {L ^ {F}}{2} z ^ {F}\tag{4b}
$$

由式 (4a) 式 (4b) 可得，企业在本国市场和外国市场的绝对加成率为:

$$
\mu^ {H} = \frac {1}{2} (c ^ {H} - c) + \frac {\gamma}{2} z ^ {H}, \mu^ {F} = \frac {\tau}{2} (c ^ {F} - c) + \frac {\gamma}{2} z ^ {F}\tag{5}
$$

根据企业利润最大化决策，得到企业最优产品质量为:

$$
z ^ {H} = \lambda^ {H} (c ^ {H} - c), z ^ {F} = \tau \lambda^ {F} (c ^ {F} - c)\tag{6}
$$

其中， $\lambda ^ { ^ H } = { \frac { L ^ { ^ H } } { 4 \theta { \mid } \rho { \mid } \ - \ \gamma L ^ { ^ H } } } , \ \lambda ^ { ^ F } = { \frac { L ^ { ^ F } } { 4 \theta { \mid } \rho { \mid } \ - \ \gamma L ^ { ^ F } } }$ <sub>。</sub> 为保证产品质量 $z ^ { H } , \ z ^ { \mathrm { ~ F ~ } } > 0$ ，假定 $\boldsymbol { \lambda } ^ { H } \cdot \ \boldsymbol { \lambda } ^ { \mathrm { ~ F ~ } } > 0$

设企业出口密集度为<sub>ω</sub>，以<sub>ω</sub> 为权重对出口企业的产品质量和加成率进行加权平均，则企业平均产品质量和平均加成率分别为:

$$
\bar {z} (\rho) = \frac {\omega \tau L ^ {F}}{4 \theta (\rho) - \gamma L ^ {F}} (c ^ {F} - c) + \frac {(1 - \omega) L ^ {H}}{4 \theta (\rho) - \gamma L ^ {H}} (c ^ {H} - c)\tag{7}
$$

$$
\bar {\mu} (\bar {z}) = \frac {\omega \tau}{2} (c ^ {F} - c) + \frac {1 - \omega}{2} (c ^ {H} - c) + \frac {\gamma}{2} \bar {z}\tag{8}
$$

将式 ( 7) <sub>、</sub> 式 ( 8) 分别对 $\rho$ 求导:

$$
\frac {\partial \bar {z}}{\partial \rho} = \frac {\partial \bar {z}}{\partial \theta} \cdot \frac {\partial \theta}{\partial \rho} = \left[ \frac {- 4 \omega \tau L ^ {F} (c ^ {F} - c)}{\left[ 4 \theta (\rho) - \gamma L ^ {F} \right] ^ {2}} + \frac {- 4 (1 - \omega) L ^ {H} (c ^ {H} - c)}{\left[ 4 \theta (\rho) - \gamma L ^ {H} \right] ^ {2}} \right] \cdot \frac {\partial \theta}{\partial \rho} > 0\tag{9}
$$

$$
\frac {\partial \bar {\mu}}{\partial \rho} = \frac {\partial \bar {\mu}}{\partial \bar {z}} \cdot \frac {\partial \bar {z}}{\partial \rho} = \frac {\gamma}{2} \cdot \left[ \frac {- 4 \omega \tau L ^ {F} (c ^ {F} - c)}{[ 4 \theta (\rho) - \gamma L ^ {F} ] ^ {2}} + \frac {- 4 (1 - \omega) L ^ {H} (c ^ {H} - c)}{[ 4 \theta (\rho) - \gamma L ^ {H} ] ^ {2}} \right] \cdot \frac {\partial \theta}{\partial \rho} > 0\tag{10}
$$

由上述推导可见，随着制造业投入服务化水平的上升，企业平均产品质量提高，从而企业加成率得以提升，据此提出本文的理论命题

命题1: 制造业投入服务化能够提升出口企业加成率<sub>。</sub>

命题2: 制造业投入服务化通过产品质量升级效应提升出口企业加成率<sub>。</sub>

## 二<sub>、</sub> 计量模型<sub>、</sub> 变量与数据

## ( 一) 计量模型

为了研究制造业投入服务化对出口企业加成率的影响，参考现有文献，本文建立如下计量模型:

$$
\ln \text { markup } _ {i j t} = \beta_ {0} + \beta_ {1} \ln \text { servitization } _ {j t} + \gamma X _ {i j t} + \lambda_ {i} + \lambda_ {t} + \varepsilon_ {i j t}\tag{11}
$$

其中，下标 i 表示企业，<sub>j</sub> 表示行业，t 表示年份; $\mathrm { l n } m a r k u p _ { i j t }$ 为j 行业中出口企业 i 在第 t 年的加成率，lnservitization 为行业j 在第 t 年的制造业投入服务化水平<sub>。</sub>控制变量为影响出口企业加成率的其他因素，包括出口密集度 中间投入品比重资本密集度 企业规模 企业年龄和补贴 此外，本文还控制了非观测的企业特征λ 和非观测的时间特征 λ <sub>。</sub>

## ( 二) 变量

## 1. 企业加成率 ( markup)

测度企业加成率的方法有两种: 一种是会计法，运用企业的增加值 工资支出和中间投入成本计算加成率 ( Martin，2002<sup>［33］</sup>; Siotis，2003<sup>［34］</sup>; 盛丹和王永进，2012) ; 另一种是生产函数法，其基本思想是在市场均衡分析框架下，通过估计生产函数 需求函数和弹性来测算加成率 ( Edmond et al. ， $2 0 1 5 ^ { [ 3 5 ] }$ <sup>］</sup>; De Loecker andWarzynski，2012<sup>［36］</sup>)

( 1) 会计法 <sub>。</sub> 根据 Domowitz 等 ( 1986) <sup>［37］</sup>的方法，企业产品价格与边际成本的关系式如下:

$$
\frac {p _ {i t} - c _ {i t}}{p _ {i t}} = 1 - \frac {1}{\text {markup} _ {i t}} = \frac {\text {va} _ {i t} - \text {pr} _ {i t}}{\text {va} _ {i t} + \text {ncm} _ {i t}}\tag{12}
$$

其中，下标 i 和 t 分别表示企业和年份，markup 表示加成率，p 为企业生产产品的价格，c 为边际成本，va 为企业工业增加值， $p r$ 为企业当年应付工资总额，ncm为净中间要素投入成本<sub>。</sub> 会计法简单明了<sub>、</sub> 数据易得，能体现行业之间的差异( Siotis，2003) ，且会计法的测算结果不受经济周期和外部冲击的影响 ( 盛丹和王永进，2012) 为了测算结果的稳健性，本文进一步采用生产函数法测算加成率，进行比较和补充

(2) 生产函数法 以生产函数法测算加成率，包括双索洛余值法，Edmond 等( 2015) 的方法，De Loecker 和 Warzynski ( 2012) 的方法 ( 以下简称 DLW 法) ，其中，DLW 法放松了市场结构 需求结构等条件的约束，用企业层面的产出数据直接推导出成本加成率，有效去除了价格或市场需求变动对生产函数的有偏影响<sub>。</sub>本文采用 DLW 法对生产函数进行估计从而计算得到加成率<sub>。</sub>

假设企业 i 在第 t 期的生产函数为:

$$
Q _ {i t} = F \left(X _ {i t} ^ {1}, \dots X _ {i t} ^ {v}, K _ {i t}, \omega_ {i t}\right)\tag{13}
$$

其中， $X _ { i t } ^ { v }$ 表示劳动<sub>、</sub> 原材料等可变要素的投入量， $K _ { i t }$ 表示资本投入， ${ \bf \omega } _ { \omega } \omega _ { \mathrm { i t } }$ 表示企业生产率，生产函数 F ( · ) 连续二阶可微 企业为了在产量既定的情况下追求成本最小化，构建的拉格朗日函数为:

$$
L \left(X _ {i t} ^ {1}, \dots , X _ {i t} ^ {v}, K _ {i t}, \lambda_ {i t}\right) = \sum_ {v = 1} ^ {V} P _ {i t} ^ {X ^ {v}} X _ {i t} ^ {v} + r _ {i t} K _ {i t} + \lambda_ {i t} \left[ Q _ {i t} - F (\cdot) \right]\tag{14}
$$

在式 ( 14) 中， $\boldsymbol { P } _ { i t } ^ { X ^ { v } }$ 和 ${ \bf r } _ { \mathrm { i t } }$ 分别表示可变要素和投资的价格 对可变投入要素进行一阶求导，得到:

$$
\frac {\partial L _ {i t}}{\partial X _ {i t} ^ {v}} = P _ {i t} ^ {X ^ {v}} - \lambda_ {i t} \frac {\partial F (\cdot)}{\partial X _ {i t} ^ {v}} = 0\tag{15}
$$

其中， $\lambda _ { \mathrm { { i t } } } = { \frac { \partial L _ { i t } } { \partial Q _ { i t } } }$ 为给定产出水平下的边际成本，将式 ( 15) 两边同时乘以$X _ { i t } ^ { v } / Q _ { i t }$ ，整理得:

$$
\frac {\partial F (\cdot)}{\partial X _ {i t} ^ {v}} \frac {X _ {i t} ^ {v}}{Q _ {i t}} = \frac {1}{\lambda_ {i t}} \frac {P _ {i t} ^ {X ^ {v}} X _ {i t} ^ {v}}{Q _ {i t}}\tag{16}
$$

其中，等式左边表示可变要素投入 $X _ { i t }$ 的产出弹性，右边表示要素在生产成本中所占份额<sub>。</sub>

定义企业的价格加成为: $\vartheta _ { i t } { = } P _ { i t } / \lambda _ { i t }$ ，将其代到式 (16) 得: $\varphi _ { i t } ^ { X ^ { v } } = \vartheta _ { \mathrm { i t } } \frac { P _ { i t } ^ { X ^ { v } } X _ { i t } ^ { v } } { P _ { i t } ^ { } Q _ { i t } ^ { } }$ 其中， $\varphi _ { \mathrm { i t } } ^ { \mathrm { X v } }$ 为可变要素 $X _ { i t } ^ { v }$ 的产出弹性，可进一步推出加成率公式为:

$$
\vartheta_ {\mathrm{it}} = \varphi_ {\mathrm{it}} ^ {X ^ {v}} \left(\gamma_ {i t} ^ {X ^ {v}}\right) ^ {- 1}\tag{17}
$$

在式 ( 17) 中， $\gamma _ { \mathrm { i t } } ^ { X ^ { v } }$ 为可变要素支出 $P _ { i t } ^ { X ^ { v } } X _ { i t } ^ { v }$ 与企业总销售额 $\mid P _ { i t } Q _ { i t } \mid$ 的比值<sub>。</sub>本文借鉴 Levinsohn 和 Petrin ( 2003) <sup>［38］</sup>的半参数估计方法 ( 简称 LP 法) 计算可变要素产出弹性，并根据式 (17) 计算得到加成率<sub>。</sub>

## 2. 制造业投入服务化

本文参考刘斌等 ( 2016) 吕越等 ( 2017) 许和连等 ( 2017) 的方法，用制造业行业中来自服务业行业的投入占比来表示制造业投入服务化水平，分为直接消耗系数法和完全消耗系数法 直接消耗系数反映了某制造业行业生产单位总产出对各服务行业的直接消耗程度，例如，j 部门生产 $Q _ { j }$ 需要消耗 i 部门的服务数量为$q _ { i j }$ ，则直接消耗系数为:

$$
a _ {i j} = \frac {q _ {i j}}{Q _ {j}}\tag{18}
$$

其中， $a _ { i j }$ 为j 部门对 i 部门的直接消耗系数，直接消耗系数矩阵为:

$$
\mathrm{A} = \left( \begin{array}{c c c} a _ {1 1} & \dots & a _ {1 n} \\ \vdots & \ddots & \vdots \\ a _ {n 1} & \dots & a _ {n n} \end{array} \right)
$$

在生产过程中，各行业之间除了直接消耗，还存在间接消耗 各行业对服务业的直接消耗和间接消耗的总和构成了制造业对服务业的完全消耗<sub>。</sub> 即:

$$
b _ {i j} = a _ {i j} + \sum_ {k = 1} ^ {n} b _ {i k} a _ {k j} = a _ {i j} + \sum_ {k = 1} ^ {n} a _ {i k} a _ {k j} + \sum_ {k = 1} ^ {n} \sum_ {s = 1} ^ {n} b _ {i s} a _ {i k} a _ {k j} = a _ {i j} + \sum_ {k = 1} ^ {n} a _ {i k} a _ {k j} + \dots\tag{19}
$$

用矩阵表示为:

$$
B = A + A ^ {2} + A ^ {3} + \dots + A ^ {k} + \dots = (I - A) ^ {- 1} - I\tag{20}
$$

其中，B 为完全消耗系数矩阵，A 为直接消耗系数矩阵， $A ^ { 2 }$ 为第一轮间接消耗系数矩阵， $A ^ { k }$ 为第k－1 轮间接消耗系数矩阵 后文的回归分析以完全消耗系数为基准，直接消耗系数主要用于稳健性检验<sub>。</sub>

图1 为2007 年中国各制造业行业的投入服务化水平 ( 以完全消耗系数法测算) 从图1 中可以看到，计算机 电子产品和光学产品制造业，汽车 挂车和半挂车制造业，电力设备制造业等技术和资本密集型行业服务化水平较高，而家具及其他制造业，食品 饮料和烟草制造业等劳动密集型行业的服务化水平较低，这在一定程度上解释了中国劳动密集型产品竞争力低下的原因

## 3. 样本选择性偏差

本文的研究对象是出口企业，但企业样本中有一部分是内销企业，忽略这类企业会带来样本选择偏差问题，因此，本文使用 Heckman 两阶段模型来解决样本选择偏差 第一阶段为企业是否出口的选择方程:

$$

## ( 三) 内生性分析

上述回归结果基本稳健，但依然可能受到内生性问题的影响 一方面，加成率高的出口企业为进一步提升产品质量和生产效率，会增加对服务要素的投入，如加大研发力度 广告投入，通过提升人力资本等来提高企业服务要素的投入比重，从而影响到行业的制造业投入服务化水平; 另一方面，尽管已经控制了非观测的企业固定效应和年份固定效应，但依然有可能遗漏一些非观测因素，从而引致内生性问题因此，本文参考刘斌和王乃嘉 (2016) 的方法，选择印度制造业投入服务化和中国制造业投入服务化的滞后1 期作为中国制造业投入服务化的工具变量 工具变量的选取需要满足两个基本条件: 第一，选取的工具变量需要与中国制造业投入服务化水平相关，由于中国经济发展水平与印度类似，且生产性服务业发展借鉴了印度模式，所以印度制造业投入服务化水平与中国制造业投入服务化水平有较强的相关性，产业结构升级具有路径依赖的特点，故制造业投入服务化水平的滞后 1 期会对当期水平有一定的影响 ( 刘斌和王乃嘉，2016) ; 第二，所选取工具变量与随机误差项不相关，印度制造业投入服务化水平和滞后 1 期的中国制造业投入服务化水平均不会直接影响当期的中国出口企业加成率，故本文所选变量符合工具变量的基本要求

## ( 四) 异质性分析

## 1. 区分行业特征

(1) 区分行业要素密集度 根据要素密集度的不同，本文将行业分为劳动密集型行业和非劳动密集型行业，考察制造业投入服务化对这两类行业的影响，结果如表 4 第 ( 1) 列 第 ( 2) 列所示，制造业投入服务化对劳动密集型行业加成率的影响显著为正，而对非劳动密集型行业加成率的影响却不显著 原因可能在于: 相比于非劳动密集型行业，劳动密集型行业的产品生命周期较短，且在产业链中更接近消费者，因此需要更多研发设计 营销以及售后服务等优质服务要素投入 ( 刘斌等，2016) ，故劳动密集型行业的企业加成率对服务要素投入的反应更敏感<sub>。</sub>

( 2) 区分行业竞争程度 参考岳希明等 ( 2010)<sup>［41］</sup>的方法，本文将行业分为垄断行业和竞争行业，考察制造业投入服务化对这两类行业的影响，结果如表4 第 ( 3) 列 第 ( 4) 列所示，制造业投入服务化对竞争行业的加成率有显著正向影响，对垄断行业的影响却不显著 原因可能在于: 竞争行业在激烈的竞争环境下，需要不断增加服务要素投入来提升加成率; 而垄断行业存在企业合谋行政管制等现象 ( 岳希明等，2010) ，从而弱化了市场竞争压力，不利于企业加成率的提高<sub>。</sub>

## 2. 区分企业特征

(1) 区分企业所有制<sub>。</sub> 根据企业所有制类型，本文将企业分为国有企业和非国有企业两大类，结果如表 5 中第 ( 1) 列 第 ( 2) 列所示，制造业投入服务化对非国有企业加成率的促进作用显著，对国有企业的影响却不显著<sub>。</sub> 可能的解释是非国有企业在市场竞争压力下，需要不断增加服务要素投入以提升产品质量，进而促进企业加成率的提高; 而一些国有企业处于行政性垄断行业，或者在其生产经营活动中享受政府补贴或优惠措施，这类国有企业增加服务要素投入的压力和动力不足，不利于加成率的提高

(2) 区分企业出口状态 根据企业出口状态，本文将出口企业样本分为退出新进入和持续出口企业 结果如表5 第 (3) － (5) 列所示，制造业投入服务化水平对持续出口企业和退出企业加成率的影响显著为正，且对退出企业的影响系数较大，而对新进入企业的影响却不显著 这与盛丹和王永进 ( 2012) 提出的我国出口企业低加成率悖论吻合: 一方面，出口退税 补贴造成了市场扭曲，使得出口企业在低加成率的情况下也能获利; 另一方面，因出口企业竞争激烈，且产品差异化程度较低，企业大多采用低价竞争策略，只能收取较低的出口加成率<sub>。</sub> 新进入企业在由内销转向国际市场时，会降低加成率，从而抵消制造业投入服务化的促进作用; 而退出企业在由国际市场转为内销时，会提高加成率，从而扩大制造业投入服务化的效应，且大于其对持续出口企业的影响作用<sub>。</sub>

## 四<sub>、</sub> 机制检验

前文的理论机制分析中，本文提出了制造业投入服务化通过产品质量升级效应提升出口企业加成率这一命题，为验证这一理论命题，本文构建中介效应模型，对可能的传导机制进行检验 结合本文第二部分的分析，引入企业产品质量这一中介变量来构造中介效应模型，探讨制造业投入服务化对加成率的影响渠道 借鉴Baron 和 Kenny ( 1986) <sup>［43］</sup>的方法，本文设定式 ( 23) － 式 ( 25) ，用逐步检验法来检验中介效应:

$$
\ln \text { markup } _ {i j t} = a _ {0} + a _ {1} \ln \text { servitization } _ {j t} + \gamma X _ {i j t} + \lambda_ {i} + \lambda_ {t} + \varepsilon_ {i t}\tag{23}
$$

$$
c q u a l i t y _ {i j t} = b _ {0} + b _ {1} \ln s e r v i t i z a t i o n _ {j t} + \gamma X _ {i j t} + \lambda_ {i} + \lambda_ {t} + \varepsilon_ {i t}\tag{24}
$$

$$
\ln \text { markup } _ {i j t} = c _ {0} + c _ {1} \ln \text { servitization } _ {j t} + c _ {2} \text { equality } _ {i j t} + \gamma X _ {i j t} + \lambda_ {i} + \lambda_ {t} + \varepsilon_ {i t}\tag{25}
$$

其中，下标 $i , j ,$ t 的含义与前文一致， $c q u a l i t y _ { i j t }$ 为企业产品质量，对产品质量的测算参考施炳展 (2013)<sup>［44］</sup>的方法，具体表达式为:

$$
\text { quality } _ {\text { imth }} = \ln \hat {\lambda} _ {\text { imth }} = \frac {\hat {\varepsilon} _ {\text { imth }}}{\delta - 1} = \frac {\ln q _ {\text { imth }} - \ln \hat {q} _ {\text { imth }}}{\delta - 1}\tag{26}
$$

由此得出企业—年份—国家—产品层面的质量<sub>。</sub> 其中，下标 i 表示企业，m 表示出口目的地，t 表示年份，h 表示产品<sub>。</sub> $q u a l i t y _ { i m t h }$ 为企业—国家—年份—产品层面的质量， $q _ { i m t h }$ 为产品出口数量，δ 为需求弹性<sub>。</sub> 此后，本文将计算得出的质量标准化，并将标准化后的产品质量按出口额为权重进行企业—年份层面的加总，得到企业 i 的平均产品质量 cquality <sub>。</sub>

## 五<sub>、</sub> 结论与政策启示

本文将制造业投入服务化纳入到扩展的 M-O 模型中，分析了制造业投入服务化对出口企业加成率的影响及其作用机制，并利用世界投入产出表 中国工业企业数据库和中国海关数据库的匹配数据，证实了本文的理论命题 研究结果表明: 第一，制造业投入服务化有利于提升出口企业加成率，并且制造业投入服务化通过产品质量升级效应对加成率产生正向影响; 第二，制造业投入服务化对劳动密集型行业 竞争行业 非国有企业 退出企业和持续出口企业的加成率的影响尤为显著;第三，制造业投入服务化对出口企业加成率的影响随企业加成率水平的提高而减小; 第四，相对于在岸服务外包，离岸服务外包更能促进中国出口企业加成率的提升<sub>。</sub>

本文的政策启示如下: 一是加快生产性服务业的开放进程，进口竞争效应可以促进国内服务业发展，进而提升制造业投入服务化水平; 二是鼓励并引导企业将非核心服务业务外包，将资源有效配置于核心业务，以不断提升企业竞争力; 三是加大国有企业改革力度，降低准入门槛，促进市场竞争，继而提升制造业投入服务化对企业加成率的促进作用<sub>。</sub>
