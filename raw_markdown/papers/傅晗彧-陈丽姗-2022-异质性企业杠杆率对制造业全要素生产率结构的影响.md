现有文献关于企业杠杆率对整体全要素生产率影响的结论存在争议 有学者从企业异质性视角进一步探讨了异质性企业杠杆率影响整体全要素生产率的差异 在一定程度上解释了相关文献关于企业杠杆率对整体全要素生产率作用的结论不一致的原因 但是少有文献深入探讨异质性企业杠杆率对全要素生产率结构的影响 为推进深化供给侧结构性改革 提高去杠杆的 <sup>“</sup>稳<sup>”</sup>和 <sup>“</sup>准<sup>”</sup>促进全要素生产率提高 从金融化 技术创新水平及外循环等异质性视角 深入系统地研究异质性企业杠杆率如何通过技术效率 前沿技术进步 规模效率和资源配置效率等影响全要素生产率的结构 并利用上市公司数据进行检验 为理论分析提供经验证据 为制定去杠杆以提高制造业全要素生产率的政策提供参考依据

## 二<sub>、</sub>理论分析

杠杆率对全要素生产率及其结构的影响非常复杂 一方面 企业杠杆会影响生产性投资或研发投入 通过影响生产规模或技术水平进而影响全要素生产率 另一方面 企业杠杆会影响企业管理效率 经营成本 经营风险 通过影响效率或资源配置进而影响全要素生产率 同时 金融化 技术创新水平及外循环等方面的异质性 也会影响杠杆率对全要素生产率及其结构的作用 以下主要从两方面分析杠杆率对全要素生产率结构的影响: 一是企业杠杆率对全要素生产率结构的影响二是异质性企业杠杆率对全要素生产率结构的影响<sub>。</sub>

## ( 一) 企业杠杆率对全要素生产率结构的影响

( 1) 企业提高杠杆率可能提升或抑制技术效率 对全要素生产率的影响不确定 一方面 企业提高杠杆率可能提升技术效率 负债压力有效约束管理者不利于企业利益的行为 促使管理层倾向于选择利润回报更稳定的项目 融资增加也意味着成本增加 可以激励代理人努力工作 降低代理成本 提高技术效率<sup>［12］</sup> 另一方面 企业提升杠杆率可能降低技术效率 企业杠杆率上升可能增加企业债务违约的风险 债权人可能高估企业违约概率和违约损失率 进而增加利息或者减少投资 降低企业技术效率 因此 企业增加杠杆对技术效率具有双重效应 对全要素生产率的影响不确定<sub>。</sub>

( 2) 企业提高杠杆率可能促进也可能抑制技术创新 对前沿技术进步及全要素生产率的影响不确定 一方面 企业提高杠杆率可能促进技术创新进而促进前沿技术进步 如融资优序理论认为外部融资可以缓解资金约束 为企业技术创新提供资金支持 促使企业增加研发投入 促进技术进步 企业杠杆率上升传递盈利能力增强的信号 会吸引更多外部投资进入创新领域 促进企业创新<sup>［13］</sup> 同时 这也会增加利息支出 产生避税效应 降低企业实际税负 为企业技术创新提供更多资金支持<sup>［14］</sup> 另外 企业通过金融中介增加杠杆使得其投资受到监督 从而促使资金流向优质的创新项目 因此 企业杠杆率上升可能激励企业技术创新 促进前沿技术进步 提高全要素生产率 另一方面 企业杠杆率上升会抑制技术创新进而阻碍全要素生产率提升 企业债务融资增加利息支出 减少企业利润 降低企业创新动机 同时 企业管理层也会更偏好短周期 资金回收较快的而非周期较长 风险偏高的研发创新项目 因为创新投资面临较高的沉没成本及产出的不确定性 增加杠杆面临还本付息的硬约束会提高企业财务风险 促使企业减少高风险的研发投资 进而抑制企业技术进步 降低全要素生产率<sup>［15</sup> <sup>－</sup> <sup>18］</sup> <sub>。</sub> 由此可以判断 企业增加杠杆对技术创新进而对前沿技术进步的影响不确定 对全要素生产率的影响不确定

( 3) 企业增加杠杆能扩大生产规模 可能产生规模经济 也可能导致规模不经济 对全要素生产率的影响不确定 一方面 企业增加杠杆可能通过实现规模经济来提高全要素生产率 因为提高杠杆率意味着获得更多外部资金 生产性投资增加 生产规模扩大 容易实现规模经济 降低平均成本 提高投入产出率 另一方面 企业杠杆率上升也可能增加管理成本 降低经营效率 导致规模不经济进而抑制全要素生产率提升 由此可以判断 企业提高杠杆率对规模效率进而对全要素生产率的影响也不确定

( 4) 企业增加杠杆可能改善也可能扭曲资源配置 对全要素生产率的影响不确定<sub>。</sub> 企业提高杠杆率可能改善资源配置进而提升全要素生产率 债务融资增加利息支出 减少企业所得税的缴纳金额 降低资本成本 可能提高资源配置效率<sup>［19］</sup> 企业增加杠杆可能扭曲资源配置进而降低全要素生产率 是因为企业杠杆率上升会增加财务成本 提高资本成本 降低资源配置效率 同时 企业增加杠杆可能会导致企业过度投资 扭曲资源配置 企业管理层因为任期约束会放弃效率前景好但成本较高 周期较长的项目 进一步加剧资源配置扭曲 阻碍全要素生产率提升 因此 企业提高杠杆率对资源配置效率进而对全要素生产率的影响不确定

## ( 二) 异质性企业杠杆率对全要素生产率结构的影响

( 1) 金融化的异质性影响企业杠杆率对全要素生产率结构的作用 在一定时期内企业可配置的资本是有限的 提高杠杆则增加可配置的资本实体企业通过外部融资获得的资本可能流向金融领域<sub>。</sub>

一方面 金融化制造企业增加杠杆可能提高技术效率 促进前沿技术进步 改善资源配置效率 促进全要素生产率提升 因为企业增加杠杆将资源配置于金融领域 可以缓解融资约束 利用金融市场的信号传递和风险分散功能 降低企业融资成本 提高经营效率 提升资源配置效率 制造企业金融投资可以发挥储蓄功能 缓解融资约束 从而增加生产投资 创新投入 改进工艺 促进前沿技术进步 塑造长期竞争优势 推动全要素生产率提高

另一方面 金融化企业增加杠杆可能降低技术效率 抑制前沿技术进步 降低规模效率 扭曲资源配置 抑制全要素生产率提升 现代企业治理制度促使管理层以追求股东价值最大化而不是以打造长期竞争优势为目标 任期制促使管理层优先选择周期短 见效快的金融投资项目 以达到任期的考核目标 增加杠杆加大企业偿还债务的压力 也会促使管理层优先选择短期回报率较高的金融投资 中国产业转型中 由于成本优势丧失 关键核心技术受制于人 中低端产能过剩 中高端需求不足 外部需求匮乏 制造企业普遍面临收益下降的困境 资本进入金融领域会减少制造企业固定资产投资和研发投入 削弱制造企业发展的根基 损害其发展能力 导致企业陷入短期利益最大化的困境 具体来说 如果金融化企业会将增加杠杆获得的资本配置到金融领域 将减少主营业务的资源投入 抑制其发展 降低主营业务投入资源的利用效率并最终导致其利润下降 同时 企业金融投资对制造企业固定投资的挤占也会阻碍企业扩大规模 抑制其规模经济 企业金融投资挤占研发 工艺改进投入 也会抑制前沿技术进步 制造企业进行金融投资意味着非主营业务投资比例上升 制造企业的资源配置效率的降低 因此 金融化企业提高杠杆率不利于技术效率 规模经济效率和资源配置效率及前沿技术进步的提高 进而阻碍全要素生产率提升

( 2) 技术创新水平的异质性影响企业杠杆率对全要素生产率结构的作用 企业技术创新需要稳定 充裕的资金支撑 在发展中国家 企业普遍面临融资约束 增加杠杆是制造企业获取外部资金支撑技术创新的重要渠道 可以促进技术创新进而促进前沿技术进步 提升全要素生产率 但是技术创新是高风险 高投入和长周期的活动 增加杠杆进行技术创新意味着风险叠加 可能放大其风险 抑制技术创新和前沿技术进步 一般而言 技术创新水平高的企业 技术创新活动频繁企业需要更稳定 更充裕的资金支撑 增加杠杆可以缓解企业技术创新的资金约束 加大企业技术创新投入的力度 技术创新水平高和杠杆率提高同时传递企业盈利能力强的信号 可以为企业生产和技术创新吸引更充足的资金支持 满足企业创新的持续投入需求 同时 技术创新水平高的企业提高杠杆率产生的税盾效应也会降低企业实际税负水平 可以为技术创新腾挪更多的资金技术创新水平高 意味着技术创新的含量高 收益高 如果增加杠杆有利于加大技术创新投入 企业杠杆率的则更加对前沿技术进步的促进作用也将更大 此外 技术创新水平高的企业增加杠杆意味着更多资源配置到收益较高的项目 从而提高其规模效率与技术效率 因此 技术创新水平高的企业提高杠杆率 可能促进全要素生产率提高

由于技术创新水平高的企业技术创新难度较大 增加杠杆进行技术创新的风险也更高 在技术创新水平高的企业 技术创新投入需要更多资金 提高杠杆率增加融资会给企业带来较高的利息负担 压缩创新资源配置的空间 技术创新和提高杠杆率叠加的风险可能使企业陷入财务困境的风险加大 增加企业破产风险 技术创新和加杠杆叠加的风险促使企业管理层更加关注短期利益 资源配置决策向短期倾斜 如将资源配置到能产生稳定现金流的金融债券投资或房地产等领域 减少实物资本投资和研发投入 更有甚者 压缩原有实物资本投资和技术创新投入的资源 降低企业技术效率 缩减实物资本投资 从而抑制规模经济 减少研发投入 阻碍前沿技术进步 使更多资源向短期投资配置 降低制造企业资源配置效率 最终导致全要素生产率下降

( 3) 外循环影响企业杠杆率对全要素生产率结构的作用 对外开放是我国持续高速增长的关键因素之一 对外开放主要表现为构建大口径外循环 充分利用国际资源和国际市场 其中利用外资和促进出口是外向型发展战略的重心 是反映外循环水平的关键指标<sup>［20］</sup>

外资企业影响企业杠杆率对全要素生产率结构的作用 外资企业和非外资企业 在企业治理水平 技术水平 市场竞争力等方面存在显著差异 提高杠杆率对技术效率 前沿技术进步 规模效率和资源配置效应的影响存在差异 进而对全要素生产率有不同影响 进入中国的外资企业母公司多在发达国家或较为发达的地区 建立了现代企业制度 治理水平高且激励约束机制较为完善 比转型中的本土企业技术效率高 因此 外资企业提高杠杆率能获得更多融资 资金利用效率提高 同时 外资企业技术水平比本地企业高 竞争力强 而且外资进入多是利用中国廉价的资源土地和劳动力等 创新动机不足 因此外资企业提高杠杆率获得外部资金进行技术创新的动机不足 前沿技术进步难以得到提高<sub>。</sub> 进入中国的外资企业多是跨国公司的子公司 增加杠杆获得更多融资 可能扩大生产规模 有利于实现规模经济 由于外资企业技术水平高 盈利能力强 投入产出率高 提高杠杆率获得更多外部资金 意味着更多资源流向了外资企业的优质项目 企业资源配置效率得到提高 因此 外资企业提高杠杆率可能通过技术效率 规模经济和资源配置效率提高全要素生产率

出口企业增加杠杆可能降低技术效率 抑制前沿技术进步和扭曲资源配置 进而阻碍全要素生产率提高 出口退税 补贴可能吸引低效率的企业选择出口 降低资源配置效率 因为加工贸易是订单贸易 存在逆 <sup>“</sup>自我选择<sup>”</sup>效应<sup>［21</sup> <sup>－</sup> <sup>22］</sup> 参与的企业由于技术水平不高 竞争力弱 效率低而选择加工贸易 全要素生产率普遍偏低 出口退税 出口补贴等政策可能进一步扩大加工贸易的逆 <sup>“</sup>选择效应<sup>”</sup> 使得大量低效率企业放弃国内市场从事加工贸易出口才能生存<sup>［23</sup> <sup>－</sup> <sup>24］</sup> 因此出口贸易特别是加工贸易会降低全要素生产率 由此可以推断 出口退税 出口补贴会吸引技术水平低缺乏竞争力的企业选择出口 企业增加杠杆则获得更多资金 扩大出口规模意味着更多资金配置到国际贸易领域 虽然可能扩大分工效应 产生规模经济 但是也会导致更多资源进入低效率的出口企业 促使加工贸易企业扩大生产规模<sup>［25</sup> <sup>－</sup> <sup>26］</sup>低效率企业过度投资 进一步降低技术效率 出口企业增加杠杆 意味着更多资金流向不具有关键核心技术的企业 不利于前沿技术进步增长同时更多资金进入低效率的出口贸易领域 也会加剧资源配置扭曲效应 综上所述 出口贸易提高杠杆率降低技术效率 抑制前沿技术进步和扭曲资源配置 可能抵消规模经济的正效应 抑制全要素生产率提升

## ( 一) 结论

提高杠杆率没有显著影响企业全要素生产率增长及技术效率和资源配置效率 但显著抑制前沿技术进步和规模效率提高 更换控制变量 杠杆率测度 变换样本和选取工具变量得到一致估计结果 进一步检验企业异质性影响杠杆率对全要素生产率增长及其结构的作用发现: 创新水平高的企业增加杠杆显著提高全要素生产率 出口企业提高杠杆率显著抑制全要素生产率提升 其他情况不显著 企业异质性没有改变提高杠杆率对前沿技术进步抑制作用的性质 金融化企业 创新水平高的企业 外资企业及非出口企业分别相对非外资企业 非金融化企业 创新水平低的企业及出口企业 提高杠杆率抑制前沿技术进步的作用更大 外资企业提高杠杆率显著降低技术效率 其他情况均不显著 外资企业 创新水平高的企业分别相对于非外资企业 创新水平低的企业提高杠杆率促进规模效率的作用更大 非金融化企业和非出口企业提高杠杆率显著提升规模效率 金融化企业和出口企业提高杠杆则没有显著影响<sub>;</sub> 金融化企业和出口企业提高杠杆显著降低资源配置效率 其他情况不显著

## ( 二) 启示

第一 依靠增加杠杆不能促进制造业前沿技术进步 随着中国成为制造大国 制造业技术实现全面进步 虽然多数技术仍在 <sup>“</sup>跟跑<sup>”</sup> 但是也有相当一部分技术已实现世界 <sup>“</sup>并跑<sup>”</sup>和 <sup>“</sup>领跑<sup>”</sup> 制造业技术无论要实现由 <sup>“</sup>跟跑<sup>”</sup> 到 <sup>“</sup>并跑<sup>”</sup> 和 <sup>“</sup>领跑<sup>”</sup> 还是持续保持 <sup>“</sup>并跑<sup>”</sup>和 <sup>“</sup>领跑<sup>”</sup> 都必须加大技术创新力度 经历依靠技术引进 技术模仿促进技术进步阶段后 进入自主创新特别是科技自立自强阶段 技术创新难度 创新风险 投入规模巨大 收益高 外部性大 企业仅通过负债难以实现技术突破 必须发挥政府的作用 持续加大基础研究投入 积极推进重大科技创新平台建设 强化国家战略科技力量 加大原创性引领性科技攻关的力度<sub>。</sub>

第二 结合企业异质性 权衡增加杠杆抑制前沿技术进步与提升规模效率的关系 无论哪类企业增加杠杆都会抑制前沿技术进步 而非金融化企业 技术创新水平高的企业 外资企业及非出口企业增加杠杆获得资金后主要用于扩大生产规模 可以提高规模效率

第三 结合企业异质性调杠杆 如金融化企业降杠杆可以矫正资源配置扭曲 改善资源配置效率 出口企业降杠杆可以提高技术效率和资源配置效率 进而提高全要素生产率
