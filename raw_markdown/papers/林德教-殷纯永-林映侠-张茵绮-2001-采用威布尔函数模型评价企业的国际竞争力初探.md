# 采用威布尔函数模型评价企业的国际竞争力初探

## 一、前言：

企业作为直接运行于市场中的基本细胞 是一个国家国际竞争力表现的载体 提高企业的国际竞争力是我国综合国力增强的前提，随着加入WTO的日益临近，我国企业所面临的社会经济环境发生了巨大变化，其显著特征是，经济全球化竞争日趋激烈：技术进步使设备的经济寿命进一步缩短：生态环境恶化和资源短缺程度越来越严重；企业所承担的社会责任加强等等不一而足，总之，企业将面临着前所未有的严峻形势和激烈挑战所以，有效地评价企业竞争力已成为近年来各国普遍重视的研究课题早在1985年“世界经济论坛 中 关于竞争力的报告 就已指出 国际竞争力是企业目前和未来在各自的环境中 以比他们国内和国外的竞争者更有吸引力的价格和质量进行设计，生产并销售货物以及提供服务的能力和机会。

我国的学者在评价企业竞争力方面也做过大量的研究 并取得了初步成果 但是至今仍缺少一个定量的表达方法 这种状况和广泛采用数字技术和工具的现实不相适应 鉴于此 本文试图从影响企业竞争力的各相关因素出发 根据 系统性 可行性 通用性 原则 建议采用威布尔 函数作为评价企业竞争力的数学模型

## 二 建立评价企业国际竞争力的数学模型

由产品的生命周期理论可知 产品从其市场调查 研发 推上市场直至最后退出市场所经历的整个生命周期可分为 萌芽期 成长期 成熟期和衰退期 这一过程可以用威布尔函数描述为

$$
\mathrm{f} (\mathrm{t}) = \mathrm{k} \cdot \lambda^ {2} \mathrm{t} \cdot \exp (- \mathrm{p} \cdot (\lambda \mathrm{t}) ^ {2})\tag{1}
$$

其中 为时间 表示企业在 时刻的竞争力 为待定参数 和 是一系列与影响企业竞争力的各个因素有关的可变参数加权 详见下文分析

假设取 $\mathrm { k } ^ { \tharpoondown }$ 和 $\scriptstyle \lambda = 1 , \mathbf { p } ^ { = 1 }$ 则对应的函数曲线如图 所示

由图 可以看出 函数值 经过萌芽期 成长期之后 在成熟期的某个时间点上取得最大值 此时对应的产品竞争力最强 之后由于竞争者的引入以及产品的更新换代等原因 其竞争力就开始走下坡路由式 对 求导并令导数值 $\mathrm { f ^ { 1 } ( t ) } = \mathrm { 0 }$ 可得 达到极值的时间 为

$$
\mathrm{t} = 1 / (\sqrt {2 \mathrm{p}} \lambda)\tag{2}
$$

对于信息类产品 不同类型产品会有所区别 根据摩尔定律知其平均更新速度为 个月 即取 $_ \mathrm { t } = 1 . 5$ 年 同时假定 $\lambda = 1$ 则可得待定参数 $\mathrm { p } ^ { = 1 / 4 . 5 } \circ$ 于是 式可化为

$$
_ {\mathrm{t}} = 1. 5 / \lambda\tag{3}
$$

此时 竞争力评价函数达到极值

$$
\mathrm{f(t)} _ {\mathrm{m}} = 0. 9 \mathrm{k} \lambda\tag{4}
$$

由此可以看出 企业产品的最强竞争力 $\mathbf { f } \left( \mathbf { t } \right) _ { \mathrm { m } }$ 分别与参数 成正比 而其中参数 同时决定了企业竞争力达到最大值所用的时间 值越大 达极值的时间越短 这表明在当前国内外激烈的市场竞争环境中，只有快速推向市场的产品才能具有强劲的竞争力，同时，随着现代企业产品科技含量的升值，更新换代周期的逐渐缩短 只有不断的加强技术创新 才能保证企业在市场中强有力的竞争优势

## 三 企业竞争力影响因素及其与威布尔函数参数 的关系

首先 市场 需求是第一位的 近几年随着经济的发展 市场已由卖方市场转向买方市场并呈多元化发展的趋势 企业经营理念必须以顾客为中心 以市场为导向 这是评价企业市场竞争力的前提铱星 的失败就是过高估计市场需求而导致了耗资 亿美元却最终破产的恶果 所以产品的开发必须面向市场

这里以 $\mathbf { k _ { M } }$ 表示市场需求与市场占有率 它与威布尔函数中的参数 正相关 表示为

$$
k _ {M} = \sum_ {i = 1} ^ {n} r _ {i} M _ {i}
$$

其中 $\mathbf { \sigma } _ { \mathbf { r } _ { \mathrm { { i } } } , \mathbf { M } _ { \mathrm { { i } } } }$ 分别为第 种产品的市场需求强度和市场占有率

其次考虑影响产品的基本四要素：T（Time时间）、Q（Quality质量）、S（服务Service）、C（成本Cost）分别阐述如下

通常指的是新产品的开发时间 上市时间和产品的交货时间 甚至产品的整个生命周期 现代制造中常用的准时制生产 敏捷制造 柔性生产等 都是与 密切相关的 这就要求企业具备快速的产品开发能力 生产能力和应变能力等

指产品本身的性能 外观 可靠性 使用寿命和人体工程学特征等方面的要求 是否满足人们的实际需要，是否达到国内国际领先水平

售前咨询 售后维护和升级升值服务 贯穿企业整个生命周期都应具有强烈的服务意识和令顾客满意的服务水平

除制造 销售成本 隐含劳动力成本 外 还应包括研发成本 运行成本 维护成本及报废后的处理成本在内的全成本不同产品其成本构成会有所不同。

分析以上诸要素对企业竞争力的影响及与威布尔函数参数 的关系 分别记作 $\lambda _ { \mathrm { { T } } } , \mathbf { k } _ { 0 } , \mathbf { k } _ { \mathrm { { S } } }$ 和 $\mathrm { k _ { C } } .$ 。其参数值主要根据本企业与国内外同类企业，即竞争对手的差异比较来获得，计算过程可以描述为，

$$
\lambda_ {\mathrm{T}} = \frac {\text {本企业从产品开发到上市所用时间}}{\text {同类产品推上市场所用平均时间}}
$$

$$
\mathrm{k} _ {\mathrm{Q}} = \text {企业内各种产品的成品率} \times (1 - \text {保修期内的维修率})
$$

$$
\mathrm {k_ {S}} = \frac {\text { 配套服务人员 }}{\text { 企业总人数 }} \times \text { 顾客满意度 }
$$

$$
\mathrm{k} _ {\mathrm{C}} = \frac {\text {销售价格}}{\text {生产全成本}} \times \frac {\text {本企业员工平均工资}}{\text {同行业员工平均工资}}
$$

除了以上四个基本要素外 在市场经济运行模式下对评价企业竞争力 我们还必须充分衡量企业的科研开发 $\mathbf { \Gamma } ( \mathbf { R } ^ { \& } \mathbf { D } )$ 能力 生产规模 市场定位和营销网络的构建 财务管理 企业领导层的管理水平等内部条件 以及新竞争对手的进入 供应商的还价能力 代理商和购买者的讨价能力 替代产品的威胁等外部环境 做到知己知彼

对这些因素的影响作以下具体分析

企业的 $\mathtt { R } ^ { \mathrm { \& } _ { \mathrm { D } } }$ 水平 $\lambda _ { \mathrm { R } }$ 包括企业研发人员比例 资金投入 拥有的专利技术等 我国企业普遍存在的问题是：自主知识产权少，据2000年《洛桑报告》统计结果，我国平均每家企业一年申请的专利只有0.28项在科研的经费投入方面明显不足 年我国科研开发投入仅占整个 的 人才严重短缺 合格工程师的可获得程度 与 合格信息技术人员可获得程度 项指标分别排倒数第 位 可见这是影响我国企业竞争力的重要因素

$$
\lambda_ {\mathrm{R}} = \frac {\text {本企业研发人员比例}}{\text {同行业研发人员比例}} \times \frac {\text {本企业科研经费投入}}{\text {同行业平均科研经费投入}} \times \frac {\text {本年度企业拥有的专利数}}{\text {本年度同行业平均专利数}}
$$

生产规模效应 $\operatorname { K s c } :$ 企业的生产规模越大 通常产品的平均成本就越低 我国企业之所以在 世界强 中只有寥寥数个 一大原因就是我国大多数企业的规模都比较小 比如汽车行业 国内大大小小的汽车厂商不下 家 但产值加起来总和还不抵美国通用汽车公司的 让 家小而全的汽车厂互相恶性竞争，不如形成各有特色的配套体系，并实施联合兼并，“捆绑式”战略，实现优势互补，以提高企业全员劳动生产率水平和品牌知名度，从而增强我国企业的总体竞争力，

$$
\mathrm{k} _ {\mathrm{SC}} = \frac {\text {企业每年生产总额}}{\text {全国(国际)该行业产品生产总量/该行业总企业数}}
$$

市场营销网络 $\mathbf { k } _ { \mathrm { { N } } } { \mathrm { { ; } } }$ 每个企业根据自身的生产能力和优势 拥有特定的目标市场 在该市场范围内能否构建起有效的市场营销体系，是关系到企业生产出来的产品是畅销，或是滞销的关键问题，在全球经济一体化的今天 我们不但要立足于国内市场 更要把目光投放到国际市场 争取将自己的产品打出国门 在激烈的国际竞争中占有一席之地 所以 市场营销网络的确立必须瞄准国内外

$$
\mathrm{k} _ {\mathrm{N}} = \frac {\text {本企业年广告投入占销售总额比例}}{\text {该行业年平均广告投入占销售总额比例}} \times \text {销售区域覆盖面}
$$

财务管理 $\mathrm { k _ { F } }$ 财务是企业管理中的有效杠杆 也是企业是否盈利的体现之一 资产负债率 资产利用率 资产运营效率等指标反映了企业的财务状况水平 如果在财务管理方面出现漏洞 则企业的盈利水平就会大打折扣

$$
\mathrm{k} _ {\mathrm{F}} = \text { 资金周转率 } \times \text { 财务人员专业化水准 }
$$

企业家素质 $\mathrm { k _ { E } } :$ 国际竞争归根结底是人才的竞争 除了上文所提到的企业急需一大批具有强烈创新意识的研究开发人员 一支精干的市场营销队伍外 企业是否拥有具备战略眼光 能够居安思危 又善于组织指挥 协调各种矛盾的领导者 是企业能否朝着正确前进方向发展的决定性条件 具有风险意识 创新和国际经营经验的企业家短缺，已经成为制约我国企业竞争力提高的关键因素之一

$$
\mathrm{k} _ {\mathrm{E}} = \text {企业家学历权重} \times (\text {决策能力} + \text {组织能力} + \text {协调能力})
$$

再来分析企业外部因素的影响

潜在竞争对手的进入 $\mathbf { k } _ { \mathrm { G P } }$ ，在任何有利可图的行业中，都会或多或少的迎来新的竞争对手，他们总想通过新的生产能力或资源在市场上赢得一定的份额 这对已处于该行业的企业是一种威胁 所以对进入同行业市场的竞争对手必须作认真分析 新竞争对手在市场中能否形成经济规模和成本优势 对手在初始阶段是否有足够的财力进行大量的投资 客观社会条件是否允许新的竞争对手顺利进入市场

$$
\mathrm{k} _ {\mathrm{CP}} = 1 - \text {新竞争对手进入的概率}
$$

供应商的讨价能力 $\mathrm { k } _ { \mathrm { P } }$ 供应商主要通过提高产品价格或降低产品质量来影响企业并从企业中瓜分利润 如果供应商所处的行业被少数几家企业所垄断 但买家却很多 或者供应商的商品具有特殊性和唯一性 尚无可替代产品 或者供应商本身就是具备将原材料加工成产品的潜在竞争对手 那么 这种供应商的还价能力就很强

$$
\mathrm{k} _ {\mathrm{p}} = \frac {\text {供应商产品的可取代性}}{\text {原材料的生产难度}}
$$

代理商和购买者的还价能力 $\mathbf { k } _ { \mathrm { B } }$ 苛刻的购买者总要求企业降低价格 提高产品质量和完善服务 这些购买者很可能是大主顾 一旦不继续购买就可能造成产品积压 企业资金周转困难 如果生产的产品是通用的，标准的，在市场上能找到其他供应商，则购买者就可能把价格还到最低，所以，一方面企业需要提出产品的差异化战略 另一方面企业则必须不断地开拓市场 切不可挤在一条跑道上

$$
\mathrm {k_ {B}} = \frac {\text {购买者数量与发散性}}{\text {产品的通用性}}
$$

替代产品的威胁 $\mathbf { k } _ { \mathrm { R P } }$ 替代品通常是伴随着新技术的发展而出现 往往具有更优越的性能或更低廉的成本 甚至二者兼而有之 这对使用传统技术生产的企业来说 是一个很大的威胁 对付替代产品威胁的办法是 对自己原有的产品不断更新 掌握主动权

$$
\mathrm {k_ {RP}} = \frac {\text {本产品的性能价格比}}{\text {可替代产品的性能价格比}}
$$

上文主要分析了以企业为基本单位的微观环境，而良好的宏观环境也是促使企业竞争力增强的“催化剂”正如哈佛大学商学院著名的战略管理专家迈克尔·波特(M·Porter)教授所指出的.“一国经济发展及竞争力水平取决于宏 微观环境 对每个个体企业来说更是如此 宏观环境主要包括自然资源 政府政策社会文化 传统习俗等 这需要企业很好地去把握 一方面企业要注意整个国民经济的发展状况对企业的影响 另一方面则要注意经济周期律对企业的影响 在低谷即将走出时投资 在高峰时投产收获 另外 要注意宏观调控手段变化对企业的影响，包括财政手段和税收影响等，记企业对市场宏观环境的把握能力为 $\mathrm { k _ { M C } }$

在地球上资源日趋紧张的今天 相当多的企业在生产经营中还必须考虑到环境保护问题 如果企业生产的产品对大气水等环境资源造成严重污染且无法有效抑制难以挽回的话，则该产品会将很快被取缔 记 $\mathbf { k } _ { \mathrm { E V } }$ 为企业对环境造成的影响

综上所述 我们可以看出 与企业竞争力评价相关的因素很多 但对于不同的企业 各影响因素的作用效果却不完全相同 每个企业应根据自身的情况 抓住主要矛盾解决最迫切的问题

## 四、结论：

2000年瑞士洛桑管理学院所作的《国际竞争力报告》指出：我国国际竞争力在47个参评国中总排名31位 其中科技竞争力排名 位 事实上 自 年开始我国参加评比以来 我国的国际竞争力排名始终徘徊在 位左右

所以 如何增强企业竞争力 这是人们普遍关心的一个重大问题 本文分析了影响企业竞争力的内外部因素 提出了基于威布尔函数描述的数学模型 为评价企业竞争力提供了一定的依据和借鉴 诚然 这还只是定量评价企业竞争力的一种探索 期望以此抛砖引玉 引发人们对此予以更多的关注

对于企业竞争力的提高 概括起来主要有两点 一是要立足和改善内部条件 瞄准市场 切实加强管理和加快科技开发力度 全面提高企业综合能力 二是要分析和适应外部环境 善于与外界打交道 增强应付外部环境变化的应变能力等，抓住机遇，迎接挑战。
