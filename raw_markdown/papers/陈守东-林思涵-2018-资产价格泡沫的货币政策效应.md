# 资产价格泡沫的货币政策效应

陈守东<sup>1</sup><sub>，</sub> 林思涵<sup>2</sup>

（1．吉林大学 数量经济研究中心 吉林 长春 130012<sub>；</sub>2．吉林大学 商学院 吉林 长春 130012）

［摘 要］ 在局部均衡框架下 结合资产价格泡沫理论将资产价格分解为基础价值成分和泡沫成分 以理论分析证明利率的变化对基础价值成分和泡沫成分具有不同影响 实证分析中通过理论推导构建了TVPSVVAR模型 用以分析外生的紧缩性货币政策冲击对资产价格的两个成分以及其他内生变量的冲击影响 结果表明 外生的紧缩性货币政策冲击能够引起资产价格的短暂下跌 其长期趋势仍为上升 但上升幅度较小<sub>；</sub>相比于基础价值成分的下跌 泡沫成分的上升更为显著 利用紧缩性政策处理资产价格泡沫不但无法达到抑制泡沫的作用反而会损害股票的基础价值 因此传统的<sup>“</sup>逆向操作<sup>”</sup>策略对资产价格泡沫的作用收效甚微 在资产价格泡沫治理方面应重视宏观审慎监管的作用<sub>，</sub>谨慎使用货币政策工具

## 一<sub>、</sub>研究背景

作为引发系统性金融风险的重要因素 资产价格泡沫的剧烈波动会影响金融体系的稳定 资产价格泡沫会导致资本配置不当 使得资本市场无法有效服务于实体经济 泡沫成分驱动的资产价格上涨会威胁金融稳定甚至引发金融风险 资产价格泡沫破裂所引发的金融危机会导致宏观经济的衰退 因此 市场非常关注资产价格泡沫治理问题 然而 该如何应对资产价格泡沫 目前还没有达成共识 货币政策往往被认为可以对资产价格产生重要影响<sup>［1</sup>－<sup>2］</sup> 由于资产价格泡沫无法精准度量以及使用货币政策来调控资产价格泡沫产生的巨大经济成本 因此货币政策仅对通货膨胀和产出缺口做出反应即可 资产价格泡沫可以与其结合到同一框架下而得到有效规避<sup>［3</sup>－<sup>4］</sup> 但2008年金融危机的发生使得这一观点被推翻 美国在低通胀率的情况下 金融体系产生了巨大的资产价格泡沫<sup>［5］</sup>因此是否应该将资产价格泡沫加入货币政策调控目标引起广泛争议 该争议主要围绕两个问题展开 一是扩张的货币政策是否有助于推动资产价格泡沫 紧缩性货币政策是否能够抑制资产价格泡沫 二是在处置资产价格泡沫方面 是否应该过度依赖货币政策进行宏观调控

2008年金融危机 美国金融体系资产价格泡沫的破裂对美国以及世界其他国家的实体经济都造成了剧烈冲击 伯南克（Bernanke）等<sup>［3］</sup>传统观点的支持者再一次反思了资产价格 货币政策与实体经济的关联机制 逆向操作策略再一次成为制定货币政策的主流观点 逆向操作的思想最早产生于劳式（Lowe）等<sup>［6</sup>－<sup>7］</sup> 的系列研究成果 他们提出货币政策应先发制人地对资产价格和金融稳定指标做出反应 通过紧缩性货币政策来抑制过热的投机行为 因此在危机之后 出现了一系列针对逆向操作的必要性的研究成果 如伊辛（Issing）<sup>［8］</sup>认为 虽然针对资产价格波动的货币政策会导致实际产出偏离目标产出 但这种损失可以被政策缓解危机的潜在收益所覆盖 艾伦 （Allen） 等<sup>［9</sup>－<sup>10］</sup> 提出了扩张性货币政策将通过信贷渠道来滋养泡沫 蒙塔兹（Mumtaz）等<sup>［11</sup>－<sup>12］</sup> 认为扩张性的货币政策有助于滋生资产价格泡沫 扩张的货币政策被认为是推动资产价格泡沫破裂的主要原因 而紧缩性货币政策可以抑制资产价格泡沫 昂格雷尔（Ungerer）<sup>［13］</sup> 的实证研究表明 通过信用扩张和高杠杆驱动的资产价格泡沫会在泡沫破裂后对实体经济带来更为严重的负面冲击 因此要通过紧缩性货币政策来抑制信贷扩张和杠杆推升

此次金融危机之后 在常规货币政策有效性不足的情况下 各国央行都不同程度地实施了一系列的非常规的扩张性货币政策 对金融稳定造成了潜在不利影响 其中一个重要的事实就是资产价格泡沫化问题越来越严重<sup>［14］</sup> 在理论研究中 关于扩张的货币政策可以推动资产价格泡沫滋生的观点是一致的 但关于紧缩性货币政策可以抑制资产价格泡沫是存在争议的 耶伦（Yellen）<sup>［15］</sup>研究表明货币政策的变化与资产价格波动之间的关系可能与<sup>“</sup>逆向操作<sup>”</sup>支持者的简单想象存在很大差异 加利（Galí）<sup>［16］</sup>说明了理性资产价格泡沫与货币政策的关联机制 由于名义刚性的存在央行通过影响实际利率实施紧缩性货币政策会增加泡沫规模 加利（Galí）等<sup>［17］</sup> 通过实证分析得到 外生的货币政策冲击确实会导致资产价格的短暂下跌 但长期呈现上升趋势 邓创等<sup>［18</sup>－<sup>19］</sup> 的实证结果表明 针对资产价格波动的货币政策具有较强的不确定性 货币政策的操作结果并不能令人满意 陈守东等<sup>［20］</sup> 在对<sup>“</sup>价格之谜<sup>”</sup>的讨论中 揭示了货币政策的低效性 并强调货币政策的精细化调控 另一类与其对应的研究结果表明 使用紧缩性货币政策来处理泡沫和金融稳定问题存在很大弊端 应依赖宏观审慎工具<sup>［21</sup>－<sup>23］</sup>

对于资产价格泡沫的预防和处理目前依旧没有形成共识 资产价格泡沫的<sup>“</sup>逆向操作<sup>”</sup>框架缺乏充足的理论依据和实证支持 以上部分研究成果在一定程度上给出了<sup>“</sup>逆向操作<sup>”</sup>可行性的理由 多数研究结论关于扩张性货币政策会滋生资产价格泡沫的结论是统一的 但关于紧缩性货币政策能够抑制资产价格泡沫并未给出统一的观点和结论 本文在现有研究的基础上 从理性资产价格泡沫理论出发 采用带有随机波动率的时变系数向量自回归 <sub>（</sub>TimeVaringStructure

## 四<sub>、</sub>结论与启示

本文在局部均衡框架下给出了一个用以分析货币政策与资产价格 资产价格泡沫成分以及基础价值成分的理论框架 通过这个理论框架我们认为紧缩性货币政策会引起资产价格泡沫成分的上升 为证明该理论观点 本文通过 TVPSVVAR模型来进行实证检验 收集了GDP当季同比数据 GDP平减指数不变价同比数据 CPI同比数据以及银行间7天同业拆借利率数据 沪深两市全部A股流通股本加权股利数据与流通股本加权股价数据构建自回归向量 通过等间隔脉冲响应与整个样本区间内的等时点脉冲响应分析了紧缩性货币政策对实际GDP 通货膨胀 实际股利 短期名义利率 股票价格 基础价值以及泡沫成分的冲击影响 得到以下研究结论

持续时间最长 其次是基础价值成分 泡沫成分与利率 最后是通货膨胀 股价与股利 由于货币政策对资产价格泡沫成分与基础价值成分的影响较强 持续性较长 因此要谨慎使用货币政策工具来治理资产价格泡沫

为排除扰动项随机波动的差异所引起的结构性差异 我们给出6个内生变量的随机波动率后验均值和一倍标准差估计结果 如图4所示 在2007年第3季度之前GDP的随机波动率的后验均值较大 此后下降到0．5以下并持续呈现下降趋势 究其原因 近年来伴随着我国经济进入新常态 经济增长放缓并持续在较为稳定的水平导致 GDP波动率呈现下降趋势 与GDP的波动率趋势不同 股利 GDP平减指数 CPI利率 股票价格的随机波动率均持续在较为稳定的水平 利率和通货膨胀的随机波动率维持在较低水平且股利和股票价格的随机波动率持续在极低水平 因此我们可以排除扰动项波动率对于模型结构的干扰

第一 针对通货膨胀和GDP两个传统货币政策目标的<sup>“</sup>逆向操作<sup>”</sup>策略确实可以达到其预期效果 即紧缩性货币政策可以有效抑制通货膨胀 并在调节通货膨胀的同时抑制经济增长 货币政策调控效果虽然具有一定时滞特征 但伴随着我国经济 金融的发展 时滞效应在明显减弱 针对传统货币政策目标 货币政策有效性显著上升

第二 紧缩性货币政策的实施会引起通货膨胀水平的显著下跌 但却仅引起部分股票价格的短暂下跌股票价格长期仍呈现上升趋势 相比于对通货膨胀水平较为确定的定向调控 货币政策对资产价格的调控具有明显的不确定性 紧缩性货币政策无法有效抑制股票价格的持续上升 因此 当股市过热时 应谨慎使用紧缩性货币政策 以避免出现政策不确定冲击影响与市场效应叠加风险 威胁资本市场稳定

第三 紧缩性货币政策无法达到有效抑制股价泡沫的作用 相比于股票基础价值的下跌 股票泡沫成分的上升更为显著 并且引起泡沫成分上升的主要原因是利率变动而引起的通胀幻觉效应 紧缩性货币政策的实施对上市公司的基础价值具有显著作用 上市公司基础价值的显著下跌导致上市公司价值缩水 不利于上市公司的长期健康发展 这主要由我国资产市场的噪声交易以及情绪因素所致 使得货币政策无法实现平滑传导

针对以上研究结论我们获得如下启示 首先 就目前我国实际状况 资本市场的发展不够健全 针对资产价格的<sup>“</sup>逆向操作<sup>”</sup>策略在施行过程中具有较强的不确定性 将资产价格稳定与其他货币政策目标 尤其是通过膨胀目标统一到同一框架进行讨论存在理论上以及实践上的难度 因此是否将金融稳定加入到货币政策目标有待进一步商榷 其次 根据我们的分析结果货币政策对上市公司的基础价值具有显著影响 紧缩的货币政策会造成基础价值成分的大幅度下跌 在流动性紧张时期 扩张的货币政策则能够显著提升上市公司的基础价值成分 进而通过基础价值上升引起的<sup>“</sup>托宾 $\mathrm { \Delta } { \mathrm { Q } } ^ { \prime \prime }$ 效应有效提振上市公司投资需求 缓解上市公司的流动性压力 最后 由于通胀幻觉的存在 紧缩性货币政策引起了资产价格泡沫成分的显著上升 因此在金融稳定 资产价格泡沫的治理方面 相比于货币政策工具的不确定性调控 政策制定者应侧重宏观审慎监管方面的作用 在资产价格泡沫出现异常膨胀的初始 即通过严谨的 全面的 多层次的审慎监管来进行有效的事前压制 避免资产价格的泡沫成分进一步扩张
