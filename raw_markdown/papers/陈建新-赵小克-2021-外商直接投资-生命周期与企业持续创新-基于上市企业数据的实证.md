# 外商直接投资、生命周期与企业持续创新基于上市企业数据的实证

陈建新<sup>1</sup> 副教授 赵小克 <sup>2</sup> 博士后

（1、常州机电职业技术学院 江苏常州 213164；2、常州大学 江苏常州 213164）

内容摘要：本文基于企业对持续创新日趋重视的背景下，利用 2007-2018 年我国 A 股上市企业的面板数据，实证分析了外商直接投资对企业持续性创新的影响，并同时考虑这种影响在不同生命周期企业间的差异性。研究发现，外商直接投资对上市企业的持续性创新表现出强烈的促进作用。此外这种促进作用仅在成熟期阶段企业显著，而在其他生命周期阶段的企业中不显著。

关键词：外商直接投资；生命周期；持续创新；上市企业；企业面板数据

## 引言及文献综述

持续创新是推动我国经济持续增长的最重要动力。持续性创新是指企业本期创新是在过去创新的基础上持续推进，进而推动新的创新项目得到不断实施。当前国内大量文献就企业自身要素投入对持续性创新产生的相关影响进行了研究。肖忠意和林琳（2019）利用 2007-2017年我国 A 股非金融上市公司的面板数据，就企业金融化对持续性创新的影响进行的相关实证分析发现，企业金融化显著抑制了非金融上市企业的持续性创新，这种抑制效应在企业成长期尤为强烈。黄宏斌和翟淑萍（2016）发现处于不同生命周期阶段的企业倾向于通过不同的融资渠道来缓解融资约束，成长期和成熟期企业分别倾向于通过股权融资与债券融资来缓解融资约束。鞠晓生和卢荻等（2013）利用1998-2008年我国非上市工业企业面板数据，就融资约束、营运资本管理对企业创新活动产生的影响进行了相关分析，结果发现高的调整成本和不稳定的融资来源制约着企业的创新活动。

近几年随着我国对外资引进政策的相关调整，流入我国的外资质量发生了显著的变化，进而对我国经济产生了较大影响。才国伟和杨豪（2019）发现外商直接投资能够矫正我国当前不合理的资本市场，从而促进企业生产效率的提升。郭炳南和唐利（2020）发现外商直接投资能够促进我国绿色经济效率的提升。

那么外商直接投资是否促进了企业的持续持创新，这种促进作用在不同发展阶段的企业间是否存在显著差异，这应当是一个需要思考的重要问题。为此，本文利用2007-2018年我国A股上市企业的面板数据，实证分析了外商直接投资对企业持续性创新的影响， 并同时考虑这种影响在不同生命周期企业间的差异性。

## 研究设计

## （一）变量定义与数据来源

变量定义，持续性创新（srd）：本文参考肖忠意和材琳（2019）的方法，使用无形资产增量除以总资产得到的数值来衡量企业的持续性创新。企业的创新成果诸如专利等都反映在企业无形资产增量中，因而用该指标衡量持续创新较为合理。

外商直接投资（fdi）：本文使用外资企业所持有的股数占上市企业总股数的比重作为外资流入情况的衡量指标。其中，外资企业所持有的股数 = 境外发起人股 +B 股流通股+H股流通股或其他境外流通股。

企业生命周期：本文采用划分企业生命周期最常用的方法即现金流模式法，该方法通过企业的经营、筹资和投资现余流三个指标来划分企业生命周期本文参考黄宏斌等（2016）的生命周期设定方法，将企业生命周期划分为成长期、成熟期、衰退期三个生命周期阶段。

本文进一步控制了其他可能影响企业持续创新的变量，这些变量包括：企业盈利能力（roa）采用总资产收益率衡量、总资产增长率（dev）、管理层持股比例（rmh）、资产负债率（lev）、企业的经营绩效（qa）采用托宾 Q值衡量、企业规模（size）采用企业总资产的对数值衡量和现金资产比率（rmoney）。

数据来源。本文从国泰安 CSMAR 数据库中获取2007-2018 年沪深两市的 A 股上市公司相关数据，就外商直接投资、生命周期对企业持续创新产生的影响进行分析。本文根据实证研究的需要对数据进行了如下处理：剔除了ST 和非金融类企业的相关数据，此外还对本文中的所有连续变量进行上下1% 的winsorize 处理。处理后相关变量的基本统计信息显示在表1 中。

由表 2 的相关系数发现各解释变量之间不存在严重的多重共线性，因而回归结果是可靠的。

## （二）计量模型

为了分析外商直接投资对企业持续创新产生的影响，本文建立计量回归模型：

$$
\mathrm{srd} _ {\mathrm{it}} = \alpha + \beta_ {1} \mathrm{fdi} _ {\mathrm{it}} + \sum \beta_ {\text { controls }} \text { controls } _ {\mathrm{it}} + \varepsilon_ {\text { it }}\tag{1}
$$

其中srd 代表企业持续创新，fdi 代表外商直接投资，controls代表控制变量。下标i 代表企业，t 为年份，ε为误差项。

## 实证结果及分析

## （一）基准模型回归结果

本文首先利用总体样本数据就外商直接投资对企业持续创新产生的影响进行实证分析。为了使回归结果更加合理，表 3 的回归中均加入了相关影响企业持续创新的控制变量，此外只有表 3 的第（3）列同时控制了行业与年份效应，为此本文对总体样本的实证讨论主要围绕第（3）列展开。

表 3 中外商直接投资 fdi 的系数为正且在 5% 的显著性水平下显著，这表明外商直接投资显著促进了企业的持续创新。外商直接投资首先直接带来了大量资金的流入，这使得企业各项创新活动能够获得足够的资金支持，从而各项创新活动能够正常开展并持续增加企业持续的创新能力。此外，外商直接投资进入企业的同时，带来了先进的管理和先进的技术，这能够激发企业更好的开展创新获得，从而提升企业的持续创新能力。

对控制变量进行观察，发现企业盈利能力（roa）的提升显著促进了企业持续创新，企业盈利能力越强则企业的留存收益就越多，越能够为企业各项创新项目提供资金支持，从而提升企业的持续创新。企业发展速度越快（dev1），企业越能进行持续创新。企业发展速度快则表明企业拥有独特的竞争优势，为了维持企业的快速发展，企业会将更多的资金投入到创新项目中，从而提升企业的持续创新。管理层持股比例（rmh）越高企业越容易进行持续创新。较高的管理层持股比例，反映了管理层对企业未来发展较为自信，管理层有动力推动各项长期创新项目的实施，进而提升企业的持续创新。资产负债率（lev）的提升抑制了企业的持续创新。过高的资产负债率（lev）使得企业更容易陷入财务困境，限制了企业在长期创新项目上的投资，因而抑制了企业的持续创新。企业规模（size）越大，企业越能进行持续创新。企业规模（size）越大，企业的创新资源越多，越容易推动各项耗资巨大的创新项目的实施，进而促进企业的持续创新。现金资产比率（rmoney）的提升抑制了企业的持续创新。过高的现金资产比率反映了企业投资项目有限，无法有限利用资金开展各项创新投资，因而抑制了企业的持续创新。

## （二）不同发展阶段企业回归分析

考虑到处于不同生命周期阶段企业的持续创新动力和能力都存在较大的差异，本文进一步根据企业所处生命周期阶段的不同进一步进行回归分析，其回归结果显示在表4 中。通过表 4 发现，外商直接投资对不同发展阶段企业持续创新产生的影响存在显著差异。外商直接投资对处于成熟期上市企业的持续性创新表现出强烈的促进作用，而对其他生命周期阶段企业的影响不显著。成熟期企业主营业务稳定，内部创新资源较多，此时外商直接投资的流入有利于激发企业的创新活动，从而促进企业的持续创新。发展期企业还不稳定，业务波动较大，企业经营风险高，外资机构对该类企业的投资较少，因而对企业持续创新影响不显著。衰退期企业主营业务往往属于夕阳产业，进一步开展创新的空间有限，因而即使外资流入也难以促进企业的持续创新。

## 结论与启示

本文利用2007-2018年我国A股上市企业的面板数据，实证分析了外商直接投资对企业持续性创新的影响，并同时考虑这种影响在不同生命周期企业间的差异性。研究发现，外商直接投资对上市企业的持续性创新表现出强烈的促进作用。此外这种促进作用仅在成熟期阶段企业显著，而在其他生命周期阶段的企业中不显著。

本文结论为如何更有效引进外资从而支持企业持续性创新提供了政策启示：

第一，面对创新资源匮乏的现状，我国应当努力继续引进高质量的外商直接投资，从而更好提升我国的持续创新能力。通过优化营商环境，简化相关投资流程从而让高质量的外商直接投资顺利进入我国。

第二，不同生命周期阶段的企业应当根据自身创新特点的不同，合理引进外资，从而摆脱自身的创新困境，进而促进企业的持续创新。
