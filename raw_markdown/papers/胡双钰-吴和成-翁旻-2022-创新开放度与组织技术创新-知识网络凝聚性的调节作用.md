# 创新开放度与组织技术创新知识网络凝聚性的调节作用

胡双钰，吴和成，翁 旻( 南京航空航天大学 经济与管理学院，南京 211106)

摘要:整合开放式创新理论和知识基础理论，基于中国2000—2018 年生物技术领域的非平衡面板数据，实证检验组织创新开放度( 开放广度 开放深度) 对技术创新的非线性影响效应及情境机制 研究发现: 开放广度 开放深度与技术创新呈倒 U 型曲线关系，就目前而言，扩大开放广度和开放深度能有效推动组织技术创新水平的提升 对于高创新性的组织，创新开放度与技术创新呈倒 U 型态势;对创新能力较低的组织来说，开放广度与组织技术创新呈不显著的正向关系，开放深度阻碍技术创新的发展 此外，局部凝聚性对开放深度与技术创新的关系起负面调节作用，全局凝聚性反向调节开放广度与技术创新的关系<sub>。</sub>

关键词:创新开放度;技术创新;局部凝聚性;全局凝聚性

随着技术复杂度的提升及市场需求更新速度的加快，依靠组织自主创新满足多变性市场需求的传统模式难以为继，开放式创新是组织在变化的技术与市场空间中获取跨边界知识的重要方式，成为组织占据市场优势的必然趋势 开放式创新理论强调，组织积极开展与外部的合作，拓宽组织获取资源的新渠道，是解决组织资源瓶颈 占据竞争优势的必然选择

现有文献对创新开放度与技术创新关系的研究结论存在较大分歧，理论上的争论主要围绕创新开放度的成本与收益展开 持积极观点的学者认为，创新开放度拓宽组织获取外部资源的渠道，以较低的成本及风险获得所需的技术与知识<sup>［1］</sup> 持消极观点的学者认为，创新过程中知识的无意识外溢及 <sup>“</sup>搭便车<sup>”</sup>行为增加了机会主义风险，抑制组织的合作倾向<sup>［2］</sup><sub>。</sub> 因此，厘清创新开放度与技术创新的关系，合理配置资源以促进创新开放度的积极作用十分重要

总体来说，已有文献为创新开放度与技术创新关系的研究提供了一个基于<sup>“</sup>行为 －绩效<sup>”</sup>的逻辑理论架构，但仍存在以下问题: 一是聚焦于微观层面，数据源于问卷调查，较少从行业层面出发探讨组织开放度对技术创新的影响;二是大多仅关注对组织外部资源获取的作用机制，忽略了组织创新能力的异质性对技术创新的作用机理;三是创新开放度受组织知识网络集聚性的约束而存在差异<sub>。</sub> 因此有必要探索组织创新开放度对其技术创新作用机理的情景因素，本文基于资源基础观和知识基础观，运用 2000—2018 年生物技术领域非平衡面板数据研究创新开放度对组织技术创新的作用机理，重点挖掘局部凝聚性和全局凝聚性在创新开放度与技术创新关系中的调节作用，进一步诠释创新开放度与技术创新关系的情景因素

## 1 理论基础与研究假设

## 1．1 理论基础

<sup>“</sup>开放式创新<sup>”</sup>由 Chesbrough 首次提出 作为全新的信息和知识转移模式，开放式创新囊括了外部资源的搜索 剖析 内化及重组全过程，为组织在市场中占据持续竞争优势提供了外部支持 按资源流动方向，开放式创新分为内向型 外向型和耦合双向型<sup>［3］</sup><sub>。</sub> 基于外部信息与资源的搜索范围与搜寻深度，Laursen 和 Salter 提出了<sup>“</sup>开放度<sup>”</sup>概念<sup>［4］</sup>，将其分为开放广度和开放深度，前者强调组织外部合作渠道的数量 广泛的外部交流有助于对市场需求和技术趋势有更精准的把握，减少在技术研发和产品市场上的不确定性<sup>［5］</sup> 后者是指组织与外部主体合作的紧密程度，通过重复合作从有限的合作对象处获得更多知识以促进技术创新 开放广度和开放深度决定组织获取外部资源的数量和质量<sup>［6］</sup><sub>。</sub>

基于吸收能力理论，网络化情境中组织知识基础集聚性的不同，使组织的竞争能力 资源整合能力及知识吸收潜力具有显著差异，最终改变组织技术创新成果<sup>［7］</sup> 知识网络集聚是指知识元素相互连结 彼此作用所形成的网络结构特征，包括局部凝聚性和全局凝聚性两个维度，反映了组织对所处行业知识的掌握程度和洞察力<sup>［7］</sup> 其中，局部凝聚性是组织知识元素与网络内其他知识元素的直接联系程度，体现组织以往知识整合经验及知识元素专业化程度<sup>［7</sup> <sup>－</sup> <sup>9］</sup> 局部凝聚性越大，表明组织具有强大而持久的学习方向和技术轨迹，是组织核心技术能力竞争力的体现 全局凝聚性是指组织知识元素在整体网络中联系的紧密程度，反映了组织整合异质性技术的综合能力<sup>［9，10］</sup> 全局凝聚性将节点间的直接与间接关系纳入考察范围，是知识网络整体的密度，体现了组织整合和应用外部知识资源的能力<sup>［7］</sup> 从知识基础集聚视角探寻创新开放度与技术创新关系的影响机制，为组织占据竞争优势提供了新的视角，有助于更好地揭示创新过程的<sup>“</sup>黑箱<sup>”</sup> <sub>。</sub>

## 1．2 研究假设

## 1．2．1 创新开放度与组织技术创新

开放广度是指组织与外部伙伴建立合作关系的广泛程度，丰富的互补性及异质性资源为组织注入新的增长活力<sup>［11］</sup> 然而，过多的开放广度会造成组织外部资源成本上升 信息过载 创新的路径依赖以及新旧知识的冲突等问题 首先，与外部伙伴的合作丰富了组织外部资源获取渠道，大量异质性的外部资源增加了组织知识元素的重组机会<sup>［2］</sup><sub>。</sub> 其次，构建并维持广泛的外部合作关系，提升了组织运营及管理能力，这种能力提升了技术创新过程中组织资源配置效率<sup>［12］</sup><sub>。</sub> 再次，随着合作伙伴的增加，组织更容易从全局上把握行业发展趋势及最新技术前沿，有针对性地采取措施提供满足市场需求的产品或服务，从而在竞争中占据优势地位<sup>［8］</sup> 但是，由于合作各方在战略目标 组织结构及工作流程等方面存在差异，面对大量多元化异质性资源时，一方面，组织必定花费大量搜寻和协调成本，以确保内外部资源的整合能最大化自身收益<sup>［6］</sup> 另一方面，根据组织行为理论，个体决策的有限理性使组织合理处理信息的能力是既定的，过多的外部资源可能造成信息过载，引起组织决策失灵 因此提出研究假设:

## H1a: 创新开放广度与组织技术创新呈倒 U 型关系

开放深度从频繁的合作互动促进隐性知识交流 建立相互信任的环境以及减少交易成本等方面促进组织技术创新，具体表现在: 一是开放深度提升有助于组织长期合作战略的制定与实施，组织间信任关系的建立不仅有助于隐性知识的转移，而且能降低交易成本 减少合作中的信息不对称及机会主义倾向<sup>［13］</sup> 二是重复合作过程中形成的学习机制及知识积累提升了组织知识的专业化程度，有助于对相关领域知识的理解 吸收及整合<sub>。</sub> 三是重复合作使组织从现有合作关系中挖掘更多的知识，节省了搜寻成本和甄别成本，降低了合作中的不确定性 然而，开放深度并非越大越好，一方面，过于紧密的外部合作关系可能会加剧创新过程中的路径依赖，忽略现有合作关系之外更具发展潜力的合作机会<sup>［5］</sup>，从而陷入<sup>“</sup>集成导向<sup>”</sup>惯性 另一方面，合作往纵深方向发展必然促使技术复杂度上升，组织面临更高的资源配置要求和协同失败风险，在一定程度上抑制了组织技术创新的积极性<sup>［14］</sup> 因此，提出研究假设:

H1b: 创新开放深度与组织技术创新呈倒 U 型关系<sub>。</sub>

## 1．2．2 知识网络凝聚性的调节效应

技术创新的实质是知识元素的重组和再创造，创新并非知识元素间简单的排列组合，而是从多个可能性集合中选择最优解决方案<sup>［11］</sup> 因此，知识网络中元素间的结构性特征根植于日常管理 内部交流及战略制定等各个方面 知识网络局部凝聚性较高的组织，在既定领域内的专业知识有助于更好地挖掘潜在的合作机会<sup>［9］</sup>，但也使组织可能沿着既定的技术范式和技术轨迹进行创新<sup>［15］</sup>，而忽略了外部异质性较强的资源，从而陷入 <sup>“</sup>技术能力陷阱<sup>”</sup>，削弱了开放广度和开放深度对技术创新的促进作用

随着开放广度的进一步增加，外部搜寻及协调成本大幅增加<sup>［16］</sup>，资源的稀缺性使组织必然将有限的资源投入到预期收益最大的合作关系中，此时精细化知识及对特定领域的深度思考使组织更善于发掘现有合作中潜在的机会<sup>［17］</sup>，从而缓解创新开放广度对技术创新的负面影响 与此同时，当开放深度增加到一定程度时，技术的日益复杂化使组织通过拓展现有合作关系实现技术创新的难度大幅增加，专业化的知识有助于解决日趋复杂的技术问题，弱化开放深度对技术创新的负面作用<sub>。</sub>由此，提出研究假设:

H2a: 局部凝聚性负向调节创新开放广度与组织技术创新的关系;

H2b: 局部凝聚性负向调节创新开放深度与组织技术创新的关系<sub>。</sub>

知识网络全局凝聚性高，意味着知识网络具有较高的稳定性和复杂性，因而组织现有知识体系缺乏外部知识嵌入的渠道和 <sup>“</sup>间隙<sup>”</sup>( Gaps)<sup>［9］</sup> 已有研究表明组织倾向于从已有合作路径中获取所需资源<sup>［16］</sup>，全局凝聚性高的组织由于知识元素间的联系紧密，更易遵循已有合作路径，从现有知识元素的重组中促进技术创新<sup>［9］</sup> 因此，知识网络的全局凝聚性削弱了开放广度 开放深度提升对技术创新的促进作用<sub>。</sub>

当开放广度增加到一定程度时，较高的全局凝聚性使组织具备了整合不同领域知识元素的能力和经验，有助于组织选择最优的解决方案，从而促使组织进入更具发展潜力的技术轨迹或加速实现创新范式转移<sup>［18］</sup> 因此，较高的全局凝聚性有助于组织缓解决策失灵带来的约束，削弱较高开放广度对技术创新的负面影响 随着开放深度的增加，组织从已有合作伙伴中挖掘更多创新机会，降低了组织外部协调成本和信息甄别成本<sup>［19］</sup>，但此时也伴随着较高的路径依赖风险，忽略现有合作关系外更具潜力的组合机会 若组织全局凝聚性高，对网络中流动的信息高度敏感，有利于发现潜在的合作机会<sup>［7］</sup>，有助于减缓开放深度对技术创新的消极影响 由此，提出研究假设:

H2c: 全局凝聚性负向调节创新开放广度与组织技术创新的关系;

H2d: 全局凝聚性负向调节创新开放深度与组织技术创新的关系<sub>。</sub>

## 2 研究设计

## 2．1 研究样本和数据来源

借鉴 OECD 对生物技术领域的专利分类( IPC) ，采用关键词搜索策略在国家知识产权局数据库中对生物技术领域的数据进行识别与检索 剔除个人发明专利，由于组织间的合作关系一般持续 3 －5 年<sup>［20］</sup>，样本组织的筛选借鉴 Zhang 和 Luo 的研究<sup>［20］</sup>，入选样本需满足在t －5 至 t －1 年期间成功申请专利，且在第 t 年也有专利授权<sub>。</sub> 本文以 IPC 前四位代码<sup>［18，21］</sup>来定义不同技术类别的知识元素，通过5 年的移动时间窗口<sup>［22］</sup>构建 19 个知识网络，最终以2000—2018 年期间的883 个组织为研究对象，构建非平衡面板( N = 2044) <sub>。</sub>

## 2． 2 变量测度

## 2． 2． 1 被解释变量

组织技术创新( Inno) 专利数量被众多学者作为技术创新的代理变量<sup>［6，19］</sup>，能较好地反映组织创新状态<sub>。</sub> 本文借鉴 Zhang 和 Luo 的研究<sup>［20］</sup>，用组织第 t 年的专利授权数表示技术创新

## 2． 2． 2 解释变量

创新开放广度( Bre) 开放广度是指焦点组织在合作网络中建立直接合作关系的外部伙伴数量，合作对象越多，说明组织与异质性合作伙伴展开的直接联系越广泛<sup>［19］</sup><sub>。</sub> 用组织t －5 至t －1 年期间联合申请专利中合作伙伴的数量表示<sup>［8］</sup> $\mathrm { B r e } = \Sigma \mathrm { P } _ { \mathrm { i } } \bullet \mathrm { P } _ { \mathrm { i } }$ 表示组织 i 有合作关系的组织数量<sub>。</sub>

创新开放深度( Dep) 反映了组织在合作中的相互依赖程度，体现了合作中信息交流的频繁程度<sup>［6］</sup><sub>。</sub> 用观测期前5 年的联合申请专利中，组织与合作者之间平均重复合作次数衡量开放深度<sup>［8，21］</sup><sub>。</sub> $\mathrm { D e p } = { \frac { \sum _ { i = 1 } ^ { N } { \left( \sum C P _ { i } \right) } } { \mathrm { B r e } } }$ ，其中 ${ \mathbf { \Omega } } _ { \bullet } \mathrm { C P } _ { \mathrm { i } }$ 表示组织与合作伙伴 i 在过去 5 年联合申请的专利数量<sub>。</sub>

## 2． 2． 3 调节变量

知识网络局部凝聚性( LC) ，用加权总体集聚系数来衡量<sup>［7］</sup><sub>。</sub> 组织知识网络局部凝聚性由组织拥有的全部知识元素局部凝聚性的均值表示<sup>［9］</sup><sub>。</sub>

## 4 研究结论与管理启示

本文基于资源基础观理论，构建了创新开放度对技术创新的影响效应分析模型，揭示了创新开放广度 开放深度与技术创新之间存在的倒 U 型曲线关系，弥补了已有研究仅从单一维度进行探究的局限 适度的开放广度通过降低协调成本 提供多渠道的异质性外部资源促进组织技术创新，这个理论印证了刘斐然等的观点<sup>［6］</sup>，深化了 Xu 等关于开放广度的传统作用机制<sup>［8］</sup><sub>。</sub>与 Kobarg 的观点具有相似性<sup>［5］</sup>，开放深度与技术创新呈倒 U 型关系 就中国生物技术领域目前阶段而言，组织增加创新开放度将有助于技术创新水平的提高 此外，将 Wang 等的研究<sup>［16］</sup>及 Wang 和 Yang 的研究成果<sup>［7］</sup>进行了有机结合，将知识网络的凝聚性纳入创新开放度与技术创新关系的情境机制，结果证实知识网络全局凝聚性对开放广度所引致的影响具有负面调节效应，知识网络局部凝聚性不利于开放深度发挥其对技术创新的影响作用<sub>。</sub>

基于上述结论，提出如下管理建议: 首先，继续推动组织开放度的发展 在竞争日益激烈 技术复杂度不断提升的市场环境中，应选择<sup>“</sup>多伙伴强关系<sup>”</sup>战略 加强与外部主体的联系，做好资源分配及战略目标的调整，以发现并整合可能的创新机会 同时，强化与已有外部渠道的深度交流，避免浅尝辄止，使组织在深度融合中以较低的成本获得准确的信息 前沿性的关键知识，从而促进知识存量的提升以及组织知识向专业化 复杂化等纵深方向的拓展

其次，从战略层面加强知识体系构建及知识资源管理，积极利用知识元素间的耦合关系和组合方式促进与合作伙伴的知识流动，以实现自身发展目标并推动行业技术演进<sub>。</sub> 应及时调整组织知识基础的集聚水平，尽可能降低其负面效应 具体地，在培养核心知识簇形成的基础上，通过建立科学的创新激励机制 营造良好的创新性氛围等多种方式，增强组织摆脱现有技术轨迹约束的内驱力，避免固有创新流程及方式的僵化

总体来说，组织应重视组织的外部知识搜索能力的培养，开拓多种外部资源合作模式，建立开放 畅通的资源流动渠道，促进组织间知识 技术等无形资源及人力资本 专用性固定资产等有形资源的协同与互补，为组织结合自身资源和外部竞争环境，寻找开放广度和开放深度的最佳组合以实现资源的优化配置创造条件
