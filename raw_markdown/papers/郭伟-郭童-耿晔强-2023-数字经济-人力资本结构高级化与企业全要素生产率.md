# 数字经济、人力资本结构高级化与企业全要素生产率

郭 伟<sup>1</sup>，郭 童<sup>2</sup>，耿晔强<sup>1</sup>

（1.山西大学 经济与管理学院，山西 太原 030006；2.纽约大学 商学院，美国 纽约 10013）

摘 要：将数字经济、人力资本结构高级化与企业全要素生产率纳入统一的分析框架，从理论层面分析数字经济、人力资本结构高级化对企业全要素生产率的影响作用，并利用2011一2021年我国上市公司微观数据进行实证分析。研究发现数字经济与人力资本结构高级化对企业全要素生产率均有明显的促进作用。进一步的研究表明，数字经济与人力资本结构高级化主要通过技术创新渠道影响企业全要素生产率。研究结果为我国政府制定提升企业全要素生产率的有效政策以推动经济高质量发展提供了启示。

关键词：数字经济；人力资本结构高级化；全要素生产率

## 一、引言

改革开放以来，我国在经济建设方面取得了举世瞩目的成就。但是，在2010年之后我国经济增长速度从过去的两位数高速经济增长下行到的速度，经济增长速度明显放缓。显然，受产业结构失衡、人口红利消失、投资边际报酬递减等因素影响，以往依靠要素投入来拉动经济增长的粗放型发展方式已难以满足新时期我国经济高质量发展的现实需求。因此，转变经济发展方式，促使依靠要素投入的经济发展方式向全要素生产率转变，是我国培育经济发展新动能、全面建设社会主义现代化国家的必然选择。而数字经济作为一种新的经济形态，在激发消费、拉动投资、创造就业等方面发挥着举足轻重的作用，能够有效提高生产效率，促进经济发展。具体来说，数字经济可以通过人工智能、大数据等新兴技术，使企业合理配置资源要素，形成规模经济、范围经济以及长尾效应，提高生产效率。与此同时，人力资本作为知识创造和技术进步的重要载体，是影响企业全要素生产率的重要因素。原因在于，人力资本结构高级化既能优化企业资源配置，促进劳动力精细化分工，为企业转型发展提供人力资本支撑，也能加快企业技术创新由原始技术向尖端技术转变，有效提升企业技术创新能力，促进企业全要素生产率的提高。在此基础上，深入研究在数字经济与人力资本结构高级化共同作用下的企业全要素生产率提升路径及机制，有助于我国激发经济发展动能，重塑经济增长引擎，实现高质量发展。

## 二、文献综述

本文主要梳理了数字经济和人力资本结构高级化对企业全要素生产率影响作用的相关内容。

目前已有不少文献分析了数字经济与全要素生产率之间的作用关系。裴长洪等认为，数字经济通过数字技术基础性、渗透性、外溢性和互补性等特点，从消费领域不断向生产领域延伸，影响着各领域全环节全要素生产率的提升<sup>[1]</sup>。在数字经济驱动下，具有易复制性、零边际成本、非损耗等特点的数据资源得以快速发展。作为新型生产要素，数据资源能够像资本、劳动等传统要素一样直接参与到生产环节当中，提高生产效率，并且还会优化要素资源配置，促进生产率的提升。另外，数字经济能够通过互联网等新兴技术将繁琐的数据转化成有用的交易信息，打破自然性市场分割，加强国内乃至国际市场的整合，减少企业因信息不对称、机会主义、有限理性等因素而产生的成本，显著提高企业生产效率，助力企业实现规模经济<sup>[2]</sup>。同时，数字经济可以改善企业发展的外部融资环境，缓解企业创新融资约束，促使企业进行数字技术创新研发活动，不断催生出新产品、新业态、新模式，有效提高企业生产率<sup>[3]</sup>。此外，数字经济还能有效降低企业内部交流和信息获取成本，加快企业“垂直化”的组织结构向“扁平化”转变，增强员工信息接受与处理能力，有效提高工作效率，进而促进企业生产率的增长[4]。

另外，国内外学者也较为关注人力资本结构高级化对企业全要素生产率的影响。董林辉和段文斌基于要素资源配置的角度进行研究，发现人力资本结构高级化促进劳动力专业分工，使劳动要素配置更为合理，有效提高企业生产率<sup>[5]</sup>。在此基础上，杨仁发和郑媛媛从要素集聚的角度进行探究，发现人力资本结构优化可以提高地区人力资本的竞争优势，使产业因知识密集型特征而集聚，同时还可以为企业提供高质量的人力资本服务，降低同类型企业的信息成本与交易成本，提高企业生产效率<sup>[6]</sup>。此外， 和 从创新方向进行研究，认为人力资本具有增强吸收和应用现有技术或是创造新技术的能力，能够显著促进生产率增长<sup>[7]</sup>。其中，李杏和侯佳妮认为，人力资本结构高级化意味着更高层次和质量的人才，具有较强的学习能力和吸收能力<sup>[8]</sup>。在此基础上，朱克朋和樊士德认为，高素质人才所具备的知识储备、研发经验以及创造能力可以通过影响企业技术创新水平来提高全要素生产率<sup>[9]</sup>。并且，人力资本结构高级化还具有明显的外溢效应，能够使企业高素质人才，尤其是知识型、技能型和技术型人才，将专业知识传播给其他劳动者，为企业带来正外部性效应。因此，人力资本结构优化可以加速技术吸收与扩散，有效提高科技成果转化效率，创造新型生产技术或产品，使得企业能够通过颠覆现有技术、管理模式等方式推动生产效率的提高<sup>[10]</sup>。

从上述文献可以看出，国内外学者倾向于单独从数字经济或人力资本结构高级化的视角探究企业全要素生产率，鲜有文献分析二者共同作用下的企业全要素生产率提升路径。并且，研究数字经济或人力资本结构高级化与企业全要素生产率之间关系的文献更注重利用具体数据进行经验研究，缺乏相关理论分析。为此，本文将理论与实证相结合，详细研究了数字经济和人力资本结构高级化对企业全要素生产率的影响作用。对比当前的相关文献，本文的创新之处在于：一是将数字经济和人力资本结构高级化以及企业全要素生产率纳入统一的分析框架，从理论层面探究企业全要素生产率的提升路径；二是利用2011—2021年我国上市公司微观数据，实证检验了数字经济、人力资本结构高级化对企业全要素生产率的影响作用，并采用多种方法进行稳健性分析，使研究结果更具有可信性；三是基于企业所有制类型以及产业类型进行异质性分析，深化已有研究；四是通过进一步研究，验证了数字经济和人力资本结构高级化能够通过技术创新这一渠道实现对企业全要素生产率的促进作用，丰富了本文的研究结论。

## 三、理论分析

本文基于研究目的，将数字技术与人力资本纳入理论分析框架，分析数字经济和人力资本结构高级化对企业生产率的影响。

## （一）家庭消费需求与劳动力市场供需

本文假定消费者效用函数如下：

$$
U _ {0} = \int_ {0} ^ {\infty} \exp (- \rho) \frac {C (t) ^ {1 - \vartheta} - 1}{1 - \vartheta} \mathrm{d} t\tag{1}
$$

其中 $, \rho > 0$ ，代表贴现系数； $\vartheta > 0$ $\vartheta \neq 1$ ，代表相对风险规避系数； $C ( t )$ 代表消费总量，由式（2）表示：

$$
C (t) = \int c _ {j} (t) ^ {\frac {\varepsilon - 1}{\varepsilon}} d j\tag{2}
$$

其中， $c _ { j } ( t )$ 代表产品j在t时的消费总量， $\varepsilon > 1$ 代表产品替代弹性。

此外，本文假定劳动力可以分为熟练劳动力L与非熟练劳动力L<sup>u</sup> 两种类型。前者主要从事技术服务与技术研发活动，可以获取较高的劳动报酬$w ^ { s }$ ；后者主要从事产品流水线上的日常生产活动，可以获得劳动报酬 $w ^ { u }$ ，并且 $w ^ { s } > w ^ { u }$ 。具体劳动市场供需函数如式（3）、式（4）所示：

$$
\bar {L} = L ^ {s} + L ^ {u}\tag{3}
$$

$$
I = w ^ {s} L ^ {s} + w ^ {u} L ^ {u}\tag{4}
$$

其中，Lˉ代表劳动供给总量，为固定值，I代表家庭预算收入。假定人力资本结构 $\scriptstyle { h s = L ^ { s } } / L ^ { u }$ ，结合式（）、式（）可知，在劳动供给总量恒定的约束条件下，熟练劳动力工资 $w ^ { s }$ 的提高可以吸引非熟练劳动力向熟练劳动力方向转移，进而提高人力资本结构的高级化水平，即：

$$
\frac {\mathrm{d} h s}{\mathrm{d} w ^ {s}} > 0\tag{5}
$$

## （二）企业生产活动

假设企业在垄断竞争条件下，利用现有技术从事产品日常生产活动，其生产函数如下：

$$
y _ {j} = q _ {j} l _ {j} k _ {j}\tag{6}
$$

其中， $q _ { j }$ 代表企业全要素生产率。 $l _ { j }$ 为企业生产产品j时所需要的非熟练劳动力数量。 $k _ { j }$ 是生产产品j时所需要的资本投入。在之后的分析过程中，由于资本要素 $k _ { j }$ 对研究结果不产生影响，本文参考Romer内生增长模型，将部分劳动力作为创新知识载体，通过单一劳动力要素来分析生产效率。因此，式（）可简化为：

$$
y _ {j} = q _ {j} l _ {j}\tag{7}
$$

此外，通过式（2）可以得到产品逆需求函数 $p _ { j } =$ $C ^ { \frac { 1 } { \varepsilon } } c _ { j } ^ { - \frac { 1 } { \varepsilon } } { _ \odot }$ 。进而可得企业生产利润函数，具体如下：

$$
\pi \left(q _ {j}\right) = \max _ {c _ {j} \geqslant 0} \left[ \left(C ^ {\frac {1}{\varepsilon}} c _ {j} ^ {- \frac {1}{\varepsilon}} - w _ {j} ^ {u} / q _ {j}\right) c _ {j} \right]\tag{8}
$$

其中， $\pi ( q _ { j } )$ 来代表企业生产利润。令式（8）导数结果为0可求得产品最优价格与最优产量，具体如下：

$$
p _ {j} = (\varepsilon / \varepsilon - 1) w _ {j} ^ {u} q _ {j} ^ {- 1}\tag{9}
$$

$$
c _ {j} = \left(\varepsilon - 1 / \varepsilon\right) ^ {\varepsilon} \left(\mathrm{w} _ {j} ^ {u}\right) ^ {- \varepsilon} q _ {j} ^ {\varepsilon} C\tag{10}
$$

结合式（9）、式（10），可得出产品均衡利润函数，具体如下：

$$
\pi \left(q _ {j}\right) = (\varepsilon - 1) ^ {\varepsilon - 1} (\varepsilon) ^ {- \varepsilon} \left(w _ {j} ^ {u}\right) ^ {1 - \varepsilon} q _ {j} ^ {\varepsilon - 1}\tag{11}
$$

将式（ ）对数化后求导，可得：

$$
\frac {\mathrm{d} \ln (\pi)}{\mathrm{d} q} = (\varepsilon - 1) q ^ {\varepsilon - 3}\tag{12}
$$

由于产品替代弹性 $\varepsilon > 1$ ，生产率 $q > 0$ ，故而$\frac { \mathrm { d } \ln { ( \pi ) } } { \mathrm { d } q } > 0 _ { \circ }$ 。显然，生产率的提升有助于企业获得技术创新所带来的垄断利润，进而吸引更多的投资者进行投资。即是说，生产率的提升可以提高投资者对企业的预期价值EV，即：

$$
\frac {\mathrm{d} E V}{\mathrm{d} q} > 0\tag{13}
$$

## （三）数字经济与企业技术研发

本文假定在数字经济发展背景下，企业为在激烈的竞争环境中胜出，会抢抓信息革命机遇，加大数字技术创新研发活动，实现企业高质量发展。

具体来说，本文基于企业创新能力差异，将企业分为高水平创新θ<sup>s</sup>与低水平创新θ<sup>u</sup>两种类型，深入考察数字经济发展背景下企业数字技术研发情况。同时，为进一步区分熟练劳动力在研发部门中的职能作用，本文将熟练劳动力L<sup>s</sup>细分为技术研发人员h与技术服务人员 $\mathcal { O } ,$ ，并且假定两类技术人员工资均为 $w ^ { s } .$ 。于是，企业数字技术研发函数如下：

$$
x = \theta^ {\gamma} h ^ {1 - \gamma}\tag{14}
$$

$$
C (x) = w ^ {s} x ^ {1 / 1 - \gamma} \theta^ {- \gamma / 1 - \gamma} = w ^ {s} G (x)\tag{15}
$$

其中，x代表企业数字技术水平，θ为企业创新类型，h为企业数字技术研发所雇佣的技术研发人员数量， $\gamma \in ( 0 , 1 ) , w ^ { s }$ 为研发人员工资， $C \left( x \right)$ 为企业实现数字技术水平 x 所需要的研发投入成本。$G ( x ) = x ^ { 1 / 1 - \gamma } \theta ^ { - \gamma / 1 - \gamma }$ 则为企业实现数字技术水平x时的技术研发人员需求。

## （四）企业进退市场均衡

本文假定市场有大量的潜在进入者。在数字经济发展背景下，企业想要进入市场需要具备具有足够价值的数字技术，使企业达到市场准入门槛。这就需要企业在进入市场前雇佣充足的技术研发人员与技术服务人员进行数字技术研发活动，即：

$$
L ^ {s e n t r y} = \emptyset + G (x)\tag{16}
$$

然后，潜在进入者会基于企业预期价值EV与数字技术投入成本 $w ^ { s } L ^ { s }$ 来分析预期回报 $\Pi ( q )$ ，并以此选择是否进入市场。因此，市场进入条件如下：

$$
\Pi (q) = \max \left[ E V ^ {\text { entry }} (q) - w ^ {s} \emptyset - w ^ {s} G \left(x ^ {\text { entry }}\right) \right] \tag {17}
$$

式（17）也决定了进入者的数字技术水平。若上式的结果为正值，就意味着会有更多的潜在进入者选择进入市场；若为负值，则难有企业进入市场。因此，在均衡状态下 $\Pi { \bigl ( } q { \bigr ) } = 0 .$ 。于是，可以得到企业进退市场的均衡条件：

$$
E V ^ {\text { entry }} (q) = w ^ {s} \emptyset + w ^ {s} G \left(x ^ {\text { entry }}\right)\tag{18}
$$

因此，当市场处于均衡状态时，将式（18）对企业数字技术水平x求导可得：

$$
\frac {\mathrm{d} E V (q)}{\mathrm{d} x} = \frac {\mathrm{d} E V (q)}{\mathrm{d} q} \times \frac {\mathrm{d} q}{\mathrm{d} x} = (1 / 1 - \gamma) w ^ {s} \theta^ {- \gamma / 1 - \gamma} x ^ {\gamma / 1 - \gamma}\tag{19}
$$

其 中 ， $0 < \gamma < 1$ $w ^ { s } > 0$ $\theta > 0$ $x > 0$ ，即$\frac { \mathrm { d } E V \left( q \right) } { \mathrm { d } x } > 0$ ，再结合式（13）可得， ${ \frac { \mathrm { d } q } { \mathrm { d } x } } > 0$ ，即数字技术水平有利于提高全要素生产率。

针对上述结论，可得到假说 ：数字经济有利于企业全要素生产率的提升。

同理，将式（18）对熟练劳动力工资 $w ^ { s }$ 求导

可得：

$$
\frac {\mathrm{d} E V (q)}{\mathrm{d} w ^ {s}} = \frac {\mathrm{d} E V (q)}{\mathrm{d} q} \times \frac {\mathrm{d} q}{\mathrm{d} w ^ {s}} = \varnothing + G (x)\tag{20}
$$

显然，熟练劳动力数量 $\mathcal { D } > 0 , G ( x ) > 0$ ，即$\frac { \mathrm { d } E V \left( q \right) } { \mathrm { d } w ^ { s } } > 0$ ，再结合式（13）可得， $\frac { \mathrm { d } q } { \mathrm { d } w ^ { s } } > 0 \mathrm { . }$ 。又由于$\frac { \mathrm { d } q } { \mathrm { d } h s } = \frac { \mathrm { d } q } { \mathrm { d } w ^ { s } } \times \frac { \mathrm { d } w ^ { s } } { \mathrm { d } h s }$ ，结合式（5）可得， $\frac { \mathrm { d } q } { \mathrm { d } h s } > 0$ ，即人力资本结构优化正向影响企业全要素生产率。

为此提出假说 ：人力资本结构高级化显著提高了企业全要素生产率。

## 七、结论与政策建议

本文构建了数字经济、人力资本结构高级化与企业全要素生产率的理论分析框架，并基于2011—2021年我国上市公司微观数据实证分析了数字经济、人力资本结构高级化对生产率的影响。与此同时，本文基于企业所有制类型与产业类型进行异质性分析，结果显示：一是国有企业与非国有企业的数字经济均对企业全要素生产率产生积极作用，且国有企业的促进效果更加突出；国有企业与非国有企业的人力资本结构高级化同样都对企业全要素生产率有着促进作用，但非国有企业的促进效果更为明显。二是第一产业、第二产业以及第三产业的数字经济均能显著提升全要素生产率；人力资本结构高级化同样能够有效提升第二产业与第三产业的全要素生产率，但对第一产业的效果却不为明显。进一步研究表明，数字经济与人力资本结构高级化主要通过技术创新渠道影响企业的生产效率。

据此，本文给出以下建议：首先，推动数字经济与实体经济深度融合。政府部门应该贯彻落实建设数字中国的战略决策，把新发展理念贯穿到数字中国建设的全过程和各领域，加快推进数字基础设施建设，有效提升信息技术创新能力，充分发挥数据要素价值，推动产业基础高级化、产业链现代化，为企业数字化转型创造良好的发展环境。另外，企业应抢抓信息革命机遇，加强对数字化的思维认知，充分利用数据资源进行生产和决策，通过关键数字技术的创新与应用，不断催生出新产品、新业态、新模式，促进企业全要素生产率的提高，推动企业高质量发展。其次，加强技能型人才队伍建设。政府部门应当继续深入实施人才强国战略，促进教育数字化，用先进理念与技术手段建设高质量人才队伍，以源动力和内生驱动力促进人力资本结构高级化。此外，企业应该积极与政府、高校及社会其他机构联合，建立适应企业发展需要的一流科技人才队伍，实现数字化人才技能结构与企业数字化转型的高度匹配，以有效提高企业的全要素生产率。

Abstract:How to effectively implement the R&D expense deduction policy is a key node in achieving an innovation driven strategy.Based on the era of digital economy，focusing on the possible manipulation of R&D expenditure classification caused by this policy，this paper takes the listed enterprises in Shanghai and Shenzhen Ashares from 2013 to 2021 as the research object，and finds that digital transformation can effectively curb this speculation.Further research found that the internal control quality and legal environment of the enterprise and the digi tal transformation formed a“governance complementary mechanism”to jointly promote the implementation of the deduction policy.
