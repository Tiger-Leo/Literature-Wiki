# 如何检验分组回归后的组间系数差异?

连玉君，廖俊平

( 中山大学 岭南学院，广东 广州 510275)

摘 要:实证研究中，若检验在不同情况下一个变量对另一变量的影响程度，则需要对样本进行分组检验，进而比较两个子样本的系数差异 然而，单独比较子样本系数的显著性水平可能会存在偏差 为解决这一问题，本文介绍三种较为常见的组间系数差异检验方法的原理及 Stata 实现 其中，<sup>“</sup>Chow 检验<sup>”</sup>通过引入交乘项的方式进行检验，该方法假定控制变量的系数不随组别发生变化，适用条件最为严格; <sup>“</sup>似无相关模型检验<sup>”</sup>则允许控制变量系数存在差异，且子样本扰动项相关，适用条件较为宽松; <sup>“</sup>费舍尔组合检验<sup>”</sup>基于自体抽样思想，通过不断抽样模拟总体特征，适用范围最为广泛

关键词:组间系数差异;Chow 检验;似无相关模型;费舍尔组合检验;企业金融

## 一<sub>、</sub>问题的提出

实证分析中，经常需要对比分析两个子样本组的系数是否存在差异<sub>。</sub> 例如，在公司金融领域，研究薪酬激励是否有助于提升业绩时，模型设定为:

$$
\mathrm{ROE} _ {\mathrm{it}} = \alpha_ {\mathrm{i}} + \text {Salary} _ {\mathrm{it-1}} \cdot \beta + \text {Controls} _ {\mathrm{it-1}} \cdot \gamma + \mathrm{u} _ {\mathrm{it}}
$$

关注的重点是系数 β 文献中经常把样本组分成 <sup>“</sup>国有企业( SOE) <sup>”</sup>和 <sup>“</sup>民营企业( PRI) <sup>”</sup>两个样本组，继而比较 $\beta _ { \mathrm { s o E } }$ 和 $\beta _ { \mathrm { P R I } }$ 是否存在差异<sub>。</sub> 通常认为，民营企业的薪酬激励更有效果，即$\beta _ { \mathrm { s o E } } < \beta _ { \mathrm { p R I } }$ 。

如果两个样本组中的模型设定是相同的，则两组之间的系数大小是可以比较的，而且这种比较在多数实证分析中都是非常必要的<sub>。</sub> 参见 Cleary( 1999) ，以及连玉君等( 2010) <sub>。</sub>

下面使用 Stata 软件自带的一份数据文件( nlsw88． dta) ，说明此类问题的关键所在<sub>。</sub> 这份数据包含了1988 年采集的2 246 个妇女的资料，包括: 小时工资( wage) ，每周工作时数( hours) ，种族( race) 等关键变量

假如我们研究的问题是种族特征是否会影响妇女的工资决定机制，则我们最为关注的是<sup>“</sup>白人组<sup>”</sup>和<sup>“</sup>黑人组<sup>”</sup>的工资决定因素是否存在差异<sub>。</sub> 分析的重点集中于工龄( ttl\_exp) 和婚姻状况( married) 这两个变量的系数在两组之间是否存在显著差异<sub>。</sub>

我们可以使用如下命令进行分组 OLS 回归，并呈现<sup>“</sup>白人组<sup>”</sup>和<sup>“</sup>黑人组<sup>”</sup>的系数估计值:

```txt
sysuse "nlsw88.dta", clear
gen agesq = age*age
*-分组虚拟变量
drop if race==3
gen black = 2.race
tab black
*-删除缺漏值
global xx "ttl_exp married south hours tenure age* i.industry"
reg wage $xx i.race
keep if e(sample)
*-分组回归
global xx "ttl_exp married south hours tenure age* i.industry"
reg wage $xx if black==0
est store White
reg wage $xx if black==1
est store Black
*-结果呈现和对比
local m "White Black"
esttab `m', mtitle(`m') b(%6.3f) nogap drop(*.industry) //
s(N r2 a) star(* 0.1 ** 0.05 *** 0.01)
```

相对而言，若把注意力放在 married 这个变量上，或许更容易判断二者的差异是否显著<sub>。</sub> 因为，married 在<sup>“</sup>白人组<sup>”</sup>和<sup>“</sup>黑人组<sup>”</sup>的系数分别为 $\beta _ { \mathrm { { w h i t e } } } = - 0 . 7 3 7$ 和 $\beta _ { \mathrm { b l a c k } } = 0 . 0 9 1$ 前者在5%水平上显著为负，而后者则不显著<sub>。</sub> 然而，即使如此，我们仍然无法确信二者的差异在统计意义上是否显著<sub>。</sub> 这是因为二者的 95% 置信区间( CI) 尚存在重叠区域: $\mathrm { C I } _ { \mathrm { w h i t e } } ~ = ~ \left[ - 1 . ~ 3 6 \right.$ 9$- 0 . 1 1 \ ] , \mathrm { C I } _ { \mathrm { b l a c k } } = \ [  0 . 6 9 , 0 . 8 7 ]$ 。

下面，我们介绍三种检验组间系数差异的方法: 其一，引入交叉项( Chow 检验) ; 其二，基于似无相关模型的检验方法( suest) ; 其三，费舍尔组合检验( Permutation test) 第一种方法是文献中普遍使用的，但假设条件最为严格，第三种方法主要以自抽样为基础，假设条件最为宽松<sub>。</sub>

## 二<sub>、</sub>检验方法

## ( 一) 引入交叉项

## 1． 基本思想

这是文献中最常用的方法，执行起来也最简单<sub>。</sub> 以检验 ttl\_exp 在两组之间的系数是否存在显著差异为例<sub>。</sub> 引入一个虚拟变量 $\mathrm { D } _ { \mathrm { i } }$ ，若某个妇女是黑人，则 $\mathrm { D } _ { \mathrm { i } } = 1$ ，否则 $\mathrm { D } _ { \mathrm { i } } = 0$ <sub>。</sub> 在如下命令中，black 变量即为这里的 $\mathrm { D } _ { \mathrm { i } } ,$ 模型设定为:

$$
\mathrm{Wage} _ {\mathrm{i}} = \alpha + \gamma \cdot \mathrm{D} _ {\mathrm{i}} + \beta \cdot \text {ttl\_exp} _ {\mathrm{i}} + \delta \left(\mathrm{D} _ {\mathrm{i}} \times \text {ttl\_exp} _ {\mathrm{i}}\right) + \text {Controls} _ {\mathrm{i}} \cdot \gamma + \varepsilon_ {\mathrm{i}}\tag{1}
$$

这是最基本的包含虚拟变量，以及虚拟变量与一个连续变量交乘项的情形

显然，对于<sup>“</sup>白人组<sup>”</sup>而言 ${ \bf \nabla } _ { \bf 3 } D _ { \mathrm { i } } = 0$ ，则( 1) 式可以写为:

$$
\mathrm{Wage} _ {\mathrm{i}} = \alpha + \beta \cdot \text {   ttl\_exp } _ {\mathrm{i}} + \text { Controls } _ {\mathrm{i}} \cdot \gamma + \varepsilon_ {\mathrm{i}}\tag{1a}
$$

对于<sup>“</sup>黑人组<sup>”</sup>，(1) 式可以写为:

$$
\text { Wage } _ {\mathrm{i}} = (\alpha + \gamma) + (\beta + \delta) \cdot \text { ttl\_exp } _ {\mathrm{i}} + \text { Controls } _ {\mathrm{i}} \cdot \gamma + \varepsilon_ {\mathrm{i}}\tag{1b}
$$

由此可见，在(1) 式中，参数 $\gamma$ 和 δ 分别反映了黑人组相对于白人组的截距和斜率差异此时，参数反映了 ttl\_exp 这个变量在两个样本组中的系数差异<sub>。</sub> 因此，检验 ttl\_exp 在两组之间的系数是否存在显著差异就转变为 $\mathrm { H } _ { 0 } : \delta = 0$ 。

## 2． Stata 实现

估计( 1b) 式的 Stata 命令如下:

```hcl
dropvars ttl_x_black marr_x_black
global xx "ttl_exp married south hours tenure age* i.industry" //Controls
gen ttl_x_black = ttl_exp*black //交乘项
reg wage black ttl_x_black $xx //全样本回归+交乘
```

然而，在上述检验过程中，我们无意识中施加了一个非常严格的假设条件: 只允许变量［ttl\_exp］的系数在两组之间存在差异，而其他控制变量( 如 married，south，hours 等) 的系数则不随组别发生变化 这显然是一个非常严格的假设 因为，从表 1 中的结果来看，married，south，hours 等变量在两组之间的差异都比较明显

我们可以放松上述假设，允许 married，south，hours 等变量的系数存在组间差异<sub>。</sub> 这主要通过引入虚拟变量 black 与上述变量的交乘项来实现( 模型2) :

```txt
reg wage i.black i.black#(c.ttl_exp i.married i.south c.hours) $xx //Model 2
```

在这种相对灵活的设定下，［ttl\_exp］的系数为 － 0． 016147，相应的 p － value = 0． 787，依然不显著<sub>。</sub>

当然，我们也可以采用更为灵活的方式: 允许所有的变量在两组之间都存在系数差异 1( 模型 3) :

```txt
global xx "c.ttl_exp married south c.hours c.tenure c.(age*) i.industry"
reg wage i.black##($xx) //Model 3
```

这其实就是大名鼎鼎的 Chow test( 邹检验) ，可以用 chowtestP 命令快捷地完成

## 3． 小结

引入交乘项来检验某个或某几个变量的系数是否存在组间差异，只需在普通线性回归中加

入交乘项即可，但需要注意这一方法背后隐含的假设条件( 为了便于说明，重新将( 1) 式列出) :

$$
\mathrm{Wage} _ {\mathrm{i}} = \alpha + \gamma \cdot \mathrm{D} _ {\mathrm{i}} + \beta \cdot \text {ttl\_exp} _ {\mathrm{i}} + \delta \left(\mathrm{D} _ {\mathrm{i}} \times \text {ttl\_exp} _ {\mathrm{i}}\right) + \text {Controls} _ {\mathrm{i}} \cdot \gamma + \varepsilon_ {\mathrm{i}}\tag{1}
$$

A1: 所有控制变量的系数在两组之间无差异，即 $\gamma _ { \mathrm { w h i t e } } = \gamma _ { \mathrm { b l a c k } } ;$

A2:两组的干扰项具有相同的分布( 因为估计时是将两组样本混合在一起进行估计的) ，即${ \mathrm { e } } _ { \mathrm { w h i t e } } \sim \mathrm { N } \big ( 0 , \sigma ^ { 2 } \big )$ ，且 $\mathbf { e } _ { \mathrm { b l a c k } } \sim \big ( 0 , \sigma ^ { 2 } \big )$ ，换言之 $\mathbf { \Delta } _ { \mathbf { \hat { \nu } } ^ { 0 } \mathbf { \bar { \nu } } _ { \mathrm { w h i t e } } } = \mathbf { \Phi } _ { \mathbf { \tilde { \nu } } \mathrm { b l a c k } } ^ { 2 }$ 。

因此，当其他变量的系数在两组之间也存在明显差异( A1 不满足) ，或存在异方差( A2 不满足) 时，上述检验方法得到的结果都存在问题<sub>。</sub>

## 4． 解决办法

对于 A1，实际操作过程中，可以通过引入更多的交项来放松 A1，如上文提到的 <sup>“</sup>模型2<sup>”</sup>或<sup>“</sup>模型 3 <sup>”</sup> <sub>。</sub>

对于 A2，则可以在上述回归分析过程中加入 vce( robust) 选项，以便允许干扰项存在异方差; 或加入 vce( cluster varname) 以便得到聚类调整后的稳健型标准误<sub>。</sub>

上述范例中，是以基于截面数据的 OLS 回归为例的，但这一方法也适用于其他命令，如针对面板数据的 xtreg，针对离散数据的 logit，probit 等 <sub>。</sub>

## ( 二) SUEST ( 基于似无相关模型 SUR 的检验)

## 1． 基本思想

顾名思义，所谓的似无相关模型( seemingly unrelated regression) 其实就是表面上看起来没有关系，但实质上有关系的两个模型<sub>。</sub> 这听起来有点匪夷所思<sub>。</sub> 这种 <sup>“</sup>实质上<sup>”</sup>的关系其实是假设白人组和黑人组的干扰项彼此相关 为了表述方便，将白人和黑人组的模型简写如下:

白人组: $\mathrm { y } _ { \mathrm { 1 i } } = \mathrm { x } _ { \mathrm { 1 i } } \big \beta _ { 1 } + \mathrm { e } _ { \mathrm { 1 i } } , \mathrm { i } = 1 , 2 , \cdots , \mathrm { N } _ { 1 }$

( 2a)

黑人组: $\mathrm { y } _ { 2 \mathrm { j } } = \mathrm { x } _ { 2 \mathrm { j } } \beta _ { 2 } + \mathrm { e } _ { 2 \mathrm { j } } , \mathrm { j } = 1 , 2 , \cdots , \mathrm { N } _ { 2 }$

( 2b)

若假设 $\mathrm { c o r r } \big ( \mathrm { \bf ~ e } _ { 1 } , \mathrm { \bf e } _ { 2 } \big ) = 0$ ，则我们可以分别对白人组和黑人组进行 OLS 估计 然而，虽然白人和黑人种族不同，但所处的社会和法律环境，面临的劳动法规都有诸多相似之处，使得二者的干扰项可能相关，即 $\mathrm { c o r r } ( \ \mathrm { e } _ { 1 } , \mathrm { e } _ { 2 } ) \neq 0$ <sub>。</sub> 此时，对两个样本组执行联合估计( GLS) 会更有效率( 详见 Greene( 2012) ，292 －304) 执行完 SUR 估计后，对两组之间的系数差异进行检验

从上面的原理介绍，可以看出，基于 SUR 估计进行组间系数差异检验时，假设条件比第一种方法要宽松一些:

其一，在估计过程中，并未预先限定白人组和黑人组中各个变量的系数相同，因此在(2) 式中，我们分别用 $\beta _ { 1 }$ 和 $\beta _ { 2 }$ 表示白人组和黑人组各个变量的系数向量;

其二，两个组的干扰项可以有不同的分布，即 $\mathbf { e } _ { \mathrm { 1 i } }$ 和 $\mathbf { e } _ { 2 \mathrm { j } }$ 可以不同，即 ${ \bf e } _ { \mathrm { 1 i } } \sim \mathrm { N } \left( \ 0 , { \sigma } _ { 1 } ^ { 2 } \right) , { \bf e } _ { 2 \mathrm { j } } \sim \mathrm { N }$ $\mathbf { \omega } ( 0 , \mathbf { \sigma } \mathbf { \sigma } _ { 2 } ^ { 2 } )$ ，且允许二者的干扰项相关， $\mathrm { , c o r r } ( \ \mathrm { e } _ { 1 } , \mathrm { e } _ { 2 } ) \neq 0$ 。

## 2． Stata 实现方法

在Stata 中执行上述检验的步骤为: (1) 分别针对白人组和黑人组进行估计( 不限于OLS 估计，可以执行 logit，tobit 等估计) ，存储估计结果; ( 2) 使用 suest 命令执行 SUR 估计; ( 3) 使用test 命令检验组间系数差异 范例如下:

```txt
*-Step1: 分别针对两个样本组执行估计
reg wage $xx if black==0
est store w //white
reg wage $xx if black==1
est store b //black
*-Step 2: SUR
suest w b
*-Step 3: 检验系数差异
test [w_mean]ttl_exp = [b_mean]ttl_exp
test [w_mean]married = [b_mean]married
test [w_mean]south = [b_mean]south
```

## ( 三) 费舍尔组合检验 ( Fisher <sup>’</sup> s Permutation test)

## 1． 基本思想

这一方法最早见于 Efron 和 Tibshirani( 1993) ( Section 15． 2，pp． 202) <sub>。</sub> Cleary( 1999) ，连玉君等(2008) ，连玉君等(2010) 等都使用了该方法进行组间系数差异检验<sub>。</sub>

同样以上述<sup>“</sup>白人组<sup>”</sup>和<sup>“</sup>黑人组<sup>”</sup>为例，假设两组的样本数分别为 $\mathbf { n } _ { 1 }$ 和 $\mathbf { n } _ { 2 }$ ，模型设定如下:

$$
\mathrm{y} = \mathrm{x} \beta_ {1} + \mathrm{e} _ {1}\tag{3a}
$$

$$
\mathbf {y} = \mathbf {x} \boldsymbol {\beta} _ {2} + \mathbf {e} _ {2}\tag{3b}
$$

将二者的系数差异定义为 $\mathrm { d } = \{ \mathsf { \Gamma } _ { 1 } - \mathsf { \beta } _ { 2 }$ ，检验的原假设为: $\mathrm { H } _ { 0 } : \mathrm { d } = 0$

我们仍然关注 ttl\_exp 变量在两组之间的系数差异<sub>。</sub> 以表 1 中的结果为例，可以看到，ttl\_$\mathrm { e x p }$ 变量在［white 组］和［black 组］的系数估计值分别为 $0 . 2 5 1 \big ( \hat { \mathsf { \beta } } _ { 1 } \big )$ 和 $0 . 2 6 9 \big ( \hat { \mathsf { \beta } } _ { 2 } \big )$ ，因此，实际观察到的系数差异为 $\mathrm { d } _ { 0 } = \bigl \{ \beta _ { 1 } - \beta _ { 2 } = 0 . 2 5 1 - 0 . 2 6 9 = - 0 . 0 1 8 $

显然 $\mathbf { , d }$ 是一个统计量，若预先知道其分布特征，便可通过分析 $\hat { \mathrm { ~ \bf ~ d ~ } }$ 在 d 的分布中的相对位置来判断我们实际观察到 $\hat { \mathrm { d } } _ { 0 } = - 0 . 0 1 8$ 的概率<sub>。</sub> 若概率很小，则表明 $\mathrm { H } _ { 0 } : \mathrm { d } = 0$ 是小概率事件，此时拒绝原假设，反之则无法拒绝原假设

例如，若假设 d 服从标准正态分布，即 $\mathrm { d } \sim \mathrm { N } \vert 0 , 1 \vert$ ，则基于实际观察到的 $\mathrm { d } _ { 0 } = 0 . 0 1 8$ ，我们很容易得出结论: 无法拒绝原假设，即两组之间的 ttl\_exp 的系数不存在显著差异<sub>。</sub> p －value 很容易计算( 可以通过查表得到) :

```txt
. dis normal(-0.018) //单尾检验
.49281943
```

然而，在实际应用过程中，我们并不知道 d 的分布特征<sub>。</sub> 此时，可以对现有样本进行重新抽样，以得到经验样本( empirical sample) ，进而利用经验样本构造出组间系数差异统计量 d 的经验分布( empirical distribution) ，从而最终得到经验 p 值( empirical p － value)

下面先通过一个小例子说明 <sup>“</sup>经验 p 值<sup>”</sup>和 <sup>“</sup>经验分布<sup>”</sup>的概念，进而介绍使用组合检验获得<sup>“</sup>经验 p 值<sup>”</sup>的流程

## 2． 经验 p 值( empirical p － value)

在这个小例子中，我们先随机生成一个服从标准正态分布的随机数 d，共有10 000 个观察值 这些观察值是通过模拟产生的 如果这些观察值构成的样本是通过从原始样本( 原始样本是从母体中一次随机抽样，称为 <sup>“</sup>抽样样本，sample<sup>”</sup>) 中二次抽样得到的，则称为 <sup>“</sup>经验样本( empirical sample) <sup>”</sup> <sub>。</sub>

然后，我们数一下在这10 000 个随机数中，有多少个是大于( 我们实际观察到的数值) ，命令为 count if d ＜ － 0． 018 <sub>。</sub> 一共有 4 963 个观察值大于，由此可得，经验 p 值 = 4963 /10000 =0． 4963 这与采用 normal( ) 函数得到的结果( 0． 4928) 非常接近

```txt
preserve
    clear
    set obs 10000
    set seed 1357
    gen d = rnormal() // d~N(0,1) 服从标准正态分布的随机数
    sum d, detail
    count if d<-0.018
    dis "Empirical p-value = " 4963/10000
restore
```

## 3． 经验样本 ( empirical sample)

上例中，我们假设 d 服从标准正态分布，从而可以通过 monte carlo 模拟的方式产生10 000个观察值，这事实上是构造了一个经验样本 但多数情况下，我们并不知道 d 的分布特征，此时无法使用 monte carlo 模拟 <sub>。</sub> 然而，若假设抽样样本( sample) 是从母体( population) 中随机抽取的，则可以通过抽样样本中二次抽样得到经验样本( empirical sample) ，这些经验样本也可以视为对母体的随机抽样

若 H 抽样过程中为无放回抽样( sampling with no replacement) ，则相应的检验方法称为 <sup>“</sup>组合检验( permutation test) <sup>”</sup> ; 若抽样过程中为有放回抽样( 也称为可重复抽样，sampling with re-placement) ，则对应的检验方法称为 <sup>“</sup>基于 Bootstrap 的检验<sup>”</sup> <sub>。</sub>

## 4． 费舍尔组合检验的步骤

若 $\mathrm { H } _ { 0 }$ 是正确的，则对于任何一个妇女而言( 不论她是白人还是黑人) ，其x 对y 的边际影响都是相同的<sub>。</sub> 因此，我们可以将白人组和黑人组的观察值混合起来，从中随机抽取 $\mathbf { n } _ { 1 }$ 个观察值，并将其视为<sup>“</sup>白人组<sup>”</sup>，剩下的 $\mathbf { n } _ { 2 }$ 个观察值可以视为 <sup>“</sup>黑人组<sup>”</sup>

Step 0: 分别针对白人组和黑人组估计模型(3a) 和(3b) ，得到系数估计值 $\beta _ { 1 }$ 和 $\beta _ { 2 }$ ，以及二者的系数差异 $\hat { \mathrm { d } } _ { 0 } = \hat { \mathsf { \beta } } _ { 1 } - \hat { \mathsf { \beta } } _ { 2 }$ <sub>2</sub> ;

Step 1: 将白人组和黑人组的样本混合起来，得到 $\mathbf { n } _ { 1 } + \mathbf { n } _ { 2 }$ 个观察值构成的样本 S;

Step 2: 获得经验样本———从S 中随机抽取( 无放回) $\mathbf { n } _ { 1 }$ 个观察值，将其视为<sup>“</sup>白人组<sup>”</sup>( 记为$\mathrm { S w } )$ ，剩下的 $\mathbf { n } _ { 2 }$ 个观察值可以视为 <sup>“</sup>黑人组<sup>”</sup>( 记为 Sb) ;

Step 3: 分别针对经验样本 $\mathrm { S w }$ 和 Sb，估计模型( 3a) 和( 3b) ，得到 $\hat { \mathsf { \beta } } _ { 1 } ^ { \mathrm { s } _ { 1 } }$ 和 β<sup>S</sup>1( 上标 $\mathrm { S } _ { 1 }$ 表示利用第一笔经验样本得到的估计值) ，以及二者的差异 $\mathrm { d } ^ { \mathrm { s _ { 1 } } } = \boldsymbol { \beta } _ { 1 } ^ { \mathrm { s _ { 1 } } } - \boldsymbol { \beta } _ { 2 } ^ { \mathrm { s _ { 1 } } }$ ;

Step 4: 获得统计量 d 的经验分布———将 Step 2 和 Step 3 重复执行 K 次( 如 K = 1 000) ，则可以得到{ $\mathrm { d } ^ { \mathrm { s } _ { 1 } } , \mathrm { d } ^ { \mathrm { s } _ { 2 } } , \cdots , \mathrm { d } ^ { \mathrm { s } _ { 1 0 0 0 } } \}$ ，亦可简记为 $\mathrm { d } ^ { \mathrm { s _ { j } } } \big ( \mathrm { ~ j = 1 ~ } , 2 \mathrm { , ~ } ^ { \dots } , \mathrm { K } \big )$ ;

Step 5: 计算经验 $\mathrm { p }$ 值， $\mathrm  \hat { \ s p } = \frac { \# \{ d ^ { s _ { j } } > d _ { 0 } } { K \} } { K \} }$ ，其中{ $\mathrm { d ^ { s _ { j } } > \hat { d } _ { 0 } } \}$ 表示 Step 4 中得到的 K 个 $\mathrm { d ^ { s _ { j } } }$ 中大于我们实际观测到 $\hat { \mathrm { d } } _ { 0 }$ 的个数<sub>。</sub> 若 $\stackrel { \hat { \mathbf { p } } } { < } 0 . 0 5$ ，则可以在5%水平上拒绝原假设，表明两组的系数差异是显著的<sub>。</sub>

需要说明的是，由于 d<sup>s</sup>j的分布未必是对称的，因此， $\hat { \mathbf { \rho } } _ { \mathbf { 0 } } = 0 . 0 3$ 与 $\mathrm { p } = 0 . 9 7$ 都可以视为在5%水平上拒绝原假设的证据<sub>。</sub> 因为，前者意味着 ${ \mathrm { d } } _ { 0 }$ 在1 000 个 d<sup>sj</sup>中属于非常大的数值，而后者意味着它是非常小的数值<sub>。</sub> 无论如何，在原假设 $\mathrm { H } _ { 0 }$ 下观察到 ${ \mathrm { d } } _ { 0 }$ 都是小概率事件，也就意味着原假设是不合理的<sub>。</sub>

此外，该方法并不局限于普通的线性回归模型( regress 命令) ，可以应用于各种模型的估计命令，如 xtreg，xtabond，logit，ivregress 等 <sub>。</sub>

## 解释和说明:

bdiff 命令中设定 bs 选项，则随机抽样为可重复抽样( bootstrap) ;

first 选项便于将组间系数差异检验结果保存在内存中，方便后续使用 esttab 合并到回归结果表格中<sub>。</sub> 具体使用方法参见 help bdiff<sub>。</sub>

由于抽样过程具有随机性，因此每次检验的结果都有微小差异<sub>。</sub> 在投稿之前，可以附加seed( ) 选项，以保证检验结果的可复制性<sub>。</sub>

其他选项和使用方法参阅 help bdiff的帮助文件<sub>。</sub>

## 三<sub>、</sub>小 结

方法1( 加入交乘项) 在多数模型中都可以使用，但要注意其背后的假设条件是比较严格的 若在混合回归中，只引入关心的变量( ttl\_exp) 与分组变量( black) 的交乘项( ttl\_exp\*black) ，则相当于假设其他控制变量在两组之间不存在系数差异<sub>。</sub> 相对保守的处理方法是: 在混合估计时，引入所有变量与分组变量的交乘项，同时附加 vce( robust) 选项，以克服异方差的影响<sub>。</sub>

方法2( 基于 SUR 模型的检验) 执行起来也比较方便，假设条件也比较宽松: 允许两组中所有变量的系数都存在差异，也允许两组的干扰项具有不同的分布，且彼此相关 局限在于，有些命令无法使用 suest 执行联合估计，如几乎所有针对面板数据的命令都不支持( xtreg，xtabond等) <sub>。</sub>

方法3( 组合检验) 是三种方法中假设条件最为宽松的，只要求原始样本是从母体中随机抽取的( 看似简单，但很难检验) ，而对于两个样本组中干扰项的分布，以及衡量组间系数差异的统计量 $\mathrm { d } = \{ \mathsf { \beta } _ { 1 } - \mathsf { \beta } \mathsf { \beta } _ { 2 }$ 的分布也未做任何限制 事实上，在获取经验 p 值的过程中，我们采用的是<sup>“</sup>就地取材<sup>” “</sup>管中窥豹<sup>”</sup>的思路，并未假设 d 的分布函数; 另一个好处在于可以适用于各种命令，如 regress，xtreg，logit，ivregress 等，而 suest 则只能应用于部分命令 <sub>。</sub>

方法无优劣<sub>。</sub> 无论选择哪种方法，都要预先审视一下是否符合这些检验方法的假设条件<sub>。</sub>
