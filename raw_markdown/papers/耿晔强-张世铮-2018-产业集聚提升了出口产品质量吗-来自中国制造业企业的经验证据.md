# 产业集聚提升了出口产品质量吗？来自中国制造业企业的经验证据

耿晔强 张世铮

摘要 <sub>：</sub> 在构建产业集聚与出口产品质量理论模型的基础上 基于2000 2007年中国工业企业数据和海关贸易数据 采用需求方程反推法对企业出口产品质量进行测算 考察产业集聚对企业出口产品质量的影响研究结果显示 在总体层次上 产业集聚对企业出口产品质量具有显著的促进作用 在区分企业类型后发现 产业集聚能够显著提升私营和外资企业 加工贸易企业 东部地区企业的出口产品质量 对国有企业一般贸易企业 中西部地区企业出口产品质量的影响则较小

关键词 <sub>：</sub> 产业集聚 <sub>；</sub> 出口产品质量 <sub>；</sub> 异质性企业 <sub>；</sub> 制造业

## 一<sub>、</sub>引言

改革开放特别是加入 WTO以来 中国对外贸易实现了<sup>“</sup>奇迹式<sup>”</sup>增长 货物贸易出口额从2001年的2661亿美元增长到2015年的22765亿美元 年均增速16<sub>．</sub>6％ 占世界出口总额比重从2001年的4<sub>．</sub>3％上升到2015年的13<sub>．</sub>8％ 中国已成为世界第一大出口国 然而 伴随着劳动力等生产要素成本不断上升 资源和环境约束逐步加强 加之世界经济复苏缓慢 国际需求不振 中国外贸发展面临严峻形势 下行压力较大 与此同时 中国出口企业大多存在自主创新能力较弱 品牌产品占比偏低同质化竞争较为普遍等问题 在国际分工和全球价值链中总体仍处于中低附加值环节 因此 中国主要依靠价格优势和数量扩张的传统外贸增长方式难以为继 如何实现外贸发展方式转型升级是亟待解决的现实问题 而产品质量是刻画外贸竞争力的一个重要维度 不仅体现企业核心竞争力（M<sub>anova</sub>和Zh<sub>an</sub> 2012）① 也是一国贸易乃至经济发展的前提（Amiti和 Kh<sub>an</sub>d<sub>e</sub>l<sub>wa</sub>l2013）② 提高出口产品质量是实现出口企业从成本优势向质量优势转变 贸易发展方式从数量扩张型向质量效益型转变 中国由贸易大国升级为贸易强国的必由之路

那么 到底是何因素能够影响出口产品质量？国内外学者从不同的方面进行了研究 一是围绕生产投入要素展开 对于物质资本 S<sub>c</sub>h<sub>o</sub>tt（2004）③ 基于美国产品层面进口数据的实证研究发现资本越丰富的国家越倾向于出口高质量产品 施炳展等（2013）④ 还考察了资本密集度对中国企业出口产品质量的影响 对于人力资本 Ab<sub>ow</sub>d等（1995）⑤基于法国企业数据的分析指出人力资本与产品质量呈现正相关关系 这一结论也得到了 S<sub>c</sub>h<sub>o</sub>tt（2004） V<sub>er</sub>h<sub>oogen</sub>（2008） ① 李坤望和王有鑫（2013） ②的研究支持 二是从外部经济环境因素出发 融资约束是制约企业提高出口产品质量的重要因素之一 质量升级的前期投资在长期才能获得更高的回报（Sh<sub>a</sub>i<sub>ro</sub>1983） ③ 然而债务融资使得投资倾向于短期项目（P<sub>eyer</sub>和Shi<sub>v</sub>d<sub>asan</sub>i2001） ④ 因此面临融资约束的公司进行质量升级的动机较弱 此外<sub>，</sub>一些学者还考察了FDI与产品质量的关系 H<sub>ar</sub>di<sub>ng</sub>和J<sub>avorc</sub>ik（2011） ⑤首次使用跨国面板数据考察了FDI与出口产品质量的关系 他们发现FDI对发展中国家的出口产品质量有积极促进效应 对发达国家则不存在这一效应 李坤望和王有鑫（2013）针对中国26个工业行业的研究表明FDI有助于中国出口产品质量升级 还有文献探讨了汇率对产品质量的影响 A<sub>w</sub> 和 R<sub>o</sub>b<sub>er</sub>t<sub>s</sub>（1986） ⑥指出汇率升值会降低企业的价格竞争力 <sub>，</sub>促使企业进行产品质量升级<sub>。</sub> 其他学者 V<sub>er</sub>h<sub>oogen</sub>（2008）及Ch<sub>en</sub>和J<sub>uvena</sub>l（2013） ⑦的实证分析也都得到了类似的结论 三是从政策上展开 较有代表性的是 Amiti和Kh<sub>an</sub>d<sub>e</sub>l<sub>wa</sub>l（2013）的研究 他们发现最终品关税和质量水平呈现非线性关系 随后 F<sub>an</sub>等（2015） ⑧聚焦于投入品关税 考察了投入品关税对出口产品质量的影响 另外 政府补贴也是影响产品质量的重要因素 Zh<sub>ou</sub>等（2002） ⑨基于博弈模型的分析表明补贴能够带来产品质量提升 Shi<sub>n</sub>和 Kim（2010） 瑏瑠进一步把补贴方式区分为三种类型 分别检验了三种补贴对于产品质量提升的有效性

有关出口产品质量影响因素的研究已经取得了丰富的成果 然而既有文献大多忽略了产业集聚在其中所起的作用 随着经济全球化的深入发展和国际专业化分工的日趋细化 产业集聚成为当今世界经济发展的一个重要特征 中国的产业集聚现象也越来越普遍 涌现出一批发展良好 规模较大的产业集群 虽然现有文献已从出口密集度 出口参与或出口二元边际等角度考察了集聚与企业出口行为的关系 但鲜有文献研究产业集聚对企业出口产品质量的微观影响 因此 本文对现有文献的有益补充主要体现在 第一 本文将产业集聚与出口产品质量纳入统一的分析框架 构建理论模型探讨了产业集聚对企业出口产品质量的影响 是对出口产品质量研究领域的一个有益补充<sub>；</sub> 第二 基于中国工业企业数据和海关数据的匹配数据 本文首次从微观层面对产业集聚与出口产品质量的关系进行了实证检验 提供了来自中国的经验证据 <sub>；</sub>第三 考虑到企业异质性 本文还按照所有制类型 贸易方式 地区分布进行了分样本回归 考察了产业集聚对不同类型企业出口产品质量影响的差异性深化了我们对产业集聚与出口产品质量关系的认识

## 二<sub>、</sub>理论模型

本文借鉴C<sub>roze</sub>t和K<sub>oen</sub>i<sub>g</sub>（2005） ①的分析框架 构建理论模型考察产业集聚对企业出口产品质量的影响

## （一）消费者行为

出口来源国表示为 b 出口目的国表示为 d 其中 $b , d \in { 1 , \cdots , N }$ 我们把产品质量嵌入 d 国消费者的CES效用函数<sub>，</sub>如下式 <sub>：</sub>

$$
U = \left\{\int_ {\omega \in \Omega} [ \lambda (\omega) q (\omega) ] ^ {(\sigma - 1) / \sigma} d \omega \right\} ^ {\sigma / (\sigma - 1)}\tag{1}
$$

其中 $, \omega$ 表示最终产品 Ω 表示 $d$ 国消费者可购买到的最终产品集合 包括来自 b 国厂商的出口产品和国内厂商生产的产品 <sub>σ</sub> 表示不同产品间的常数替代弹性 且 $\sigma { > } 1 , q ( \omega )$ 表示 d 国消费者对产品 $\omega$ 的消费量<sub>，</sub> $\lambda ( \omega )$ 表示 d 国消费者所消费的产品 $\omega$ 的质量水平<sub>。</sub>

根据消费者效用最大化条件 可得 d 国消费者对某特定厂商产品 的总需求量为

$$
q (\omega) = \lambda (\omega) ^ {\sigma - 1} p (\omega) ^ {- \sigma} P ^ {\sigma - 1} Y\tag{2}
$$

其中 $\scriptstyle { p ( \omega ) }$ 表示 d 国消费者购买产品 $\omega$ 的价格 $P = { \scriptstyle \int \int _ { \omega \in \Omega } } [ { \boldsymbol { \phi } } ( \omega ) / q ( \omega ) ] ^ { 1 - \sigma } d \omega \} ^ { 1 / ( 1 - \sigma ) }$ 表示 d 国加总的价格指数 Y 表示d 国的总收入

## （二）厂商行为

假定 b 国的市场结构为垄断竞争市场 厂商进入或退出一个行业是自由的 不同厂商拥有不同的生产率 每个厂商在规模收益递增条件下使用单一要素劳动力生产差异化产品 其中出口厂商生产 $\varphi _ { i }$ 的产品会全部对 d 国出口 本文以 表示厂商所在地区 k 行业 的集聚程度 产业集聚主要通过直 $\rho _ { k j }$ 接渠道和间接渠道降低厂商的生产经营成本 直接渠道指的是经济活动的集聚使得厂商之间分工协作密切 还可以共担基础设施 共享劳动力市场 这种规模效应能大大降低厂商的成本 而且空间上的邻近使得厂商间频繁交流成为可能 降低了厂商的信息成本 间接渠道是指产业集聚通过知识或技术的外溢能够推动厂商进行技术创新从而提高生产效率（即 $\partial \varphi _ { i } / \partial \rho _ { k j } > 0 )$ 进而影响厂商的成本 综合上述考虑 本文把 b 国生产率为 $\varphi _ { i }$ 的出口厂商i 的成本函数设定为

$$
C _ {i} = \frac {w x _ {i}}{\varphi_ {i} \rho_ {k j}} + \alpha
$$

（3）

其中 为 b 国的工资水平 $x _ { i }$ 为厂商i 生产的产品产量 为固定成本 固定成本 既包括生产所需的固定投入 如建筑物和机器设备的折旧费等 还包括出口所需的固定投入成本 例如进入出口市场所投入的沉没成本和留在出口市场的维持成本等

在 b 国 每个厂商都存在规模收益递增并生产差异化产品 加之消费者对多样化产品的偏好 这意味着没有厂商会选择生产其他厂商生产的同种产品 因而每种产品只会由单独一个厂商生产 另外 假定在 d 国价格指数给定的情况下 b 国的出口厂商都选定自己的产品价格 那么 b 国出口厂商所面临的需求价格弹性等于d 国不同产品间的常数替代弹性<sub>σ</sub> 基于此 b 国出口厂商 i 在出口产品到d 国时 其最优决策为 <sub>：</sub>

$$
\mathrm{man} \pi_ {i} = (p _ {i} - \frac {w \tau}{\varphi_ {i} \rho_ {k j}}) \lambda_ {i} ^ {\sigma - 1} p _ {i} ^ {- \sigma} P ^ {\sigma - 1} Y - \alpha\tag{4}
$$

其中<sub>，τ</sub> 表示出口的冰山成本 由（4）可得<sub>，</sub>在利润最大化条件下<sub>，</sub>b 国出口厂商i 出口产品<sub>ω</sub> 的最优定价和最优产量分别为

$$
p _ {i} = \frac {w \tau}{\varphi_ {i} \rho_ {k j}} \frac {\sigma}{\sigma - 1}\tag{5}
$$

$$
x _ {i} = \lambda_ {i} ^ {\sigma - 1} P ^ {\sigma - 1} Y \left[ \frac {w \tau}{\varphi_ {i} \rho_ {k j}} \left(\frac {\sigma}{\sigma - 1}\right) \right] ^ {- \sigma}\tag{6}
$$

将之带入（4）式进而可得企业的最大化利润为 <sub>：</sub>

$$
\pi_ {i} = \frac {1}{\sigma - 1} (\frac {\sigma}{\sigma - 1}) ^ {- \sigma} (\frac {w \tau}{\varphi_ {i} \rho_ {k j}}) ^ {1 - \sigma} \lambda_ {i} ^ {\sigma - 1} P ^ {\sigma - 1} Y - \alpha\tag{7}
$$

当允许厂商自由进入或退出一个行业时 可以知道厂商在实现均衡时利润必定为0 由此可得 b国出口厂商i 生产产品 $\omega$ 的均衡产量为 <sub>：</sub>

$$
x _ {i} = \frac {\alpha \varphi_ {i} \rho_ {k j} (\sigma - 1)}{w \tau}\tag{8}
$$

## （三）均衡 <sub>：</sub>产业集聚与出口产品质量的关系

接着我们讨论模型的均衡 由于本文假设 b 国每个出口厂商生产的产品会全部对 d 国出口<sub>，</sub>因此 b 国出口厂商均衡时的产品产量即为其均衡时的产品出口量 在市场均衡时 有 b 国出口厂商 i 对产品<sub>ω</sub> 的出口量等于 $d$ 国消费者对厂商i $\arctan$ 品 $\omega$ 的需求量 也可以说 b 国出口厂商 i 生产的产品<sub>ω</sub>的产量等于d 国消费者对厂商i 产品 $\omega$ 的需求量 即 $x _ { i } \left( \omega \right) { = } q _ { i } \left( \omega \right)$ 可以得到 <sub>：</sub>

$$
\frac {\alpha \varphi_ {i} \rho_ {k j} (\sigma - 1)}{w \tau} = \lambda_ {i} ^ {\sigma - 1} p _ {i} ^ {- \sigma} P ^ {\sigma - 1} Y\tag{9}
$$

整理得 <sub>：</sub>

$$
\begin{array}{r l} \lambda_ {i} & = \frac {\alpha^ {\frac {1}{\sigma - 1}} (\sigma - 1) ^ {\frac {1}{\sigma - 1}} p _ {i} ^ {\frac {\sigma}{\sigma - 1}} \varphi_ {i} ^ {\frac {1}{\sigma - 1}} \rho_ {k j} ^ {\frac {1}{\sigma - 1}}}{P ^ {\frac {\sigma - 1}{\sigma - 1}} Y ^ {\frac {1}{\sigma - 1}} w _ {\sigma - 1} ^ {\frac {1}{\sigma - 1}} \tau^ {\frac {1}{\sigma - 1}}} \\ & = \frac {1}{P} [ \frac {\alpha (\sigma - 1)}{Y w \tau} ] ^ {\frac {1}{\sigma - 1}} p _ {i} ^ {\frac {\sigma}{\sigma - 1}} \varphi_ {i} ^ {\frac {1}{\sigma - 1}} \rho_ {k j} ^ {\frac {1}{\sigma - 1}} \end{array}\tag{10}
$$

由（10）式对集聚程度 $\rho _ { \mathrm { k j } }$ 求偏导 则有 <sub>：</sub>

$$
\begin{array}{l} \frac {\partial \lambda_ {i}}{\partial \rho_ {k j}} = \frac {1}{P} \left[ \frac {\alpha (\sigma - 1)}{Y w \tau} \right] ^ {\frac {1}{\sigma - 1}} p _ {i} ^ {\frac {\sigma}{\sigma - 1}} \left[ \left(\varphi_ {i} ^ {\frac {1}{\sigma - 1}}\right) ^ {\prime} \rho_ {k j} ^ {\frac {1}{\sigma - 1}} + \varphi_ {i} ^ {\frac {1}{\sigma - 1}} \left(\rho_ {k j} ^ {\frac {1}{\sigma - 1}}\right) ^ {\prime} \right] \\ = \frac {1}{P} \left[ \frac {\alpha (\sigma - 1)}{Y w \tau} \right] ^ {\frac {1}{\sigma - 1}} p _ {i} ^ {\frac {\sigma}{\sigma - 1}} \frac {1}{\sigma - 1} \left(\frac {\partial \varphi_ {i}}{\partial \rho_ {k j}} \varphi_ {i} ^ {\frac {2 - \sigma}{\sigma - 1}} \rho_ {k j} ^ {\frac {1}{\sigma - 1}} + \varphi_ {i} ^ {\frac {1}{\sigma - 1}} \rho_ {k j} ^ {\frac {2 - \sigma}{\sigma - 1}}\right) > 0 \end{array}\tag{11}
$$

据此 我们可以得出结论 出口厂商所处的地区和行业集聚程度越高 其出口产品质量越高 由此本文从理论层面证实了产业集聚对企业出口产品质量的正向影响

## 三 模型 变量与数据

## （一）计量模型的设定

根据本文的理论框架 我们构建如下计量模型

$$
\ln q u a l i t y _ {i j k t} = a _ {0} + a _ {1} \ln l q _ {j k t} + a _ {2} Z _ {i j k t} + \nu_ {j} + \nu_ {k} + \nu_ {t} + \varepsilon_ {i j k t}\tag{12}
$$

其中 下标 $i , j , k , t$ 分别表示企业 行业 地区 年份 $q u a l i t y _ { i j k t }$ 表示企业出口产品质量<sub>，</sub> $l q _ { j k t }$ 表示企业所处地区和行业的产业集聚程度 $Z _ { i j k t }$ 为控制变量集合 此外 $\cdot \nu _ { j } \setminus \nu _ { k } \setminus \nu _ { t }$ 分别表示行业 地区以及年份固定效应 $\mathfrak { E } _ { i j k t }$ 是随机扰动项

## （二）变量说明

1<sub>．</sub>产业集聚的测度 本文选用区位熵来衡量产业集聚程度 其计算公式为

$$
l q _ {j k t} = \frac {x _ {j k t} / x _ {k t}}{x _ {j t} / x _ {t}}\tag{13}
$$

其中 $l q _ { j k t }$ 为t 期地区 k 行业j 的区位熵 $\boldsymbol { \mathcal { X } } _ { j k t }$ 为地区 k 行业j 的就业人数 $\mathcal { X } _ { k t }$ 为地区 k 的就业人数 $\boldsymbol { \mathcal { X } } _ { j t }$ 为行业j 的就业人数 <sub>x</sub> 为全国的总就业人数 在地理单元上 考虑到城市是经济活动集聚的基本单位<sub>，</sub>并参考大多数研究集聚的文献做法 <sub>，</sub> 本文将地区界定为城市① 对于行业范围 <sub>，</sub> 已有研究大多仅到二分位 本文则拓展到三分位和四分位 更为细致的行业划分有利于更准确的考察产业集聚与出口产品质量的关系 综上 本文计算了三种行业分类标准下城市<sub>－</sub>行业层面的区位熵

2<sub>．</sub>出口产品质量的测度 本文使用 Kh<sub>an</sub>d<sub>e</sub>l<sub>wa</sub>l等（2013） ②的需求方程反推法对企业出口产品质量进行测算 首先根据（2）式可得 <sub>：</sub>

$$
q _ {i h c t} = \lambda_ {i h c t} ^ {\sigma - 1} p _ {i h c t} ^ {- \sigma} P _ {c t} ^ {\sigma - 1} Y _ {c t}\tag{14}
$$

其中 下标 h 代表企业出口的 HS6位编码产品 <sub>c</sub> 代表出口目的国 据上可知 $q _ { i h c t } \mathrm { ~ . ~ } p _ { i h c t } \mathrm { ~ . ~ } \lambda _ { i h c t }$ 分别表示t 期出口目的国 <sub>c</sub> 的消费者购买企业i 生产的产品h 的数量 价格和质量 或者说 $q _ { i h c t } \ 、 \ P _ { i h c t } \ 、 \lambda _ { i h c t }$ 分别代表t 期企业i 生产的产品h 在出口目的国 <sub>c</sub> 的出口数量 出口价格和出口产品质量

对（14）式两边取自然对数 有 <sub>：</sub>

$$
\ln q _ {i h c t} + \sigma \ln p _ {i h c t} = \mu_ {h} + \mu_ {c t} + \varepsilon_ {i h c t}\tag{15}
$$

其中 $, \ d \mu _ { h }$ 代表产品固定效应 $, \mu _ { d }$ 代表国家<sub>－</sub>年份固定效应 $\varepsilon _ { i h c t }$ 为残差项 且满足 $\varepsilon _ { i h c t } = ( \sigma ^ { - } 1 ) \lambda _ { i h c t }$

然后通过OLS法对方程式（15）回归得到残差值 $\varepsilon _ { i h c t }$ <sub>，</sub>求得残差后可通过（16）式得到企业<sub>－</sub>产品国家<sub>－</sub>年份层面的出口产品质量 <sub>：</sub>

$$
\text { quality } _ {i h c t} = \hat {\lambda} _ {i h c t} = \frac {\hat {\varepsilon} _ {i h c t}}{\sigma - 1}\tag{16}
$$

根据B<sub>ro</sub>d<sub>a</sub>等（2006） ③的估算<sub>，</sub>本文假设产品之间的替代弹性值<sub>σ</sub> 为4和8 为了便于比较<sub>，</sub>本文利用（17）式进行标准化处理

$$
\text { quality\_normal } _ {i h c t} = \frac {\text { quality } _ {i h c t} - \text { minquality } _ {i c t}}{\text { maxquality } _ {i c t} - \text { minquality } _ {i c t}}\tag{17}
$$

式（17）中<sub>，</sub>mi<sub>nqua</sub>lit<sub>yict 、</sub>m<sub>axqua</sub>lit<sub>yict</sub>分别表示某一产品在所有年份<sub>、</sub>所有企业<sub>、</sub>所有出口目的国的出口产品质量最小值和最大值 在此基础上 本文以出口额比例为权重 把企业<sub>－</sub>产品<sub>－</sub>国家<sub>－</sub>年份层面的出口产品质量加总到企业<sub>－</sub>年份层面 计算公式如下

$$
q u a l i t y _ {i t} = \sum \frac {\text { value } _ {i h c t}}{\sum \text { value } _ {i h c t}} \text { quality\_normal } _ {i h c t}\tag{18}
$$

其中<sub>，</sub> $\tau a l u e _ { i h c i }$ 表示t 期企业i 出口到出口目的国 <sub>c</sub> $\nsim$ 品h 的金额

3<sub>．</sub>控制变量的选取<sub>。</sub> （1）人力资本（h<sub>u</sub>m<sub>an</sub>） <sub>，</sub>用职工教育费与全部从业人员年平均人数的比值来测度 （2）资本密集度（<sub>cap</sub>it<sub>a</sub>l） <sub>，</sub>用固定资产净值年平均余额与全部从业人员年平均人数的比值进行衡量 （3）企业年龄（<sub>age</sub>） 用当年年份与成立年份的差值进行计算 （4）融资约束（fi<sub>nance</sub>） 本文使用流动比率作为融资约束的衡量指标 其计算方法为流动资产减去流动负债再除以总资产 （5）研发投入（<sub>r</sub>d） 本文引入企业研发投入虚拟变量 当企业有研发投入时将其赋值为1 否则为0

## （三）稳健性检验

为了保证估计结果的可靠性 本文从以下四个方面进行稳健性检验 第一 改变出口产品质量指标 采用单位价值法来测度出口产品质量 第二 剔除异常样本 将样本按照区位熵指数从高到低排序 计算出95％分位数 然后把区位熵高于95％分位数的样本予以剔除 第三 处理内生性问题 选取产业集聚及人力资本变量的滞后一期作为工具变量 DWH检验在5％的显著性水平上拒绝了解释变量没有内生性的原假设 在此基础上采用两阶段最小二乘法（2SLS）进行估计 第四 对研发投入非零的子样本进行估计 用研发投入额与工业销售产值的比值作为研发的代理指标 结果见表5和表6 与前文汇报回归结果的逻辑一致 稳健性检验也分别呈现了二分位 三分位及四分位行业区位熵的回归结果①

## 五<sub>、</sub>结论与建议

本文通过构建理论模型 从理论层面证明了产业集聚对企业出口产品质量的正向促进作用 进一步<sub>，</sub>本文运用2000 2007年中国工业企业数据和海关数据对产业集聚与企业出口产品质量的关系进行了实证检验 结果表明<sub>，</sub>产业集聚对中国制造业企业出口产品质量具有显著的提升作用 控制变量中 人力资本 研发投入 资本密集度对企业出口产品质量有促进作用 融资约束则对企业出口产品质量有抑制作用 而企业年龄对企业出口产品质量的影响不确定 此外 产业集聚对企业出口产品质量的影响会因企业类型的差异而有所不同 具体而言 （1）从所有制性质来看 产业集聚对私营和外资企业出口产品质量有显著的促进作用 对国有企业出口产品质量则没有明显促进作用 <sub>；</sub> （2）从贸易方式来看 一般贸易企业出口产品质量受到产业集聚的影响较小 而加工贸易企业的出口产品质量受到产业集聚的影响较大 （3）从所处地区来看 产业集聚对东部地区企业出口产品质量有显著的提升效应 对中西部地区企业出口产品质量则没有明显影响

基于研究结论 本文提出以下政策建议 第一 引导各类型企业集聚发展 改善集聚条件 完善服务功能 同时鼓励发展先进制造业 新兴产业集群 增强集聚效应 特别是要充分发挥中小企业的集聚效应 来加快出口产品质量提升 第二 进一步加强加工贸易产业集群的环境建设 服务水平提升和管理制度完善 加快加工贸易转型升级步伐 不断延伸产业链 从而增强加工贸易产业集群的溢出效应 促进加工贸易企业出口产品质量不断提升 第三 加强中西部地区基础设施建设 人力资本积累 投资环境改善 为要素流动 产业集聚打好基础 另一方面要支持中西部地区因地制宜承接产业转移 促进承接产业集中布局 提高中西部地区的集聚水平 以发挥出产业集聚对中西部地区出口产品质量的提升效应
