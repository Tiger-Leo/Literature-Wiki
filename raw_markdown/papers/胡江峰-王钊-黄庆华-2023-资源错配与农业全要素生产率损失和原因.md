## 二、农业资源错配机理解析

在农业部门中ꎬ由于受到政策、税收、气候等摩擦性因素的影响ꎬ使得土地和劳动力无法被转移到生产率更高的用途ꎬ造成土地、劳动力以及其他资源错配ꎬ不利于农业经济增长(Restuccia 等ꎬ2017)ꎮ

## (一)土地错配

相关文献表明 如果土地产权不明 市场无法有效运转 那么就会给土地的分配 流转和用途带来诸多限制ꎬ进而造成土地错配ꎮ Adamopoulos 等(2020)研究了菲律宾 1988 年土地改革政策ꎬ发现该土改政策规定了土地持有上限 将高于上限的土地重新分配给无地家庭和小农家庭 严重限制了重新分配的农田的可转让性ꎬ造成土地错配ꎬ并使得土地改革平均降低了 34％的土地规模ꎮ Le(2020)发现如果越南 稻米土地指定政策 限制特定土地只能种植水稻 使得农户无法按照市场机制灵活配置土地规模和用途ꎬ从而导致了土地错配ꎮ 近年来ꎬ也有学者研究了中国土地错配的原因ꎬ尤其是在工业化、城市化进程加快的阶段ꎬ中国地方政府通过扭曲的土地出让价格政策ꎬ以较低的价格征用土地ꎬ而用较高的价格出让商业用地ꎬ导致土地错配(邓楚雄等ꎬ2021)ꎮ

在农业领域 由政府主导下的劳动 土地和资本存在严重的错配 朱喜等 其中在家庭承包责任制下 农村土地进行平均分配 忽略了农业在农业生产率上的差异 使得中国农村的土地资源错配程度随着时间的推移呈恶化趋势( Chari 等ꎬ2021ꎻGao 等ꎬ2021ꎻ盖庆恩等ꎬ2021ꎬ2017)ꎮ Zhao发现中国政府 年颁布的 农村土地承包法 禁止土地重新分配 缓解了劳动力错配 但同时也降低了农民土地外包的意愿 从而加剧了土地错配 中国新一轮的农村土地承包经营权确权登记颁证试点于 年启动 但仍然存在 被确权 确空权 等问题 阻碍了土地流转 林文声等朱文清等 等 发现即使土地完成了确权 但如果土地市场不完善 土地价格差异过大 市场机制不健全 仍然会造成土地错配 此外 近年来随着农村土地经营权规模化流转溢价不断提高 增加了土地流转的成本 抑制了适度规模经营的需求 梁伟 祝国平等从而使得土地无法配置到效率较高的一方

## (二)劳动错配

有学者发现中国农业还存在较为严重的劳动力错配 等 认为中国城乡二元结构阻碍了劳动力向生产率更高的非农部门转移 如果消除农民职业选择的扭曲 户籍限制 那么农业生产率较低的劳动力将会向非农部门转移 而生产率较高的劳动力则会留在农业部门 从而会放大纠正土地错配对农业 的增进效应 等 近年来 与户籍制度相关的改革加快推进 劳动力流动的政策环境也明显改善 劳动力可以自由在城市和非农产业进行选择 蔡昉然而 由户籍制度差异而引致的住房 医疗 保险 教育等的社会福利差异 仍然使得劳动力在不同地区流动受到限制 郑宏运等 朱喜等 劳动者无法选择最适合自身的工作 从而导致劳动错配 等 巫强等 证明了中国劳动力流动存在省际边界壁垒 从而使不同区域 产业间劳动力要素资源边际收益不等 扭曲了要素的配置效率 导致宏观经济失衡 降低中国的全要素生产率 赵连阁等 此外 也有研究表明 同工不同酬 解雇成本也会使得劳动力市场发生扭曲 从而造成劳动力错配 等 等

## (三)其他要素错配

实际上 现有关于农业资源错配的文献主要集中在土地和劳动错配的研究上 而对机械和化肥错配的研究相对较少 但考虑到 要素之间存在互补和替代关系 从而不难判断当劳动力和土地存在错配时其他资源的配置情况 一般认为 在中国现行户籍制度下 进入到城市就业的农村劳动力仍然保有耕地 并兼职农事生产活动 导致土地难以流转集中 限制了农业投入 等 以及机械对劳动的替代 郑旭媛等 从而导致农业机械配置不足 为了维持粮食产量 农户往往倾向于在单位面积土地上追加更多的相对廉价的化肥以弥补劳动投入不足(Wang 等ꎬ2019ꎻ侯孟阳等ꎬ2021)ꎬ这也使得化肥配置过量ꎬ造成 TFP 损失ꎮ 此外ꎬ长期以来的宏观发展政策存在城市偏向ꎬ使得农业部门在国民经济和资源配置上都处于相对弱势地位 郑宏运等 造成农业资本投入不足和配置不当ꎬ不利于 TFP 提升ꎮ

## (二)全要素生产率加总

省域层面加总 当存在市场摩擦的情况下 不同地级市面临着差异化的要素市场扭曲 从而使得每个地级市的要素边际收益存在差异 长期以来 由于城乡二元结构导致了劳动市场扭曲$( \tau _ { \mathrm { i } } ^ { \mathrm { N } } )$ 盖庆恩等 家庭联产承包责任制 土地市场不健全等因素造成了土地市场扭曲 $( \tau _ { \mathrm { i } } ^ { \mathrm { L } } )$ (Zhaoꎬ2020ꎻ盖庆恩等ꎬ2021ꎬ2017)ꎬ农业资本市场不健全导致资本市场扭曲 $( \tau _ { \mathrm { i } } ^ { \mathrm { u } } )$ ꎬ化学农资补贴导致了化肥市场扭曲 $( \tau _ { \mathrm { i } } ^ { \mathrm { F } } )$ 一般来说 如果各要素市场的扭曲无法得到消除或抵消那么就会使得资源无法配置到最优水平ꎬ即资源错配ꎮ

由前述分析可知 各省间的资源错配贡献了总体 大部分损失 然而 考虑到各省之间由于存在资源禀赋 气候 空间距离上的差异可能会限制资源跨省流动 基于此 本文将总样本分别按照资源禀赋差异和空间地理距离远近进行分组 进而估算不同分组下的 损失

资源禀赋分组下的错配损失 本文参考龚斌磊 以土地与劳动之比来衡量资源禀赋并根据 个地级市的年均资源禀赋将总体样本划分为 个子样本组 进而测算 损失 由表可知 在 年 中国农业总体错配 损失为 略高于按省分组的 从组内错配损失和组间错配损失对比来看 组内错配损失为 而组间错配损失仅为 表明总体错配损失主要来源于资源禀赋相似组的内部 这是因为资源禀赋相似的地区无法进行优势互补 从而使得组内错配损失较高 与此相反 不同分组可通过各自在资源禀赋上的差异进行优势互补 实现资源有效配置 降低 损失
