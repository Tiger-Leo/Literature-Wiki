# 机构投资者<sub>、</sub> 税收征管与企业避税

蔡宏标 饶品贵

( 暨南大学管理学院 <sup>510632</sup>)

【摘要】 本文研究机构投资者对企业避税的因果关系影响 有鉴于机构投资者和企业避税之间的内生性问题，本文选择机构投资者与被投资上市公司之间的空间距离作为机构持股的工具变量，我们发现在控制内生性之后，机构投资者对企业避税行为仍然存在明显的制约作用; 进一步研究发现机构投资者与税收征管在避税上存在互为补充的关系，同时机构投资者能通过抑制企业避税提升公司价值，而这一效应在税收征管强的地区更为明显。本文提供了机构投资者对企业避税影响的因果关系证据，从而拓展了机构投资者公司治理作用的文献，对于抑制管理层的机会主义倾向和治理企业避税也有重要的实践意义

【关键词】 机构投资者 税收征管 避税 内生性 企业价值

## 一<sub>、</sub> 引言

随着我国资本市场的持续发展，我国已经发展出多层次的机构投资者，包括投资基金 社保基金 <sup>QFII</sup> 保险和券商等，机构投资者已经成为资本市场的重要力量 根据 <sup>《</sup>深交所多层次资本市场上市公司<sup>2012</sup> 年报实证分析报告<sup>》</sup> 统计，截止<sup>2012</sup> 年底，深交所上市公司中机构投资者持股比例超过 <sup>10%</sup>的公司有 <sup>449</sup> 家，占比 <sup>29.19%</sup>; 机构164 <sub>，</sub> 114家上市公司中占有董事席位 这表明，机构投资者不仅在上市公司有较高的持股比例，而且他们也通过各种方式积极地参与公司治理

机构投资者由于具有较强的信息处理能力通过资源和专业知识优势有效监控公司管理层的行为并影响公司决策从以往研究来看，机构投资者能抑制管理层的机会主义动机，并减少企业盈余管理行为 ( 薄仙慧和吴联生，<sup>2009</sup>;Chung et al． <sub>，</sub>2002<sub>) 提高公司整体的盈余质量 (</sub> Velury<sup>and Jenkins</sup>，<sup>2006</sup>) 识别市场的交易异象 ( 饶品贵和姜国华，<sup>2008</sup>) 能够提高股票市场的定价效率 ( 王亚平等，<sup>2009</sup>) 约束内部人的自利行为，从而促使公司披露更多高质量的信息 ( <sup>Koh</sup>，<sup>2003</sup>) ，提高公司的现金股利发放水平( Moh'd，1995 ) ，<sub>并 最 终 提 高 公 司 会 计 业 绩</sub> ( Ryan andSchneider<sub>，</sub>2002<sub>) 和提升公司价值 (</sub> McConnell and Servaes<sub>，</sub>1990<sub>)</sub>

但是机构投资者能否制约企业的避税行为，文献却得到不同的研究结论 一方面有研究 ( <sup>Cheng et al．</sup> ，<sup>2013</sup>)表明机构投资者借助自身专业知识和资源，通过避税方式能增加公司价值，机构持股越高的公司税收政策越激进另一方面有文献则认为机构投资者持股能有效制约企业避税行为 ( 陈冬和唐建新，<sup>2013</sup>) ，其原因在于避税过程是存在成本的。

这种分歧，究其原因，我们认为在于机构投资者持股与企业避税之间存在比较严重的内生性问题，即机构投资者和企业避税可能互为因果关系。尽管现有文献也采用二<sub>阶段回归 ( 比如</sub> Khurana and Moser<sub>，</sub>2013<sub>) ，但至今尚未找</sub>到有效的工具变量以解决这一问题 为此，我们采用机构投资者和上市公司之间的空间距离作为工具变量，通过等权和持股比例加权的方式计算各持股的基金管理公司与上市公司总部之间平均距离 以此作为本文机构投资者持股的工具变量，我们研究发现在控制了内生性之后，机构持股显著地制约了企业的避税行为。

对于制约企业避税行为，税收征管制度是一种有效的外部治理机制（曾亚敏和张俊生，2009；叶康涛和刘行，<sup>2011</sup>) 企业所在地区税收征管力度越强，避税被发现的概率就越大，这样避税的机会成本就会增大，从而制约企业管理层的税收避税行为的出现 那么作为外部治理机制的税收征管与内部治理机制的机构投资者在企业避税上是怎样的相互关系？我们认为虽然两者之间可能存在一定的替代关系，但更有可能是互为补充的关系，其原因在于机构投资者作为股东与管理者之间仍然存在代理问题，无法完全杜绝管理层的避税行为; 而税收征管机构高密度和大规模的税收检查需要大量人力成本，而税务机关人力资源是有限的，同时现在的避税手段和方式更复杂，税收征管也是无法杜绝避税行为。 本文实证检验中的结果也支持了两者的互补关系。

本文进一步分析机构投资者制约企业避税产生的经济后果 我们认为内外部的机构投资者和税收征管会使得企业避税难度上升和程度下降，导致现有避税的边际效用出现上升，因而我们发现机构投资者和税收征管会通过抑制避税而使企业价值上升，这一情况在税收征管强度高的地区更为明显，更进一步说明机构投资者与税收征管在避税上的互补效应

本文的研究贡献有三个方面: 第一，本文采用距离作为机构投资者持股比例的工具变量，验证了机构投资者对企业避税抑制作用的因果关系，因此本文拓展了现有机构投资者的研究，是对机构投资者的公司治理作用有益的补充; 第二，税收征管能够发挥外部治理效应，制约企业避税 ( 曾亚敏和张俊生，<sup>2009</sup>; 叶康涛和刘行，<sup>2011</sup>) ，但文献中对税收征管与机构投资者之间的交互作用对避税产生的影响并未研究，而本文研究发现税收征管与机构投资者分别发挥了企业外部和内部的公司治理作用，两者之间呈现叠加效应，这拓展了税收征管的研究文献; 最后，本文的研究证据表明机构投资者和税收征管双重监督下避税有增加企业价值的效应，从而拓展了避税的经济后果方面的研究

本文的余下内容安排如下: 第二部分为理论分析和研究假设; 第三部分为研究设计; 第四部分为样本选择与描述性统计; 第五部分是实证检验与结果分析，最后我们进行简要总结

## 二<sub>、</sub> 理论分析与研究假设

管理层可以通过任职企业向管理层及其关系人控制的企业通过转移定价方式 高资本成本借入债务，支付高额咨询费用等，虽然管理层任职企业降低了税收负担从而节约现金流，但管理层也从中获得了私利 ( <sup>Schadewald</sup>，<sup>2005</sup>) ，这可能对企业股东会产生不利影响，从而避税活动<sub>可能导致公司价值下降 (</sub> Desai and Dharmapala<sub>，</sub>2006<sub>) 为</sub>了撞盖避税活动被税务机关的查处以及避税所产生的不利信息，企业通常设计复杂且隐蔽的交易，随着避税交易不透明性的增加，管理者隐藏其获取私人利益的机会也增加，<sub>这会增加管理层实施避税交易的意愿</sub>，Desai and Dharmapa-<sup>la</sup> ( <sup>2006</sup>) 将这种情形称为反哺效应

尽管避税会给企业和管理层带来潜在收益，但避税可<sub>能伴随着相应的直接和间接成本</sub> ( Hanlon and Slemrod，2009<sub>)</sub><sub>付税 收 方 面 的 审 计 所 花 费 的 时 间</sub> ( Badertscher et al． ，<sup>2013</sup>) ，而间接成本是避税一旦被发现就将受到税收机关的严惩，不仅无法获得收益反而要付出更多的现金流，而且可能进入税收机关的黑名单，企业的声誉败坏而受到税收机关<sub>， (</sub> Hanlon and Slemrod<sub>，</sub>2009<sub>)</sub>

公司治理机制能有效约束管理层的自利行为 根据有效监督假说，作为公司治理机制一部分的机构投资者，能够发挥积极监管作用，抑制管理层的机会主义行为<sub>(</sub> Chung et al． <sub>，</sub>2002<sub>;</sub> Koh<sub>，</sub>2003<sub>) 机构投资者凭借其信</sub>息处理能力 资源和专业优势，能发现隐藏在关联交易和定价转移活动的管理层自利行为，并且机构投资者可以通过代理投票权活动、 股东提案、 进入董事会以及法律诉讼等行动，有效提高公司治理水平，并抑制企业管理层自利动机下的复杂避税行为的发生 ( 陈冬和唐建新，<sup>2013</sup>)由此，本文提出研究假设<sup>1</sup>:

## <sup>H1</sup>: 机构投资者持股比例越高，企业避税程度越小

税务机关可以通过实地检查，更清楚和全面了解企业生产经营情况，发现企业避税行为的概率更高，因此税收征管可以视作对公司运营监控的重要外部力量，尤其对于企业避税的监管 已有文献也支持了税收征管的外部治理<sub>机制作用 (</sub> Desai et al． <sub>，</sub>2007<sub>; 曾亚敏和张俊生，</sub>2009<sub>) 。</sub>如果企业有明显的避税行为，内部的机构投资者发挥了治理作用，那么外部的税收征管就较少地发挥治理作用; 反之亦然 因此两者之间可能呈现的是替代关系

但是机构投资者作为股东与管理者之间仍然存在代理问题，机构投资者是无法完全杜绝企业的避税行为的，甚至机构投资者在一定程度上是默许企业的 <sup>“</sup>合理<sup>”</sup> 避税行为的 另一方面，尽管税收征管的外部治理效应在很大程度上得到认可，一般而言税务机关的税收征纳力度越大，公司税负越高 ( 刘慧龙和吴联生，<sup>2014</sup>) 但仅有税收征管对企业避税的监督与治理显然是不够的，一方面高密度和大规模的税收检查需要大量人力成本，而税务机关人力资源是有限的，因此制约企业的避税活动存在难度; 另一方面，随着时代发展，企业采取的避税手段和方式更为丰富与复杂，比如关联交易 转移定价 ( 曾亚敏和张俊生，<sup>2009</sup>) ，这无疑加大了税务机关调查取证的时间和技术难度，因此税收征管只能在一定程度上发挥外部治理机制，很难完全杜绝企业避税行为 因此我们认为在制约企业避税行为上，机构投资者与税收征管制度内 外部公司治理机制更有可能的是存在叠加的效应，两者之间的互补能有效地制约企业的避税行为 由此我们提出假设<sup>2</sup>:

## <sup>H2</sup>: 税收征管和机构投资者在抑制企业避税行为上存在互补关系

对于避税与企业价值之间的关系，文献中存在一定的争论。 传统的看法认为避税节约了公司的现金流，从而有利于提升公司的价值，但是近期的文献却有一些新的研究<sub>发现，比如</sub> Desai and Dharmapala <sub>(</sub> 2009<sub>) 研究避税对公司</sub>价值影响时，发现平均而言，避税并没有带给公司价值的提升，只有在公司治理相对好的企业中合理避税才能增加公司价值

因为机构投资者的监督会使得管理层避税出现不同程度的下降和避税难度的上升，按照边际效用递减，下降后的避税程度会对管理层产生更大的效用，而管理层也会选择对自己更为有利的避税程度与方式 我们认为机构投资者的监督可能使得企业降低对公司有潜在危害的避税程度，因此受机构投资者影响的下降后的避税边际效用是上升的，因而可能对企业价值产生正面的影响。 我们认为这也是Desai and Dharmapala <sub>(</sub> 2009<sub>) 发现合理避税在公司治理相</sub>对好的企业才增加企业价值的主要原因，因为避税只有在公司治理相对较好的企业才能合理利用。 与之相似，在税收征管强度相对高的地区，企业避税难度相对较大、避税的潜在成本也相对较高，因此单位的避税边际效用相对更大 由此，我们认为如果机构投资者和税收征管能分别有效地发挥内、 外部的公司治理效应，应当会通过抑制避税提升公司的价值，而这一效应在税收征管强的地区更明显一些 由此，本文提出研究假设<sup>3</sup>:

<sup>H3</sup>: 机构投资者能通过抑制企业避税提升公司价值;而这种效应在税收征管强的地区效应更为明显

## 三<sub>、</sub> 研究设计

<sub>以往的研究中，部分文献 (</sub> Badertscher et al． <sub>，</sub>2010<sub>;</sub>陈冬和唐建新，<sup>2013</sup>) 直接采用 <sup>OLS</sup> 回归的方法，忽略了<sub>内生性问题; 另外部分文献 (</sub> Cheng et al． <sub>，</sub>2013<sub>;</sub> Khurana<sup>and Moser</sup> ( <sup>2013</sup>) 分别尝试采用 <sup>PSM</sup> 和两阶段回归的方法，尽量避免内生性对结论的影响 比如 <sup>Khurana and Mos-</sup><sup>er</sup> ( <sup>2013</sup>) 采用了两阶段回归，第一阶段选取了一些与机<sub>构持股相关的变量，如</sub> turnover volatility <sub>等，拟合机构持</sub>股比例，作为第二阶段的回归自变量 但是文章选取的变量均不是外生变量，所以无法解决机构持股与企业避税的因果关系 为了解决已有文献存在的内生性问题，我们采用距离作为研究机构投资者对企业避税影响的工具变量

由于距离是严格外生，而且距离能影响机构投资者对上市公司持股决策 距离越近的机构投资者对公司的监督所花费的交通成本和信息收集成本更低，并且由于距离接近，机构投资者能更频繁的参与公司的各类重大会议，并对大会提案提出建议，有效监督了公司各项活动，提高了公司整体的治理水平 即使机构投资者没有经常参与公司活动，但由于地理位置越接近，也能从心理上对管理层起到威慑作用，减少管理层从事损害股东利益的行为。 因此，距离远近可能会对机构投资者持股决策产生重大影响。

关于距离对上市公司和利益相关者之间的影响已有较<sub>为丰富的文献</sub> Coval and Moskowitz <sub>(</sub> 2001<sub>) 和</sub> Baik et al．( <sup>2010</sup>) 发现距离近的机构投资者比距离远的机构投资者获得的信息更多 <sup>Ayers et al．</sup> ( <sup>2011</sup>) 认为本地机构投资者由于地理位置上的优势，能有效削弱了外部投资者和管理层之间的信息不对称 宋玉等 ( <sup>2012</sup>) 发现公司办公地与机构投资者之间的距离与机构投资者的持股比例负相关，这为国内研究距离影响机构投资者持股比例提供了直接证据。因此，我们认为，距离是合适的工具变量。

本文采用基金管理公司的办公地址和上市公司总部的办公地址之间的直线距离度量 方法是通过百度地图和<sup>Google Earth</sup> 软件查找每家公司对应的经纬度，借鉴先前研<sub>究 (</sub> Coval and Moskowitz<sub>，</sub>2001<sub>;</sub> Gaspar and Massa<sub>，</sub>2007<sub>;</sub><sup>Ayers et al．</sup> ，<sup>2011</sup>) ，采用如下公式计算出公司 <sup>i</sup> 和基金管理公司 <sup>j</sup> 之间的距离:

$$
\begin{array}{r l} \text {Distance} & = 2 \pi r / 3 6 0 \times \arccos \left\{\cos (\text {lati}) \times \cos (\text {loni}) \right. \\ & \quad \times \cos (\text {latj}) \times \cos (\text {lonj}) + \cos (\text {lati}) \times \\ & \quad \sin (\text {loni}) \times \cos (\text {latj}) \times \sin (\text {lonj}) + \sin \\ & (\text {lati}) \times \sin (\text {latj}) \} \end{array}
$$

式中: <sup>r</sup> 为赤道半径，取值为 <sup>6378</sup> 千米; <sup>loni</sup> 和 <sup>lati</sup> 表示上市公司的经度和纬度; <sup>lonj</sup> 和 <sup>latj</sup> 表示机构投资者的经度和纬度。

由于上市公司可能存在多家基金持股，为此我们分别采用等权和以基金持股比例加权的方式计算出 <sup>E\_DIST</sup> 和 <sup>V</sup><sup>\_DIST</sup>，并对这两个变量进行标准化 ( 即均值为 <sup>0</sup>，标准差<sub>为</sub> 1<sub>) 。 因此本文分别以</sub> E\_DIST <sub>和</sub> V\_DIST <sub>作为</sub> FUND <sub>的工</sub>具变量，先进行第一阶段回归 ( 控制第二阶段中的外生变量) ，然后取其拟合值作为自变量进行第二阶段回归。

第二阶段回归我们借鉴 <sup>Chen et al．</sup> ( <sup>2010</sup>) 的模型，进行如下的模型设定:

$$
\begin{array}{r l} T A X \_ A V _ {i, t} & = \beta_ {0} + \beta_ {1} F U N D _ {i, t - 1} + \beta_ {2} S I Z E _ {i, t} + \beta_ {3} L E V _ {i, t} + \\ & \beta_ {4} P P E _ {i, t} + \beta_ {5} R O A _ {i, t} + \beta_ {6} G R O W _ {i, t} + \beta_ {7} \\ & S T A T E _ {i, t} + \beta_ {8} R A T E _ {i, t} + \beta_ {9} T O P 1 _ {i, t} + Y e a r \\ & a n d I n d u s t r y + \varepsilon \end{array}
$$

模型的被解释 <sup>TAX\_AV</sup> 为企业避税，我们采用两种方法衡量: 第一是会计 <sup>－</sup>税收差异 ( <sup>BTD</sup>) 和扣除应计利润影响之后的会计 <sup>－</sup> 税收差异 ( <sup>DD\_BTD</sup>) 会计 <sup>－</sup> 税收差异 <sup>=</sup>( 利润总额 <sup>－</sup>应纳税所得额) <sup>/</sup>上年总资产，应纳税所得额= <sub>(</sub> － <sub>)</sub> /<sub>鉴</sub> Desai and Dharmapala <sub>(</sub> 2006<sub>) 方 法，采 用 公 司</sub> $B T D _ { i , t } =$ $\alpha T A _ { i , t } + \mu _ { i } + \xi _ { i , t }$ 其中，<sup>BTD</sup> 按照上述公式计算得出，<sup>TA</sup> 是公司当年应计项目总额， $\mu _ { i }$ 代表公司税负差异不随时间变化的固有特征部分， $\xi _ { i , t }$ 代表公司税负差异的变动特征部分，回归时均用上一年资产总额对两个变量进行标准化处理，$D D \underline { { { B T D } } } _ { i , t } = \mu _ { i } + \xi _ { i , }$ ，代表<sup>BTD</sup>中不能被应计项目解释的部分

模型中主要的解释变量是基金持股比例 ( <sup>FUND</sup>) 本文借鉴了饶品贵和姜国华 ( <sup>2008</sup>) 采用基金持股数占该上市公司所有在外流通股的比例来反映机构投资者的持股水<sub>，</sub> E\_DIST V\_DIST<sup>FUND</sup> 的工具变量，因此这里的 <sup>FUND</sup> 是第一阶段回归的拟合值 本文的研究假设 <sup>1</sup> 认为基金持股比例越高，企业避税程度越小，因此我们预期 $\beta _ { 1 }$ 显著为负 参照已有企业避税的文献，本文控制了公司规模 ( 对数化的年末总资产，<sup>SIZE</sup>) 资产负债率 ( <sup>LEV</sup>) 固定资产比重 ( <sup>PPE</sup>)企业盈利能力 ( <sup>ROA</sup>) 总资产增长率 ( <sup>GROW</sup>) 和企业是否国有 ( <sup>STATE</sup>) 等变量。

为了检验本文研究假设<sup>2</sup>，我们在上述模型的基础上，按照税收征管强度分组回归，考察在不同税收征纳力度下，机构持股对企业的避税行为的制约作用。

税收征管强度 ( <sup>TE</sup>) ，我们借鉴叶康涛和刘行 ( <sup>2011</sup>)以及曾亚敏和张俊生 ( <sup>2009</sup>) 等的方法，将各地区实际税收收入与预期税收收入之比作为当地税务机关税收征管强度的替代变量 该值越大，表示征管强度越大 我们进一步设置了 <sup>TE</sup> 的虚拟变量 <sup>DTE</sup>，当 <sup>TE</sup> 大于样本中位数时取<sup>1</sup>，否则为<sup>0</sup> 根据本文的研究假设<sup>2</sup>，我们预期在税收征管强度大的地区，基金持股比例越大，对企业避税的制约也越大。

为了验证本文的研究假设<sup>3</sup>，我们借鉴 <sup>Desai and Dhar-</sup><sup>mapala</sup> ( <sup>2009</sup>) 和陈旭东和王雪 ( <sup>2011</sup>) 的模型，进行如下的模型设定:

$$
\begin{array}{r l} \text { Tobi   n } Q _ {i, t} & = \beta_ {0} + \beta_ {1} \text { TAX\_AV } _ {i, t} + \beta_ {2} \text { FUND } _ {i, t - 1} + \beta_ {3} \text { TAX\_AV } _ {i, t} \\ & \times \text { FUND } _ {i, t - 1} + \beta_ {4} \text { SIZE } _ {i, t} + \beta_ {5} \text { LEV } _ {i, t} + \beta_ {6} \text { ROA } _ {i, t} \\ & + \beta_ {7} \text { GROW } _ {i, t} + \beta_ {8} \text { TOP1 } _ {i, t} + \beta_ {9} \text { TOP1 } _ {\text { SQ } i, t} + \\ & \text { Year   and   Industry } + \varepsilon \end{array}
$$

模型中我们同样采用空间距离作为 <sup>FUND</sup> 的工具变量，进行二阶段回归 这个回归中我们还控制了 <sup>“</sup>第一大股东持股比例 ( <sup>TOP1</sup>) <sup>”</sup> 和 <sup>“</sup>第一大股东持股比例的平方( <sup>TOP1\_SQ</sup>) <sup>”</sup> 我们将两个会计 <sup>－</sup> 税收差异变量 ( <sup>BTD</sup><sup>DD\_BTD</sup>) 和基金持股比例交乘，预期在税收征管强度大的情形下的交乘项系数更大

## 六<sub>、</sub> 研究结论和政策启示

基于我国上市公司 <sup>2004 －2012</sup> 年的数据，本文采用等权距离和机构投资者持股比例加权距离作为工具变量后，我们研究发现机构投资者在整体上能够发挥有效的公司治理作用，而且这种效应在税收征管强度高的地区更为明显，这说明机构投资者和税收征管分别发挥了内 外的公司治理作用，两者对避税的制约作用存在叠加效应; 进一步研究发现，机构投资者能通过抑制企业避税而提升公司价值，而这种效应更多地体现在税收征管强的地区。

本文的研究证据表明即使在像我国这样的新兴市场条件下，机构投资者仍然可以在外部法律制度不健全 投资保护机制有待完善的情形下发挥作用，有效地抑制管理层在避税上的机会主义行为，并因此对企业价值产生正向影响。 相对于发达资本市场，我国的机构投资者尽管得到了很大发展，但仍然不是市场的主导力量，而现有的机构投资者秉承价值投资理念也不够充分，存在比较多的短期投资行为，这对充分发挥机构投资者的公司治理作用是不利的。 因此我国资本市场有必要更好地发展机构投资者和发挥机构投资者的公司治理作用

另一方面，税收征管制度是一种有效的外部治理机制，但在现有资源条件和税收征管水平有待提高的情况下，税收征管很难完全遏制企业避税行为 本研究发现机构投资者和税收征管存在互补关系，这说明只有内外部的公司治理机制双管齐下才能更为有效地制约管理层在避税行为的机会主义动机，进而提高企业价值
