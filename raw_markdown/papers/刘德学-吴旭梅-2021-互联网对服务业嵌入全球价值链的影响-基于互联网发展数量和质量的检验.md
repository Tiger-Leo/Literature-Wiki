# 互联网对服务业嵌入全球价值链的影响<sup>\*</sup> <sub>①</sub>

# ——— 基于互联网发展数量和质量的检验

刘德学，吴旭梅

( 暨南大学经济学院，广州510632)

摘 要: 本文基于跨国面板数据模型，从互联网发展数量和质量两个角度考察互联网对服务业参与全球价值链的影响及其作用机制并进行异质性分析 研究发现: (1) 互联网发展数量和质量均能显著提高服务业全球价值链参与度，但两者作用的大小存在明显差异，互联网质量提升的作用效果更强 ( 2) 机制检验表明，通过降低交易成本 优化资源配置从而提高生产率是互联网发展促进服务业参与全球价值链的重要路径 (3) 互联网发展对交易环节多 信息技术密集度高的服务业全球价值链参与度的促进作用更为明显; 在互联网发展水平较低的国家，服务业全球价值链参与度与互联网发展数量和质量均显著正相关，而在互联网发展水平较高国家只对互联网质量敏感 本文研究结果可为制定互联网发展战略，更好地促进服务业发展及融入全球价值链提供参考<sub>。</sub>

关键词: 互联网接入数量; 互联网发展质量; 服务业; 全球价值链参与度; 异质性

## 一<sub>、</sub> 引 言

在传统国际经济学研究中，服务业通常被认为不可贸易且生产率低 这使得一直以来人们认为经济增长与制造业密切相关，且多数研究都偏重于制造业，对服务业的关注较少<sub>。</sub> 然而，随着经济全球化的不断推进以及科技水平的进步，服务业受到的时空限制正在逐渐被打破，并以前所未有的速度蓬勃发展<sub>。</sub> 尤其是互联网技术的迅猛发展使得服务的可贸易性和生产率都在显著提高，服务贸易领域和流量也在迅速扩大 全球服务贸易占 GDP 的比重已从 2000 年的 9. 3%增长到 2014 年的 13%，服务贸易已成为世界主要经济体国内生产总值的重要组成部分 联合国贸发会议 ( 2017) 称，2016 年全球服务总出口达到4. 9 万亿美元，占商品出口的三分之一由此可见，服务业已经成为一国竞争力和经济增长的关键贡献者 然而，服务贸易的快速增长和服务业的发展在很大程度上归功于全球化以及信息和通信技术 ( ICT) 的进步，特别是互联网 互联网史无前例的发展已经对两类产品产生了重大影响: ( 1)一些传统上以物理形式提供的商品和服务，现在可以通过网络以数字比特的形式进行传输，主要包括可数字化的媒体产品，如电影 各种类型的印刷材料 视频游戏和各种记录信息的软件 (2) 诸多领域的服务，如咨询 通讯 金融 教育和医疗行业现在可以数字化生产和通过网络传播 正如 Blinder所论述，技术的可获得性，尤其是交通 信息和通讯技术，很大程度上决定了产品在国际市场上的可贸易性<sup>［1］</sup> 因此，服务业的迅速发展已是新技术革命引起的国际分工深化和全球产业结构调整升级的必然结果

在国际分工过程中，互联网技术通过全球价值链 ( GVCs) 嵌入到整个生产网络，两者的结合不仅从根本上改变了全球服务贸易的性质，同时也为全球价值链的发展向服务主导转变提供更可靠的发展途径 <sub>。</sub> National Board of Trade 运用 <sup>“</sup>微笑曲线 <sup>”</sup> 描述了服务业与价值链之间的关系 该微笑曲线揭示了服务业所处的始末两端不仅是价值增值最多的环节，同时也是服务业在整个生产中占据主导地位的重要环节<sup>［2］</sup> <sub>。</sub> Deardorff ( 迪尔多夫，2001) 考察服务业在国际分工生产中的重要性时指出技术进步促进了服务贸易自由化，也使得更多的服务要素被投入到全球价值链生产中<sup>［3］</sup><sub>。</sub> 事实上，随着互联网等信息技术在全球经济活动中的不断渗透，信息技术已成为改变当前分工生产与贸易格局的高级生产要素，也是导致各经济体在价值链中位置不同的重要因素在全球价值链参与过程中，不同于技术水平较低的发展中经济体，发达经济体主要凭借高端技术 资本等要素优势嵌入到全球价值链高端环节 因此如何充分利用技术进步有效提高生产效率从而获得充足的低成本服务不仅很大程度上决定了全球价值链参与的收益高低，也是驱动全球价值链发展的关键所在

互联网技术的发展和应用对社会经济发展产生了重大影响，也为服务业的快速崛起及其嵌入全球价值链提供了契机 目前，互联网与经济发展的关系已持续成为国内外学者研究的热点，但研究对象更偏重于制造业，而对服务业关注较为缺乏 此外，现有研究对互联网发展水平的衡量绝大多数都是采用互联网接入数量或者订阅数量或者这些变量 ( 非)加权指数进行测度<sub>。</sub> 然而近几十年来，互联网接入方式不断多样化，以往利用互联网硬件数量的接入情况来表示一国互联网发展水平的惯常做法，不仅不能够真实反映出各国互联网的实际使用情况以及互联网技术数字通信能力，而且也可能导致研究结果的偏误 在此背景下，本文将从互联网发展数量和质量两个角度重点考察互联网发展水平对服务业嵌入全球价值链的影响及其作用机制，并进行异质性分析

本文可能的贡献和创新点主要有: 第一，选取服务业作为研究对象，弥补了现有研究偏重于制造业的局限性 第二，基于互联网接入数量和质量两个角度较为真实测度了互联网发展水平，使得研究结果更加准确可信<sub>。</sub> 第三，检验了不同 GVCs 模式<sub>、</sub>不同信息技术密集度以及样本国不同互联网发展水平这些异质性特征如何影响互联网与服务业全球价值链的关系

## 二<sub>、</sub> 文献综述

互联网与全球价值链的融合不仅有效激发了全球生产网络的创新活力，也为国际贸易带来了新的发展渠道和发展动力 尤其是 20 世纪末以来，互联网技术快速发展的同时服务贸易也呈现出前所未有的增长态势，这使得近年来文献中逐渐出现了涉及互联网和服务关系的研究分支<sub>。</sub> W<sub>y</sub>mbs ( 温布斯，2000) 认为全球服务贸易的空前增长归因于全球化的速度和国际贸易的进步，特别是互联网<sup>［4］</sup><sub>。</sub> 互联网作为一种无处不在的便于信息交换的工具，丰富了服务贸易的内涵 拓展了服务贸易方式 促进了服务贸易发展 <sub>。</sub> Freund 和 Weinhold ( 佛洛伊德和温霍尔德，2002) Choi ( 蔡，2010) 均采用跨国面板数据实证证实了互联网对服务贸易发展具有正向促进作用<sup>［5，6］</sup> 江小涓 (2017) 指出互联网技术的发展正在改变传统服务业的基本性质，引起了广泛的资源重组与聚合<sup>［7］</sup> 江小涓 ( 2018) 进一步以生产率较低的体育服务业和文化服务业为例实证检验了互联网对其生产率的影响，发现网络技术能够大幅提高这两个服务行业的生产效率，使其具有显著的规模经济和长尾效应特征<sup>［8］</sup> 信息技术尤其是互联网技术已经成为服务贸易增长的关键因素<sup>［9］</sup><sub>。</sub> 此外，以互联网为代表的信息技术对数字服务消费的发展业起到了重大推动作用<sup>［10］</sup>，多种形式的信息产品的数字化正在以越来越快的速度发生<sub>。</sub> 例如，一件艺术品只要访问网站就可以观赏; 再如以前需要实体传输的数据或存储在 CD 中的音乐文件，现在可以通过数字网络传输<sub>。</sub> 由此可见，数字网络已经改变并极大地促进了服务业的发展

有关互联网影响服务贸易和服务业发展的作用机理的研究也在不断出现<sub>。</sub> 长久以来，服务由于自身传统特点一直发展缓慢，而互联网的发展和应用有效降低了服务在交易活动中受到的诸多限制<sup>［11］</sup>，使得许多服务可以跨越国界进行转移和交易，为服务业快速发展提供了无限动力 互联网技术的广泛使用不仅有效降低消费者的搜索成本，缩减服务供给者的服务成本<sup>［12，13］</sup>，而且作为信息平台能够扩大交易规模 优化资源配置水平，从而拓展服务市场需求 此外，互联网在现代服务行业的应用降低了服务成本，革新了服务技术，拓展了现代服务业的服务内容和贸易空间，从而有效提升了现代服务行业生产效率<sup>［14］</sup><sub>。</sub> 由此可见，互联网技术主要通过降低各种成本优化资源配置来提升生产效率，进而对服务贸易和服务业的发展产生显著促进作用

尽管目前有关互联网和服务贸易之间关系及其作用机制的研究取得了一定成果但文献数量并不多，这意味着互联网对服务业嵌入全球价值链的影响及驱动机制以及异质性等方面仍是一个崭新的研究话题<sub>。</sub> 而且值得关注的是，学术界对于如何测度互联网发展水平并没有一致或者标准的方法<sub>。</sub> 现有实证研究中有关互联网发展水平的测度几乎都是以 ICT 或者互联网硬件的数量接入情况或订阅数量作为代理变量，然而代表数字容量的这类代理变量并不能直接代表数字通信容量<sup>［15］</sup><sub>。</sub> 在 20 世纪 80 年代末的模拟时代，绝大多数的互联网订阅都是固定电话，它们的性能都是一样的，基于这种关系将互联网订阅数量与互联网质量等同起来可能不存在方法上的问题 然而现今互联网订阅种类及其性能范围越来越多样化<sub>。</sub> 虽然一些国家的互联网订阅量已经达到了一定的饱和度，且带宽速度能力也在持续增长<sup>［16］</sup>，但采用互联网订阅数量作为一个独立变量 ( 单独或某种指数) 并未考虑一些国家的实际情况，例如2010 年沙特阿拉伯国内平均安装的带宽速度人均小于1 千比特/秒，而韩国每个订阅用户的带宽速度几乎达到12 千比特/秒 OECD － WTO 报告显示，在最不发达国家不可靠的互联网接入量或低带宽的覆盖率仍有35%<sup>［17］</sup> 这表明不同国家或区域互联网的接入数量和带宽速度差异很大<sup>［18］</sup><sub>。</sub> 由此可见，使用互联网订阅数量作为互联网发展水平代理变量不仅不能够完全真实的反映各国互联网的实际使用情况，而且也会导致实证结果出现偏误 因此，为了更为准确真实的反映出互联网发展水平，从互联网发展数量及其质量两个角度进行考察具有很强的必要性<sub>。</sub>

综上所述可以发现，首先，目前虽然国内外已有不少学者在理论和实证上逐渐聚焦于互联网技术，也有越来越多的学者意识到互联网技术对服务业发展的意义但相关研究并不多，有关互联网与服务业嵌入全球价值链关系的专题更是匮乏; 而且在研究对象主要集中于制造业，对服务业关注几乎很少其次，尽管互联网技术已成为驱动相关产业参与全球价值链的关键因素，但国内外研究更多的是基于互联网发展数量的单一视角展开研究 ( 这种情况在国内研究中尤为普遍) ，很少有学者从互联网发展数量和质量两个角度综合考察真实的互联网发展水平再者，由于包括制造业和服务业在内的诸多产业参与到全球价值链具有多种模式，互联网技术也使得不同行业参与到全球价值链的模式正在发生很大的变革，因此，有必要研究互联网发展对不同 GVCs 模式下的服务业参与全球价值链的程度是否存在差异性 最后，随着信息技术的不断渗透，信息技术在行业生产过程中的投入也势必存在异质性，然而鲜有文献对此展开分析<sub>。</sub> 为此，本文将基于互联网发展数量和质量视角综合考察互联网对服务业嵌入全球价值链的影响及其驱动机理并进行相关的异质性检验

## 三 模型设定 变量说明与数据来源

## ( 一) 模型设定

为了从互联网发展数量和质量两个视角更全面地考察互联网与服务业嵌入全球价值链之间的关系，本文参考姜晓运<sup>［19］</sup>，韩剑等<sup>［20］</sup>相关研究，构建了如下计量模型:

$$
\begin{array}{r l} G V C p a _ {i j t} & = \beta_ {0} + \beta_ {1} \text {   internetqn } _ {i t} + \beta_ {2} \text {   interentql } _ {i t} + \beta_ {3} Z _ {i t} \\ & + \gamma_ {j} + \theta_ {t} + \varepsilon_ {i j t} \end{array} \tag {1}
$$

其中，被解释变量 $G V C p a _ { i j t }$ 表示 t 年i 国j 行业的全球价值链参与度 <sub>。</sub> 解释变量 i<sub>n</sub>t<sub>e</sub>r<sub>ne</sub>t<sub>qn</sub> 和 i<sub>n</sub>t<sub>e</sub>r<sub>en</sub>t<sub>q</sub>l分别表示 t 年 i 国互联网发展数量和互联网发展质量 $Z _ { i t }$ 为控制变量，包括各经济体的经济发展水平$( \ g d p )$ <sub>、</sub> 工业化水平 ( indle) <sub>、</sub> 人均资本存量 ${ \big ( } { p c k } { \big ) }$ 外商直接投资 (fdir) 和基础设施总体质量 $( \mathrm { \it ~ i n f r a } )$ $\gamma _ { j }$ 和 θ 分别为行业固定效应和时间固定效应， $\beta _ { t }$ 为待估参数， $\varepsilon _ { i j t }$ 为随机误差项<sub>。</sub>

## ( 二) 变量说明

## 1． 被解释变量

为了测算各样本国的服务业全球价值链中参与度，文 章 参 考 Koo<sub>p</sub>man 和 Wan<sub>g</sub> ( 库 普 曼 和 王，2014) <sup>［21］</sup>提出的出口分解模型 ( KKW 模型) ，将 VS1和 VS 占总出口的比值结合起来衡量全球价值链参与程度，其中 VS1 和 VS 均为衡量垂直专业化程度的指数<sup>［22］</sup> 根据 KKW 模型， $\left. V S 1 _ { _ r } \right. = \left. V _ { _ r } \sum _ { _ { r \neq s } } ^ { _ G } B _ { _ { r s } } E _ { _ r } \right.$ <sub>\*</sub> 指数表示一国中间品出口过程中经直接进口国加工后再次出口到第三国的国内增加值 ( 即 GVCs 的前向参与率) ， $\begin{array} { r } { \mathrm { V S } _ { r } \ = \ \sum _ { r \neq s } ^ { G } V _ { r } B _ { r s } E _ { s } } \end{array}$ <sub>\*</sub> 则表示一国出口中的国外增加值 ( 即 GVCs 的后向参与率) ，因而，一国某部门的 GVCs 参与程度计算公式如下:

$$
G V C s _ {-} p a = \frac {V S 1 _ {s i}}{E _ {s i}} + \frac {V S _ {s i}}{E _ {s i}}\tag{2}
$$

其中，<sub>s</sub> 表示国家，i 表示行业， $G V C s \_ p a$ 表示 <sub>s</sub>国 i 部门的全球价值链参与程度，该指数越大说明在全球价值链中的参与度越高

## 2． 解释变量

为了考察互联网发展水平，如何合理选取互联网代理变量将是本文的重点 关于互联网发展的代理变量，当前文献常用的标准做法是以互联网订阅数量表示互联网数字通信能力，包括个人电脑，电话和互联网用户<sup>［23，24，25］</sup> 宽带订阅数量<sup>［26］</sup>或这些变量 ( 非) 加权指数<sup>［27，28］</sup><sub>。</sub> 此外，也有学者利用企业电子邮件和网站两种网络工具来衡量互联网的发展程度<sup>［29］</sup><sub>。</sub> 然而，现今互联网订阅种类及其性能范围越来越多样化，单一的使用互联网订阅数量作为互联网发展水平代理变量做法过于片面，而且也可能导致实证结果出现偏误<sub>。</sub> 因此，基于互联网发展数量和质量两个角度考察互联网发展对全球价值链参与度的影响尤显重要<sub>。</sub>

本文将分别采用固定宽带的订阅量 ( 每百人)作为衡量互联网接入数量的指标，以符号 i<sub>n</sub>t<sub>erne</sub>t<sub>qn</sub>表示; 采用固定宽度速度作为衡量互联网设施发展质量的指标，以符号 i<sub>n</sub>t<sub>erne</sub>t<sub>q</sub>l 表示<sub>。</sub> 这两个指标不仅能够反映各国互联网设施发展的广泛性也能体现互联网发展质量，从而可以更为真实的反映出一国的互联网发展水平<sub>。</sub>

## 3． 控制变量

本文选取的控制变量包括: 经济发展水平( <sub>g</sub>d<sub>p</sub>) 工业化水平 ( indle) 人均资本存量 ( <sub>p</sub>ck)外商直接投资 ( fdir) 和基础设施总体质量 ( infra)其中，(1) 经济发展水平 ( <sub>g</sub>d<sub>p</sub>) ，采用国内生产总值衡量; (2) 工业化水平 ( indle) ，采用各国服务业增加值占 GDP 比重来衡量; ( 3) 人均资本存量( ck) ，采用资本存量与劳动力总数的比重来衡量;(4) 外商直接投资 ( fdir) ，采用各国外商直接投资净流入占 GDP 比重来衡量; (5) 基础设施总体质量( infra) ，采用世界经济论坛全球竞争力指数报告中各国基础设施总体质量指数来衡量<sub>。</sub> 该指数取值范围为1 －7，其中最低分 1 代表一国基础设施发展处于极度不发达水平; 最高分7 代表一国基础设施的发展达到了广泛有效的国际标准<sub>。</sub>

## ( 三) 样本选取与数据来源

现有的跨国投入产出表主要有 WIOD GTAP －ICIO OECD － ICIO 等 其中 WIOD 为具有时间序列的标准数据表，数据更新速度较快，也是很多其他投入产出表编制的基础数据库，但包含的国家数量尤其是亚洲国家数量偏少 GTAP － ICIO 的优点在于包含的国家范围广，缺点在于数据更新速度慢 ( 每5年更新一次) OECD － ICIO 则是以各国官方投入产出表为基础，从附加值角度出发建立的一个涵盖 64个经济体 ( 包括36 个经合组织经济体和28 个非经合组织经济体) 36 个行业在国家和行业间的所有交易的全新数据库 相比于 WIOD 和 GTAP － ICIO 数据库，OECD －ICIO 数据库包含有数量相当的发达国家和发展中国家，且数据连续 ( 更新到 2015 年) ，考虑到全球价值链主题的复杂性和数据可得性并结合文章研究目标，本文选择 OECD － ICIO 数据库中 63个经济体 ( 台湾剔除) 的14 个服务行业 2005 －2015年的面板数据作为样本<sub>。</sub>

其中，被解释变量即服务业全球价值链参与度( GVC<sub>p</sub>a) 原始数据来源于 OECD TiVA 数据库提供的世界各国国家间投入 － 产出 ( ICIO) 原始数据 解释变量即互联网发展数量和质量的两个代理变量:固定宽带订阅量 ( 每百人) ( internet<sub>q</sub>n) 和固定宽度速度 ( internet<sub>q</sub>l) 原始数据均源于 ITU 数据库 <sub>。</sub> 工具变量: 国际互联网带宽订阅量 ( 每人) ( i<sub>p</sub>) 和国际互联网带宽速度 ( ib ) 原始数据均源于 ITU 数据库控制变量国内生产总值 ( <sub>g</sub>d<sub>p</sub>) 外商直接投资( fdir) 和工业化水平 ( indle) 的原始数据源于 WDI数据库; 基础设施总体质量 ( infra) 原始数据源于世界经济论坛全球竞争力指数报告，人均资本存量( <sub>p</sub>ck) 原始数据源于 Park9.0 为了避免估计系数中的异常值，文章对所有的变量进行了标准化处理，从而也便于系数值的比较

## ( 二) 机制检验

根据前文基准检验结果可知，互联网显著提升了服务业全球价值链参与度 那么互联网通过何种机制实现驱动作用呢? 目前已有诸多文献充分证实互联网等信息技术的进步会带来生产效率的大幅提高，例如 Jor<sub>g</sub>enson 等 ( 2008) <sup>［30］</sup> 发现信息通信技术的使用提高了美国企业的生产率; 刘生龙和胡鞍钢( 2010) <sup>［31］</sup>，黄群慧 ( 2019) <sup>［32］</sup>等使用工企数据分析发现互联网的使用能够降低成本提高企业生产效率

由于传统的服务具有无形性 不可储存性和不可贸易性等诸多特殊性质，这使得长久以来服务业都无法通过规模经济提高生产率，但是互联网技术的发展和应用在很大程度上突破了服务业诸多传统性质的局限，为服务业嵌入价值链进行生产交易实现资源优化配置提供了契机 在全球生产网络不断扩大，国际不断分工深化背景下，互联网技术推动了全球生产服务体系的形成，价值链各环节的可分解性和中间产品的可贸易性越来越突显，资源配置效率和分散化程度越来越高 互联网通过发挥信息技术的优势可以有效帮助服务业在价值链中的各环节突破时间和空间约束进行跨区域转移和交易，大大降低了服务供求者之间的交易成本，实现了更高效率的资源配置和生产 此外，作为服务重要组成部分，互联网为价值链生产提供了日渐专业化的服务要素，有效提高了价值链各环节间的运作效率，促进了高附加值的服务行业在全球价值链的攀升综上可知，互联网技术能够通过降低交易成本优化资源配置来提高生产效率，进而对服务业全球价值链参与度产生影响 为此，文章接下来将对该作用机制进行实证检验

## ( 三) 异质性检验

互联网技术的拓展与渗透使得各经济体参与全球价值链的程度和环节正在发生重大变革，互联网发展对服务业全球价值链参与度的影响与其所处的GVCs 模式紧密相关 此外，服务业生产过程中所投入的信息技术以及各国互联网发展水平的差异性也可能影响它们在全球价值链中的参与程度 为此，文章接下来将从 GVCs 模式 信息技术密集度以及互联网发展水平三个层面对互联网与服务业全球价值链参与度之间关系进行异质性检验

## 1． 基于全球价值链模式的异质性检验

一国 ( 地区) 技术水平的差异会导致产品的生产链长度不同<sub>。</sub> 在嵌入全球价值链生产过程中，服务产品对信息技术需求的差异性使得整个交易环节和价值链长度不同，由此形成的全球价值链的模式也不相同 现实中，一国嵌入全球价值链的模式主要有 <sup>“</sup>蛇型<sup>” “</sup>蜘蛛型<sup>”</sup> 和 <sup>“</sup>混合型<sup>”</sup> 三种<sub>。</sub> 由于混合型模式更为复杂，本文只研究蛇型和蜘蛛型两种模式下互联网对服务业全球价值链参与度的影响根据图1 可知，同一产品它既可以通过蛇型也可以由蜘蛛型的 GVCs 进行生产，但其生产长度在两种情况下可能并不相同，因此蛇型和蜘蛛型全球价值链的区别可以通过全球价值链的长度来辨析 如图 1 所示，蛇型的零部件1 必须运到国家2 进行加工，再继续运到国家3 进一步加工以此类推，直到最后被运到集装中心组装后交付给最终消费者，而蜘蛛型零部件1 2 3 则是直接运到集装中心进行最终组装就交付给最终消费者 由此可知，蛇型模式下的产品在垂直生产过程中发生移动，其全球价值链往往较长，在交付最终产品之前必须跨越多个阶段和国家，且在每个阶段在制品的总商业价值都在增加，交易成本也在增加<sub>。</sub> 蜘蛛型模式则是不同零部件同时生产再组装成最终产品的生产过程 蜘蛛型的全球价值链长度相对蛇型更短，这是因为在任何情况下蜘蛛型模式下的零部件生产最多发生两次边界跨越，即一次直接转移和一次最终产品交付，因此整个生产过程相对扁平化 为此，全球价值链的蛇型和蜘蛛型模式及其长度 ( 以过境的数量衡量) 和相关贸易成本，决定了体现在最终商品价值中的累计贸易成本的大小

本文主要借鉴 Baldwin 和 Venables ( 鲍德温和维纳布尔斯，2013) <sup>［35］</sup> Formai 和 Caffarelli ( 福迈和卡法雷利，2016)<sup>［36］</sup>的做法，将前向产业关联的平均产品长度 ( APL) 指标作为区分蛇型和蜘蛛型的代理变量 其中 APL 指数等于1 ( 最终生产阶段) ，加上生产所需的加权阶段数 它也可以理解为生产链中所涉及的阶段 ( 工厂) 的平均数量，计算权重由每个阶段增加的价值决定 APL 指数数值越高表明参与生产过程的部门越多 为了更准确的区分蛇型和蜘蛛型的全球价值链模式，本文按照 APL 指数的三分位数划分样本，其中位于 25% 以下的样本划分为蜘蛛型模式，而位于75%以上的样本归为蛇型模式

## 3． 基于样本国信息技术发展水平的异质性检验

前面的计量检验都是针对所有国家样本进行的回归检验，然而不同国家长期以来的互联网发展水平参差不齐，在国际分工中所处的初始地位也不同，要素禀赋和发展路径都存在较大差异 一般而言，互联网发展水平较高国家的互联网覆盖率和普及率都相对较高，互联网数量提升空间较小，而相对的互联网质量仍存在很大的发展空间，因此相比于互联网数量，互联网发展水平较高国家的服务业全球价值链参与度可能对互联网质量的敏感度更高 而在互联网发展水平较低国家，由于互联网数量和质量发展都不够完善，且仍具有很大的提升空间，因此这些国家的服务业在参与全球价值链过程中对互联网数量和质量都可能会具有很高的依赖度 基于此，本文综合比较了互联网发展数量和质量两个指标绝对值大小，将互联网发展数量和质量排名都均在前27 的样本国归为互联网发展水平较高国家，剩下的36 个样本国归为互联网发展水平较低国家，并纳入所有控制变量，进行分样本回归

互联网数量在低水平国家的促进作用更大，互联网发展质量在高水平国家的提升效果更强<sub>。</sub> 这可能是因为互联网发展数量和质量对互联网发展水平不同的国家的服务业全球价值链参与度具有不同的边际效应<sub>。</sub> 互联网发展水平较高国家的互联网基础设施建设起步早<sub>、</sub> 覆盖率和普及度都普遍更高，而互联网发展质量仍在不断提升阶段，因此对于互联网数量对互联网发展水平较高国家的服务业全球价值链参与度的作用或将很小甚至不显著，而互联网质量的促进作用仍将持续 在互联网发展水平较低国家则普遍存在互联网基础设施建设落后 覆盖率低带宽速度缓慢等特征，这意味着这些国家的互联网数量和质量都具有很大的发展空间，且均对服务业嵌入全球价值链起着重要的推动作用 此外，互联网发展水平较低国家不完善的互联网基础设施会导致其所能够支撑的互联网信息传输能力受限，因此互联网发展水平较低国家对互联网质量的敏感度明显低于互联网发展水平较高国家<sub>。</sub> 综上可知，互联网发展水平较高国家应该更注重互联网质量的提升，而互联网发展水平较低的国家应该优先扩展和完善互联网数量的建设，在此基础上再去发展互联网质量，从而推进服务业快速发展和升级<sub>。</sub>

## 五<sub>、</sub> 结论与启示

有别于既往研究仅从互联网接入数量单一视角测度互联网发展水平，本文基于 2005 －2015 年的跨国面板数据模型，从互联网发展数量和质量两个角度较为全面真实的考察了互联网发展水平对服务业参与全球价值链的影响及其作用机理，并进行异质性检验<sub>。</sub> 研究结果显示: (1) 互联网发展数量和质量对服务业全球价值链参与度都具有显著的提升作用，相比于发展数量，发展质量的促进作用更大其原因在于互联网技术能够有效打破服务业在交易活动受到的时空限制，为服务业的快速发展及其嵌入价值链提供了可能，因此相比于其他产业，服务业发展对互联网尤其互联网质量的要求更高 依赖度更大 此外，在样本期间内各样本国的互联网接入数量都较高，在此基础上提升数量可能会由于边际递减效应致使其对服务业参与全球价值链的促进作用减弱甚至不再显著; 而互联网质量在不断上升阶段，因此其促进作用将持续显著的增强 (2) 互联网能够通过降低交易成本优化资源配置来提高生产效率，因而提高生产率是互联网促进服务业参与全球价值链的重要路径 ( 3) 互联网发展数量和质量对价值链更长 信息技术密集度更高的服务业全球价值链参与度的提升效果更为明显; 在互联网发展水平较低国家，互联网发展数量和质量均能明显提高服务业全球价值链参与度，而在互联网发展水平较高的国家服务业全球价值链参与度只与互联网发展质量显著正相关

基于以上结论，至少可以给出以下启示: ( 1)充分认识发展互联网对促进服务业嵌入价值链及结构优化升级的重要作用 互联网不仅能够促进服务业嵌入全球价值链，且存在结构性影响差异 对于交易环节较多 信息技术密集度较高的现代或高端服务业 ( 如电信 金融与保险业 信息服务) ，应积极构建专业的互联网平台，深化互联网技术在这些服务业领域的广泛应用和渗透，从而推进服务业智能化和网络化升级，促进现代服务业更好的嵌入全球价值链 ( 2) 各国应根据自身情况制定相应的互联网发展战略，协调好互联网发展数量和质量的关系 处在互联网发展低水平阶段的国家应优先完善互联网基础设施的建设和供给，在改善互联网低覆盖 低普及的基础上逐步提升互联网技术发展质量，从而为服务业发展及其嵌入全球价值链提供更好的信息化基础<sub>。</sub> 而处在互联网发展高水平阶段的国家应在自身良好的互联网建设数量基础上不断强化互联网质量的发展，通过提升互联网技术质量更好的推动服务业发展 (3) 注重提升互联网质量，大力挖掘互联网质量在服务业发展的潜在功能<sub>。</sub> 相比于互联网发展数量，互联网发展质量对服务业促进作用更大，因此应在注重提升互联网质量发展的基础上，充分挖掘和发挥互联网质量的潜在功能，实现服务产品创新，催生出新型企业组织结构，创造出新的商业模式，从而拓展服务市场，促进服务业发展及嵌入价值链
