# 数实融合与企业出口产品策略优化：基于柔性生产视角

蒋　为　倪诗程　彭　淼<sup>\*</sup>

内容提要　本文构建了一个包含数字企业的多产品异质性企业模型，从柔性生产视角深入探索了数字企业赋能多产品企业出口产品策略优化的理论机制。我们采用 年中国微观企业层面的数据，构建模型检验了数字接近度对中国制造业企业出口产品策略的影响及其机制。研究结果表明：中国制造业企业与数字企业间接近度的提升不仅扩张了其出口产品范围，还显著提升了其出口偏度，在改善企业内资源配置的同时丰富了其出口产品范围，实现了中国企业出口产品策略在效率与多样性上的共同提升。此外，机制分析结果表明，数字接近度的柔性生产效应不仅直接提升了制造业企业的柔性生产能力，还间接提高了市场竞争程度，最终驱动制造业企业出口产品策略的优化。

关 键 词　数实融合　出口产品策略　企业内资源配置　柔性生产　市场竞争

## 一 引言

世纪以来，数字企业成为全球经济发展中最活跃的变革力量，为全球发展开辟出一条新主线。在数字化浪潮下，数字企业对实体经济的赋能效应日益显著，它们通过提供丰富的数字化工具和数据分析、云计算等新兴技术，使传统产业能够更高效、更智能地运营。党的二十大报告明确指出，要“加快发展数字经济，促进数字经济和实体经济深度融合，打造具有国际竞争力的数字产业集群”，为中国经济高质量发展明确了方向。近年来，越来越多的学者开始着眼数字企业在经济中的重要地位，认为其是经济发展的重要部门之一。大量文献探究了数字企业的组织特征、业务模式和价值创造方式（Kretschmer et al.，2022； Giustiziero et al.，2023）。相较于传统企业，数字企业拥有更加扁平的组织结构，更强的创新能力，更高效的管理能力，更灵活的扩展能力，以及更高价值的创造能力等特征。数字企业提供的数字技术能有效帮助制造业企业实现生产模式变革、组织结构重塑和业务模式挖掘创新，增强制造业企业的产业竞争力。

数字企业通过先进的数字技术与丰富的数字化解决方案等方式赋能制造业企业生产，实现制造业生产模式的变革。一方面，由于数字要素的可嵌入性和可迭代性等特征，数字企业提供的数字化技术、产品、服务及数字化解决方案的接入将会驱动制造业企业充分实现效率变革，显著提高企业的资源利用率，实现企业内部管理升级、产品品质提高和研发周期缩短等效益（ ， ）。另一方面，数字企业赋能还将通过提高企业的柔性生产能力实现经济效益，促使企业在面对市场变化中能快速进行产品策略调整并形成精准的定制化服务，提高企业的响应速度和抗风险能力，进行具有竞争优势的产品策略调整。

本文基于Mayer et al（. 2014）对多产品企业出口行为的理论探索，构建了一个包含数字企业的多产品企业开放一般均衡模型，从制造业与数字企业间的接近程度角度刻画了数字企业赋能制造业企业生产决策的理论设定，从柔性生产视角提出了数字企业赋能多产品企业出口产品策略优化的理论机制。本文理论分析表明，一方面，数字接近度的提高能使企业利用柔性生产技术缩小核心产品与边缘产品间的边际成本差距，从而灵活调整出口产品组合，形成柔性生产效应，将其生产和出口活动向核心产品倾斜，最终实现企业内资源有效配置。另一方面，数字接近度提高带来的柔性生产优势会降低多产品出口企业面临的出口目的地临界成本，从一般均衡层面形成竞争效应，从而促使企业将其生产和出口活动向非核心产品倾斜，通过多元化产品策略规避激烈的市场竞争。总体来看，数字接近度对制造业企业出口产品策略的影响并不确定，取决于柔性生产效应和竞争效应的相对大小。

本文采用中国 年高度细化的企业 目的地层面海关进出口数据，通过构建面板固定效应模型检验了外部数字接近度对中国企业出口产品范围和出口产品偏度的影响及其机制。研究结果表明，制造业企业与数字企业接近度的提升不仅有助于其扩张出口产品范围，还能显著提升其出口产品偏度，在提升企业内资源配置效率的同时丰富了其出口产品范围，实现了中国企业出口产品策略在保持核心竞争力和产品多样化的双向提升。本文结论在考虑了变量测度、样本选择、内生性问题和进行安慰剂检验后仍然成立。此外，本文还对数字赋能情形下中国制造业企业出口产品策略优化的路径与机制进行了检验，研究发现，数字接近度提高通过柔性生产效应不仅直接提升了中国制造业企业的柔性生产能力，还间接提高了市场竞争程度，经验回归结果支持了本文理论模型所得到的命题。

本文贡献与创新有以下几方面。首先，从数实融合发展视角研究了数字企业赋能实体经济发展的经济影响，丰富了现有数字经济的相关研究。具体而言，现有大量文献从数字基建和数字化转型两个层面探讨了数字经济对实体经济发展的经济影响。一类文献重点关注互联网等数字基础设施建设，基于“宽带中国”试点政策、“国家级大数据综合试验区”等构建双重差分模型，探索数字经济对实体经济产生的经济影响（方福前等，2023；孙伟增等，2023）。但这类文献忽视了数字企业对实体经济发展的重要性，对于数字企业如何影响实体经济的问题仍缺乏足够关注。另一类文献则从数字化转型和数字技术创新视角讨论了数字经济对制造业企业的影响（袁淳等， ；陶锋等， ）。然而，企业的数字化决策本身是一个内生变量，既取决于内部的经营要素，又依赖于外部数字企业的发展。但现有研究却忽视了外部市场的数字技术供给，即数字企业对制造业企业的影响。因此，不同于已有文献，本文从企业数字化决策的内生动因出发，探索数字企业快速发展将如何赋能实体经济发展。与本文主题最为接近的一类文献主要基于跨境电商平台探索其对于制造业企业的影响（刘玉荣等， ；吕越等， ），但这类文献从流通环节聚焦数字企业对实体经济的影响，忽视了生产环节的赋能效应。因此，本文重点关注数字企业如何通过赋能制造业企业的生产环节实现出口产品策略的优化，从而有效弥补现有文献的不足。

其次，从数字企业的角度扩展了快速发展的多产品出口企业研究，为探索数字企业赋能情形下的多产品企业出口行为提供了理论认识和经验证据。近年来，国内外大量文献通过贸易自由化、外部需求冲击和税收改革等传统视角探索了多产品企业出口行为（樊海潮和张丽娜， ；钟腾龙和余淼杰， ； et al.， ），但对数字科技等新兴要素将如何影响多产品企业出口行为的关注还不够。与本文主题最为接近的是綦建红和张志彤（2022）的研究，他们基于人工智能视角对多产品企业出口行为提供了经验证据，但该文主要侧重工业机器人而非数字企业，与本文研究视角与理论机制截然不同。由此，本文从柔性生产视角出发深入探索数字企业赋能多产品企业出口产品策略优化的理论机理，为现有研究提供理论洞见。此外，现有多产品研究主要发现企业通过“倾斜效应”调整产品组合以实现企业内资源优化配置，将贸易得益归因于出口目的地市场竞争效应（Mayer et al.，2014；Flach et al.，2021）。然而，不同于以往文献仅从竞争效应出发，本文则考虑了数字企业赋能情形下的柔性生产特征，从柔性生产效应这一角度揭示了数字企业赋能中国制造业企业出口产品策略优化的机制路径，为中国企业运用数字技术内生驱动出口产品策略优化提供了新思路。

最后，为检验数字经济赋能实体经济发展提供了一种新的测度方式和经验策略，从数字企业赋能的角度为数字经济研究提供了新思路。现有数字经济文献主要采用以下指标进行研究：一是主成分分析法，将多个衡量互联网发展和信息技术指标进行降维处理，得到衡量地区数字经济发展水平的综合指标（黄群慧等，2019；柏培文和喻理， ）。二是文本分析法，对上市公司披露的年度报告进行词频统计，通过计算年报中数字化关键词词频作为数字化转型程度的代理指标（吴非等， ；袁淳等，2021）。但以上两个方法均忽视了数字企业对实体经济发展的重要作用，无法有效检验数字企业对制造业企业的赋能效应。基于此，本文聚焦数字企业这一创新视角，采用文本分析的方式提出了一套有效识别中国数字企业的新方法，创新性地构造数字接近度指标，为现有数字经济研究提供了一种刻画数字企业赋能更为科学的测度方式。在此基础上，本文构造计量模型检验了数字接近度对企业出口产品策略的影响，从数字企业赋能角度为探索数字经济赋能实体经济发展奠定了方法基础。

本文余下部分结构安排为：第二部分为理论模型；第三部分是数据来源与计量模型设定；第四部分为经验检验结果与分析；第五部分为微观机制检验与分析；第六部分为异质性分析；最后是本文结论与政策建议。

## 二　理论模型

## （一）消费者偏好

参考 （ ）的消费者多产品偏好假定，假定各国代表性消费者的效用函数为连续产品集合Λ上的二次型效用函数：

$$
U = q _ {0} + a \int_ {g \in \Lambda} q _ {g} \mathrm{d} g - \frac {1}{2} b \int_ {g \in \Lambda} \left(q _ {g}\right) ^ {2} \mathrm{d} g - \frac {1}{2} \eta (\int_ {g \in \Lambda} q _ {g} \mathrm{d} g) ^ {2}\tag{1}
$$

其中，U为消费者总效用， $q _ { 0 }$ 与 $q _ { \mathrm { g } }$ 分别为消费者对基准产品和水平差异化产品$g ( g \in A )$ 的消费数量，参数 $a$ 与 $\eta$ 反映了基准产品和水平差异化产品的替代程度，b反映了水平差异化产品间的替代程度。我们将基准产品看作计价物，差异化产品 $^ { g }$ 的价格为p ，则消费者对产品 $p _ { g }$ $^ { g }$ 的反需求函数为：

$$
p _ {g} = a - b q _ {g} - \eta Q, Q \equiv \int_ {g \in \Lambda} q _ {g} \mathrm{d} g\tag{2}
$$

假定消费者的数量为L，则产品 $^ { g }$ 的市场需求函数可转化为：

$$
q _ {g} = \frac {a L}{\eta G + b} - \frac {L}{b} p _ {g} + \frac {\eta G}{\eta G + b} \frac {L}{b} \bar {p}, \forall i \in \Lambda^ {*}\tag{3}
$$

其中，G代表消费者在产品集 $\pmb { { \cal { \Lambda } } } ^ { * } ( \pmb { { \cal { A } } } ^ { * } \subset \pmb { { \cal { A } } } )$ 中消费的水平差异化产品种类数量，$\bar { p } = \left( 1 / G \right) \int _ { \varepsilon \in A ^ { * } } p _ { g } d g$ 是消费水平差异化产品种类的平均价格。为满足集合Λ\*为集合Λ的最大子集，则需要满足下式：

$$
p _ {g} \leqslant \frac {1}{\eta G + b} (a b + \eta G \bar {p}) \equiv p ^ {\max}\tag{4}
$$

其中， $p ^ { \mathrm { m a x } }$ 表示消费者对产品 $^ { g }$ 消费数量趋于0时的最大价格；需求价格弹性为$\xi = [ ( \ d p ^ { \mathrm { m a x } } / \ d p _ { g } ) - 1 ] ^ { - 1 }$ 。结合上式，更低平均价格 $\bar { p }$ 或更多产品品种数G都会导致约束价格 $p ^ { \mathrm { m a x } }$ 降低以及任何给定 $p _ { g }$ 的需求价格弹性增加以影响市场竞争程度。

## （二）生产者行为

参考 et al（. ）的多产品企业生产模型设定，本文将劳动力设定为唯一的生产要素，在完全竞争市场中缺乏供给弹性。计价商品在完全竞争市场中以单位成本生产。在水平差异化产品部门中，企业在垄断竞争市场中内生决定产品品种和数量，从事生产活动。每个企业拥有 个核心产品，在进入市场时，需支付进入成本 $f _ { E }$ 后才会观测到自己生产核心产品的边际成本c，假定边际成本服从帕累托分布$M ( c ) = ( c / c _ { { \scriptscriptstyle M } } ) ^ { \theta } , c \in [ 0 , c _ { { \scriptscriptstyle M } } ] , \theta > 1$ 为形状参数。每个企业都可以选择生产任意数量的新产品，但新增产品的边际成本将随着与核心产品距离的增大而提高，生产能力逐渐远离核心生产力。我们借鉴 et al（. ）的做法，定义“生产阶梯”刻画核心产品与其他产品间的成本关系。具体而言，我们通过 $^ { g }$ 对产品种类进行索引，即企业其他种类产品与核心产品的距离。 $g = 0$ 表示核心产品， $^ { g }$ 越大表明该新产品与核心产品距离越远，具有更高的边际成本。基于此，我们将企业生产品种g的边际成本定义 $^ { g }$ 为：v $\left( \varrho , c \right) = \omega ^ { - g } c$ 且 $\omega \in ( 0 , 1 )$ 。其中， $\omega$ 反映核心产品与边缘产品间的生产阶梯关系，定制成本的几何级增长确保企业不会进行无限制的新产品扩张。较低的 $\omega$ 意味着与核心产品相比，扩大产品组合会导致额外品种的边际生产成本呈更大幅度的增长。

## （三）数字技术与企业数字化决策

伴随着数字技术的广泛应用，越来越多的制造业企业通过实施数字化战略以实现数字赋能改造。数字技术的引入有助于制造业企业形成规范的生产标准和管理流程，显著提升企业的柔性生产能力，推动企业灵活地应对多产品生产流程（ et al.，2019）。这不仅有助于企业提高其生产效率，还能实现更加合理的成本控制和资源分配，优化企业的多产品生产阶梯并缩小其在多产品生产的边际成本差距。基于此，我们假定一个数字化柔性因子δ(k)刻画数字技术对边际成本的影响，并将企业的边际成本重写为 $v \left( g , c \right) = \left( \delta \omega \right) ^ { - g } c _ { c }$ 。我们假定数字化柔性因子 $\delta ( k ) > 1 ^ { \mathrm { { ( 1 ) } } }$ ，表明制造业企业能够通过数字技术改善其核心产品与边缘产品间的生产阶梯关系，使核心产品与边缘产品间的边际成本差距逐渐缩小。我们假设 $\delta \omega < 1$ ，这表明数字技术对生产阶梯关系具有正向作用。

在此基础上，我们定义 $s \in \left[ 0 , 1 \right)$ 表示企业通过数字技术提高其柔性生产能力带来的边际成本削减幅度，即 $s = \omega ^ { - g } c - ( \delta \omega ) ^ { - g } c = ( 1 - \delta ^ { - g } ) \omega ^ { - g } c \circ$ 。因此，边际成本削减幅度s捕捉了企业采纳数字技术获得的数字收益，并满足 $s ^ { \prime } ( k ) > 0 _ { \circ }$ 。此外，企业采纳数字技术时还会产生数字成本。我们将数字成本定义为与边际成本削减幅度s相关的函数②： $: x ( s ) = ( \upsilon s ) ^ { 2 } , \upsilon > 0$ 为成本参数。数字成本满足以下条件： $x ^ { \prime } ( s ) > 0 \ldots x ^ { \prime \prime } ( s ) > 0$ 和$\operatorname* { l i m } _ { s \to 1 } x ( s ) = \infty$ 。因此，制造业企业将根据采纳数字技术带来的收益和成本进行权衡，从而内生决定其数字化决策k。

## （四）数字接近度

从现实情况看，虽然制造业企业能够通过数字技术实现生产模式变革，但由于企业在数字化变革中面临着复杂的内外部环境，加之数字技术研发需要具备极高的资金要求和技术门槛，这都使得企业的数字化进程面临着多种数字摩擦因素的影响，导致这一进程能否完全实现仍然取决于数字企业是否能够为制造业企业提供足够的数字技术支持。基于此，我们将制造业企业与数字企业间的接近程度（以下简写为“数字接近度”）定义为μ，该变量刻画了制造业企业能够通过数字企业赋能在多大程度上缓解其存在的数字技术约束。

对于上式，我们发现数字接近度将通过柔性生产效应和竞争效应共同影响企业出口产品范围，进而从扩展边际渠道影响企业出口产品偏度。根据理论命题 ，数字接近度产生的柔性生产效应（竞争效应）将扩大（缩小）企业的出口产品范围，进而提高（降低）企业的出口产品偏度。我们进一步使出口产品种类保持不变，从集约边际渠道探索数字接近度影响企业出口产品偏度的理论机制，平均出口收入式为：

$$
\frac {R _ {h f} (v (g , c))}{\bar {R} _ {h f} (c)} = \frac {G _ {h f} (c) \cdot R _ {h f} (v (g , c))}{\sum_ {g = 0} ^ {G _ {h f} (c) - 1} R _ {h f} (v (g , c))} = \frac {G _ {h f} (c) \left[ c _ {f f} - \zeta (g , c) \right] ^ {2}}{\left[ c _ {f f} - \psi (g , c) \right] ^ {2}}\tag{24}
$$

其中， $\begin{array} { r } {  { \boldsymbol { \zeta } } (  { \boldsymbol { g } } , c ) = \tau _ { h f } ( \delta \omega ) ^ { - g } c ;  { \boldsymbol { \psi } } (  { \boldsymbol { g } } , c ) = \tau _ { h f } \sum _ { g = 0 } ^ { G _ { h f } ( c ) - 1 } ( \delta \omega ) ^ { - g } c } \end{array}$ 衡量了柔性生产的平均成本。根据（22）式，我们可以得到数字接近度对企业平均出口收入的一阶导数为：

$$
\frac {\mathrm{d} \left(R _ {h f} / \bar {R} _ {h f}\right)}{\mathrm{d} \mu} = \underbrace {\frac {2 G _ {h f} \left\{\left[ c _ {f f} - \psi (g , c) \right] ^ {2} \left\{\left[ \zeta (g , c) - c _ {f f} \right] \cdot \frac {\mathrm{d} \zeta}{\mathrm{d} \delta} \right\} - \left[ c _ {f f} - \zeta (g , c) \right] ^ {2} \left\{\left[ \psi (g , c) - c _ {f f} \right] \cdot \frac {\mathrm{d} \psi}{\mathrm{d} \delta} \right\} \right\}}{\left(c _ {f f} - \psi (g , c)\right) ^ {4}}} _ {\text {柔性生产效应(+)}} \frac {\mathrm{d} \delta}{\mathrm{d} \mu} + \underbrace {\frac {2 G _ {h f} \left\{\left[ c _ {f f} - \zeta (g , c) \right] \left[ c _ {f f} - \psi (g , c) \right] ^ {2} - \left[ c _ {f f} - \psi (g , c) \right] \left[ c _ {f f} - \zeta (g , c) \right] ^ {2} \right\}}{\left[ c _ {f f} - \psi (g , c) \right] ^ {4}} \frac {\mathrm{d} c _ {f f}}{\mathrm{d} \mu}} _ {\text {竞争效应(-)}}\tag{25}
$$

根据（ ）式，一方面，数字接近度提升产生的柔性生产效应将提高企业的平均出口收入，进而提高其出口产品偏度；另一方面，数字接近度产生的竞争效应将降低企业的平均出口收入，进而降低企业出口产品偏度。结合（ ）和（ ）式我们可知，数字接近度的提高将对出口产品偏度产生两种效应。一方面，数字接近度产生的柔性生产效应将提高企业出口产品偏度，这促使企业将其生产和出口活动向核心产品倾斜，从而提升企业内的资源配置情况。另一方面，数字接近度产生的竞争效应将降低企业出口产品偏度，这促使企业将其生产和出口活动向非核心产品倾斜。总体来看，数字接近度对企业出口产品偏度的影响取决于柔性生产效应与竞争效应的相对大小。由此，我们得到本文理论命题 。

## （三）变量构建

被解释变量：出口产品策略。本文采用出口产品范围和出口产品偏度两个指标衡量企业出口产品策略。其中，出口产品范围（Scope）以企业出口到目的地市场的位码产品种类数的对数值进行测度。由于本文研究对象是多产品出口企业，因此，我们将其定义为出口产品种类数大于等于 的企业。在稳健性检验中，我们将改变多产品出口企业的定义和HS编码标准检验估计结果的稳健性。关于出口产品偏度的度量，现有文献主要采用泰尔指数（Flach et al.，2021；Mayer et al.，2021）、核心产品收入占总出口收入比重（綦建红和张志彤，2022）以及赫芬达尔指数（Mayer et al.，）进行刻画。基于此，本文在基准回归中选择泰尔指数作为出口产品偏度的衡量指标，并在稳健性检验中使用核心产品收入比重与赫芬达尔指数作为替代变量进行估计。具体而言，以泰尔指数衡量的出口 $\vec { \cal J } ^ { \mathrm { s } }$ 品偏度如下式所示：

$$
S k e w n e s s _ {i d t} = \frac {1}{G _ {i d t}} \sum_ {g = 0} ^ {G} \frac {R _ {i d g t}}{\bar {R} _ {i d t}} \ln \frac {R _ {i d g t}}{\bar {R} _ {i d t}}\tag{27}
$$

其中， $G _ { i d t }$ 为企业i向目的地d出口的 位码产品种类数， $R _ { i d g t }$ 为企业i在t时期向目的地d出口HS8位码产品g的出口收入， $^ { g }$ $\bar { R } _ { i d t }$ 为i企业t时期向目的地d出口的平均出口收入。该指标越大意味着企业的出口产品偏度越大，即企业越集中于生产核心产品。

核心解释变量：数字接近度。数字企业赋能是数字企业为制造业企业提供数字技术以帮助制造业企业实现数字化的过程。在本文理论设定中，数字接近度刻画了制造业企业能够在多大程度上提高获取更高数字解决方案效率的可能性，体现了缓解制造业企业在获取数字技术上受到外部约束与限制的经济内涵。数字接近度越高，制造业企业能够在市场中可及的数字企业数量越多，使得制造业企业更有可能从数字企业获取更多数字技术相关支持与赋能，从而接近最优数字化程度。因此，数字企业是制造业企业使用数字技术实现赋能的基础，制造业企业获取数字技术支持的能力与市场上可及的数字企业数量成正比。

然而，如何识别数字企业是本文经验分析面对的首要问题。为解决这一关键问题，我们参考Beraja et al（. 2023）的研究思路，采用文本分析法制定了一套识别数字企业的策略。首先，我们利用文本识别方法为数字企业构建一个业务范围词库，如果企业披露的经营范围在词库中至少包含5个词汇，则将该企业定义为一家数字企业①。其次，通过这一词库，我们对企查查数据库中所有企业的经营范围进行文本分析，从中识别出数字企业。最后，我们根据每家数字企业注册的地址信息及其注册成立时间，计算得到中国每个地级市在该年仍然存续的数字企业数量，得到一个随时间和地级市变化的数字企业数量面板数据。

在经验研究策略中，我们以各城市数字企业数量作为基础，以城市间地理距离为权重，通过加权计算得到制造业企业面临的数字接近度，具体测算方式为：

$$
D P _ {j t} = \ln \left(\frac {\text { DigitalFirm } _ {j t}}{\text { Distance } _ {j j}} + \sum_ {j \neq \kappa} \frac {\text { DigitalFirm } _ {\kappa t}}{\text { Distance } _ {j \kappa}}\right)\tag{28}
$$

其中， $D i g i t a l F i r m _ { j t }$ 为城市j在t年的数字企业数量； $D i s t a n c e _ { j \kappa }$ 为城市j与城市κ的最短球面距离。本文根据城市经纬度信息计算各城市间的最短球面距离；城市j的内部距离为其城市半径，计算公式为 $D i s t a n c e _ { j j } = 2 \sqrt { a r e a _ { j } } / \pi \ , a r e a _ { j }$ 为城市j的土地面积。（28）式的含义为，一个城市的数字接近度由本地数字企业数量和其他城市的数字企业数量经过地理距离加权后得到。在稳健性检验中，本文将采用其他权重对数字接近度进行测算以避免测度偏差问题。

## （二）稳健性检验与分析

本文在基准回归中对理论预测进行了初步检验，但仍在变量测度、遗漏重要解释变量及反向因果关系等方面可能存在问题。因此，本文从以下几方面进行稳健性检验①。

被解释变量的测度偏差问题。在基准回归中，本文采用出口产品范围和出口产品偏度衡量多产品企业的出口产品策略，但由于现有文献对多产品企业的定义没有一致做法，且海关数据库中记录产品信息的HS编码存在多种标准（Mayer et al.，；钟腾龙和余淼杰， ；綦建红和张志彤， ），采用单一指标可能会引发测度偏差问题。因此，我们对出口产品策略重新测度，采用4种不同替代指标进行稳健性检验。一方面，对于出口产品范围，我们基于 和 位代码再次界定产品种类，计算产品范围，并保留产品种类数大于等于1和大于等于5的企业作为研究样本进行估计。另一方面，对于出口产品偏度，我们仍然采用 和 位代码计算出口产品偏度，并采用赫芬达尔指数和核心产品比重作为替代指标。估计结果表明，在考虑了测算方法对被解释变量测度的影响后，结果与基准结果保持一致，本文结果稳健。

核心解释变量的测度偏差问题。为避免核心解释变量测度偏差带来的估计偏误，本文进行了如下稳健性检验。首先，对识别频次进行调整，将数字企业的识别频次分别调整为大于等于 次和 次，以解决数字企业的遗漏识别和过度识别问题。其次，对变量构建中选取的权重进行更替，将地理距离权重替换为经济距离，采用省际贸易额作为权重进行测算。最后，重新筛选数字企业样本，剔除注册资本小于万元的数字企业以避免企业的过度申请行为。从以上检验结果可知，在考虑了核心解释变量的测算偏差问题后，数字接近度对企业出口产品策略的影响仍然是稳健的。

3.遗漏重要解释变量。虽然我们在基准模型中已加入一系列决定企业出口产品策略的重要因素作为控制变量，但其仍然可能受到其他竞争性机制以及第三方共同决定因素的影响。因此，本文从城市市场规模、城市数字市场规模和企业数字技术自主创新3个方面进行稳健性检验。首先，采用市场潜力指标，以控制城市市场规模的影响。其次，我们采用互联网用户数量、电信业务总量及移动电话年末用户数三个指标，加入一系列衡量城市数字市场规模的控制变量以排除城市数字市场规模差异对估计结果的影响。最后，参考陶锋等（2023）的做法，加入衡量企业数字技术创新水平的控制变量，考虑企业自主研发创新数字技术这一情形。从以上检验结果可知，在控制了城市市场规模、城市数字市场规模及企业数字技术自主创新3方面影响后，本文重点关注变量的估计系数仍然没有显著变化，表明本文结论是稳健的。

安慰剂检验：构建虚假的城市间地理距离。在基准回归中，我们利用各城市的数字企业数量，以城市间地理距离作为权重对数字接近度进行测算。但由于数字技术的特殊性在于其能有效突破信息传输的“地理壁垒”，使得我们仍然需要讨论地理距离是否能有效刻画制造业企业与数字企业间联系的权重。基于此，本文借鉴安慰剂检验的思路，通过构建虚假的城市间地理距离对数字接近度变量重新测度并进行回归。如果虚构的数字接近度未对出口产品策略呈现显著影响，则说明地理距离在数字企业为制造业企业提供数字解决方案时仍起到重要作用，使用城市间地理距离作为权重具备合理性。具体而言，我们通过随机抽取为各城市构造虚假的地理距离，并在此基础上测算出虚构的数字接近度进行估计。我们将上述过程重复 次，得到每次核心解释变量的估计系数。从结果可知， 次随机检验得到的估计系数均值接近于 且不显著，且绝大部分样本均明显低于基准回归中的估计系数。这表明虚构的数字接近度并不会对出口产品范围和出口产品偏度产生显著影响，侧面证明了使用城市间地理距离作为权重计算数字接近度是合理的。

内生性问题。反向因果关系是造成内生性问题的重要原因之一。具体而言，具有更优出口产品策略的企业可能有更高的需求去推动数字技术应用以稳固其国际市场竞争优势，从而形成反向因果关系。因此，本文采用工具变量法解决基准回归的潜在内生性问题。

我们构造了两组数字接近度的工具变量。其一，本文参考黄群慧等（ ）的方法，利用 年各地级市邮局数作为工具变量。 年地级市邮局数量作为历史变量，难以受到当前时期数字经济的影响，满足工具变量的外生性要求。而互联网最早是从电话拨号开始的，在固定电话普及前期，邮局作为铺设固定电话的执行部门，其分布将在一定程度上影响固定电话的分布进而影响互联网接入，从而满足相关性要求。在此基础上，我们采用前 年全国互联网上网人数与 年地级市邮局数量交乘以体现时变性并进行工具变量检验，表 第（）和（）列汇报了工具变量第二阶段的回归结果。从结果可知，数字接近度对企业出口产品策略的影响在1%水平下显著为正。此外，模型通过了不可识别和弱识别检验，一阶段F统计量均大于10，表明工具变量是有效的。

其二，我们从高校学科分布视角出发，采用2002-2004年第一轮学科评估结果构造各城市数字技术学科接近度作为工具变量，以反映各地区数字技术学科资源的地理分布①。具体构造方法为：如果某高校在第一轮学科评估中有任意一个数字技术相关学科上榜（即评分在 分以上），则在该高校所在城市的学科资源数量上加1，通过累加该城市内所有高校的学科上榜次数，即可得到中国各城市数字技术学科总数。在此基础上，本文基于与数字接近度一致的构造方式，利用地理距离作为权重对各城市数字技术学科数量进行加权，最终得到城市层面的数字技术学科接近度。

## （一）柔性生产效应检验

根据理论分析，数字接近度提高能促使企业利用柔性生产技术缩小产品间的边际成本差距，形成柔性生产效应以优化出口产品策略。基于此，我们从两方面对柔性生产效应进行检验。

一方面，由于现有数据难以对企业柔性生产程度进行准确测算，因此，我们基于理论模型构建了柔性生产因子与企业出口产品范围和市场竞争程度之间的联系，采用可观测数据对其进行测算。我们对理论模型（ ）式进行整理后可得：

$$
\ln \delta \omega = \frac {\ln c - \ln c _ {h f}}{g _ {h f} (c)} \Rightarrow \ln \delta = A - \frac {\ln c _ {h f}}{g _ {h f} (c)} \Rightarrow \ln \delta \propto - \frac {\ln c _ {h f}}{g _ {h f} (c)}\tag{29}
$$

其中， $, A = \ln c / g ( c ) - \ln \omega ; c _ { h f }$ 为出口市场临界成本，即企业面临的市场竞争程度；$\boldsymbol { g } _ { h f } ( \boldsymbol { c } )$ 为出口产品范围。通过（29）式，我们构建了柔性生产因子（δ）与市场竞争程度$( c _ { h f } )$ 和产品范围 $\left( g _ { h f } ( c ) \right)$ ）之间的理论联系。其中，柔性生产因子与市场竞争程度和产品范围之比呈负相关关系，这从结果导向反映了柔性生产因子的影响。因此，我们能基于这一理论联系产生的相对效应，利用可观测数据对市场竞争程度和出口产品范围进行测度，从而间接测算得到企业层面的柔性因子，并以此检验数字接近度产生的柔性生产效应。

$$
\ln p r o f i t _ {i t} = \beta_ {0} + \beta_ {1} (m c _ {i t} / p _ {i t}) + \varepsilon_ {i t}\tag{31}
$$

其中， ${ { p r o f i t } _ { i t } }$ 为企业利润； $m c _ { i t } / p _ { i t }$ 为边际成本与价格之比，记为 $M C _ { i t ^ { \circ } }$ 。参数 $\beta _ { \iota }$ 即为Boone指数，衡量了企业利润对边际成本的敏感度。该指数的估计系数为负，其绝对值越高表明边际成本对企业利润负面影响越大，即市场竞争程度越激烈。基于此，我们构造了数字接近度与 $M C _ { i t }$ 的交互项，利用调节效应分析检验数字接近度所产生的竞争效应，具体估计式为：

$$
\ln \text { profit } _ {i j t} = \beta_ {2} + \beta_ {3} M C _ {i t} + \beta_ {4} D P _ {j t} + \beta_ {5} M C _ {i t} \times D P _ {j t} + \varepsilon_ {i j t}\tag{32}
$$

其中， $D P _ { j t }$ 为数字接近度；交互项 $M C _ { i t } \times D P _ { j t }$ 捕捉了数字接近度对竞争程度的影响。根据（ ）式，边际成本对企业利润的影响 $\beta _ { 3 }$ 为负。若交互项的估计系数 $\beta _ { \mathfrak { s } }$ 显著为负，表明数字接近度增强了边际成本对企业利润的负向影响，此时数字接近度增加了市场的竞争程度，若估计系数 $\beta _ { 5 }$ 显著为正则反之。由此我们可以根据估计系数 ${ \bf \dot { \rho } } _ { \beta _ { 5 } }$ 检验数字接近度的竞争效应。

## 七　结论与政策建议

本文基于 et al（. ）的理论从柔性生产视角出发构建了一个包含企业数字决策的多产品企业开放一般均衡模型，从理论层面探讨了中国制造业企业如何在数字赋能情形下对其出口产品策略进行优化调整，并探索了企业出口产品策略优化的理论机制。本文采用 年中国海关进出口企业数据库，构建计量模型对理论预测及其影响机制进行了经验检验。研究结果发现，第一，数字企业接近度的提升不仅有助于其出口产品范围的扩张，还显著提升了其出口产品偏度，在改善企业内资源配置的同时实现了产品多样化策略，且这一结论在经过变量测度、样本选择、内生性问题和安慰剂检验等稳健性检验后仍然成立。第二，本文发现数字接近度提高产生的柔性生产效应不仅直接提升了企业的柔性生产能力，还间接提高了市场竞争程度，从而检验了本文理论机制。第三，数字接近度对出口产品策略的优化促进作用具有异质性特征。在企业特征方面，数字接近度对国有企业、出口到发达国家企业和出口生存年限更高企业具有更为显著的促进作用；在行业特征方面，数字接近度对高数字技术应用程度、低技术约束度和低资金约束度行业具有更为显著的正向作用。

本文结论对数字经济支持实体经济发展、培育企业出口竞争新优势、实现贸易高质量发展具有重要的政策含义。首先，从数实融合的角度看，数字企业的崛起赋能制造业企业转型升级是实体经济高质量发展的更深层次要求。中国企业应以新一代数字技术和平台企业生态为契机，以数据驱动业务，以仿真驱动研发，以场景驱动决策，实现企业保持出口竞争力与出口产品多样化的“双赢”。政府要大力推动数字企业与制造业企业合作建设“智能工厂”“数字工厂”及“网络工厂”，对二者合作形成“品牌效应”的案例进行推介并积极实施企业税收减免等优惠措施，实现数字企业对实体经济的有效赋能。其次，在高度不确定性和激烈竞争的出口市场中，中国制造业企业需要实现柔性化生产以应对市场变化，而数字企业提供的数字化解决方案成为赋能制造业企业实现柔性生产的关键。因此，政府要加快数字产业集群建设，要重点打造一批能够深度参与到实体经济转型中的数字企业，以数字化思维打通制造业企业在传统生产中所面临的难点，推动形成制造业企业模块化、精准化、网络化的柔性生产模式，以适应市场需求多变和竞争激烈的情况，提高中国企业在国际市场中产品配置的策略能力。最后，要结合政策引导和行业探索，提高企业数字化改造的积极性。部分民营企业或资金约束程度较高的企业受限于自身发展状况，导致数字化赋能的经济效益不足。对于此，政府要给予这些企业更大力度的扶持政策，一方面通过提供专项技术补贴或融资解决企业转型面临的资金难题，尤其要加大科技金融创新发展力度，不仅促使金融服务数字企业，还要驱动数实融合发展；另一方面对于存在技术门槛限制的企业给予技术咨询，助力企业成功赋能转型，从而加快促进“数字中国”建设，打造具有国际竞争力的现代产业集群，为中国贸易高质量发展提供新引擎。

# Digital-Substantive Integration and Optimization of Export Product Strategies for Firms: Based on the Perspective of Flexible Production

Jiang Wei; Ni Shicheng; Peng Miao

Abstract: This paper constructs a model of multi-product heterogeneous firms that includes digital firms and investigates the theoretical mechanism of digital firms that empowers multi-product firms to optimise their export product strategies from a flexible production perspective. Using Chinese firm-level data from between 2000 and 2016, it develops an econometric model to examine the effect and mechanism of digital proximity on the export product scope and skewness of Chinese manufacturing firms. The results of the study indicate that increasing digital proximity not only helps to expand the export product scope, but also significantly improves their export skewness, which enhances intra-firm resource allocation and enriches their export product scope, thus achieving the joint improvement of Chinese firms’ export product strategies in terms of efficiency and diversity. The analysis of the mechanism also reveals that digital proximity not only directly improves the flexible production capacity of manufacturing firms through the flexible production effect, but also indirectly increases the degree of market competition, ultimately driving the optimisation of export product strategies for manufacturing firms.

Key words: digital-substantive integration, export product strategies, intra-firm resource allocation, flexible production, market competition
