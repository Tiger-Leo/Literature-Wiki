# 论新型文化业态的发展机理

■ 郭鸿雁

2012 年5 月18 日，第八届中国国际文化产业博览交易会在深圳开幕<sub>。</sub> 安徽日报报业集团的 3D 报纸<sub>、</sub> 数字报刊，出版集团的数字出版 多媒体交互式阅读数字产品，发行集团数字发行平台<sub>、</sub> 云教育<sub>、</sub> 现代物流等新兴文化业态集中体现的 <sup>“</sup>文化与科技融合<sup>”</sup> 的理念在文博会上大放光彩<sub>。</sub>

新型文化业态是与传统文化业态相对的概念，指伴随现代科学技术的发展而催生的新兴文化业态<sub>。</sub> 进入 21 世纪以来，数字信息技术与知识经济的融合不断催生新型文化业态，各类文化业态之间相互交错<sub>、</sub> 相互影响<sub>。</sub> 新的文化业态的不断涌现是文化发展的客观规律，也是文化生产和传播领域革命的重要表现

新型文化业态的发展机理，即生成与运作原理，旨在从理论上探讨新型文化业态形成的内在机理<sub>。</sub> 由于新型文化业态具有系统性 开放性 跨业性 复杂性与广泛性，因此从研究方法上很难将其归入某一学科方法论中，抑或难以用某一特定方法对其进行研究<sub>。</sub> 本文拟从跨学科视角，分别运用系统科学<sub>、</sub> 产业经济学<sub>、</sub> 传媒经济学理论方法展开分析，具体包括自组织理论与耗散结构理论 产业价值链理论<sub>、</sub> 网络经济理论等，从中说明新型文化业态形成的理论实质<sub>。</sub>

## 一<sub>、</sub> 系统科学角度

自组织理论与耗散结构理论表明，文化产业的渗透<sub>、</sub>交叉与重组必然导致产业边界的突破与重构，在此过程中，产业原结构和功能实现优化，产业系统正熵增加受到抑制，也即从无序走向有序，从而形成新型文化业态<sub>。</sub>

自组织理论认为，涨落是系统自组织演化的重要动因普利高津描述了演化系统中结构<sub>、</sub> 功能与涨落之间的关系<sub>。</sub>概括来说，结构 功能与涨落之间相互联系 相互制约<sub>。</sub>随机的涨落引起系统功能的局部改变，一定条件下又引起系统结构的局部改变，而这一改变将决定未来涨落的范围在文化产业经济系统中，这一演化过程以渗透<sub>、</sub> 交叉<sub>、</sub> 重组等融合形式表现出来，其结果必然导致产业边界的突破以及突破后产业边界的重构，而边界重构体现的则是文化产业原结构和功能的优化<sub>。</sub>

耗散结构理论对于新型文化业态的形成研究同样给予重要启发<sub>。</sub> 系统的开放程度决定系统的生存和发展能力，当系统与外界存在相互作用并进行物质<sub>、</sub> 能量<sub>、</sub> 信息的彼此交换时，才能形成新的有序状态<sub>。</sub> 作为耗散系统，文化产业经济系统内部必然存在正熵 ( 混乱和无序度) 自然增加的过程<sub>。</sub> 从整体优化和系统科学的观点看，新型文化业态的形成则有利于文化产业通过渗透<sub>、</sub> 交叉<sub>、</sub> 重组等方式从无序走向有序，从而有效抑制文化产业系统正熵增加，推动文化产业结构实现合理化与高度化

## 二<sub>、</sub> 产业经济学角度

从产业经济学角度看，新型文化业态的生成与运作源于价值链重构与产业链协同<sub>。</sub>

## 1. 价值链重构

所谓 <sup>“</sup>价值链<sup>”</sup>，是指企业在生产产品或提供服务时，各价值环节分别承担一定的价值创造功能，上下游各价值环节之间分工协作，共同向用户提供价值的一系列活动<sub>。</sub>

价值链重构，即文化企业打破原有生产最终产品或服务所经历的价值增加过程，对价值增加环节予以重新识别或整合 以广播电视业为例，其价值链环节包括内容制作节目播出<sub>、</sub> 广告经营和衍生服务<sub>。</sub> 其中，内容制作涉及广播电台<sub>、</sub> 电视台的总编室或其他社会性的内容生产部门，节目播出涉及广播电台 电视台的节目播出机构，广告经营涉及广播电台<sub>、</sub> 电视台的广告部或其他社会性广告代理公司和机构，衍生服务涉及与广电产品价值增值相关的所有衍生部门，如音像<sub>、</sub> 软件<sub>、</sub> 旅游<sub>、</sub> 娱乐<sub>、</sub> 玩具<sub>、</sub> 服装等<sub>。</sub>对于广播电视业来说，通过横向延伸与纵向拓展，可整合形成以内容产品为核心，以电视<sub>、</sub> 广播<sub>、</sub> 网络<sub>、</sub> 报纸<sub>、</sub> 图书<sub>、</sub> 杂志<sub>、</sub> 光盘等为传播渠道，通过内容创意生产<sub>、</sub> 推广<sub>、</sub>交易 传播 受众反馈及广告等关联环节形成价值运作体系的新型文化业态<sub>。</sub>

例如，广电巨头英国广播公司 ( BBC) 算得上多媒体融合变革中的翘楚<sub>。</sub> 在数字广播和数字电视领域，BBC 占据着全球最新传播科技的制高点; 在新媒体业务方面，BBC更成为电视台模仿的对象<sub>。</sub> 旗下 Top Gea》 是世界范围内知名度最高<sub>、</sub> 历史最悠久的时尚汽车节目之一，粉丝达 3. 5亿<sub>。</sub> 在制作日常节目之外，Top Gear 还出售节目版权，组织社会活动，出版发行音乐磁带<sub>、</sub> 录像带<sub>、</sub> CD<sub>、</sub> DVD<sub>、</sub> 杂志<sub>、</sub>游戏，生产纪念品等<sub>。</sub> Top Gear 在 <sup>“</sup>BBC 在线<sup>”</sup> 有一个与节目内容密切挂钩的官网，同时还有一个能够刊登广告和负责销售相关衍生品 ( 服装<sub>、</sub> 杂志<sub>、</sub> 音像制品等) 的商业网站 topgear. com <sub>。</sub> 2010 年，BBC 环球公司将 Top Gear 列为知名品牌的高端产品，其年收入位列环球公司整体销售收入 ( 广告<sub>、</sub> 零售与服务) 第一<sub>。</sub>

## 2. 产业链协同

为便于分析和研究，我们将产业链与价值链进行进一步的区分和界定 概括地说，产业链与价值链是彼此联系又相互区别的两个概念<sub>。</sub> 二者的关系主要体现在两个方面:第一，产业链各参与者与价值链各环节经常不一一对应，产业链中的企业可能只对应一个价值环节，也可能对应多个价值环节; 第二，价值链上的单一价值环节可能分解为几个子环节，某个价值环节可能由产业链上的几类企业来完成<sub>。</sub>

产业链协同，即对文化产业内部各参与企业的不同价值创造功能及其分工合作关系按照协同方式进行整合，使产业系统产生 <sup>“</sup>1 +1 ＞2<sup>”</sup> 的系统经济效应<sub>。</sub> 以广播电视业为例，其产业链包括内容生产<sub>、</sub> 内容集成<sub>、</sub> 平台运营和技术服务 其中，内容生产涉及所有的内容制作部门，内容集成涉及集成 包装 销售内容的所有部门，平台运营以有线网络运营商为主，同时涉及卫星及微波网络运营商，技术服务涉及与音频 视频业务相关的所有硬件或软件公司 对于广播电视业来说，通过协同上下游企业的分工合作关系，能够形成以水平一体化 垂直一体化或混合一体化为特征的新型文化业态<sub>。</sub>

如，2012 年6 月，中国电信正式推出运营商级的云手机，与之前北京电信引入过的手机厂家推出的云手机不同，该手机不限于某一款或几款特定型号，任意一款安装 <sup>“</sup>天翼桌面<sup>”</sup> ( 中国电信自主开发的云手机应用软件) 的中国电信3G 智能机都可以成为一台云手机<sub>。</sub> 所谓 <sup>“</sup>云手机<sup>”</sup>，与普通手机最大的不同就在于拥有一个强大的后端云平台<sub>。</sub>目前北京电信搭建完成的云手机服务平台，可向全国的云手机用户提供 GB 级的个人存储和丰富的在线应用<sub>。</sub> 中国电信推出云手机，正是电信产业网络运营商向下游终端设备生产商进行垂直整合的直接结果，有助于电信运营商通过手机应用布局而产生的软件增值服务获取更多利益

## 三<sub>、</sub> 传媒经济学角度

从传媒经济学角度看，文化产业具有的网络外部性与联结经济性特征将通过子产业之间的合作竞争自然地导致新型文化业态生成<sub>。</sub> 网络外部性与联结经济性均强调了复数主体通过网络联结所产生的集成效应，网络经济条件下合作型文化经济组织大量涌现，打破原有产业及产业间的经营界限，从而推动新型文化业态生成<sub>。</sub>

所谓网络外部性，指每个用户连接到网络的价值取决于已连接到该网络的其他用户的数量，也叫需求方规模经济<sub>。</sub> 梅特卡夫法则 ( Metcalfe Law) 形象地说明了网络外部性，即网络的价值与其用户数量的平方成正比<sub>。</sub> 以有线电视为例，有线电视网络的需求方即用户的含义是多重的，它不仅指电视节目的收看者———受众，也指电视节目的播出机构———电视台，还包括进行视频点播等其他更高级业务的用户<sub>。</sub> 对于有线电视来说，其网络规模 ( 即用户数量)扩大100 倍，则其网络价值就增长10000 倍<sub>。</sub>

在以非信息运行平台为主导的工业经济时代，单一经济主体或者通过大批量专业化生产获得 <sup>“</sup>规模经济性<sup>”</sup> 效果，或者通过拓展产品经营范围实行多角化经营获得 <sup>“</sup>范围经济性<sup>”</sup> 效果<sub>。</sub> 而在信息网络化社会中，分属于不同经营领域的复数市场主体通过信息网络异业联手<sub>、</sub> 协同合作，开发新产品，能够更迅速地满足不断变动的多方面的消费需求，获得更大的经济效果 ( 周振华，2004)

网络经济条件下文化产业合作型组织的典型形式有战略联盟 虚拟企业 业务外包等 仍以 BBC 为例，2002年，BBC 联合独立电视台与第四频道开通免费的 Freeview数字电视平台; 2009 年，由 BBC<sub>、</sub> 独立电视台<sub>、</sub> 第四频道和星空媒体共同开发的免费数字卫星电视平台 Freesat 开始播放高清节目; 2010 年，Freeview 推出高清节目; 2011 年，由 BBC<sub>、</sub> 独立电视台<sub>、</sub> Arqiva<sub>、</sub> 第四频道<sub>、</sub> 第五频道<sub>、</sub> 英国电信和 Talk Talk 联合投资 ( BBC 拥有 16. 6% 股权) ，提供电视互联网视频服务 ( IPTV) 的 <sup>“</sup>画布<sup>”</sup> ( Project Canvas)项目开通<sub>。</sub> 2009 年，BBC 还和四家报纸媒介与一些网站成立新闻视频共享项目，得到良好口碑<sub>。</sub> 在技术研发和应用程序开拓上，BBC 和 IT 业精英们有着深度合作，如微软和苹果公司<sub>。</sub> 合作型文化产业组织不仅拓展了文化市场或文化产业的边界，而且使文化企业获得了超出自身范围之外的资源，同时降低了市场交易的不确定性<sub>。</sub>

网络经济特征背景下合作型文化经济组织的大量涌现，有助于在文化产业内部以及文化产业与其他产业之间形成新型的竞争协同关系，从而加速文化产业集成化的进程具体来说，合作型文化产业组织通过复数市场主体联结产生联结经济效应，进一步导致 <sup>“</sup>业际化<sup>”</sup> 倾向，即各产业部门打破原有产业及产业间的经营界限 相互介入，从而形成一种新型的产业间竞争和协同关系<sub>。</sub> 这种新型关系不仅比企业经营多角化所涉及的范围更加广泛和深刻，而且比通常所说的 <sup>“</sup>兼业化<sup>”</sup> 更具有竞争色彩 它不仅是由于产业内部或产业间的进入障碍降低而出现的产业集成关系，而且是更为激烈的竞争关系<sub>。</sub> 在合作竞争过程中，文化产业组织通过与拥有互补性资源和能力的经济组织建立更为紧密的合作与交易关系从而获取协作收益，文化产业组织结构日趋网络化，文化产业边界日趋开放化，于是，新型文化业态的出现成为必然
