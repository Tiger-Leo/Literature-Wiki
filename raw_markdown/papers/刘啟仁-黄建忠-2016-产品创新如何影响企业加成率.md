# 产品创新如何影响企业加成率

刘啟仁 黄建忠<sup>\*</sup>

内容提要 本文从成本加成率角度分析企业获取创新垄断租金的微观机制，一方面，产品创新通过增加市场份额降低产品需求弹性，企业可以索要更高的加成率，即<sup>“</sup>市场份额效应<sup>”</sup>; 另一方面，产品创新带来的生产率提升促使企业边际成本降低，进而提升加成率，即 <sup>“</sup>成本效应<sup>”</sup> 我们理论分析了 <sup>“</sup>市场份额效应<sup>”</sup>，并在成本加成率和生产率估计模型中考虑 <sup>“</sup>成本效应<sup>”</sup>，将企业创新纳入其生产率动态过程 利用2001－2007 年中国工业企业数据研究验证了以下理论预期: 产品创新通过增加市场份额显著提升了企业成本加成率，与此同时，产品创新也通过降低边际成本显著提升成本加成率，但 <sup>“</sup>成本效应<sup>”</sup>弱于 <sup>“</sup>市场份额效应<sup>”</sup> 考虑创新的自选择 测量误差和内生性问题后结论仍然稳健

关 键 词 产品创新 成本加成率 市场份额 生产率 垄断租金

## 一 引言

随着技术更新速度的加快和全球市场竞争的加剧，产品和服务的固有优势被迅速侵蚀，企业要进入新市场<sub>、</sub>增加市场份额和增强竞争优势，最基本的手段是不断创新<sub>。</sub>创新与企业绩效关系要追溯到 Schumpeter(1934) 的研究，他认为创新具有两大功能:一是创新可以抵消要素边际报酬递减的不利影响;二是创新通过生产要素的重新组合可以突破资源稀缺的瓶颈问题<sub>。</sub> 总之，创新能力是影响企业绩效的重要因素之一( Subramaniam 和 Youndt，2005) <sub>。</sub>

由于投资创新的利得具有不确定性，企业根据预期创新利得来决定其创新投资水平 因此，明确创新利得的获取机制对促进企业和政府投资创新均具有重要意义 目前研究创新利得的文献主要集中在以下两个方面: 其一，创新与企业利润 股票市值等显性绩效关系 Bowen 等(2010) 采用 Meta 分析法对这类文献进行分析发现创新对企业绩效的影响并无一致结论，例如，Matsuo(2006) 认为企业市场导向型创新有助于提升企业销售部门的绩效，但是，Balkin 等(2000) 却认为创新并不能改善企业未来绩效，Hitt 等(1997) 则认为产品创新与企业绩效具有非线性关系，该关系的正负还取决于企业市场多样化的大小 其二，创新与企业生产率的关系 Hall 等(2010) 认为大部分文献均发现创新研发对企业生产率提升具有显著的促进作用，针对中国企业数据的研究也得出类似的结论( 吴延兵，2006)

一个值得注意的问题是 <sup>“</sup>生产率<sup>”</sup>并不等同于 <sup>“</sup>盈利能力<sup>”</sup>，后者区别于前者的关键在于它不但取决于物理投入产出技术效率，而且取决于产品差异和在边际成本上的加成率大小 目前企业级生产率主要采取 Olley 和 Pakes( 1996) ( 下文简称 OP) 和Levinsohn 和 Petrin( 2003) ( 下文简称 LP) 等方法得到，该生产率实质上为 <sup>“</sup>测量的生产率( measured productivity) <sup>”</sup>，从而掺杂了价格和成本等因素 创新不但影响到实际生产率( 即投入产出技术效率) ，还会影响企业的成本加成率( markup) ，但是以上文献均忽视了创新对企业成本加成率的影响 <sub>。</sub> 实际上，Aghion 和 Howitt( 1992) Klette 和Griliches(2000) 等文献均认为企业投资创新最主要的目的是为了获得垄断租金，即在其新产品被模仿出来之前，企业可以在其边际成本上设定更高的加成率<sub>。</sub> 企业成本加成率是指产品或服务的定价超过其成本的幅度，它是衡量市场垄断能力的关键指标( 刘啟仁和黄建忠，2015) 创新活动最终能让企业获取多大的利润，首先要看创新产品能否获得市场的认可，其次关键还要看企业在其边际成本上能够设定多高的加成率，加成率越高单位利润越大 因此，本文采用成本加成率衡量垄断租金的大小，检验产品创新带来的垄断租金激励，并试图分析企业获取创新垄断租金的微观机制<sub>。</sub>

那么产品创新如何影响企业绩效呢? 新经济增长理论学者分析了创新研发对社会全要素生产率的促进作用( Solow，1957) ，在微观研究方面，Hall 等(2010) 的综述研究也发现大部分文献均认为创新研发对企业生产率具有提升作用，这意味着产品创新能促使企业边际成本节省，进而可以增加 <sup>“</sup>价格边际成本指数<sup>”</sup>( price-cost margin in-dex) ，本文称为产品创新的 <sup>“</sup>成本效应<sup>”</sup> 但是以上分析仅仅停留在企业内部改进层面，产品创新还能产生企业间的市场重新配置效应，导致企业间的绩效差异( 外部改进) Kim 和 Mauborgne(1997) 认为产品创新不但能让企业适时满足不断变化的消费者需求，而且能够持续不断地在其产品上创造和增强价值，因此，产品创新为企业提供了一个比竞争对手更好地代表收益和满足消费者需求的平台，进而得到更好的市场表现 Rosenbusch 等(2011) 采用 Meta 分析法验证了产品创新对企业绩效的促进作用但是，现有文献并没有提出产品创新影响企业绩效的具体机制，也没有将以上产品创新的内部改进和外部改进结合起来分析

本文从企业内部的生产率改进和外部的市场份额提升两方面综合分析产品创新的影响机制 我们首先基于 Atkeson 和 Burstein(2008) 的研究从市场份额渠道分析了企业获取创新垄断租金的具体机制，研究结果表明: 产品创新能通过增加市场份额降低产品需求弹性，企业进而可以索要更高的加成率，即 <sup>“</sup>市场份额效应<sup>”</sup> 与此同时，产品创新带来的生产率提升促使企业边际成本降低，进而提升其成本加成率，即 <sup>“</sup>成本效应<sup>”</sup> 我们在计量估计中纳入了 <sup>“</sup>成本效应<sup>”</sup>的影响，将企业创新纳入其生产率动态过程估计成本加成率和生产率 利用2001－2007 年中国工业企业数据分析支持了以下理论预期: 产品创新通过增加市场份额显著提升了企业成本加成率，与此同时，产品创新也通过降低边际成本显著提升成本加成率，但 <sup>“</sup>成本效应<sup>”</sup>弱于 <sup>“</sup>市场份额效应<sup>”</sup>，考虑创新的自选择 测量误差和内生性问题后结论仍然稳健<sub>。</sub>

与已有的研究相比，本文的贡献主要体现在以下四个方面: 第一，我们分析了企业产品创新对其成本加成率的影响，因而更为直接地评估了创新的垄断租金大小;第二，我们从企业内部和企业间两个维度提出了创新影响成本加成率的具体机制，分析了创新的<sup>“</sup>市场份额效应<sup>”</sup>和<sup>“</sup>成本效应<sup>”</sup>;第三，我们注意到了企业创新对其生产率的动态影响，即<sup>“</sup>成本效应<sup>”</sup>，将企业创新行为纳入企业生产率动态过程，基于 Ackerberg 等(2015) ( 下文简称 ACF) 的研究分两步较为稳健地估计得到企业成本加成率和生产率;第四，我们还考虑了企业创新的自选择 测量误差和内生性问题，较为稳健地验证了创新<sup>“</sup>市场份额效应<sup>”</sup>和<sup>“</sup>成本效应<sup>”</sup>的显著贡献<sub>。</sub>

本文其余部分安排为: 第二部分为创新的 <sup>“</sup>市场份额效应<sup>”</sup>机理分析; 第三部分为考虑创新<sup>“</sup>成本效应<sup>”</sup>的企业成本加成率和生产率估计方法及结果; 第四部分为计量模型 数据与变量说明;第五部分为经验检验结果与稳健性讨论;最后为结论

## 二 创新的 <sup>“</sup>市场份额效应<sup>”</sup>机理分析

企业投资创新最主要的目的是为了获得垄断租金( Aghion 和 Howitt，1992; Klette和 Griliches，2000) 首先，创新有助于企业生产率攀升( Hall 等，2010) ，相应的边际成本更具优势，进而带来更高的加成率，即创新的 <sup>“</sup>成本效应<sup>”</sup>; 其次，企业创造的新产品往往能更迎合消费者的偏好需求，在新产品被模仿前该企业的产品组合具有更有利的偏好优势，进而提高企业的市场份额，市场份额的号召力又使得消费者对该产品组合的需求价格弹性比较低，因此，垄断竞争厂商就可以在其边际成本上设定更高的加成率，进而获取更大的单位利润，即创新的<sup>“</sup>市场份额效应<sup>”</sup>

我们基于 Atkeson 和 Burstein(2008) 的研究从市场份额渠道分析企业获取该垄断租金的具体机理 参考 Ju( 2003) Bernard 等( 2010) 和 Bernard 等( 2011) 的多产品概念<sup>①</sup>，我们考虑行业j 中的企业 i 生产差异性产品组合( indexes products) ，对于产品创新企业，该产品组合既包括新产品组( new) ，也可能包括老产品组( －new) ，企业产品创新后既可能保留老产品，也可能舍弃部分老产品，甚至可能出现新产品完全替代老产品的情形 新产品在企业产品组合中的地位取决于其销售占比，新产品占比越高企业内部的资源分配也越偏向于新产品<sup>②</sup><sub>。</sub>

我们假设企业 i 面对的消费者具有嵌套的 CES 需求函数，则该企业的市场需求指数( consumption index) 为 C:

$$
C _ {i j} = \Lambda (- n e w _ {i j}, n e w _ {i j}) P _ {i j} ^ {- \rho} P _ {j} ^ {\rho - \eta} D _ {j}\tag{1}
$$

其中， $C _ { i j }$ 为消费者对企业 i 产品组合的需求指数，Λ( · ) 为该企业产品组合的相对偏好，Kim 和 Mauborgne (1997) 认为产品创新为企业提供了一个比竞争对手更好地代表收益和满足消费者需求的平台，因此，我们假设它为产品创新( $n e w _ { i j } )$ 的增函数，则有 $\partial { \cal { \Lambda } } / \partial n e w > 0$ ，即产品创新有助于提高整体企业产品组合的相对偏好位置，新产品占比越高，该企业产品组在行业内的偏好也越处于有利位置 $P _ { i j }$ 为企业 i 产品组合的价格指数， ${ \mathbf { } } _ { } { P } _ { j }$ 为行业j 的价格指数 ${ \pmb \mathscr P }$ 为行业内部不同企业产品组合之间的替代弹性，而 $\eta$ 为行业间的替代弹性，假设 $\rho > \eta \geqslant 1$ ，即行业内产品的可替代性大于行业间产品的可替代性<sup>①</sup>， $D _ { j }$ 为行业的共同需求因子，企业视其为给定，为了简便我们省略了时间下标 t <sub>。</sub>

基于嵌套的CES 需求函数，行业价格指数为 $P _ { j } \equiv \ [ \sum _ { i } \varLambda ( \ - n e w _ { i j } , n e w _ { i j } ) P _ { i j } ^ { 1 - \rho } ] ^ { 1 / ( 1 - \rho ) }$ 我们单位化 $\Sigma _ { i } { \varLambda } ( { \mathrm { ~ -- ~ } } n e w _ { i j } { \mathrm { ~ } } { \mathrm { , } } n e w _ { i j } ) { \mathrm { ~ } } = 1$ ，则企业i 的市场份额为:

$$
S _ {i j} \equiv \frac {P _ {i j} Q _ {i j}}{\sum_ {n} P _ {n j} Q _ {n j}} = \Lambda (- n e w _ {i j}, n e w _ {i j}) \left(\frac {P _ {i j}}{P _ {j}}\right) ^ {1 - \rho}\tag{2}
$$

其中 $\bullet S _ { i j } \in \ [ 0 , 1 ]$ 为企业 i 在行业j 中的市场份额 给定企业相对价格不变，则创新与市场份额的关系为: $\partial S _ { i j } / \partial n e w _ { i j } = \left( \ \partial \Lambda / \partial n e w _ { i j } \right) \mid { \cal P } _ { i j } / P _ { j } ^ { \phantom { } 1 - \rho } > 0$ ，因此，我们得到以下命题:

命题1:给定企业相对价格不变，产品创新能增加企业市场份额<sup>②</sup><sub>。</sub>

此外，企业 i 的实际需求弹性为:

$$
\sigma_ {i j} \equiv - \frac {d \log Q _ {i j}}{d \log P _ {i j}} = (1 - S _ {i j}) \rho + S _ {i j} \eta = \rho + (\eta - p) S _ {i j}\tag{3}
$$

由上式我们可以看出，企业实际需求弹性为按市场份额的行业内和行业间替代弹性的加权平均，由于 $\eta \varphi < 0$ ，则高市场份额企业具有更低的实际需求弹性，使得需求对其自身价格更不敏感 即 $\partial { \sigma _ { i j } } / \partial n e w _ { i j } = \left( \begin{array} { c } { { \eta \mathbf { \overline { { \mathbf { \sigma } } } } } } \end{array} \right) \partial S _ { i j } / \partial n e w _ { i j } < 0$ ，则企业创新通过增加市场份额可以降低实际需求弹性，因此，我们得到以下命题:

命题2:企业产品创新通过增加市场份额可以降低实际需求价格弹性<sub>。</sub>

按垄断竞争企业成本加成定价公式我们得到企业成本加成率为:

$$
\mu_ {i j} = \sigma_ {i j} / (\sigma_ {i j} - 1)\tag{4}
$$

由上式可知，企业实际需求价格弹性 $\mid \sigma _ { i j } \mid$ 越低，企业成本加成率 $\big ( \mu _ { i j } \big )$ 越高，即

${ \partial \mu _ { i j } } / { \partial \sigma _ { i j } } < 0$ ，因此，我们可以得到企业创新与成本加成率的关系:

$$
\frac {\partial \mu_ {i j}}{\partial n e w _ {i j}} = \frac {\partial \mu_ {i j}}{\partial \sigma_ {i j}} \cdot \frac {\partial \sigma_ {i j}}{\partial n e w _ {i j}} = \frac {\partial \mu_ {i j}}{\underbrace {\partial \sigma_ {i j}} _ {<   0}} \times \underbrace {\left(\eta - \rho\right)} _ {<   0} \frac {\partial S _ {i j}}{\underbrace {\partial n e w _ {i j}} _ {> 0}} > 0\tag{5}
$$

由上式和命题1 命题2 可知，企业进行产品创新使得其在行业内达到更有利的相对偏好位置，这会引起企业市场份额的增加，企业的实际需求价格弹性受制于企业市场份额影响力而变小，最终企业可以在市场上索要更高的成本加成率<sub>。</sub> 因此，我们可以综合得到以下命题:

命题3:企业产品创新通过增加市场份额降低实际需求价格弹性，进而提升企业成本加成率，存在创新的<sup>“</sup>市场份额效应<sup>”</sup>

总之，创新不但从企业内部改进了成本优势，而且从企业外部获取了更大的市场份额，两者均有助于创新企业获取更大的创新垄断租金<sub>。</sub> 以上两个改进效应还有可能存在相互强化，例如: 具有成本优势企业也有助于获取更大的市场份额，因此，我们在经验分析时可能需要同时纳入以上两种机制

## 三 纳入创新 <sup>“</sup>成本效应<sup>”</sup>的加成率估计

创新研发对企业生产率提升具有显著的促进作用( Hall 等，2010) ，创新的 <sup>“</sup>成本效应<sup>”</sup>和<sup>“</sup>市场份额效应<sup>”</sup>可能存在相互强化，在估计成本加成率时割裂创新对生产率的影响可能导致偏误 因此，为纳入<sup>“</sup>成本效应<sup>”</sup>的影响，我们在企业成本加成率和生产率的估计模型中将企业创新行为纳入企业生产率动态过程

## ( 一) 加成率估计方法的回顾

加成率估计方法主要分为会计法和计量估计法( 钱学锋和范冬梅，2015) 会计法的缺陷在于它只有在规模报酬和资本使用成本不变的条件下才等于真实的加成率因此，越来越多的学者试图从企业要素投入和产出信息中估计加成率，即计量估计法，该方法考虑了企业资本使用成本的变化和规模报酬的差异性 Hall (1986) 首先构建了行业加成率的模型框架，该方法主要基于生产函数结构的分析，在完全竞争市场条件下企业追求利润最大化，则当边际收益等于边际成本时，可变生产要素的产出弹性等于该要素投入占总产出的比率 在不完全竞争市场环境下两者并不相等，但两者的关系可反映出相应的加成率

Hall (1986) 是成本加成率估计的基准模型，然而，在实际运用中该方法还存在一系列问题，最大的问题在于一些不可观测的因素会影响到企业的产出，其中最重要的因素为生产率，由于生产率往往与企业投入选择相关，不控制生产率冲击将导致产出弹性系数的估计产生偏误<sub>。</sub> 因此，部分学者采用工具变量和 GMM 方法进行改进( Wooldridge，2009) 另外两个常用的解决企业投入内生性问题的方法分别为 OP 和LP 法，他们分别基于企业投资和中间投入与生产率的单调关系对不可观测的生产率进行控制 De Loecker 和 Warzynski ( 2012) ( 下文简称 DLW) 进一步完善了 Hall ( 1986) 的方法，采用ACF 方法进行估计 刘啟仁和黄建忠(2015) 则根据 Martin (2010) 的研究选取企业<sup>“</sup>净收入<sup>”</sup>控制企业生产率，并对中国工业企业的加成率水平进行了估计<sub>。</sub>

本文在 DLW 的基础上将企业创新行为纳入生产率动态过程，依据 ACF 两步法估计得到较为稳健的要素产出弹性系数<sup>①</sup><sub>。</sub> 另外，我们还考虑了创新选择对企业生存的影响，采用 Probit 模型估计了企业退出的概率，以控制生产函数估计中的 <sup>“</sup>样本选择性偏差( sample selection bias) <sup>”</sup> <sub>。</sub>

## ( 二) 纳入创新<sup>“</sup>成本效应<sup>”</sup>的加成率估计模型

Hall (1986) 估计行业成本加成率的模型基准式为:

$$
\mu = \left(\partial \ln Q / \partial \ln X\right) / S _ {X}\tag{6}
$$

其中 ${ \bf \Omega } _ { \bullet } S _ { \cal x }$ 为要素X 的支出占企业 i 总产出的份额<sub>。</sub> 不难看出，在完全竞争市场条件下企业追求利润最大化 $\mathbf { \nabla } \cdot \boldsymbol { \mu } = 1$ ，则有 $\partial \ln Q / \partial \ln X = S _ { X }$ ，即要素的产出弹性等于该要素投入的产出占比 然而，在不完全竞争市场环境下投入要素的产出占比与其产出弹性并不相等，但两者的关系可反映出相应的加成率<sub>。</sub>

加成率估计的关键在于如何得到稳健的可变要素产出弹性 为更好地与企业观测数据吻合，我们假设观测的工业总产值对数 $y _ { i t } = \ln Q _ { i t } + \varepsilon _ { i t }$ ，其中 <sub>ε</sub> 为包含测量误差等不可预期的 i. i. d 随机冲击，因此相应的生产函数为:

$$
y _ {i t} = f (x _ {i t}; \beta) + \omega_ {i t} + \varepsilon_ {i t}\tag{7}
$$

生产函数f( · ) 通常被假定为<sup>“</sup>科布 －道格拉斯( 下文简称 CD) <sup>”</sup>形式，其缺点在于各企业的要素产出弹性均相等且固定不变，因此加成率的变化仅来自于企业层面的要素投入份额的变化<sub>。</sub> 为增强生产函数的灵活性和适用性，我们采用由 Christensen等 ( 1973) 提出的 <sup>“</sup>超越对数形式( 下文简称 Translog) <sup>”</sup> :

$$
\begin{array}{r l} y _ {i t} = & \beta_ {l} l _ {i t} + \beta_ {k} k _ {i t} + \beta_ {m} m _ {i t} + \beta_ {l l} l _ {i t} ^ {2} + \beta_ {k k} k _ {i t} ^ {2} + \beta_ {m m} m _ {i t} ^ {2} \\ & + \beta_ {l k} l _ {i t} k _ {i t} + \beta_ {k m} k _ {i t} m _ {i t} + \beta_ {l m} l _ {i t} m _ {i t} + \beta_ {l k m} l _ {i t} k _ {i t} m _ {i t} + \omega_ {i t} + \varepsilon_ {i t} \end{array}\tag{8}
$$

其中 $\bullet \boldsymbol { y }$ 为工业总产值，l<sub>、</sub>k 和 m 分别为劳动<sub>、</sub>资本和中间材料投入要素 ${ \bf \Pi } _ { 9 } \omega$ 为企业异质性生产率，以上小写字母均为相应变量的自然对数，<sub>ε</sub> 为随机误差项<sub>。</sub> 从上式可以看出，中间材料 $m$ 的产出弹性为 $\beta _ { m } + 2 \beta _ { m m } m _ { i t } + \beta _ { k m } k _ { i t } + \beta _ { l m } l _ { i t } + \beta _ { l k m } l _ { i t } k _ { i t }$ ，因此中间材料产出总弹性不但与其本身相关，而且也与资本和劳动投入相关，因而考虑了企业资本和劳动使用成本的变化，体现了 <sup>“</sup>计量法<sup>”</sup>与 <sup>“</sup>会计法<sup>”</sup>的区别<sub>。</sub> 总之，采用 Translog生产函数估计出的要素产出弹性在企业间具有差异性且时间上具有变化性<sub>。</sub>

为稳健地估计上式的要素产出弹性系数，我们根据 ACF 两步法进行估计: 第一步，我们采用非参方法对生产函数进行估计:

$$
y _ {i t} = \phi_ {t} (l _ {i t}, k _ {i t}, m _ {i t}) + \varepsilon_ {i t}\tag{9}
$$

再得到估计的产出 $\bigl ( \hat { \phi } _ { i t } \bigr )$ 和随机冲击 $\textstyle { \bigl ( } { \widehat { \varepsilon } } _ { i t } { \bigr ) }$ ，上式的 $\phi _ { i t }$ 由下式给出:

$$
\begin{array}{r l} \phi_ {t} (l _ {i t}, k _ {i t}, m _ {i t}) & \equiv \phi_ {i t} = \beta_ {l} l _ {i t} + \beta_ {k} k _ {i t} + \beta_ {m} m _ {i t} + \beta_ {l l} l _ {i t} ^ {2} + \beta_ {k k} k _ {i t} ^ {2} + \beta_ {m m} m _ {i t} ^ {2} + \beta_ {l k} l _ {i t} k _ {i t} \\ & \qquad + \beta_ {k m} k _ {i t} m _ {i t} + \beta_ {l m} l _ {i t} m _ {i t} + \beta_ {l k m} l _ {i t} k _ {i t} m _ {i t} + \omega_ {i t} \end{array}\tag{10}
$$

其中，虽然生产率 $\omega _ { i t }$ 无法观测，但是我们可以采用 LP 类似的控制方程方法<sup>①</sup>，选取中间材料投入( m) 和资本( k) 对不可观测的生产率进行控制，处理要素投入的内生性问题，即:

$$
\omega_ {i t} = h _ {t} (m _ {i t}, k _ {i t})\tag{11}
$$

第二步则依据对生产率动态过程的假设来估计生产函数中的弹性系数 本文与OP 和 LP 类似，也假设生产率服从马尔可夫( Markov) 过程 <sub>。</sub> 但是，Doraszelski 和 Jau-mandreu (2013) Hall 等(2010) 等均认为企业创新活动对其生产率能产生显著影响，即本文提出的创新 <sup>“</sup>成本效应<sup>”</sup> 因此，本文将企业创新行为( new) 纳入生产率动态过程，即:

$$
\omega_ {i t} = g \left(\omega_ {i t - 1}, \omega_ {i t - 1}, n e w _ {i t - 1}\right) + v _ {i t}\tag{12}
$$

其中， $, g ( \mathrm { ~  ~ \cdot ~ } ) = \mathrm { E } _ { \mathrm { t } - 1 } \{ \omega _ { i t } \} , \omega _ { i t - 1 }$ 为厂商退出的生产率下限值， $n e w _ { i t - 1 }$ 为新产品产值的对数， $v _ { i t }$ 为独立同分布的生产率随机冲击<sup>②</sup><sub>。</sub>

我们还采用了 Probit 模型估计企业退出概率，即估计以下模型:

$$
P _ {i t} = P \big (k _ {i t - 1}, m _ {i t - 1}, z _ {i t - 1} \big)\tag{13}
$$

其中 $\pmb { \mathscr { s z } } _ { i t - 1 }$ 为产出价格指数<sup>①</sup>，代表需求方面的冲击因素<sub>。</sub> P( · ) 仍然采用 Trans-log 形式进行估计，最终将得到的退出概率估计值 $\hat { \boldsymbol P } _ { i t }$ 代替不可观测的企业退出生产率下限 $\mathbf { \nabla } _ { \omega _ { i t - 1 } }$

第一阶段得到产出 $\widehat { \phi } _ { i t }$ 后，对任意参数向量 $( \mathbf { \Sigma } _ { \beta _ { l } } , \mathbf { \Sigma } _ { \beta _ { k } } , \mathbf { \Sigma } _ { \beta _ { m } } , \beta _ { l l } , \mathbf { \Sigma } _ { \beta _ { k k } } , \mathbf { \beta } _ { \beta _ { m m } } , \beta _ { l k } , \mathbf { \beta } _ { \beta _ { k m } } , \beta _ { l m } , \mathbf { \Sigma } _ { m } )$ $\beta _ { l k m } \big )$ ，我们均可以由式(10) 计算出相应的生产率 $\omega _ { i t } \vert \beta \vert$ 然后，我们采用非参方法将$\omega _ { i t } \vert \beta \vert$ 对其滞后项 滞后生产率下限( 用退出概率估计值 $\hat { P } _ { i t - 1 }$ 代替) 以及创新行为指标( $n e w _ { i t - 1 } )$ 进行回归估计得到式(12) 中的生产率随机冲击 $\widehat { v } _ { i t } \left( \beta \right)$ 接下来，我们需要利用生产率随机冲击与当期固定要素<sub>、</sub>滞后期可变要素投入不相关的矩条件:

$$
\left. \right.\left[ v _ {i t} (\beta) \left(l _ {i t - 1}, k _ {i t}, m _ {i t - 1}, l _ {i t - 1} ^ {2}, k _ {i t - 1} ^ {2}, m _ {i t - 1} ^ {2}, l _ {i t - 1} k _ {i t}, k _ {i t} m _ {i t - 1}, l _ {i t - 1} m _ {i t - 1}, l _ {i t - 1} k _ {i t} m _ {i t - 1}\right)\right] = 0\tag{14}
$$

我们采用式(14) 中的矩条件进行 GMM 估计得到生产函数中的弹性系数向量 $\hat { \beta }$ ，最后，我们采用估计的中间材料总产出弹性系数和中间材料支出份额<sup>②</sup>，根据式(6) 计算出企业可变成本加成率，生产率可以同时采用式(10) 计算得到<sub>。</sub>

## ( 三) 加成率估计过程和结果

估计成本加成率时，我们首先对企业工业总产值<sub>、</sub>资本存量等指标进行了平减处理，平减指数来源于 Brandt 等(2012) 的研究，最终得到式(8) 中近似的产量和要素投入量数据，再采用以上估计方法对 <sup>“</sup>国民经济行业分类 GB/T 4754—2003( 下文简称CIC) <sup>”</sup>中的2 位码行业分别估计得到企业成本加成率<sup>③</sup><sub>。</sub> 为增加估计的可参照性，我们首先采用 CD 形式的生产函数进行估计，其次将 CD 生产函数变换为 Translog 形式进行估计，最后，将创新活动纳入生产率动态过程，以 Translog 形式的生产函数估计得到企业成本加成率

从估计结果来看<sup>④</sup>，三种估计结果具有较强的相关性 从不同生产函数形式估计出的加成率全样本均值统计量来看，CD 形式估计的企业成本加成率均值为 1. 276，而采用 Translog 形式估计的均值为1. 278，将创新纳入到企业生产率动态过程后，企业成本加成率均值增加到1. 28 另外，从加成率均值可以看出，三种估计方法均能反映创新企业的加成率优势 为提高生产函数的灵活性以及纳入创新对企业生产率的影响，本文经验分析部分均采用 <sup>“</sup>Translog +创新<sup>”</sup>的估计结果，生产率采用本文第三部分的估计方法同时得到<sup>①</sup><sub>。</sub>

## 四 计量模型<sub>、</sub>数据与变量说明

## ( 一) 计量模型

为检验产品创新对成本加成率的影响机制，我们首先检验产品创新是否带来了显著的加成率差距;其次，我们分别检验<sup>“</sup>市场份额<sup>”</sup>和<sup>“</sup>成本<sup>”</sup>两种效应的显著性; 最后，考虑到以上两种效应的相互强化作用，我们同时检验<sup>“</sup>市场份额<sup>”</sup>和 <sup>“</sup>成本<sup>”</sup>两种效应<sub>。</sub>为检验产品创新是否带来了显著的加成率差距，我们考虑以下计量模型:

$$
\ln \mu_ {i j t} = \alpha_ {0} + \alpha_ {1} n e w d _ {i j t} + \beta X ^ {\prime} + \gamma G _ {r} + \delta_ {j} + \lambda_ {t} + \delta_ {j} \times \lambda_ {t} + \varepsilon_ {i j t}\tag{15}
$$

其中，i 代表企业，j 代表所在的行业，t 为所在年份，被解释变量 lnu 为企业成本加成率的对数 关键的解释变量为产品创新哑变量 newd，我们控制了企业特征变量 X，主要包括企业生产率omega 资本集中度kl 用工人数l 人均工资pwage 和规模哑变量large 此外，我们控制了行业固定效应 δ 年份固定效应 λ 和地理因素 G( 省份哑变量) ，我们还加入了行业与年份交互项(δ ×λ) 以控制难以观测的随时间变化的行业特征 产品创新哑变量的系数 $\alpha _ { I }$ 衡量了企业是否创新带来的加成率百分比差距<sup>②</sup>，我们预期该系数显著为正，即企业产品创新能显著提升企业的成本加成率<sub>。</sub> 检验产品创新的<sup>“</sup>市场份额<sup>”</sup>和<sup>“</sup>成本<sup>”</sup>两种效应时，我们采用以下计量模型:

$$
\begin{array}{r l} \ln \mu_ {i j t} & = \alpha_ {0} + \alpha_ {1} m k s h _ {i j t} + \alpha_ {2} m k s h _ {i j t} \times n e w d _ {i j t} + \beta_ {1} o m e g a _ {i j t} + \beta_ {2} o m e g a _ {i j t} \\ & \times n e w d _ {i j t} + \gamma n e w d _ {i j t} + X \beta + \varphi G _ {r} + \delta_ {j} + \lambda_ {t} + \delta_ {j} \times \lambda_ {t} + \varepsilon_ {i j t} \end{array}\tag{16}
$$

其中， $m k s h _ { i j t }$ 为 t 年企业 i 在行业j 中的市场份额，omega 为相应的生产率对数，其他控制变量与式(15) 一致 市场份额与产品创新虚拟变量交互项( mksh ×newd) 的系数 $\alpha _ { 2 }$ 为企业是否进行产品创新通过市场份额反映出的差异，即无产品创新企业市场份额的贡献为 $\alpha _ { I }$ ，而产品创新企业其市场份额的贡献增加到 $\boldsymbol { \alpha } _ { I } + \boldsymbol { \alpha } _ { 2 }$ ，根据命题3 我们预期 $\alpha _ { I }$ 和 $\alpha _ { 2 }$ 均显著为正，则产品创新通过市场份额效应带来的贡献百分比为( $\alpha _ { 2 } ,$ /$\alpha _ { \scriptscriptstyle I } ) \ \times 1 0 0$ ，即产品创新的<sup>“</sup>市场份额效应<sup>”</sup>大小<sub>。</sub> 同时，生产率与产品创新虚拟变量交互项( omega × newd) 的系数 $\beta _ { 2 }$ 为企业是否产品创新通过成本节省反映出的差异，根据命题1 我们预期 $\beta _ { I }$ 和 $\beta _ { 2 }$ 均显著为正，则产品创新通过成本效应带来的贡献百分比为 $\left( \beta _ { 2 } / \beta _ { l } \right) \times 1 0 0$ ，即产品创新的<sup>“</sup>成本效应<sup>”</sup>大小<sub>。</sub>

我们还采用<sup>“</sup>新产品占比( newrate) <sup>”</sup>进一步衡量企业产品创新情况，以避免测量误差导致的内生性问题<sub>。</sub> 新产品占比越高，该企业产品组合在行业内的偏好越处于有利位置，因此，利用该指标同样可以检验产品创新对加成率的影响<sup>①</sup><sub>。</sub>

## ( 二) 数据处理与变量说明

本文采用2001－2007 年中国工业企业数据库<sup>②</sup>，参考 Brandt 等(2012) 等文献的做法，我们对原始数据进行了一系列匹配整理，在此不再赘述 我们在估计成本加成率后还剔除了加成率的上下5%分位异常值，最终得到1 097 303 个企业年观测值，时间跨度为7 年 另外，林炜(2013) 认为中国劳动力成本的上升显著激励了企业进行创新活动，因此，本文还采用了2001－2007 年城市最低工资数据作为企业创新的工具变量，城市最低工资数据来源于各企业所在地市劳动和社会保障厅，我们再按企业所在地对这两个数据进行匹配<sub>。</sub> 经验分析中用到的除 <sup>“</sup>成本加成率<sup>”</sup>和<sup>“</sup>生产率<sup>”</sup>以外的主要变量定义和说明如下:

1. 企业创新活动 广义的创新是指生产要素的新组合( Schumpeter，1934) ，但目前经验研究中主要的创新指标包含两大类，其一为创新投入，包括: 研发密度 研发经费和研发人员数;另一类为创新产出，包括新产品种类或数量( Audretsch 和 Feldman，1996) 专利申请或发明数( Jaffe，1989) 本文在经验分析中主要根据企业是否报告正的<sup>“</sup>新产品产值<sup>”</sup>构建产品创新哑变量( newd) 来衡量创新活动，采用产品创新哑变量衡量创新活动的优点在于: 首先，与 <sup>“</sup>研究开发费<sup>”</sup>相比，<sup>“</sup>新产品产值<sup>”</sup>数据较为完整③;其次，创新投入转化为产出往往具有一定的时滞性，而<sup>“</sup>新产品产值<sup>”</sup>更能反映出创新的市场结果，从而更贴近本文对企业成本加成率的研究;最后，采用产品创新哑变量回归时能直接得到是否进行产品创新带来的成本加成率差距<sub>。</sub> 然而，仅采用以上的哑变量指标衡量企业创新活动较为单一，为避免单一变量测量误差导致的内生性问题，我们还采用<sup>“</sup>企业新产品产值占工业总产值的比重<sup>”</sup>，即 <sup>“</sup>新产品占比( newrate) <sup>”</sup>，进一步衡量企业产品创新情况<sub>。</sub>

2. 企业市场份额<sub>。</sub> 根据理论分析模型，我们按 CIC3 位码行业分别计算企业在该行业的市场份额，即<sup>“</sup>企业工业总产值/行业内所有企业工业总产值合计<sup>”</sup>

3. 其他控制变量<sub>。</sub> 企业加成率的高低与企业自身特征是息息相关的，我们参考了 DLW，首先，资本集中度高的行业往往进入门槛较高，导致竞争相对较小，而且资本集中度高的企业抗风险能力也相对较强，因此这也可能带来较高的加成率，本文采用固定资产合计与从业人员总数比值的对数计算企业资本集中度( kl) ; 其次，规模较大的企业其投入材料的议价能力较强，成本控制能力高，这也会影响到企业加成率，我们一方面采用企业用工人数( l) 衡量规模，另一方面直接构建是否为大型企业的哑变量( large) 进行衡量; 最后，人均工资(pwage) 是企业用工成本的指标，特别是在中国劳动力成本日益上升的背景下，劳动力成本会对企业加成率产生更加重要影响<sub>。</sub>

4. 地理因素 影响企业成本加成率的还有地理因素，首先，中国地区市场分割问题较为严重( 朱希伟等，2005) ，企业则可以采用 <sup>“</sup>价格歧视<sup>”</sup>策略，这就会直接影响到企业的加成率;其次，企业地理上的集聚也会可能产生正外部性，但与此同时，集聚也可能带来更大的竞争，进而改变其成本加成率 我们采用省份的虚拟变量对地理因素进行控制

从变量描述性统计结果可以看出<sup>①</sup>，除哑变量外，新产品占比<sub>、</sub>市场份额<sub>、</sub>生产率和成本加成率的变异系数均较大，这反映出企业间新产品的份额 市场占有率 生产率和成本加成率均存在较大差异，其他控制变量的变异系数均小于 0.6 另外，我们采用核密度图粗略地分析了是否进行产品创新的绩效差异<sup>②</sup>，产品创新企业的市场份额平均高于无产品创新企业，这反映了命题 1 具有一定合理性<sub>。</sub> 另外，采用人均产出衡量企业的生产率显示，产品创新企业绩效优于无产品创新企业，这直观地反映出产品创新能促使边际成本降低，即存在<sup>“</sup>成本效应<sup>”</sup> 最后，产品创新企业的成本加成率也平均高于无产品创新企业，这说明产品创新有助于企业获得市场垄断租金，即命题 3可能成立

2. 样本选择性偏差调整 我们注意到产品创新选择会影响到企业绩效，因此这会影响到企业存活，进而可能导致样本选择性偏差 为解决企业自选择创新带来的样本选择性偏差问题，我们采用 Heckman(1979) 两阶段方法进行调整<sub>。</sub> 首先，我们采用Probit 模型估计企业选择创新的概率:

$$
P r (n e w d = 1) = \Phi (X ^ {\prime} \delta)\tag{17}
$$

其中，X'为影响企业创新选择的变量，企业特征 竞争状况和地理等因素均会影响到企业创新( Pavitt 等，1987; Chen 等，2004) ，我们也同时参考林炜( 2013) 董晓芳和袁燕(2014) 等的研究控制了滞后的生产率 资本集中度 用工人数 人均工资 规模哑变量 所有制性质哑变量和竞争状况变量 另外，我们还采用行业 年份和地理等固定效应控制其他因素

估计式( 17) 后可计算得到逆米尔斯比( inverse Mill <sup>’</sup> s ratio) ，即 $l a m b d a = \varphi \vert \ X ^ { \prime } \delta \vert \ /$ Φ( X'δ) ，其中分子 分母分别为标准正态分布密度和累积分布函数 将第一阶段估计得到逆米尔斯比( lambda) 作为式(15) 的一个控制变量进行回归，若其系数显著则说明处理样本自选择偏差是有必要的 从表1 列(4) Heckmen 两阶段的结果可以看出，lambda 系数显著，因此模型存在样本自选择偏差 调整样本选择偏差后，产品创新带来的企业加成率差距由列(2) 中的0. 4%增加到列(4) 中的0. 5%，其他变量的系数也较为稳健<sub>。</sub>

3. 内生性问题与工具变量回归 尽管我们处理了样本选择偏差，而且采用新产品衡量产品创新的时滞性问题较小，但计量模型中还存在一定的内生性问题，即具有垄断优势的企业更有可能进行产品创新<sub>。</sub> 为降低内生性问题，我们一方面在表 1 列(5) 中将所有解释变量滞后一期进行回归分析，结果仍一致<sub>。</sub> 另一方面，我们试图寻找创新活动的工具变量，可靠的工具变量要满足两个基本条件: 首先，工具变量需与企业创新活动高度相关;其次，工具变量并不直接影响成本加成率 我们遵循微观计量经济学研究中的通常做法，即假设内生性问题只存在于微观个体层面，因此可以考虑采用企业所在行业或地区等更为宏观层面的数量作为工具变量 我们采用滞后一期的城市最低工资作为微观企业创新活动的工具变量，首先，最低工资的上升导致企业劳动力成本上升会迫使企业进行创新( 卫兴华和侯为民，2007; 李钢等，2009; 林炜，2013) ，因此，最低工资与企业创新有较强的相关性<sub>。</sub> 其次，最低工资具有较强的政策强制性，个体企业的市场势力很难对其产生直接影响，因而满足工具变量外生性条件

从表1 列(6) 的工具变量二阶段最小二乘法( IV －2SLS) 结果可以看到，产品创新和生产率的系数有较为明显的上升，是否创新带来的成本加成率差距扩大至16. 9%，除人均工资外，其他变量的系数和显著性均较为稳定 为检验工具变量的适用性，我们对工具变量进行了多种检验: 首先，Kleibergen 和 Paap(2006) 的 LM 统计量检验未被包括的工具变量是否与内生变量相关，其 P 值(0.000) 反映出其在 1%显著水平拒绝了 <sup>“</sup>工具变量识别不足<sup>”</sup>的原假设; 其次，Kleibergen 和 Paap( 2006) 的 F 统计量也远大于 Stock-Yogo 弱识别检验的 10%临界值，因此拒绝了最低工资变量弱识别的原假设 因此，工具变量二阶段回归结果是可靠的 总之，解决内生性问题后，我们仍然可以发现企业创新对其成本加成率的显著贡献

4. 测量误差导致的内生性问题 我们在前文中均只采用是否产品创新的哑变量来衡量创新，因此指标较为单一，而指标测量误差也可能带来内生性问题 为避免变量测量误差导致的内生性问题，我们还采用新产品占比( newrate) 进一步衡量企业产品创新情况 从表2 中的回归结果可以看出，新产品占比越高，企业的加成率显著越大<sub>。</sub> 该结论在处理样本选择性偏差和创新选择内生性后仍较为稳健<sub>。</sub> 其他变量与表1 相比也较为稳定，总体来看，企业生产率 资本集中度 用工人数和规模变量越大，企业加成率越高，而人均工资越高加成率越低 这反映出用工成本的上涨会压低企业的成本加成率，而企业通过提升生产率以降低成本和扩大企业规模等手段可以获取更高加成率<sub>。</sub> 但是控制以上这些因素后，企业提升新产品占比仍能显著地提升企业的加成率<sub>。</sub>

## 六 结论

本文从成本加成率角度分析企业获取垄断租金的微观机制 基于 Atkeson 和Burstein(2008) 研究我们分析了产品创新的 <sup>“</sup>市场份额效应<sup>”</sup>影响机理，得到了企业投资创新获得垄断租金的路径之一为: 一方面，企业进行产品创新使得其产品在行业内达到更有利的相对偏好，进而引起企业市场份额的增加 而市场份额的上升又使得企业在市场中的影响力变大，企业的实际需求价格弹性受制于企业市场份额的影响力而变小，最终企业可以在市场上索要更高的成本加成率，获取更大的创新垄断租金，本文称之为产品创新的 <sup>“</sup>市场份额效应<sup>”</sup> 另一方面，产品创新带来的生产率提升促使企业边际成本降低，进而也可以提升加成率，本文称之为产品创新的 <sup>“</sup>成本效应<sup>”</sup>

我们在计量模型中考虑 <sup>“</sup>成本效应<sup>”</sup>的影响，在 DLW 的基础上将企业创新行为纳入生产率动态过程，依据 ACF 两步法估计得到较为稳健的企业可变成本加成率<sub>。</sub> 考虑到创新选择对企业生存的影响，我们还采用 Probit 模型估计了企业退出概率，将企业退出概率作为企业退出的生产率下限，控制了生产函数估计中的 <sup>“</sup>样本选择性偏差<sup>”</sup> 采用2001－2007 年中国工业企业数据估计表明: 企业成本加成率的均值为1.276 至1. 28，不同企业类型之间的加成率差异较大，产品创新企业的市场份额和加成率均高于非创新企业<sub>。</sub>

我们针对产品创新的 <sup>“</sup>市场份额效应<sup>”</sup>和 <sup>“</sup>成本效应<sup>”</sup>进行了经验检验，结果支持了本文的理论预期: 首先，产品创新带来了显著的企业成本加成率提升效应，产品创新企业比非创新企业的成本加成率平均至少高 0.4% <sub>。</sub> 其次，比较是否进行产品创新的企业市场份额核密度分布图发现产品创新的平均市场份额高于非创新企业，回归结果表明市场份额与成本加成率显著正相关，产品创新通过增加市场份额显著提升了企业成本加成率，其通过市场份额渠道提升的幅度均高于 40% 最后，企业生产率提升也有助于提升加成率，产品创新通过边际成本节省也进一步显著地提升了加成率，即存在显著的<sup>“</sup>成本效应<sup>”</sup>，其通过成本渠道提升的幅度高于6%，但 <sup>“</sup>成本效应<sup>”</sup>明显弱于<sup>“</sup>市场份额效应<sup>”</sup>，考虑创新的自选择<sub>、</sub>测量误差和内生性问题后结论仍然稳健<sub>。</sub>

总之，本文论证了企业获取垄断租金的内外双重机制，明确了创新对企业绩效的重大作用 这也从侧面上反映了加大力度激发私营和出口企业创新积极性的重要性，另外，打破国有企业垄断并降低其 <sup>“</sup>创新效率<sup>”</sup>损失对经济发展也具有重大意义 特别是在中国人口红利逐渐丧失的大背景下，中国亟须充分发挥创新具有的持久市场推动力，以抵消经济快速增长后要素边际报酬递减和资源瓶颈的不利影响<sub>。</sub>

Abstract<sup>:</sup> This paper analyzes how firms get monopoly rents from product innovation. Based on Atkeson and Burstein ( 2008) ，we show that product innovation can help firms get more market share from its relative comparative advantage，which can lower its price elasticity and therefore charge higher markups. In addition，product innovation can help reducing the marginal cost and improving the price-cost margin. Using the 2001－2007 firm-level data in China，this paper provides evidence that product innovation can significantly improve firm <sup>’</sup> s markup through both cost and market share channels. The results are robust even after considering the sample selection bias，measurement errors and endogenous problems.
