# 科技金融政策是否提升了企业竞争力?

———来自高新技术上市公司的证据

程 翔 张 瑞 张 峰

内容提要:在创新驱动发展战略背景下研究区域科技金融政策对微观企业竞争力的影响具有重要意义 宏观层面以<sup>2007</sup>—<sup>2017</sup> 年全国<sup>31</sup> 个省份颁布的科技金融政策作为研究对象，设计政策量化手册对科技金融政策进行文本量化; 微观层面构建企业竞争力评价指标体系，选取 <sup>A</sup> 股<sup>558</sup> 家高科技产业上市公司，通过实证模型研究区域科技金融政策对企业竞争力的影响。 结果表明:科技金融政策与企业竞争力呈显著的正相关关系且具有一定滞后性; 不同政策类型 不同市场类型 不同企业性质使得科技金融政策的实施效果不尽相同。

关键词:科技金融政策 企业竞争力 高科技产业 政策量化

## 一<sub>、</sub>问题提出

中国已步入经济高质量发展阶段，科技创新将成为经济持续增长的新引擎和新动能 面对世界百年未有之大变局，综合国力的竞争从微观层面来看也将是个体企业的竞争，科技创新不仅来自企业提升其自身竞争力的内部冲动，也来自外部尤其是政府层面的政策推动 高科技产业上市公司作为创新活动的重要主体，其竞争力不仅反映着中国的科技发展水平，也反映着科技创新政策制定和实施的效果 在资本的视域下审视经济尤其是实体经济与科技创新的关系，建立金融市场联结科技创新的通道，需要更多科技金融政策的颁布和落实。 国家宏观层面的科技金融政策如何影响微观主体的竞争能力，一直以来是政府和学界格外关注和聚焦的问题。

在学术研究领域，科技金融政策作为一种客观性 系统性的政策文本，政策数量繁多 内容复杂，不易于直接对其文本内容进行分析，学者们通过对科技金融政策文献的梳理对科技金融政策进行分析 苑泽明等( <sup>2018</sup>) 对中国科技金融政策评价及其经济效果评价的文献进行梳理，并借鉴公共政策理论构建了科技金融政策的执行分析框架<sup>［1］</sup>; 饶彩霞等( <sup>2013</sup>) 对中国的科技金融政策进行了汇总梳理<sup>［2］</sup>; 唐五湘等( <sup>2013</sup>) 对<sup>2001</sup>—<sup>2012</sup> 年的北京市科技金融政策文本描述统计从政策的总体发展、主体、主题以及作用面等方面进行分析<sup>［3］</sup>; 曲昭等( <sup>2015</sup>) 基于文献计量方法，对科技金融政策研究文献的年度数量 文献类型及来源分布等方面进行了统计分析，并通过主题演化和关键词共现，对科技金融政策内容进行了深入挖掘<sup>［4］</sup>。 相比于对政策文献描述性统计分析，科技金融政策的文本量化分析更适于实证研究与效率测算 利贝卡( <sup>Libecap</sup>，<sup>1978</sup>) 以美国西部矿产权为例，最先对政策进行量化研究<sup>［5］</sup>; 彭纪生等( <sup>2008</sup>) 以技术创新政策为例，在政策量化方面又进一步做了探索性研究<sup>［6］</sup> 科技金融政策作为一种宏观层面的经济调控手段，要通过一定的传导机制才能影响到经济实体，进而达到提升国家科技发展水平的目的。 韩凤芹和罗珵( <sup>2018</sup>) 综合新时期科技金融发展实践中的新特点，提出中国科技金融目前出现了服务对象更精准 投贷联动初见成效 准公共服务属性增强等新进展<sup>［7］</sup>; 邱雨辰( <sup>2017</sup>) 基于双重差分法，发现中国科技金融政策对科技创新的影响从整体上看并不明显，并且其政策投入对不同区域的科技创新效果也不一致<sup>［8］</sup>。 目前对企业竞争力的衡量方法众说纷纭 诺斯和斯莫尔伯恩( <sup>North ＆ Smallbace</sup>，<sup>1996</sup>) 认为应从管理 财务与人口等方面评价企业竞争力，并从企业内部和外部两个角度分别考虑<sup>［9］</sup>; 纽伯特( <sup>Newbert</sup>，<sup>2008</sup>) 认为企业竞争力与企业财务绩效高度相关<sup>［10］</sup>; 莫特艾娃( <sup>Mottaeva</sup>，<sup>2017</sup>) 通过构建企业竞争力指数来衡量企业竞争力，并用其评价了汽车运输企业的竞争力状况<sup>［11］</sup>; 赵冬梅和周荣征( <sup>2007</sup>) 认为建立企业竞争力指标体系应该按照目的性 全面性 可行性通用性和发展性相结合的原则<sup>［12］</sup>; 张进财和左小德( <sup>2013</sup>) 从企业内部与外部发展的关联性出发，从系统工程的角度构建企业竞争力指标体系<sup>［13］</sup> 竞争力是企业各方面能力的综合体现，有些学者通过企业其他方面能力来整体衡量企业竞争力。 王芳( <sup>2015</sup>) 以河南省<sup>58</sup> 家上市公司为研究对象，从盈利能力、经营能力、财务结构 规模实力及增长潜力五个方面，选取了<sup>19</sup> 个主要测量指标建立评价指标体系<sup>［14］</sup>; 杜瑞等( <sup>2016</sup>) 认为用盈利性指标来测算企业竞争力并不准确，企业竞争优势实际上反映了其在行业内的定价能力，因此选取了勒纳指数来衡量高科技企业的竞争力<sup>［15］</sup> 在研究科技金融政策对企业竞争力的影响方面，直接研究科技金融政策对企业竞争力影响的文献较少 汉姆伯格( <sup>Hamberg</sup>，<sup>1966</sup>) 以美国国防部资助的企业作为样本，发现科技金融政策能促进企业增加自主创新投资的力度<sup>［16］</sup>; 莱文和赖斯( <sup>Levin ＆ Reiss</sup>，<sup>1984</sup>) 研究了国家层面政策性金融水平与企业层面自主创新投入之间的关系，发现二者具有显著的关联性<sup>［17］</sup>; 阿尔马斯和查尔尼茨基( <sup>Almus ＆ Czarnitzki</sup>，<sup>2003</sup>) 从国家层面研究发现政策性金融对企业自主创新具有促进作用<sup>［18］</sup>; 查尔茨基和胡辛格( <sup>Czarnitzki ＆ Hussinger</sup>，<sup>2004</sup>) 以专利产出衡量企业的科技水平，研究发现受到政府在金融方面政策资助的企业具有明显竞争优势<sup>［19］</sup>; 卡朱罗瓦和林纳特( <sup>Kajurová ＆ Linnertová</sup>，<sup>2018</sup>) 以捷克企业为样本，研究了宏观层面的宽松货币政策对微观层面企业竞争力的影响<sup>［20］</sup>; 蔺鹏等( <sup>2018</sup>) 基于<sup>2013</sup>—<sup>2016</sup> 年河北省实施的 <sup>112</sup> 项科技金融政策的量化分析，利用灰色关联度耦合计量模型对科技金融政策与科技型中小企业创新绩效的耦合协调程度进行实证检验<sup>［21］</sup>; 李瑞晶等( <sup>2017</sup>) 以<sup>2005</sup>—<sup>2015</sup> 年中小板 创业板<sup>127</sup> 家上市公司及其所处省市的科技金融投入均衡面板数据为例，建立动态面板系统 <sup>GMM</sup> 模型，实证检验不同渠道的区域科技金融投入对中小企业创新能力提升的影响<sup>［22］</sup>

通过文献的梳理，可以发现以往对科技金融政策的研究往往只局限于宏观层面的研究，缺乏对企业微观主体尤其是企业竞争力影响层面的研究，这为本文提供了新的研究空间。本文将在宏观层面对科技金融政策进行文本量化，在微观层面构建企业竞争力评价指标体系，通过实证模型研究科技金融政策与企业竞争力之间的关系，进而判断宏观科技金融政策对微观企业竞争力的影响。

## 二、区域科技金融政策的文本量化分析

## ( 一) 政策文本数据来源

根据科技金融政策中涉及的 <sup>“</sup>金融<sup>”</sup>来源的不同，可以将科技金融政策分为五个类型，具体为: 财政科技投入政策、科技信贷与担保政策、科技资本市场政策、科技保险政策与综合类科技金融政策。

本文运用 <sup>《</sup>中国法律检索系统<sup>》</sup>( 北大法宝) 对科技金融政策进行收集，参考唐五湘等( <sup>2013</sup>)<sup>［3］</sup>的做法，通过设定<sup>“</sup>科技金融<sup>” “</sup>科技保险<sup>”</sup>等关键词对政策文本进行搜索，进而筛选出各省份的科技金融政策 本文收集了<sup>2007</sup>—<sup>2017</sup> 年全国<sup>31</sup> 个省份( 不含港澳台地区) 的科技金融政策。

## <sup>2．</sup> 量化方法

按照上述标准，本文对每一项科技金融政策分别在政策力度 政策目标以及政策措施三个维度进行打分，分值均为1\~5分。根据打分标准得到的三个分数，通过进一步计算得出每一项科技金融政策的量化值，具体计算方法如式<sup>1</sup> 所示

$$
S T F P _ {i t} = \sum_ {j = 1} ^ {n} \left(G _ {j} + M _ {j}\right) P _ {j}\tag{1}
$$

式中 <sup>i</sup> 为科技金融政策的颁布省份; <sup>t</sup> 为科技金融政策的颁布时间; <sup>j</sup> 为第 <sup>i</sup> 个省份、第 <sup>t</sup> 年颁布的第 <sup>j</sup> 项政策; <sup>n</sup> 为第<sup>i</sup> 个省份 第<sup>t</sup> 年颁布的政策的项数; $G _ { j }$ 表示第<sup>j</sup> 项政策的政策目标( $g o a l )$ 得分; $M _ { j }$ 表示第<sup>j</sup> 项政策的政策措施( <sup>measure</sup>) 得分; $\mathcal { \hat { P } } _ { j } ^ { \mathrm { c } }$ 表示第 <sup>j</sup> 项政策的政策力度( <sup>power</sup>) 得分; $\mathrm { \Sigma } _ { S T F } ^ { \mathrm { * } \mathrm { l } \mathrm { | } } \mathrm { \Sigma } _ { i t } ^ { \mathrm { * } \mathrm { i } }$ 为第 <sup>i</sup> 个省份 第 <sup>t</sup> 年的科技金融政策的最终量化值，反映了具体省份在具体年份科技金融政策的整体状况。

## ( 一) 企业竞争力指标体系的建立

在企业竞争力的评价中，选取单个指标作为企业竞争力的代理指标是一种常见的做法<sup>［15，24</sup> <sup>－</sup> <sup>25］</sup>，此法虽操作简单 数据易获取，但难以全面 系统地描绘出企业的竞争力画像 与之比较，构建综合指数可以更好地实现不同企业之间的比较，进而得到更加科学、准确、全面的企业竞争力评价体系。

## <sup>1．</sup> 企业竞争力指标体系

关于企业竞争力的评价，金培( <sup>2003</sup>) 力是一个认为竞争内涵和外延都难以精确界定的概念，对竞争力的评价应当从其外在表现与内部原因两方面展开<sup>［26］</sup> 在此基础上，本文根据已提出的指标体系构建原则将企业竞争力划分为显性竞争力与潜在竞争力。

## <sup>2．</sup> 指标权重的确定

( <sup>2</sup>) 指标权重确定方法。 本文采用主观赋权法和客观赋权法相结合的组合赋权法来确定各指标的权重系数 具体而言，对于二级指标采用主观赋权的方法，对于三级指标采用客观赋权的方法 主观赋权法主要采用专家会议法; 客观赋权法主要采用熵权法。 熵值法确定指标权重系数的具体步骤如下:

第一步: 将各指标进行非负化处理，鉴于指标体系中都为正向指标，按照如下公式进行操作:

$$
X _ {a b} = \frac {x _ {a b} - x _ {\min}}{x _ {\max} - x _ {\min}}\tag{2}
$$

其中， ${ \mathsf { \Omega } } _ { \bullet } X _ { a b }$ 为非负化处理后指标值; $x _ { a b }$ 为各项指标的原始值; $x _ { \mathrm { m i n } }$ 和 $x _ { \mathrm { m a x } }$ 分别为各指标中的最小值和最大值，非负化处理同时也使得各指标实现无量纲化;

第二步: 计算第 <sup>j</sup> 个指标下第 <sup>i</sup> 个方案的贡献度 $P _ { i j } \mathrm { : }$ :

$$
P _ {i j} = \frac {x _ {i j}}{\sum_ {i = 1} ^ {m} x _ {i j}}\tag{3}
$$

其中 $\pmb { \mathscr { s x } } _ { i j }$ 代表第 <sup>j</sup> 个指标下第 <sup>i</sup> 个方案的观测数值， $\mathbf { \nabla } m$ 为待评方案总数。

第三步: 计算第 <sup>j</sup> 项指标的熵值 $E _ { j }$ :

$$
E _ {j} = - k \sum_ {i = 1} ^ {m} P _ {i j} \times \ln P _ {i j}\tag{4}
$$

其中，常数 $k = \frac { 1 } { \mathbf { l n } m }$ ，当 $P _ { i j } = 0$ 时，令 $P _ { i j } \mathrm { l n } P _ { i j } = 0$

第四步: 计算第 <sup>j</sup> 项指标的权重 $W _ { j }$ :

$$
d _ {j} = 1 - E _ {j}\tag{5}
$$

$$
W _ {j} = \frac {d _ {j}}{\sum_ {j = 1} ^ {n} d _ {j}}\tag{6}
$$

其中 $\bullet ^ { d _ { j } }$ 为第 $j$ 项指标的差异性系数， $\bullet n$ 为所有参与熵权计算的指标数目。

## 四、实证设计与结果分析

## ( 一) 研究假设

科技金融是第一生产力与第一推动力的结合，其目标是实现第一竞争力<sup>［31］</sup>。 科技金融在推动科技发展方面大有可为。 科技金融的目标为科技，但其本质仍然为金融，金融资本的支持是科技水平提升以及科技型企业增长的重要引擎 <sup>［32］</sup>，关于金融对科技的推动作用，亚历山德拉和斯通曼( <sup>Alessandra ＆ Stoneman</sup>，<sup>2008</sup>) 利用英国的数据发现金融发展与技术创新之间具有正相关关系<sup>［33］</sup>，本弗拉泰洛等( <sup>Benfra tello et al．</sup>，<sup>2008</sup>) 利用意大利的企业数据再次验证了金融投入与科技动力之间的正相关关系<sup>［34］</sup> 科技金融作为一种主体高度明确的专项金融，与普通的金融资本支持相比，可以在更大程度上促进科技水平的发展 科技金融可以发挥财政 信贷 保险 资本市场等多方面的金融力量支持各种形式的科技创新发展 科技金融可以极大促进科技发展，而政策是科技金融的灵魂，并且高科技上市公司的企业竞争力又是科技水平的重要表现者，故科技金融政策与企业竞争力之间便可能具有一定相关性 在另一层面，科技金融政策本身会对企业产生直接的影响，提升高科技企业对于创新活动的心理预期与信心水平，为企业营造一个更好的创新环境与社会氛围。 同时，科技金融政策能够降低企业的科技创新风险和成本，可以对企业创新效率产生积极影响35。并且科技金融政策能够提升企业的技术创新水平，而企业的技术创新对企业竞争优势又至关重要<sup>［15］</sup> 因此，科技金融政策可以对企业层面的竞争力产生巨大的推动作用，二者具有显著的正相关关系，具体如图<sup>1</sup> 所示 科技金融政策作为政府层面颁布的政策，其在出台之后都需要沿着政策路径传导一段时间，才会深入影响到微观主体与宏观经济，由此产生了政策的外部时滞 由于科技金融政策通过引导各类资源投入企业技术开发创新活动<sup>［30］</sup>，所以其传导路径也将会复杂多样 科技金融政策首先会提升科技金融的力

度，其次会增强金融手段对科技发展的支持力度，进而影响到企业的技术创新与竞争力，因而具有较长的外部时滞。 另外，科技金融政策的颁布改善了科技金融整体环境与微观企业的心理预期，但环境与心理预期对于企业的改变是潜移默化的，企业需要一定时间去调整与适应新的政策环境，最终表现在企业竞争力上也会具有一定的时间滞后 综合以上分析，本文提出如下两个假设:

假设 <sup>H1</sup>: 科技金融政策可以显著提升企业竞争力。

假设 <sup>H2</sup>: 科技金融政策具有滞后性。

## <sup>4．</sup> 稳健性检验

参考甄珍等( <sup>2013</sup>)<sup>［25］</sup>对企业竞争优势的测度方法，本文直接以营业收入的自然对数作为企业竞争力的代理变量，分别对当期科技金融政策与滞后一期科技金融政策进行回归 根据回归结果，当期与滞后一期的科技金融政策仍对企业竞争力有显著的正向作用，并且滞后一期的估计系数要大于当期的估计系数，滞后一期的调整后的 $R ^ { 2 }$ 略微提升，仍表明科技金融政策具有滞后性。 由此可知，科技金融政策与企业竞争力的回归结果稳健。

## 五、研究结论与建议

## ( 一) 研究结论

本文在宏观层面以<sup>2007</sup>—<sup>2017</sup> 年全国<sup>31</sup> 个省份颁布的科技金融政策作为研究对象，设计政策量化手册对科技金融政策进行文本量化; 在微观层面构建企业竞争力评价指标体系，选取 <sup>A</sup> 股<sup>558</sup> 家高科技产业上市公司，构建面板数据模型，进行多种回归分析与检验，来探究科技金融政策与企业竞争力之间的关系。研究结果显示: ( <sup>1</sup>) 区域科技金融政策与企业竞争力呈显著的正相关关系，表明政府在宏观层面颁布的科技金融政策对微观企业起到了显著的支持作用，有较好的政策效果，能够提升企业的竞争力 ( <sup>2</sup>) 滞后一期的科技金融政策与企业竞争力也呈显著的正相关关系，且估计系数显著提升 这表明科技金融政策具有滞后性，从政策制定出台到具体部门落实 再到市场确认 政策效果显现，传导过程具有时滞性 ( <sup>3</sup>) 财政科技投入政策与科技资本市场政策在提升高科技企业竞争力方面效果更为显著，科技保险政策与综合类科技金融政策有着相对较长的政策时滞，而科技信贷与担保政策在长期的效果并不理想 ( <sup>4</sup>) 在不同板块下，科技金融政策均对企业竞争力有显著的影响，其中对深圳主板市场上市企业竞争力有着更强的解释力 ( <sup>5</sup>) 科技金融政策对不同性质的企业竞争力均有正向影响，但是对国有企业竞争力的提升较之民营企业更为显著

## ( 二) 建议

科技金融政策是释放创新潜能 提升企业竞争力的重要助推器，为更好地发挥其效果，本文提出以下建议：(1)科技金融政策的颁布要注意政策内容的连贯性和前瞻性。区域科技金融政策的效果由宏观层面传达到微观企业层面需要一定的时间，因此颁布的政策在内容上需要前后连贯，当期颁布的科技金融政策需要考虑前期政策效果的释放，要长远、系统地考虑科技金融政策的颁布，以发展和前瞻的眼光制定和颁布科技金融政策 ( <sup>2</sup>) 协调不同类型的科技金融政策，政策的颁布要综合考虑不同类型科技金融政策的特点五类科技金融政策的侧重点也不同，其发挥作用的阶段也不同，政策的颁布要充分统筹和调动财政 信贷保险与资本市场等各方力量，形成科技金融政策的合力; 在政策实施过程中政府要充分发挥引导作用，灵活发挥各类科技金融政策的优势，使之相辅相成 优势互补 ( <sup>3</sup>) 提升科技金融政策的知晓率 由于科技金融政策的制定涉及多个部，要強化客部的协调，升编制和发放料技金政策知晓手册，利用经信委等平台 政府各部门 <sup>APP</sup> 企业微信群等多渠道加大对企业尤其是民营企业的科技金融政策宣传力度，以更好地助力科技金融政策的落地<sub>。</sub> ( <sup>4</sup>) 建立科技金融政策的企业反馈机制，微观企业是宏观政策效果的最终体现者，应当根据企业在科技创新方面的表现对科技金融政策的效果做出评估，加强政府与企业间的良性互动，激发企业参与活力，结合企业需求强化科技金融政策引导以提高政策效率。
